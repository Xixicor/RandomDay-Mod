# RandomDay v0.3.16-alpha

RandomDay rotates an Abiotic Factor world's sandbox rules at the safe
next-start boundary. This release includes two complete downloads.

## Downloads

- `RandomDay_v0.3.16-alpha_DedicatedServer.zip` for persistent or temporary
  dedicated servers.
- `RandomDay_v0.3.16-alpha_SingleplayerLAN.zip` for the manual-copy local-world
  workflow.

Do not combine the packages.

## Highlights

- Seventeen profile families with seventeen profiles per family.
- Configured or random starting profile.
- Sequential or non-repeating random progression.
- Separate active and prepared profile state.
- Bounded player notices and optional supported-mod adapters.
- Verified backups, readback, and rollback around sandbox writes.
- English documentation plus 27 localized entry pages.

Read `INSTALL.md` before replacing an existing installation.
