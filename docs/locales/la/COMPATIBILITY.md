<a id="supported-installations"></a>
## Fontae officinae

RandomDay is built for Abiotic Factor installations that can load UE4SS Lua mods.

| Environment | Support | Package |
| --- | --- | --- |
| Fenestra dedicata servo | Suffitus | Dedicated-server ZIP |
| Windows singleplayer or LAN host | manualis-copia subnixus workflow | Singleplayer/LAN ZIP |
| Linux servo utens Vino vel Proton | Non emissio probata | In Fenestra dicata sarcina ab peritis operariis aestimari potest, sed nulla compatibilitas promissio facta est. |
| Xbox et PlayStation | Non suffulta | Hae tabulae accessum tabellae non praebent et UE4SS Lua via loading ab hac remissione requiritur. |

RandomDay duas sarcinas non coniungit. Servo dicato qui tantum in fabula occasionali inchoata est, adhuc dedicato servitori ZIP utitur et mores temporales in configuratione deligit.

## Abiotic Factor updates
