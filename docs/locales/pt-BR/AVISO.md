RandomDay é um mod comunitário independente para servidores dedicados do Abiotic Factor.

RandomDay não inclui, copia, hospeda novamente ou redistribui código de mods de terceiros suportados. A integração opcional é feita por meio de RandomDay-owned scripts de adaptador que corrigem configurações expostas somente quando o proprietário do servidor instalou esses mods suportados separadamente.
