# Contribuição

> **Fonte canônica em inglês:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Essa documentação localizada preserva comandos, caminhos, chaves, valores de status, hashes e nomes de arquivos exatos. Se o texto técnico for diferente, use a fonte em inglês.


RandomDay é mantido como um projeto controlado.

Solicitações pull públicas, envios de código não solicitados, reescritas automatizadas, envios de limpeza de código gerado e patches de recursos especulativos não são aceitos, a menos que solicitados explicitamente pelo proprietário do repositório.

<a id="accepted-contact"></a>
## Aceito contato

Para relatórios de bugs, notas de compatibilidade ou observações de administração do servidor, use os canais de contato listados na documentação do projeto.

<a id="not-accepted"></a>
## Não aceito

Os itens a seguir não são aceitos por padrão:

- solicitações pull não solicitadas;
- código gerado reescritas;
- refatorações amplas;
- alterações de formatação somente de estilo;
- alterações de lógica de jogo não testadas;
- arquivos mod de terceiros agrupados;
- código-fonte de terceiros redistribuído;
- alterações que impliquem afiliação oficial à Abiotic Factor, UE4SS, Nexus Mods ou autores de mods terceirizados.

<a id="controlled-development"></a>
## Desenvolvimento controlado

O proprietário do repositório pode solicitar revisão específica, testes ou ajuda com documentação quando necessário. Envios não solicitados podem ser encerrados sem revisão.
