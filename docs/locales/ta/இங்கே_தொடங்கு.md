# இங்கே தொடங்கவும்: முதலில் முடிக்கவும் RandomDay சுழற்சி

> **நியாய ஆங்கில மூல:** [START_HERE.md](../../START_HERE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்த வழிகாட்டி RandomDay நிறுவப்பட்டது. மோட் என்ன மாறுகிறது, எதைத் தனியாக விட்டுச் செல்கிறது மற்றும் ஒரு வெற்றிகரமான சுழற்சியை எவ்வாறு அங்கீகரிப்பது என்பதை இது காட்டுகிறது.

<a id="know-the-two-states"></a>
## இரண்டு நிலைகளை அறியவும்

Abiotic Factor உலகின் சாண்ட்பாக்ஸ் அமைப்புகளை இதற்கு முன் படிக்கிறது RandomDay தொடங்குகிறது. RandomDay எனவே தெளிவாக பெயரிடப்பட்ட இரண்டு நிலைகளை வைத்திருக்கிறது:

- **செயலில் உள்ள சுயவிவரம்:** தற்போதைய அமர்வு ஏற்கனவே பயன்படுத்தும் விதிகள்.
- **தயாரிக்கப்பட்ட சுயவிவரம்:** அடுத்த தொடக்கத்திற்கான விதிகள் சேமிக்கப்பட்டன.

தயாரிக்கப்பட்ட சுயவிவரமானது ஏற்கனவே செயலில் உள்ள அமர்வை மாற்றாது.

<a id="dedicated-server-prepare-the-next-profile"></a>
## பிரத்யேக சேவையகம்: அடுத்த சுயவிவரத்தை தயார் செய்யவும்

1. சேவையகத்தை சாதாரணமாகத் தொடங்கவும்.
2. காத்திருங்கள் RandomDay அதன் தொடக்கப் பணியை முடிக்க.
3. திற `RandomDay/web_export/today.html`.
4. கண்டுபிடி **செயலில் உள்ள சுயவிவரம்** மற்றும் **தயாரிக்கப்பட்ட சுயவிவரம்**.

முதல் வெற்றிகரமான தொடக்கத்தில், பக்கம் ஏற்கனவே செயலில் உள்ள விதிகளை பெயரிட வேண்டும் மற்றும் அடுத்த தொடக்கத்திற்காக காத்திருக்கும் வேறு சுயவிவரம். தேர்ந்தெடுக்கப்பட்ட குடும்பம், நிலை மற்றும் தயாரிக்கப்பட்ட கோப்பு அதன் பாதுகாப்புச் சரிபார்ப்பை நிறைவேற்றியதா என்பதையும் பக்கம் விளக்குகிறது.

நிலையை மாற்றுவதற்காக மட்டும் மறுதொடக்கம் செய்ய வேண்டாம். அடுத்த திட்டமிடப்பட்ட சர்வர் தொடங்கும் வரை செயலில் உள்ள விதிகளுடன் விளையாடுவதைத் தொடரவும்.

<a id="dedicated-server-activate-it-later"></a>
## பிரத்யேக சேவையகம்: பின்னர் செயல்படுத்தவும்

1. அடுத்த திட்டமிடப்பட்ட மறுதொடக்கத்தில் சேவையகத்தை நிறுத்தி தொடங்கவும்.
2. படிக்கக்கூடிய நிலைப் பக்கத்தை மீண்டும் திறக்கவும்.
3. முன்பு தயாரிக்கப்பட்ட சுயவிவரம் இப்போது செயலில் உள்ளதாக பட்டியலிடப்பட்டுள்ளதை உறுதிப்படுத்தவும்.
4. அதை உறுதிப்படுத்தவும் RandomDay பின்வரும் சுயவிவரத்தைத் தயாரித்தது.

தயாரிப்பு-பின்-செயல்படுத்தும் மாற்றம் ஒரு முழுமையானது RandomDay சுழற்சி.

<a id="temporary-dedicated-servers"></a>
## தற்காலிக பிரத்யேக சேவையகங்கள்

தற்காலிக நடத்தை அதே dedicated-server தொகுப்பைப் பயன்படுத்துகிறது. [உள்ளமைவு](%E0%AE%89%E0%AE%B3%E0%AF%8D%E0%AE%B3%E0%AE%AE%E0%AF%88%E0%AE%B5%E0%AF%81.md), ஒரு குறிப்பிட்ட சுயவிவரத்தில் புதிய ரன் தொடங்குகிறதா அல்லது சீரற்ற தொடக்கப் புள்ளியைத் தேர்ந்தெடுக்க வேண்டுமா என்பதைத் தேர்ந்தெடுக்கவும். நிலைப் பக்கம் இன்னும் செயலில் உள்ள சுயவிவரத்தை அடுத்த தொடக்கத்திற்குத் தயார் செய்ததில் இருந்து பிரிக்கிறது.

<a id="singleplayer-or-lan"></a>
## Singleplayer அல்லது LAN

1. singleplayer/LAN தொகுப்பு நிறுவப்பட்டது.
2. பின்னர் கேமை முழுவதுமாக மூடு RandomDay முடிந்தது.
3. உருவாக்கப்பட்ட சுருக்கத்தைப் படிக்கவும்.
4. உருவாக்கியதை நகலெடுக்கவும் `SandboxSettings.ini` கேம் மூடப்பட்டிருக்கும் போது நீங்கள் தேர்ந்தெடுத்த உலகத்திற்கு.
5. அந்த உலகத்தைத் தொடங்கி, எதிர்பார்க்கப்படும் விதிகளை உறுதிப்படுத்தவும்.

உள்ளூர் தொகுப்பு ஒரு உலகத்தைத் தேர்ந்தெடுக்காது அல்லது கோப்பை தானாகவே சேமிப்பில் நகலெடுக்காது. பார்க்கவும் [Singleplayer மற்றும் LAN](SINGLEPLAYER_LAN.md).

<a id="if-the-expected-result-is-missing"></a>
## எதிர்பார்த்த முடிவு விடுபட்டால்

மறுதொடக்கம் செய்ய வேண்டாம். தற்போதைய கோப்புகளைப் பாதுகாத்து, [சரிசெய்தல்](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%9A%E0%AF%86%E0%AE%AF%E0%AF%8D%E0%AE%A4%E0%AE%B2%E0%AF%8D.md). இயல்பான முடிவு எப்போதும் செயலில் உள்ள சுயவிவரம் மற்றும் தயாரிக்கப்பட்ட சுயவிவரம் அல்லது ஒரு தெளிவான தயாரிப்பில் தோல்வி என்று பெயரிடுகிறது.
