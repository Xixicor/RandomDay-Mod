# அகராதி

> **நியாய ஆங்கில மூல:** [GLOSSARY.md](../../GLOSSARY.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இது RandomDay ஆவணங்கள். பல வழிகாட்டிகளில் ஒரே நிலையை மறுவரையறை செய்வதற்குப் பதிலாக இந்த வரையறைகளுடன் செயல்முறைகள் இணைக்கப்படுகின்றன. திட்டவட்டமான புல விதிகள் [இயக்க நேர வெளியீடுகள்](%E0%AE%87%E0%AE%AF%E0%AE%95%E0%AF%8D%E0%AE%95_%E0%AE%A8%E0%AF%87%E0%AE%B0_%E0%AE%B5%E0%AF%86%E0%AE%B3%E0%AE%BF%E0%AE%AF%E0%AF%80%E0%AE%9F%E0%AF%81%E0%AE%95%E0%AE%B3%E0%AF%8D.md).

| காலம் | தெளிவான பொருள் | சரியான தொழில்நுட்ப பொருள் |
|---|---|---|
| செயலில் உள்ள சுயவிவரம் | தற்போதைய அமர்வு பயன்படுத்தும் விதிகள். | தி family/day சுயவிவரம் RandomDay செயல்முறை தொடக்கத்தில் சாண்ட்பாக்ஸிலிருந்து மார்க்கர் படிக்கப்பட்டது. |
| தயாரிக்கப்பட்ட சுயவிவரம் | பிறகு அமர்வுக்கு விதிகள் தயார். | முழுமை family/day சுயவிவரம், அதன் இலக்கு பைட்டுகள் சரிபார்ப்பு மற்றும் ரீட்பேக்கை கடந்து சென்றது மற்றும் அதன் சுழற்சி நிலை உறுதி செய்யப்பட்டது. ரீட்பேக்கை மறுதொடக்கம் செய்வதற்கு முன் அது செயலில் இல்லை. |
| மீட்டெடுக்கப்பட்டது | தயாரிப்பு தோல்வியடைந்தது மற்றும் முன் சரிபார்க்கப்பட்ட பைட்டுகள் மீண்டும் வைக்கப்பட்டன. | தோல்வியுற்ற பரிவர்த்தனையானது வெற்றிகரமான திரும்பப் பெறுதல் மற்றும் மீட்டெடுக்கப்பட்ட அசல் அல்லது சரிபார்க்கப்பட்ட மீட்டெடுப்பு நகலைத் திரும்பப் பெறுவதாகப் புகாரளிக்கிறது. |
| அடுத்த மறுதொடக்கம் வரிசை | அடுத்த துவக்கத்திற்கு ஒரு தயாரிக்கப்பட்ட தேர்வு உள்ளது. | `next_reboot_queue` ஒரு செயல்முறைக்கு ஒரு முறை தேர்ந்தெடுக்கிறது மற்றும் மேற்பார்வையின் போது அந்த துவக்க-சொந்தமான தேர்வை மீண்டும் பயன்படுத்துகிறது. |
| பூட்ஸ்டார்ப் | செயலில் குறிப்பான் இல்லாத போது முதல் தயாரிப்பு. | தகுதியுள்ள குடும்பத்திலிருந்து உள்ளமைக்கப்பட்ட அல்லது சீரற்ற முதல் நாளைத் தேர்ந்தெடுப்பது; `cycle.bootstrap_day` என்பது ஒரு பொருந்தக்கூடிய பின்னடைவு மட்டுமே. |
| குடும்பம் | 17-நாள் பிளேஸ்டைல் ​​முன்னேற்றம். | ஒரு பதிவேட்டில் உள்ளீடு மற்றும் சரியாக 17 முழு சுயவிவரங்களை உருவாக்கும் குடும்ப தொகுதி. |
| சுழற்சி | தகுதியுள்ள குடும்பங்கள் மூலம் ஒரு பாஸ். | நிலை அடையாளம் `rotation_id`, கிடைக்கும், மீதமுள்ள மற்றும் நிறைவு செய்யப்பட்ட குடும்பப் பட்டியல்கள். |
| இயக்கு | 17 நாள் ஐடிகளில் ஒரு குடும்பம். | குடும்பத்திற்கு உட்பட்ட வரிசை `run_id`; ஒவ்வொரு நாள்-ஆர்டர் நிலையும் முடிவடையும் வரை குடும்பம் பூட்டப்பட்டிருக்கும். |
| அமர்வு முறை | இந்த தொகுப்பை இயக்குபவர் எவ்வாறு பயன்படுத்துகிறார். | `persistent_dedicated`, `temporary_dedicated`, அல்லது `singleplayer_lan`; தொகுப்பு பயன்முறை கோப்பு முறைமை எல்லையை இன்னும் கட்டுப்படுத்துகிறது. |
| நாள் ஆர்டர் | ஒரு குடும்ப இயக்கம் பயன்படுத்தும் சரியான வரிசை. | 17-எண் வரிசைமாற்றம் தொடர்ந்தது. தொடர் முறை அதன் தொடக்க நாளிலிருந்து மறைகிறது; சீரற்ற பயன்முறை மீண்டும் மீண்டும் இல்லாமல் ஒருமுறை மாற்றப்படும். |
| குறிப்பான் | சாண்ட்பாக்ஸ் கோப்பில் அடையாளம் சேமிக்கப்பட்டுள்ளது. | `RANDOMDAY_*` புலங்கள் முழு சுயவிவரத்துடன் கொடுக்கப்பட்டு அடுத்த செயல்முறை தொடக்கத்தில் படிக்கப்படும். |
| தயாரானது | எழுதும் நிலையும் வெற்றியடைந்தது. | `prepared_ready=true` க்கு வெற்றிகரமான சாண்ட்பாக்ஸ் முடிவு தேவை மற்றும் மாநில-கமிட் தோல்வி இல்லை. இது செயல்படுத்தப்படுவதை நிரூபிக்கவில்லை. |
| ஏற்கனவே நடப்பு | இலக்கு ஏற்கனவே உத்தேசிக்கப்பட்ட பைட்டுகளைக் கொண்டுள்ளது. | ரெண்டர் செய்யப்பட்ட சுயவிவர ஹாஷ் இலக்குடன் பொருந்துகிறது, எனவே RandomDay சரிபார்க்கிறது last-good/mirror முதன்மையை மீண்டும் எழுதாமல் வேலை செய்கிறது. |
| குறைந்த நிலை நிலைத்தன்மை | சாண்ட்பாக்ஸ் பைட்டுகள் வெற்றி பெற்றன, ஆனால் சுழற்சி கணக்குப்பதிவு செய்யவில்லை. | `profile_status=degraded_state_persistence`; அடாப்டர்கள் மற்றும் தயாரிக்கப்பட்ட சுயவிவர செய்திகள் தவிர்க்கப்பட்டன. |
| நிலுவையிலுள்ள கோப்பு | வேட்பாளர் பைட்டுகள் இன்னும் விளம்பரப்படுத்தப்படவில்லை. | `<target>.randomday.pending`, எழுதப்பட்ட, மீண்டும் படிக்க மற்றும் மாற்றுவதற்கு முன் சரிபார்க்கப்பட்டது. |
| ரோல்பேக் கோப்பு | மாற்றத்தின் போது வைத்திருக்கும் அசல். | `<target>.randomday.rollback`, விளம்பரம் அல்லது சரிபார்ப்பு தோல்வியில் உற்பத்தியை மீட்டெடுக்கப் பயன்படுகிறது. |
| செயல்பாட்டு காப்புப்பிரதி | மாற்றத்திற்கு முன் செய்யப்பட்ட நீடித்த நகல். | இன் கீழ் சரிபார்க்கப்பட்ட கோப்பு `runtime/backups/` முதன்மை, கண்ணாடி அல்லது அடாப்டர் பரிவர்த்தனைக்கு. |
| கடைசியாக அறியப்பட்டது | சமீபத்திய சாண்ட்பாக்ஸ் மீட்டெடுக்கப்பட்டது. | `runtime/last_good/SandboxSettings.ini` கூட்டல் `manifest.lua`; இந்த ஜோடி சுயவிவர அடையாளத்தையும் ஹாஷையும் பதிவு செய்கிறது. |
| மிரர் | விருப்பமான இரண்டாவது சாண்ட்பாக்ஸ் இலக்கு. | வெளிப்படையாக உள்ளமைக்கப்பட்ட அல்லது உலகப் பெயரால் பெறப்பட்ட இலக்கு அதன் சொந்த பரிவர்த்தனை மூலம் முதன்மைக்குப் பிறகு எழுதப்பட்டது. |
| பேக்கேஜ் பயன்முறை | வெளியீட்டுச் சொத்தால் தேர்ந்தெடுக்கப்பட்ட எல்லையை நிறுவவும். | `dedicated_server` அல்லது `singleplayer_manual` இலிருந்து `.randomday_mode`. |
| கையேடு-நகல் பயன்முறை | Singleplayer/LAN கண்டுபிடிப்பைச் சேமிக்காமல் உருவாக்குதல். | `singleplayer_manual` உள்ளே மட்டுமே எழுதுகிறது `runtime/singleplayer_manual/` மற்றும் அடாப்டர்கள் மற்றும் கண்ணாடிகளை முடக்குகிறது. |
| அடாப்டர் | RandomDay-owned மற்றொரு நிறுவப்பட்ட மோட் மேப்பிங். | காப்புப் பிரதி மற்றும் இணக்கத்தன்மை சரிபார்ப்புகளுக்குப் பிறகு மட்டுமே ஏற்கனவே உள்ள பணிகளைப் புதுப்பிக்கும் கையொப்பம் கொண்ட பரிவர்த்தனைத் திட்டம். |
| அங்கீகரிக்கப்பட்ட தளவமைப்பு | சரியான அடாப்டர் கோப்பு வடிவம் எழுதுவதற்கு ஏற்றுக்கொள்ளப்பட்டது. | தேவையான அனைத்து கையொப்ப விசைகளும் இலக்கு கோப்புகளும் உள்ளன; கோப்பு பெயர் மட்டும் போதாது. |
| `not_installed` | விருப்ப இலக்கு காணப்படவில்லை. | மாற்றம் இல்லாத பாதுகாப்பான அடாப்டர் விளைவு. |
| `skipped_incompatible` | ஒரு இலக்கு உள்ளது ஆனால் அதன் வடிவம் ஆதரிக்கப்படவில்லை. | முழுமையான கையொப்பம் பொருந்தாததால் எந்த மாற்றமும் இல்லாத பாதுகாப்பான அடாப்டர் விளைவு. |
| `failed_rolled_back` | ஒரு மாற்றம் தோல்வியடைந்தது மற்றும் முந்தைய பைட்டுகள் அப்படியே உள்ளன. | மாற்றத்திற்கு முன் அடாப்டர் பரிவர்த்தனை தோல்வியடைந்தது அல்லது பாதிக்கப்பட்ட அனைத்து கோப்புகளும் மீட்டமைக்கப்பட்டு சரிபார்க்கப்படும். |
| `rollback_failed` | தானியங்கு மீட்டெடுப்பை சரிபார்க்க முடியவில்லை. | ஹார்ட்-ஸ்டாப் அடாப்டர் நிலை, பதிவு செய்யப்பட்ட காப்புப்பிரதியிலிருந்து கைமுறையாக மீட்டெடுக்க வேண்டும். |
| அகராதி | மூல மதிப்புகளிலிருந்து பொது விளக்கங்களுக்கு மேப்பிங். | `randomday_dictionary_v2`, `dictionary.lua` மற்றும் இயக்க நேர நிலை வெளியீட்டில் சேர்க்கப்பட்டுள்ளது. |
