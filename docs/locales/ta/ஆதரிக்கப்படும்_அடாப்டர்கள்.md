# ஆதரிக்கப்படும் விருப்ப முறைகள்

> **நியாய ஆங்கில மூல:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


RandomDay செயலில் உள்ளதை பின்தொடர தனித்தனியாக நிறுவப்பட்ட மோட் செய்ய முடியும் RandomDay சுயவிவரம். இந்த அம்சம் அர்ப்பணிக்கப்பட்ட-சர்வர் தொகுப்பில் மட்டுமே கிடைக்கும். தி singleplayer/LAN தொகுப்பு மற்றொரு mod ஐ திருத்தாது.

RandomDay இங்கு பட்டியலிடப்பட்டுள்ள எந்த மோட்களையும் சேர்க்கவில்லை அல்லது மறுவிநியோகம் செய்யவில்லை. ஒவ்வொரு விருப்ப மோட்களையும் அதன் சொந்த Nexus பக்கத்திலிருந்து நிறுவி இயக்கவும் மற்றும் முதலில் அதன் ஆசிரியரின் வழிமுறைகளைப் பின்பற்றவும். RandomDay மாற்றுகிறது. இது மற்றொரு மோடில் அம்சங்களைச் சேர்க்காது, மேலும் அந்த மோடை நிறுவல் நீக்காமல் ஒரு அடாப்டரை முடக்கலாம். அர்ப்பணிக்கப்பட்ட சர்வர் தொகுப்பு `external_mods.enabled = true`.

## என்ன RandomDay மாற்றங்கள்

| விருப்ப ஒருங்கிணைப்பு | செயலில் உள்ள சுயவிவரத்திலிருந்து தேர்ந்தெடுக்கப்பட்ட அமைப்புகள் |
| --- | --- |
| குழப்பமான ஸ்பான் எஞ்சின் / DynamicSpawns | வன் முறை, player/area கூல்டவுன் நடத்தை, புயல் மற்றும் வெப்ப மண்டல செயல்பாடு, முதலாளி மற்றும் பர்ஸ்ட் ஸ்பான்கள், ஸ்பான்-சைக்கிள் டைமிங், சிறிய மற்றும் பெரிய கூல்டவுன் வரம்புகள், ஸ்பான் தூரம், global/local/mod தொப்பிகள், போர்டல்-புயல், ஆர்டர்-மீறல் மற்றும் முதலாளி வாய்ப்புகள் மற்றும் ஒரு பகுதிக்கு குறைந்தபட்ச ஸ்பான்கள். |
| விருப்பமான குழப்பமான ஸ்பான் எஞ்சின் நீட்டிப்பு புலங்கள் | நிறுவப்பட்டபோது `SharedData.lua` ஏற்கனவே உள்ளது RandomDay நீட்டிப்பு புலங்கள், அடாப்டர் என்கவுண்டர் சுயவிவரம், அடுக்கு, தீம், குழு வரம்புகள், சிறப்பு நிகழ்வு மற்றும் கலப்பு-சந்திப்பு மதிப்புகள், பட்ஜெட், கூல்டவுன் மற்றும் உலக நோக்கக் கட்டுப்பாடுகளை வழங்க முடியும். இது பதிவிறக்குவதற்கான மற்றொரு மோட் அல்ல. |
| லேத்தல் லேசர்கள் | மோட் ஆக்டிவேஷன் மற்றும் சேதம் மற்றும் பயன்படுத்தக்கூடிய உமிழ்ப்பான்கள், சுற்றுச்சூழல் உமிழ்ப்பான்கள், பிரதிபலிப்பான்கள் மற்றும் ப்ரிஸங்களுக்கான கட்டுப்பாடுகளை இயக்குதல். |
| ANTE மேலே | Respawn-frequency multiplier, Antevariant frequency, and தற்சமயம் development/debug சுவிட்சுகள். RandomDay அனைத்து அங்கீகரிக்கப்பட்ட மேம்பாடு மற்றும் பிழைத்திருத்தம் அணைக்கப்படும். |

சுயவிவர நூலகம் ஒவ்வொரு ஆதரிக்கப்படும் நாளுக்கும் ஒரு தயாரிக்கப்பட்ட மதிப்பை வழங்குகிறது. ஒரு அமைதியான நாள் அழுத்தத்தைக் குறைக்கலாம், ஒரு ஆபத்து நாள் அதை உயர்த்தலாம், மற்றும் ஒரு மீட்பு நாள் அதைக் கடுமையாகக் குறைக்கலாம். RandomDay துவக்கத்தில் தன்னிச்சையான மதிப்புகளைக் கணக்கிடாது; செயலில் உள்ள சுயவிவரத்தால் பெயரிடப்பட்ட மதிப்பாய்வு செய்யப்பட்ட மதிப்பை இது பயன்படுத்துகிறது.

## தற்போதைய பதிப்பு ஆதாரம்

இந்த அட்டவணை 20 ஜூலை 2026 அன்று மதிப்பாய்வு செய்யப்பட்டது. “அங்கீகரிக்கப்பட்டது” என்றால் வெளியிடப்பட்ட அடாப்டரில் பெயரிடப்பட்ட அமைப்புகளுக்கான முழுமையான உள்ளூர் தளவமைப்பு பொருத்தப்பட்டுள்ளது. ஒவ்வொரு எதிர்கால வெளியீட்டிற்கும் ஒரே கோப்பு வடிவம் இருக்கும் என்று அர்த்தம் இல்லை.

<a id="how-recognition-protects-another-mod"></a>
## அங்கீகாரம் மற்றொரு மோடை எவ்வாறு பாதுகாக்கிறது

பழக்கமான கோப்புப் பெயரைக் கண்டறிவது போதாது. எழுதுவதற்கு முன், RandomDay அந்த அடாப்டருக்கு தேவையான ஒவ்வொரு அமைப்பும் இலக்கு கோப்பில் உள்ளதா என சரிபார்க்கிறது. இது ஏற்கனவே உள்ள பணிகளை மட்டுமே இணைக்கிறது; அது ஒருபோதும் விடுபட்ட அமைப்பைக் கண்டுபிடிக்காது.

அங்கீகரிக்கப்பட்ட தளவமைப்புக்கு, RandomDay ஒரு எல்லைக்குட்பட்ட பரிவர்த்தனையைச் செய்கிறது:

1. செயலில் உள்ள சுயவிவரத்திற்கான ஒவ்வொரு உத்தேசிக்கப்பட்ட மதிப்பையும் கணக்கிடுக;
2. ஒவ்வொரு இலக்கு கோப்பின் காப்புப்பிரதியையும் உருவாக்கி, பைட் சரிபார்க்கவும்;
3. உடன்பிறப்பு நிலுவையில் உள்ள கோப்பு மூலம் எழுதவும்;
4. நிலுவையில் உள்ள கோப்பை விளம்பரப்படுத்தி, சேமித்த பைட்டுகளை மீண்டும் படிக்கவும்;
5. உத்தேசிக்கப்பட்ட ஒவ்வொரு மதிப்பையும் உறுதிப்படுத்தவும்;
6. எந்தப் படியும் தோல்வியுற்றால் சரிபார்க்கப்பட்ட காப்புப்பிரதியிலிருந்து தானியங்கு மறுசீரமைப்பைப் பயன்படுத்தவும்.

DynamicSpawns ஒரு பரிவர்த்தனையில் அதன் அமைப்புகளையும் அங்கீகரிக்கப்பட்ட பிளேயர்-மெசேஜ் கோப்புகளையும் சேர்க்கலாம். RandomDay பல கோப்பு புதுப்பிப்பு வெற்றிகரமாக இருப்பதாகப் புகாரளிக்காது.

## அடாப்டர் முடிவைப் படிக்கவும்

| முடிவு | பொருள் |
| --- | --- |
| `applied` | அங்கீகரிக்கப்பட்ட அமைப்புகள் மாற்றப்பட்டு, ரீட்பேக் அனுப்பப்பட்டது. |
| `already_current` | அங்கீகரிக்கப்பட்ட அமைப்புகள் ஏற்கனவே செயலில் உள்ள சுயவிவரத்துடன் பொருந்துகின்றன. |
| `not_installed` | விருப்ப மோட் கிடைக்கவில்லை. RandomDay அது இல்லாமல் தொடர்ந்தது. |
| `skipped_incompatible` | ஒரு கோப்பு கண்டறியப்பட்டது, ஆனால் அதன் முழுமையான அமைப்பு தளவமைப்பு அங்கீகரிக்கப்படவில்லை. எதுவும் மாற்றப்படவில்லை. |
| `partial` | முதன்மை DynamicSpawns அமைப்புகள் பயன்படுத்தப்பட்டன, ஆனால் விருப்பமாக மொழிபெயர்க்கப்பட்ட செய்திக் கோப்பு முழுமையடையவில்லை. பதிவுசெய்யப்பட்ட அடாப்டர் முடிவை மதிப்பாய்வு செய்யவும். |
| `failed_rolled_back` | ஒரு பரிவர்த்தனை தோல்வியடைந்தது மற்றும் முந்தைய பைட்டுகள் அப்படியே இருந்தன அல்லது மீட்டமைக்கப்பட்டு சரிபார்க்கப்பட்டன. |
| `rollback_failed` | RandomDay மாற்றத்தை அல்லது மீட்டமைப்பைச் சரிபார்க்க முடியவில்லை. பாதிக்கப்பட்ட மோடை நிறுத்தி, அதன் பதிவு செய்யப்பட்ட காப்புப்பிரதியை கைமுறையாக மீட்டெடுக்கவும். |

காணாமல் போன மற்றும் பொருந்தாத விருப்ப முறைகள் நிறுத்தப்படாது RandomDay's அனுப்பப்பட்ட உள்ளமைவின் கீழ் சாண்ட்பாக்ஸ் சுழற்சி.

<a id="enable-or-disable-integrations"></a>
## ஒருங்கிணைப்புகளை இயக்கு அல்லது முடக்கு

கட்டுப்பாடுகள் இதில் உள்ளன:

```text
RandomDay/Scripts/ax_config/server.lua
```

பிரத்யேக-சர்வர் தொகுப்பு இதனுடன் அனுப்பப்படுகிறது:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- அமைவு `enabled = false` நிறுத்த RandomDay ஒவ்வொரு விருப்ப மோட்களையும் பரிசோதிப்பது அல்லது மாற்றுவது.
- ஒரு அடாப்டர் ஐடியை அகற்றி, மற்ற ஒருங்கிணைப்புகளை செயலில் வைத்திருக்கும் போது, ​​அந்த மோட்டைத் தனியாக விட்டுவிடவும்.
- வை `patch_only_existing_keys` மற்றும் `backup_before_write` என அமைக்கப்பட்டது `true`. அவை எழுத்து-பாதுகாப்பு எல்லை.
- வை `optional_by_default = true` ஒவ்வொரு பட்டியலிடப்பட்ட விருப்ப மோட் சேவையகத்தின் அவசியமான பகுதியாக இல்லாவிட்டால். `false` ஒரு விடுபட்ட, இணக்கமற்ற அல்லது பாதுகாப்பாக ரோல்-பேக் அடாப்டரை மொத்த முடிவைப் பாதிக்கிறது.

நீங்கள் அதை செயலிழக்கச் செய்யும்போது விருப்பமான மோட் ஒன்றை நிறுவல் நீக்கவோ அல்லது முடக்கவோ தேவையில்லை RandomDay அடாப்டர்.

RandomDay's அடாப்டர்கள் நிறுவப்பட்ட, அங்கீகரிக்கப்பட்ட தளவமைப்பில் உள்ள கட்டமைப்பு புலங்களை மட்டுமே பயன்படுத்துகின்றன; அவர்கள் அந்த மோட்களை மறுபகிர்வு செய்யவோ அல்லது மாற்றவோ இல்லை.

<a id="backups-and-manual-recovery"></a>
## காப்புப்பிரதிகள் மற்றும் கைமுறை மீட்டெடுப்பு

சரிபார்க்கப்பட்ட முன்-எழுத நகல்கள் இதன் கீழ் தக்கவைக்கப்படுகின்றன:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

என்றால் `rollback_failed` தோன்றும்:

1. கேம் அல்லது சர்வரை நிறுத்து;
2. செட் `external_mods.enabled = false`, அல்லது பாதிக்கப்பட்ட அடாப்டர் ஐடியை அகற்றவும்;
3. தற்போதைய இலக்குக் கோப்பையும் அதன் உடன்பிறப்பையும் பாதுகாக்கவும் pending/rollback கோப்புகள்;
4. அடாப்டர் முடிவில் பதிவுசெய்யப்பட்ட இலக்கு பாதைகளுடன் எண்ணிடப்பட்ட காப்பு கோப்புகளை பொருத்தவும்;
5. சேவை நிறுத்தப்படும் போது சரிபார்க்கப்பட்ட பைட்டுகளை மீட்டெடுக்கவும்;
6. அதன் RandomDay அடாப்டர்.

அமைப்புகளை மறுபெயரிடுவதன் மூலமோ அல்லது விடுபட்ட விசைகளைச் சேர்ப்பதன் மூலமோ இணக்கத்தன்மையை கட்டாயப்படுத்த வேண்டாம். அங்கீகரிக்கப்பட்ட தளவமைப்பைப் பயன்படுத்தவும், அடாப்டரை முடக்கி விடவும் அல்லது ஆதரவு உரிமைகோரலை விரிவுபடுத்தும் முன் புதிய பதிப்பு சாதனம் மற்றும் பரிவர்த்தனை சோதனையைச் சேர்க்கவும்.
