# நிலை மற்றும் பிழை குறிப்பு

> **நியாய ஆங்கில மூல:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


சரியானதைப் பயன்படுத்தவும் `status`, `transaction_status`, `rollback_status`, மற்றும் `error` மதிப்புகள். பேனல் அல்லது கன்சோலில் உள்ள ஒரே மாதிரியான வார்த்தைகள் அந்த புலங்களுக்கு மாற்றாக இல்லை.

இந்தப் பகுதி முழுமையான தேடல் குறிப்பு. மேலே உள்ள முடிவு மரம் தொடர்புடைய வகையைத் தேர்ந்தெடுக்கிறது; இந்த அட்டவணைகள் சரியான இயந்திர மதிப்புகள் மற்றும் பாதுகாப்பான ஆபரேட்டர் பதில்களை பாதுகாக்கின்றன.

## சாதாரண அல்லது தகவல் நிலைகள்

| நிலை | பொருள் | ஆபரேட்டர் பதில் |
|---|---|---|
| `prepared_for_next_reboot` | அடுத்த துவக்கத்திற்கு சரிபார்க்கப்பட்ட சுயவிவரம் எழுதப்பட்டது. | செயல் இல்லை; தற்போதைய அமர்வு மாறாமல் உள்ளது. |
| `next_reboot_already_prepared` | உத்தேசித்துள்ள அடுத்த சுயவிவரம் ஏற்கனவே இலக்குடன் பொருந்துகிறது. | செயல் இல்லை; மற்றொரு சுழற்சியை கட்டாயப்படுத்த வேண்டாம். |
| `already_current` / `unchanged` | இலக்கு ஏற்கனவே உத்தேசிக்கப்பட்ட பைட்டுகளைக் கொண்டுள்ளது. | செயல் இல்லை. |
| `applied` | எழுதுதல் மற்றும் உற்பத்தி ரீட்பேக் கடந்துவிட்டன. | சரிபார்க்கவும் active/prepared வேறுபாடு. |
| `bootstrap_prepare_first_family_start_day` | முன் சுழற்சி நிலை எதுவும் இல்லை, எனவே உள்ளமைக்கப்பட்ட முதல் நாள் தயார் செய்யப்பட்டது. | முதல் பயன்பாட்டில் எதிர்பார்க்கப்படுகிறது. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | சேமிக்கப்பட்ட நிலை மீட்டெடுக்கப்பட்டது மற்றும் அதே தயாரிக்கப்பட்ட சுயவிவரம் மீண்டும் எழுதப்பட்டது. | மீட்டெடுக்கப்பட்ட நாளைச் சரிபார்க்கவும்; புதிய சீரற்ற தேர்வு எதுவும் நிகழவில்லை. |
| `supervision_reconfirm_prepared_profile_no_advance` | ஒரு கண்காணிப்பு அனுமதி ஏற்கனவே உள்ள தயாரிப்பை உறுதிப்படுத்தியது. | எதிர்பார்க்கப்பட்டது; வரிசை இரண்டு முறை முன்னேறவில்லை. |
| `external_mods_disabled` | விருப்ப அடாப்டர் செயலாக்கம் முடக்கப்பட்டுள்ளது. | அடாப்டர்களை நோக்கமாக கொண்டால் தவிர எந்த நடவடிக்கையும் இல்லை. |
| `external_mods_processed` | அனைத்து இயக்கப்பட்ட அடாப்டர் திட்டங்களும் ஒரு முனைய முடிவை அடைந்துள்ளன. | ஒவ்வொரு அடாப்டர் வரிசையையும் மதிப்பாய்வு செய்யவும். |

<a id="startup-configuration-errors"></a>
## தொடக்க உள்ளமைவு பிழைகள்

இந்தச் செய்திகள் தொடங்குவதற்கு முன் RandomDay ஒரு சுயவிவரத்தை எழுதுகிறது. பெயரிடப்பட்ட அமைப்பு அல்லது தொகுப்பு மார்க்கரை சரிசெய்யவும்; சரிபார்ப்பு கிளையை கடந்து செல்ல வேண்டாம்.

| பிழை உரை | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` காணவில்லை, தவறாக வடிவமைக்கப்பட்டுள்ளது அல்லது தவறான தொகுப்பில் உள்ளது. | ஒரு முழுமையான தொகுப்பை சுத்தமான ஸ்டேஜிங் கோப்புறையில் மீண்டும் நிறுவி, உத்தேசிக்கப்பட்ட பயன்முறை மார்க்கரைப் பாதுகாக்கவும். |
| `invalid experience.mode` | `experience.mode` ஆவணப்படுத்தப்பட்ட மதிப்புகளில் ஒன்றல்ல. | பயன்படுத்து `auto`, `persistent_dedicated`, `temporary_dedicated`, அல்லது `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | ஒரு கையேடு-நகல் தொகுப்பு ஒரு பிரத்யேக சேவையகமாக உள்ளமைக்கப்பட்டது. | மீட்டமை `auto` அல்லது `singleplayer_lan`; அதை தானாக ஒரு வெளிப்புற உலகில் சுட்டிக்காட்ட வேண்டாம். |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | கையேடு-நகல் பணிப்பாய்வுக்காக ஒரு பிரத்யேக தொகுப்பு உள்ளமைக்கப்பட்டது. | பயன்படுத்து `auto`, `persistent_dedicated`, அல்லது `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | ஆரம்ப நாள் தேர்வி தவறானது. | சரியாகப் பயன்படுத்தவும் `configured` அல்லது `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | நாள்-வரிசை தேர்வி தவறானது. | சரியாகப் பயன்படுத்தவும் `sequential` அல்லது `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | கட்டமைக்கப்பட்ட தொடக்க நாள் பகுதியளவு அல்லது சுழற்சிக்கு வெளியே உள்ளது. | 1 முதல் `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | காப்புப்பிரதி அல்லது கடைசியாக நல்ல மறுசீரமைப்பு முடக்கப்பட்டது. | இரண்டு பாதுகாப்பு பூட்டுகளையும் மீட்டமை; RandomDay பாதுகாப்பற்ற எழுத்துகளை வேண்டுமென்றே மறுக்கிறது. |
| `external adapter transaction safety locks must remain true` | அடாப்டர் ஒட்டுதல் அல்லது காப்புப் பாதுகாப்பு முடக்கப்பட்டது. | அடாப்டர் பாதுகாப்பு பூட்டுகள் இரண்டையும் மீட்டெடுக்கவும் அல்லது ஒரு குழுவாக அடாப்டர்களை முடக்கவும். |
| `paths.world_name must be one folder name` | உள்ளமைக்கப்பட்ட உலகப் பெயரில் பிரிப்பான் அல்லது பாதுகாப்பற்ற எழுத்து உள்ளது. | எழுத்துக்கள், எண்கள், இடைவெளிகள், அடிக்கோடுகள் அல்லது ஹைபன்களைப் பயன்படுத்தி சரியான கோப்புறை பெயரை மட்டும் உள்ளிடவும். |
| `required runtime directory unavailable` | தேவையான மோட்-உள்ளூர் வெளியீட்டு கோப்பகத்தை உருவாக்கவோ அல்லது உறுதிப்படுத்தவோ முடியவில்லை. | பெயரிடப்பட்டதை மட்டும் சரிபார்க்கவும் RandomDay அடைவு மற்றும் அதன் எழுத அனுமதி. |

<a id="profile-wide-configuration-errors"></a>
## சுயவிவரம் முழுவதும் உள்ளமைவு பிழைகள்

இந்தப் பிழைகள் சாண்ட்பாக்ஸ் எழுதுவதற்கு முன் சுயவிவரக் கட்டமைப்பை நிறுத்துகின்றன.

| பிழை உரை | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `sandbox.profile_overrides must be a table` | நான்கு சுயவிவர அளவிலான தேர்வுகள் மற்றொரு Lua வகையுடன் மாற்றப்பட்டன. | ஆவணப்படுத்தப்பட்ட அட்டவணையை `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | அட்டவணையில் ஆதரிக்கப்படும் நான்கு விசைகளில் ஒன்று இல்லாத அமைப்பு உள்ளது. | பெயரிடப்பட்ட விசையை அகற்றி family/profile ஆதாரங்கள். |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` அல்லது `AllowIronMode` என்பது `true` அல்லது `false`. | மேற்கோள் செய்யப்படாத Lua boolean ஐப் பயன்படுத்தவும். |
| `sandbox.profile_overrides.<key> must be integer` | ஆதரவு மதிப்பு முழு எண் அல்ல. | முழு எண்ணைப் பயன்படுத்தவும். |
| `sandbox.profile_overrides.<key> outside supported range` | ஒரு ஆதரவு மதிப்பு வெளியே உள்ளது `0..1000`. | `0` மூலம் `1000`. |

<a id="rollback-and-intermediate-states"></a>
## ரோல்பேக் மற்றும் இடைநிலை நிலைகள்

| மதிப்பு | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `not_started` / `pending` | பரிவர்த்தனை அல்லது அடாப்டர் திட்டம் ஒரு முனைய முடிவை அடையவில்லை. | தற்போதைய வரம்பிற்குட்பட்ட தொடக்க பாஸுக்கு மட்டும் காத்திருங்கள்; நிலையான நிலைக்கு விசாரணை தேவை. |
| `not_needed` | திரும்பத் தேவையில்லை. | செயல் இல்லை. |
| `original_held` | அசல் இலக்கு பதவி உயர்வுக்கு முன் மீட்பு நிலைக்கு நகர்த்தப்பட்டது. | பரிவர்த்தனை முழுமையடையாத நிலையில் மீட்பு கோப்பை நீக்க வேண்டாம். |
| `retained_after_success` | புதிய இலக்கு சரிபார்க்கப்பட்டது, ஆனால் தூய்மைப்படுத்தல் கிடைக்காததால் அல்லது வேண்டுமென்றே தக்கவைக்கப்பட்டதால் மீட்புத் தரவு அப்படியே உள்ளது. | பெயரிடப்பட்ட மீட்டெடுப்பு கோப்பை அகற்றும் முன் தயாரிப்பு பைட்களை சரிபார்க்கவும். |
| `discarded_after_success` | மாற்று சரிபார்க்கப்பட்டது மற்றும் தற்காலிக திரும்பப்பெறுதல் தரவு அழிக்கப்பட்டது. | செயல் இல்லை. |
| `rollback_failed` | மீட்டெடுக்க முயற்சித்ததைச் சரிபார்க்க முடியவில்லை. | சேவையகத்தை நிறுத்தி வைத்து கடைசியாக சரிபார்க்கப்பட்ட செயல்பாட்டு காப்புப்பிரதியைப் பயன்படுத்தவும். |
| `skipped_state_persistence_failed` | சாண்ட்பாக்ஸ் பைட்டுகள் தயாரிக்கப்பட்டன, ஆனால் சுழற்சி நிலை நீடிக்கவில்லை, எனவே அடாப்டர்கள் மற்றும் தயாரிக்கப்பட்ட பிளேயர் செய்திகள் தவிர்க்கப்பட்டன. | இயக்க நேர நிலை சேமிப்பகத்தை சரிசெய்தல்; வரிசையை கைமுறையாக மாற்றவோ அல்லது முன்னேறவோ வேண்டாம். |
| `failed` | ஒரு சுருக்க வரிசையானது டெர்மினல் தோல்வியைக் குறிக்கிறது, அதன் குறிப்பிட்ட காரணம் அதன் `error` அல்லது பரிவர்த்தனை புலங்கள். | முதல் குறிப்பிட்ட குறியீட்டைப் பின்பற்றவும்; `failed` தனியாக. |

## பரிவர்த்தனை தோல்விகள்

## மொழிபெயர்ப்பு மற்றும் செய்தி சரிபார்ப்பு பிழைகள்

இவை அகராதி அல்லது விளக்கக்காட்சி ஒப்பந்த தோல்விகள். அவை வெளியீட்டிற்கு முன் சரிபார்க்கப்பட்டு வரம்பிற்குட்பட்ட இயக்க நேர-நிலை எச்சரிக்கையாகவும் தோன்றலாம்.

| பிழை உரை | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `dictionary coverage mismatch` | சுயவிவர அகராதி ஒவ்வொரு ஆவணப்படுத்தப்பட்ட அமைப்பையும் விளக்கவில்லை. | விடுபட்ட அகராதி உள்ளீட்டைச் சேர்த்து சுயவிவரத்தை மீண்டும் இயக்கவும் generation/validation. |
