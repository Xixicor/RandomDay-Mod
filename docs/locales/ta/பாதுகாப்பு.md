# பாதுகாப்புக் கொள்கை

> **நியாய ஆங்கில மூல:** [SECURITY.md](../../../SECURITY.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


RandomDay சேவையக உள்ளமைவு கோப்புகளை எழுதுகிறது மற்றும் விருப்ப மோட் உள்ளமைவு கோப்புகளை இணைக்க முடியும். மாற்றங்களை செயல்பாட்டு உணர்திறன் கொண்டதாகக் கருதுங்கள்.

<a id="do-not-report-as-security-issues"></a>
## பாதுகாப்புச் சிக்கல்கள் எனப் புகாரளிக்க வேண்டாம்

- இயல்பான விளையாட்டு சமநிலை மாற்றங்கள்.
- எதிர்பார்க்கப்படும் அடுத்த மறுதொடக்கம் சுயவிவர சுழற்சி.

<a id="report-privately"></a>
## தனிப்பட்ட முறையில் புகாரளிக்கவும்

- பாதையில் பயணிக்கும் அபாயங்கள்.
- பாதுகாப்பற்ற கோப்பு எழுதும் நடத்தை.
- நோக்கத்திற்கு வெளியே கோப்புகளை மேலெழுதும் திறன் server/mod பாதைகள்.
- தீங்கிழைக்கும் கட்டளை செயல்படுத்தல்.

பொது பாதுகாப்பு சேனல் இருக்கும் வரை, களஞ்சிய உரிமையாளரிடம் தனிப்பட்ட முறையில் புகாரளிக்கவும்.
