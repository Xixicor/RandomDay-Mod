# வெளியீடு சரிபார்ப்பு

> **நியாய ஆங்கில மூல:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்தப் பக்கம் பங்களிப்பாளர்கள் மற்றும் வெளியீடு பராமரிப்பாளர்களுக்கானது. மோடை நிறுவும் பிளேயர்கள் இந்தக் கட்டளைகளை இயக்கத் தேவையில்லை.

<a id="ordinary-user-proof"></a>
## சாதாரண பயனர் ஆதாரம்

புதிய ரீடர் இரண்டு தொகுப்புகளில் ஒன்றைத் தேர்வுசெய்து, அதை நிறுவி, பின்தொடரும் சுயவிவரத்திலிருந்து செயலில் உள்ள இணைப்பைத் தவறவிட்ட வழிகாட்டியின் மூலம், ஒரு புதிய வாசகரை மீட்டெடுக்கும்போது, ​​ஒரு வெளியீட்டைப் புரிந்துகொள்ள முடியும். அந்த வாசகர் பணிகளுக்கு Git, PowerShell, பைதான் அல்லது செக்சம் அறிவு.

<a id="contributor-checks"></a>
## பங்களிப்பாளர் சோதனைகள்

ரெபோசிட்டரி ரூட்டிலிருந்து இயக்கவும்:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

எப்போது `luac` உள்ளது, அனுப்பப்பட்ட ஒவ்வொரு Lua கோப்பையும் தொடரியல்-சரிபார்க்கவும்:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

Lua இயக்க நேர சோதனைகள் தேவை `lupa`. விடுபட்ட Lua மொழிபெயர்ப்பாளர் அல்லது `lupa` நிறுவல் என்பது கிடைக்காத சோதனைத் திறனாகும், தேர்ச்சி முடிவு அல்ல.

<a id="release-checks"></a>
## சரிபார்ப்புகளை வெளியிடு

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

வெளியீட்டு சரிபார்ப்பு இந்த நிபந்தனைகளை சரிபார்க்கிறது:

- `VERSION` மற்றும் `RandomDay/.randomday_version` பொருத்தம்.
- தற்போதைய பதிப்பு மட்டுமே `releases/`.
- அர்ப்பணிக்கப்பட்ட மற்றும் singleplayer/LAN ZIPகள் முழுமையான மாற்றுகள்.
- இரண்டு காப்பகங்களிலும் நியமனம் உள்ளது `RandomDay/Scripts/main.lua` பாதை மற்றும் கேஸ்-மோதுதல் ஏற்றி இல்லை.
- பேக்கேஜ் பயன்முறை குறிப்பான்கள் `dedicated_server` மற்றும் `singleplayer_manual`.
- ZIP பைட்டுகள் உறுதியானவை மற்றும் பொருந்துகின்றன `CHECKSUMS.sha256`.
- இயக்க நேர தரவு, தனிப்பட்ட உள்ளமைவு, சான்றுகள், தற்காலிக சேமிப்புகள் அல்லது சோதனை வெளியீடு தொகுக்கப்படவில்லை.
- அனைத்து உள்ளூர் ஆவண இணைப்புகளும் 27 மொழி நுழைவு பக்கங்களும் சரிபார்க்கப்படுகின்றன.

<a id="avoid-validation-environment-pitfalls"></a>
## சரிபார்ப்பு சூழல் ஆபத்துகளைத் தவிர்க்கவும்

- ரெபோசிட்டரி-ரைட்டிங் காசோலைகளை தொடர்ச்சியாக இயக்கவும், இதனால் இரண்டு செயல்முறைகள் ஒரே தற்காலிக கோப்பை ஒரே நேரத்தில் மாற்றாது.
- விண்டோஸில், சரிபார்க்கவும் ZIP சிற்றெழுத்து ஏற்றி உள்ளதா என்பதைத் தீர்மானிக்க, கேஸ்-சென்சிட்டிவ் கோப்புத் தேடலைப் பயன்படுத்துவதற்குப் பதிலாக உறுப்பினர் பெயர்கள்.
- உறுதிப்படுத்து `mods.txt` மற்றும் `enabled.txt` நிறுவப்பட்ட-சேவையக சோதனையில் மட்டுமே; ஆதார சோதனைகள் இயங்கின என்பதற்கு அவை ஆதாரம் அல்ல.
- கமாண்ட் காலாவதியை முழுமையடையாததாக பதிவு செய்யவும். கட்டளையின் வரம்பிற்குட்பட்ட வெளியீடு இல்லாமல் அதை பாஸ் அல்லது தோல்விக்கு மாற்ற வேண்டாம்.
- தற்காலிகக் கோப்புகளை களஞ்சியத்தில் உள்ள புறக்கணிக்கப்பட்டது `.tmp/` அடைவு.

<a id="known-limits"></a>
## தெரிந்த வரம்புகள்

உள்ளூர் சரிபார்ப்பு ஆதாரம், தொகுப்பு, ஆவணங்கள் மற்றும் ஃபிக்சர் ஒப்பந்தங்களை நிரூபிக்கிறது. இது ஒரு குறிப்பிட்ட சர்வர் பேனலின் தொடக்க வரிசை, நேரடி கிளையண்ட் செய்தி தளவமைப்பு அல்லது ஹோஸ்ட்-குறிப்பிட்ட கோப்பு முறைமை பாதையை நிரூபிக்கவில்லை. சோதனையின் போது அவற்றை தனி ஒருங்கிணைப்பு முடிவுகளாகப் பதிவுசெய்க.
