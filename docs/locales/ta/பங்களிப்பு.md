# பங்களிப்பு

> **நியாய ஆங்கில மூல:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


RandomDay ஒரு கட்டுப்படுத்தப்பட்ட திட்டமாக பராமரிக்கப்படுகிறது.

பொது இழுப்புக் கோரிக்கைகள், கோரப்படாத குறியீடு சமர்ப்பிப்புகள், தானியங்கு மீண்டும் எழுதுதல், உருவாக்கப்பட்ட-குறியீடு சுத்தப்படுத்துதல் சமர்ப்பிப்புகள் மற்றும் ஊக அம்ச இணைப்புகள் ஆகியவை களஞ்சிய உரிமையாளரால் வெளிப்படையாகக் கோரப்படும் வரை ஏற்றுக்கொள்ளப்படாது.

<a id="accepted-contact"></a>
## ஏற்றுக்கொள்ளப்பட்ட தொடர்பு

பிழை அறிக்கைகள், பொருந்தக்கூடிய குறிப்புகள் அல்லது சர்வர்-நிர்வாக அவதானிப்புகளுக்கு, திட்ட ஆவணத்தில் பட்டியலிடப்பட்டுள்ள தொடர்பு சேனல்களைப் பயன்படுத்தவும்.

<a id="not-accepted"></a>
## ஏற்கப்படவில்லை

இயல்புநிலையாக பின்வருபவை ஏற்கப்படாது:

- கோரிக்கப்படாத இழுத்தல் கோரிக்கைகள்;
- generated-code rewrites;
- பரந்த ரீஃபாக்டர்கள்;
- பாணியில் மட்டும் வடிவமைப்பு மாற்றங்கள்;
- சோதனை செய்யப்படாத விளையாட்டு தர்க்க மாற்றங்கள்;
- தொகுக்கப்பட்ட மூன்றாம் தரப்பு மோட் கோப்புகள்;
- மூன்றாம் தரப்பு மூலக் குறியீடு மறுபகிர்வு செய்யப்பட்டது;
- மாற்றங்கள் அபியோடிக் காரணியுடன் உத்தியோகபூர்வ தொடர்பைக் குறிக்கின்றன, UE4SS, Nexus Mods அல்லது மூன்றாம் தரப்பு மோட் ஆசிரியர்கள்.

<a id="controlled-development"></a>
## கட்டுப்படுத்தப்பட்ட வளர்ச்சி

ரெபோசிட்டரி உரிமையாளர் தேவைப்படும் போது குறிப்பிட்ட மதிப்பாய்வு, சோதனை அல்லது ஆவண உதவியைக் கோரலாம். கோரப்படாத சமர்ப்பிப்புகள் மதிப்பாய்வு இல்லாமல் மூடப்படலாம்.
