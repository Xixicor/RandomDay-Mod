# இயக்க நேர நிலை மற்றும் வெளியீட்டு திட்டங்களை விளக்கவும்

> **நியாய ஆங்கில மூல:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இது நியமன புலம்-முழுமையான திட்ட வழிகாட்டி. ஒவ்வொரு புலம், நிலை, வெற்று மதிப்பு மற்றும் இயந்திர முடிவு என்ன என்பதை இது பதிலளிக்கிறது. [இயக்க நேர கோப்பு வரைபடம்](%E0%AE%87%E0%AE%AF%E0%AE%95%E0%AF%8D%E0%AE%95_%E0%AE%A8%E0%AF%87%E0%AE%B0_%E0%AE%95%E0%AF%8B%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81%E0%AE%95%E0%AE%B3%E0%AF%8D.md) தயாரிப்பாளர்கள், பாதைகள், எழுதும் நேரம், தக்கவைப்பு, பரிவர்த்தனை பக்க கார்கள் மற்றும் மீட்பு இடங்கள்.

இந்த வழிகாட்டியில் உள்ள அனைத்து பாதைகளும் நிறுவப்பட்டவற்றுடன் தொடர்புடையவை `RandomDay/` கோப்புறையில் உள்ளமைக்கப்பட்ட சாண்ட்பாக்ஸ் அல்லது விருப்பமான அடாப்டர் இலக்கை ஒரு வரிசை வெளிப்படையாக குறிப்பிடவில்லை. இயக்க நேர வெளியீடுகள் நிறுவலுக்குப் பிறகு உருவாக்கப்படும் மற்றும் அவை வெளியீட்டின் உறுப்பினர்கள் அல்ல ZIP.

## அதிகாரப்பூர்வ காட்சியைத் தேர்ந்தெடுக்கவும்

| தேவை | அதிகாரப்பூர்வ ஆதாரம் |
|---|---|
| தற்போதைய செயல்முறையால் ஏற்றப்பட்ட விதிகள் | RandomDay குறிப்பான் `SandboxSettings.ini` தொடக்கத்தில் படிக்கவும் |
| தயாரிக்கப்பட்ட வரிசை புத்தக பராமரிப்பு | `runtime/rotation_state.txt`, ஸ்கீமா `1` |
| விரிவான உள்ளூர் நிலை | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| பொது இயந்திரம் படிக்கக்கூடிய நிலை | `web_export/today.json`, ஸ்கீமா `2` மற்றும் `randomday_public_status_v2` |
| மனிதர்கள் படிக்கக்கூடிய நிலை | `web_export/today.html`, அதே பொது நிலை மாற்றத்திலிருந்து பெறப்பட்டது |
| மொழிபெயர்ப்பு சொல்லகராதி | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| சரியான கட்டுப்பட்ட பிளேயர் அறிவிப்பு | `runtime/current/player_message_preview.txt` |

தி HTML பார்வை, முன்னோட்டம் மற்றும் மொழிபெயர்க்கப்பட்ட சுருக்கங்கள் பெறப்பட்ட பார்வைகள். அவை சாண்ட்பாக்ஸ் மார்க்கர், பரிவர்த்தனை முடிவு அல்லது அசல் சுயவிவர மதிப்புகளை மீறுவதில்லை. கடைசியாக அறியப்பட்ட நல்ல கோப்புகள், செயல்பாட்டு காப்புப்பிரதிகள், சைட்கார்கள், கண்ணாடிகள், அடாப்டர் இலக்குகள் மற்றும் `UE4SS.log` in [இயக்க நேர கோப்புகள்](%E0%AE%87%E0%AE%AF%E0%AE%95%E0%AF%8D%E0%AE%95_%E0%AE%A8%E0%AF%87%E0%AE%B0_%E0%AE%95%E0%AF%8B%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81%E0%AE%95%E0%AE%B3%E0%AF%8D.md).

<a id="rotation-state-schema"></a>
## சுழற்சி நிலை திட்டம்

`runtime/rotation_state.txt` ஸ்கீமாவைப் பயன்படுத்துகிறது `1` மற்றும் ஒன்று உள்ளது `key=value` ஒரு வரிக்கு ஜோடி:

| புலம் | பொருள் |
|---|---|
| `schema_version` | இருக்க வேண்டும் `1`. |
| `mod_version` | பேக்கேஜ் அடையாளம் `.randomday_version`. |
| `rotation_id` | தகுதியான குடும்பத் தொகுப்பின் மூலம் தற்போதைய பாஸிற்கான அடையாளங்காட்டி. |
| `mode` | `selected_run`, `non_repeating_random_run`, அல்லது `rotation_run`. |
| `available_families` | உள்ளமைவு வடிகட்டலுக்குப் பிறகு காற்புள்ளியால் பிரிக்கப்பட்ட தகுதியான குடும்ப ஐடிகள். |
| `remaining_families` | தற்போதைய ரிப்பீட் அல்லாத பாஸில் தகுதியான குடும்பங்கள் இன்னும் தேர்ந்தெடுக்கப்படவில்லை. |
| `completed_families` | தற்போதைய பாஸில் 17-நிலை வரிசையை நிறைவு செய்த குடும்பங்கள். |
| `active_family`, `active_day` | தேர்வு செய்யப்பட்டபோது பதிவுசெய்யப்பட்ட செயலில் உள்ள குறிப்பான் தகவல். சாண்ட்பாக்ஸ் மார்க்கர் அடுத்த துவக்கத்தில் அதிகாரப்பூர்வமானது. |
| `prepared_family`, `prepared_day` | சுயவிவரம் அடுத்த மறுதொடக்கத்திற்கு வைக்கப்பட்டுள்ளது. |
| `active_run_id` | தயாரிக்கப்பட்ட தேர்வோடு தொடர்புடைய குடும்பம் நடத்தும் அடையாளங்காட்டி. |
| `last_status` | இந்த கோப்பை உருவாக்கிய காலெண்டர் தேர்வு நிலை. |
| `session_mode` | தீர்க்கப்பட்ட நிலையான அர்ப்பணிப்பு, தற்காலிக அர்ப்பணிப்பு அல்லது singleplayer/LAN வாழ்க்கைச் சுழற்சி. |
| `start_day_mode` | புதிய இயக்கத்திற்கான உள்ளமைக்கப்பட்ட அல்லது ஒரு முறை சீரற்ற தொடக்கத் தேர்வு. |
| `day_progression_mode` | வரிசைப்படுத்தப்பட்ட அல்லது திரும்பத் திரும்ப வராத சீரற்ற முன்னேற்றம். |
| `day_order` | காற்புள்ளியால் பிரிக்கப்பட்ட தொடர் நாள் ஐடிகள் சரியான வரிசையில் தயார் செய்யப்படும். |
| `day_position` | தயாரிக்கப்பட்ட நாளின் நிலை `day_order`. |
| `updated_at` | ஆபரேட்டர் ஒப்பீடுக்கான உள்ளூர் எழுதும் நேரம். |

ஸ்கீமா மார்க்கர், தயாரிக்கப்பட்ட குடும்பம் மற்றும் தயாரிக்கப்பட்ட நாள் ஆகியவற்றைச் சரியாகப் படிக்கும்போது மட்டுமே மாநில எழுத்து ஏற்றுக்கொள்ளப்படும். படிக்க முடியாத தற்போதைய கோப்பு `rotation_state.last_good.txt`; தேர்ந்தெடுக்கப்பட்ட சாண்ட்பாக்ஸ் மார்க்கர் தற்போதைய செயல்முறைக்கு கேம் என்ன ஏற்றப்பட்டது என்பதை இன்னும் தீர்மானிக்கிறது.

<a id="runtime-status-json"></a>
## இயக்க நேர நிலை JSON

`runtime/current/randomday_status.json` பயன்படுத்துகிறது `status_schema=randomday_runtime_status_v2`. அதன் முக்கிய களக் குழுக்கள்:

| குழு | புலங்கள் மற்றும் விளக்கம் |
|---|---|
| அடையாளம் | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| தேர்வு | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| செயலில் | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| தயாரித்தது | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| மனித சுருக்கங்கள் | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| ஆதாரத்தை எழுது | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| அடாப்டர் ஆதாரம் | `adapter_status`, `adapter_results`; ஒவ்வொரு அடாப்டர் பதிவிலும் பொருந்தக்கூடிய சான்றுகள் உள்ளன, transaction/rollback நிலை, மாற்றப்பட்ட கோப்பு எண்ணிக்கை மற்றும் திருத்தப்பட்ட இலக்கு குறிப்புகள் |
| எல்லைகள் | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| கண்டறிதல் | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

தெரியாத செயலில் உள்ள மதிப்புகள் தற்போதைய சாண்ட்பாக்ஸில் படிக்கக்கூடியவை இல்லை என்று அர்த்தம் RandomDay மார்க்கர். அவை தயாரிக்கப்பட்ட மதிப்புகளுடன் மாற்றப்படக்கூடாது. அடாப்டர் பாதைகள் வெளியே `runtime/` அடிப்படைப்பெயர் குறிப்பிற்கு குறைக்கப்பட்டது, மேலும் கண்டறியும் சரங்கள் கண்டறியப்பட்ட முழுமையான பாதைகளை மாற்றியமைக்கின்றன.

<a id="public-status-json"></a>
## பொது நிலை JSON

`web_export/today.json` பயன்படுத்துகிறது `schema_version=2` மற்றும் `status_schema=randomday_public_status_v2`. இது active/prepared, தேர்வு, பரிவர்த்தனை, அடாப்டர் மற்றும் மறுதொடக்கம்-எல்லை உண்மைகள் ஆபரேட்டருக்குத் தேவை. இதில் பின்வருவனவும் அடங்கும்:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order`, மற்றும் `prepared_day_position`;
- `family_selection_mode`, மரபு `family_locked_until_day_17`, மற்றும் `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`, மற்றும் அவற்றின் எண்ணிக்கை;
- தயாரிக்கப்பட்ட சந்திப்பு சுயவிவரம், அடுக்கு, தீம் மற்றும் கலவையான சந்திப்பு வாய்ப்பு;
- உலக-நோக்கம் செயலாக்கம், திறந்த-உலக அமைப்பு, அறியப்படாத-உலகக் கொள்கை மற்றும் உள்ளமைக்கப்பட்ட விலக்கப்பட்ட-உலக வடிவங்களின் எண்ணிக்கை மட்டுமே;
- தயாரிக்கப்பட்ட செய்தி மற்றும் ஒருங்கிணைந்த செய்தி மாதிரிக்காட்சிகள்;
- `selected_at`, `sandbox_target`, `manual_copy_required`, மற்றும் தயாரிக்கப்பட்ட ஹாஷ்.

`profile_status` என்பது `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence`, அல்லது `write_failed_or_rollback`. `prepared_ready=true` என்பது இன்னும் செயலில் உள்ளதைக் குறிக்கவில்லை; பிந்தைய தொடக்க மார்க்கர் தேவை.

<a id="dictionary-and-translation-output"></a>
## அகராதி மற்றும் மொழிபெயர்ப்பு வெளியீடு

`runtime/current/randomday_dictionary.json` பயன்படுத்துகிறது `schema=randomday_runtime_dictionary_v2` மற்றும் அகராதி பதிப்பை அடையாளம் காணும் `randomday_dictionary_v2`. இது தொகுப்பு முறைகள், தேர்வு நிலைகள், அழுத்த களங்கள், லேபிள்கள் அமைத்தல், மூல மதிப்புகள் மற்றும் எளிய மொழி அர்த்தங்களை விவரிக்கிறது. அறியப்படாத மதிப்புகள் நம்பிக்கையான விளக்கமாக மாற்றப்படுவதற்குப் பதிலாக வெளிப்படையாகவே இருக்கும்.

`player_message_preview.txt`, `today.json`, `today.html`, மற்றும் இன்-கேம் அறிவிப்புகள் ஒரே மொழிபெயர்ப்பு தொகுதியிலிருந்து பெறப்பட்ட பார்வைகள். அடிப்படை சுயவிவரம் மற்றும் ரா `SandboxSettings.ini` மதிப்புகள் உண்மையின் ஆதாரமாக இருக்கும்.

## தோல்வி மற்றும் மீட்பு விதிகள்

1. தோல்வியுற்ற நிலுவையிலுள்ள எழுதுதல் அல்லது சரிபார்ப்பு ஒருபோதும் உற்பத்தி இலக்காகாது.
2. தோல்வியுற்ற விளம்பரம் அல்லது தயாரிப்பு ரீட்பேக் வைத்திருக்கும் அசலை மீட்டெடுக்க தூண்டுகிறது; செயல்பாட்டு காப்புப்பிரதி என்பது மீட்டெடுப்பு தோல்வியடையும் போது ஏற்படும் பின்னடைவாகும்.
3. ஒரு தக்கவைக்கப்பட்ட ரோல்பேக் கோப்பு அல்லது `rollback_failed` கேம் அல்லது சர்வர் நிறுத்தப்பட்டிருக்கும் போது, ​​நிலைக்கு கைமுறையாக மதிப்பாய்வு தேவை.
4. ஒரு வெற்றிகரமான சாண்ட்பாக்ஸ் ரைட் மற்றும் தோல்வியுற்ற சுழற்சி நிலை கமிட் சிதைக்கப்பட்டது, தயாராக இல்லை; அடாப்டர்கள் மற்றும் தயாரிக்கப்பட்ட சுயவிவர செய்திகள் தவிர்க்கப்பட்டன.
5. ஏற்றுமதி தோல்வியானது சாண்ட்பாக்ஸ் முடிவை மாற்றாது, ஆனால் இது ஒரு வசதியான ஆதாரத்தை நீக்குகிறது. பரிவர்த்தனை பதிவுகள், நிலை மற்றும் கோப்பு ரீட்பேக் ஆகியவற்றைப் பயன்படுத்தவும்.
6. இயக்க நேர வெளியீடுகள் உள்ளூர் செயல்பாட்டுத் தரவு. அவற்றை வெளியீட்டில் சேர்க்க வேண்டாம் ZIP அல்லது தனி தனியுரிமை மதிப்பாய்வு இல்லாமல் அவற்றை எடுத்துக்காட்டுகளாக வெளியிடவும்.
