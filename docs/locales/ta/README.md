# தமிழில் RandomDay வழிகாட்டி

**v0.3.16-alpha**

RandomDay அடுத்த Abiotic Factor தொடக்கத்திற்கான முழுமையான
`SandboxSettings.ini` கோப்பைத் தயாரிக்கிறது. இயங்கும் அமர்வின் விதிகளை இது
மாற்றாது; செயலில் உள்ள சுயவிவரமும் அடுத்து தயாரிக்கப்பட்ட சுயவிவரமும் தனியாக
அறிவிக்கப்படுகின்றன.

## நிறுவலும் சரிபார்ப்பும்

[நிறுவல் வழிகாட்டியை](../../../INSTALL.md) பின்பற்றவும். சரியான கோப்புறை
`ue4ss/Mods/RandomDay`; `mods.txt` கோப்பில் `RandomDay : 1` இருக்க வேண்டும்.
பொதுவாக முதல் தொடக்கம் சுயவிவரத்தைத் தயாரித்து, அடுத்தது அதைச் செயல்படுத்தும்.

`runtime/current/randomday_status.json`, `runtime/rotation_state.txt` மற்றும்
`web_export/today.json` ஆகியவற்றைப் பார்க்கவும். செயலில் உள்ள மற்றும்
தயாரிக்கப்பட்ட சுயவிவர அடையாளங்கள் மூன்றிலும் ஒரே மாதிரியாக இருக்க வேண்டும்.

## அனுபவத்தைத் தேர்வு செய்தல்

`RandomDay/Scripts/ax_config/server.lua` கோப்பில் முறை, குடும்பம், முதல் நாள்
மற்றும் முன்னேற்றத்தை அமைக்கவும். [தொடக்கம்](../../START_HERE.md),
[சுயவிவரத் தேர்வு](../../CHOOSE_A_PROFILE.md), [அமைப்பு](../../CONFIGURATION.md),
மற்றும் [சிக்கல் தீர்வு](../../TROUBLESHOOTING.md) ஆகியவற்றைப் படிக்கவும்.

`HardcoreMode=False`, `AllowIronMode=False`, `StructuralSupportLimit=0` மற்றும்
`BridgeSupports=0` ஆகியவை வழங்கப்படும் சுயவிவர உருவாக்கியின் தொடக்க மதிப்புகள்;
Abiotic Factor கட்டாய விதிகள் அல்ல. மாற்றி மீண்டும் உருவாக்கும் முறை அமைப்பு
ஆவணத்தில் உள்ளது.

உண்மையான கோப்புகளுடன் துல்லியமாகப் பொருந்த கட்டளைகள், பாதைகள், INI விசைகள் மற்றும்
நிலைகள் ஆங்கிலத்திலேயே இருக்கும்.

## ஆல்பா வெளியீடும் நிலைத்த தேர்வுகளும்

இது ஓர் ஆல்பா வெளியீடு. ஆவணப்படுத்தப்பட்ட நிறுவல், சுழற்சி மற்றும் மீட்பு வழிகள் சோதிக்கப்பட்டுள்ளன; இணக்கத்தன்மையும் பயன்பாட்டு எளிமையும் தொடர்ந்து மேம்படுத்தப்படுகின்றன.

`RandomDay/Scripts/ax_config/server.lua` இல் உள்ள `sandbox.profile_overrides` நான்கு மதிப்புகளையும் எல்லா குடும்பங்களுக்கும் நாட்களுக்கும் வைத்திருக்கும். சேவையகத்தை நிறுத்தி, ஒருமுறை மாற்றி, மீண்டும் தொடங்குங்கள். பின்னர் வரும் சுழற்சிகளும் தொடக்கங்களும் அதே மதிப்புகளைப் பயன்படுத்தும்; `SandboxSettings.ini` மட்டும் மாற்றுவது தற்காலிகம்.

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

கீழே உள்ள விருப்ப மாட்கள் அவற்றின் ஆசிரியர்களின் தனி பதிவிறக்கங்கள். RandomDay அவற்றை மறுவிநியோகம் செய்யாது அல்லது அம்சங்களை மாற்றாது; இயக்கப்பட்ட அடாப்டர் ஏற்கனவே உள்ள ஆதரிக்கப்படும் அமைப்புகளை மட்டும் மாற்றும். ஆசிரியர்களுக்கும் பராமரிப்பாளர்களுக்கும் நன்றி.
