# RandomDay சுயவிவர ஆவணம்

> **நியாய ஆங்கில மூல:** [README.md](../../../profiles/README.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


பதிப்பு: `v0.3.16-alpha`

- குடும்பங்கள்: **17**
- சுயவிவரங்கள்: **289**
- SandboxSettings அகராதி உள்ளீடுகள்: **46**

[சுயவிவர தேர்வு வழிகாட்டி](../%E0%AE%92%E0%AE%B0%E0%AF%81_%E0%AE%9A%E0%AF%81%E0%AE%AF%E0%AE%B5%E0%AE%BF%E0%AE%B5%E0%AE%B0%E0%AE%A4%E0%AF%8D%E0%AE%A4%E0%AF%88%E0%AE%A4%E0%AF%8D_%E0%AE%A4%E0%AF%87%E0%AE%B0%E0%AF%8D%E0%AE%B5%E0%AF%81%E0%AE%9A%E0%AF%86%E0%AE%AF%E0%AF%8D%E0%AE%95.md), பின்னர் துல்லியமான மதிப்புகளுக்கு இந்த உருவாக்கப்பட்ட குறியீட்டைப் பயன்படுத்தவும்.

இந்தக் கோப்புகள் இயக்க நேர லுவா மூலத்திலிருந்து உருவாக்கப்பட்டவை மற்றும் அதன் dictionary/translation ஒப்பந்தம். அவர்கள் அனுப்பியதைக் காட்டுகிறார்கள் `sandbox.profile_overrides` இயல்புநிலைகள்; ஒரு சேவையகத்தின் உள்ளமைக்கப்பட்ட மதிப்புகள் வேறுபடலாம்:

- `profiles.generated.json`: இயந்திரம் படிக்கக்கூடிய சுயவிவரங்கள், மூல மதிப்புகள், அகராதி மற்றும் மொழிபெயர்ப்பு.
- `FULL_PROFILE_REFERENCE.md`: முழுமையான அட்டவணை மற்றும் விளக்க விதிகள்.
- `SANDBOX_SETTINGS_KEYS.md`: 46-விசை அகராதியை முடிக்கவும்.
- `families/*.md`: விரிவான 17-நாள் குடும்பக் குறிப்புகள்.

இதன் மூலம் மீண்டும் உருவாக்கவும்: `python -B tools/generate_profile_docs.py` இதனுடன் சறுக்கல் உள்ளதா எனச் சரிபார்க்கவும்: `python -B tools/generate_profile_docs.py --check`
