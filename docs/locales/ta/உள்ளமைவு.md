# உள்ளமைவு

> **நியாய ஆங்கில மூல:** [CONFIGURATION.md](../../CONFIGURATION.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


முக்கிய ஆபரேட்டர் உள்ளமைவு:

```text
RandomDay/Scripts/ax_config/server.lua
```

கோப்பை காப்புப்பிரதி எடுத்து, ஒரு நேரத்தில் ஒரு பகுதியை மாற்றவும். லுவா பூலியன்கள் சிற்றெழுத்து `true` மற்றும் `false`; சரங்களுக்கு மேற்கோள்கள் தேவை; பட்டியல் உள்ளீடுகளுக்கு காற்புள்ளிகள் தேவை. அடுத்த தொடக்கத்திற்குப் பிறகு, மற்றொரு மாற்றத்தை செய்வதற்கு முன் நிலைப் பக்கத்தைப் படிக்கவும். மூலத்திலிருந்து பணிபுரியும் பங்களிப்பாளர்கள் தனி [வெளியீடு சரிபார்ப்பு](%E0%AE%B5%E0%AF%86%E0%AE%B3%E0%AE%BF%E0%AE%AF%E0%AF%80%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AF%81_%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%AA%E0%AE%BE%E0%AE%B0%E0%AF%8D%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81.md) மாற்றியமைக்கப்பட்ட கட்டமைப்பை பேக்கேஜிங் செய்வதற்கு முன் சரிபார்க்கிறது.

கையால் திருத்த வேண்டாம் `.randomday_mode`, `.randomday_version`, உருவாக்கப்பட்ட சுயவிவரக் குறிப்புகள், `runtime/`, அல்லது `web_export/`. தொகுப்புப் பயன்முறை மற்றும் பதிப்புக் குறிப்பான்களை பேக்கேஜ் பில்டருக்குச் சொந்தமானது மற்றும் அவர்கள் வெளியீட்டு மெட்டாடேட்டாவுடன் உடன்படுகிறார்களா என்பதைச் சரிபார்க்கிறார்.

கீழே உள்ள ஒவ்வொரு அமைப்பும் `RandomDay/Scripts/ax_config/server.lua`. அட்டவணைகள் திருத்தக்கூடிய அமைப்புகளை வெளியீட்டிற்கு சொந்தமான அடையாளம் மற்றும் ஒதுக்கப்பட்ட பொருந்தக்கூடிய புலங்களிலிருந்து வேறுபடுத்துகின்றன. லுவாவில் ஒரு புலம் இருப்பதால் அதை மாற்றுவது என்பது ஆதரிக்கப்படும் நடத்தை என்று அர்த்தமல்ல.

<a id="choose-an-experience"></a>
## அனுபவத்தைத் தேர்ந்தெடுக்கவும்

RandomDay இரண்டு தொகுப்புகளைக் கொண்டுள்ளது: ஒவ்வொரு பிரத்யேக சேவையகத்திற்கும் ஒன்று மற்றும் singleplayer/LAN கையேடு நகல். பிரத்யேக தொகுப்பு இரண்டு இயக்க முறைகளைக் கொண்டுள்ளது; அந்த முறைகள் அமைப்புகள், தனி பதிவிறக்கங்கள் அல்ல.

| உங்கள் உலகம் | நிறுவு | இந்த நடத்தையைத் தேர்ந்தெடுக்கவும் |
| --- | --- | --- |
| வழக்கமான மறுதொடக்கம் முழுவதும் ஒரு பிரச்சாரத்தை நகர்த்தி வைக்கும் ஒரு பிரத்யேக சர்வர் | Dedicated-server தொகுப்பு | `persistent_dedicated` சேமித்த குடும்பம் மற்றும் சுயவிவர வரிசையை மீண்டும் தொடங்கும். |
| தனிப்பட்ட விளையாட்டு அமர்வுகளுக்கு மட்டுமே பிரத்யேக சேவையகம் திறக்கப்பட்டது | அதே dedicated-server தொகுப்பு | `temporary_dedicated` அடுத்த சுயவிவரத்தை அமர்வுகளுக்கு இடையில் பாதுகாப்பாக வைத்திருக்கும், அதே நேரத்தில் ஒரு புதிய குடும்ப இயக்கமானது உள்ளமைக்கப்பட்ட அல்லது சீரற்ற தொடக்கத்தைப் பயன்படுத்தலாம். |
| ஒரு சிங்கிள் பிளேயர் அல்லது LAN உலகம் | Singleplayer/LAN தொகுப்பு | `auto` கையேடு-நகல் நடத்தையைத் தேர்ந்தெடுக்கிறது; உருவாக்கப்பட்ட கோப்பை நகலெடுக்கும் முன் உலகத்தை நிறுத்தவும். |

உங்களுக்குத் தெரியாவிட்டால், `auto`. தொகுப்பு அதன் நிறுவல் வகைக்கான இயல்பான நடத்தையைத் தேர்ந்தெடுக்கிறது. [குடும்ப சுழற்சி](%E0%AE%95%E0%AF%81%E0%AE%9F%E0%AF%81%E0%AE%AE%E0%AF%8D%E0%AE%AA_%E0%AE%9A%E0%AF%81%E0%AE%B4%E0%AE%B1%E0%AF%8D%E0%AE%9A%E0%AE%BF.md). [உருவாக்கப்பட்ட குடும்பக் குறியீடு](%E0%AE%9A%E0%AF%81%E0%AE%AF%E0%AE%B5%E0%AE%BF%E0%AE%B5%E0%AE%B0%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AE%B3%E0%AF%8D/%E0%AE%9A%E0%AF%81%E0%AE%AF%E0%AE%B5%E0%AE%BF%E0%AE%B5%E0%AE%B0_%E0%AE%86%E0%AE%B5%E0%AE%A3%E0%AE%AE%E0%AF%8D.md) நீங்கள் சரியான விளையாட்டு மற்றும் சாண்ட்பாக்ஸ் மதிப்புகளை விரும்பினால். பிறகு முதல் நாள் மற்றும் முன்னேற்றத்தைத் தேர்ந்தெடுக்கவும்:

- `start_day_mode="configured"` `start_day`.
- `start_day_mode="random"` ஒரு புதிய குடும்ப ஓட்டத்தின் தொடக்கத்தில் ஒரு செல்லுபடியாகும் முதல் நாளைத் தேர்வுசெய்து, அந்தத் தேர்வைத் தொடரும்.
- `day_progression_mode="sequential"` அனைத்து 17 நிலைகளிலும் முடிவடைகிறது.
- `day_progression_mode="non_repeating_random"` ஒரு ஷஃபிள் செய்யப்பட்ட ஆர்டரைச் சேமிக்கிறது, அதில் ஒவ்வொரு நாளும் சரியாக ஒரு முறை இருக்கும்.

முழு முன்னமைவுகளை [சுழற்சி](#rotation). தேர்ந்தெடுக்கப்பட்ட முதல் சுயவிவரத்தைத் தயாரிப்பதற்கு ஒரு புதிய நிறுவலுக்கு இன்னும் ஒரு தொடக்கமும் அதைச் செயல்படுத்துவதற்குப் பிறகு தொடங்கவும் வேண்டும்.

<a id="release-identity-and-logging"></a>
## அடையாளத்தை வெளியிடுதல் மற்றும் பதிவு செய்தல்

| அமைப்பு | வகை மற்றும் அனுப்பப்பட்ட மதிப்பு | ஆதரிக்கப்படும் பயன்பாடு | தோல்வி அல்லது தொடர்பு |
|---|---|---|---|
| `version` | சரம் வாசிக்கப்பட்டது `.randomday_version` | படிக்க மட்டும். | காணவில்லை அல்லது வெற்று மார்க்கர் ஆனது `unversioned`; இறுதி தொகுப்பு சரிபார்ப்பு அடையாள சறுக்கலை நிராகரிக்கிறது. |
| `package_mode` | சரம் வாசிக்கப்பட்டது `.randomday_mode` | படிக்க மட்டும்: `dedicated_server` அல்லது `singleplayer_manual`. | இலக்கு எழுதும் முன் வேறு எந்த மதிப்பும் தொடக்கத்தை நிறுத்தும். |
| `plan_basis` | சரம்: `RandomDay - Seventeen Suns Rotation + Open World Scope` | கண்டறியும் லேபிள் மட்டும்; அதை ஒரு அம்சம் மாற்றாகப் பயன்படுத்த வேண்டாம். | தற்போதைய இயக்க நேரம் இந்தப் புலத்தில் பிரிவதில்லை. |
| `logging.level` | சரம்: `info` | `debug`, `info`, `warn`, அல்லது `error`. | தெரியாத மதிப்புகள் பதிவு இடங்களைச் சேர்க்காது; `info` சுயவிவர தலைமுறை நடத்தை கண்டறியும் வரை. |

எடுத்துக்காட்டு:

```lua
logging = { level = "debug" }
```

பயன்படுத்து `debug` தற்காலிகமாக, தொடர்புடையவற்றைப் பாதுகாக்கவும் `UE4SS.log`, பின்னர் `info`. பதிவுகள் குறைந்த அளவிலான தோல்விகளிலிருந்து உள்ளூர் பாதைகளைக் கொண்டிருக்கலாம்; பகிர்வதற்கு முன் அவற்றை மதிப்பாய்வு செய்யவும்.

<a id="experience-mode"></a>
## அனுபவ பயன்முறை

`experience.mode` குறிப்பிடுகிறது. இது அடுத்த தொடக்க பாதுகாப்பு எல்லையை பலவீனப்படுத்தாது: Abiotic Factor UE4SS ஏற்றங்கள் RandomDay, எனவே ஏற்கனவே இயங்கும் செயல்முறையின் விதிகளை எந்த பயன்முறையும் மாற்ற முடியாது.

| அமைப்பு | அனுப்பப்பட்ட மதிப்பு | ஆதரிக்கப்படும் மதிப்புகள் | விளைவு |
|---|---:|---|---|
| `experience.mode` | `auto` | `auto`, `persistent_dedicated`, `temporary_dedicated`, `singleplayer_lan` | `auto` தொகுப்பிலிருந்து தீர்க்கிறது. பிரத்யேக தொகுப்புகள் பிரத்யேக பயன்முறையைப் பயன்படுத்தலாம். கையேடு-நகல் தொகுப்பு `auto` அல்லது `singleplayer_lan`. |

- `persistent_dedicated` ஒன்றைச் சேமிக்கும் family/day ஆர்டர்.
- `temporary_dedicated` வரையறுக்கப்பட்ட விளையாட்டு அமர்வுகளுக்காக தொடங்கப்பட்ட சேவையகத்தை விவரிக்கிறது. இது இன்னும் தயாரிக்கப்பட்ட வரிசையைத் தொடர்கிறது, எனவே ஹோஸ்ட்டை நிறுத்துவது அடுத்த அமர்வை அமைதியாக மறுதொடக்கம் செய்யாது.
- `singleplayer_lan` கட்டுப்படுத்தப்பட்ட கையேடு-நகல் வெளியீட்டை மட்டுமே உருவாக்குகிறது. தனிப்பட்ட சேமிப்பு கோப்புறையை இது ஒருபோதும் கண்டறியாது அல்லது திருத்தாது.

ஒரு இணக்கமற்றது package/experience சேர்க்கை நிறுத்தப்படும்.

<a id="recommended-presets"></a>
### பரிந்துரைக்கப்பட்ட முன்னமைவுகள்

தொடர்ச்சியான அர்ப்பணிப்பு சேவையகம்:

```lua
experience = { mode = "persistent_dedicated" }
cycle = {
    application_mode = "next_reboot_queue",
    cycle_length_days = 17,
    start_day_mode = "configured",
    start_day = 1,
    day_progression_mode = "sequential",
    bootstrap_day = 1,
    check_interval_ms = 0,
}
```

ஒரு புதிய குடும்ப ஓட்டத்திற்கு மீண்டும் மீண்டும் செய்யாத வெவ்வேறு வரிசையுடன் தற்காலிக பிரத்யேக அமர்வுகள்:

```lua
experience = { mode = "temporary_dedicated" }
cycle.start_day_mode = "random"
cycle.day_progression_mode = "non_repeating_random"
```

Singleplayer/LAN கையேடு நகல் சிங்கிள் பிளேயர் தொகுப்பைப் பயன்படுத்துகிறது மற்றும் பொதுவாக வெளியேறுகிறது `experience.mode="auto"`. அடுத்த கோப்பை உருவாக்கும் முன், அதே தொடக்க மற்றும் முன்னேற்றக் கட்டுப்பாடுகளை நீங்கள் தேர்வு செய்யலாம். இயக்க நேர நிலை மற்றும் உலகின் ஏற்றப்பட்ட சுயவிவரம் சீரமைக்கப்பட வேண்டும் என நீங்கள் விரும்பினால், உருவாக்கப்பட்ட கோப்பை மற்றொரு தலைமுறை இயங்கும் முன் தேர்ந்தெடுக்கப்பட்ட நிறுத்தப்பட்ட உலகில் நகலெடுக்கவும்.

புதிய நிறுவலில், முதல் செயல்முறை தேர்ந்தெடுக்கப்பட்ட தொடக்க நாளை மட்டுமே தயாரிக்க முடியும். பிந்தைய செயல்முறை அதை செயல்படுத்துகிறது. சீரற்ற அல்லது உள்ளமைக்கப்பட்ட தொடக்கமானது அந்த எஞ்சின் ஏற்றுதல் வரிசையைத் தவிர்க்காது.

ஒரு நிலையான பில்டர் இயக்கத்திற்கான எடுத்துக்காட்டு:

```lua
profile_family = {
    mode = "selected_run",
    selected_family = "builder",
    default_family = "action",
    allowed_families = { "builder" },
    preserve_family_until_day_17 = true,
    reroll_only_after_day_17 = true,
    prevent_repeats_until_rotation_complete = true,
}
```

வெற்று அல்லது அறியப்படாத தகுதியான தொகுப்பு முழுமையற்ற சுயவிவரத்தை உருவாக்குவதற்குப் பதிலாக பதிவுசெய்யப்பட்ட குடும்பத்திற்குத் திரும்பும்.


செயல்முறையின் தற்போதைய செயல்பாட்டு கோப்பகத்தில் இருந்து இந்த குறைப்பு தீர்க்கப்படவில்லை. `sandbox_path_override` உங்கள் நிறுவல் வேறு நேரடியான கோப்பைப் பயன்படுத்தும் போது மட்டுமே. அதை ஒன்றுக்கு சுட்டி `SandboxSettings.ini`, அடைவு அல்ல. சேவையகத்தை நிறுத்தி, கோப்பு பயன்படுத்தப்படுவதற்கு முன், நிறுவலின் உள்ளே இருப்பதை உறுதிப்படுத்தவும்.

<a id="optional-mirrors"></a>
### விருப்பக் கண்ணாடிகள்

`paths.write_sandbox_mirrors` `true`, ஆனால் கண்ணாடி பாதை பட்டியல் காலியாக உள்ளது மற்றும் `paths.world_name` என்பது `nil`. எனவே அனுப்பப்பட்ட இயல்புநிலைகள் கூடுதல் கண்ணாடியை எழுதுவதில்லை. அதை `false` நிறுவல் எப்போதும் தீர்க்கப்பட்ட முதன்மை இலக்கை மட்டுமே எழுத வேண்டும். உள்ளமைக்கப்படாத மிரர் கேண்டிடேட் அல்லது உலகப் பெயர் இல்லாமல், மதிப்பு இன்னும் முதன்மை சாண்ட்பாக்ஸ் கோப்பை மட்டுமே எழுதுகிறது.

நீங்கள் வேண்டுமென்றே ஒரு துல்லியமான உள்ளீட்டை `paths.sandbox_mirror_candidates` அல்லது அமை `paths.world_name`. இரண்டாவது உலக-குறிப்பிட்ட சாண்ட்பாக்ஸ் பாதையைப் படிக்கும் நிறுவல்களுக்கான சிறந்த முயற்சி பிரதிகள் கண்ணாடிகள். அவை சரியான முதன்மை பாதையை உள்ளமைப்பதற்கு மாற்றாக இல்லை.

கண்ணாடியை இயக்கும் முன்:

1. சேவையகத்தை நிறுத்து;
2. சேவையகம் படிக்கும் கோப்பை சரியாக அடையாளம் காணவும்;
3. இலக்கு உத்தேசிக்கப்பட்ட நிறுவலின் உள்ளே இருப்பதை உறுதிப்படுத்தவும்;
4. இதை காப்பு பிரதி எடுக்கவும்;
5. அந்தப் பாதையை மட்டும் சேர்;
6. தயாரித்த பிறகு கண்ணாடி முடிவைச் சரிபார்க்கவும்.

உதாரணம் கண்ணாடி இல்லாமல் மேலெழுதுதல்:

```lua
paths = {
    runtime_dir = "ue4ss/Mods/RandomDay/runtime",
    web_export_dir = "ue4ss/Mods/RandomDay/web_export",
    sandbox_path_override = "<server-root>/AbioticFactor/Saved/Config/WindowsServer/SandboxSettings.ini",
    sandbox_candidates = {},
    write_sandbox_mirrors = false,
    sandbox_mirror_required = false,
    world_name = nil,
    sandbox_mirror_candidates = {},
}
```

`<server-root>` என்பது ஒரு ஒதுக்கிடமாகும். அதை உள்நாட்டில் மாற்றவும்; இயந்திரம் சார்ந்த பாதையை வெளியிட வேண்டாம்.

<a id="non-disableable-safety-locks"></a>
## முடக்க முடியாத பாதுகாப்பு பூட்டுகள்

| அமைப்பு | தேவையான மதிப்பு | பொருள் |
|---|---:|---|
| `sandbox.backup_before_write` | `true` | ஏற்கனவே உள்ள முதன்மை கோப்பை மாற்றும் முன் சரிபார்க்கப்பட்ட நகலை சேமிக்கவும். |
| `sandbox.restore_last_good_on_failure` | `true` | தோல்வியடைந்த மாற்றீடு அல்லது மறுபரிசீலனைக்குப் பிறகு தானாகவே மீட்டெடுக்க முயற்சிக்கவும். |
| `external_mods.patch_only_existing_keys` | `true` | மற்றொரு மோட் கோப்பில் தெரியாத அமைப்பைக் கண்டுபிடிக்க மறுக்கவும். |
| `external_mods.backup_before_write` | `true` | ஆதரிக்கப்படும் பரிவர்த்தனை அடாப்டர் திருத்தத்திற்கு முன் இலக்கு பைட்டுகளைப் பாதுகாக்கவும். |

RandomDay தொடக்கத்தை மறுக்கிறது `true`. அவை பாதுகாப்பு பூட்டுகள், ஆபரேட்டர் மாற்றுகளை ஆதரிக்கவில்லை. மேம்பாடு அல்லது சரிசெய்தல் உட்பட அவற்றை முடக்க வேண்டாம், ஏனெனில் அவ்வாறு செய்வது எழுத்தாளர் மற்றும் அடாப்டர் சோதனைகள் நிரூபிக்கும் தோல்வி-மூடப்பட்ட எல்லையை மாற்றுகிறது.

`sandbox.force_rewrite_every_supervision_tick` ஒரு சாதாரண அமைப்பாக உள்ளது மற்றும் `false`, இது ஏற்கனவே பொருந்தும் சாண்ட்பாக்ஸ் கோப்பைத் தொடாமல் விட்டுவிடுகிறது. இது ஒரு பூலியனை ஏற்றுக்கொள்கிறது. `true` அதே செயல்முறைக்கு சொந்தமான தயாரிக்கப்பட்ட பைட்டுகளை மீண்டும் எழுத்தாளர் மூலம் கட்டாயப்படுத்துகிறது; அது family/day. மீண்டும் மீண்டும் எழுதுவது அதிக செயல்பாட்டு காப்புப்பிரதிகளை உருவாக்கும் என்பதால், வரம்புக்குட்பட்ட மீட்பு சோதனைக்கு மட்டுமே இதைப் பயன்படுத்தவும்.

<a id="optional-mod-adapters"></a>
## விருப்ப மோட் அடாப்டர்கள்

| அமைப்பு | அனுப்பப்பட்ட மதிப்பு | பொருள் |
|---|---:|---|
| `external_mods.enabled` | `true` | தனியாக நிறுவப்பட்ட இலக்குகளை ஆய்வு செய்ய உள்ளமைக்கப்பட்ட அடாப்டர்களை அனுமதிக்கவும். |
| `external_mods.optional_by_default` | `true` | காணாமல் போன அல்லது பொருந்தாத விருப்ப முறைகள் தடுக்காது RandomDay. |
| `external_mods.patch_only_existing_keys` | `true` | தேவையான பாதுகாப்பு பூட்டு; மாற்றினால் தொடக்கம் தோல்வியடையும். |
| `external_mods.backup_before_write` | `true` | தேவையான பாதுகாப்பு பூட்டு; மாற்றினால் தொடக்கம் தோல்வியடையும். |
| `external_mods.adapters` | நான்கு பொது அடாப்டர் ஐடிகள் | எதைக் கட்டுப்படுத்துகிறது RandomDay-owned அடாப்டர்கள் இயங்கலாம். |

மூன்றாம் தரப்பு மோடை முடக்காமல் அல்லது நிறுவல் நீக்காமல், அந்த ஒருங்கிணைப்பை அப்படியே விட்டுவிட, பட்டியலிலிருந்து அடாப்டர் ஐடியை அகற்றவும். தி singleplayer/LAN தொகுப்பு இந்தப் பட்டியலைப் பொருட்படுத்தாமல் ஒவ்வொரு அடாப்டரையும் முடக்குகிறது.

`external_mods.optional_by_default=false` `applied` அல்லது `already_current` மொத்த அடாப்டர் முடிவு தோல்வி. இது முதன்மை சாண்ட்பாக்ஸ் பரிவர்த்தனையை திரும்பப்பெறச் செய்யாது. அனுப்பப்பட்டதை `true` ஆபரேட்டருக்கு ஒரு ஒருங்கிணைப்பு தேவைப்படுவதற்கான சோதனைக் காரணம் இருந்தால் தவிர.

பார்க்கவும் [ஆதரிக்கப்படும் மோட் அடாப்டர்கள்](%E0%AE%86%E0%AE%A4%E0%AE%B0%E0%AE%BF%E0%AE%95%E0%AF%8D%E0%AE%95%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AE%9F%E0%AF%81%E0%AE%AE%E0%AF%8D_%E0%AE%85%E0%AE%9F%E0%AE%BE%E0%AE%AA%E0%AF%8D%E0%AE%9F%E0%AE%B0%E0%AF%8D%E0%AE%95%E0%AE%B3%E0%AF%8D.md) அங்கீகரிக்கப்பட்ட தளவமைப்புகள் மற்றும் ஆறு சாத்தியமான விளைவுகளுக்கு.

<a id="optional-chaotic-spawn-engine-scope-fields"></a>
### விருப்பமான குழப்பமான ஸ்பான் எஞ்சின் ஸ்கோப் புலங்கள்

`world_scope` ஐந்து விருப்பங்களை வழங்குகிறது RandomDay நீட்டிப்பு அமைப்புகள் அங்கீகரிக்கப்பட்ட குழப்பமான ஸ்பான் எஞ்சின் `DynamicSpawns/SharedData.lua` தளவமைப்பில் ஏற்கனவே அந்தப் புலங்கள் உள்ளன. இது ஒரு தனி மோட் அல்லது பதிவிறக்கம் அல்ல:

| அமைப்பு | அனுப்பப்பட்ட மதிப்பு | அடாப்டர் விளைவு |
|---|---:|---|
| `world_scope.enabled` | `true` | விருப்பத்தைக் கோருகிறது RandomDay அங்கீகரிக்கப்பட்ட DynamicSpawns தளவமைப்பு. |
| `world_scope.affect_open_worlds` | `true` | இலக்கு மோட் பாதுகாக்கப்பட்ட-உலக விதியைப் பயன்படுத்தாவிட்டால் திறந்த உலகங்களை உள்ளடக்கியது. |
| `world_scope.unknown_world_policy` | `allow` | கோரிக்கைகள் `allow` அல்லது `block` இலக்கு மோட் உலகத்தை வகைப்படுத்த முடியாத போது. |
| `world_scope.log_scope_decisions` | `true` | அதன் நோக்கம் முடிவுக்காக இலக்கு-மோட் உள்நுழைவைக் கோருகிறது. |
| `world_scope.protected_worlds` | காலி பட்டியல் | இலக்கு அமைப்பிற்கு காற்புள்ளியால் பிரிக்கப்பட்ட பாதுகாக்கப்பட்ட உலக வடிவங்களை வழங்குகிறது. |

இந்த மதிப்புகள் அடாப்டர் உள்ளீடு, RandomDay's சாண்ட்பாக்ஸ் எழுத்தாளர். தனித்தனியாக நிறுவப்பட்ட குழப்பமான ஸ்பான் என்ஜின் தளவமைப்பு ஏற்கனவே முழுமையான விருப்பத்தை கொண்டிருக்கும் போது மட்டுமே அவை செயல்படும் RandomDay புல தொகுப்பு மற்றும் அறிக்கைகள் `applied` அல்லது `already_current`. இயக்க நேரத்தில் அந்த புலங்களைப் பயன்படுத்துவதற்கு குழப்பமான ஸ்பான் எஞ்சின் பொறுப்பாக உள்ளது. நீட்டிப்பு புலங்கள் இல்லாத ஒரு சாதாரண நிறுவல் மாறாமல் உள்ளது.

ஐந்து மதிப்புகளும் அடாப்டர் உள்ளீடுகள். `unknown_world_policy` ஆவணப்படுத்தப்பட்ட இலக்கு மதிப்புகளை மட்டுமே ஏற்றுக்கொள்கிறது `allow` அல்லது `block`; அங்கீகரிக்கப்படாத இலக்கு தளவமைப்பு தவிர்க்கப்பட்டது. `protected_worlds` காலியாக உள்ளது. ஒரு ஆபரேட்டர் உள்ளூர் வடிவங்களைப் பயன்படுத்தினால், அவை ஸ்கிரீன்ஷாட்கள், சிக்கல்கள் அல்லது வெளியீட்டு கலைப்பொருட்களில் சேர்க்கப்படக்கூடாது.

<a id="player-messages"></a>
## பிளேயர் செய்திகள்

அனுப்பப்பட்ட டெடிகேட்டட்-சர்வர் உள்ளமைவு, கச்சிதமான கூட்டு அறிவிப்புகள் மற்றும் ஒரு சிறிய தினசரி வரியை செயல்படுத்துகிறது. இது முதல் பாஸுக்கு 30 வினாடிகள் காத்திருக்கிறது, ஒவ்வொரு 15 வினாடிகளுக்கும் புதிதாகச் சேர்ந்த வீரர்களைச் சரிபார்க்கிறது, மேலும் தினசரி வரிக்கு முன் ஒரு சேர அறிவிப்புக்குப் பிறகு 10 வினாடிகள் காத்திருக்கிறது.

| அமைப்பு | அனுப்பப்பட்ட மதிப்பு |
|---|---:|
| `player_message.enabled` | `true` |
| `player_message.log_on_startup` | `true` |
| `player_message.register_console_command` | `false` |
| `player_message.console_command` | `randomday` |
| `player_message.broadcast_enabled` | `true` |
| `player_message.startup_delay_ms` | `30000` |
| `player_message.join_check_interval_ms` | `15000` |
| `player_message.send_daily_joke_after_join` | `true` |
| `player_message.daily_joke_delay_seconds` | `10` |
| `player_message.criticality_join` | `2` |
| `player_message.criticality_joke` | `0` |
| `player_message.max_line_chars` | `42` |
| `player_message.max_join_lines` | `4` |
| `player_message.max_warning_lines` | `3` |
| `player_message.max_note_lines` | `3` |

செய்தி நீள சரிபார்ப்பு மூல வரம்புகளைச் சரிபார்க்கிறது. ஒவ்வொரு கிளையன்ட் தெளிவுத்திறனிலும் காட்சி சோதனையை இது மாற்றாது.

நேர மதிப்புகள் `daily_joke_delay_seconds`. முடக்கப்பட்ட செய்தி அல்லது ஒளிபரப்பு அமைப்பு சாண்ட்பாக்ஸ் தயாரிப்பை மாற்றாமல் கிளையன்ட் அறிவிப்புகளை அடக்குகிறது. அமைப்பு மற்றும் UE4SS ஹேண்ட்லர் கிடைக்கிறது. பெயரிடப்பட்ட கிளையன்ட் சோதனை மற்றொரு மதிப்பை நிரூபிக்கும் வரை, அனுப்பப்பட்ட போக்குவரத்து நிலைகளில் முக்கியமான மதிப்புகளை வைத்திருங்கள்.

`max_line_chars` மொழிபெயர்ப்பாளரால் 8 முதல் 64 எழுத்துகள் வரை இணைக்கப்பட்டுள்ளது. மூன்று வரி-எண்ணிக்கை அமைப்புகள் முறையே இணைத்தல், எச்சரிக்கை மற்றும் குறிப்பு வெளியீட்டைக் கட்டுப்படுத்துகின்றன; அனுப்பப்பட்ட மதிப்புகள் கிடைக்கக்கூடிய மூல வரிகளின் எண்ணிக்கையுடன் பொருந்துகின்றன. கிளையன்ட்-லேஅவுட் சோதனையானது குறுகிய அமைப்பை நிரூபிக்கும் வரை, இந்த நான்கு வரம்புகளையும் அவற்றின் இயல்புநிலையில் வைத்திருங்கள்.

முடக்கப்பட்ட செய்திகளுடன் உதாரணம்:

```lua
player_message = {
    enabled = false,
    log_on_startup = true,
    register_console_command = false,
    console_command = "randomday",
    broadcast_enabled = false,
    startup_delay_ms = 30000,
    join_check_interval_ms = 15000,
    send_daily_joke_after_join = false,
    daily_joke_delay_seconds = 10,
    criticality_join = 2,
    criticality_joke = 0,
    max_line_chars = 42,
    max_join_lines = 4,
    max_warning_lines = 3,
    max_note_lines = 3,
}
```

## சுயவிவரங்கள் மற்றும் சாண்ட்பாக்ஸ் மதிப்புகள்

குடும்ப மூல கோப்புகள் `RandomDay/Scripts/ax_profiles/families/` ஒரு குடும்பத்திற்கு 17 முழுமையான நாட்களை வரையறுக்கிறது. `docs/profiles/` என்பது குறிப்பு வெளியீடு, தனிப்பயனாக்க மூலமல்ல.

பயன்படுத்து [சாண்ட்பாக்ஸ் முக்கிய குறிப்பு](%E0%AE%9A%E0%AF%81%E0%AE%AF%E0%AE%B5%E0%AE%BF%E0%AE%B5%E0%AE%B0%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AE%B3%E0%AF%8D/%E0%AE%9A%E0%AE%BE%E0%AE%A3%E0%AF%8D%E0%AE%9F%E0%AF%8D%E0%AE%AA%E0%AE%BE%E0%AE%95%E0%AF%8D%E0%AE%B8%E0%AF%8D_%E0%AE%85%E0%AE%AE%E0%AF%88%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81%E0%AE%95%E0%AE%B3%E0%AF%8D_%E0%AE%B5%E0%AE%BF%E0%AE%9A%E0%AF%88%E0%AE%95%E0%AE%B3%E0%AF%8D.md) வகைகள், வரம்புகள், அனுப்பப்பட்ட சுயவிவர இயல்புநிலைகள் மற்றும் மீதமுள்ள மாறாத மதிப்புகள். சுயவிவர மூலத்தைத் திருத்திய பிறகு, அனைத்து 289 சேர்க்கைகளையும் மீண்டும் உருவாக்கி சரிபார்க்கவும்; உருவாக்கப்பட்ட மார்க் டவுன் அல்லது JSON கையால் பதிவு செய்யவும்.

<a id="customize-the-shipped-profile-defaults"></a>
### ஷிப் செய்யப்பட்ட சுயவிவர இயல்புநிலைகளைத் தனிப்பயனாக்குக

திற:

```text
RandomDay/Scripts/ax_config/server.lua
```

இந்தத் தடுப்பை `sandbox`:

```lua
profile_overrides = {
    HardcoreMode = false,
    AllowIronMode = false,
    StructuralSupportLimit = 0,
    BridgeSupports = 0,
}
```

இவை RandomDay's தொடக்கத் தேர்வுகள், மாற்ற முடியாத அபியோடிக் காரணி விதிகள் அல்ல. எந்த பயன்முறையையும் `true` அல்லது `false`. ஒவ்வொரு ஆதரவு மதிப்பையும் `0` மூலம் `1000`. கோப்பைத் திருத்துவதற்கு முன் கேமையோ அல்லது பிரத்யேக சேவையகத்தையோ நிறுத்தி, அதைச் சேமித்து, பின்னர் மீண்டும் தொடங்கவும், இதனால் Lua புதிய உள்ளமைவை ஏற்றுகிறது.

RandomDay ஒரு குடும்பத்தில் 17 சுயவிவரங்களை உருவாக்கும் போதெல்லாம் இந்தத் தொகுதியைப் படிக்கும். தேர்ந்தெடுக்கப்பட்ட மதிப்புகள் ஒவ்வொரு குடும்பத்திற்கும் நாளுக்கும் பயன்படுத்தப்படும், சுழற்சிக்குப் பிறகு தயாரிக்கப்பட்ட சுயவிவரங்கள் மற்றும் பின்னர் சேவையகத் தொடக்கத்திற்குப் பிறகு மீண்டும் கட்டமைக்கப்பட்ட சுயவிவரங்கள் உட்பட. நீங்கள் 289 சுயவிவரக் கோப்புகளைத் திருத்தவோ சுயவிவரக் குறிப்பை மீண்டும் உருவாக்கவோ தேவையில்லை.

நேரலையை மட்டும் மாற்றுகிறது `SandboxSettings.ini` தற்காலிகமானது, ஏனெனில் அடுத்த தயாரிக்கப்பட்ட சுயவிவரம் `server.lua`. தவறான வகைகள், தெரியாத விசைகள் அல்லது ஆதரவு மதிப்புகள் `0..1000` இயல்புநிலைகளுக்கு அமைதியாக மாற்றுவதற்குப் பதிலாக பெயரிடப்பட்ட உள்ளமைவுப் பிழையுடன் சுயவிவரக் கட்டமைப்பை நிறுத்தவும்.

உருவாக்கப்பட்ட சுயவிவரக் குறிப்பு அனுப்பப்பட்ட இயல்புநிலைகளைக் காண்பிக்கும். இது ஒரு வெளியீட்டு குறிப்பு, ஒரு சேவையகத்தின் தனிப்பட்ட உள்ளமைவின் நகல் அல்ல.
