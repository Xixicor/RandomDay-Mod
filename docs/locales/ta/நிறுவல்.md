# நிறுவவும், புதுப்பிக்கவும் அல்லது அகற்றவும் RandomDay

> **நியாய ஆங்கில மூல:** [INSTALL.md](../../../INSTALL.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


RandomDay இரண்டு முழுமையான பதிவிறக்கங்களைக் கொண்டுள்ளது. நீங்கள் அமைக்கும் உலகத்திற்கான ஒன்றைத் தேர்ந்தெடுக்கவும்:

- ஐப் பயன்படுத்தவும் **dedicated-server ZIP**, அவ்வப்போது அமர்வுகளுக்கு மட்டுமே திறக்கப்படும் சேவையகம் உட்பட;
- ஐப் பயன்படுத்தவும் **singleplayer/LAN ZIP** ஒரு உள்ளூர் உலகத்திற்கான அமைப்புகளை நீங்கள் கைமுறையாக நகலெடுக்கலாம்.

தொகுப்புகளை இணைக்க வேண்டாம். நிலையான அல்லது தற்காலிக பிரத்யேக சேவையகம் RandomDay's அமைப்புகள், வேறு பதிவிறக்கம் அல்ல.

<a id="before-you-begin"></a>
## தொடங்கும் முன்

இதன் மீட்டெடுக்கக்கூடிய நகலை உருவாக்கவும்:

- நீங்கள் மாற்றும் உலகம்;
- அதன் தற்போதைய `SandboxSettings.ini`;
- தற்போதுள்ள `RandomDay` கோப்புறை, ஒன்று நிறுவப்பட்டிருந்தால்.

நிறுவு UE4SSக்கு முன் RandomDay. கீழே உள்ள வழிமுறைகளில், **Mods கோப்புறை** என்பது `ue4ss/Mods/` கேமுக்குள் அடைவு அல்லது அர்ப்பணிக்கப்பட்ட-சேவையக நிறுவல்.

<a id="dedicated-server"></a>
## பிரத்யேக சேவையகம்

<a id="new-installation"></a>
### புதிய நிறுவல்

1. சேவையகத்தை நிறுத்து.
2. அதன் UE4SS `Mods` கோப்புறை.
3. அர்ப்பணிக்கப்பட்ட சேவையகத்தைப் பிரித்தெடுக்கவும் ZIP. முடிவு ஒன்று `ue4ss/Mods/RandomDay/` கோப்புறை, மற்றொரு உள்ளே உள்ள கோப்புறை அல்ல `RandomDay` கோப்புறை.
4. அந்த கோப்புறையைத் திறந்து உறுதிப்படுத்தவும் `RandomDay/Scripts/main.lua` உள்ளது. அது விடுபட்டால், ZIP தவறான நிலையில் பிரித்தெடுக்கப்பட்டது.
5. திற UE4SS `mods.txt` மற்றும் இந்த வரியை இயக்கவும்:

   ```text
   RandomDay : 1
   ```

6. சேவையகத்தை சாதாரணமாகத் தொடங்கவும்.
7. திற RandomDay's படிக்கக்கூடிய நிலைப் பக்கம் மற்றும் செயலில் உள்ள சுயவிவரம் மற்றும் அடுத்த தொடக்கத்திற்குத் தயாரிக்கப்பட்ட சுயவிவரம் ஆகிய இரண்டையும் உறுதிப்படுத்துகிறது.

முதல் தொடக்கமானது அந்த அமர்வால் ஏற்கனவே ஏற்றப்பட்ட விதிகளை மாற்றாது. இது அடுத்த சுயவிவரத்தைத் தயாரிக்கிறது. அந்தத் தயாரிக்கப்பட்ட சுயவிவரம் செயலில் இருக்க வேண்டும் என நீங்கள் விரும்பினால் மட்டுமே சேவையகத்தை மீண்டும் தொடங்கவும்.

[முதல் சுழற்சியைச் சரிபார்க்கவும்](%E0%AE%87%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%87_%E0%AE%A4%E0%AF%8A%E0%AE%9F%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%81.md)

<a id="choose-always-on-or-temporary-behavior"></a>
### எப்போதும் இயங்கும் அல்லது தற்காலிக நடத்தையைத் தேர்வு செய்யவும்

அர்ப்பணிப்பு-சேவையக தொகுப்பு இரண்டு பாணிகளையும் ஆதரிக்கிறது:

- **தொடர்ச்சியான அர்ப்பணிப்பு** சாதாரண மறுதொடக்கம் முழுவதும் சேமிக்கப்பட்ட சுழற்சியை மீண்டும் தொடங்கும்;
- **தற்காலிகமானது** ஒரு புதிய தற்காலிக ரன் தொடங்கும் போது கட்டமைக்கப்பட்ட அல்லது சீரற்ற தொடக்க புள்ளியில் இருந்து தொடங்கலாம்.

[உள்ளமைவு](%E0%AE%89%E0%AE%B3%E0%AF%8D%E0%AE%B3%E0%AE%AE%E0%AF%88%E0%AE%B5%E0%AF%81.md). இந்த அமைப்பை மாற்ற இரண்டாவது தொகுப்பை நிறுவ வேண்டாம்.

<a id="update-an-existing-installation"></a>
### ஏற்கனவே உள்ள நிறுவலைப் புதுப்பிக்கவும்

1. சேவையகத்தை நிறுத்தி, மேலே பட்டியலிடப்பட்டுள்ள காப்புப்பிரதிகளை உருவாக்கவும்.
2. பழையதை நகர்த்தவும் `RandomDay` கோப்புறைக்கு வெளியே UE4SS `Mods` கோப்புறை. புதுப்பிப்பு ஒரு வெற்றிகரமான சுழற்சியை முடிக்கும் வரை அதை வைத்திருங்கள்.
3. புதிய dedicated-server ஐ பிரித்தெடுக்கவும் ZIP இல் `Mods` கோப்புறை.
4. நீங்கள் வேண்டுமென்றே மாற்றிய மற்றும் புதிய அமைப்பில் இருக்கும் அமைப்புகளை மட்டும் மீண்டும் பயன்படுத்தவும் [உள்ளமைவு வழிகாட்டி](%E0%AE%89%E0%AE%B3%E0%AF%8D%E0%AE%B3%E0%AE%AE%E0%AF%88%E0%AE%B5%E0%AF%81.md).
5. ஆவணப்படுத்தப்பட்ட சுழற்சி நிலை கோப்புகளை அவற்றின் வடிவம் இணக்கமானது என்று வெளியீட்டு குறிப்புகள் கூறும்போது மட்டுமே அவற்றை வைத்திருக்கவும். பழைய தற்காலிக வெளியீடு அல்லது தோல்வியடைந்த-எழுதும் கோப்புகளை புதிய நிறுவலில் நகலெடுக்க வேண்டாம்.
6. உறுதிப்படுத்து `RandomDay : 1` இன்னும் இயக்கத்தில் உள்ளது, பிறகு சர்வரை ஒருமுறை தொடங்கி செயலில் உள்ள மற்றும் தயாரிக்கப்பட்ட சுயவிவரப் பெயர்களைச் சரிபார்க்கவும்.

<a id="updating-from-v0315-alpha"></a>
### இலிருந்து புதுப்பிக்கிறது v0.3.15-alpha

`RandomDay_v0.3.15-alpha.zip` என்பது பழைய அடிப்படை தொகுப்பாகும். `RandomDay_v0.3.15-alpha_singleplayer_patch.zip` ஒரு மேலடுக்கு மற்றும் ஒரு முழுமையான பதிவிறக்கம் அல்ல.

தற்போதைய `v0.3.16-alpha` இரண்டு முழுமையான தொகுப்புகளுடன் வரலாற்று அடிப்படை மற்றும் மேலடுக்கு ஏற்பாட்டை மாற்றுகிறது. இரண்டு தொகுப்பிலும் பழைய பேட்சை வைக்க வேண்டாம். தற்போதைய குறிப்பான்கள் `.randomday_mode=dedicated_server` மற்றும் `.randomday_mode=singleplayer_manual`.

<a id="singleplayer-or-lan"></a>
## Singleplayer அல்லது LAN

தி singleplayer/LAN தொகுப்பு அமைப்புக் கோப்பை உருவாக்குகிறது; தனிப்பட்ட சேமிப்பைத் தேடவோ மாற்றவோ இல்லை.

1. கேமை மூடு.
2. உலகையும் அதன் நடப்பையும் காப்புப் பிரதி எடுக்கவும் `SandboxSettings.ini`.
3. இதை பிரித்தெடுக்கவும் singleplayer/LAN ZIP விளையாட்டில் UE4SS `Mods` கோப்புறை ஒன்று `Mods/RandomDay/` கோப்புறை உள்ளது.
4. இயக்கு `RandomDay : 1` in UE4SS `mods.txt`.
5. ஒருமுறை விளையாட்டைத் தொடங்கவும், RandomDay முடிக்க, கேமை முழுமையாக மூடவும்.
6. உருவாக்கப்பட்டதைக் கண்டுபிடி `SandboxSettings.ini` in RandomDay's `runtime/singleplayer_manual/` கோப்புறை.
7. உருவாக்கப்பட்ட சுருக்கத்தைப் படித்து, நீங்கள் தேர்ந்தெடுத்த உலகத்திற்கு கோப்பை நகலெடுக்கவும்.
8. அந்த உலகத்தைத் தொடங்கி, எதிர்பார்க்கப்படும் சாண்ட்பாக்ஸ் நடத்தை செயலில் உள்ளதா எனச் சரிபார்க்கவும்.

LAN அதே கைமுறை செயல்முறையைப் பயன்படுத்துகிறது, ஏனெனில் ஹோஸ்ட் உள்ளூர் உலகத்தை வைத்திருக்கிறது. மோட் ஒரு உலகத்தைத் தேர்ந்தெடுக்காது அல்லது தானாக மேலெழுதும்.

[Singleplayer மற்றும் LAN வழிகாட்டி](SINGLEPLAYER_LAN.md)

<a id="remove-or-disable-randomday"></a>
## நீக்கு அல்லது முடக்கு RandomDay

1. கேம் அல்லது சர்வரை நிறுத்தவும்.
2. உலகம், அதன் தற்போதைய சாண்ட்பாக்ஸ் அமைப்புகள் மற்றும் RandomDay's நிலை.
3. அமைவு `RandomDay : 0` in UE4SS `mods.txt` mod ஐ முடக்க அல்லது முழுமையாக நகர்த்த `RandomDay` கோப்புறைக்கு வெளியே `Mods` கோப்புறை.
4. எதைத் தீர்மானிக்கவும் `SandboxSettings.ini` ஏற்றப்பட வேண்டும். தற்போது தயாரிக்கப்பட்ட RandomDay சுயவிவரம்.
5. உலகைத் தொடங்கி, எந்த காப்புப்பிரதியையும் நீக்கும் முன் அதன் விதிகளை உறுதிப்படுத்தவும்.

முடக்குகிறது RandomDay எதிர்கால சுயவிவரத் தயாரிப்பை நிறுத்துகிறது. வட்டில் ஏற்கனவே காத்திருக்கும் சாண்ட்பாக்ஸ் கோப்பை இது மீண்டும் எழுதாது.

<a id="recover-from-an-unsuccessful-update"></a>
## தோல்வியடைந்த புதுப்பித்தலில் இருந்து மீட்டெடுக்கவும்

முதல் தெளிவான தோல்விக்குப் பிறகு நிறுத்தவும். மீண்டும் மீண்டும் தொடங்குவது எந்த சுயவிவரம் செயலில் உள்ளது மற்றும் எது காத்திருக்கிறது என்பதைப் பார்ப்பதை கடினமாக்கும்.

1. கேம் அல்லது சர்வரை நிறுத்தவும்.
2. தோல்வியடைந்த நிறுவலை நீக்காமல் ஒதுக்கி நகர்த்தவும்.
3. முழுமையை மீட்டெடுக்கவும் RandomDay கோப்புறை மற்றும் சாண்ட்பாக்ஸ் காப்புப் பிரதி எடுக்கப்பட்டது.
4. ஒருமுறை தொடங்கி, மீட்டமைக்கப்பட்ட செயலில் மற்றும் தயாரிக்கப்பட்ட சுயவிவரப் பெயர்களை உறுதிப்படுத்தவும்.
5. பயன்படுத்து [சரிசெய்தல்](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%9A%E0%AF%86%E0%AE%AF%E0%AF%8D%E0%AE%A4%E0%AE%B2%E0%AF%8D.md) மற்றொரு புதுப்பிப்பை முயற்சிக்கும் முன் காணாமல் போன அல்லது தோல்வியடைந்த முதல் படிக்கு.
