# அறிவிப்பு

> **நியாய ஆங்கில மூல:** [NOTICE.md](../../../NOTICE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும். இந்த மொழிபெயர்ப்பு தகவல் சார்ந்தது; ஆங்கில சட்ட உரை கட்டுப்பாடுகள்.


RandomDay என்பது Abiotic Factor அர்ப்பணிக்கப்பட்ட சேவையகங்களுக்கான ஒரு சுயாதீனமான சமூக மோட் ஆகும்.

RandomDay ஆதரிக்கப்படும் மூன்றாம் தரப்பு மோட்களில் இருந்து குறியீட்டை சேர்க்கவோ, நகலெடுக்கவோ, மீண்டும் ஹோஸ்ட் செய்வதோ அல்லது மறுவிநியோகம் செய்வதோ இல்லை. விருப்ப ஒருங்கிணைப்பு RandomDay-owned அடாப்டர் ஸ்கிரிப்ட்கள், சேவையக உரிமையாளர் அந்த ஆதரிக்கப்படும் மோட்களை தனித்தனியாக நிறுவியிருந்தால் மட்டுமே வெளிப்படும் அமைப்புகளை இணைக்கும்.
