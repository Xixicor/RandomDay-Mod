# நடத்தை விதி

> **நியாய ஆங்கில மூல:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும். இந்த மொழிபெயர்ப்பு தகவல் சார்ந்தது; ஆங்கில சட்ட உரை கட்டுப்பாடுகள்.


அறிக்கைகளை தொழில்நுட்பம், மறுஉருவாக்கம் மற்றும் மரியாதைக்குரியதாக வைத்திருங்கள்.

இந்த களஞ்சியமானது சர்வர் மோட்டின் கட்டுப்படுத்தப்பட்ட மேம்பாட்டிற்கானது. பிழை அறிக்கைகளில் பதிவுகள், பாதைகள், எதிர்பார்க்கப்படும் நடத்தை மற்றும் உண்மையான நடத்தை ஆகியவை இருக்க வேண்டும்.
