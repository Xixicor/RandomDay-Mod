# སྤྱོད་ལམ་གྱི་སྒྲིག་གཞི

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས། སྐད་སྒྱུར་འདི་ཆ་འཕྲིན་ཡིན། དབྱིན་ཡིག་གི་ཁྲིམས་ལུགས་ཡིག་ཆ་དེས་ཚོད་འཛིན་བྱེད་ཀྱི་ཡོད།


སྙན་ཞུ་དེ་ཚོ་ལག་རྩལ་དང་བསྐྱར་བཟོ་ཐུབ་པ་དང་བརྩི་བཀུར་ལྡན་པ་ཞིག་ཉར་དགོས།

མཛོད་འདི་ནི་སར་བར་གྱི་མོ་ཌི་ཚོད་འཛིན་བྱེད་པའི་འཕེལ་རྒྱས་ཆེད་དུ་ཡིན། ནོར་འཁྲུལ་གྱི་སྙན་ཞུའི་ནང་དྲན་ཐོ་དང་ལམ་ཐིག་དང་རེ་བ་བྱེད་པའི་སྤྱོད་ཚུལ་དང་སྤྱོད་ཚུལ་དངོས་ཚུད་དགོས།
