# གནས་ཚུལ་དང་ནོར་འཁྲུལ་དཔྱད་གཞི།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཏག་ཏག་`status`, `transaction_status`, `rollback_status`, དང་ `error` བཀོལ་སྤྱོད་དུས་ཚོད་ཕྱིར་འདྲེན་ནས་རིན་ཐང་། ཐིག་ཁྲམ་ཡང་ན་མཉེན་ཆས་ནང་དུ་མིང་ཚིག་འདྲ་མཚུངས་ཡོད་པ་དེ་ས་སྒོ་དེ་དག་གི་ཚབ་བྱེད་མིན།

ཚན་པ་འདི་ནི་འཚོལ་བཤེར་གཞི་གྲངས་ཆ་ཚང་ཡིན། གོང་དུ་ཐག་གཅོད་ཤིང་གིས་འབྲེལ་ཡོད་སྡེ་ཚན་འདེམས་པ་དང་། ཐིག་ཁྲམ་འདི་དག་གིས་འཕྲུལ་ཆས་ཀྱི་རིན་ཐང་ངེས་ཅན་དང་བཀོལ་སྤྱོད་བྱེད་མཁན་གྱི་ལན་འདེབས་ཉེན་མེད་ཉར་ཚགས་བྱེད།
