`world_scope`མཁོ་སྤྲོད་ལྔའི་གདམ་གསེས།RandomDay ངོས་འཛིན་བྱས་པའི་མགོ་རྙོག་ཅན་གྱི་འཕེལ་རྒྱས་འཕྲུལ་འཁོར་ `DynamicSpawns/SharedData.lua` བཀོད་སྒྲིག་ནང་ལ་ས་ཁོངས་དེ་དག་སྔོན་ནས་ཡོད། འདི་ནི་སོ་སོའི་མོ་ཌི་ཡང་ན་ཕབ་ལེན་མིན།:

| སྒྲིག་སྟངས། | བསྐུར་བའི་རིན་ཐང་། | བསྒྱུར་ཆས་ནུས་པ། |
|---|---:|---|
| `world_scope.enabled` | `true` | གདམ་ཀའི་རེ་ཞུ་བྱེད།RandomDay ངོས་འཛིན་བྱས་པའི་DynamicSpawns བཀོད་སྒྲིག |
| `world_scope.affect_open_worlds` | `true` | དམིགས་འབེན་མོ་ཌི་ཡིས་སྲུང་སྐྱོབ་འཛམ་གླིང་ཁྲིམས་ལུགས་བཀོལ་སྤྱོད་མ་བྱས་ན་ཁ་ཕྱེ་བའི་འཛམ་གླིང་ཚུད་ཡོད། |

རིན་ཐང་འདི་དག་ནི་བསྒྱུར་ཆས་ནང་འཇུག་ཡིན་པ་ལས་ RandomDay's བྱེ་སྒམ་འབྲི་མཁན། དེ་དག་སོ་སོར་སྒྲིག་འཇུག་བྱས་པའི་ཅའོ་ཊིག་སི་པོན་འཕྲུལ་འཁོར་གྱི་བཀོད་སྒྲིག་ནང་གདམ་ག་ཆ་ཚང་ཡོད་པའི་སྐབས་སུ་རྐྱངམ་གཅིག་ནུས་པ་ཐོན་ཐུབ། RandomDayཡིག་དུམ་གྱི་ཆ་སྒྲིག་དང་སྙན་ཞུ།`applied` ཡང་ན་ `already_current`. མགོ་རྙོག་ཅན་གྱི་འཕེལ་རྒྱས་འཕྲུལ་འཁོར་གྱིས་རྒྱུག་པའི་སྐབས་ལ་ས་ཁོངས་དེ་དག་བེད་སྤྱོད་གཏོང་བའི་འགན་འཁྲི་འཁུར་གྱི་ཡོད། རྒྱ་བསྐྱེད་ས་ཁོངས་མེད་པའི་སྤྱིར་བཏང་གི་སྒྲིག་འཇུག་ཅིག་བསྒྱུར་བཅོས་མེད་པར་བཞག་ཡོད།

གནས་གོང་ལྔ་པོ་ཚང་མ་མཉམ་སྦྲེལ་ནང་འཇུག་ཡིན། `unknown_world_policy` ཡིག་ཆ་བཟོས་པའི་དམིགས་འབེན་རིན་ཐང་ཁོ་ན་དང་ལེན་བྱེད།`allow` ཡང་ན་ `block`; ངོས་འཛིན་མ་ཐུབ་པའི་དམིགས་འབེན་བཀོད་སྒྲིག་ཅིག་བརྒལ་ཡོད། ཉར་ཚགས་`protected_worlds`ཡིག་ཆའི་དཔེ་མཚོན་ནང་སྟོང་པ་ གལ་ཏེ་བཀོལ་སྤྱོད་པ་ཞིག་གིས་ས་གནས་ཀྱི་བཀོད་རིས་བེད་སྤྱོད་བྱེད་ན། དེ་དག་གསལ་གཞིའི་པར་རིས་དང་གནད་དོན།

## གཏོང་མཁན་གྱི་འཕྲིན་ཡིག

སྐྱེལ་འདྲེན་བྱས་པའི་དམིགས་བསལ་གྱི་ཞབས་ཞུའི་སྒྲིག་བཀོད་དེས་མཉམ་སྦྲེལ་བརྡ་ཐོ་ཆུང་ཆུང་དང་ཉིན་རེའི་ཐིག་ཐུང་ཐུང་ཞིག་བཟོ་ཐུབ། དེས་སྤྲོད་ཐེངས་དང་པོའི་སྔོན་ལ་སྐར་ཆ་ ༣༠ སྒུག་དགོས། སྐར་ཆ་ ༡༥ རེ་ལ་རྩེད་འགྲན་པ་གསར་པ་མཉམ་ཞུགས་ཡོད་མེད་བརྟག་དཔྱད་བྱེད་དགོས།

| སྒྲིག་སྟངས། | བསྐུར་བའི་རིན་ཐང་། |
|---|---:|
| `player_message.enabled` | `true` |
| `player_message.log_on_startup` | `true` |
| `player_message.register_console_command` | `false` |
| `player_message.console_command` | `randomday` |
| `player_message.broadcast_enabled` | `true` |
| `player_message.startup_delay_ms` | `30000` |
| `player_message.join_check_interval_ms` | `15000` |
| `player_message.send_daily_joke_after_join` | `true` |
| `player_message.daily_joke_delay_seconds` | `10` |
| `player_message.criticality_join` | `2` |
| `player_message.criticality_joke` | `0` |
| `player_message.max_line_chars` | `42` |
| `player_message.max_join_lines` | `4` |
| `player_message.max_warning_lines` | `3` |
| `player_message.max_note_lines` | `3` |

འཕྲིན་ཡིག་རིང་ཚད་བདེན་དཔང་གིས་ཐོན་ཁུངས་ཚད་གཞི་ཞིབ་བཤེར་བྱེད། དེས་ཚོང་ཤག་གི་ཐག་གཅོད་ཚང་མའི་ཐོག་ལ་མཐོང་ཐོས་ཚོད་ལྟའི་ཚབ་བྱེད་ཀྱི་མེད།

དུས་ཚོད་ཀྱི་རིན་ཐང་ནི་ `daily_joke_delay_seconds`. བརྡ་འཕྲིན་ཡང་ན་རྒྱང་བསྒྲགས་སྒྲིག་སྟངས་ནུས་མེད་ཀྱིས་བྱེ་སྒམ་གྱི་གྲ་སྒྲིག་ལ་འགྱུར་བ་མ་བཏང་བར་ཚོང་ཤག་གི་བརྡ་ཐོ་བཀག་འགོག་བྱེད། མཐུན་སྒྲིལ་བཀའ་ཚིག་དེ་སྒྲིག་སྟངས་དང་ UE4SS འཛིན་སྐྱོང་བྱེད་མཁན་ཡོད། མིང་བཏགས་པའི་ཚོང་ཤག་ཚོད་ལྟས་རིན་ཐང་གཞན་ཞིག་བདེན་དཔང་མ་བྱས་ན་གལ་ཆེའི་རིན་ཐང་དེ་སྐྱེལ་འདྲེན་གྱི་གནས་ཚད་ལ་འཇོག་དགོས།

`max_line_chars` སྐད་སྒྱུར་པས་ཡིག་འབྲུ་ ༨ ནས་ ༦༤ བར་བཀག་ཡོད། གྲལ་ཐིག་གྲངས་འབོར་གྱི་སྒྲིག་སྟངས་གསུམ་གྱིས་གོ་རིམ་བཞིན་མཉམ་སྦྲེལ་དང་ཉེན་བརྡ་དང་དྲན་ཐོའི་ཐོན་འབྲས་ལ་ཚད་བཀག་བྱེད། བཏང་བའི་རིན་ཐང་དེ་ཚོ་ཐོན་ཁུངས་གྲལ་ཐིག་ཡོད་པའི་གྲངས་དང་མཐུན་པ་རེད། མཁོ་སྤྲོད་བྱེད་མཁན་གྱི་སྒྲིག་བཀོད་ཚོད་ལྟ་གྱིས་སྒྲིག་བཀོད་དོག་པོ་ཞིག་བདེན་དཔང་མ་བྱས་ན་ཚད་གཞི་བཞི་པོ་དེ་དག་སྔོན་སྒྲིག་ལྟར་ཉར་དགོས།

བརྡ་འཕྲིན་ལྕོགས་མིན་བཟོས་པའི་དཔེ།:

