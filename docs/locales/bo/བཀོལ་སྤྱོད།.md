# ཤུགས་ལྡན་དང་གྲ་སྒྲིག་དང་སླར་གསོའི་གནས་སྟངས་བཀོལ་སྤྱོད་བྱེད།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [OPERATIONS.md](../../OPERATIONS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


RandomDay མ་འོངས་པའི་འགོ་འཛུགས་ཆེད་དུ་བྱེ་སྒམ་གྱི་ཡིག་ཆ་བསྒྱུར་བཅོས་བྱེད། འདིས་གཡོག་བཞིན་པའི་ཨ་བྷི་ཡོ་ཊིག་རྒྱུ་རྐྱེན་ལས་རིམ་ནང་མངོན་ཟིན་བྱས་པའི་ཁྲིམས་ལུགས་བསྒྱུར་བཅོས་མི་བྱེད།

RandomDay སྤུན་མཆེད་ཡིག་ཆའི་ནང་བཱའིཊི་གསར་པ་གྲ་སྒྲིག་བྱེད་པ་དང་དེ་དག་ལོག་ཀློག་པ་དང་བྱེ་མའི་སྒམ་ཆ་ཚང་བདེན་དཔང་བྱེད་པ་དང་ཡིག་ཆ་གསར་པ་དེ་ཡོད་པའི་སྐབས་ཐོག་མ་དེ་ཉར་ཚགས་བྱེད་པ་དང་ཡིག་ཆ་གསར་པ་དེ་ཁྱབ་སྤེལ་བྱེད་པ་དང་ཡང་བསྐྱར་ཀློག་པ་ ཐོན་སྐྱེད་བསྐྱར་ཀློག་མོས་མཐུན་བྱུང་རྗེས་གཞི་ནས་གྲ་སྒྲིག་ཡིན་པའི་སྙན་ཞུ་འབུལ་དགོས།

གལ་ཏེ་ཁྱབ་བསྒྲགས་ཡང་ན་ཐོན་སྐྱེད་བདེན་དཔང་འཐུས་ཤོར་བྱུང་ཚེ།RandomDay བཀོལ་སྤྱོད་དེས་འཛིན་པའི་ཡིག་ཆ་སླར་གསོ་བྱེད་པར་འབད་བརྩོན་བྱེད། སླར་གསོ་འཐུས་ཤོར་ནི་བཀག་འགོག་དཀའ་པོ་ཞིག་ཡིན། སར་བར་བཀག་ནས་ལག་ཐོག་ནས་སླར་གསོ་བྱེད་དགོས།

## མཐུན་འགྱུར་གྱི་མཇུག་འབྲས་ལ་ལན་འདེབས་བྱེད།

བེད་སྤྱོད།[རྒྱབ་སྐྱོར་བྱེད་པའི་བསྒྱུར་ཆས།](%E0%BD%A2%E0%BE%92%E0%BE%B1%E0%BD%96%E0%BC%8B%E0%BD%A6%E0%BE%90%E0%BE%B1%E0%BD%BC%E0%BD%A2%E0%BC%8B%E0%BD%96%E0%BE%B1%E0%BD%BA%E0%BD%91%E0%BC%8B%E0%BD%94%E0%BD%A0%E0%BD%B2%E0%BC%8B%E0%BD%96%E0%BD%A6%E0%BE%92%E0%BE%B1%E0%BD%B4%E0%BD%A2%E0%BC%8B%E0%BD%86%E0%BD%A6%E0%BC%8D.md#read-an-adapter-result) ཁྲིམས་མཐུན་གནས་སྟངས་དྲུག་གི་གྲུབ་འབྲས་ཐིག་ཁྲམ་དང་བྱ་སྤྱོད་རྗེས་མའི་ཆེད་དུ། སྨན་བཅོས་ `rollback_failed` བཀག་སྡོམ་དམ་པོ་ལྟར། སོ་སོར་ཐོ་འགོད་བྱས་པའི་མཐུད་ཆས་རྒྱབ་སྣོན་ནི་སླར་གསོའི་འབྱུང་ཁུངས་ཡིན།

བསྒྱུར་ཆས་ཀྱིས་སོ་སོར་སྒྲིག་འཇུག་བྱས་པའི་མོ་ཌི་ཁོ་ནར་ཤུགས་རྐྱེན་ཐེབས་ཡོད། ཁོང་ཚོས་གྲ་སྒྲིག་བྱས་པའི་RandomDay བྱེ་སྒམ་གྱི་གསལ་སྡུད་ཤུགས་ལྡན་ཡིན།

སྤྱིར་བཏང་གི་འགོ་འཛུགས་སྐབས་མཉམ་སྦྲེལ་གྱི་རིན་ཐང་དེ་ཤུགས་ལྡན་གྱི་གསལ་སྡུད་ནས་འདེམས་སྒྲུག་བྱས་ཡོད།UE4SS འགོ་འཛུགས། འགོ་འཛུགས་ཐོག་མའི་སྐབས། ཤུགས་ལྡན་མེད་པའི་སྐབས་RandomDay རྟགས་ཡོད་ན། གྲ་སྒྲིག་བྱས་པའི་འགོ་འཛུགས་ཉིན་མོའི་གསལ་སྡུད་དེ་ས་ཁྲ་བཟོ་ཐུབ་པའི་ས་ཁྲ་གཅིག་པུ་དེ་རེད། དུས་ཚོད་ཀྱི་ཁྲིམས་ལུགས་འདི་རྗེས་མའི་བསྐྱར་འགོ་འཛུགས་བྱེ་སྒམ་གྱི་མཚམས་ཐིག་ལས་ཐ་དད་ཡིན་པ་དང་ད་དུང་ཡང་མོ་ཌི་གཞན་པའི་རང་ཉིད་ཀྱི་མངོན་པའི་སྤྱོད་ཚུལ་ལ་རག་སླེབས་ཀྱི་ཡོད།
