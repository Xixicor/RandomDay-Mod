> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [START_HERE.md](../../START_HERE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ལམ་སྟོན་འདི་RandomDay སྒྲིག་འཇུག་བྱས་ཡོད། དེས་མོ་ཌི་ཡིས་གང་བསྒྱུར་བ་དང་། དེས་གང་གཅིག་པུར་བཞག་པ། དེ་བཞིན་གྲུབ་འབྲས་ལྡན་པའི་འཁོར་ཡུན་གཅིག་ངོས་འཛིན་བྱེད་སྟངས་སྟོན་གྱི་ཡོད།

<a id="know-the-two-states"></a>
## གནས་སྟངས་གཉིས་ཤེས་དགོས།

ཨ་བྷི་ཡོ་ཊིག་ཆ་རྐྱེན་གྱིས་འཛམ་གླིང་གི་བྱེ་སྒམ་གྱི་སྒྲིག་སྟངས་སྔོན་RandomDay འགོ་བཙུགས། RandomDay དེར་བརྟེན་མིང་གསལ་པོ་ཡོད་པའི་གནས་སྟངས་གཉིས་ཉར་ཚགས་བྱེད།

- **ཤུགས་ལྡན་གྱི་གསལ་སྡུད་:** ད་ལྟའི་ལས་རིམ་གྱིས་བེད་སྤྱོད་བྱེད་བཞིན་པའི་སྒྲིག་གཞི།
- **གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད།:** འགོ་འཛུགས་རྗེས་མའི་ཆེད་དུ་ཉར་ཚགས་བྱས་པའི་སྒྲིག་གཞི།

གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་ཀྱིས་ད་ལྟ་འགྲོ་བཞིན་པའི་ལས་རིམ་ལ་འགྱུར་བ་གཏོང་གི་མེད།

<a id="dedicated-server-prepare-the-next-profile"></a>
## དམིགས་བསལ་གྱི་སར་བར: གསལ་སྡུད་རྗེས་མ་གྲ་སྒྲིག་བྱེད།

1. སར་བར་རྒྱུན་གཏན་ལྟར་འགོ་འཛུགས།
2. སྒུག་དགོས།RandomDay དེའི་འགོ་འཛུགས་ལས་ཀ་མཇུག་སྒྲིལ་ཆེད།
3. ཁ་ཕྱེ།`RandomDay/web_export/today.html` སྒྲིག་འཇུག་བྱས་པའི་མོ་ཌི་སྣོད་ཐོའི་ནང་།
4. འཚོལ་བ་ **ཤུགས་ལྡན་གྱི་གསལ་སྡུད་** དང་ **གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་**.

མཐར་ཕྱིན་པའི་འགོ་འཛུགས་ཐོག་མ་ཐོག་ཤོག་ངོས་དེས་སྔོན་ནས་ཤུགས་ལྡན་ཡིན་པའི་སྒྲིག་གཞི་དང་འགོ་འཛུགས་རྗེས་མར་སྒུག་པའི་གསལ་སྡུད་གཞན་ཞིག་ལ་མིང་བཏགས་དགོས། ཤོག་ངོས་འདིས་འདེམས་སྒྲུག་བྱས་པའི་ཁྱིམ་ཚང་དང་གནས་བབ་དང་གྲ་སྒྲིག་བྱས་པའི་ཡིག་ཆ་དེ་བདེ་འཇགས་ཞིབ་བཤེར་ལས་བརྒལ་ཡོད་མེད་ཀྱང་འགྲེལ་བཤད་རྒྱག་ཡོད།

གནས་སྟངས་བསྒྱུར་བཅོས་གཏོང་ཆེད་དུ་བསྐྱར་དུ་འགོ་འཛུགས་མ་བྱེད། འཆར་གཞི་ཡོད་པའི་སར་བར་རྗེས་མ་འགོ་མ་བཙུགས་བར་དུ་ཁྲིམས་ལུགས་ཤུགས་ལྡན་དེ་རྩེད་མོ་རྩེ་བཞིན་ཡོད།

<a id="dedicated-server-activate-it-later"></a>
## དམིགས་སུ་བཀར་བའི་སར་བར: དེ་རྗེས་སུ་ཤུགས་སྣོན་རྒྱག

1. འཆར་གཞི་རྗེས་མའི་བསྐྱར་འགོ་འཛུགས་སྐབས་སར་བར་བཀག་ནས་འགོ་འཛུགས།
2. ཀློག་ཆོག་པའི་གནས་ཚུལ་ཤོག་ངོས་སླར་ཡང་ཁ་ཕྱེ།
3. སྔོན་ནས་གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་དེ་ད་ལྟ་ཤུགས་ལྡན་དུ་ཐོ་འགོད་བྱས་ཡོད་པར་གཏན་འཁེལ་བྱེད།
4. དེ་གཏན་འཁེལ་བྱོས།RandomDay གཤམ་གྱི་གསལ་སྡུད་གྲ་སྒྲིག་བྱས།

གྲ་སྒྲིག་དང་དེ་ནས་ཤུགས་སྣོན་གཏོང་བའི་འགྱུར་ལྡོག་དེ་ཆ་ཚང་ཞིག་རེད། RandomDay འཁོར་རིམ།

## གནས་སྐབས་ཀྱི་དམིགས་བསལ་ཞབས་ཞུ།

གནས་སྐབས་སྤྱོད་ལམ་གྱིས་དམིགས་བསལ་གྱི་ཞབས་ཞུའི་ཐུམ་སྒྲིལ་གཅིག་པ་བེད་སྤྱོད་བྱེད། [སྒྲིག་བཀོད།](%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%96%E0%BD%80%E0%BD%BC%E0%BD%91%E0%BC%8D.md), དམིགས་བསལ་གྱི་གསལ་སྡུད་སྟེང་རྒྱུག་ཤར་གསར་པ་འགོ་འཛུགས་མིན་ཡང་ན་གང་བྱུང་འགོ་འཛུགས་ས་ཚིགས་འདེམས་པ། གནས་ཚད་ཤོག་ངོས་དེས་ད་དུང་ཡང་ཤུགས་ལྡན་གྱི་གསལ་སྡུད་དེ་འགོ་འཛུགས་རྗེས་མའི་ཆེད་དུ་གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་ལས་དབྱེ་འབྱེད་བྱེད་ཀྱི་ཡོད།

## རྩེད་མོ་རྐྱང་པའམ་ཡང་ན་LAN

1. རྩེད་མོ་དེ་ singleplayer/LANཐུམ་སྒྲིལ་སྒྲིག་འཇུག་བྱས།
2. རྗེས་སུ་རྩེད་མོ་ཡོངས་སུ་ཁ་རྒྱག RandomDay མཇུག་སྒྲིལ།
3. བཟོས་པའི་སྙིང་བསྡུས་ཀློག
4. བཟོས་པ་འདྲ་བཤུས།`SandboxSettings.ini` རྩེད་མོ་ཁ་རྒྱག་སྐབས་ཁྱེད་ཀྱིས་འདེམས་པའི་འཛམ་གླིང་ནང་དུ།
5. འཇིག་རྟེན་དེ་འགོ་བཙུགས་ནས་རེ་བ་བྱེད་པའི་སྒྲིག་གཞི་གཏན་འཁེལ་བྱས།

ས་གནས་ཀྱི་ཐུམ་སྒྲིལ་གྱིས་ནམ་ཡང་འཛམ་གླིང་ཞིག་འདེམས་པའམ་ཡིག་ཆ་དེ་རང་ཉིད་ཀྱིས་ཉར་ཚགས་ནང་འདྲ་བཤུས་མི་བྱེད། [རྩེད་མོ་རྐྱང་པ་དངLAN](%E0%BD%A2%E0%BE%A9%E0%BD%BA%E0%BD%91%E0%BC%8B%E0%BD%98%E0%BD%BC%E0%BC%8B%E0%BD%A2%E0%BE%90%E0%BE%B1%E0%BD%84%E0%BC%8B%E0%BD%94%E0%BD%A0%E0%BD%B2%E0%BC%8B%E0%BD%A3%E0%BD%93%E0%BC%8B.md) བྱ་ཐབས་ཆ་ཚང་ཆེད་དུ།

བསྐྱར་དུ་འགོ་འཛུགས་མི་བྱེད། ད་ལྟའི་ཡིག་ཆ་རྣམས་ཉར་ཚགས་བྱས་ནས་ [སྐྱོན་སེལ་ཐབས།](%E0%BD%A6%E0%BE%90%E0%BE%B1%E0%BD%BC%E0%BD%93%E0%BC%8B%E0%BD%A6%E0%BD%BA%E0%BD%A3%E0%BC%8B%E0%BD%90%E0%BD%96%E0%BD%A6%E0%BC%8D.md). སྤྱིར་བཏང་གི་གྲུབ་འབྲས་ཀྱིས་རྟག་ཏུ་ཤུགས་ལྡན་གྱི་གསལ་སྡུད་དང་གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་ཡང་ན་གྲ་སྒྲིག་བྱས་པའི་འཐུས་ཤོར་གསལ་པོ་གཅིག་ལ་མིང་བཏགས་ཡོད།
