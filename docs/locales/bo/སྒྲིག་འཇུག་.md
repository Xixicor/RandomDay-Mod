# སྒྲིག་འཇུག་དང་གསར་བཅོས་ཡང་ན་མེད་པར་བཟོ་ RandomDay

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [INSTALL.md](../../../INSTALL.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


RandomDay ཕབ་ལེན་ཆ་ཚང་གཉིས་ཡོད། ཁྱེད་ཀྱིས་སྒྲིག་འཛུགས་བྱེད་བཞིན་པའི་འཛམ་གླིང་ལ་གཅིག་འདེམས།

- བེད་སྤྱོད།**དམིགས་བསལ་གྱི་ཞབས་ཞུ། ZIP** དམིགས་བསལ་སར་བར་གང་རུང་ཞིག་གི་ཆེད་དུ། དེའི་ནང་སྐབས་སྐབས་ཀྱི་ལས་རིམ་ཁོ་ནའི་ཆེད་དུ་ཁ་ཕྱེ་བའི་སར་བར་ཡང་ཚུད་ཡོད།
- བེད་སྤྱོད།**singleplayer/LAN ZIP** ས་གནས་ཀྱི་འཛམ་གླིང་ཞིག་གི་ཆེད་དུ། དེའི་སྒྲིག་སྟངས་ཁྱེད་ཀྱིས་ལག་ཐོག་ནས་འདྲ་བཤུས་བྱེད།

ཐུམ་སྒྲིལ་མཉམ་སྡེབ་མ་བྱེད། རྟག་བརྟན་ཡང་ན་གནས་སྐབས་ཀྱི་དམིགས་བསལ་སར་བར་ནི་ RandomDay'sསྒྲིག་སྟངས་ལས་ཕབ་ལེན་མི་འདྲ་བ་མ་རེད།

### རྟག་ཏུ་ཁ་ཕྱེ་བའམ་གནས་སྐབས་ཀྱི་བྱ་སྤྱོད་འདེམས།

དམིགས་བསལ་གྱི་ཞབས་ཞུའི་ཐུམ་སྒྲིལ་གྱིས་བཟོ་ལྟ་གཉིས་ཀར་རྒྱབ་སྐྱོར་བྱེད།

- **རྟག་ཏུ་དམིགས་པ།** སྤྱིར་བཏང་གི་བསྐྱར་འགོ་འཛུགས་སྐབས་ཉར་ཚགས་བྱས་པའི་འཁོར་སྐྱོད་བསྐྱར་འགོ་ཚུགས།
- **གནས་སྐབས་སུ་དམིགས་པ།** གནས་སྐབས་བཀོལ་སྤྱོད་གསར་པ་འགོ་འཛུགས་སྐབས་རིམ་སྒྲིག་བྱས་པའམ་ཡང་ན་གང་བྱུང་འགོ་འཛུགས་ས་ཚིགས་ནས་འགོ་འཛུགས་ཐུབ།

[སྒྲིག་བཀོད།](%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%96%E0%BD%80%E0%BD%BC%E0%BD%91%E0%BC%8D.md). སྒྲིག་སྟངས་འདི་བརྗེ་སྒྱུར་བྱེད་པར་ཐུམ་སྒྲིལ་གཉིས་པ་སྒྲིག་འཇུག་མི་བྱེད།

### ད་ཡོད་ཀྱི་སྒྲིག་འཇུག་ཅིག་གསར་བཅོས་བྱེད།

1. སར་བར་བཀག་ནས་གོང་དུ་ཐོ་འགོད་བྱས་པའི་རྒྱབ་ལྗོངས་བཟོས།
2. རྙིང་པ་སྤོ`RandomDay` སྣོད་ཐོའི་ནང་ནས་UE4SS `Mods` སྣོད་ཐོ། གསར་བརྗེ་དེས་གྲུབ་འབྲས་ལྡན་པའི་འཁོར་ཡུན་གཅིག་མཇུག་སྒྲིལ་བར་དུ་ཉར་དགོས།
3. དམིགས་བསལ་གྱི་ཞབས་ཞུ་གསར་པ་ཕྱིར་འདོན་བྱེད། ZIPདེའི་ནང་དུ།`Mods` སྣོད་ཐོ།
4. ཁྱེད་ཀྱིས་བསམ་བཞིན་དུ་བསྒྱུར་བའི་སྒྲིག་སྟངས་ཁོ་ན་དང་གསར་པའི་ནང་ད་དུང་གནས་ཡོད་པའི་སྒྲིག་སྟངས་ཁོ་ན་ཡང་བསྐྱར་འཇུག་སྤྱོད་བྱེད།[སྒྲིག་བཀོད་ལམ་སྟོན།](%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%96%E0%BD%80%E0%BD%BC%E0%BD%91%E0%BC%8D.md).
5. ཡིག་ཆ་བཟོས་པའི་འཁོར་སྐྱོད་གནས་སྟངས་ཡིག་ཆ་དེ་ཚོ་འགྲེམ་སྤེལ་དྲན་ཐོའི་རྣམ་གཞག་མཐུན་སྒྲིལ་ཡིན་ཟེར་སྐབས་རྐྱངམ་གཅིག་ཉར་དགོས། གནས་སྐབས་ཀྱི་ཐོན་འབྲས་རྙིང་པའམ་ཡང་ན་འབྲི་མ་ཐུབ་པའི་ཡིག་ཆ་རྣམས་གཞི་བཙུགས་གསར་པའི་ནང་དུ་འདྲ་བཤུས་མ་བྱེད།
6. གཏན་འཁེལ་བྱོས།`RandomDay : 1` ད་དུང་ཡང་ལྕོགས་ཅན་ཡིན་ན་སར་བར་ཐེངས་གཅིག་འགོ་འཛུགས་བྱས་ནས་ཤུགས་ལྡན་དང་གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་མིང་ལ་ཞིབ་བཤེར་བྱེད་དགོས།

## མེད་པར་བཟོ་བའམ་མེད་པར་བཟོ་བ།RandomDay

1. རྩེད་མོའམ་སར་བར་བཀག་དགོས།
2. འཛམ་གླིང་དང་དེའི་ད་ལྟའི་བྱེ་སྒམ་གྱི་སྒྲིག་སྟངས་དང་RandomDay's གནས་སྟངས།
3. གཞི་སྒྲིག་`RandomDay : 0` UE4SS `mods.txt` མོ་ཌི་ལྕོགས་མིན་བཟོ་བའམ་ཡང་ན་ཆ་ཚང་སྤོ་བཤུད་བྱེད་པ`RandomDay` སྣོད་ཐོའི་ནང་ནས་`Mods` སྣོད་དེ་མེད་པར་བཟོ་དགོས།
4. གང་ཞིག་ཐག་གཅོད་དགོས།`SandboxSettings.ini` དེ་འགོ་འཛུགས་རྗེས་མར་མངོན་དགོས། གལ་ཏེ་ཁྱེད་ལ་ད་ལྟ་གྲ་སྒྲིག་བྱས་པ་དེ་མི་དགོས་ན་ཁྱེད་ཀྱི་སྔོན་སྒྲིག་འདྲ་བཤུས་སླར་གསོ་བྱོས། RandomDay གསལ་སྡུད།
5. རྒྱབ་ལྗོངས་གང་རུང་ཞིག་མ་བསུབས་གོང་འཛམ་གླིང་འགོ་འཛུགས་བྱས་ནས་དེའི་སྒྲིག་གཞི་གཏན་འཁེལ་བྱེད་དགོས།

4. ཐེངས་གཅིག་འགོ་འཛུགས་ནས་སླར་གསོ་བྱས་པའི་ཤུགས་ལྡན་དང་གྲ་སྒྲིག་བྱས་པའི་གསལ་སྡུད་མིང་གཏན་འཁེལ་བྱེད་དགོས།
