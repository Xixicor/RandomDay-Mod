# ཁྱིམ་ཚང་བཅུ་བདུན། ཉིན་བཅུ་བདུན

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [FAMILY_ROTATION.md](../../FAMILY_ROTATION.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


RandomDay ནང་དུ་རྩེད་མོའི་རྣམ་པའི་ཁྱིམ་ཚང་ ༡༧ ཡོད་ཅིང་། ཁྱིམ་ཚང་རེ་རེའི་ནང་ཉིན་རེའི་གནས་ཚུལ་ཆ་ཚང་ ༡༧ ཡོད། དེས་ཡིག་ཆ289ཐོན་ཡོད། family/day མཉམ་སྡེབ།

ཁྱིམ་ཚང་གིས་རྒྱུག་འགྲན་གྱི་རྒྱ་ཆེ་བའི་བཟོ་རྣམ་སྒྲིག་བཀོད་བྱེད། ཉིན་དང་པོ་ནས་བཅུ་བདུན་བར་ཁྱིམ་ཚང་དེའི་གནོན་ཤུགས་དང་། བསྐྱར་གསོ། གོམ་སྟབས། ཐོན་ཁུངས་བཅས་ཀྱི་ཐད་ལ་ཡར་རྒྱས་འགྲོ་བར་མཁོ་སྤྲོད་བྱེད། རྒྱུག་ཤར་གྱིས་ཉིན་རེའི་IDཡོད་པའི་མངགས་ཉོ་གཅིག་ལ་ཐེངས་གཅིག་གསོག་འཇོག་བྱེད་ཀྱི་ཡོད། བསྐྱར་དུ་འགོ་འཛུགས་བྱེད་པ་དེ་གསོག་འཇོག་བྱས་པའི་གནས་གནས་རྗེས་མར་མདུན་སྐྱོད་བྱེད། RandomDay གོ་རིམ་གྱི་དཀྱིལ་དུ་ཁྱིམ་ཚང་བསྒྱུར་མི་ཐུབ།

| ཐབས་ལམ | བཀོལ་སྤྱོད་གསར་བའི་བྱ་སྤྱོད། | རྒྱུག་པའི་སྐབས། |
|---|---|---|
| `selected_run` | བེད་སྤྱོད།`profile_family.selected_family`. | ཁྱིམ་ཚང་དེ་གསོག་འཇོག་བྱས་པའི་གནས་རིམ་17ཚང་མ་བརྒྱུད་ནས་ཉར་ཚགས་བྱེད། |
| `non_repeating_random_run` | བེད་སྤྱོད་མ་བཏང་བའི་འོས་འཚམ་གྱི་ཁྱིམ་ཚང་འདེམས་པ། | གནས་རིམ་17ཚང་མ་བརྒྱུད་དེ་ཉར་ཚགས་བྱེད་པ་དང་འོས་འཚམ་གྱི་ཐོ་གཞུང་མ་ཚར་བར་དུ་ཁྱིམ་ཚང་བསྐྱར་ལོག་བྱེད་པ་སྔོན་འགོག་བྱེད། |
| `rotation_run` | རིམ་སྒྲིག་བྱས་པའི་གོ་རིམ་ནང་ཁྱིམ་ཚང་རྗེས་མ་ལེན་གྱི་ཡོད། | གསོག་འཇོག་བྱས་པའི་གནས་ 17 ཚང་མ་བརྒྱུད་དེ་ཉར་ཚགས་བྱེད། |

སྐྱེལ་འདྲེན་བྱས་པའི་རིམ་སྒྲིག་གིས་`non_repeating_random_run`. མཐའ་མའི་གསོག་འཇོག་བྱས་པའི་གནས་བབ་རྗེས་སུ་གྲ་སྒྲིག་བྱས་པའི་ཁྱིམ་ཚང་དེ་ད་དུང་གྲ་སྒྲིག་བྱས་ཡོད། བསྐྱར་དུ་འགོ་འཛུགས་རྗེས་ཤུགས་ལྡན་དུ་འགྱུར་བ་རེད། `cycle.start_day_mode` དང་ `cycle.day_progression_mode` ཁྱིམ་ཚང་གི་འདེམས་སྒྲུག་ལ་འགྱུར་བ་མ་བཏང་བར་ཉིན་དང་པོ་དང་ཉིན་གྱི་གོ་རིམ་འདེམས།
