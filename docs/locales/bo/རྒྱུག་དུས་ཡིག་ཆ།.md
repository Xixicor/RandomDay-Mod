# རྒྱུག་དུས་ཀྱི་ཡིག་ཆ་དང་གནས་ཚུལ་འཚོལ་ཞིབ་བྱེད་པ།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [RUNTIME_FILES.md](../../RUNTIME_FILES.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


འདི་ནི་བཀོལ་སྤྱོད་དང་འབྱུང་ཁུངས་རྗེས་འདེད་ཐུབ་ཚད་ཀྱིས་བེད་སྤྱོད་བྱེད་པའི་ཁྲིམས་མཐུན་འགྲོ་ལམ་གྱི་ཐོ་གཞུང་ཡིན། ཡིག་ཆ་གང་དུ་ཡོད་མེད་དང་། སུས་བྲིས་པ། དེ་ག་དུས་འགྱུར་བ་འགྲོ་བ། དུས་ཡུན་ག་ཚོད་རིང་པོ་གནས་པ། དེ[རྒྱུག་དུས་ཀྱི་ཐོན་འབྲས་གཞི་གྲངས།](%E0%BD%A2%E0%BE%92%E0%BE%B1%E0%BD%B4%E0%BD%82%E0%BC%8B%E0%BD%91%E0%BD%B4%E0%BD%A6%E0%BC%8B%E0%BD%80%E0%BE%B1%E0%BD%B2%E0%BC%8B%E0%BD%90%E0%BD%BC%E0%BD%93%E0%BC%8B%E0%BD%A0%E0%BD%96%E0%BE%B2%E0%BD%A6%E0%BC%8B.md) ལ་འཆར་གཞི་དང་ས་སྒོའི་དོན་དག་དང་སྟོང་པའི་གནས་སྟངས་དང་འཕྲུལ་ཆས་ཀྱི་རིན་ཐང་དོན་འགྲེལ་གྱི་བདག་དབང་ཡོད།
