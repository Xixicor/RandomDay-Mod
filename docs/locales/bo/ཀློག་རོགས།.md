# RandomDay བོད་ཡིག་ལམ་སྟོན།

**v0.3.16-alpha**

`SandboxSettings.ini` ཆ་ཚང་ཞིག་གྲ་སྒྲིག་བྱེད། ད་ལྟའི་རྩེད་མོའི་སྒྲིག་སྲོལ་
མི་བསྒྱུར་ཞིང་། ད་ལྟ་སྤྱོད་པ་དང་རྗེས་མའི་གྲ་སྒྲིག་ཟིན་པ་སོ་སོར་སྟོན།

## ཨལ་ཕ་ཐོན་རིམ་དང་རྒྱུན་མཐུད་ཀྱི་གདམ་ག

འདི་ནི་ཨལ་ཕ་ཐོན་རིམ་ཞིག་ཡིན། ཡིག་ཆར་བཀོད་པའི་སྒྲིག་འཇུག་དང་རེས་སྐོར། སླར་གསོའི་ལམ་བུ་ཚོད་ལྟ་བྱས་ཡོད་ཀྱང་མཐུན་འགྱུར་དང་སྤྱོད་བདེ་མུ་མཐུད་ལེགས་བཅོས་བྱེད།

`RandomDay/Scripts/ax_config/server.lua` ནང་གི `sandbox.profile_overrides` ཡིས་རིགས་ཚན་དང་ཉིན་རེར་གྲངས་ཐང་བཞི་པོ་ཉར་ཚགས་བྱེད། ཞབས་ཞུ་མཚམས་འཇོག་བྱས་ཏེ་ཐེངས་གཅིག་བཟོ་བཅོས་བྱས་རྗེས་སླར་འགོ་འཛུགས། `SandboxSettings.ini` ཁོ་ན་བཟོ་བཅོས་བྱས་པ་གནས་སྐབས་ཙམ་ཡིན།
