# ཐུམ་སྒྲིལ་བྱུང་ཁུངས་གཞི་གྲངས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


འགྲེམ་སྤེལ་དེ།ZIP ནང་གཤམ་གྱི་ལམ་ཐིག་ ༥༡ ཏག་ཏག་ཡོད། བཟོ་མཁན་གྱིས་འགྲོ་ལམ་བརླག་པ་དང་། ཐུམ་སྒྲིལ་བཟོ་ལྟའི་ཐོན་ཁུངས་ཁ་སྣོན། གནད་དོན་ཁ་གཏད་གཅོག་པ། རྟགས་མཚན་འབྲེལ་མཐུད། ཡང་ན་དེའི་ཚིག་དོན་གྱི་ཆོག་མཆན་ཐོ་གཞུང་གི་ཕྱི་རོལ་གྱི་འཐུས་མི་ཁས་མི་ལེན། གཡོག་བཀོལ་དུས་ཚོད་ཀྱི་ཐོན་འབྲས་དང་། བརྟག་དཔྱད། མཛོད་ཁང་གི་ཡིག་ཆ་། དེ་བཞིན་ཕྱོགས་གསུམ་པའི་མོ་ཌི་བཅས་ནི་ཐུམ་སྒྲིལ་གྱི་ཁོངས་མི་མིན།

འཕྲུལ་ཆས་ཀྱིས་ཞིབ་བཤེར་བྱེད་ཐུབ་པའི་རོགས་ཟླ་ནི་[`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json). དེས་ནང་འཇུག་དང་། ཐོན་འབྲས། ཟུར་ཕོག་། སྤྱི་དམངས་སྒྲིག་སྟངས། མཐོང་ཐུབ་པའི་གནས་སྟངས། འཐུས་ཤོར་ཐབས་ལམ། རྩོམ་སྒྲིག་བྱེད་ཐུབ་པ། དེ་བཞིན་ཁྲིམས་མཐུན་ཡིག་ཆ་བཅས་དང་ལྷན་དུ་འགྲོ་ལམ་གཅིག་པ་ཐོ་འགོད་བྱེད།

སྐྱེལ་འདྲེན་བྱས་པའི་ལུའུ་གྲལ་རིམ་རེ་རེར་གཏན་འཇགས་གཅིག་རེ་ཡོད། `module-*` གཞི་སྒྲོམ། དེའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས་མགོ་ཡིག་དང་འཕྲུལ་ཆས་ཀྱི་ཐོ་འགོད་ནང་དུ་ཡོད་པའི་འབྲེལ་མཐུད་གཅིག་པ་དེས་བདག་དབང་དང་། གན་རྒྱ། ཟུར་ཕོག་། འཐུས་ཤོར། སླར་གསོ་བཅས་ཐད་ཀར་རྗེས་འདེད་གཏོང་ཐུབ།
