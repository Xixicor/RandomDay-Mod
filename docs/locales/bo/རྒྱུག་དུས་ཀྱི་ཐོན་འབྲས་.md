# རྒྱུག་དུས་གནས་སྟངས་དང་ཐོན་འབྲས་འཆར་གཞི་དོན་འགྲེལ།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


འདི་ནི་ཁྲིམས་མཐུན་ཡིག་དུམ་ཆ་ཚང་རིམ་སྒྲིག་ལམ་སྟོན་ཡིན། དེས་ས་ཁོངས་རེ་རེ་དང་། གནས་སྟངས། རིན་ཐང་སྟོང་པ། འཕྲུལ་ཆས་ཀྱི་གྲུབ་འབྲས་བཅས་ལ་ལན་འདེབས་བྱེད། [རྒྱུག་དུས་ཡིག་ཆའི་ས་ཁྲ་](%E0%BD%A2%E0%BE%92%E0%BE%B1%E0%BD%B4%E0%BD%82%E0%BC%8B%E0%BD%91%E0%BD%B4%E0%BD%A6%E0%BC%8B%E0%BD%A1%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%86%E0%BC%8D.md) ཐོན་སྐྱེད་བྱེད་མཁན་དང་། ལམ་ཐིག འབྲི་བའི་དུས་ཚོད། བཀག་སྡོམ། ཚོང་དོན་གྱི་ཟུར་འཁོར་དང་སླར་གསོའི་གནས་ཡུལ་བཅས་ལ།

ལམ་སྟོན་འདིའི་ནང་གི་འགྲོ་ལམ་ཚང་མ་སྒྲིག་འཇུག་བྱས་པའི་`RandomDay/` སྣོད་ཐོ། གྲལ་ཐིག་ཅིག་གིས་རིམ་སྒྲིག་བྱས་པའི་བྱེ་སྒམ་ཡང་ན་འདམ་ཀའི་མཐུན་སྒྲིལ་དམིགས་འབེན་ལ་མིང་གསལ་པོ་མ་བཏགས་པ་མ་གཏོགས། གཡོག་བཀོལ་དུས་ཚོད་ཀྱི་ཐོན་འབྲས་དེ་སྒྲིག་འཇུག་བྱས་རྗེས་བཟོས་པ་དང་དེ་གཉིས་ཀ་འགྲེམ་སྤེལ་གང་རུང་གི་ཚོགས་མི་མིན། ZIP.
