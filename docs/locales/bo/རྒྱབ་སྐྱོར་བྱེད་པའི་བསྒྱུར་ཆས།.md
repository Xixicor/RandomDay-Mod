## ངོས་འཛིན་གྱིས་མོ་ཌི་གཞན་ཞིག་ལ་སྲུང་སྐྱོབ་བྱེད་སྟངས།

རྒྱུས་མངའ་ཡོད་པའི་ཡིག་ཆའི་མིང་འཚོལ་བ་ཙམ་གྱིས་མི་འགྲིག RandomDay གིས་དམིགས་འབེན་ཡིག་ཆའི་ནང་དུ་མཐུད་ཆས་དེ་ལ་དགོས་མཁོའི་སྒྲིག་སྟངས་ཚང་མ་ཡོད་མེད་བརྟག་དཔྱད་བྱེད། དེས་ད་ཡོད་ཀྱི་ལས་འགན་ཁོ་ན་ལ་བཅོས་སྒྲིག་བྱེད། དེས་ནམ་ཡང་བརླག་པའི་སྒྲིག་བཀོད་གསར་གཏོད་བྱེད་ཀྱི་མེད།

ངོས་འཛིན་བྱས་པའི་བཀོད་སྒྲིག་ཅིག་གི་ཆེད་དུ།RandomDay གིས་མཚམས་ཐིག་ཅན་གྱི་ཚོང་དོན་གཅིག་སྒྲུབ་པ་:

1. ཤུགས་ལྡན་གསལ་སྡུད་ཀྱི་དམིགས་ཡུལ་གྱི་རིན་ཐང་རེ་རེ་རྩིས་རྒྱག;
2. དམིགས་འབེན་ཡིག་ཆ་རེ་རེའི་རྒྱབ་ལྗོངས་གསར་བཟོ་དང་བཱའིཊི་ཞིབ་བཤེར་བྱེད།
3. སྤུན་མཆེད་སྒུག་པའི་ཡིག་ཆ་བརྒྱུད་ནས་བྲིས།
4. སྒུག་བཞིན་པའི་ཡིག་ཆ་དེ་སྐུལ་འདེད་གཏོང་བ་དང་ཉར་ཚགས་བྱས་པའི་བཱའིཊི་དེ་ཕྱིར་ཀློག ;
5. དམིགས་ཡུལ་གྱི་རིན་ཐང་རེ་རེ་བཞིན་གཏན་འཁེལ་བྱེད།
6. གལ་ཏེ་གོམ་པ་གང་རུང་ཞིག་འཐུས་ཤོར་ཕྱིན་ན་བདེན་དཔང་བྱས་པའི་རྒྱབ་ལྗོངས་ནས་རང་འགུལ་སླར་གསོ་བེད་སྤྱོད་བྱེད།

## རྒྱབ་ལྗོངས་དང་ལག་ཐོག་སླར་གསོ

བདེན་དཔང་བྱས་པའི་སྔོན་འབྲི་འདྲ་བཤུས་རྣམས་འོག་ཏུ་ཉར་ཚགས་བྱས་ཡོད།

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

གལ་ཏེ`rollback_failed` འབྱུང་བ་:

1. རྩེད་མོའམ་སར་བར་བཀག་དགོས།
2. ཆ་སྒྲིག་`external_mods.enabled = false`, ཡང་ན་ཤུགས་རྐྱེན་ཐེབས་པའི་མཉམ་སྦྲེལ་ID མེད་པར་བཟོས།
3. མིག་སྔའི་དམིགས་འབེན་ཡིག་ཆ་དང་དེའི་སྤུན་མཆེད་ཉར་ཚགས་བྱེད།pending/rollbackཡིག་ཆ།
4. ཨང་གྲངས་ཡོད་པའི་རྒྱབ་ལྗོངས་ཡིག་ཆ་དེ་མཐུན་སྒྲིག་གྲུབ་འབྲས་ནང་ཐོ་འགོད་བྱས་པའི་དམིགས་འབེན་ལམ་ཐིག་ལ་མཐུན་སྒྲིག་བྱེད།
5. ཞབས་ཞུ་བཀག་པའི་སྐབས་བདེན་དཔང་བྱས་པའི་བཱའིཊི་སླར་གསོ་བྱེད།
6. གདམ་གའི་མོ་ཌི་དེ་བསྐྱར་དུ་ལྕོགས་ཅན་མ་བཟོ་བའི་སྔོན་ལ་རང་ཉིད་ཀྱིས་འགོ་འཛུགས་དགོས། RandomDay མཐུད་ཆས།

སྒྲིག་སྟངས་མིང་བསྒྱུར་བའམ་ཡང་ན་བརླག་པའི་ལྡེ་མིག་ཁ་སྣོན་བྱས་ནས་མཐུན་སྒྲིལ་བཙན་ཤེད་མ་བྱེད། ངོས་འཛིན་བྱས་པའི་བཀོད་སྒྲིག་བེད་སྤྱོད་བྱེད་པ་དང་། མཐུན་སྒྲིལ་བྱེད་མཁན་དེ་ལྕོགས་མིན་དུ་བཞག་པ། ཡང་ན་རྒྱབ་སྐྱོར་ཐོབ་ཐང་རྒྱ་བསྐྱེད་མ་བྱེད་གོང་ཐོན་རིམ་གསར་པ་སྒྲིག་ཆས་དང་ཚོང་དོན་ཚོད་ལྟ་ཁ་སྣོན་བྱེད།
