# RandomDay belgeler

> **Kanonik İngilizce kaynağı:** [README.md](../../README.md). Bu yerelleştirilmiş belgeler tam komutları, yolları, anahtarları, durum değerlerini, karmaları ve dosya adlarını korur. Teknik ifadeler farklıysa İngilizce kaynağı kullanın.
