# Güvenlik politikası

> **Kanonik İngilizce kaynağı:** [SECURITY.md](../../../SECURITY.md). Bu yerelleştirilmiş belgeler tam komutları, yolları, anahtarları, durum değerlerini, karmaları ve dosya adlarını korur. Teknik ifadeler farklıysa İngilizce kaynağı kullanın.


RandomDay sunucu yapılandırma dosyalarını yazar ve isteğe bağlı mod yapılandırma dosyalarını yamalayabilir. Değişiklikleri operasyonel açıdan hassas olarak değerlendirin.

<a id="do-not-report-as-security-issues"></a>
## Güvenlik sorunu olarak bildirme

- Normal oyun dengesi değişiklikleri.
- Bir sonraki yeniden başlatmada profil rotasyonu bekleniyor.

<a id="report-privately"></a>
## Gizli olarak raporlayın

- Yol geçiş riskleri.
- Güvenli olmayan dosya yazma davranışı.
- İstenen dışında dosyaların üzerine yazabilme yeteneği server/mod yollar.
- Kötü amaçlı komut yürütme.

Bir kamu güvenlik kanalı mevcut olana kadar veri deposu sahibine özel olarak rapor verin.
