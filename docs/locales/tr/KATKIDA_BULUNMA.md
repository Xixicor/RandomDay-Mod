# Katkıda bulunma

> **Kanonik İngilizce kaynağı:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Bu yerelleştirilmiş belgeler tam komutları, yolları, anahtarları, durum değerlerini, karmaları ve dosya adlarını korur. Teknik ifadeler farklıysa İngilizce kaynağı kullanın.


RandomDay kontrollü olarak korunur projesi.

Genel çekme istekleri, istenmeyen kod gönderimleri, otomatik yeniden yazmalar, oluşturulan kod temizleme gönderimleri ve spekülatif özellik yamaları, depo sahibi tarafından açıkça talep edilmediği sürece kabul edilmez.

<a id="accepted-contact"></a>
## Kabul edilen iletişim

Hata raporları, uyumluluk notları veya sunucu yönetimi gözlemleri için proje belgelerinde listelenen iletişim kanallarını kullanın.

<a id="not-accepted"></a>
## Kabul edilmez

Aşağıdakiler varsayılan olarak kabul edilmez:

- istenmeyen çekme istekleri;
- oluşturulan kod yeniden yazmaları;
- geniş yeniden düzenleme;
- yalnızca stil biçimlendirme değişiklikleri;
- denenmemiş oyun mantığı değişiklikleri;
- paketlenmiş üçüncü taraf mod dosyaları;
- yeniden dağıtılmış üçüncü taraf kaynak kodu;
- Abiyotik Faktörü, UE4SS, Nexus Modları veya üçüncü taraf mod yazarlarıyla resmi ilişkisi olduğunu ima eden değişiklikler.

<a id="controlled-development"></a>
## Kontrollü geliştirme

Depo sahibi, gerektiğinde belirli inceleme, test veya dokümantasyon yardımı talep edebilir. İstenmeyen gönderimler incelenmeden kapatılabilir.
