# Contribuyente

> **Fuente canónica en inglés:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Esta documentación localizada conserva comandos, rutas, claves, valores de estado, hashes y nombres de archivos exactos. Si la redacción técnica difiere, utilice la fuente en inglés.


RandomDay se mantiene como un sistema controlado proyecto.

No se aceptan solicitudes de extracción públicas, envíos de código no solicitados, reescrituras automatizadas, envíos de limpieza de código generado y parches de características especulativas a menos que lo solicite explícitamente el propietario del repositorio.

<a id="accepted-contact"></a>
## Aceptado contacto

Para informes de errores, notas de compatibilidad u observaciones de administración del servidor, utilice los canales de contacto enumerados en la documentación del proyecto.

<a id="not-accepted"></a>
## No aceptado

Lo siguiente no se acepta de forma predeterminada:

- solicitudes de extracción no solicitadas;
- código generado reescrituras;
- refactorizaciones amplias;
- cambios de formato solo de estilo;
- cambios en la lógica del juego no probados;
- archivos mod de terceros incluidos;
- código fuente de terceros redistribuido;
- cambios que implican afiliación oficial con Abiotic Factor, UE4SS, Nexus Mods o autores de mods de terceros.

<a id="controlled-development"></a>
## Desarrollo controlado

El propietario del repositorio puede solicitar ayuda específica para revisiones, pruebas o documentación cuando sea necesario. Los envíos no solicitados se pueden cerrar sin revisión.
