## v0.3.16-alpha

- Se agregaron dos paquetes completos: uno para servidores dedicados y otro para un jugador o LAN mundos.
- Se agregaron modos de servidor dedicado persistente y temporal, perfiles iniciales configurables y progresión aleatoria secuencial o no repetitiva.
- Se amplió la biblioteca a diecisiete familias de perfiles con diecisiete perfiles en cada una. familia.
- Se agregó estado de perfil legible active/prepared, avisos de reproductor compacto, escrituras seguras en sandbox, copias de seguridad verificadas, lectura y reversión.
- Se agregaron adaptadores opcionales con diseño verificado para modificaciones complementarias compatibles.
- Se agregaron controles persistentes en todo el perfil para el Modo Duro, Modo Hierro, soporte estructural y soporte de puente en la configuración del servidor público.
- Se agregó una biblioteca de guías completa en inglés y 27 páginas de entrada localizadas.
- Validó los paquetes de lanzamiento como diseños limpios, deterministas y con seguridad entre mayúsculas y minúsculas UE4SS sin configuración privada ni datos de tiempo de ejecución.
