# Política de seguridad

> **Fuente canónica en inglés:** [SECURITY.md](../../../SECURITY.md). Esta documentación localizada conserva comandos, rutas, claves, valores de estado, hashes y nombres de archivos exactos. Si la redacción técnica difiere, utilice la fuente en inglés.


RandomDay escribe archivos de configuración del servidor y puede parchear archivos de configuración de mod opcionales. Trate los cambios como operacionalmente sensibles.

<a id="do-not-report-as-security-issues"></a>
## No informar como problemas de seguridad

- Cambios en el equilibrio normal del juego.
- Rotación de perfil prevista para el próximo reinicio.

<a id="report-privately"></a>
## Informar de forma privada

- Riesgos al atravesar el camino.
- Comportamiento de escritura de archivos no seguro.
- Capacidad de sobrescribir archivos fuera de lo previsto server/mod rutas.
- Ejecución de comando malicioso.

Hasta que exista un canal de seguridad público, informe de forma privada al propietario del repositorio.
