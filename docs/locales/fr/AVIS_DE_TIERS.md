# Avis de tiers

> **Source canonique en anglais:** [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). Cette documentation localisée conserve les commandes, chemins, clés, valeurs d'état, hachages et noms de fichiers exacts. Si la formulation technique diffère, utilisez la source anglaise. Cette traduction est informative ; le texte juridique anglais contrôle.


RandomDay est un mod communautaire indépendant pour Abiotic Factor et UE4SS.

Les adaptateurs facultatifs peuvent mettre à jour les configurations reconnues appartenant à des mods installés séparément. Ces mods ne sont pas inclus, copiés ou redistribués avec RandomDay. Leurs noms restent la propriété de leurs auteurs respectifs.

Voir `docs/SUPPORTED_ADAPTERS.md` pour les configurations exactes actuellement reconnues.
