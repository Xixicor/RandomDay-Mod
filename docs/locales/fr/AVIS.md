# Avis

> **Source canonique en anglais:** [NOTICE.md](../../../NOTICE.md). Cette documentation localisée conserve les commandes, chemins, clés, valeurs d'état, hachages et noms de fichiers exacts. Si la formulation technique diffère, utilisez la source anglaise. Cette traduction est informative ; le texte juridique anglais contrôle.


RandomDay est un mod communautaire indépendant pour les serveurs dédiés Abiotic Factor.

RandomDay n'inclut, ne copie, ne réhéberge ni ne redistribue le code des mods tiers pris en charge. L'intégration facultative est gérée via RandomDay-owned scripts d'adaptateur qui corrigent les paramètres exposés uniquement lorsque le propriétaire du serveur a installé ces mods pris en charge séparément.
