<a id="contributing"></a>
# Contribution

> **Source canonique en anglais:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Cette documentation localisée conserve les commandes, chemins, clés, valeurs d'état, hachages et noms de fichiers exacts. Si la formulation technique diffère, utilisez la source anglaise.


RandomDay est maintenu en tant que système contrôlé projet.

Les demandes d'extraction publiques, les soumissions de code non sollicitées, les réécritures automatisées, les soumissions de nettoyage de code généré et les correctifs de fonctionnalités spéculatives ne sont pas acceptés sauf demande explicite du propriétaire du référentiel.

<a id="accepted-contact"></a>
## Accepté contact

Pour les rapports de bogues, les notes de compatibilité ou les observations d'administration du serveur, utilisez les canaux de contact répertoriés dans la documentation du projet.

<a id="not-accepted"></a>
## Non accepté

Les éléments suivants ne sont pas acceptés par défaut :

- demandes d'extraction non sollicitées ;
- réécritures de code généré ;
- refactors étendus ;
- modifications de formatage de style uniquement ;
- modifications de logique de jeu non testées ;
- fichiers de mod tiers regroupés ;
- code source tiers redistribué ;
- changements qui impliquent une affiliation officielle avec Abiotic Factor, UE4SS, Nexus Mods ou des auteurs de mods tiers.

<a id="controlled-development"></a>
## Développement contrôlé

Le propriétaire du référentiel peut demander une révision spécifique, des tests ou une aide à la documentation si nécessaire. Les soumissions non demandées peuvent être fermées sans examen.
