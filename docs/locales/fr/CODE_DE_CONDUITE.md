# Code de conduite

> **Source canonique en anglais:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). Cette documentation localisée conserve les commandes, chemins, clés, valeurs d'état, hachages et noms de fichiers exacts. Si la formulation technique diffère, utilisez la source anglaise. Cette traduction est informative ; le texte juridique anglais contrôle.


Gardez les rapports techniques, reproductibles et respectueux.

Ce référentiel est pour le développement contrôlé d'un mod serveur. Les rapports de bogues doivent inclure les journaux, les chemins, le comportement attendu et le comportement réel.
