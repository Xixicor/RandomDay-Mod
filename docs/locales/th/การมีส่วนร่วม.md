# การมีส่วนร่วม

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDay ได้รับการดูแลให้เป็นโปรเจ็กต์ที่มีการควบคุม

คำขอดึงสาธารณะ การส่งโค้ดที่ไม่พึงประสงค์ การเขียนใหม่อัตโนมัติ การส่งการล้างโค้ดที่สร้างขึ้น และแพตช์ฟีเจอร์เชิงคาดเดาจะไม่ได้รับการยอมรับ เว้นแต่จะมีการร้องขออย่างชัดเจนจากเจ้าของพื้นที่เก็บข้อมูล

<a id="accepted-contact"></a>
## ยอมรับแล้ว ติดต่อ

สำหรับรายงานข้อผิดพลาด บันทึกความเข้ากันได้ หรือการสังเกตการดูแลระบบเซิร์ฟเวอร์ ให้ใช้ช่องทางการติดต่อที่ระบุไว้ในเอกสารประกอบโครงการ

<a id="not-accepted"></a>
## ไม่ยอมรับ

สิ่งต่อไปนี้ไม่ได้รับการยอมรับตามค่าเริ่มต้น:

- คำขอดึงที่ไม่พึงประสงค์;
- เขียนโค้ดที่สร้างใหม่;
- refactors แบบกว้าง
- การเปลี่ยนแปลงการจัดรูปแบบเฉพาะสไตล์
- การเปลี่ยนแปลงตรรกะการเล่นเกมที่ยังไม่ทดสอบ
- ไฟล์ mod ของบุคคลที่สามที่รวมกลุ่ม
- แจกจ่ายซอร์สโค้ดบุคคลที่สาม
- การเปลี่ยนแปลงที่บ่งบอกถึงความเกี่ยวข้องอย่างเป็นทางการกับ Abiotic Factor, UE4SS, Nexus Mods หรือผู้สร้างม็อดบุคคลที่สาม

<a id="controlled-development"></a>
## การพัฒนาที่มีการควบคุม

เจ้าของพื้นที่เก็บข้อมูลอาจร้องขอการตรวจสอบ การทดสอบ หรือความช่วยเหลือด้านเอกสารโดยเฉพาะเมื่อจำเป็น การส่งที่ไม่ได้รับการร้องขออาจถูกปิดโดยไม่มีการตรวจสอบ
