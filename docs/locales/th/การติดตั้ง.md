# ติดตั้ง อัปเดต หรือลบ RandomDay

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [INSTALL.md](../../../INSTALL.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDay มีการดาวน์โหลดเสร็จสมบูรณ์สองครั้ง เลือกหนึ่งรายการสำหรับโลกที่คุณกำลังตั้งค่า:

- ใช้ **เซิร์ฟเวอร์เฉพาะ ZIP** สำหรับเซิร์ฟเวอร์เฉพาะใด ๆ รวมถึงเซิร์ฟเวอร์ที่เปิดเฉพาะสำหรับเซสชันเป็นครั้งคราวเท่านั้น
- ใช้ **singleplayer/LAN ZIP** สำหรับโลกท้องถิ่นที่คุณจะคัดลอกการตั้งค่าด้วยตนเอง

อย่ารวมแพ็คเกจ เซิร์ฟเวอร์เฉพาะถาวรหรือชั่วคราวเป็นตัวเลือกในการตั้งค่าของ RandomDay's การตั้งค่า ไม่ใช่การดาวน์โหลดอื่น

<a id="before-you-begin"></a>
## ก่อนที่คุณจะเริ่มต้น

สร้างสำเนาที่สามารถกู้คืนได้ของ:

- โลกที่คุณกำลังเปลี่ยนแปลง
- ปัจจุบัน `SandboxSettings.ini`;
- ที่มีอยู่ `RandomDay` หากมีการติดตั้งไว้

ติดตั้ง UE4SS ก่อน RandomDay ในคำแนะนำด้านล่าง **โฟลเดอร์ Mods** หมายถึง `ue4ss/Mods/` ภายในเกมหรือการติดตั้งเซิร์ฟเวอร์เฉพาะ

<a id="dedicated-server"></a>
## เซิร์ฟเวอร์เฉพาะ

<a id="new-installation"></a>
### การติดตั้งใหม่

1. หยุดเซิร์ฟเวอร์
2. เปิด UE4SS `Mods` โฟลเดอร์
3. แยกเซิร์ฟเวอร์เฉพาะ ZIP ผลลัพธ์ควรเป็นหนึ่ง `ue4ss/Mods/RandomDay/` ไม่ใช่โฟลเดอร์ภายในโฟลเดอร์อื่น `RandomDay` โฟลเดอร์
4. เปิดโฟลเดอร์นั้นและยืนยัน `RandomDay/Scripts/main.lua` ที่มีอยู่ หากหายไป ZIP จะถูกแยกออกไปในระดับที่ไม่ถูกต้อง
5. เปิด UE4SS `mods.txt` และเปิดใช้งานบรรทัดนี้:

   ```text
   RandomDay : 1
   ```

6. เริ่มเซิร์ฟเวอร์ตามปกติ
7. เปิด RandomDay's หน้าสถานะที่อ่านได้ และยืนยันว่าตั้งชื่อทั้งโปรไฟล์ที่ใช้งานอยู่และโปรไฟล์ที่เตรียมไว้สำหรับการเริ่มต้นครั้งถัดไป

การเริ่มต้นครั้งแรกไม่ได้แทนที่กฎที่โหลดไว้แล้วในเซสชันนั้น มันเตรียมโปรไฟล์ต่อไป เริ่มเซิร์ฟเวอร์อีกครั้งเฉพาะเมื่อคุณต้องการให้โปรไฟล์ที่เตรียมไว้นั้นเปิดใช้งานจริง ๆ เท่านั้น

[ตรวจสอบรอบแรก](%E0%B9%80%E0%B8%A3%E0%B8%B4%E0%B9%88%E0%B8%A1%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B8%99%E0%B8%B5%E0%B9%88.md)

<a id="choose-always-on-or-temporary-behavior"></a>
### เลือกการทำงานตลอดเวลาหรือชั่วคราว

แพ็คเกจเซิร์ฟเวอร์เฉพาะรองรับทั้งสองสไตล์:

- **ถาวรโดยเฉพาะ** ดำเนินการหมุนเวียนที่บันทึกไว้ต่อตามปกติ รีสตาร์ท
- **เฉพาะชั่วคราว** สามารถเริ่มต้นจากจุดเริ่มต้นที่กำหนดค่าหรือสุ่มเมื่อเริ่มต้นการทำงานชั่วคราวใหม่

เลือกลักษณะการทำงานใน [การกำหนดค่า](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md) อย่าติดตั้งแพ็คเกจที่สองเพื่อเปลี่ยนการตั้งค่านี้

<a id="update-an-existing-installation"></a>
### อัปเดตการติดตั้งที่มีอยู่

1. หยุดเซิร์ฟเวอร์และทำการสำรองข้อมูลตามรายการด้านบน
2. ย้ายอันเก่า `RandomDay` โฟลเดอร์ออกจากโฟลเดอร์ UE4SS `Mods` โฟลเดอร์ เก็บไว้จนกว่าการอัปเดตจะเสร็จสิ้นหนึ่งรอบสำเร็จ
3. แยกเซิร์ฟเวอร์เฉพาะใหม่ ZIP ลงใน `Mods` โฟลเดอร์
4. ใช้เฉพาะการตั้งค่าที่คุณตั้งใจเปลี่ยนแปลงและยังคงอยู่ในสถานะใหม่ [คู่มือการกำหนดค่า](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md).
5. เก็บไฟล์สถานะการหมุนที่บันทึกไว้เฉพาะเมื่อบันทึกประจำรุ่นระบุว่ารูปแบบเข้ากันได้เท่านั้น อย่าคัดลอกเอาต์พุตชั่วคราวเก่าหรือไฟล์ที่เขียนไม่สำเร็จลงในการติดตั้งใหม่
6. ยืนยัน `RandomDay : 1` ยังคงเปิดใช้งานอยู่ จากนั้นเริ่มเซิร์ฟเวอร์หนึ่งครั้งและตรวจสอบชื่อโปรไฟล์ที่ใช้งานอยู่และที่เตรียมไว้

<a id="updating-from-v0315-alpha"></a>
### การอัปเดตจาก v0.3.15-alpha

`RandomDay_v0.3.15-alpha.zip` เป็นแพ็คเกจพื้นฐานเก่า `RandomDay_v0.3.15-alpha_singleplayer_patch.zip` เป็นโอเวอร์เลย์และไม่ใช่การดาวน์โหลดแบบสแตนด์อโลน

ปัจจุบัน `v0.3.16-alpha` แทนที่การจัดเรียงฐานและโอเวอร์เลย์ในอดีตด้วยแพ็คเกจที่สมบูรณ์สองแพ็คเกจ อย่าวางแพทช์เก่าไว้บนบรรจุภัณฑ์อย่างใดอย่างหนึ่ง เครื่องหมายปัจจุบันคือ `.randomday_mode=dedicated_server` และ `.randomday_mode=singleplayer_manual`.

<a id="singleplayer-or-lan"></a>
## ผู้เล่นคนเดียวหรือ LAN

แพ็คเกจ singleplayer/LAN สร้างไฟล์การตั้งค่า มันจะไม่ค้นหาหรือเปลี่ยนแปลงการบันทึกส่วนตัวด้วยตัวเอง

1. ปิดเกม
2. สำรองข้อมูลโลกและ `SandboxSettings.ini`.
3. แตกไฟล์ singleplayer/LAN ZIP ลงใน UE4SS `Mods` ของเกม ดังนั้นหนึ่งโฟลเดอร์ `Mods/RandomDay/` มีอยู่แล้ว
4. เปิดใช้งาน `RandomDay : 1` ใน UE4SS `mods.txt`.
5. เริ่มเกมหนึ่งครั้ง รอ RandomDay เสร็จสิ้น และปิดเกมโดยสมบูรณ์
6. ค้นหา `SandboxSettings.ini` ใน RandomDay's `runtime/singleplayer_manual/` โฟลเดอร์
7. อ่านที่สร้างขึ้น สรุป จากนั้นคัดลอกไฟล์ไปยังโลกเดียวที่คุณเลือก
8. เริ่มต้นโลกนั้นและตรวจสอบว่าลักษณะการทำงานของแซนด์บ็อกซ์ที่คาดหวังนั้นทำงานอยู่

LAN ใช้กระบวนการแบบแมนนวลเดียวกันเนื่องจาก โฮสต์เป็นเจ้าของโลกท้องถิ่น Mod จะไม่เลือกโลกหรือเขียนทับโลกโดยอัตโนมัติ

[เล่นคนเดียวและ LAN คำแนะนำ](SINGLEPLAYER_LAN.md)

<a id="remove-or-disable-randomday"></a>
## ลบหรือปิดการใช้งาน RandomDay

1. หยุดเกมหรือเซิร์ฟเวอร์
2. สำรองข้อมูลโลก การตั้งค่าแซนด์บ็อกซ์ปัจจุบัน และสถานะของ RandomDay's สถานะ
3. ตั้งค่า `RandomDay : 0` ใน UE4SS `mods.txt` เพื่อปิดการใช้งาน mod หรือย้าย mod ที่สมบูรณ์ `RandomDay` โฟลเดอร์ออกจากโฟลเดอร์ `Mods` เพื่อลบออก
4. ตัดสินใจว่าควรโหลด `SandboxSettings.ini` ควรโหลดแล้ว ในการเริ่มต้นครั้งถัดไป คืนค่าสำเนาที่ติดตั้งไว้ล่วงหน้าของคุณหากคุณไม่ต้องการให้โปรไฟล์ RandomDay ที่เตรียมไว้ในปัจจุบัน
5. เริ่มต้นโลกและยืนยันกฎก่อนที่จะลบข้อมูลสำรองใด ๆ

การปิดใช้งาน RandomDay เป็นการหยุดการเตรียมโปรไฟล์ในอนาคต โดยจะไม่เขียนไฟล์แซนด์บ็อกซ์ที่รออยู่ในดิสก์แล้ว

<a id="recover-from-an-unsuccessful-update"></a>
## กู้คืนจากการอัปเดตที่ไม่สำเร็จ

หยุดหลังจากความล้มเหลวที่ชัดเจนครั้งแรก การรีสตาร์ทซ้ำหลายครั้งอาจทำให้ยากขึ้นในการดูว่าโปรไฟล์ใดที่ใช้งานอยู่และโปรไฟล์ใดกำลังรออยู่

1. หยุดเกมหรือเซิร์ฟเวอร์
2. ย้ายการติดตั้งที่ไม่สำเร็จออกไปด้านข้าง กำลังลบออก
3. กู้คืนโฟลเดอร์ RandomDay ทั้งหมดที่ทำขึ้นก่อน อัปเดต
4. เริ่มต้นหนึ่งครั้งและยืนยันชื่อโปรไฟล์ที่ใช้งานอยู่และเตรียมไว้แล้ว
5. ใช้ [การแก้ไขปัญหา](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B9%89%E0%B9%84%E0%B8%82%E0%B8%9B%E0%B8%B1%E0%B8%8D%E0%B8%AB%E0%B8%B2.md) สำหรับขั้นตอนแรกที่ขาดหายไปหรือล้มเหลวก่อนที่จะลองอัปเดตอีกครั้ง
