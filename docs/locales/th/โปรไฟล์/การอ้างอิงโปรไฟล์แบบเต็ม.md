# RandomDay - การอ้างอิงโปรไฟล์แบบเต็ม

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [FULL_PROFILE_REFERENCE.md](../../../profiles/FULL_PROFILE_REFERENCE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


เวอร์ชัน: `v0.3.16-alpha`

สิ่งนี้ ข้อมูลอ้างอิงที่สร้างขึ้นครอบคลุมโปรไฟล์ทั้งหมด 289 โปรไฟล์ใน 17 ตระกูล มันถูกสร้างขึ้นจากตารางโปรไฟล์ Lua และพจนานุกรมการแปลเดียวกันกับที่ใช้ในรันไทม์ ค่าดิบยังคงเชื่อถือได้

<a id="read-the-reference"></a>
## อ่านข้อมูลอ้างอิง

- การให้คะแนนโดยรวมและโดเมนคำนวณจากคีย์ SandboxSettings ทั้งหมด 46 คีย์ บวกกับแรงกดดัน
- ข้อความภาษาธรรมดาถือเป็นคำแนะนำ ค่าที่แน่นอนจะยังคงอยู่ข้างๆ ทุกคำอธิบาย
- การตั้งค่าที่ใช้งานอยู่จะมีผลกับการบูตปัจจุบัน การตั้งค่าที่เตรียมไว้จะใช้หลังจากการรีสตาร์ทครั้งถัดไปเท่านั้น
- การเลือกอแด็ปเตอร์เสริมเป็นการร้องขอ สถานะรันไทม์บันทึกว่าอะแดปเตอร์ที่ติดตั้งตรงกันและตรวจสอบแล้วจริงหรือไม่
