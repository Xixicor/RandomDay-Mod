<a id="day-1---loose-inventory-ethics"></a>
## วันที่ 1 - จริยธรรมสินค้าคงคลังที่หลวม

**รหัสโปรไฟล์:** `scavenger_loose_inventory_ethics` **เงื่อนไขโดยรวม:** ความดันมาตรฐาน (1.79/5) **ความหมายธรรมดา:** ความดันมาตรฐาน ความกดดันด้านสิ่งแวดล้อม: ความกดดันมาตรฐานคือความกดดันหลัก ความกดดันในการเอาชีวิตรอด: ความกดดันมาตรฐานเป็นปัจจัยที่แข็งแกร่งที่สุดรองลงมา **คำแนะนำสำหรับผู้เล่น:** ตรวจสอบการป้องกันไฟฟ้า น้ำ ที่พักพิง และอันตรายก่อนออกจากฐาน

<a id="main-effects"></a>
### ผลกระทบหลัก

- ความจุของสแต็กสูงมาก (8x).
- ความเสียหายจากการยิงที่เป็นมิตรนั้นต่ำกว่าปกติมาก (0.25x).
- การสูญเสียความทนทานต่อการเสียชีวิตนั้นต่ำกว่าปกติมาก (0.25x).
- ปลั๊กไฟปิดในเวลากลางคืน
- สามารถส่งคืนของปล้นได้หลังจากการเก็บรวบรวม
