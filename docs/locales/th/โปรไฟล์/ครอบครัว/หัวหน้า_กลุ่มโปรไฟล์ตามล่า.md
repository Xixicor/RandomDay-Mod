<a id="day-1---trophy-orientation"></a>
## วันที่ 1 - การวางแนวถ้วยรางวัล

**รหัสโปรไฟล์:** `boss_hunt_trophy_orientation` **เงื่อนไขโดยรวม:** ความดันมาตรฐาน (1.98/5) **ความหมายธรรมดา:** แรงกดดันมาตรฐาน แรงกดดันในการต่อสู้: แรงกดดันมาตรฐานคือแรงกดดันหลัก ความกดดันด้านสิ่งแวดล้อม: ความกดดันมาตรฐานเป็นปัจจัยที่แข็งแกร่งที่สุดรองลงมา **คำแนะนำสำหรับผู้เล่น:** พกพากระสุน รักษาเส้นทางล่าถอย และหลีกเลี่ยงการสู้รบที่ไม่ได้รับการสนับสนุน

<a id="main-effects"></a>
### ผลกระทบหลัก

- ความแม่นยำของศัตรู: แม่นยำ
- ความเสียหายจากการยิงที่เป็นมิตรนั้นต่ำกว่าปกติมาก (0.25x).
- การสูญเสียความทนทานต่อการเสียชีวิตนั้นต่ำกว่าปกติมาก (0.25x).
- ความจุสแต็กสูงกว่าปกติมาก (2x).
- ปลั๊กไฟปิดในเวลากลางคืน
