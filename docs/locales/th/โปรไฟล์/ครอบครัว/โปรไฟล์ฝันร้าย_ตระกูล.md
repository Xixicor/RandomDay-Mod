<a id="day-1---softly-lit-mistake"></a>
## วันที่ 1 - ข้อผิดพลาดที่เบาลง

**รหัสโปรไฟล์:** `nightmare_softly_lit_mistake` **เงื่อนไขโดยรวม:** ความดันมาตรฐาน (2.03/5) **ความหมายธรรมดา:** แรงกดดันมาตรฐาน ความกดดันด้านสิ่งแวดล้อม: ความกดดันมาตรฐานคือความกดดันหลัก ความกดดันในการต่อสู้: ความกดดันมาตรฐานคือปัจจัยที่แข็งแกร่งที่สุดรองลงมา **คำแนะนำสำหรับผู้เล่น:** ตรวจสอบการป้องกันไฟฟ้า น้ำ ที่พักพิง และอันตรายก่อนออกจากฐาน

<a id="main-effects"></a>
### ผลกระทบหลัก

- สถานะกลางวัน-กลางคืน: อคติกลางคืน
- ความแม่นยำของศัตรู: แม่นยำ
- ความเสียหายจากการยิงที่เป็นมิตรนั้นต่ำกว่าปกติมาก (0.25x).
- การสูญเสียความทนทานต่อการเสียชีวิตนั้นต่ำกว่าปกติมาก (0.25x).
- ความจุสแต็กสูงกว่าปกติมาก (2x).
