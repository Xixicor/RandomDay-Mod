<a id="day-1---dimensional-intake"></a>
## วันที่ 1 - การบริโภคตามมิติ

**รหัสโปรไฟล์:** `anteverse_dimensional_intake` **เงื่อนไขโดยรวม:** ความดันมาตรฐาน (1.88/5) **ความหมายธรรมดา:** แรงกดดันมาตรฐาน ความกดดันด้านสิ่งแวดล้อม: ความกดดันมาตรฐานคือความกดดันหลัก ความกดดันในการต่อสู้: ความกดดันมาตรฐานคือปัจจัยที่แข็งแกร่งที่สุดรองลงมา **คำแนะนำสำหรับผู้เล่น:** ตรวจสอบการป้องกันไฟฟ้า น้ำ ที่พักพิง และอันตรายก่อนออกจากฐาน

<a id="main-effects"></a>
### ผลกระทบหลัก

- ความเสียหายจากการยิงที่เป็นมิตรนั้นต่ำกว่าปกติมาก (0.25x).
- การสูญเสียความทนทานต่อการเสียชีวิตนั้นต่ำกว่าปกติมาก (0.25x).
- ความจุสแต็กสูงกว่าปกติมาก (2x).
- ปลั๊กไฟปิดในเวลากลางคืน
- ของที่รวบรวมมาจะไม่เกิดใหม่
