# RandomDay เอกสารประกอบโปรไฟล์

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [README.md](../../../profiles/README.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


เวอร์ชัน: `v0.3.16-alpha`

- ครอบครัว: **17**
- โปรไฟล์: **289**
- SandboxSettings รายการพจนานุกรม: **46**

เลือกตระกูลตามจุดประสงค์ในการเล่นเกมใน [คำแนะนำการเลือกโปรไฟล์](../%E0%B9%80%E0%B8%A5%E0%B8%B7%E0%B8%AD%E0%B8%81%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C.md) จากนั้นใช้ดัชนีที่สร้างขึ้นนี้สำหรับค่าที่แน่นอน

ไฟล์เหล่านี้สร้างขึ้นจากแหล่งที่มา Lua รันไทม์และสัญญา dictionary/translation พวกเขาแสดงค่าเริ่มต้นที่จัดส่ง `sandbox.profile_overrides` ค่าที่กำหนดค่าของเซิร์ฟเวอร์หนึ่งอาจแตกต่างกัน:

- `profiles.generated.json`: โปรไฟล์ที่เครื่องอ่านได้ ค่าดิบ พจนานุกรม และการแปล
- `FULL_PROFILE_REFERENCE.md`: ทำดัชนีและกฎการตีความให้ครบถ้วน
- `SANDBOX_SETTINGS_KEYS.md`: พจนานุกรม 46 คีย์ที่สมบูรณ์
- `families/*.md`: การอ้างอิงครอบครัวโดยละเอียดในช่วง 17 วัน

สร้างใหม่ด้วย: `python -B tools/generate_profile_docs.py` ตรวจสอบการดริฟท์ด้วย: `python -B tools/generate_profile_docs.py --check`
