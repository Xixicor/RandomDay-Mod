# ประกาศ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [NOTICE.md](../../../NOTICE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ การแปลนี้เป็นการให้ข้อมูล; การควบคุมข้อความทางกฎหมายภาษาอังกฤษ


RandomDay เป็น mod ชุมชนอิสระสำหรับเซิร์ฟเวอร์เฉพาะของ Abiotic Factor

RandomDay ไม่รวม คัดลอก โฮสต์ใหม่ หรือแจกจ่ายรหัสจาก mod ของบุคคลที่สามที่ได้รับการสนับสนุน การรวมตัวเลือกจะได้รับการจัดการผ่าน RandomDay-owned สคริปต์อะแดปเตอร์ที่แก้ไขการตั้งค่าที่เปิดเผยเฉพาะเมื่อเจ้าของเซิร์ฟเวอร์ได้ติดตั้ง mods ที่รองรับเหล่านั้นแยกต่างหาก
