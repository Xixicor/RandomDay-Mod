# ประกาศของบุคคลที่สาม

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ การแปลนี้เป็นการให้ข้อมูล; การควบคุมข้อความทางกฎหมายภาษาอังกฤษ


RandomDay เป็น mod ชุมชนอิสระสำหรับ Abiotic Factor และ UE4SS.

อะแดปเตอร์เสริมสามารถอัปเดตเค้าโครงการกำหนดค่าที่รู้จักซึ่งเป็นของ mod ที่ติดตั้งแยกต่างหากจะไม่ถูกรวม คัดลอก หรือแจกจ่ายซ้ำด้วย RandomDay. ชื่อของพวกเขายังคงเป็นทรัพย์สินของผู้เขียนที่เกี่ยวข้อง

ดู `docs/SUPPORTED_ADAPTERS.md` สำหรับโครงร่างที่แน่นอนที่ได้รับการยอมรับในปัจจุบัน
