# เลือกประเภทของเกมที่คุณต้องการ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [CHOOSE_A_PROFILE.md](../../CHOOSE_A_PROFILE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDay ประกอบด้วยกฎโลกสำเร็จรูป 289 ชุด โดยจัดเป็น 17 **ครอบครัว** ด้วย 17 **โปรไฟล์** ในแต่ละตระกูล:

- ตระกูลคือสไตล์การเล่นแบบกว้างๆ แนวเดียว เช่น เอาชีวิตรอด การสร้าง การลักลอบ หรือการสำรวจ
- โปรไฟล์คือชุดกฎที่สมบูรณ์ชุดเดียวภายในสไตล์การเล่นนั้น และ
- หมายเลขโปรไฟล์ถูกเรียกว่าวัน เนื่องจาก RandomDay เคลื่อนผ่าน 17 ตำแหน่งเหล่านั้นเมื่อเซิร์ฟเวอร์รีสตาร์ท ไม่ใช่วันตามปฏิทินโลกแห่งความเป็นจริง

เริ่มต้นด้วยตารางด้านล่าง เลือกแถวที่ฟังดูใกล้เคียงกับเซสชันที่คุณต้องการมากที่สุด จากนั้นเปิดหน้าครอบครัวหนึ่งหรือสองหน้าเพื่อเปรียบเทียบเอฟเฟกต์เหล่านั้น

1. เปิดหน้าครอบครัวและเปรียบเทียบตำแหน่ง 17 วันทั้งหมด
2. ใช้ [การอ้างอิงโปรไฟล์แบบเต็ม](%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C/%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%AD%E0%B9%89%E0%B8%B2%E0%B8%87%E0%B8%AD%E0%B8%B4%E0%B8%87%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C%E0%B9%81%E0%B8%9A%E0%B8%9A%E0%B9%80%E0%B8%95%E0%B9%87%E0%B8%A1.md) เพื่อเปรียบเทียบชื่อโปรไฟล์และกฎการตีความในชุดค่าผสมทั้ง 289 รายการ
3. ใช้ [คีย์การตั้งค่าแซนด์บ็อกซ์](%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C/%E0%B8%84%E0%B8%B5%E0%B8%A2%E0%B9%8C%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%95%E0%B8%B1%E0%B9%89%E0%B8%87%E0%B8%84%E0%B9%88%E0%B8%B2%E0%B9%81%E0%B8%8B%E0%B8%99%E0%B8%94%E0%B9%8C%E0%B8%9A%E0%B9%87%E0%B8%AD%E0%B8%81%E0%B8%8B%E0%B9%8C.md) เพื่อตีความแต่ละค่าดิบ ช่วงที่สนับสนุน แถบคะแนน และค่าเริ่มต้นของโปรไฟล์ที่จัดส่ง
4. ใช้ [`profiles.generated.json`](../../profiles/profiles.generated.json) เมื่อเครื่องมือต้องการโปรไฟล์ที่เครื่องอ่านได้ พจนานุกรม และแหล่งที่มาของการแปล

## กำหนดค่าประสบการณ์ที่เลือก

ติดตาม [เลือกประสบการณ์](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md#choose-an-experience) เพื่อตั้งค่าโหมดครอบครัว รายชื่อครอบครัวที่มีสิทธิ์ พฤติกรรมของวันเริ่มต้น และลำดับวันตามลำดับหรือไม่ซ้ำกัน RandomDay ยังคงมีลำดับที่เลือก; การกู้คืนจะไม่ทำการสุ่มการรันตระกูลที่กำลังดำเนินการอยู่
