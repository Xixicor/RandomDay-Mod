# การตรวจสอบความถูกต้องของรุ่น

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


หน้านี้มีไว้สำหรับผู้มีส่วนร่วมและผู้ดูแลรีลีส ผู้เล่นที่ติดตั้งม็อดไม่จำเป็นต้องเรียกใช้คำสั่งเหล่านี้

<a id="ordinary-user-proof"></a>
## หลักฐานผู้ใช้ทั่วไป

การเผยแพร่จะเข้าใจได้เมื่อผู้อ่านใหม่สามารถเลือกหนึ่งในสองแพ็คเกจ ติดตั้ง ระบุโปรไฟล์ที่ใช้งานอยู่และโปรไฟล์ที่เตรียมไว้ และกู้คืนจากผลลัพธ์ที่ขาดหายไปโดยทำตามคำแนะนำที่เชื่อมโยง งานผู้อ่านเหล่านั้นจะต้องไม่ต้องใช้ Git PowerShell, Python หรือความรู้ในการตรวจสอบ

<a id="contributor-checks"></a>
## การตรวจสอบผู้ร่วมให้ข้อมูล

เรียกใช้จากรากของที่เก็บ:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

เมื่อใด `luac` พร้อมใช้งาน ตรวจสอบไวยากรณ์ทุกไฟล์ Lua ที่จัดส่ง:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

การทดสอบรันไทม์ Lua ต้องการ `lupa`. ล่าม Lua หายไปหรือ `lupa` การติดตั้งคือความสามารถในการทดสอบที่ไม่พร้อมใช้งาน ไม่ใช่ผลลัพธ์ที่ผ่าน

<a id="release-checks"></a>
## ปล่อยการตรวจสอบ

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

การตรวจสอบการเปิดตัวจะตรวจสอบเงื่อนไขเหล่านี้:

- `VERSION` และ `RandomDay/.randomday_version` ตรงกัน
- เฉพาะรุ่นปัจจุบันเท่านั้นที่มีอยู่ภายใต้ `releases/`.
- เฉพาะและ singleplayer/LAN ZIP เป็นทางเลือกที่สมบูรณ์
- ทั้งสองไฟล์มีรูปแบบบัญญัติ `RandomDay/Scripts/main.lua` เส้นทางและไม่มีตัวโหลดที่ชนกันของตัวพิมพ์
- เครื่องหมายโหมดแพ็คเกจคือ `dedicated_server` และ `singleplayer_manual`.
- ZIP ไบต์ถูกกำหนดไว้และตรงกัน `CHECKSUMS.sha256`.
- ไม่มีแพ็กเกจข้อมูลรันไทม์ การกำหนดค่าส่วนตัว ข้อมูลประจำตัว แคช หรือเอาต์พุตทดสอบ
- ลิงก์เอกสารในเครื่องทั้งหมดและหน้ารายการสถานที่ 27 หน้าตรวจสอบ

<a id="avoid-validation-environment-pitfalls"></a>
## หลีกเลี่ยงข้อผิดพลาดของสภาพแวดล้อมในการตรวจสอบ

- เรียกใช้การตรวจสอบการเขียนที่เก็บข้อมูลตามลำดับ เพื่อให้กระบวนการทั้งสองไม่แทนที่ไฟล์ชั่วคราวเดียวกันในครั้งเดียว
- บน Windows ให้ทำเครื่องหมายที่ ZIP ชื่อสมาชิกแทนที่จะใช้การค้นหาไฟล์ที่ไม่คำนึงถึงตัวพิมพ์เล็กและใหญ่เพื่อตัดสินใจว่ามีตัวโหลดตัวพิมพ์เล็กอยู่หรือไม่
- ยืนยัน `mods.txt` และ `enabled.txt` เฉพาะในการทดสอบเซิร์ฟเวอร์ที่ติดตั้งเท่านั้น ไม่ใช่ข้อพิสูจน์ว่าการทดสอบแหล่งที่มาทำงานอยู่
- บันทึกการหมดเวลาของคำสั่งว่าไม่สมบูรณ์ อย่าแปลงเป็นการส่งผ่านหรือล้มเหลวโดยไม่มีเอาต์พุตที่ถูกผูกไว้ของคำสั่ง
- เก็บไฟล์ชั่วคราวไว้ใน `.tmp/`

<a id="known-limits"></a>
## ขีดจำกัดที่ทราบ

การตรวจสอบความถูกต้องในท้องถิ่นจะพิสูจน์แหล่งที่มา แพ็คเกจ เอกสารประกอบ และสัญญาฟิกซ์เจอร์ ไม่ได้พิสูจน์ลำดับการเริ่มต้นของแผงเซิร์ฟเวอร์เฉพาะ เค้าโครงข้อความของไคลเอ็นต์ที่ใช้งานจริง หรือเส้นทางระบบไฟล์เฉพาะโฮสต์ บันทึกสิ่งเหล่านั้นเป็นผลลัพธ์การรวมแยกกันเมื่อมีการทดสอบ
