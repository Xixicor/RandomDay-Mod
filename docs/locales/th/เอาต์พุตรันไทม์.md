# ตีความสถานะรันไทม์และสคีมาเอาต์พุต

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


นี่คือคำแนะนำสคีมาแบบเต็มช่องตามรูปแบบบัญญัติ โดยจะตอบความหมายของแต่ละฟิลด์ สถานะ ค่าว่าง และผลลัพธ์ของเครื่อง ใช้ [แผนผังไฟล์รันไทม์](%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C%E0%B8%A3%E0%B8%B1%E0%B8%99%E0%B9%84%E0%B8%97%E0%B8%A1%E0%B9%8C.md) สำหรับผู้ผลิต เส้นทาง เวลาในการเขียน การเก็บรักษา ไซด์คาร์ธุรกรรม และสถานที่กู้คืน

เส้นทางทั้งหมดในคู่มือนี้สัมพันธ์กับโฟลเดอร์ `RandomDay/` โฟลเดอร์ เว้นแต่แถวจะตั้งชื่อแซนด์บ็อกซ์ที่กำหนดค่าไว้อย่างชัดเจนหรือเป้าหมายของอะแดปเตอร์เสริม เอาต์พุตรันไทม์จะถูกสร้างขึ้นหลังการติดตั้ง และไม่ใช่สมาชิกของรุ่นใดรุ่นหนึ่ง ZIP.

<a id="choose-the-authoritative-view"></a>
## เลือกมุมมองที่เชื่อถือได้

| ต้องการ | แหล่งที่มาที่เชื่อถือได้ |
|---|---|
| กฎที่โหลดโดยกระบวนการปัจจุบัน | RandomDay เครื่องหมายใน `SandboxSettings.ini` อ่านที่ การเริ่มต้น |
| การทำบัญชีคิวที่เตรียมไว้ | `runtime/rotation_state.txt`, สคีมา `1` |
| สถานะท้องถิ่นโดยละเอียด | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| สถานะที่เครื่องสาธารณะสามารถอ่านได้ | `web_export/today.json`, สคีมา `2` และ `randomday_public_status_v2` |
| สถานะที่มนุษย์สามารถอ่านได้ | `web_export/today.html` ซึ่งได้มาจากการเปลี่ยนแปลงสถานะสาธารณะเดียวกัน |
| คำศัพท์การแปล | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| ประกาศของผู้เล่นที่มีขอบเขตที่แน่นอน | `runtime/current/player_message_preview.txt` |

แพ็คเกจ HTML มุมมอง การแสดงตัวอย่าง และข้อมูลสรุปที่แปลแล้วเป็นมุมมองที่ได้รับ โดยจะไม่แทนที่เครื่องหมายแซนด์บ็อกซ์ ผลลัพธ์ของธุรกรรม หรือค่าโปรไฟล์ดิบ ค้นหาไฟล์ที่ทราบล่าสุด การสำรองข้อมูลการดำเนินการ ไซด์คาร์ มิเรอร์ เป้าหมายของอะแดปเตอร์ และ `UE4SS.log` ใน [ไฟล์รันไทม์](%E0%B9%84%E0%B8%9F%E0%B8%A5%E0%B9%8C%E0%B8%A3%E0%B8%B1%E0%B8%99%E0%B9%84%E0%B8%97%E0%B8%A1%E0%B9%8C.md).

<a id="rotation-state-schema"></a>
## สคีมาสถานะการหมุน

`runtime/rotation_state.txt` ใช้สคีมา `1` และมีคู่ `key=value` หนึ่งคู่ต่อบรรทัด:

| ฟิลด์ | ความหมาย |
|---|---|
| `schema_version` | ต้องเป็น `1`. |
| `mod_version` | ข้อมูลระบุตัวตนของแพ็คเกจที่อ่านจาก `.randomday_version`. |
| `rotation_id` | ตัวระบุสำหรับการส่งผ่านปัจจุบันผ่านชุดตระกูลที่มีสิทธิ์ |
| `mode` | `selected_run`, `non_repeating_random_run` หรือ `rotation_run`. |
| `available_families` | รหัสครอบครัวที่มีสิทธิ์โดยคั่นด้วยเครื่องหมายจุลภาคหลังจากการกรองการกำหนดค่า |
| `remaining_families` | ตระกูลที่มีสิทธิ์ยังไม่ได้เลือกในบัตรผ่านที่ไม่ซ้ำในปัจจุบัน |
| `completed_families` | ครอบครัวที่มีคำสั่งซื้อ 17 ตำแหน่งที่คงอยู่เสร็จสมบูรณ์แล้วในบัตรปัจจุบัน |
| `active_family`, `active_day` | ข้อมูลเครื่องหมายที่ใช้งานอยู่จะถูกบันทึกเมื่อมีการยืนยันการเลือก เครื่องหมายแซนด์บ็อกซ์เชื่อถือได้ในการบูตครั้งถัดไป |
| `prepared_family`, `prepared_day` | โปรไฟล์ถูกระงับไว้สำหรับการรีสตาร์ทครั้งต่อไป |
| `active_run_id` | ตัวระบุที่ดำเนินกิจการโดยครอบครัวที่เกี่ยวข้องกับการเลือกที่เตรียมไว้ |
| `last_status` | สถานะการเลือกปฏิทินที่สร้างไฟล์นี้ |
| `session_mode` | ได้รับการแก้ไขแล้ว ทุ่มเทอย่างต่อเนื่อง ทุ่มเทชั่วคราว หรือ singleplayer/LAN วงจรชีวิต |
| `start_day_mode` | ตัวเลือกการเริ่มต้นที่กำหนดค่าหรือสุ่มครั้งเดียวสำหรับการรันใหม่ |
| `day_progression_mode` | ห่อความก้าวหน้าตามลำดับหรือไม่ซ้ำแบบสุ่ม |
| `day_order` | รหัสวันที่คงอยู่ซึ่งคั่นด้วยเครื่องหมายจุลภาคในลำดับที่แน่นอนที่จะเตรียมไว้ |
| `day_position` | ตำแหน่งของวันที่เตรียมไว้ใน `day_order`. |
| `updated_at` | เวลาเขียนในเครื่องสำหรับการเปรียบเทียบตัวดำเนินการ |

การเขียนสถานะจะยอมรับก็ต่อเมื่อเครื่องหมายสคีมา ตระกูลที่เตรียมไว้ และวันที่เตรียมไว้อ่านกลับอย่างถูกต้องเท่านั้น ไฟล์ปัจจุบันที่อ่านไม่ได้อาจถอยกลับไปอยู่ที่ `rotation_state.last_good.txt`; เครื่องหมายแซนด์บ็อกซ์ที่เลือกยังคงกำหนดว่าเกมจะโหลดอะไรสำหรับกระบวนการปัจจุบัน

<a id="runtime-status-json"></a>
## สถานะรันไทม์ JSON

`runtime/current/randomday_status.json` ใช้ `status_schema=randomday_runtime_status_v2`. กลุ่มฟิลด์หลักคือ:

| กลุ่ม | สาขาและการตีความ |
|---|---|
| ตัวตน | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| การเลือก | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| ใช้งานอยู่ | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| เตรียมพร้อม | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| บทสรุปของมนุษย์ | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| เขียนหลักฐาน | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| หลักฐานอะแดปเตอร์ | `adapter_status`, `adapter_results`; บันทึกอะแดปเตอร์แต่ละรายการมีหลักฐานความเข้ากันได้transaction/rollback สถานะ จำนวนไฟล์ที่เปลี่ยนแปลง และการอ้างอิงเป้าหมายที่ถูกแก้ไข |
| ขอบเขต | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| การวินิจฉัย | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

ค่าที่ใช้งานที่ไม่รู้จักหมายความว่าแซนด์บ็อกซ์ปัจจุบันไม่มีค่าที่สามารถอ่านได้ RandomDay เครื่องหมาย จะต้องไม่แทนที่ด้วยค่าที่เตรียมไว้ เส้นทางอะแดปเตอร์ภายนอก `runtime/` จะลดลงเป็นการอ้างอิงชื่อฐาน และสตริงการวินิจฉัยจะตรวจทานเส้นทางสัมบูรณ์ที่ตรวจพบ

<a id="public-status-json"></a>
## สถานะสาธารณะ JSON

`web_export/today.json` ใช้ `schema_version=2` และ `status_schema=randomday_public_status_v2`. มันซ้ำตัวตน active/prepared การเลือก ธุรกรรม อะแดปเตอร์ และข้อเท็จจริงขอบเขตการรีสตาร์ทที่ผู้ดำเนินการต้องการ และยังรวมถึง:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` ปัจจุบัน และ `prepared_day_position`;
- `family_selection_mode`, ดั้งเดิม `family_locked_until_day_17` ปัจจุบัน และ `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families` และการนับ;
- โปรไฟล์การเผชิญหน้าที่เตรียมไว้ ระดับ ธีม และโอกาสในการเผชิญหน้าแบบผสม
- การเปิดใช้งานขอบเขตโลก การตั้งค่าโลกเปิด นโยบายโลกที่ไม่รู้จัก และรูปแบบโลกที่ยกเว้นที่กำหนดค่าเพียงจำนวนหนึ่งเท่านั้น
- ข้อความที่เตรียมไว้และการแสดงตัวอย่างข้อความแบบรวม
- `selected_at`, `sandbox_target`, `manual_copy_required` และแฮชที่เตรียมไว้

`profile_status` เป็นหนึ่งใน `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` หรือ `write_failed_or_rollback`. `prepared_ready=true` ยังคงไม่ได้หมายความว่าใช้งานอยู่ จำเป็นต้องมีเครื่องหมายเริ่มต้นระบบในภายหลัง

<a id="dictionary-and-translation-output"></a>
## เอาต์พุตพจนานุกรมและการแปล

`runtime/current/randomday_dictionary.json` ใช้ `schema=randomday_runtime_dictionary_v2` และระบุเวอร์ชันพจนานุกรม `randomday_dictionary_v2`. โดยจะอธิบายโหมดแพ็กเกจ สถานะการเลือก โดเมนความดัน การตั้งค่าป้ายกำกับ ค่าดิบ และความหมายในภาษาธรรมดา ค่าที่ไม่รู้จักจะยังคงชัดเจนแทนที่จะแปลงเป็นคำอธิบายที่มั่นใจ

`player_message_preview.txt`, `today.json`, `today.html` และประกาศในเกมเป็นการดูที่ได้มาจากโมดูลการแปลเดียวกัน โปรไฟล์พื้นฐานและดิบ `SandboxSettings.ini` ยังคงเป็นแหล่งที่มาของความจริง

<a id="failure-and-recovery-rules"></a>
## กฎความล้มเหลวและการกู้คืน

1. การเขียนหรือการตรวจสอบที่รอดำเนินการล้มเหลวจะไม่กลายเป็นเป้าหมายการใช้งานจริง
2. การเลื่อนระดับหรือการอ่านกลับที่ใช้งานจริงที่ล้มเหลวจะกระตุ้นให้มีการเรียกคืนต้นฉบับที่เก็บไว้ การสำรองข้อมูลการดำเนินการเป็นทางเลือกเมื่อการคืนค่าล้มเหลว
3. ไฟล์ย้อนกลับที่เก็บไว้หรือ `rollback_failed` สถานะต้องมีการตรวจสอบโดยเจ้าหน้าที่ในขณะที่เกมหรือเซิร์ฟเวอร์หยุดทำงาน
4. การเขียนแซนด์บ็อกซ์ที่สำเร็จบวกกับการคอมมิตสถานะการหมุนที่ล้มเหลวถูกลดระดับลง ไม่พร้อม อะแดปเตอร์และการส่งข้อความโปรไฟล์ที่เตรียมไว้จะถูกข้ามไป
5. ความล้มเหลวในการส่งออกจะไม่เปลี่ยนผลลัพธ์ของแซนด์บ็อกซ์ แต่จะลบแหล่งพิสูจน์ความสะดวกออก ใช้บันทึกธุรกรรม สถานะ และการอ่านไฟล์
6. เอาต์พุตรันไทม์คือข้อมูลการปฏิบัติงานในเครื่อง อย่าเพิ่มลงในรุ่น ZIP หรือเผยแพร่เป็นตัวอย่างโดยไม่ต้องมีการตรวจสอบความเป็นส่วนตัวแยกต่างหาก
