# นโยบายความปลอดภัย

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [SECURITY.md](../../../SECURITY.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDay เขียนการกำหนดค่าเซิร์ฟเวอร์ และสามารถแก้ไขไฟล์การกำหนดค่า mod เสริมได้ ถือว่าการเปลี่ยนแปลงมีความละเอียดอ่อนในการปฏิบัติงาน

<a id="do-not-report-as-security-issues"></a>
## อย่ารายงานว่าเป็นปัญหาด้านความปลอดภัย

- การเปลี่ยนแปลงสมดุลการเล่นเกมปกติ
- คาดว่าจะมีการหมุนเวียนโปรไฟล์รีบูตครั้งถัดไป

<a id="report-privately"></a>
## รายงานแบบส่วนตัว

- ความเสี่ยงในการข้ามเส้นทาง
- พฤติกรรมการเขียนไฟล์ที่ไม่ปลอดภัย
- ความสามารถในการเขียนทับไฟล์ที่อยู่นอกเส้นทาง server/mod ที่ต้องการ
- การดำเนินการคำสั่งที่เป็นอันตราย

รายงานแบบส่วนตัวไปยังเจ้าของพื้นที่เก็บข้อมูลจนกว่าจะมีช่องสัญญาณความปลอดภัยสาธารณะ
