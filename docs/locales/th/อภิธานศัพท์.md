# อภิธานศัพท์

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [GLOSSARY.md](../../GLOSSARY.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


นี่คือคำศัพท์มาตรฐานสำหรับ RandomDay เอกสารประกอบ ขั้นตอนเชื่อมโยงกับคำจำกัดความเหล่านี้แทนที่จะกำหนดสถานะเดียวกันใหม่ในคำแนะนำหลายรายการ กฎฟิลด์เฉพาะสคีมายังคงอยู่ใน [เอาต์พุตรันไทม์](%E0%B9%80%E0%B8%AD%E0%B8%B2%E0%B8%95%E0%B9%8C%E0%B8%9E%E0%B8%B8%E0%B8%95%E0%B8%A3%E0%B8%B1%E0%B8%99%E0%B9%84%E0%B8%97%E0%B8%A1%E0%B9%8C.md).

| Term | ความหมายธรรมดา | ความหมายทางเทคนิคที่แน่นอน |
|---|---|---|
| โปรไฟล์ที่ใช้งานอยู่ | กฎที่เซสชันปัจจุบันใช้ | แพ็คเกจ family/day โปรไฟล์ที่ระบุโดย RandomDay เครื่องหมายอ่านจากแซนด์บ็อกซ์เมื่อเริ่มต้นกระบวนการ |
| โปรไฟล์ที่เตรียมไว้ | กฎพร้อมสำหรับเซสชันในภายหลัง | โปรไฟล์ family/day ที่สมบูรณ์ซึ่งมีไบต์เป้าหมายผ่านการตรวจสอบความถูกต้องและการอ่านกลับ และมีสถานะการหมุนที่ถูกกำหนดไว้ จะไม่ทำงานก่อนที่จะรีสตาร์ทการอ่านอีกครั้ง |
| กู้คืนแล้ว | การเตรียมการล้มเหลวและไบต์ที่ตรวจสอบแล้วก่อนหน้านี้ถูกใส่กลับ | ธุรกรรมที่ล้มเหลวรายงานการย้อนกลับและการอ่านกลับที่ประสบความสำเร็จของสำเนาการกู้คืนต้นฉบับหรือที่ตรวจสอบแล้วที่เก็บไว้ |
| คิวการรีบูตครั้งถัดไป | ตัวเลือกหนึ่งที่เตรียมไว้สำหรับการบูตครั้งถัดไป | `next_reboot_queue` เลือกหนึ่งครั้งต่อกระบวนการและนำตัวเลือกที่เป็นเจ้าของการบูตมาใช้ซ้ำในระหว่าง การกำกับดูแล |
| Bootstrap | การเตรียมการครั้งแรกเมื่อไม่มีเครื่องหมายที่ใช้งานอยู่ | การเลือกวันแรกที่กำหนดค่าหรือสุ่มจากตระกูลที่มีสิทธิ์ `cycle.bootstrap_day` เป็นเพียงทางเลือกที่เข้ากันได้เท่านั้น |
| ครอบครัว | ความก้าวหน้าของสไตล์การเล่น 17 วัน | หนึ่งรายการรีจิสทรีและโมดูลตระกูลที่สร้างโปรไฟล์ที่สมบูรณ์ 17 โปรไฟล์ |
| การหมุน | การส่งผ่านตระกูลที่มีสิทธิ์ | สถานะที่ระบุโดย `rotation_id` พร้อมด้วยรายการครอบครัวที่มีอยู่ เหลือ และเสร็จสมบูรณ์ |
| เรียกใช้ | หนึ่งครอบครัวจาก ID 17 วันทั้งหมด | ลำดับที่ผูกมัดโดยครอบครัวที่ระบุโดย `run_id`; ครอบครัวยังคงถูกล็อคจนกว่าทุกตำแหน่งการสั่งซื้อรายวันที่คงอยู่จะเสร็จสมบูรณ์ |
| โหมดเซสชัน | วิธีที่ผู้ดำเนินการใช้แพ็คเกจนี้ | `persistent_dedicated`, `temporary_dedicated` หรือ `singleplayer_lan`; โหมดแพ็คเกจยังคงควบคุมขอบเขตของระบบไฟล์ |
| ลำดับวัน | ลำดับที่แน่นอนที่ใช้โดยหนึ่งครอบครัว | การเรียงสับเปลี่ยน 17 หมายเลขที่คงอยู่ โหมดต่อเนื่องจะสิ้นสุดตั้งแต่วันเริ่มต้น โหมดสุ่มจะสับเปลี่ยนหนึ่งครั้งโดยไม่มีการทำซ้ำ |
| เครื่องหมาย | ข้อมูลประจำตัวที่จัดเก็บไว้ในไฟล์แซนด์บ็อกซ์ | `RANDOMDAY_*` ฟิลด์แสดงผลด้วยโปรไฟล์ที่สมบูรณ์และอ่านเมื่อเริ่มต้นกระบวนการครั้งถัดไป |
| เตรียมพร้อมแล้ว | การเขียนและสถานะคอมมิตสำเร็จ | `prepared_ready=true` ต้องการผลลัพธ์แซนด์บ็อกซ์ที่สำเร็จ และไม่มีความล้มเหลวในการดำเนินการของรัฐ มันไม่ได้พิสูจน์การเปิดใช้งาน |
| ปัจจุบันแล้ว | เป้าหมายมีไบต์ที่ต้องการแล้ว | แฮชของโปรไฟล์ที่แสดงผลตรงกับเป้าหมาย ดังนั้น RandomDay ตรวจสอบ last-good/mirror ทำงานโดยไม่ต้องเขียนหลักใหม่ |
| ความคงอยู่ของสถานะลดลง | ไบต์ของแซนด์บ็อกซ์สำเร็จ แต่การทำบัญชีแบบหมุนเวียนไม่สำเร็จ | `profile_status=degraded_state_persistence`; อะแดปเตอร์และการส่งข้อความโปรไฟล์ที่เตรียมไว้จะถูกข้ามไป |
| ไฟล์ที่รอดำเนินการ | ไบต์ของผู้สมัครที่ยังไม่ได้เลื่อนระดับ | `<target>.randomday.pending` เขียน อ่านกลับ และตรวจสอบความถูกต้องก่อนแทนที่ |
| ไฟล์ย้อนกลับ | ต้นฉบับถูกเก็บไว้ระหว่างการเปลี่ยน | `<target>.randomday.rollback` ใช้เพื่อกู้คืนการใช้งานจริงเมื่อโปรโมชันหรือการตรวจสอบล้มเหลว |
| การสำรองข้อมูลการดำเนินการ | สำเนาถาวรที่ทำก่อนการเปลี่ยนแปลง | ไฟล์ที่ได้รับการยืนยันภายใต้ `runtime/backups/` สำหรับธุรกรรมหลัก มิเรอร์ หรืออะแดปเตอร์ |
| สินค้าที่ทราบล่าสุด | แซนด์บ็อกซ์ล่าสุดที่ยอมรับสำหรับการกู้คืน | `runtime/last_good/SandboxSettings.ini` บวก `manifest.lua`; ทั้งคู่บันทึกข้อมูลประจำตัวของโปรไฟล์และแฮช |
| กระจก | เป้าหมายแซนด์บ็อกซ์ที่สองที่เป็นตัวเลือก | เป้าหมายที่ได้รับการกำหนดค่าอย่างชัดเจนหรือมาจากชื่อโลกที่เขียนหลังจากเป้าหมายหลักผ่านธุรกรรมของตัวเอง |
| โหมดแพ็คเกจ | ติดตั้งขอบเขตที่เลือกโดยเนื้อหาที่เผยแพร่ | `dedicated_server` หรือ `singleplayer_manual` จาก `.randomday_mode`. |
| โหมดการคัดลอกด้วยตนเอง | Singleplayer/LAN การสร้างโดยไม่ต้องบันทึกการค้นพบ | `singleplayer_manual` เขียนเฉพาะภายใน `runtime/singleplayer_manual/` และปิดการใช้งานอะแดปเตอร์และมิเรอร์ |
| อะแดปเตอร์ | RandomDay-owned การแมปสำหรับ mod อื่นที่ติดตั้งไว้ | แผนธุรกรรมที่มีลายเซ็นซึ่งอัปเดตการมอบหมายที่มีอยู่หลังจากการตรวจสอบการสำรองข้อมูลและความเข้ากันได้เท่านั้น |
| รูปแบบที่ได้รับการยอมรับ | รูปแบบไฟล์อะแดปเตอร์ที่แน่นอนได้รับการยอมรับสำหรับการเขียน | มีคีย์ลายเซ็นและไฟล์เป้าหมายที่จำเป็นทั้งหมด ชื่อไฟล์เพียงอย่างเดียวไม่เพียงพอ |
| `not_installed` | ไม่พบเป้าหมายเพิ่มเติม | ผลลัพธ์ของอะแดปเตอร์ที่ปลอดภัยโดยไม่มีการเปลี่ยนแปลง |
| `skipped_incompatible` | มีเป้าหมายอยู่แล้ว แต่ไม่รองรับรูปร่าง | ผลลัพธ์ของอะแดปเตอร์ที่ปลอดภัยโดยไม่มีการเปลี่ยนแปลงเนื่องจากลายเซ็นที่สมบูรณ์ไม่ตรงกัน |
| `failed_rolled_back` | การเปลี่ยนแปลงล้มเหลวและไบต์ก่อนหน้าไม่เสียหาย | ธุรกรรมของอะแดปเตอร์ล้มเหลวก่อนการเปลี่ยนแปลงหรือไฟล์ที่ได้รับผลกระทบทั้งหมดได้รับการกู้คืนและตรวจสอบแล้ว |
| `rollback_failed` | ไม่สามารถตรวจสอบการกู้คืนอัตโนมัติได้ | สถานะอแด็ปเตอร์ฮาร์ดสต็อปจำเป็นต้องมีการกู้คืนด้วยตนเองจากข้อมูลสำรองที่บันทึกไว้ |
| พจนานุกรม | การจับคู่จากค่าดิบไปยังคำอธิบายสาธารณะ | `randomday_dictionary_v2` สร้างจาก `dictionary.lua` และรวมอยู่ในเอาต์พุตสถานะรันไทม์ |
| การแปล | มุมมองของมนุษย์ได้มาจากค่าโปรไฟล์ดิบ | คะแนนโดเมนที่ถูกผูกไว้ ข้อเท็จจริง สรุป และข้อความที่สร้างโดย `translation.lua`; ค่าดิบยังคงเชื่อถือได้ |
| สถานะสาธารณะ | สรุปผู้ปฏิบัติงานที่เครื่องอ่านได้ที่ผ่านการฆ่าเชื้อแล้ว | `web_export/today.json` โดยใช้ `randomday_public_status_v2`. |
| สถานะรันไทม์ | สแนปชอตโดยละเอียดที่เครื่องอ่านได้ | `runtime/current/randomday_status.json` โดยใช้ `randomday_runtime_status_v2`. |
