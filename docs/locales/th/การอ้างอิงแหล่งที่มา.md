# การอ้างอิงแหล่งที่มาแบบแพ็กเกจ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


การเปิดตัว ZIP มี 51 เส้นทางด้านล่างทุกประการ ตัวสร้างปฏิเสธเส้นทางที่ขาดหายไป แหล่งที่มาในรูปแบบแพ็คเกจเพิ่มเติม การชนกันของเคส ลิงก์สัญลักษณ์ หรือสมาชิกที่อยู่นอกรายการที่อนุญาตตามตัวอักษร รันไทม์เอาต์พุต การทดสอบ เอกสารที่เก็บ และม็อดของบริษัทอื่นไม่ใช่สมาชิกของแพ็คเกจ

ตัวช่วยที่ตรวจสอบด้วยเครื่องได้คือ [`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json). โดยจะบันทึกเส้นทางเดียวกันกับอินพุต เอาท์พุต ผลข้างเคียง การตั้งค่าสาธารณะ สถานะที่มองเห็นได้ โหมดความล้มเหลว การแก้ไขได้ และเอกสารประกอบตามรูปแบบบัญญัติ

ทุกแถว Lua ที่จัดส่งจะมีจุดยึด `module-*` ที่เสถียรหนึ่งอัน ลิงก์ที่เหมือนกันในส่วนหัวต้นทาง Canonical และบันทึกของเครื่องทำให้ความเป็นเจ้าของ สัญญา ผลข้างเคียง ความล้มเหลว และการกู้คืนสามารถตรวจสอบย้อนกลับได้โดยตรง
