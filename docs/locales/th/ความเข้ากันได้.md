# ความเข้ากันได้

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [COMPATIBILITY.md](../../COMPATIBILITY.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


<a id="supported-installations"></a>
## การติดตั้งที่รองรับ

RandomDay ถูกสร้างขึ้นสำหรับการติดตั้ง Abiotic Factor ที่สามารถโหลด UE4SS Lua mods

| สภาพแวดล้อม | การสนับสนุน | แพ็คเกจ |
| --- | --- | --- |
| เซิร์ฟเวอร์เฉพาะของ Windows | รองรับ | Dedicated-server ZIP |
| Windows singleplayer หรือ LAN host | เวิร์กโฟลว์การคัดลอกด้วยตนเองที่รองรับ | Singleplayer/LAN ZIP |
| เซิร์ฟเวอร์ Linux ที่ใช้ Wine หรือ Proton | ไม่ใช่ ผ่านการทดสอบการเปิดตัว | แพ็คเกจเฉพาะสำหรับ Windows อาจได้รับการประเมินโดยผู้ให้บริการที่มีประสบการณ์ แต่ไม่มีการรับประกันความเข้ากันได้ |
| Xbox และ PlayStation | ไม่รองรับ | แพลตฟอร์มเหล่านี้ไม่ได้ให้การเข้าถึงไฟล์และ UE4SS พาธการโหลด Lua ที่จำเป็นสำหรับรีลีสนี้ |

RandomDay ไม่รวมทั้งสองแพ็คเกจ เซิร์ฟเวอร์เฉพาะที่เริ่มต้นสำหรับการเล่นเป็นครั้งคราวเท่านั้น ยังคงใช้เซิร์ฟเวอร์เฉพาะ ZIP และเลือกลักษณะการทำงานชั่วคราวในการกำหนดค่า

<a id="abiotic-factor-updates"></a>
## การอัปเดตปัจจัยทางชีวะ

หลังการอัปเดตเกม ให้เริ่มต้นด้วยการที่เซิร์ฟเวอร์หยุดทำงานและเก็บสำเนาของโลกที่สามารถกู้คืนได้ `SandboxSettings.ini` ปัจจุบัน และ RandomDay สถานะ ยืนยันการโหลด UE4SS จากนั้นดำเนินการ RandomDay หนึ่งรอบ และตรวจสอบทั้งโปรไฟล์ที่ใช้งานอยู่และโปรไฟล์ที่เตรียมไว้ก่อนที่จะดำเนินการหมุนตามปกติต่อ

<a id="companion-mods"></a>
## ตัวดัดแปลงสหาย

RandomDay เปลี่ยน mod ที่ติดตั้งแยกต่างหากเฉพาะเมื่อเค้าโครงการตั้งค่าที่สมบูรณ์ตรงกับอะแดปเตอร์ที่รองรับเท่านั้น หมายเลขเวอร์ชันเพียงอย่างเดียวนั้นไม่เพียงพอ

| บูรณาการ | ตรวจสอบเวอร์ชันปัจจุบันแล้ว | RandomDay ขอบเขตการสนับสนุน |
| --- | --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | `0.8.5`; ไฟล์หลัก`0.8.5-Hotfix1` | ที่รองรับ `SharedData.lua` รูปแบบครอบคลุมการวางไข่ คูลดาวน์ จำนวนประชากร พอร์ทัล การละเมิด บอส และ RandomDay พบการตั้งค่าที่แสดงอยู่ในการอ้างอิงอะแดปเตอร์ |
| เลเซอร์สังหาร | `1.0-UE4SS` | ที่รองรับ `Scripts/main.lua` เค้าโครงครอบคลุมการตั้งค่าตัวปล่อยที่ได้รับการยอมรับ ตัวส่งสัญญาณสิ่งแวดล้อม ตัวสะท้อนแสง และปริซึม |
| ANTE ขึ้น | `1` อัปเดตเมื่อวันที่ 19 กรกฎาคม 2026 | โครงร่างสาธารณะในปัจจุบันยังไม่เสร็จสิ้นการติดตั้งอะแด็ปเตอร์ RandomDay ข้ามไฟล์ที่ไม่ตรงกันโดยไม่มีการเปลี่ยนแปลงจนกว่าโครงร่างนั้นจะได้รับการตรวจสอบ |

ตัวดัดแปลงที่แสดงร่วมที่หายไป ปิดใช้งาน หรือไม่รู้จักจะไม่มีการเปลี่ยนแปลง ดู [ตัวดัดแปลงเสริมที่รองรับ](%E0%B8%AD%E0%B8%B0%E0%B9%81%E0%B8%94%E0%B8%9B%E0%B9%80%E0%B8%95%E0%B8%AD%E0%B8%A3%E0%B9%8C%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B8%A3%E0%B8%AD%E0%B8%87%E0%B8%A3%E0%B8%B1%E0%B8%9A.md) สำหรับการตั้งค่า การควบคุมการกำหนดค่า ลักษณะการสำรองข้อมูล และขั้นตอนการกู้คืนที่แน่นอน

<a id="what-compatibility-validation-proves"></a>
## สิ่งที่พิสูจน์ได้จากการตรวจสอบความเข้ากันได้

การตรวจสอบความถูกต้องของพื้นที่เก็บข้อมูลสามารถพิสูจน์โครงร่างแพ็คเกจที่จัดส่ง ความครอบคลุมของการกำหนดค่า ฟิลด์อะแด็ปเตอร์ที่ได้รับการยอมรับ ลักษณะการทำงานในการสำรองและกู้คืน และการปฏิเสธโครงร่างที่ไม่รู้จักอย่างปลอดภัย ไม่สามารถพิสูจน์ Abiotic Factor ในอนาคตทั้งหมด UE4SS หรือเวอร์ชัน Companion-Mod ได้ บันทึกประจำรุ่นชื่อเวอร์ชันที่ทดสอบแทนที่จะสันนิษฐานว่าเข้ากันได้จากการโหลดที่สำเร็จ
