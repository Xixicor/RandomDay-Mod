# การอ้างอิงสถานะและข้อผิดพลาด

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


ใช้ค่า `status`, `transaction_status`, `rollback_status` ปัจจุบัน และ `error` ที่แน่นอนจากการส่งออกรันไทม์ ข้อความที่คล้ายกันในแผงหรือคอนโซลไม่สามารถทดแทนฟิลด์เหล่านั้นได้

ส่วนนี้เป็นการอ้างอิงการค้นหาที่สมบูรณ์ แผนผังการตัดสินใจด้านบนเลือกหมวดหมู่ที่เกี่ยวข้อง ตารางเหล่านี้จะรักษาค่าเครื่องจักรที่แน่นอนและการตอบสนองของผู้ปฏิบัติงานที่ปลอดภัย

<a id="normal-or-informational-states"></a>
## สถานะปกติหรือเป็นข้อมูล

| สถานะ | ความหมาย | การตอบสนองของผู้ปฏิบัติงาน |
|---|---|---|
| `prepared_for_next_reboot` | โปรไฟล์ที่ได้รับการตรวจสอบแล้วถูกเขียนสำหรับการบูตครั้งถัดไป | ไม่มีการดำเนินการ; เซสชันปัจจุบันไม่มีการเปลี่ยนแปลง |
| `next_reboot_already_prepared` | โปรไฟล์ถัดไปที่ต้องการตรงกับเป้าหมายแล้ว | ไม่มีการดำเนินการ; อย่าบังคับให้หมุนอีกครั้ง |
| `already_current` / `unchanged` | เป้าหมายมีไบต์ที่ต้องการอยู่แล้ว | ไม่มีการดำเนินการ |
| `applied` | การอ่านกลับการเขียนและการผลิตผ่านไปแล้ว | ตรวจสอบความแตกต่าง active/prepared หลังจากการบูตครั้งถัดไป |
| `bootstrap_prepare_first_family_start_day` | ไม่มีสถานะการหมุนก่อนหน้า ดังนั้นการกำหนดค่า เตรียมวันแรกแล้ว | คาดว่าจะได้รับเมื่อใช้ครั้งแรก |
| `state_recovery_rewrite_prepared_profile_no_reroll` | สถานะที่จัดเก็บได้รับการกู้คืนแล้ว และโปรไฟล์ที่เตรียมไว้เหมือนกันถูกเขียนใหม่ | ตรวจสอบวันที่กู้คืน ไม่มีตัวเลือกสุ่มใหม่เกิดขึ้น |
| `supervision_reconfirm_prepared_profile_no_advance` | ผ่านการควบคุมดูแลยืนยันการเตรียมการที่มีอยู่ | คาดหวัง; คิวไม่เลื่อนไปสองครั้ง |
| `external_mods_disabled` | การประมวลผลอแด็ปเตอร์เสริมถูกปิดใช้งาน | ไม่มีการดำเนินการใดๆ ยกเว้นว่าตั้งใจจะให้อะแดปเตอร์ |
| `external_mods_processed` | แผนอะแด็ปเตอร์ที่เปิดใช้งานทั้งหมดไปถึงผลลัพธ์เทอร์มินัล | ตรวจสอบแต่ละแถวของอะแดปเตอร์ |

<a id="startup-configuration-errors"></a>
## ข้อผิดพลาดในการกำหนดค่าการเริ่มต้นระบบ

ข้อความเหล่านี้หยุดเริ่มต้นก่อนที่ RandomDay จะเขียนโปรไฟล์ แก้ไขการตั้งค่าที่มีชื่อหรือเครื่องหมายแพ็คเกจ อย่าข้ามสาขาการตรวจสอบ

| ข้อความแสดงข้อผิดพลาด | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` หายไป มีรูปแบบไม่ถูกต้อง หรือมาจากแพ็คเกจที่ไม่ถูกต้อง | ติดตั้งแพ็คเกจที่สมบูรณ์หนึ่งแพ็คเกจอีกครั้งในโฟลเดอร์ staging ที่สะอาดและรักษาตัวทำเครื่องหมายโหมดที่ต้องการไว้ |
| `invalid experience.mode` | `experience.mode` ไม่ใช่หนึ่งในค่าที่บันทึกไว้ | ใช้ `auto`, `persistent_dedicated`, `temporary_dedicated` หรือ `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | แพ็คเกจการคัดลอกด้วยตนเองคือ กำหนดค่าเป็นเซิร์ฟเวอร์เฉพาะ | กู้คืน `auto` หรือ `singleplayer_lan`; อย่าชี้ไปที่โลกภายนอกโดยอัตโนมัติ |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | แพ็คเกจเฉพาะได้รับการกำหนดค่าสำหรับเวิร์กโฟลว์การคัดลอกด้วยตนเอง | ใช้ `auto`, `persistent_dedicated` หรือ `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | ตัวเลือกวันแรกไม่ถูกต้อง | ใช้ทุกประการ `configured` หรือ `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | ตัวเลือกลำดับวันไม่ถูกต้อง | ใช้ทุกประการ `sequential` หรือ `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | วันเริ่มต้นที่กำหนดค่าไว้เป็นเศษส่วนหรืออยู่นอก วนรอบ | ใช้ตัวเลขทั้งหมดตั้งแต่ 1 ถึง `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | การสำรองข้อมูลหรือการกู้คืนล่าสุดถูกปิดใช้งาน | กู้คืนล็อคนิรภัยทั้งสองอัน RandomDay จงใจปฏิเสธการเขียนที่ไม่ปลอดภัย |
| `external adapter transaction safety locks must remain true` | การแพตช์อะแดปเตอร์หรือการป้องกันการสำรองข้อมูลถูกปิดใช้งาน | เรียกคืนทั้งการล็อคความปลอดภัยของอะแดปเตอร์หรือปิดใช้งานอะแดปเตอร์เป็นกลุ่ม |
| `paths.world_name must be one folder name` | ชื่อโลกที่กำหนดค่ามีตัวคั่นหรืออักขระที่ไม่ปลอดภัย | ป้อนเฉพาะชื่อโฟลเดอร์ที่แน่นอน โดยใช้ตัวอักษร ตัวเลข ช่องว่าง ขีดล่างหรือขีดกลาง |
| `required runtime directory unavailable` | ไม่สามารถสร้างหรือยืนยันไดเร็กทอรีเอาต์พุต mod-local ที่จำเป็นได้ | ตรวจสอบเฉพาะไดเร็กทอรี RandomDay ที่มีชื่อและการอนุญาตในการเขียน |

<a id="profile-wide-configuration-errors"></a>
## ข้อผิดพลาดในการกำหนดค่าทั้งโปรไฟล์

ข้อผิดพลาดเหล่านี้หยุดการสร้างโปรไฟล์ก่อนที่จะเขียนแซนด์บ็อกซ์

| ข้อความแสดงข้อผิดพลาด | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `sandbox.profile_overrides must be a table` | ตัวเลือกทั้งสี่โปรไฟล์ถูกแทนที่ด้วย Lua ประเภทอื่น | กู้คืนตารางเอกสารใน `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | ตารางประกอบด้วยการตั้งค่าที่ไม่ใช่หนึ่งในสี่คีย์ที่รองรับ | ลบคีย์ที่มีชื่อและใช้ family/profile แหล่งที่มาสำหรับการตั้งค่า Sandbox อื่น ๆ |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` หรือ `AllowIronMode` ไม่ใช่ `true` หรือ `false`. | ใช้ Lua boolean ที่ไม่มีเครื่องหมายคำพูด |
| `sandbox.profile_overrides.<key> must be integer` | ค่ารองรับไม่ใช่จำนวนเต็ม | ใช้จำนวนเต็ม |
| `sandbox.profile_overrides.<key> outside supported range` | ค่ารองรับอยู่นอก `0..1000`. | เลือกจำนวนเต็มจาก `0` ถึง `1000`. |

<a id="rollback-and-intermediate-states"></a>
## ย้อนกลับและค่ากลาง ระบุ

| ค่า | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `not_started` / `pending` | ธุรกรรมหรือแผนอะแดปเตอร์ยังไม่ถึงผลลัพธ์เทอร์มินัล | รอเฉพาะบัตรผ่านการเริ่มต้นระบบที่มีขอบเขตในปัจจุบันเท่านั้น สถานะคงอยู่จำเป็นต้องมีการตรวจสอบ |
| `not_needed` | ไม่จำเป็นต้องย้อนกลับ | ไม่มีการดำเนินการ |
| `original_held` | เป้าหมายเดิมถูกย้ายไปยังตำแหน่งการกู้คืนก่อนที่จะเลื่อนตำแหน่ง | อย่าลบไฟล์การกู้คืนในขณะที่ธุรกรรมไม่สมบูรณ์ |
| `retained_after_success` | เป้าหมายใหม่ได้รับการยืนยัน แต่ข้อมูลการกู้คืนยังคงอยู่เนื่องจากการล้างข้อมูลไม่พร้อมใช้งานหรือตั้งใจเก็บไว้ | ตรวจสอบไบต์ที่ใช้งานจริงก่อนที่จะลบไฟล์การกู้คืนที่มีชื่อใดๆ |
| `discarded_after_success` | ข้อมูลการแทนที่ที่ได้รับการยืนยันและข้อมูลการย้อนกลับชั่วคราวถูกล้างแล้ว | ไม่มีการดำเนินการ |
| `rollback_failed` | ไม่สามารถตรวจสอบการพยายามกู้คืนได้ | ทำให้เซิร์ฟเวอร์หยุดทำงานและใช้การสำรองข้อมูลการดำเนินการที่ตรวจสอบครั้งล่าสุด |
| `skipped_state_persistence_failed` | ไบต์ของแซนด์บ็อกซ์ได้รับการจัดเตรียมไว้แล้ว แต่สถานะการหมุนไม่คงอยู่ ดังนั้น อะแดปเตอร์และการส่งข้อความของผู้เล่นที่เตรียมไว้ถูกข้ามไป | ซ่อมแซมที่เก็บข้อมูลสถานะรันไทม์ อย่าหมุนซ้ำหรือเลื่อนคิวด้วยตนเอง |
| `failed` | แถวสรุปแสดงถึงความล้มเหลวของเทอร์มินัลซึ่งมีสาเหตุเฉพาะอยู่ใน `error` หรือฟิลด์ธุรกรรม | ทำตามโค้ดเฉพาะตัวแรก อย่าแก้ไขปัญหาจาก `failed` เพียงอย่างเดียว |

<a id="transaction-failures"></a>
## ความล้มเหลวในการทำธุรกรรม

| สถานะ | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `invalid_input` | คำขอเปลี่ยนไม่ใช่ข้อความที่ถูกต้องหรือขาดเป้าหมายที่ถูกต้อง | การกำหนดค่าที่ถูกต้อง อย่าลองอีกครั้งโดยไม่เปลี่ยนแปลง |
| `stale_pending_cleanup_failed` | ไม่สามารถลบไฟล์เก่าที่ค้างอยู่ได้ | หยุดและรักษาไฟล์ที่ค้างอยู่ก่อนที่จะล้างข้อมูลด้วยตนเอง |
| `stale_rollback_requires_review` | ข้อมูลการกู้คืนมีอยู่ข้างเป้าหมายปัจจุบันและไม่สามารถทิ้งได้อย่างปลอดภัย | เปรียบเทียบไบต์เป้าหมายและไบต์ย้อนกลับก่อนเลือกอย่างใดอย่างหนึ่ง |
| `interrupted_transaction_restore_failed` | การกู้คืนหลังจากการแทนที่ที่ถูกขัดจังหวะไม่สามารถกู้คืนเป้าหมายได้ | ทำให้เซิร์ฟเวอร์หยุดทำงานและกู้คืนการสำรองข้อมูลที่ได้รับการยืนยัน |
| `interrupted_transaction_cleanup_failed` | เป้าหมายได้รับการกู้คืนแล้ว แต่ข้อมูลธุรกรรมเก่าไม่สามารถล้างได้ | ตรวจสอบไบต์เป้าหมาย จากนั้นลบเฉพาะ sidecar เก่าที่มีชื่อ |
| `pending_write_failed` | ผู้สมัครไม่สามารถ เขียนแล้ว | ตรวจสอบไดเรกทอรีเป้าหมายที่แคบและพื้นที่ว่าง |
| `pending_readback_failed` / `pending_readback_mismatch` | ไม่สามารถอ่านหรือเปลี่ยนแปลงไบต์ของผู้สมัครได้หลังจากเขียน | อย่าเลื่อนระดับไฟล์ที่รอดำเนินการ |
| `pending_validation_failed` | ผู้สมัครล้มเหลว schema/profile การตรวจสอบก่อนที่จะเลื่อนตำแหน่ง | แก้ไข คีย์หรือกฎที่รายงาน อย่าข้ามการตรวจสอบ |
| `operation_backup_failed` / `backup_failed` | ไม่ได้สร้างการสำรองข้อมูลก่อนเขียนที่ได้รับการยืนยัน | หยุด; ไม่ควรเชื่อถือการแทนที่เป้าหมาย |
| `original_preserved_move_failed` | เป้าหมายเดิมไม่สามารถย้ายไปยังตำแหน่งการกู้คืนได้ | เก็บไฟล์ธุรกรรมทั้งหมดและกู้คืนด้วยตนเอง |
| `promotion_failed` | ผู้สมัครที่รอดำเนินการไม่สามารถกลายเป็นเป้าหมายการผลิตได้ | ตรวจสอบว่าต้นฉบับได้รับการกู้คืนหรือไม่ก่อนที่จะลองอีกครั้ง |
| `production_validation_failed` | ไบต์ที่เลื่อนระดับล้มเหลวในการผลิต readback/validation. | กู้คืนข้อมูลสำรองที่ได้รับการยืนยันและตรวจสอบผู้เขียนเป้าหมาย |
| `replacement_committed_recovery_cleanup_failed` | การแทนที่นั้นถูกต้อง แต่ข้อมูลการย้อนกลับไม่สามารถล้างได้ | ปฏิบัติต่อเป้าหมายตามที่คอมมิต; ลบเฉพาะข้อมูลการกู้คืนเก่าที่ตรวจสอบแล้ว |
| `rollback_failed` | การกู้คืนอัตโนมัติไม่ได้ตรวจสอบ | ให้เซิร์ฟเวอร์หยุดทำงานและใช้การกู้คืนด้วยตนเอง |

<a id="target-profile-adapter-and-export-failures"></a>
## เป้าหมาย โปรไฟล์ อะแดปเตอร์ และความล้มเหลวในการส่งออก

| สถานะ | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `target_refused` | เส้นทางที่กำหนดค่าอยู่นอกขอบเขตโหมดที่อนุญาต | แก้ไขเส้นทาง อย่าทำให้ขอบเขตอ่อนแอลง |
| `target_directory_failed` | ไม่สามารถสร้างหรือยืนยันไดเรกทอรีเป้าหมายได้ | ตรวจสอบเฉพาะการมีอยู่และการอนุญาตของไดเรกทอรีนั้นเท่านั้น |
| `profile_validation_failed` | โปรไฟล์ไม่มีคีย์ มีผิด type/range หรือละเมิดกฎคงที่ที่เหลืออยู่ | ใช้คีย์ที่มีชื่อ `sandbox.profile_overrides` และการอ้างอิงโปรไฟล์เพื่อซ่อมแซมแหล่งที่มา |
| `skipped_incompatible` | มี mod เสริมอยู่ แต่ไม่ตรงกับลายเซ็นของอะแดปเตอร์ที่รองรับ | ปล่อยไว้ไม่เปลี่ยนแปลงหรือปิดการใช้งานอะแดปเตอร์นั้น |
| `external_mods_partial` | อะแดปเตอร์เสริมบางตัวเสร็จสมบูรณ์แล้วและตัวอื่น ๆ ได้รับความปลอดภัย skipped/failed. | ตรวจสอบแถวของอะแดปเตอร์อย่างอิสระ ผลลัพธ์แซนด์บ็อกซ์จะแยกจากกัน |
| `external_adapter_failed` | อแด็ปเตอร์ที่จำเป็นไม่เสร็จสมบูรณ์อย่างปลอดภัย | คืนค่าการสำรองข้อมูลที่ได้รับการยืนยันก่อนที่จะลองอีกครั้ง |
| `degraded_state_persistence` | การเตรียมแซนด์บ็อกซ์เสร็จสมบูรณ์ แต่การคงอยู่ของสถานะการหมุนไม่สามารถทำได้ | อย่าถือว่าการบูตครั้งถัดไปสามารถดำเนินการได้อย่างถูกต้อง ซ่อมแซมที่เก็บข้อมูลสถานะ |
| `export_directory_failed` | `web_export/` ไม่สามารถสร้างหรือเขียนได้ | การเตรียมการเล่นเกมอาจยังคงใช้ได้ รายงานการซ่อมแซมแยกกัน |

<a id="translation-and-message-validation-errors"></a>
## ข้อผิดพลาดในการแปลและการตรวจสอบความถูกต้องของข้อความ

สิ่งเหล่านี้คือความล้มเหลวในพจนานุกรมหรือการนำเสนอในสัญญา ได้รับการตรวจสอบก่อนเผยแพร่และอาจปรากฏเป็นคำเตือนสถานะรันไทม์แบบมีขอบเขต

| ข้อความแสดงข้อผิดพลาด | ความหมาย | การตอบสนองอย่างปลอดภัย |
|---|---|---|
| `dictionary coverage mismatch` | พจนานุกรมโปรไฟล์ไม่ได้อธิบายการตั้งค่าที่บันทึกไว้ทุกรายการ | เพิ่มรายการพจนานุกรมที่ขาดหายไปและรันโปรไฟล์อีกครั้ง generation/validation. |
| `missing profile setting` | โปรไฟล์ที่เลือกขาดการตั้งค่าที่จำเป็นสำหรับ dictionary/schema. | ซ่อมแซมแหล่งที่มาของตระกูลโปรไฟล์ อย่าสร้างค่าเริ่มต้นรันไทม์ |
| `empty explanation` | มีการตั้งค่า แต่ไม่มี operator/player คำอธิบาย | เพิ่มคำอธิบายแบบธรรมดาก่อนเผยแพร่ |
| `join line too wide` | บรรทัดการรวมที่สร้างขึ้นเกินขีดจำกัดแหล่งที่มา 42 อักขระ | ย่อวลีพจนานุกรม ไม่ต้องพึ่งพาการห่อไคลเอ็นต์ |
| `join message too tall` | สรุปการรวมที่สร้างขึ้นมีความยาวเกินสี่บรรทัด | ลดหรือจัดลำดับความสำคัญของเนื้อหาข้อความใหม่ |
