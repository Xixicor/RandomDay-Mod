# เริ่มต้นที่นี่: กรอกครั้งแรก RandomDay รอบ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [START_HERE.md](../../START_HERE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


คำแนะนำนี้เริ่มต้นหลังจากติดตั้ง RandomDay แล้ว โดยจะแสดงสิ่งที่ mod เปลี่ยนแปลง สิ่งที่ปล่อยให้อยู่คนเดียว และวิธีการจดจำหนึ่งรอบที่ประสบความสำเร็จ

<a id="know-the-two-states"></a>
## รู้จักสถานะทั้งสอง

Abiotic Factor อ่านการตั้งค่าแซนด์บ็อกซ์ของโลกก่อนที่ RandomDay จะเริ่มทำงาน RandomDay ดังนั้น จึงเก็บสถานะที่มีชื่อไว้อย่างชัดเจนสองสถานะ:

- **โปรไฟล์ที่ใช้งานอยู่:** กฎที่เซสชันปัจจุบันใช้อยู่แล้ว
- **โปรไฟล์ที่เตรียมไว้:** กฎที่บันทึกไว้สำหรับการเริ่มต้นครั้งต่อไป

โปรไฟล์ที่เตรียมไว้จะไม่เปลี่ยนเซสชันที่กำลังดำเนินการอยู่

<a id="dedicated-server-prepare-the-next-profile"></a>
## เซิร์ฟเวอร์เฉพาะ: เตรียมโปรไฟล์ถัดไป

1. เริ่มเซิร์ฟเวอร์ตามปกติ
2. รอ RandomDay เพื่อเสร็จสิ้นการทำงานเริ่มต้น
3. เปิด `RandomDay/web_export/today.html` ในโฟลเดอร์ mod ที่ติดตั้งไว้
4. ค้นหา **โปรไฟล์ที่ใช้งานอยู่** และ **โปรไฟล์ที่เตรียมไว้**.

เมื่อเริ่มต้นสำเร็จครั้งแรก เพจควรตั้งชื่อกฎที่ใช้งานอยู่แล้วและโปรไฟล์อื่นที่รอการเริ่มต้นครั้งถัดไป หน้านี้ยังอธิบายตระกูลที่เลือก ตำแหน่ง และไฟล์ที่เตรียมไว้ผ่านการตรวจสอบความปลอดภัยหรือไม่

อย่ารีสตาร์ทเพียงเพื่อให้สถานะเปลี่ยนแปลง เล่นกับกฎที่ใช้งานอยู่ต่อไปจนกว่าเซิร์ฟเวอร์ที่วางแผนไว้ถัดไปจะเริ่มทำงาน

<a id="dedicated-server-activate-it-later"></a>
## เซิร์ฟเวอร์เฉพาะ: เปิดใช้งานในภายหลัง

1. หยุดและเริ่มเซิร์ฟเวอร์ในการรีสตาร์ทที่วางแผนไว้ครั้งถัดไป
2. เปิดหน้าสถานะที่อ่านได้อีกครั้ง
3. ยืนยันว่าขณะนี้โปรไฟล์ที่เตรียมไว้ก่อนหน้านี้ถูกระบุว่าใช้งานอยู่
4. ยืนยันว่า RandomDay ได้เตรียมโปรไฟล์ต่อไปนี้

การเปลี่ยนแปลงที่เตรียมแล้วเปิดใช้งานนั้นเสร็จสมบูรณ์เพียงครั้งเดียว RandomDay วนรอบ

<a id="temporary-dedicated-servers"></a>
## เซิร์ฟเวอร์เฉพาะชั่วคราว

พฤติกรรมชั่วคราวใช้แพ็คเกจเซิร์ฟเวอร์เฉพาะเดียวกัน ใน [การกำหนดค่า](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md) เลือกว่าจะเริ่มต้นการทดสอบใหม่กับโปรไฟล์เฉพาะหรือเลือกจุดเริ่มต้นแบบสุ่ม หน้าสถานะยังคงแยกโปรไฟล์ที่ใช้งานอยู่ออกจากโปรไฟล์ที่เตรียมไว้สำหรับการเริ่มต้นครั้งถัดไป

<a id="singleplayer-or-lan"></a>
## ผู้เล่นคนเดียวหรือ LAN

1. เริ่มเกมหนึ่งครั้งโดยติดตั้งแพ็คเกจ singleplayer/LAN
2. ปิดเกมโดยสมบูรณ์หลังจาก RandomDay เสร็จสิ้น
3. อ่านบทสรุปที่สร้างขึ้น
4. คัดลอก `SandboxSettings.ini` ที่สร้างขึ้นลงใน โลกที่คุณเลือกในขณะที่เกมปิดอยู่
5. เริ่มโลกนั้นและยืนยันกฎที่คาดหวัง

แพ็คเกจภายในเครื่องจะไม่เลือกโลกหรือคัดลอกไฟล์ลงในบันทึกด้วยตัวเอง ดู [เล่นคนเดียวและ LAN](SINGLEPLAYER_LAN.md) สำหรับขั้นตอนทั้งหมด

<a id="if-the-expected-result-is-missing"></a>
## หากผลลัพธ์ที่คาดหวังหายไป

อย่ารีสตาร์ทต่อไป รักษาไฟล์ปัจจุบันและเลือกอาการที่ตรงกันใน [การแก้ไขปัญหา](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B9%89%E0%B9%84%E0%B8%82%E0%B8%9B%E0%B8%B1%E0%B8%8D%E0%B8%AB%E0%B8%B2.md). ผลลัพธ์ปกติจะตั้งชื่อโปรไฟล์ที่ใช้งานอยู่และโปรไฟล์ที่เตรียมไว้หรือความล้มเหลวในการเตรียมที่ชัดเจนเสมอ
