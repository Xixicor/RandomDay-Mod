# Mods ตัวเลือกที่รองรับ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDay สามารถทำให้ mod ที่ติดตั้งแยกต่างหากติดตามโปรไฟล์ RandomDay ที่ใช้งานอยู่ คุณลักษณะนี้มีเฉพาะในแพ็คเกจเซิร์ฟเวอร์เฉพาะเท่านั้น singleplayer/LAN จะไม่แก้ไข mod อื่น

RandomDay ไม่รวมหรือแจกจ่าย mod ใด ๆ ที่แสดงไว้ที่นี่ ติดตั้งและเปิดใช้งานม็อดเสริมแต่ละตัวจากหน้า Nexus ของตัวเอง และทำตามคำแนะนำของผู้เขียนก่อน RandomDay เปลี่ยนเฉพาะการตั้งค่าที่รู้จักซึ่งมีอยู่แล้วในไฟล์ที่ติดตั้ง ไม่ได้เพิ่มคุณสมบัติให้กับ mod อื่น และสามารถปิดใช้งานอะแดปเตอร์ได้โดยไม่ต้องถอนการติดตั้ง mod นั้น แพ็คเกจเซิร์ฟเวอร์เฉพาะเริ่มต้นด้วย `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## สิ่งที่ RandomDay การเปลี่ยนแปลง

| บูรณาการทางเลือก | การตั้งค่าที่เลือกจากโปรไฟล์ที่ใช้งานอยู่ |
| --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | โหมดฮาร์ด player/area พฤติกรรมคูลดาวน์, กิจกรรมพายุและโซนร้อน, การเกิดของบอสและการระเบิด, ระยะเวลาของวงจรการเกิด, ช่วงคูลดาวน์เล็กและใหญ่, ระยะการวางไข่, global/local/mod caps, พอร์ทัลพายุ, การละเมิดคำสั่งและโอกาสของบอส และการเกิดขั้นต่ำต่อพื้นที่ |
| ช่องส่วนขยาย Chaotic Spawn Engine เสริม | เมื่อติดตั้ง `SharedData.lua` มีฟิลด์ส่วนขยาย RandomDay อยู่แล้ว อะแดปเตอร์สามารถจัดหาโปรไฟล์การเผชิญหน้า ระดับ ธีม ขีดจำกัดกลุ่ม กิจกรรมพิเศษและค่าการเผชิญหน้าแบบผสม งบประมาณ คูลดาวน์ และการควบคุมขอบเขตโลก นี่ไม่ใช่ mod อื่นที่จะดาวน์โหลด |
| เลเซอร์สังหาร | การเปิดใช้งาน Mod บวกกับความเสียหายและเปิดใช้งานการควบคุมสำหรับตัวปล่อยที่ปรับใช้ได้ ตัวปล่อยสภาพแวดล้อม ตัวสะท้อน และปริซึม |
| ANTE ขึ้น | ตัวคูณความถี่การเกิดใหม่ ความถี่ก่อนการเปลี่ยนแปลง และค่าที่มีอยู่ development/debug สวิตช์ RandomDay ปิดสวิตช์การพัฒนาและการแก้ไขข้อบกพร่องที่ได้รับการยอมรับทั้งหมด |

ไลบรารีโปรไฟล์จัดเตรียมชุดค่าที่เตรียมไว้สำหรับทุกวันที่รองรับ วันที่เงียบสงบสามารถลดแรงกดดันได้ วันอันตรายสามารถเพิ่มความกดดันได้ และวันพักฟื้นสามารถลดความกดดันลงอย่างมาก RandomDay ไม่คำนวณค่าที่กำหนดเองตอนบูต โดยจะใช้ค่าที่ได้รับการตรวจทานที่กำหนดชื่อโดยโปรไฟล์ที่ใช้งานอยู่

<a id="current-version-evidence"></a>
## หลักฐานเวอร์ชันปัจจุบัน

ตารางนี้ได้รับการตรวจสอบเมื่อวันที่ 20 กรกฎาคม พ.ศ. 2569 “ได้รับการยอมรับ” หมายความว่าอะแดปเตอร์ที่เผยแพร่มีฟิกซ์เจอร์เลย์เอาต์เฉพาะเครื่องที่สมบูรณ์สำหรับการตั้งค่าที่ระบุชื่อ ไม่ได้หมายความว่าทุกรุ่นในอนาคตจะมีรูปแบบไฟล์เหมือนกัน

| ตัวดัดแปลงเสริม | ตรวจสอบเวอร์ชันอัปสตรีมปัจจุบันแล้ว | RandomDay สถานะการเปิดตัว |
| --- | --- | --- |
| [เครื่องมือวางไข่วุ่นวาย](https://www.nexusmods.com/abioticfactor/mods/156) | หน้า Nexus `0.8.5`; ไฟล์หลักปัจจุบัน`0.8.5-Hotfix1` | ได้รับการยอมรับ `DynamicSpawns/Scripts/SharedData.lua` รูปแบบสำหรับการวางไข่ คูลดาวน์ ขีดจำกัด พอร์ทัล การละเมิด และการตั้งค่าบอสที่สมบูรณ์ |
| ช่องส่วนขยาย Chaotic Spawn Engine เสริม | ไม่มีการดาวน์โหลดแยกต่างหาก ช่องตัวเลือกภายใน `SharedData.lua` | ใช้เฉพาะเมื่อทุกฟิลด์ส่วนขยายมีอยู่แล้ว การติดตั้ง Chaotic Spawn Engine แบบธรรมดาจะไม่เปลี่ยนแปลงหากไม่มีฟิลด์เหล่านั้น ID ของอะแด็ปเตอร์ภายในคือ `encounter_director`; มันไม่ได้ตั้งชื่อ mod สาธารณะแยกต่างหาก |
| [เลเซอร์สังหาร](https://www.nexusmods.com/abioticfactor/mods/141) | `1.0-UE4SS` | ได้รับการยอมรับ `LethalLasers/Scripts/main.lua` เค้าโครงสำหรับการตั้งค่าตัวส่งสัญญาณ สภาพแวดล้อมตัวส่งสัญญาณ ตัวสะท้อนแสง และปริซึมทั้งหมดที่แสดงไว้ด้านบน |
| [ANTE ขึ้น](https://www.nexusmods.com/abioticfactor/mods/201) | `1` อัปเดตเมื่อวันที่ 19 กรกฎาคม 2026 | อแด็ปเตอร์ที่ปล่อยออกมารู้จักรุ่นก่อนหน้า `Settings.lua` ชุดฟิลด์ เวอร์ชัน 1 จะไม่ถูกอ้างสิทธิ์ว่าเข้ากันได้จนกว่าไฟล์ปัจจุบันจะถูกเพิ่มไปยังฟิกซ์เจอร์และผ่านการทดสอบธุรกรรมของอะแดปเตอร์ หากโครงร่างแตกต่าง RandomDay รายงาน `skipped_incompatible` และไม่เปลี่ยนแปลง |

<a id="how-recognition-protects-another-mod"></a>
## การจดจำปกป้อง mod อื่นได้อย่างไร

การค้นหา ชื่อไฟล์ที่คุ้นเคยนั้นไม่เพียงพอ ก่อนที่จะเขียน RandomDay ตรวจสอบว่าการตั้งค่าที่จำเป็นทั้งหมดสำหรับอะแดปเตอร์นั้นมีอยู่ในไฟล์เป้าหมาย โดยจะแก้ไขการกำหนดที่มีอยู่เท่านั้น และจะไม่สร้างการตั้งค่าที่ขาดหายไป

สำหรับโครงร่างที่รู้จัก RandomDay จะดำเนินการหนึ่งธุรกรรมที่มีขอบเขต:

1. คำนวณทุกค่าที่ต้องการสำหรับโปรไฟล์ที่ใช้งานอยู่
2. สร้างและตรวจสอบไบต์ของข้อมูลสำรองของทุกไฟล์เป้าหมาย;
3. เขียนผ่านไฟล์พี่น้องที่ค้างอยู่
4. เลื่อนระดับไฟล์ที่ค้างอยู่และอ่านไบต์ที่บันทึกไว้กลับ;
5. ยืนยันทุกค่าที่ต้องการ;
6. ใช้การกู้คืนอัตโนมัติจากการสำรองข้อมูลที่ได้รับการตรวจสอบ หากขั้นตอนใดล้มเหลว

DynamicSpawns สามารถรวมการตั้งค่าและไฟล์ข้อความของผู้เล่นที่ได้รับการยอมรับไว้ในธุรกรรมเดียว RandomDay ไม่รายงานว่าการอัปเดตหลายไฟล์สำเร็จ เว้นแต่ธุรกรรมจะเสร็จสิ้น

<a id="read-an-adapter-result"></a>
## อ่านผลลัพธ์ของอะแดปเตอร์

| ผลลัพธ์ | ความหมาย |
| --- | --- |
| `applied` | การตั้งค่าที่ได้รับการยอมรับมีการเปลี่ยนแปลงและผ่านการอ่านแล้ว |
| `already_current` | การตั้งค่าที่ได้รับการยอมรับตรงกับโปรไฟล์ที่ใช้งานอยู่ |
| `not_installed` | ไม่พบ mod ที่เป็นตัวเลือก RandomDay ดำเนินการต่อโดยไม่มีการตั้งค่า |
| `skipped_incompatible` | พบไฟล์แล้ว แต่ระบบไม่รู้จักเค้าโครงการตั้งค่าที่สมบูรณ์ ไม่มีอะไรเปลี่ยนแปลง |
| `partial` | การตั้งค่าหลัก DynamicSpawns ถูกนำมาใช้ แต่ไฟล์ข้อความที่แปลซึ่งเป็นทางเลือกยังไม่เสร็จสมบูรณ์ ตรวจสอบผลลัพธ์ของอะแดปเตอร์ที่บันทึกไว้ |
| `failed_rolled_back` | ธุรกรรมล้มเหลวและไบต์ก่อนหน้ายังคงไม่เสียหายหรือได้รับการกู้คืนและตรวจสอบแล้ว |
| `rollback_failed` | RandomDay ไม่สามารถตรวจสอบการเปลี่ยนแปลงหรือการเรียกคืนได้ ให้ม็อดที่ได้รับผลกระทบหยุดทำงานและกู้คืนข้อมูลสำรองที่บันทึกไว้ด้วยตนเอง |

การที่ม็อดเสริมที่ขาดหายไปและเข้ากันไม่ได้จะไม่หยุดการหมุนเวียนแซนด์บ็อกซ์ของ RandomDay's การหมุนแซนด์บ็อกซ์ภายใต้การกำหนดค่าที่จัดส่ง

<a id="enable-or-disable-integrations"></a>
## เปิดใช้งานหรือปิดใช้งานการรวมระบบ

ส่วนควบคุมอยู่ใน:

```text
RandomDay/Scripts/ax_config/server.lua
```

แพ็คเกจเซิร์ฟเวอร์เฉพาะมาพร้อมกับ:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- ตั้งค่า `enabled = false` เพื่อหยุด RandomDay จากการตรวจสอบหรือเปลี่ยนแปลงม็อดเสริมทุกตัว
- ลบ ID ของอะแดปเตอร์ออกหนึ่งตัวเพื่อปล่อยให้ Mod นั้นอยู่คนเดียวในขณะที่ยังคงใช้งานการผสานรวมอื่นๆ อยู่
- คง `patch_only_existing_keys` และ `backup_before_write` ตั้งค่าเป็น `true` สิ่งเหล่านี้เป็นขอบเขตความปลอดภัยในการเขียน
- คง `optional_by_default = true` เว้นแต่ว่า mod ทางเลือกทุกตัวที่อยู่ในรายการเป็นส่วนที่จำเป็นของเซิร์ฟเวอร์ การตั้งค่าเป็น `false` จะทำให้อะแดปเตอร์ที่หายไป เข้ากันไม่ได้ หรือย้อนกลับได้อย่างปลอดภัยจะส่งผลต่อผลลัพธ์โดยรวม

คุณไม่จำเป็นต้องถอนการติดตั้งหรือปิดการใช้งานม็อดเสริม เมื่อคุณปิดการใช้งาน RandomDay อะแดปเตอร์

<a id="thanks-and-ownership"></a>
## ขอขอบคุณและความเป็นเจ้าของ

ขอขอบคุณผู้เขียนและผู้ดูแล [เครื่องมือวางไข่วุ่นวาย](https://www.nexusmods.com/abioticfactor/mods/156), [เลเซอร์สังหาร](https://www.nexusmods.com/abioticfactor/mods/141) ปัจจุบัน และ [ANTE ขึ้น](https://www.nexusmods.com/abioticfactor/mods/201). ม็อดของพวกเขายังคงเป็นการดาวน์โหลดแยกต่างหากซึ่งควบคุมโดยหน้าเพจ การอนุญาต และคำแนะนำการสนับสนุนของพวกเขาเอง RandomDay's ใช้เฉพาะฟิลด์การกำหนดค่าที่มีอยู่ในโครงร่างที่ติดตั้งและเป็นที่รู้จักเท่านั้น พวกเขาไม่ได้แจกจ่ายซ้ำหรือแทนที่ม็อดเหล่านั้น

<a id="backups-and-manual-recovery"></a>
## การสำรองข้อมูลและการกู้คืนด้วยตนเอง

สำเนาที่เขียนล่วงหน้าที่ตรวจสอบแล้วจะถูกเก็บไว้ภายใต้:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

หาก `rollback_failed` ปรากฏ:

1. หยุดเกมหรือเซิร์ฟเวอร์
2. ตั้งค่า `external_mods.enabled = false` หรือลบ ID อะแดปเตอร์ที่ได้รับผลกระทบ
3. รักษาไฟล์เป้าหมายปัจจุบันและไฟล์พี่น้อง pending/rollback;
4. จับคู่ไฟล์สำรองข้อมูลที่มีหมายเลขกับพาธเป้าหมายที่บันทึกไว้ในผลลัพธ์ของอะแดปเตอร์
5. เรียกคืนไบต์ที่ตรวจสอบแล้วในขณะที่บริการหยุด
6. เริ่ม mod ทางเลือกด้วยตัวเองก่อนที่จะเปิดใช้งานอีกครั้ง RandomDay อะแดปเตอร์

อย่าบังคับความเข้ากันได้ด้วยการเปลี่ยนชื่อการตั้งค่าหรือเพิ่มคีย์ที่หายไป ใช้เค้าโครงที่ได้รับการยอมรับ ปล่อยให้อะแดปเตอร์ปิดใช้งาน หรือเพิ่มฟิกซ์เจอร์เวอร์ชันใหม่และการทดสอบธุรกรรมก่อนที่จะขยายการอ้างสิทธิ์การสนับสนุน
