# RandomDay ქართულად

**v0.3.16-alpha**

RandomDay ამზადებს სრულ `SandboxSettings.ini` ფაილს Abiotic Factor-ის შემდეგი
გაშვებისთვის. მიმდინარე სესიის წესებს არ ცვლის; აქტიური და შემდეგი გაშვებისთვის
მომზადებული პროფილები ცალ-ცალკე აისახება.

## ინსტალაცია და შემოწმება

მიჰყევით [ინსტალაციის სახელმძღვანელოს](../../../INSTALL.md). სწორი საქაღალდეა
`ue4ss/Mods/RandomDay`, ხოლო `mods.txt` უნდა შეიცავდეს `RandomDay : 1`.
ჩვეულებრივ პირველი გაშვება ამზადებს პროფილს, შემდეგი კი ააქტიურებს.

შეამოწმეთ `runtime/current/randomday_status.json`, `runtime/rotation_state.txt`
და `web_export/today.json`. აქტიური და მომზადებული პროფილების იდენტობა სამივე
ფაილში უნდა ემთხვეოდეს.

## გამოცდილების არჩევა

რეჟიმი, ოჯახი, პირველი დღე და წინსვლა დააყენეთ
`RandomDay/Scripts/ax_config/server.lua` ფაილში. იხილეთ
[დაწყება](../../START_HERE.md), [პროფილის არჩევა](../../CHOOSE_A_PROFILE.md),
[კონფიგურაცია](../../CONFIGURATION.md) და [პრობლემების მოგვარება](../../TROUBLESHOOTING.md).

`HardcoreMode=False`, `AllowIronMode=False`, `StructuralSupportLimit=0` და
`BridgeSupports=0` არის ჩართული პროფილის შემქმნელის საწყისი მნიშვნელობები და
არა Abiotic Factor-ის სავალდებულო წესები. მათი შეცვლისა და პროფილების თავიდან
შექმნის წესი აღწერილია კონფიგურაციის დოკუმენტში.

ბრძანებები, ბილიკები, INI გასაღებები და მდგომარეობები ინგლისურად რჩება, რათა
რეალურ ფაილებს ზუსტად დაემთხვეს.

## ალფა გამოცემა და მუდმივი არჩევანი

ეს ალფა გამოცემაა. დოკუმენტირებული დაყენების, როტაციისა და აღდგენის გზები გამოცდილია; თავსებადობა და გამოყენების სიმარტივე კვლავ უმჯობესდება.

`RandomDay/Scripts/ax_config/server.lua`-ში `sandbox.profile_overrides` ოთხ მნიშვნელობას ყველა ოჯახისა და დღისთვის ინარჩუნებს. გააჩერეთ სერვერი, ერთხელ შეცვალეთ და ხელახლა ჩართეთ. შემდეგი როტაციები და გაშვებები იმავე მნიშვნელობებს იყენებს; მხოლოდ `SandboxSettings.ini`-ის შეცვლა დროებითია.

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

ქვემოთ მოცემული არჩევითი მოდები მათი ავტორების ცალკე ჩამოტვირთვებია. RandomDay მათ არ ავრცელებს და ფუნქციებს არ ცვლის; ჩართული ადაპტერი მხოლოდ არსებულ მხარდაჭერილ პარამეტრებს არეგულირებს. მადლობა ავტორებსა და მომვლელებს.
