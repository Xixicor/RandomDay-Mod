# RandomDay პროფილის დოკუმენტაცია

> **კანონიკური ინგლისური წყარო:** [README.md](../../../profiles/README.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ვერსია: `v0.3.16-alpha`

- ოჯახები: **17**
- პროფილები: **289**
- SandboxSettings ლექსიკონის ჩანაწერები: **46**

აირჩიეთ ოჯახი თამაშის მიზნის მიხედვით [პროფილის არჩევის სახელმძღვანელო](../%E1%B2%90%E1%B2%98%E1%B2%A0%E1%B2%A9%E1%B2%98%E1%B2%94%E1%B2%97_%E1%B2%9E%E1%B2%A0%E1%B2%9D%E1%B2%A4%E1%B2%98%E1%B2%9A%E1%B2%98.md), შემდეგ გამოიყენეთ ეს გენერირებული ინდექსი ზუსტი მნიშვნელობებისთვის.

ეს ფაილები გენერირებულია Runtime Lua-ს წყაროდან და მისი dictionary/translation კონტრაქტი. ისინი აჩვენებენ გაგზავნილს `sandbox.profile_overrides` ნაგულისხმევი; ერთი სერვერის კონფიგურირებული მნიშვნელობები შეიძლება განსხვავდებოდეს:

- `profiles.generated.json`: მანქანით წასაკითხი პროფილები, ნედლეული მნიშვნელობები, ლექსიკონი და თარგმანები.
- `FULL_PROFILE_REFERENCE.md`: სრული ინდექსი და ინტერპრეტაციის წესები.
- `SANDBOX_SETTINGS_KEYS.md`: დაასრულეთ 46 კლავიშიანი ლექსიკონი.
- `families/*.md`: დეტალური 17-დღიანი ოჯახის მითითებები.

რეგენერაცია: `python -B tools/generate_profile_docs.py` შეამოწმეთ დრიფტი: `python -B tools/generate_profile_docs.py --check`
