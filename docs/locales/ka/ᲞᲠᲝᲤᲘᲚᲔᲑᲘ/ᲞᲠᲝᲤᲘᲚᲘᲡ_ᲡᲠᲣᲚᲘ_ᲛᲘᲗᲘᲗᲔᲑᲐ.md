# RandomDay - სრული პროფილის მითითება

> **კანონიკური ინგლისური წყარო:** [FULL_PROFILE_REFERENCE.md](../../../profiles/FULL_PROFILE_REFERENCE.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ვერსია: `v0.3.16-alpha`

ეს გენერირებული მითითება მოიცავს 289 პროფილს 17 ოჯახში. იგი გენერირებულია იმავე ლუას პროფილის ცხრილებიდან და თარგმანის ლექსიკონიდან, რომელიც გამოიყენება გაშვების დროს; ნედლეული მნიშვნელობები რჩება ავტორიტეტული.

## წაიკითხეთ მითითება

- საერთო და დომენის რეიტინგი გამოითვლება ყველა 46-დან SandboxSettings კლავიშები პლუს შეტაკების წნევა.
- მარტივი ტექსტი საკონსულტაციოა. ზუსტი მნიშვნელობები შენარჩუნებულია ყოველი ახსნის გვერდით.
- აქტიური პარამეტრები ვრცელდება მიმდინარე ჩატვირთვაზე. მომზადებული პარამეტრები მოქმედებს მხოლოდ შემდეგი გადატვირთვის შემდეგ.
- საარჩევნო ადაპტერის არჩევანი არის მოთხოვნა; გაშვების სტატუსი აღრიცხავს თუ არა დაინსტალირებული ადაპტერი რეალურად ემთხვევა და დამოწმებული.
