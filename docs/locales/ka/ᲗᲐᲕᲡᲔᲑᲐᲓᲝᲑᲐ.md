# თავსებადობა

> **კანონიკური ინგლისური წყარო:** [COMPATIBILITY.md](../../COMPATIBILITY.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


<a id="supported-installations"></a>
## მხარდაჭერილი ინსტალაციები

RandomDay შექმნილია Abiotic Factor ინსტალაციებისთვის, რომლებსაც შეუძლიათ ჩატვირთვა UE4SS ლუას მოდიფიკაციები.

| გარემო | მხარდაჭერა | პაკეტი |
| --- | --- | --- |
| Windows გამოყოფილი სერვერი | მხარდაჭერილი | გამოყოფილი სერვერი ZIP |
| Windows singleplayer ან LAN ჰოსტი | ხელით ასლის მუშაობის პროცესის მხარდაჭერა | Singleplayer/LAN ZIP |
| Linux სერვერი Wine-ის ან Proton-ის გამოყენებით | გამოშვების ტესტირება არ არის | Windows-ის გამოყოფილი პაკეტი შეიძლება შეფასდეს გამოცდილი ოპერატორების მიერ, მაგრამ თავსებადობის დაპირება არ არის გაცემული. |
| Xbox და PlayStation | მხარდაჭერილი არ არის | ეს პლატფორმები არ იძლევა ფაილზე წვდომას და UE4SS ამ გამოშვებისთვის საჭიროა Lua ჩატვირთვის გზა. |

RandomDay არ აერთიანებს ორ პაკეტს. გამოყოფილი სერვერი, რომელიც მხოლოდ დროდადრო სათამაშოდ არის დაწყებული, კვლავ იყენებს გამოყოფილი სერვერს ZIP და ირჩევს დროებით ქცევას კონფიგურაციაში.

<a id="abiotic-factor-updates"></a>
## აბიოტიკური ფაქტორის განახლებები

თამაშის განახლების შემდეგ დაიწყეთ სერვერის გაჩერებით და შეინახეთ მსოფლიოს აღდგენითი ასლი, `SandboxSettings.ini` და RandomDay მდგომარეობა. დაადასტურეთ UE4SS იტვირთება, შემდეგ შეავსეთ ერთი RandomDay ციკლი და შეამოწმეთ როგორც აქტიური, ასევე მომზადებული პროფილი, სანამ განაახლებთ ნორმალურ ბრუნვას.

<a id="companion-mods"></a>
## კომპანია მოდიფიკაციები

RandomDay ცვლის ცალკე დაყენებულ მოდს მხოლოდ მაშინ, როდესაც მისი სრული პარამეტრების განლაგება ემთხვევა მხარდაჭერილ ადაპტერს. მხოლოდ ვერსიის ნომერი არ არის საკმარისი.

| ინტეგრაცია | მიმდინარე ვერსია განხილულია | RandomDay მხარდაჭერის საზღვარი |
| --- | --- | --- |
| ქაოტური ქვირითის ძრავა / DynamicSpawns | `0.8.5`; მთავარი ფაილი `0.8.5-Hotfix1` | მხარდაჭერილი `SharedData.lua` განლაგება მოიცავს ქვირითს, გაგრილებას, პოპულაციას, პორტალს, დარღვევას, ბოსს და RandomDay შეხვდით ადაპტერის მითითებაში ჩამოთვლილ პარამეტრებს. |
| ლეტალური ლაზერები | `1.0-UE4SS` | მხარდაჭერილი `Scripts/main.lua` განლაგება მოიცავს ამოცნობილ ემიტერს, გარემო-ემიტერს, რეფლექტორს და პრიზმის პარამეტრებს. |
| ANTE ზემოთ | `1`, განახლებულია 2026 წლის 19 ივლისს | მიმდინარე საჯარო განლაგებამ არ დაასრულა ადაპტერის მოწყობილობა. RandomDay გამოტოვებს შეუსაბამო ფაილს უცვლელად, სანამ ეს განლაგება არ დადასტურდება. |

არყოფნის, გათიშული ან ამოუცნობი კომპანიონის რეჟიმი უცვლელი რჩება. იხილეთ [მხარდაჭერილი არასავალდებულო მოდიფიკაციები](%E1%B2%9B%E1%B2%AE%E1%B2%90%E1%B2%A0%E1%B2%93%E1%B2%90%E1%B2%AD%E1%B2%94%E1%B2%A0%E1%B2%98%E1%B2%9A%E1%B2%98_%E1%B2%90%E1%B2%93%E1%B2%90%E1%B2%9E%E1%B2%A2%E1%B2%94%E1%B2%A0%E1%B2%94%E1%B2%91%E1%B2%98.md) ზუსტი პარამეტრების, კონფიგურაციის კონტროლის, სარეზერვო ქცევისა და აღდგენის ნაბიჯებისთვის.

<a id="what-compatibility-validation-proves"></a>
## რას ადასტურებს თავსებადობის ვალიდაცია

საცავის ვალიდაციამ შეიძლება დაამტკიცოს გაგზავნილი პაკეტის განლაგება, კონფიგურაციის დაფარვა, ადაპტერის აღიარებული ველები, სარეზერვო და აღდგენის ქცევა და უცნობი განლაგების უსაფრთხო უარყოფა. მას არ შეუძლია დაამტკიცოს ყველა მომავალი აბიოტური ფაქტორი, UE4SS, ან companion-mod ვერსია. გამოშვების შენიშვნები ასახელებს შემოწმებულ ვერსიებს და არა თავსებადობა წარმატებული ჩატვირთვით.
