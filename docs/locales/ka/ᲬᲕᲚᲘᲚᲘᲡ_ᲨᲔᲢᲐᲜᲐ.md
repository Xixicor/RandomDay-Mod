# წვლილის შეტანა

> **კანონიკური ინგლისური წყარო:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDay ინახება როგორც კონტროლირებადი პროექტი.

საჯარო მოთხოვნილებები, არასასურველი კოდის გაგზავნა, ავტომატური ხელახალი ჩაწერა, გენერირებული კოდის გასუფთავების წარდგენები და სპეკულაციური მახასიათებლების პატჩები არ მიიღება, თუ ცალსახად არ არის მოთხოვნილი საცავის მფლობელის მიერ.

<a id="accepted-contact"></a>
## მიღებული კონტაქტი

შეცდომის შესახებ შეტყობინებების, თავსებადობის შენიშვნებისთვის ან სერვერის ადმინისტრაციის დაკვირვებისთვის გამოიყენეთ პროექტის დოკუმენტაციაში ჩამოთვლილი საკონტაქტო არხები.

<a id="not-accepted"></a>
## არ მიიღება

ქვემოთ ნაგულისხმევად არ არის მიღებული:

- გამოთხოვის მოთხოვნა;
- გენერირებული კოდის ხელახალი ჩაწერა;
- ფართო რეფაქტორები;
- მხოლოდ სტილის ფორმატის ცვლილებები;
- გადაუმოწმებელი თამაშის ლოგიკის ცვლილებები;
- შეფუთული მესამე მხარის მოდიფიკაციის ფაილები;
- გადანაწილებული მესამე მხარის წყაროს კოდი;
- ცვლილებები, რომლებიც გულისხმობს ოფიციალურ კავშირს აბიოტურ ფაქტორთან, UE4SS, Nexus Mods ან მესამე მხარის mod ავტორები.

<a id="controlled-development"></a>
## კონტროლირებული განვითარება

საცავის მფლობელს შეუძლია მოითხოვოს კონკრეტული განხილვის, ტესტირების ან დოკუმენტაციის დახმარება საჭიროების შემთხვევაში. გამოუყენებელი წარდგენები შეიძლება დაიხუროს განხილვის გარეშე.
