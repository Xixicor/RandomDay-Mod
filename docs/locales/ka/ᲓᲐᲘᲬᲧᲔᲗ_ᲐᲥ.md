# დაიწყეთ აქ: დაასრულეთ პირველი RandomDay ციკლი

> **კანონიკური ინგლისური წყარო:** [START_HERE.md](../../START_HERE.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ეს სახელმძღვანელო იწყება RandomDay დაინსტალირებულია. ის აჩვენებს, თუ რას ცვლის მოდიფიკაცია, რას ტოვებს ის მარტო და როგორ ამოვიცნოთ ერთი წარმატებული ციკლი.

<a id="know-the-two-states"></a>
## იცოდე ორი მდგომარეობა

Abiotic Factor კითხულობს მსოფლიოს sandbox პარამეტრებს მანამდე RandomDay. RandomDay ამიტომ ინახავს ორ მკაფიოდ დასახელებულ მდგომარეობას:

- **აქტიური პროფილი:** წესები, რომელსაც მიმდინარე სესია უკვე იყენებს.
- **მომზადებული პროფილი:** წესები შენახულია შემდეგი დასაწყისისთვის.

მომზადებული პროფილი არ ცვლის უკვე მიმდინარე სესიას.

<a id="dedicated-server-prepare-the-next-profile"></a>
## გამოყოფილი სერვერი: მოამზადეთ შემდეგი პროფილი

1. ჩართეთ სერვერი ნორმალურად.
2. დაელოდეთ RandomDay გაშვების სამუშაოს დასასრულებლად.
3. გახსენით `RandomDay/web_export/today.html` დაინსტალირებული mod საქაღალდეში.
4. იპოვეთ **აქტიური პროფილი** და **მომზადებული პროფილი**.

პირველ წარმატებულ დაწყებაზე გვერდმა უნდა დაასახელოს უკვე აქტიური წესები და სხვა პროფილი, რომელიც ელოდება შემდეგ დაწყებას. გვერდი ასევე განმარტავს არჩეულ ოჯახს, პოზიციას და გაიარა თუ არა მომზადებულმა ფაილმა უსაფრთხოების შემოწმება.

არ გადატვირთოთ მხოლოდ სტატუსის შესაცვლელად. გააგრძელეთ აქტიური წესებით თამაში შემდეგი დაგეგმილი სერვერის დაწყებამდე.

<a id="dedicated-server-activate-it-later"></a>
## გამოყოფილი სერვერი: გააქტიურეთ მოგვიანებით

1. გააჩერეთ და გაუშვით სერვერი შემდეგი დაგეგმილი გადატვირთვისას.
2. ხელახლა გახსენით წასაკითხი სტატუსის გვერდი.
3. დაადასტურეთ, რომ ადრე მომზადებული პროფილი ახლა ჩამოთვლილია როგორც აქტიური.
4. დაადასტურეთ ეს RandomDay მოამზადა შემდეგი პროფილი.

გადასვლის მომზადება-შემდეგ-გააქტიურება არის სრული RandomDay ციკლი.

<a id="temporary-dedicated-servers"></a>
## დროებითი გამოყოფილი სერვერები

დროებითი ქცევა იყენებს იმავე გამოყოფილი სერვერის პაკეტს. [კონფიგურაცია](%E1%B2%99%E1%B2%9D%E1%B2%9C%E1%B2%A4%E1%B2%98%E1%B2%92%E1%B2%A3%E1%B2%A0%E1%B2%90%E1%B2%AA%E1%B2%98%E1%B2%90.md), აირჩიეთ ახალი გაშვება დაიწყება კონკრეტულ პროფილზე თუ აირჩევთ შემთხვევით საწყის წერტილს. სტატუსის გვერდი კვლავ განასხვავებს აქტიურ პროფილს შემდეგი დასაწყისისთვის მომზადებულისგან.

<a id="singleplayer-or-lan"></a>
## ერთი მოთამაშე ან LAN

1. დაიწყეთ თამაში ერთხელ singleplayer/LAN პაკეტი.
2. სრულად დახურეთ თამაში RandomDay სრულდება.
3. წაიკითხეთ გენერირებული რეზიუმე.
4. დააკოპირეთ გენერირებული `SandboxSettings.ini` თქვენს მიერ არჩეულ სამყაროში, სანამ თამაში დახურულია.
5. დაიწყეთ ეს სამყარო და დაადასტურეთ მოსალოდნელი წესები.

ლოკალური პაკეტი არასოდეს ირჩევს სამყაროს და არ აკოპირებს ფაილს შენახვაში. იხილეთ [ერთი მოთამაშე და LAN](SINGLEPLAYER_LAN.md) სრული პროცედურისთვის.

<a id="if-the-expected-result-is-missing"></a>
## თუ მოსალოდნელი შედეგი აკლია

არ განაგრძოთ გადატვირთვა. შეინახეთ მიმდინარე ფაილები და აირჩიეთ შესაბამისი სიმპტომი [პრობლემების აღმოფხვრა](%E1%B2%9E%E1%B2%A0%E1%B2%9D%E1%B2%91%E1%B2%9A%E1%B2%94%E1%B2%9B%E1%B2%94%E1%B2%91%E1%B2%98%E1%B2%A1_%E1%B2%90%E1%B2%A6%E1%B2%9B%E1%B2%9D%E1%B2%A4%E1%B2%AE%E1%B2%95%E1%B2%A0%E1%B2%90.md). ნორმალური შედეგი ყოველთვის ასახელებს აქტიურ პროფილს და ან მომზადებულ პროფილს, ან ერთ აშკარა მომზადების წარუმატებლობას.
