# ჩვიდმეტი ოჯახი, ჩვიდმეტი დღე

> **კანონიკური ინგლისური წყარო:** [FAMILY_ROTATION.md](../../FAMILY_ROTATION.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDay შეიცავს 17 playstyle ოჯახს 17 სრული ყოველდღიური პროფილით თითოეულ ოჯახში. ეს აწარმოებს 289 დოკუმენტურ family/day კომბინაციები.

ოჯახი ადგენს გარბენის ფართო სტილს. 1-დან 17-მდე დღეები უზრუნველყოფს ამ ოჯახის პროგრესირებას ზეწოლაში, გამოჯანმრთელებაში, ტემპში და რესურსებში. გაშვება ინახავს ერთ შეკვეთას, რომელიც შეიცავს ყოველ დღე ID ზუსტად ერთხელ. გადატვირთვა გადადის შემდეგ შენახულ პოზიციაზე; RandomDay არ ცვლის ოჯახებს შეკვეთის შუა რიცხვებში.

<a id="selection-modes"></a>
## შერჩევის რეჟიმები

| რეჟიმი | ახალი გაშვების ქცევა | გაშვების დროს |
|---|---|---|
| `selected_run` | იყენებს `profile_family.selected_family`. | ინახავს ამ ოჯახს 17-ვე შენახულ პოზიციაზე. |
| `non_repeating_random_run` | ირჩევს დასაშვებ გამოუყენებელ ოჯახს. | ინახავს მას 17-ვე პოზიციაზე და თავს არიდებს ოჯახის განმეორებას, სანამ არ ამოიწურება უფლებამოსილი სია. |
| `rotation_run` | იღებს შემდეგ ოჯახს კონფიგურირებული თანმიმდევრობით. | ინახავს მას 17-ვე შენახულ პოზიციაზე. |

გაგზავნილი კონფიგურაცია იყენებს `non_repeating_random_run`. საბოლოო შენახული პოზიციის შემდეგ მომზადებული ოჯახი ჯერ კიდევ მხოლოდ მომზადებულია; ის აქტიური ხდება გადატვირთვის შემდეგ. `cycle.start_day_mode` და `cycle.day_progression_mode` აირჩიეთ პირველი დღის და დღის შეკვეთა ოჯახის არჩევანის შეცვლის გარეშე.

## მორგებული ოჯახები და დღეები

ოჯახის წყარო ცხოვრობს:

```text
RandomDay/Scripts/ax_profiles/families/
```

Markdown და JSON `docs/profiles/` არის გენერირებული მითითებები. შეცვალეთ წყარო, არ გენერირებული გამომავალი, შემდეგ გაუშვით სრული profile/schema ვალიდაცია. მორგებული ნაკრები არ არის მზად, როდესაც მხოლოდ ერთი დღე ანალიზდება; all 17 days, configured profile defaults, types, ranges, and the generated reference must agree.
