# ცვლილებების ჟურნალი

> **კანონიკური ინგლისური წყარო:** [CHANGELOG.md](../../../CHANGELOG.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


<a id="v0316-alpha"></a>
## v0.3.16-alpha

- დამატებულია ორი სრული პაკეტი: ერთი გამოყოფილი სერვერებისთვის და ერთი ერთი მოთამაშისთვის ან LAN სამყაროები.
- დამატებულია მუდმივი და დროებითი გამოყოფილი სერვერის რეჟიმები, კონფიგურირებადი საწყისი პროფილები და თანმიმდევრული ან განუმეორებელი შემთხვევითი პროგრესი.
- ბიბლიოთეკა გააფართოვა ჩვიდმეტი პროფილის ოჯახამდე, თითოეულ ოჯახში ჩვიდმეტი პროფილით.
- დამატებულია იკითხებადი active/prepared პროფილის სტატუსი, კომპაქტური მოთამაშის შენიშვნები, უსაფრთხო sandbox ჩაწერა, დადასტურებული სარეზერვო ასლები, წაკითხვა და დაბრუნება.
- დამატებულია არასავალდებულო, განლაგებით შემოწმებული გადამყვანები მხარდაჭერილი კომპანიონი მოდებისთვის.
- დაემატა მუდმივი კონტროლი მთელი პროფილისთვის Hardcore Mode, Iron Mode, სტრუქტურული მხარდაჭერა და ხიდის მხარდაჭერა საჯარო სერვერის კონფიგურაციაში.
- დაემატა ინგლისური სახელმძღვანელოს სრული ბიბლიოთეკა და 27 ლოკალიზებული შესვლის გვერდი.
- დაადასტურა გამოშვების პაკეტები, როგორც სუფთა, განმსაზღვრელი, შემთხვევისთვის უსაფრთხო UE4SS განლაგება პირადი კონფიგურაციის ან გაშვების მონაცემების გარეშე.
