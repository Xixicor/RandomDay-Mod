# გაშვების ვალიდაცია

> **კანონიკური ინგლისური წყარო:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ეს გვერდი განკუთვნილია კონტრიბუტორებისა და გამოშვების შემსრულებლებისთვის. მოთამაშეებს, რომლებიც აინსტალირებენ მოდს, არ სჭირდებათ ამ ბრძანებების გაშვება.

<a id="ordinary-user-proof"></a>
## ჩვეულებრივი მომხმარებლის მტკიცებულება

გამოცემა გასაგებია, როდესაც ახალ მკითხველს შეუძლია აირჩიოს ორი პაკეტიდან ერთ-ერთი, დააინსტალიროს იგი, გამოტოვოს მომზადებული გზამკვლევი და აღადგინოს პროფილის აქტიური პროფილიდან. მკითხველის ამ ამოცანებს არ უნდა მოითხოვდეს Git, PowerShell, Python, ან საკონტროლო ჯამის ცოდნა.

<a id="contributor-checks"></a>
## კონტრიბუტორი ამოწმებს

გაშვება საცავის ძირიდან:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

როდესაც `luac` ხელმისაწვდომია, სინტაქსის შემოწმება Lua-ს ყველა გაგზავნილი ფაილი:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

ლუას გაშვების ტესტები მოითხოვს `lupa`. დაკარგული ლუას თარჯიმანი ან `lupa` ინსტალაცია არის მიუწვდომელი ტესტის შესაძლებლობა და არა წარმავალი შედეგი.

<a id="release-checks"></a>
## გაუშვით ჩეკები

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

გამოშვების შემოწმება ამოწმებს ამ პირობებს:

- `VERSION` და `RandomDay/.randomday_version` ემთხვევა.
- მხოლოდ მიმდინარე ვერსია არსებობს `releases/`.
- გამოყოფილი და singleplayer/LAN ZIP-ები სრული ალტერნატივაა.
- ორივე არქივი შეიცავს კანონიკურ `RandomDay/Scripts/main.lua` გზა და შემთხვევის ჩამტვირთველი არ არის.
- პაკეტის რეჟიმის მარკერები არის `dedicated_server` და `singleplayer_manual`.
- ZIP ბაიტები დეტერმინისტულია და ემთხვევა `CHECKSUMS.sha256`.
- გაშვების დროის მონაცემები, პირადი კონფიგურაცია, რწმუნებათა სიგელები, ქეშები ან სატესტო გამომავალი არ არის შეფუთული.
- ყველა ადგილობრივი დოკუმენტაციის ბმული და ლოკალური შესვლის 27 გვერდი ვალიდირებულია.

<a id="avoid-validation-environment-pitfalls"></a>
## მოერიდეთ ვალიდაციის გარემოს ხარვეზებს

- გაუშვით საცავში ჩაწერის შემოწმებები სერიულად, რათა ორმა პროცესმა არ ჩაანაცვლოს ერთი და იგივე დროებითი ფაილი ერთდროულად.
- Windows-ზე შეამოწმეთ ZIP ასახელებს წევრების სახელებს, ვიდრე რეგისტრირებული ფაილების ძიებას, რათა გადაწყვიტოს, არსებობს თუ არა პატარა ჩამტვირთავი.
- დაადასტურეთ `mods.txt` და `enabled.txt` მხოლოდ დაინსტალირებული სერვერის ტესტში; ისინი არ არიან იმის მტკიცებულება, რომ წყაროს ტესტები ჩატარდა.
- ჩაწერეთ ბრძანების ვადის ამოწურვა, როგორც არასრული. არ დააკონვერტიროთ ის გაშვებად ან წარუმატებლად ბრძანების შეზღუდული გამომავალის გარეშე.
- დროებითი ფაილები საცავში იგნორირებული იყოს `.tmp/` დირექტორია.

<a id="known-limits"></a>
## ცნობილი ლიმიტები

ადგილობრივი ვალიდაცია ადასტურებს წყაროს, პაკეტს, დოკუმენტაციას და მოწყობილობების კონტრაქტებს. ის არ ადასტურებს კონკრეტული სერვერის პანელის გაშვების ბრძანებას, პირდაპირი კლიენტის შეტყობინებების განლაგებას ან მასპინძლის სპეციფიკურ ფაილური სისტემის გზას. ჩაწერეთ ისინი, როგორც ცალკეული ინტეგრაციის შედეგები ტესტირებისას.
