# შეფუთული წყაროს მითითება

> **კანონიკური ინგლისური წყარო:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


გამოცემა ZIP შეიცავს ზუსტად 51 ბილიკს ქვემოთ. მშენებელი უარყოფს გამოტოვებულ ბილიკს, დამატებით პაკეტის ფორმის წყაროს, შემთხვევის შეჯახებას, სიმბლაკს ან წევრს მისი პირდაპირი დაშვების სიის გარეთ. გაშვების დროის გამომავალი, ტესტები, საცავის დოკუმენტები და მესამე მხარის მოდიფიკაციები არ არის პაკეტის წევრები.

მანქანით შესამოწმებელი კომპანიონი არის [`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json). ის იწერს იგივე ბილიკებს შეყვანით, გამომავალებით, გვერდითი ეფექტებით, საჯარო პარამეტრებით, ხილული მდგომარეობებით, წარუმატებლობის რეჟიმებით, რედაქტირებით და კანონიკური დოკუმენტაციით.

თითოეულ გაგზავნილ Lua მწკრივს აქვს ერთი სტაბილური `module-*` წამყვანი. მისი კანონიკური წყაროს სათაურისა და მანქანის ჩანაწერის იდენტური ბმული ხდის საკუთრებას, კონტრაქტს, გვერდით ეფექტებს, წარუმატებლობებს და აღდგენას უშუალოდ მიკვლევადს.
