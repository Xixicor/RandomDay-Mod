# მხარდაჭერილი არასავალდებულო მოდიფიკაციები

> **კანონიკური ინგლისური წყარო:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDay შეუძლია ცალ-ცალკე დაინსტალირებული მოდი აქტიურ RandomDay პროფილი. ეს ფუნქცია ხელმისაწვდომია მხოლოდ გამოყოფილი სერვერის პაკეტში. singleplayer/LAN პაკეტი არასოდეს არედაქტირებს სხვა მოდიფიკაციას.

RandomDay არ შეიცავს ან არ ავრცელებს აქ ჩამოთვლილ მოდებს. დააინსტალირეთ და ჩართეთ თითოეული არჩევითი რეჟიმი Nexus-ის საკუთარი გვერდიდან და პირველ რიგში მიჰყევით მისი ავტორის მითითებებს. RandomDay ცვლის მხოლოდ აღიარებულ პარამეტრებს, რომლებიც უკვე არსებობს დაინსტალირებულ ფაილში. ის არ ამატებს ფუნქციებს სხვა მოდში და ადაპტერი შეიძლება გამორთოთ ამ რეჟიმის დეინსტალაციის გარეშე. გამოყოფილი სერვერის პაკეტი იწყება `external_mods.enabled = true`.

## როგორ იცავს ამოცნობა სხვა მოდს

ნაცნობი ფაილის სახელის პოვნა საკმარისი არ არის. დაწერამდე, RandomDay ამოწმებს, რომ ამ ადაპტერის ყველა საჭირო პარამეტრი არსებობს სამიზნე ფაილში. ის ასწორებს მხოლოდ არსებულ დავალებებს; ის არასოდეს იგონებს გამოტოვებულ პარამეტრს.

აღიარებული განლაგებისთვის, RandomDay ასრულებს ერთ შეზღუდულ ტრანზაქციას:

1. გამოთვალეთ ყველა სავარაუდო მნიშვნელობა აქტიური პროფილისთვის;
2. შექმენით და შეამოწმეთ ყველა სამიზნე ფაილის სარეზერვო ასლი;
3. ჩაწერეთ და-ძმის მომლოდინე ფაილში;
4. გააკეთეთ მომლოდინე ფაილი და წაიკითხეთ შენახული ბაიტები;
5. დაადასტურეთ ყველა სავარაუდო მნიშვნელობა;
6. გამოიყენეთ ავტომატური აღდგენა დამოწმებული სარეზერვო ასლებიდან, თუ რომელიმე ნაბიჯი ვერ მოხერხდა.

DynamicSpawns შეიძლება შეიცავდეს მის პარამეტრებს და მოთამაშის შეტყობინებების აღიარებულ ფაილებს ერთ ტრანზაქციაში. RandomDay არ აცნობებს ამ მრავალფაილის განახლებას, როგორც წარმატებულს, თუ სრული ტრანზაქცია არ დასრულდება.

<a id="enable-or-disable-integrations"></a>
## ჩართეთ ან გამორთეთ ინტეგრაციები

კონტროლი არის:

```text
RandomDay/Scripts/ax_config/server.lua
```

გამოყოფილი სერვერის პაკეტი მიეწოდება შემდეგს:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- დაყენება `enabled = false` შეჩერება RandomDay ყველა არასავალდებულო რეჟიმის შემოწმების ან შეცვლისგან.
- ამოშალეთ ერთი ადაპტერის ID, რომ დატოვოთ ეს რეჟიმი, ხოლო დანარჩენი ინტეგრაციები აქტიური იყოს.
- შეინახე `patch_only_existing_keys` და `backup_before_write` დაყენებულია `true`. ისინი ჩაწერის უსაფრთხოების ზღვარია.
- შეინახე `optional_by_default = true` თუ ყველა ჩამოთვლილი არჩევითი რეჟიმი არ არის სერვერის აუცილებელი ნაწილი. დააყენეთ `false` გამოტოვებული, შეუთავსებელი ან უსაფრთხოდ შემობრუნებული ადაპტერი გავლენას ახდენს მთლიან შედეგზე.

თქვენ არ გჭირდებათ არასავალდებულო რეჟიმის დეინსტალაცია ან გამორთვა, როდესაც გამორთავთ მის RandomDay ადაპტერი.

<a id="backups-and-manual-recovery"></a>
## სარეზერვო ასლები და ხელით აღდგენა

დამოწმებული წინასწარ ჩაწერის ასლები ინახება შემდეგში:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

თუ `rollback_failed` გამოჩნდება:

1. შეაჩერე თამაში ან სერვერი;
2. კომპლექტი `external_mods.enabled = false` ან წაშალეთ დაზარალებული ადაპტერის ID;
3. შეინახეთ მიმდინარე სამიზნე ფაილი და მისი ძმა pending/rollback ფაილები;
4. შეესაბამება დანომრილი სარეზერვო ფაილები ადაპტერის შედეგში დაფიქსირებულ სამიზნე ბილიკებს;
5. აღადგინეთ დამოწმებული ბაიტები, სანამ სერვისი შეჩერებულია;
6. დაიწყეთ სურვილისამებრ მოდიფიკაცია, სანამ ხელახლა ჩართავთ მის RandomDay ადაპტერი.

არ აიძულოთ თავსებადობა პარამეტრების სახელის გადარქმევით ან დაკარგული გასაღებების დამატებით. გამოიყენეთ აღიარებული განლაგება, დატოვეთ ადაპტერი გამორთული, ან დაამატეთ ახალი ვერსიის მოწყობილობა და ტრანზაქციის ტესტი მხარდაჭერის საჩივრის გაფართოებამდე.
