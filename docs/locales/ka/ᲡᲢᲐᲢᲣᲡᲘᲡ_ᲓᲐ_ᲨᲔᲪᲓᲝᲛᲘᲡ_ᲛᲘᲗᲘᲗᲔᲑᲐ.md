# სტატუსისა და შეცდომის მითითება

> **კანონიკური ინგლისური წყარო:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


გამოიყენეთ ზუსტი `status`, `transaction_status`, `rollback_status` და `error` მნიშვნელობები გაშვების დროის ექსპორტიდან. პანელში ან კონსოლში მსგავსი ფორმულირება არ არის ამ ველების შემცვლელი.

ეს განყოფილება არის სრული საძიებო მითითება. ზემოთ მოცემული გადაწყვეტილების ხე ირჩევს შესაბამის კატეგორიას; ეს ცხრილები ინახავს მანქანის ზუსტ მნიშვნელობებს და უსაფრთხო ოპერატორის პასუხებს.

<a id="startup-configuration-errors"></a>
## გაშვების კონფიგურაციის შეცდომები

ეს შეტყობინებები აჩერებს დაწყებას RandomDay წერს პროფილს. შეასწორეთ დასახელებული პარამეტრი ან პაკეტის მარკერი; არ გადალახოთ ვალიდაციის ფილიალი.

| შეცდომის ტექსტი | მნიშვნელობა | უსაფრთხო პასუხი |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` აკლია, არასწორია ან არასწორი პაკეტიდან. | ხელახლა დააინსტალირეთ ერთი სრული პაკეტი სუფთა დადგმულ საქაღალდეში და შეინახეთ განკუთვნილი რეჟიმის მარკერი. |
| `invalid experience.mode` | `experience.mode` არ არის დოკუმენტირებული მნიშვნელობა. | გამოიყენეთ `auto`, `persistent_dedicated`, `temporary_dedicated` ან `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | ხელით ასლის პაკეტი კონფიგურირებული იყო, როგორც გამოყოფილი სერვერი. | აღდგენა `auto` ან `singleplayer_lan`; ავტომატურად არ მიუთითოთ იგი გარე სამყაროზე. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | გამოყოფილი პაკეტი კონფიგურირებული იყო ხელით ასლის სამუშაო ნაკადისთვის. | გამოიყენეთ `auto`, `persistent_dedicated` ან `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | საწყისი დღის ამომრჩევი არასწორია. | გამოიყენეთ ზუსტად `configured` ან `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | დღის რიგის ამომრჩეველი არასწორია. | გამოიყენეთ ზუსტად `sequential` ან `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | კონფიგურირებული საწყისი დღე არის წილადი ან ციკლის გარეთ. | გამოიყენეთ მთელი რიცხვი 1-დან `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | სარეზერვო ან ბოლო კარგი აღდგენა გამორთულია. | ორივე უსაფრთხოების საკეტის აღდგენა; RandomDay განზრახ უარს ამბობს სახიფათო ჩაწერაზე. |
| `external adapter transaction safety locks must remain true` | ადაპტერის შესწორება ან სარეზერვო დაცვა გამორთულია. | აღადგინეთ ორივე ადაპტერის უსაფრთხოების საკეტები ან გამორთეთ ადაპტერები ჯგუფურად. |
| `paths.world_name must be one folder name` | კონფიგურირებული მსოფლიო სახელი შეიცავს გამყოფს ან სახიფათო სიმბოლოს. | შეიყვანეთ მხოლოდ საქაღალდის ზუსტი სახელი ასოების, ციფრების, შუალედების, ქვედა ხაზის ან დეფისების გამოყენებით. |
| `required runtime directory unavailable` | მოთხოვნილი მოდ-ლოკალური გამომავალი დირექტორია ვერ შეიქმნა ან დადასტურდა. | შეამოწმეთ მხოლოდ დასახელებული RandomDay დირექტორია და მისი ჩაწერის უფლება. |

<a id="profile-wide-configuration-errors"></a>
## პროფილის კონფიგურაციის შეცდომები

ეს შეცდომები აჩერებს პროფილის მშენებლობას სავარჯიშოში ჩაწერამდე.

| შეცდომის ტექსტი | მნიშვნელობა | უსაფრთხო პასუხი |
|---|---|---|
| `sandbox.profile_overrides must be a table` | პროფილის მასშტაბით ოთხი არჩევანი შეიცვალა სხვა ლუას ტიპით. | აღადგინეთ დოკუმენტირებული ცხრილი `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | ცხრილი შეიცავს პარამეტრს, რომელიც არ არის ოთხი მხარდაჭერილი გასაღებიდან ერთ-ერთი. | ამოშალეთ დასახელებული გასაღები და გამოიყენეთ family/profile წყაროები Sandbox-ის სხვა პარამეტრებისთვის. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` ან `AllowIronMode` არ არის `true` ან `false`. | გამოიყენეთ არაციტირებული ლუა ლოგიკური. |
| `sandbox.profile_overrides.<key> must be integer` | მხარდაჭერის მნიშვნელობა არ არის მთელი რიცხვი. | გამოიყენეთ მთელი რიცხვი. |
| `sandbox.profile_overrides.<key> outside supported range` | მხარდაჭერის მნიშვნელობა არის გარეთ `0..1000`. | აირჩიეთ მთელი რიცხვი `0` `1000`. |

| `not_needed` | არ იყო საჭირო უკან დაბრუნება. | მოქმედება არ არის. |
| `original_held` | თავდაპირველი სამიზნე გადავიდა აღდგენის პოზიციაზე დაწინაურებამდე. | არ წაშალოთ აღდგენის ფაილი, სანამ ტრანზაქცია არასრულია. |
| `retained_after_success` | ახალი სამიზნე დადასტურებულია, მაგრამ აღდგენის მონაცემები რჩება, რადგან გასუფთავება მიუწვდომელი იყო ან განზრახ შენახული იყო. | დაამოწმეთ წარმოების ბაიტები რომელიმე დასახელებული აღდგენის ფაილის წაშლამდე. |
| `discarded_after_success` | ჩანაცვლება დადასტურდა და დროებითი დაბრუნების მონაცემები წაიშალა. | მოქმედება არ არის. |
| `rollback_failed` | აღდგენის მცდელობა ვერ დადასტურდა. | გააჩერეთ სერვერი და გამოიყენეთ ბოლო დადასტურებული ოპერაციის სარეზერვო ასლი. |
| `skipped_state_persistence_failed` | Sandbox ბაიტები მომზადდა, მაგრამ ბრუნვის მდგომარეობა არ შენარჩუნდა, ამიტომ გადამყვანები და მომზადებული მოთამაშის შეტყობინებები გამოტოვებულია. | გაშვების მდგომარეობის მდგომარეობის შეკეთება; არ გადააბრუნოთ ან ხელით წინ გადახვიდეთ რიგში. |
| `failed` | შემაჯამებელი მწკრივი წარმოადგენს ტერმინალის უკმარისობას, რომლის კონკრეტული მიზეზი არის `error` ან ტრანზაქციის ველები. | მიჰყევით პირველ კონკრეტულ კოდს; არ მოაგვაროთ პრობლემები `failed` მარტო. |

## თარგმანისა და შეტყობინების ვალიდაციის შეცდომები

ეს არის ლექსიკონის ან პრეზენტაცია-კონტრაქტის წარუმატებლობა. ისინი დამოწმებულია გამოშვებამდე და შესაძლოა გამოჩნდეს როგორც შეზღუდული გაშვების სტატუსის გაფრთხილება.

|---|---|---|
| `dictionary coverage mismatch` | პროფილის ლექსიკონი არ ხსნის ყველა დოკუმენტურ პარამეტრს. | დაამატეთ ლექსიკონში გამოტოვებული ჩანაწერი და ხელახლა გაუშვით პროფილი generation/validation. |
