# ტერმინი

> **კანონიკური ინგლისური წყარო:** [GLOSSARY.md](../../GLOSSARY.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ეს არის RandomDay დოკუმენტაცია. პროცედურები უკავშირდება ამ განმარტებებს იმის ნაცვლად, რომ ხელახლა განსაზღვრონ იგივე მდგომარეობა მრავალ სახელმძღვანელოში. სქემის სპეციფიკური ველის წესები რჩება [გაშვების დროის გამომავალი](%E1%B2%92%E1%B2%90%E1%B2%A8%E1%B2%95%E1%B2%94%E1%B2%91%E1%B2%98%E1%B2%A1_%E1%B2%93%E1%B2%A0%E1%B2%9D%E1%B2%98%E1%B2%A1_%E1%B2%A8%E1%B2%94%E1%B2%93%E1%B2%94%E1%B2%92%E1%B2%94%E1%B2%91%E1%B2%98.md).
