# უსაფრთხოების პოლიტიკა

> **კანონიკური ინგლისური წყარო:** [SECURITY.md](../../../SECURITY.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDay წერს სერვერის კონფიგურაციის ფაილებს და შეუძლია არჩევითი mod კონფიგურაციის ფაილების დაყენება. განიხილეთ ცვლილებები, როგორც ოპერაციულად მგრძნობიარე.

<a id="do-not-report-as-security-issues"></a>
## არ შეატყობინოთ უსაფრთხოების საკითხებს

- თამაშის ნორმალური ბალანსი იცვლება.
- მოსალოდნელია შემდეგი გადატვირთვის პროფილის როტაცია.

<a id="report-privately"></a>
## შეტყობინება პირადად

- გზის გავლის რისკები.
- არაუსაფრთხო ფაილის ჩაწერის ქცევა.
- შესაძლოა ფაილების გადაწერა server/mod ბილიკები.
- მავნე ბრძანების შესრულება.

სანამ საჯარო უსაფრთხოების არხი იარსებებს, შეატყობინეთ პირადად საცავის მფლობელს.
