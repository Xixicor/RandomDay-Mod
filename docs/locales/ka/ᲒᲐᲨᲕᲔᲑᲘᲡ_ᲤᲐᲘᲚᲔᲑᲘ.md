# გაშვების დროის ფაილების და სტატუსის მოძებნა

> **კანონიკური ინგლისური წყარო:** [RUNTIME_FILES.md](../../RUNTIME_FILES.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ეს არის კანონიკური ბილიკის ინვენტარი, რომელსაც იყენებენ ოპერატორები და წყაროს მიკვლევადობა. ის პასუხობს სად არის ფაილი, ვინ წერს მას, როდის იცვლება, რამდენ ხანს რჩება და რომელ აღდგენის როლს ასრულებს. [გაშვების დროის გამომავალი მითითება](%E1%B2%92%E1%B2%90%E1%B2%A8%E1%B2%95%E1%B2%94%E1%B2%91%E1%B2%98%E1%B2%A1_%E1%B2%93%E1%B2%A0%E1%B2%9D%E1%B2%98%E1%B2%A1_%E1%B2%A8%E1%B2%94%E1%B2%93%E1%B2%94%E1%B2%92%E1%B2%94%E1%B2%91%E1%B2%98.md) ფლობს სქემებს, ველების მნიშვნელობებს, ცარიელ მდგომარეობებს და მანქანის მნიშვნელობის ინტერპრეტაციას.

ამ სახელმძღვანელოში ყველა ბილიკი შეესაბამება დაინსტალირებულს `RandomDay/` საქაღალდე, თუ სხვა რამ არ არის მითითებული. Runtime-ის შედეგები იქმნება ინსტალაციის შემდეგ; ისინი გამორიცხულია გამოშვების ZIP-ებიდან.

### აცნობეთ ფაილის ცარიელი და წარუმატებელი მდგომარეობა

- შეიძლება შეიქმნას დაკარგული ძირითადი ან სარკის სამიზნე. არასწორი პროფილი, მომლოდინე ჩაწერა, დაწინაურება ან პროდუქციის წაკითხვის მარცხი მზად არ არის. სარკისებური უკმარისობა არ ცვლის მიღებულ პირველად შედეგს.
- `runtime/singleplayer_manual/SandboxSettings.ini` შეიძლება შეიქმნას პირველი ხელით გაშვებისას. გენერირების წარუმატებლობა რჩება ხილული სტატუსისა და ჟურნალის გამომავალში.
-  წაუკითხავი `rotation_state.txt` შეიძლება დაუბრუნდეს ბოლო კარგ მდგომარეობას ან მარკერზე დაფუძნებულ ჩამტვირთველს. წარუმატებელი მდგომარეობის დასრულება აწარმოებს `degraded_state_persistence`.
- `runtime/last_good/` შეიძლება არ იყოს პირველი დადასტურებული სამიზნემდე. თუ დაწყვილებული მანიფესტის განახლება ვერ მოხერხდა, RandomDay აღადგენს წინა მიღებულ წყვილს.
- `runtime/backups/mirror_<operation>/` არის სარკისებური სარეზერვო მდებარეობა. არ არსებობს პირველადი ან სარკისებური სარეზერვო ფაილი, როდესაც ეს სამიზნე არ არსებობდა ტრანზაქციამდე.
- ადაპტერის მუტაცია არ იწყება, როდესაც მისი სარეზერვო შექმნა ან წაკითხვა ვერ ხერხდება.
- ამჟამინდელი სტატუსი, ლექსიკონი ან გადახედვის ფაილები შეიძლება არ იყოს, როდესაც გაშვების სტატუსის გამომავალი მიუწვდომელია ან არასრულია.
- ან `export_failed` შედეგმა შეიძლება დატოვოს ძველი `today.json` ადგილზეა. Sandbox წარუმატებლობის განახლებები JSON მაგრამ არ ქმნის ახალ წარუმატებლობას HTML გვერდი; შეადარეთ დროის ანაბეჭდები `UE4SS.log`.
- მორჩენილი მომლოდინე გვერდითი კარა ამოღებულია ახალ მცდელობამდე; გაწმენდის წარუმატებლობა აჩერებს ტრანზაქციას. თუ ორივე საწარმოო სამიზნე და უკან დაბრუნების გვერდითი მანქანა არსებობს, RandomDay ინახავს აღდგენის ბაიტებს განსახილველად.
- არა `[RandomDay]` საწყისი ხაზი `UE4SS.log` ნიშნავს, რომ რეჟიმის ჩატვირთვა არ დადასტურდა.

## შეინარჩუნეთ აღდგენის მტკიცებულება
