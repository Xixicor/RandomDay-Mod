# Kebijakan keamanan

> **Sumber kanonis bahasa Inggris:** [SECURITY.md](../../../SECURITY.md). Dokumentasi yang dilokalkan ini mempertahankan perintah, jalur, kunci, nilai status, hash, dan nama file yang tepat. Jika kata-kata teknisnya berbeda, gunakan sumber bahasa Inggris.


RandomDay menulis file konfigurasi server dan dapat menambal file konfigurasi mod opsional. Perlakukan perubahan sebagai hal yang sensitif secara operasional.

<a id="do-not-report-as-security-issues"></a>
## Jangan laporkan sebagai masalah keamanan

- Keseimbangan gameplay normal berubah.
- Rotasi profil reboot berikutnya diharapkan.

<a id="report-privately"></a>
## Laporkan secara pribadi

- Risiko penjelajahan jalur.
- Perilaku penulisan file yang tidak aman.
- Kemampuan untuk menimpa file di luar yang dimaksudkan server/mod jalur.
- Eksekusi perintah berbahaya.

Sampai ada saluran keamanan publik, laporkan secara pribadi kepada pemilik repositori.
