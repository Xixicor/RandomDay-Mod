## v0.3.16-alpha

- Menambahkan dua paket lengkap: satu untuk server khusus dan satu lagi untuk dunia singleplayer atau LAN.
- Menambahkan mode server khusus yang persisten dan sementara, profil awal yang dapat dikonfigurasi, dan perkembangan acak yang berurutan atau tidak berulang.
- Memperluas perpustakaan menjadi tujuh belas kelompok profil dengan masing-masing tujuh belas profil keluarga.
- Menambahkan status profil active/prepared yang dapat dibaca, pemberitahuan pemain ringkas, penulisan sandbox yang aman, pencadangan terverifikasi, readback, dan rollback.
- Menambahkan adaptor opsional yang diperiksa tata letak untuk mod pendamping yang didukung.
- Menambahkan kontrol seluruh profil persisten untuk Mode Tegar, Mode Besi, dukungan struktural, dan dukungan jembatan di konfigurasi server publik.
- Menambahkan perpustakaan panduan bahasa Inggris yang lengkap dan 27 halaman entri yang dilokalkan.
- Memvalidasi paket rilis sebagai tata letak yang bersih, deterministik, dan case-safe UE4SS tanpa konfigurasi pribadi atau data runtime.
