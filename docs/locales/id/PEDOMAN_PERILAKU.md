# Pedoman perilaku

> **Sumber kanonis bahasa Inggris:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). Dokumentasi yang dilokalkan ini mempertahankan perintah, jalur, kunci, nilai status, hash, dan nama file yang tepat. Jika kata-kata teknisnya berbeda, gunakan sumber bahasa Inggris. Terjemahan ini bersifat informatif; kontrol teks hukum bahasa Inggris.


Menjaga laporan tetap teknis, dapat direproduksi, dan terhormat.

Repositori ini adalah untuk pengembangan mod server yang terkontrol. Laporan bug harus mencakup log, jalur, perilaku yang diharapkan, dan perilaku aktual.
