# RandomDay dokumentasi profil

> **Sumber kanonis bahasa Inggris:** [README.md](../../../profiles/README.md). Dokumentasi yang dilokalkan ini mempertahankan perintah, jalur, kunci, nilai status, hash, dan nama file yang tepat. Jika kata-kata teknisnya berbeda, gunakan sumber bahasa Inggris.


Versi: `v0.3.16-alpha`

- Keluarga: **17**
- Profil: **289**
- SandboxSettings entri kamus: **46**

Pilih keluarga berdasarkan maksud gameplay di [panduan pilihan profil](../PILIH_PROFIL.md), lalu gunakan indeks yang dihasilkan ini untuk nilai yang tepat.

File-file ini dihasilkan dari sumber runtime Lua dan dictionary/translation kontrak. Mereka menunjukkan `sandbox.profile_overrides` default; nilai yang dikonfigurasi satu server mungkin berbeda:

- `profiles.generated.json`: profil yang dapat dibaca mesin, nilai mentah, kamus, dan terjemahan.
- `FULL_PROFILE_REFERENCE.md`: aturan indeks dan interpretasi lengkap.
- `SANDBOX_SETTINGS_KEYS.md`: kamus 46 kunci lengkap.
- `families/*.md`: referensi keluarga terperinci selama 17 hari.

Buat kembali dengan: `python -B tools/generate_profile_docs.py` Periksa penyimpangan dengan: `python -B tools/generate_profile_docs.py --check`
