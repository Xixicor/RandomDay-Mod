# Pemberitahuan pihak ketiga

> **Sumber kanonis bahasa Inggris:** [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). Dokumentasi yang dilokalkan ini mempertahankan perintah, jalur, kunci, nilai status, hash, dan nama file yang tepat. Jika kata-kata teknisnya berbeda, gunakan sumber bahasa Inggris. Terjemahan ini bersifat informatif; kontrol teks hukum bahasa Inggris.


RandomDay adalah mod komunitas independen untuk Faktor Abiotik dan UE4SS.

Adaptor opsional dapat memperbarui tata letak konfigurasi yang dikenali milik mod yang dipasang secara terpisah. Mod tersebut tidak disertakan, disalin, atau didistribusikan ulang dengan RandomDay. Namanya tetap menjadi milik penulisnya masing-masing.

Lihat `docs/SUPPORTED_ADAPTERS.md` untuk tata letak persis yang saat ini dikenali.
