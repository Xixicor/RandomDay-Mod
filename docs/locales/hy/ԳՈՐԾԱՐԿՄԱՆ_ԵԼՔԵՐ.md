# Մեկնաբանեք գործարկման վիճակի և ելքային սխեմաները

> **Կանոնական անգլերեն աղբյուր:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Սա կանոնական դաշտի ամբողջական սխեմայի ուղեցույցն է: Այն պատասխանում է, թե ինչ է նշանակում յուրաքանչյուր դաշտ, վիճակ, դատարկ արժեք և մեքենայի արդյունք: Օգտագործեք [գործարկման ֆայլի քարտեզ](%D4%B3%D5%88%D5%90%D4%BE%D4%B1%D5%90%D4%BF%D5%84%D4%B1%D5%86_%D4%BA%D4%B1%D5%84%D4%B1%D5%86%D4%B1%D4%BF%D4%BB_%D5%96%D4%B1%D5%85%D4%BC%D4%B5%D5%90.md) արտադրողների, ուղիների, գրելու ժամանակի, պահպանման, գործարքների կողային մասերի և վերականգնման վայրերի համար:

Այս ուղեցույցի բոլոր ուղիները հարաբերական են տեղադրված `RandomDay/` թղթապանակ, եթե տողում հստակ նշված չէ կազմաձևված ավազատուփը կամ կամընտիր ադապտերի թիրախը: Runtime արդյունքները ստեղծվում են տեղադրումից հետո և չեն հանդիսանում ZIP.

<a id="choose-the-authoritative-view"></a>
## Ընտրեք հեղինակավոր տեսքը

| Անհրաժեշտ է | Հեղինակավոր աղբյուր |
|---|---|
| Ընթացիկ գործընթացով բեռնված կանոններ | RandomDay նշիչը `SandboxSettings.ini` կարդալ գործարկման ժամանակ |
| Պատրաստված է հերթերի հաշվապահություն | `runtime/rotation_state.txt`, սխեմա `1` |
| Մանրամասն տեղական կարգավիճակ | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| Հանրային մեքենանընթեռնելի կարգավիճակ | `web_export/today.json`, սխեմա `2` և `randomday_public_status_v2` |
| Մարդու կողմից ընթերցվող կարգավիճակ | `web_export/today.html`՝ ստացված նույն հանրային կարգավիճակի անցումից |
| Թարգմանական բառապաշար | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| Խաղացողի ճշգրիտ սահմանափակված ծանուցում | `runtime/current/player_message_preview.txt` |

HTML դիտումը, նախադիտումը և թարգմանված ամփոփագրերը ստացված դիտումներ են: Նրանք չեն անտեսում ավազատուփի նշիչը, գործարքի արդյունքը կամ չմշակված պրոֆիլի արժեքները: Գտեք վերջին հայտնի ֆայլերը, գործառնական կրկնօրինակները, կողային վահանակները, հայելիները, ադապտերների թիրախները և `UE4SS.log` [Գործարկման ժամանակի ֆայլեր](%D4%B3%D5%88%D5%90%D4%BE%D4%B1%D5%90%D4%BF%D5%84%D4%B1%D5%86_%D4%BA%D4%B1%D5%84%D4%B1%D5%86%D4%B1%D4%BF%D4%BB_%D5%96%D4%B1%D5%85%D4%BC%D4%B5%D5%90.md).

<a id="rotation-state-schema"></a>
## Պտտման վիճակի սխեման

`runtime/rotation_state.txt` օգտագործում է սխեման `1` և պարունակում է մեկ `key=value` զույգ յուրաքանչյուր տողում՝

| Դաշտ | Իմաստը |
|---|---|
| `schema_version` | Պետք է լինի `1`. |
| `mod_version` | Փաթեթի ինքնությունը կարդացվել է `.randomday_version`. |
| `rotation_id` | Ընտանեկան փաթեթի ընթացիկ փոխանցման նույնացուցիչը: |
| `mode` | `selected_run`, `non_repeating_random_run` կամ `rotation_run`. |
| `available_families` | Կազմաձևման զտումից հետո ստորակետերով բաժանված համապատասխան ընտանիքի ID-ները: |
| `remaining_families` | Պատասխան ընտանիքները դեռ ընտրված չեն ընթացիկ չկրկնվող անցագրում: |
| `completed_families` | Ընտանիքներ, որոնց 17 պաշտոնի ամբողջական պատվերը լրացվել է ընթացիկ անցումով: |
| `active_family`, `active_day` | Ակտիվ նշիչի տեղեկատվությունը գրանցված է ընտրությունը կատարելիս: Sandbox նշիչը հեղինակավոր է հաջորդ բեռնման ժամանակ: |
| `prepared_family`, `prepared_day` | Պրոֆիլը պահվում է հաջորդ վերագործարկման համար: |
| `active_run_id` | Ընտանեկան գործարկվող նույնացուցիչ՝ կապված պատրաստված ընտրության հետ: |
| `last_status` | Օրացույցի ընտրված վիճակ, որը ստեղծել է այս ֆայլը: |
| `session_mode` | լուծված է մշտական ​​հատկացված, ժամանակավոր հատկացված կամ singleplayer/LAN կյանքի ցիկլը: |
| `start_day_mode` | Կազմաձևված կամ մեկանգամյա պատահական մեկնարկի ընտրություն նոր գործարկման համար: |
| `day_progression_mode` | Փաթաթված հաջորդական կամ չկրկնվող պատահական առաջընթաց: |
| `day_order` | Ստորակետերով բաժանված պահպանվող օրվա ID-ները ճշգրիտ հերթականությամբ, որոնք կպատրաստվեն: |
| `day_position` | Պատրաստված օրվա դիրքը `day_order`. |
| `updated_at` | Օպերատորի համեմատության տեղական գրելու ժամանակը: |

Պետական ​​գրությունը ընդունվում է միայն այն դեպքում, երբ սխեմայի նշիչը, պատրաստված ընտանիքը և նախապատրաստված օրը ճիշտ կարդում են: Անընթեռնելի ընթացիկ ֆայլը կարող է վերադառնալ `rotation_state.last_good.txt`; ընտրված ավազատուփի նշիչը դեռևս որոշում է, թե ինչ է խաղը բեռնել ընթացիկ գործընթացի համար:

<a id="runtime-status-json"></a>
## Գործարկման ժամանակի կարգավիճակ JSON

`runtime/current/randomday_status.json` օգտագործում է `status_schema=randomday_runtime_status_v2`: Դրա հիմնական դաշտային խմբերն են՝

| Խումբ | Դաշտեր և մեկնաբանություն |
|---|---|
| Ինքնությունը | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| Ընտրություն | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| Ակտիվ | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| Պատրաստված է | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| Մարդկային ամփոփագրեր | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| Գրեք ապացույց | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| Ադապտորների ապացույց | `adapter_status`, `adapter_results`; ադապտերների յուրաքանչյուր գրառում պարունակում է համատեղելիության ապացույցներ, transaction/rollback վիճակ, փոխված ֆայլերի քանակ և ուղղված թիրախային հղումներ |
| Սահմաններ | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| Ախտորոշում | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

Անհայտ ակտիվ արժեքները նշանակում են, որ ընթացիկ ավազատուփը չի պարունակում ընթեռնելի RandomDay նշիչ: Դրանք չպետք է փոխարինվեն պատրաստված արժեքներով։ Ադապտորների ուղիները `runtime/` վերածվում է բազային անվանման հղումի, իսկ ախտորոշիչ տողերը վերացնում են հայտնաբերված բացարձակ ուղիները:

<a id="public-status-json"></a>
## Հանրային կարգավիճակ JSON

`web_export/today.json` օգտագործում է `schema_version=2` և `status_schema=randomday_public_status_v2`: Այն կրկնում է ինքնությունը, active/prepared, ընտրություն, գործարք, ադապտեր և վերագործարկման սահմանային փաստեր, որոնք անհրաժեշտ են օպերատորին: Այն նաև ներառում է՝

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` և `prepared_day_position`;
- `family_selection_mode`, ժառանգություն `family_locked_until_day_17` և `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families` և դրանց թիվը;
- պատրաստված հանդիպման պրոֆիլ, մակարդակ, թեմա և խառը հանդիպման հնարավորություն;
- աշխարհի տիրույթի ակտիվացում, բաց աշխարհի կարգավորում, անհայտ աշխարհի քաղաքականություն և միայն կազմաձևված բացառված աշխարհի օրինաչափություններ.
- պատրաստված հաղորդագրություն և համակցված հաղորդագրությունների նախադիտումներ;
- `selected_at`, `sandbox_target`, `manual_copy_required` և պատրաստված հեշ:

`profile_status`-ը `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` կամ `write_failed_or_rollback`. `prepared_ready=true` դեռ չի նշանակում ակտիվ; ուշ գործարկման նշիչը պահանջվում է:

<a id="dictionary-and-translation-output"></a>
## Բառարան և թարգմանություն

`runtime/current/randomday_dictionary.json` օգտագործում է `schema=randomday_runtime_dictionary_v2` և նույնականացնում է բառարանի տարբերակը `randomday_dictionary_v2`: Այն նկարագրում է փաթեթի ռեժիմները, ընտրության վիճակները, ճնշման տիրույթները, պարամետրերի պիտակները, հումքի արժեքները և պարզ լեզվով իմաստները: Անհայտ արժեքները մնում են հստակ՝ վստահ նկարագրության փոխարկվելու փոխարեն:

`player_message_preview.txt`, `today.json`, `today.html`, իսկ խաղի ներսում ծանուցումները նույն թարգմանության մոդուլից ստացված դիտումներ են: Հիմնական պրոֆիլը և հումքը `SandboxSettings.ini` արժեքները մնում են ճշմարտության աղբյուր:

<a id="failure-and-recovery-rules"></a>
## Խափանման և վերականգնման կանոններ

1. Չհաջողված սպասող գրությունը կամ վավերացումը երբեք չի դառնում արտադրության թիրախ:
2. Չհաջողված առաջխաղացումը կամ արտադրության հետադարձ ընթերցումը խթանում է պահված բնօրինակի վերականգնումը. գործողության կրկնօրինակը այն հետադարձն է, երբ վերականգնումը ձախողվում է:
3. Պահպանված հետադարձ ֆայլ կամ `rollback_failed` կարգավիճակը պահանջում է ձեռքով վերանայում, մինչ խաղը կամ սերվերը դադարեցված է:
