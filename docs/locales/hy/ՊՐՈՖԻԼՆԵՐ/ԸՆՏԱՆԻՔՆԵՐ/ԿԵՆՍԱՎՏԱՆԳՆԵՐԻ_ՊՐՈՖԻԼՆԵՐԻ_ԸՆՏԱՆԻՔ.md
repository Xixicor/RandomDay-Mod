<a id="day-1---acceptable-contamination"></a>
## Օր 1 - Ընդունելի աղտոտում

**Պրոֆիլի ID՝** `biohazard_acceptable_contamination` **Ընդհանուր պայմաններ.** Ստանդարտ ճնշում (2.03/5) **Պարզ իմաստ՝** Ստանդարտ ճնշում: Գոյատևման ճնշում. պահանջկոտ պայմանները հիմնական ճնշումն են: Շրջակա միջավայրի ճնշում. Ստանդարտ ճնշումը հաջորդ ամենաուժեղ գործոնն է: **Խաղացողի խորհուրդ.** Տարեք սնունդ և ջուր, հանգստացեք երկար ճանապարհորդություններից առաջ և պլանավորեք անվտանգ կանգառներ:

<a id="main-effects"></a>

- Կույտի հզորությունը նորմալից շատ բարձր է (2x).

**Պրոֆիլի ID՝** `biohazard_night_disinfection_failure` **Ընդհանուր պայմաններ.** Ստանդարտ ճնշում (2.28/5) **Պարզ իմաստ՝** Ստանդարտ ճնշում: Գոյատևման ճնշում. պահանջկոտ պայմանները հիմնական ճնշումն են: Մարտական ​​ճնշում. ## Օր 14 - Մատակարարման պահարան Ստերիլ-իշ

**Պրոֆիլի ID՝** `biohazard_supply_closet_sterile_ish` **Ընդհանուր պայմաններ.** Բարենպաստ պայմաններ (1.16/5) **Պարզ իմաստ՝** Բարենպաստ պայմաններ. Շրջակա միջավայրի ճնշումը. բարենպաստ պայմանները հիմնական ճնշումն են: Գոյատևման ճնշում. բարենպաստ պայմանները հաջորդ ամենաուժեղ գործոնն է: **Խաղացողի խորհուրդ.** Օգտագործեք բարենպաստ պայմանները ուսումնասիրելու, համալրելու, վերանորոգելու և հաջորդ վերագործարկմանը պատրաստվելու համար:
