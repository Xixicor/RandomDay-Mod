# Աջակցվող ընտրովի ռեժիմներ

> **Կանոնական անգլերեն աղբյուր:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


RandomDay կարող է ստիպել առանձին տեղադրված ռեժիմը հետևել ակտիվ RandomDay պրոֆիլ: Այս հատկությունը հասանելի է միայն հատուկ սերվերային փաթեթում: singleplayer/LAN փաթեթը երբեք չի խմբագրում այլ ռեժիմ:

RandomDay-ը չի ներառում կամ վերաբաշխում այստեղ թվարկված ռեժիմներից որևէ մեկը: Տեղադրեք և միացրեք յուրաքանչյուր ընտրովի ռեժիմ իր սեփական Nexus էջից և նախ հետևեք դրա հեղինակի հրահանգներին: RandomDay փոխում է միայն ճանաչված կարգավորումները, որոնք արդեն առկա են տեղադրված ֆայլում: Այն չի ավելացնում գործառույթներ մեկ այլ ռեժիմում, և ադապտերը կարող է անջատվել առանց այդ ռեժիմը հեռացնելու: Նվիրված սերվերի փաթեթը սկսվում է `external_mods.enabled = true`.

## Ինչպես է ճանաչումը պաշտպանում մեկ այլ ռեժիմ

Ծանոթ ֆայլի անուն գտնելը բավարար չէ: Գրելուց առաջ RandomDay-ը ստուգում է, որ այդ ադապտերի համար անհրաժեշտ բոլոր կարգավորումները առկա են թիրախային ֆայլում: Այն կարկատում է միայն առկա առաջադրանքները. այն երբեք չի հորինում բացակայող պարամետր:

Ճանաչված դասավորության համար RandomDay կատարում է մեկ սահմանափակ գործարք.

1. հաշվեք ակտիվ պրոֆիլի համար նախատեսված յուրաքանչյուր արժեքը;
2. ստեղծեք և բայթ-ստուգեք յուրաքանչյուր թիրախային ֆայլի կրկնօրինակում;
3. գրել եղբոր կամ եղբոր սպասող ֆայլի միջոցով;
4. խթանեք առկախ ֆայլը և հետ կարդացեք պահված բայթերը;
5. հաստատեք բոլոր նախատեսված արժեքը;
6. օգտագործեք ավտոմատ վերականգնում հաստատված կրկնօրինակներից, եթե որևէ քայլ ձախողվի:

DynamicSpawns-ը կարող է ներառել իր կարգավորումները և ճանաչված նվագարկիչ-հաղորդագրությունների ֆայլերը մեկ գործարքում: RandomDay-ը չի հայտնում այդ բազմաֆայլ թարմացումը որպես հաջող, քանի դեռ ամբողջական գործարքն ավարտված չէ:

<a id="read-an-adapter-result"></a>
## Կարդացեք ադապտերների արդյունքը

| Արդյունք | Իմաստը |
| --- | --- |
| `applied` | Ճանաչված կարգավորումները փոխվել են և հետ են անցել: |
| `already_current` | Ճանաչված կարգավորումներն արդեն համընկնում էին ակտիվ պրոֆիլի հետ: |
| `not_installed` | Ընտրովի ռեժիմը չի գտնվել: RandomDay շարունակվեց առանց դրա: |
| `skipped_incompatible` | Գտնվել է ֆայլ, սակայն դրա ամբողջական կարգավորումների դասավորությունը չի ճանաչվել: Ոչինչ չի փոխվել: |
| `partial` | Առաջնային DynamicSpawns կարգավորումները կիրառվել են, սակայն կամընտիր թարգմանված հաղորդագրության ֆայլը չի ​​ավարտվել: Դիտեք գրանցված ադապտերների արդյունքը: |
| `failed_rolled_back` | Գործարքը ձախողվեց, և նախորդ բայթերը մնացին անփոփոխ կամ վերականգնվեցին և հաստատվեցին: |
| `rollback_failed` | RandomDay չկարողացավ հաստատել փոփոխությունը կամ վերականգնումը: Պահպանեք ազդակիր ռեժիմը և վերականգնեք դրա գրանցված կրկնօրինակը ձեռքով: |

Բացակայող և անհամատեղելի ընտրովի ռեժիմները չեն դադարում RandomDay's ավազարկղի պտտումը առաքված կազմաձևման ներքո:

<a id="enable-or-disable-integrations"></a>
## Միացնել կամ անջատել ինտեգրումները

Կարգավորումները գտնվում են հետևյալում.

```text
RandomDay/Scripts/ax_config/server.lua
```

Նվիրված սերվերի փաթեթը առաքվում է հետևյալով`

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- Սահմանել `enabled = false` դադարեցնել RandomDay յուրաքանչյուր ընտրովի ռեժիմ ստուգելուց կամ փոխելուց:
- Հեռացրեք մեկ ադապտեր ID-ն` այդ ռեժիմը հանգիստ թողնելու համար, մինչդեռ մյուս ինտեգրումները ակտիվ պահեք:
- Պահպանեք `patch_only_existing_keys` և `backup_before_write` սահմանվել է `true`: Դրանք գրելու-անվտանգության սահմանն են:
- Պահպանեք `optional_by_default = true`, եթե յուրաքանչյուր թվարկված կամընտիր ռեժիմը սերվերի պարտադիր մասն է: Սահմանելով այն `false`-ը ստիպում է բացակայող, անհամատեղելի կամ ապահով կերպով վերադարձված ադապտերն ազդել ընդհանուր արդյունքի վրա:

Դուք պետք չէ հեռացնել կամ անջատել կամընտիր ռեժիմը, երբ անջատեք այն RandomDay ադապտեր:

## Շնորհակալություն և սեփականության իրավունք

Շնորհակալություն [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156), [Մահացու լազերներ](https://www.nexusmods.com/abioticfactor/mods/141) և [ANTE Վերև](https://www.nexusmods.com/abioticfactor/mods/201): Նրանց ռեժիմները մնում են առանձին ներբեռնումներ, որոնք ղեկավարվում են իրենց սեփական էջերով, թույլտվություններով և աջակցության հրահանգներով: RandomDay's ադապտերներն օգտագործում են միայն տեղադրված, ճանաչված դասավորության մեջ առկա կազմաձևման դաշտերը; նրանք չեն վերաբաշխում կամ փոխարինում այդ ռեժիմները:

<a id="backups-and-manual-recovery"></a>
## Պահուստավորում և ձեռքով վերականգնում

Նախապես գրելու հաստատված պատճենները պահպանվում են հետևյալում.

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

Եթե `rollback_failed` հայտնվում է.

1. դադարեցնել խաղը կամ սերվերը;
2. սահմանել `external_mods.enabled = false` կամ հեռացնել վնասված ադապտեր ID-ն;
3. պահպանեք ընթացիկ թիրախային ֆայլը և նրա եղբայրը pending/rollback ֆայլեր;
4. համապատասխանեցրեք համարակալված պահուստային ֆայլերը ադապտերների արդյունքում գրանցված թիրախային ուղիներին.
5. վերականգնեք ստուգված բայթերը, քանի դեռ ծառայությունը դադարեցված է;
6. գործարկեք կամընտիր ռեժիմն ինքնուրույն, նախքան այն նորից միացնելը RandomDay ադապտեր:

Մի պարտադրեք համատեղելիությունը` վերանվանելով կարգավորումները կամ ավելացնելով բացակայող ստեղները: Օգտագործեք ճանաչված դասավորություն, թողեք ադապտերն անջատված կամ ավելացրեք նոր տարբերակի հարմարանք և գործարքի փորձարկում՝ նախքան աջակցության հայցը ընդլայնելը:
