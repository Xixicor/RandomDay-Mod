# Կարգավիճակի և սխալի հղում

> **Կանոնական անգլերեն աղբյուր:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Օգտագործեք ճշգրիտ `status`, `transaction_status`, `rollback_status` և `error` արժեքներ գործարկման ժամանակի արտահանումից: Վահանակի կամ վահանակի նման ձևակերպումները չեն կարող փոխարինել այդ դաշտերին:

Այս բաժինը ամբողջական որոնման հղումն է: Վերևում գտնվող որոշման ծառն ընտրում է համապատասխան կատեգորիա. այս աղյուսակները պահպանում են մեքենայի ճշգրիտ արժեքները և անվտանգ օպերատորի պատասխանները:

<a id="normal-or-informational-states"></a>
## Նորմալ կամ տեղեկատվական վիճակներ

| Կարգավիճակ | Իմաստը | Օպերատորի պատասխան |
|---|---|---|
| `prepared_for_next_reboot` | Հաջորդ բեռնման համար գրվել է վավերացված պրոֆիլ: | Ոչ մի գործողություն; ընթացիկ նստաշրջանն անփոփոխ է: |
| `next_reboot_already_prepared` | Նախատեսված հաջորդ պրոֆիլն արդեն համապատասխանում է նպատակին: | Ոչ մի գործողություն; մի ստիպեք այլ պտույտ կատարել: |
| `already_current` / `unchanged` | Թիրախն արդեն պարունակում է նախատեսված բայթերը: | Գործողություն չկա: |
| `applied` | Գրման և արտադրության ընթերցումն անցել է: | Հաստատեք active/prepared տարբերակում հաջորդ բեռնումից հետո: |
| `bootstrap_prepare_first_family_start_day` | Նախօրոք պտտվող վիճակ գոյություն չի ունեցել, ուստի կազմաձևված առաջին օրը պատրաստվել է: | Ակնկալվում է առաջին օգտագործման ժամանակ: |
| `state_recovery_rewrite_prepared_profile_no_reroll` | Պահված վիճակը վերականգնվել է, և նույն պատրաստված պրոֆիլը վերագրվել է: | Ստուգեք վերականգնված օրը; նոր պատահական ընտրություն տեղի չի ունեցել: |
| `supervision_reconfirm_prepared_profile_no_advance` | Վերահսկողության անցագիրը հաստատեց առկա նախապատրաստումը: | Սպասվում է; հերթը երկու անգամ չի առաջացել: |
| `external_mods_disabled` | Ընտրովի ադապտերների մշակումն անջատված է: | Ոչ մի գործողություն, եթե նախատեսված չեն ադապտերներ: |
| `external_mods_processed` | Միացված ադապտերների բոլոր պլանները հասել են վերջնական արդյունքի: | Դիտեք ադապտերների յուրաքանչյուր տող: |

<a id="startup-configuration-errors"></a>
## Գործարկման կազմաձևման սխալներ

Այս հաղորդագրությունները դադարեցնում են գործարկումը մինչև RandomDay գրում է պրոֆիլ: Ուղղեք անվանված պարամետրը կամ փաթեթի նշիչը. մի շրջանցեք վավերացման ճյուղը:

| Սխալի տեքստ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` բացակայում է, սխալ ձևավորված է կամ սխալ փաթեթից է: | Վերատեղադրեք մեկ ամբողջական փաթեթ մաքուր փուլային թղթապանակում և պահպանեք նախատեսված ռեժիմի նշիչը: |
| `invalid experience.mode` | `experience.mode`-ը փաստաթղթավորված արժեքներից չէ: | Օգտագործեք `auto`, `persistent_dedicated`, `temporary_dedicated` կամ `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | Ձեռքով պատճենահանման փաթեթը կազմաձևվել է որպես հատուկ սերվեր: | Վերականգնել `auto` կամ `singleplayer_lan`; ինքնաբերաբար մի ուղղեք այն արտաքին աշխարհի վրա: |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | Ձեռքով պատճենահանման աշխատանքային հոսքի համար կազմաձևվել է հատուկ փաթեթ: | Օգտագործեք `auto`, `persistent_dedicated` կամ `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | Սկզբնական օրվա ընտրիչն անվավեր է: | Օգտագործեք հենց `configured` կամ `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | Օրվա կարգի ընտրիչն անվավեր է: | Օգտագործեք հենց `sequential` կամ `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | Կազմաձև մեկնարկի օրը կոտորակային է կամ ցիկլից դուրս: | Օգտագործեք ամբողջ թիվ 1-ից մինչև `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | Պահուստավորումը կամ վերջին լավ վերականգնումն անջատված է: | Վերականգնել երկու անվտանգության կողպեքները; RandomDay միտումնավոր հրաժարվում է ոչ անվտանգ գրառումներից: |
| `external adapter transaction safety locks must remain true` | Ադապտերի կարկատումը կամ պահուստավորման պաշտպանությունն անջատված է: | Վերականգնեք երկու ադապտերների անվտանգության կողպեքները կամ անջատեք ադապտերները որպես խումբ: |
| `paths.world_name must be one folder name` | Կազմաձևված աշխարհի անունը պարունակում է տարանջատիչ կամ անապահով նիշ: | Մուտքագրեք միայն թղթապանակի ճշգրիտ անունը՝ օգտագործելով տառեր, թվեր, բացատներ, ընդգծումներ կամ գծիկներ: |
| `required runtime directory unavailable` | Պահանջվող mod-local ելքային գրացուցակը չհաջողվեց ստեղծել կամ հաստատել: | Ստուգեք միայն անվանված RandomDay գրացուցակը և դրա գրելու թույլտվությունը: |

<a id="profile-wide-configuration-errors"></a>
## Ամբողջ պրոֆիլի կազմաձևման սխալներ

Այս սխալները դադարեցնում են պրոֆիլի կառուցումը նախքան ավազարկղում գրելը:

| Սխալի տեքստ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `sandbox.profile_overrides must be a table` | Չորս պրոֆիլի ընտրանքները փոխարինվեցին Lua-ի մեկ այլ տեսակով: | Վերականգնել փաստաթղթավորված աղյուսակը `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | Աղյուսակը պարունակում է կարգավորում, որը չորս աջակցվող բանալիներից չէ: | Հեռացրեք անվանված բանալին և օգտագործեք family/profile աղբյուրներ այլ sandbox կարգավորումների համար: |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` կամ `AllowIronMode`-ը `true` կամ `false`. | Օգտագործեք չակերտավոր Լուա բուլյան: |
| `sandbox.profile_overrides.<key> must be integer` | Աջակցող արժեքը ամբողջ թիվ չէ: | Օգտագործեք ամբողջ թիվ: |
| `sandbox.profile_overrides.<key> outside supported range` | Աջակցման արժեքը դուրս է `0..1000`. | Ընտրեք ամբողջ թիվ `0`-ից մինչև `1000`. |

<a id="rollback-and-intermediate-states"></a>
## Վերադարձ և միջանկյալ վիճակներ

| Արժեք | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `not_started` / `pending` | Գործարքի կամ ադապտերների պլանը վերջնական արդյունքի չի հասել: | Սպասեք միայն ընթացիկ սահմանափակված գործարկման անցագրին; մշտական ​​վիճակը պահանջում է հետաքննություն: |
| `not_needed` | Հետ վերադարձ չի պահանջվում: | Գործողություն չկա: |
| `original_held` | Սկզբնական թիրախը տեղափոխվել է վերականգնման դիրք` առաջխաղացումից առաջ: | Մի ջնջեք վերականգնման ֆայլը, քանի դեռ գործարքը թերի է: |
| `retained_after_success` | Նոր թիրախը հաստատված է, սակայն վերականգնման տվյալները մնում են, քանի որ մաքրումն անհասանելի է կամ միտումնավոր պահպանվել է: | Հաստատեք արտադրական բայթերը նախքան անվանված վերականգնման ֆայլը հեռացնելը: |
| `discarded_after_success` | Փոխարինումը հաստատված է և ժամանակավոր հետադարձ տվյալները ջնջվել են: | Գործողություն չկա: |
| `rollback_failed` | Վերականգնման փորձը չհաջողվեց ստուգել: | Սերվերը կանգնեցրեք և օգտագործեք վերջին հաստատված գործողության կրկնօրինակը: |
| `skipped_state_persistence_failed` | Պատրաստվել են Sandbox բայթերը, սակայն պտտման վիճակը չի պահպանվել, ուստի ադապտերները և պատրաստված նվագարկչի հաղորդագրությունները բաց են թողնվել: | Վերականգնել աշխատաժամանակի վիճակային պահեստը; ձեռքով մի գլորեք կամ առաջ միացրեք հերթը: |
| `failed` | Ամփոփ տողը ներկայացնում է տերմինալի ձախողումը, որի կոնկրետ պատճառը `error` կամ գործարքի դաշտեր: | Հետևեք առաջին կոնկրետ կոդը; մի շտկեք անսարքությունները `failed` միայնակ: |

<a id="transaction-failures"></a>
## Գործարքի ձախողումներ

| Կարգավիճակ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `invalid_input` | Փոխարինման հարցումը վավեր տեքստ չէր կամ չուներ վավեր թիրախ: | Ճիշտ կոնֆիգուրացիա; մի նորից փորձեք անփոփոխ: |
| `stale_pending_cleanup_failed` | Հին առկախ ֆայլը չհաջողվեց հեռացնել: | Դադարեցրեք և պահպանեք առկախ ֆայլը մինչև ձեռքով մաքրումը: |
| `stale_rollback_requires_review` | Վերականգնման տվյալները գոյություն ունեն ներկա թիրախի կողքին և չեն կարող անվտանգ հեռացվել: | Նախքան որևէ մեկը ընտրելը, համեմատեք թիրախային և հետադարձ բայթերը: |
| `interrupted_transaction_restore_failed` | Վերականգնումը ընդհատված փոխարինումից հետո չի կարող վերականգնել թիրախը: | Սերվերը կանգնեցրեք և վերականգնեք հաստատված կրկնօրինակը: |

## Թարգմանության և հաղորդագրությունների վավերացման սխալներ

Սրանք բառարանի կամ ներկայացման պայմանագրի ձախողումներ են: Դրանք վավերացված են մինչև թողարկումը և կարող են նաև երևալ որպես սահմանափակ գործարկման կարգավիճակի նախազգուշացում:

| Սխալի տեքստ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `dictionary coverage mismatch` | Պրոֆիլի բառարանը չի բացատրում բոլոր փաստաթղթավորված կարգավորումները: | Ավելացրեք բառարանի բացակայող մուտքը և կրկնվող պրոֆիլը generation/validation. |
| `missing profile setting` | Ընտրված պրոֆիլում բացակայում է dictionary/schema. | Վերականգնել պրոֆիլի ընտանիքի աղբյուրը; մի հորինեք գործարկման ժամանակի լռելյայն: |
| `empty explanation` | Կարգավորում կա, բայց չունի operator/player բացատրություն: | Ավելացրեք պարզ լեզվով բացատրություն մինչև թողարկումը: |
| `join line too wide` | Ստեղծված միացման տողը գերազանցում է 42 նիշանոց աղբյուրի սահմանաչափը: | Կարճացրեք բառարանի արտահայտությունը. մի վստահեք հաճախորդի փաթեթավորմանը: |
| `join message too tall` | Ստեղծված միացման ամփոփագիրը գերազանցում է չորս տողը: | Նվազեցրեք կամ վերադասավորեք հաղորդագրության բովանդակությունը: |
