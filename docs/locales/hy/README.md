# RandomDay հայերեն

**v0.3.16-alpha**

RandomDay-ը պատրաստում է ամբողջական `SandboxSettings.ini` ֆայլ Abiotic Factor-ի
հաջորդ մեկնարկի համար։ Այն չի փոխում ընթացիկ աշխատաշրջանի կանոնները․ ակտիվ և
հաջորդ մեկնարկի համար պատրաստված պրոֆիլները ցուցադրվում են առանձին։

## Տեղադրում և ստուգում

Հետևեք [տեղադրման ուղեցույցին](../../../INSTALL.md)։ Ճիշտ պանակն է
`ue4ss/Mods/RandomDay`, իսկ `mods.txt`-ը պետք է պարունակի `RandomDay : 1`։
Սովորաբար առաջին մեկնարկը պատրաստում է պրոֆիլը, հաջորդը՝ ակտիվացնում։

Ստուգեք `runtime/current/randomday_status.json`, `runtime/rotation_state.txt`
և `web_export/today.json`։ Ակտիվ և պատրաստված պրոֆիլների նույնականացումները
պետք է համընկնեն երեք ֆայլերում։

## Փորձառության ընտրություն

Ռեժիմը, ընտանիքը, առաջին օրը և առաջընթացը սահմանեք
`RandomDay/Scripts/ax_config/server.lua` ֆայլում։ Կարդացեք
[Սկիզբ](../../START_HERE.md), [Պրոֆիլի ընտրություն](../../CHOOSE_A_PROFILE.md),
[Կարգավորում](../../CONFIGURATION.md) և [Խնդիրների լուծում](../../TROUBLESHOOTING.md) էջերը։

`HardcoreMode=False`, `AllowIronMode=False`, `StructuralSupportLimit=0` և
`BridgeSupports=0` արժեքները ներառված պրոֆիլ ստեղծողի սկզբնական արժեքներն են,
ոչ թե Abiotic Factor-ի պարտադիր կանոնները։ Փոփոխման և վերաստեղծման կարգը նշված
է կարգավորման փաստաթղթում։

Հրամանները, ուղիները, INI բանալիներն ու վիճակները մնում են անգլերեն, որպեսզի
ճշգրիտ համապատասխանեն իրական ֆայլերին։

## Ալֆա թողարկում և պահպանվող ընտրություններ

Սա ալֆա թողարկում է։ Փաստաթղթավորված տեղադրման, հերթափոխի և վերականգնման ուղիները փորձարկված են, իսկ համատեղելիությունն ու օգտագործելիությունը շարունակվում են բարելավվել։

`RandomDay/Scripts/ax_config/server.lua`-ում `sandbox.profile_overrides`-ը պահպանում է չորս արժեքները բոլոր ընտանիքների և օրերի համար։ Կանգնեցրեք սերվերը, մեկ անգամ փոխեք և կրկին գործարկեք։ Հետագա հերթափոխերն ու մեկնարկները կիրառում են նույն արժեքները, իսկ միայն `SandboxSettings.ini`-ի փոփոխությունը ժամանակավոր է։

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

Ստորև նշված ընտրովի մոդերը իրենց հեղինակների առանձին ներբեռնումներն են։ RandomDay-ը դրանք չի վերաբաշխում և չի փոխում դրանց հնարավորությունները․ միացված ադապտերը փոխում է միայն առկա, աջակցվող կարգավորումները։ Շնորհակալություն հեղինակներին և սպասարկողներին։
