# Նպաստում է

> **Կանոնական անգլերեն աղբյուր:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


RandomDay պահպանվում է որպես վերահսկվող նախագիծ:

Հանրային ձգման հարցումները, չպահանջված կոդերի ներկայացումները, ավտոմատացված վերաշարադրումները, ստեղծվող կոդերի մաքրման հայտերը և սպեկուլյատիվ առանձնահատկությունների պատչերը չեն ընդունվում, մինչև պահեստի սեփականատիրոջ բացահայտ պահանջը:

<a id="accepted-contact"></a>
## Ընդունված կոնտակտ

Սխալների հաշվետվությունների, համատեղելիության նշումների կամ սերվերի վարչակազմի դիտարկումների համար օգտագործեք նախագծի փաստաթղթերում նշված կոնտակտային ուղիները:

<a id="not-accepted"></a>
## Չի ընդունվում

Հետևյալը լռելյայն չի ընդունվում.

- չպահանջված ձգման հարցումներ;
- ստեղծված կոդերի վերագրում;
- լայն ռեֆակտորներ;
- միայն ոճի ձևաչափման փոփոխություններ;
- չստուգված խաղի տրամաբանության փոփոխություններ;
- համալրված երրորդ կողմի mod ֆայլեր;
- վերաբաշխված երրորդ կողմի սկզբնական կոդը;
- փոփոխություններ, որոնք ենթադրում են պաշտոնական պատկանելություն Abiotic Factor-ին, UE4SS, Nexus Mods կամ երրորդ կողմի ռեժիմի հեղինակներ:

<a id="controlled-development"></a>
## Վերահսկվող մշակում
