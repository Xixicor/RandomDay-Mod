# Բառարան

> **Կանոնական անգլերեն աղբյուր:** [GLOSSARY.md](../../GLOSSARY.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Սա RandomDay փաստաթղթեր: Ընթացակարգերը կապվում են այս սահմանումների հետ՝ մի քանի ուղեցույցներում նույն վիճակը վերասահմանելու փոխարեն: Սխեմային հատուկ դաշտի կանոնները մնում են [Գործարկման ելքեր](%D4%B3%D5%88%D5%90%D4%BE%D4%B1%D5%90%D4%BF%D5%84%D4%B1%D5%86_%D4%B5%D4%BC%D5%94%D4%B5%D5%90.md).

| Ժամկետ | Պարզ իմաստ | Ճշգրիտ տեխնիկական նշանակություն |
|---|---|---|
| Ակտիվ պրոֆիլ | Կանոնները, որոնք օգտագործում է ընթացիկ նստաշրջանը: | family/day պրոֆիլը նշված է RandomDay նշիչը կարդացվում է ավազարկղից գործընթացի գործարկման ժամանակ: |
| Պատրաստված է պրոֆիլը | Կանոնները պատրաստ են ավելի ուշ աշխատաշրջանի համար: | Ամբողջական family/day պրոֆիլ, որի թիրախային բայթերն անցել են վավերացում և հետադարձ ընթերցում, և որի ռոտացիայի վիճակը կատարվել է: Այն ակտիվ չէ վերսկսելուց առաջ: |
| Վերականգնվել է | Նախապատրաստումը ձախողվեց, և նախկինում հաստատված բայթերը հետ են դրվել: | Ձախողված գործարքը հաղորդում է պահված բնօրինակի կամ հաստատված վերականգնման պատճենի հաջող վերադարձ և հետադարձ կապ: |
| Հաջորդ վերագործարկման հերթ | Մի պատրաստ ընտրություն հաջորդ բեռնման համար: | `next_reboot_queue` ընտրում է մեկ անգամ յուրաքանչյուր գործընթացում և վերաօգտագործում է բեռնախցիկի կողմից պատկանող ընտրությունը վերահսկողության ընթացքում: |
| Bootstrap | Առաջին պատրաստումը, երբ ակտիվ նշիչ չկա: | Կազմաձևված կամ պատահական առաջին օրվա ընտրություն իրավասու ընտանիքից; `cycle.bootstrap_day` միայն համատեղելիության հետադարձ տարբերակ է: |
| Ընտանիք | 17-օրյա խաղային ոճի առաջընթաց: | Մեկ գրանցամատյանում և ընտանեկան մոդուլ, որն արտադրում է ուղիղ 17 ամբողջական պրոֆիլ: |
| Ռոտացիա | Անցում իրավասու ընտանիքներից: | Պետությունը նույնականացվում է `rotation_id`՝ հասանելի, մնացած և լրացված ընտանեկան ցուցակներով: |
| Գործարկել | Մեկ ընտանիք բոլոր 17 օրվա ID-ներում: | Ընտանիքի հետ կապված հաջորդականություն, որը նույնացվում է `run_id`; Ընտանիքը մնում է կողպված այնքան ժամանակ, մինչև ավարտվի յուրաքանչյուր հաստատված օրվա պատվերի դիրքը: |
| Սեսիայի ռեժիմ | Ինչպես է օպերատորն օգտագործում այս փաթեթը: | `persistent_dedicated`, `temporary_dedicated` կամ `singleplayer_lan`; փաթեթի ռեժիմը դեռևս վերահսկում է ֆայլային համակարգի սահմանը: |
| Օրվա պատվեր | Ճշգրիտ հաջորդականությունը, որն օգտագործվում է մեկ ընտանիքի կողմից: | 17 թվի մշտական ​​փոխարկում: Հաջորդական ռեժիմը փաթաթվում է իր մեկնարկի օրվանից; պատահական ռեժիմը խառնվում է մեկ անգամ՝ առանց կրկնության: |
| Մարկեր | Ինքնությունը պահվում է sandbox ֆայլում: | `RANDOMDAY_*` դաշտերը ներկայացվել են ամբողջական պրոֆիլով և կարդալ հաջորդ գործընթացի մեկնարկի ժամանակ: |
| Պատրաստված է պատրաստ | Գրման և վիճակագրության կատարումը հաջողվեց: | `prepared_ready=true`-ը պահանջում է ավազատուփի հաջող արդյունք և ոչ մի վիճակի կատարման ձախողում: Այն չի ապացուցում ակտիվացումը: |
| Արդեն ընթացիկ | Թիրախն արդեն ունի նախատեսված բայթերը: | Ներդրված պրոֆիլի հեշը համապատասխանում է թիրախին, ուստի RandomDay հաստատում է last-good/mirror աշխատում է առանց առաջնայինը վերագրելու: |
| Վատացած վիճակի կայունություն | Sandbox բայթերը հաջողվեցին, բայց ռոտացիոն հաշվապահությունը` ոչ: | `profile_status=degraded_state_persistence`; ադապտերները և պատրաստված պրոֆիլի հաղորդագրությունները բաց են թողնվել: |
| Սպասող ֆայլ | Հավակնորդ բայթերը դեռ չեն առաջմղվել: | `<target>.randomday.pending`, գրված, հետ կարդալ և վավերացված նախքան փոխարինումը: |
| Վերադարձ ֆայլ | Բնօրինակը պահվել է փոխարինման ժամանակ: | `<target>.randomday.rollback`, որն օգտագործվում է խթանման կամ վավերացման ձախողման դեպքում արտադրությունը վերականգնելու համար: |
| Օպերացիայի կրկնօրինակում | Կրկնվող պատճեն, որն արվել է մինչև մուտացիան: | Հաստատված ֆայլ `runtime/backups/` հիմնական, հայելային կամ ադապտերային գործարքի համար: |
| Վերջին հայտնի լավը | Վերջին ավազարկղը ընդունված է վերականգնման համար: | `runtime/last_good/SandboxSettings.ini` գումարած `manifest.lua`; զույգը գրանցում է պրոֆիլի ինքնությունը և հեշը: |
| Հայելի | Ընտրովի երկրորդ sandbox թիրախ: | Հստակ կազմաձևված կամ համաշխարհային անվանումից ստացված թիրախ, որը գրված է առաջնայինից հետո՝ իր սեփական գործարքի միջոցով: |
| Փաթեթի ռեժիմ | Տեղադրեք թողարկման օբյեկտի կողմից ընտրված սահմանը: | `dedicated_server` կամ `singleplayer_manual` `.randomday_mode`. |
| Ձեռքով պատճենման ռեժիմ | Singleplayer/LAN սերունդ՝ առանց պահումների հայտնաբերման: | `singleplayer_manual` գրում է միայն ներսում `runtime/singleplayer_manual/` և անջատում է ադապտերներն ու հայելիները: |
| Ադապտոր | RandomDay-owned քարտեզագրում մեկ այլ տեղադրված ռեժիմի համար: | Ստորագրությամբ փակված գործարքի պլան, որը թարմացնում է առկա հանձնարարությունները միայն պահեստային և համատեղելիության ստուգումներից հետո: |
| Ճանաչված դասավորություն | Ադապտորների ֆայլի ճշգրիտ ձևն ընդունված է գրելու համար: | Բոլոր անհրաժեշտ ստորագրության բանալիներն ու թիրախային ֆայլերը առկա են. միայն ֆայլի անունը բավարար չէ: |
| `not_installed` | Ընտրովի թիրախը չի գտնվել: | Ադապտորների անվտանգ արդյունք` առանց մուտացիայի: |
| `skipped_incompatible` | Թիրախ գոյություն ունի, սակայն դրա ձևը չի աջակցվում: | Անվտանգ ադապտեր առանց մուտացիայի, քանի որ ամբողջական ստորագրությունը չի համընկնում: |
| `failed_rolled_back` | Փոփոխությունը ձախողվեց, և նախորդ բայթերը անփոփոխ են: | Ադապտերով գործարքը ձախողվեց մինչև մուտացիան կամ վնասված բոլոր ֆայլերը վերականգնվեցին և հաստատվեցին: |
| `rollback_failed` | Ավտոմատ վերականգնումը չհաջողվեց ստուգել: | Ադապտերի վիճակը, որը պահանջում է ձեռքով վերականգնում, գրանցված պահուստավորումից: |
| Բառարան | Քարտեզագրում չմշակված արժեքներից մինչև հրապարակային բացատրություններ: | `randomday_dictionary_v2`, ստեղծվել է `dictionary.lua` և ներառված է գործարկման ժամանակի կարգավիճակի ելքում: |
| Թարգմանություն | Մարդկային տեսակետը ստացված է չմշակված պրոֆիլի արժեքներից: | Սահմանափակ տիրույթի միավորներ, փաստեր, ամփոփագրեր և հաղորդագրություններ, որոնք ստեղծվել են `translation.lua`; չմշակված արժեքները մնում են հեղինակավոր: |
| Հանրային կարգավիճակ | Ախտահանված մեքենանընթեռնելի օպերատորի ամփոփագիր: | `web_export/today.json` օգտագործելով `randomday_public_status_v2`. |
| Գործարկման ժամանակի կարգավիճակ | Մանրամասն տեղական մեքենայաընթեռնելի լուսանկար: | `runtime/current/randomday_status.json` օգտագործելով `randomday_runtime_status_v2`. |
