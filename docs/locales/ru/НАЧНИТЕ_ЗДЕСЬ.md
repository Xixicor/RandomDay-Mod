# Начните здесь: выполните первый RandomDay цикл

> **Канонический английский источник:** [START_HERE.md](../../START_HERE.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Это руководство начинается после установки RandomDay. Он показывает, что мод меняет, что оставляет в покое и как распознать один успешный цикл.

<a id="know-the-two-states"></a>
## Знайте два состояния

Abiotic Factor считывает мировые настройки песочницы перед запуском RandomDay. Таким образом, RandomDay сохраняет два четко названных состояния:

- **Активный профиль:** правила, которые уже использует текущий сеанс.
- **Подготовленный профиль:** правила, сохраненные для следующего запуска.

Подготовленный профиль не меняет уже текущий сеанс.

<a id="dedicated-server-prepare-the-next-profile"></a>
## Выделенный сервер: подготовьте следующий профиль

1. Запустите сервер в обычном режиме.
2. Подождите, пока RandomDay завершит работу по запуску.
3. Откройте `RandomDay/web_export/today.html` в папке установленного мода.
4. Найти **Активный профиль** и **Подготовленный профиль**.

При первом успешном запуске страница должна назвать уже активные правила и другой профиль ждет следующего запуска. На странице также объясняется выбранное семейство, положение и то, прошел ли подготовленный файл проверку безопасности.

Не перезапускайте файл только для того, чтобы изменить статус. Продолжайте играть с активными правилами до следующего запланированного запуска сервера.

<a id="dedicated-server-activate-it-later"></a>
## Выделенный сервер: активируйте его позже

1. Остановите и запустите сервер при следующем запланированном перезапуске.
2. Снова откройте читаемую страницу состояния.
3. Подтвердите, что ранее подготовленный профиль теперь указан как активный.
4. Подтвердите, что RandomDay подготовил следующий профиль.

Этот переход «подготовка, затем активация» завершен. RandomDay цикл.

<a id="temporary-dedicated-servers"></a>
## Временные выделенные серверы

Временное поведение использует тот же пакет выделенного сервера. В [Конфигурация](%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%AF.md) выберите, будет ли новый запуск начинаться с определенного профиля или будет выбрана случайная начальная точка. Страница статуса по-прежнему отделяет активный профиль от подготовленного для следующего запуска.

<a id="singleplayer-or-lan"></a>
## одиночной игре или LAN

1. Запустите игру один раз с установленным пакетом singleplayer/LAN.
2. Закройте игру полностью после завершения RandomDay.
3. Прочитайте сгенерированную сводку.
4. Скопируйте сгенерированный `SandboxSettings.ini` в выбранный вами мир, пока игра закрыта.
5. Запустите этот мир и подтвердите ожидаемые правила.

Локальный пакет никогда не выбирает мир и не копирует файл в сохранение сам. Полную процедуру см. в [Одиночная игра и LAN](%D0%9B%D0%90%D0%9D_%D0%94%D0%9B%D0%AF_%D0%9E%D0%94%D0%98%D0%9D%D0%9E%D0%A7%D0%9D%D0%9E%D0%99_%D0%98%D0%93%D0%A0%D0%AB.md).

<a id="if-the-expected-result-is-missing"></a>
## Если ожидаемый результат отсутствует

Не перезапускайте. Сохраните текущие файлы и выберите соответствующий признак в [Устранение неполадок](%D0%A3%D0%A1%D0%A2%D0%A0%D0%90%D0%9D%D0%95%D0%9D%D0%98%D0%95_%D0%9D%D0%95%D0%9F%D0%9E%D0%9B%D0%90%D0%94%D0%9E%D0%9A.md). В нормальном результате всегда указывается активный профиль и либо подготовленный профиль, либо один явный провал подготовки.
