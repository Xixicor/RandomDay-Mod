# RandomDay документация профиля

> **Канонический английский источник:** [README.md](../../../profiles/README.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Версия: `v0.3.16-alpha`

- Семьи: **17**
- Профили: **289**
- SandboxSettings словарные статьи: **46**

Выберите семью по цели игрового процесса в [руководстве по выбору профиля](../%D0%92%D0%AB%D0%91%D0%95%D0%A0%D0%98%D0%A2%D0%95_%D0%9F%D0%A0%D0%9E%D0%A4%D0%98%D0%9B%D0%AC.md), затем используйте этот сгенерированный индекс для точных значений.

Эти файлы генерируются из исходного кода Lua среды выполнения и его dictionary/translation контракт. Они показывают поставляемые `sandbox.profile_overrides` значения по умолчанию; настроенные значения одного сервера могут отличаться:

- `profiles.generated.json`: машиночитаемые профили, необработанные значения, словарь и переводы.
- `FULL_PROFILE_REFERENCE.md`: полный индекс и правила интерпретации.
- `SANDBOX_SETTINGS_KEYS.md`: полный словарь из 46 ключей.
- `families/*.md`: подробные 17-дневные семейные ссылки.

Обновить с помощью: `python -B tools/generate_profile_docs.py` Проверьте наличие отклонений с помощью: `python -B tools/generate_profile_docs.py --check`
