## v0.3.16-alpha

- Добавлены два полных пакета: один для выделенных серверов и один для одиночной игры или LAN миров.
- Добавлены постоянные и временные режимы выделенного сервера, настраиваемые стартовые профили и последовательное или неповторяющееся случайное развитие.
- Библиотека расширена до семнадцати семейств профилей с помощью семнадцать профилей в каждом семействе.
- Добавлен читаемый active/prepared статус профиля, компактные уведомления игрока, безопасная запись в песочнице, проверенные резервные копии, считывание и откат.
- Добавлены дополнительные адаптеры с проверкой макета для поддерживаемых сопутствующих модов.
- Добавлены постоянные элементы управления для всего профиля для режима Hardcore, режима Iron, структурного режима. поддержка и мостовая поддержка в конфигурации общедоступного сервера.
- Добавлена полная библиотека руководств на английском языке и 27 локализованных страниц ввода.
- Проверены выпускные пакеты как чистые, детерминированные, безопасные для регистра UE4SS макеты без частной конфигурации или данных времени выполнения.
