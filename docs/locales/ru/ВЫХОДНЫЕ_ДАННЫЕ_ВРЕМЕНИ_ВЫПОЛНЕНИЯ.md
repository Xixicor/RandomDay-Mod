# Интерпретация состояния времени выполнения и схем вывода

> **Канонический английский источник:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Это руководство по канонической схеме с заполнением полей. Он отвечает, что означает каждое поле, состояние, пустое значение и машинный результат. Используйте [карту файлов времени выполнения](%D0%A4%D0%90%D0%99%D0%9B%D0%AB_%D0%92%D0%A0%D0%95%D0%9C%D0%95%D0%9D%D0%98_%D0%92%D0%AB%D0%9F%D0%9E%D0%9B%D0%9D%D0%95%D0%9D%D0%98%D0%AF.md) для производителей, путей, времени записи, хранения, дополнительных транзакций и мест восстановления.

Все пути в этом руководстве относятся к установленной папке `RandomDay/`, если в строке явно не указана настроенная песочница или необязательный целевой адаптер. Выходные данные среды выполнения генерируются после установки и не являются частью ни одного из выпусков ZIP.

<a id="choose-the-authoritative-view"></a>
## Выберите авторитетный вид

| Нужен | Авторитетный источник |
|---|---|
| Правила, загруженные текущим процессом | RandomDay в `SandboxSettings.ini` считывается при запуске |
| Учет подготовленной очереди | `runtime/rotation_state.txt`, схема `1` |
| Подробный локальный статус | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| Общедоступный машиночитаемый статус | `web_export/today.json`, схема `2` и `randomday_public_status_v2` |
| Человекочитаемый статус | `web_export/today.html`, получено из тот же переход общедоступного статуса |
| Словарь перевода | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| Точное ограниченное уведомление игрока | `runtime/current/player_message_preview.txt` |

HTML Представление, предварительный просмотр и переведенные сводки являются производными представлениями. Они не переопределяют маркер песочницы, результат транзакции или необработанные значения профиля. Найдите последние удачные файлы, резервные копии операций, дополнительные файлы, зеркала, целевые объекты адаптеров и `UE4SS.log` в [файлы времени выполнения](%D0%A4%D0%90%D0%99%D0%9B%D0%AB_%D0%92%D0%A0%D0%95%D0%9C%D0%95%D0%9D%D0%98_%D0%92%D0%AB%D0%9F%D0%9E%D0%9B%D0%9D%D0%95%D0%9D%D0%98%D0%AF.md).

<a id="rotation-state-schema"></a>
## Схема состояния вращения

`runtime/rotation_state.txt` использует схему `1` и содержит одну `key=value` пару в строке:

| Поле | Значение |
|---|---|
| `schema_version` | Должно быть `1`. |
| `mod_version` | Идентификатор пакета, считанный из `.randomday_version`. |
| `rotation_id` | Идентификатор текущего прохода через набор подходящих семей. |
| `mode` | `selected_run`, `non_repeating_random_run` или `rotation_run`. |
| `available_families` | Идентификаторы подходящих семей, разделенные запятыми, после фильтрации конфигурации. |
| `remaining_families` | Подходящие семьи, еще не выбранные в текущем неповторяющемся проходе. |
| `completed_families` | Семьи, полный сохраненный 17-позиционный порядок которых завершен в текущем проходе. |
| `active_family`, `active_day` | Информация об активном маркере, записанная при фиксации выбора. Маркер песочницы является авторитетным при следующей загрузке. |
| `prepared_family`, `prepared_day` | Профиль сохраняется до следующего перезапуска. |
| `active_run_id` | Идентификатор семейного использования, связанный с подготовленным выбором. |
| `last_status` | Состояние выбора календаря, в результате которого был создан этот файл. |
| `session_mode` | Разрешенный постоянный выделенный, временный выделенный или singleplayer/LAN жизненный цикл. |
| `start_day_mode` | Настраиваемый или однократный случайный выбор начала для нового запуска. |
| `day_progression_mode` | Завернутая последовательная или неповторяющаяся случайная прогрессия. |
| `day_order` | Постоянные идентификаторы дней, разделенные запятыми, в точном порядке, в котором они будут подготовлены. |
| `day_position` | Позиция подготовленного дня в `day_order`. |
| `updated_at` | Локальное время записи для сравнения операторов. |

Запись состояния принимается только в том случае, если маркер схемы, подготовленное семейство и подготовленный день считываются правильно. Нечитаемый текущий файл может вернуться к `rotation_state.last_good.txt`; выбранный маркер песочницы по-прежнему определяет, что игра загружает для текущего процесса.

<a id="runtime-status-json"></a>
## Состояние выполнения JSON

`runtime/current/randomday_status.json` использует `status_schema=randomday_runtime_status_v2`. Его основными группами полей являются:

| Группа | Поля и интерпретация |
|---|---|
| Идентификация | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| Выбор | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| Активно | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| Подготовлено | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| Сводки, подготовленные пользователем | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| Напишите подтверждение | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| Подготовлено | `adapter_status`, `adapter_results`; каждая запись адаптера содержит свидетельства совместимости, transaction/rollback состояние, количество измененных файлов и отредактированные целевые ссылки. |
| Границы | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| Диагностика | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

Неизвестные активные значения означают, что текущая песочница не содержит файла, доступного для чтения RandomDay. Их нельзя заменять подготовленными значениями. Пути адаптера снаружи `runtime/` сводятся к ссылке на базовое имя, а диагностические строки корректируют обнаруженные абсолютные пути.

<a id="public-status-json"></a>
## Общественный статус JSON

`web_export/today.json` использует `schema_version=2` и `status_schema=randomday_public_status_v2`. Он повторяет идентификатор, active/prepared, выбор, транзакцию, адаптер и факты перезапуска границы, необходимые оператору. Сюда также входят:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` и `prepared_day_position`;
- `family_selection_mode`, устаревшие `family_locked_until_day_17` и `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families` и их количество;
- подготовленный профиль столкновения, уровень, тема и вероятность смешанного столкновения;
- включение области действия мира, настройка открытого мира, политика неизвестного мира и только количество настроенных шаблонов исключенного мира;
- подготовленное сообщение и предварительный просмотр комбинированного сообщения;
- `selected_at`, `sandbox_target`, `manual_copy_required` и подготовленный хэш.

`profile_status` является одним из `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` или `write_failed_or_rollback`. `prepared_ready=true`, что еще не означает активное; требуется более поздний маркер запуска.

<a id="dictionary-and-translation-output"></a>
## Вывод словаря и перевода

`runtime/current/randomday_dictionary.json` использует `schema=randomday_runtime_dictionary_v2` и идентифицирует версию словаря `randomday_dictionary_v2`. Он описывает режимы пакета, состояния выбора, области давления, метки настроек, необработанные значения и значения, понятные простым языком. Неизвестные значения остаются явными, а не преобразуются в достоверное описание.

`player_message_preview.txt`, `today.json`, `today.html`, а внутриигровые уведомления представляют собой представления, полученные из того же модуля перевода. Базовый профиль и необработанные значения `SandboxSettings.ini` остаются источником истины.

<a id="failure-and-recovery-rules"></a>
## Правила сбоев и восстановления

1. Неудачная ожидающая запись или проверка никогда не становится рабочей целью.
2. Неудачное продвижение или обратное чтение рабочей версии запускает восстановление удерживаемого оригинала; резервная копия операции является запасным вариантом в случае сбоя восстановления.
3. Сохраненный файл отката или `rollback_failed` статус требует проверки вручную, пока игра или сервер остановлены.
4. Успешная запись в песочнице и неудачная фиксация состояния вращения ухудшены и не готовы; адаптеры и обмен сообщениями подготовленного профиля пропускаются.
5. Ошибка экспорта не меняет результат песочницы, но удаляет удобный источник проверки. Используйте журналы транзакций, состояние и обратное чтение файлов.
6. Выходные данные времени выполнения — это локальные операционные данные. Не добавляйте их в релиз ZIP или опубликуйте их в качестве примеров без отдельной проверки конфиденциальности.
