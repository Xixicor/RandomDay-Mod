# RandomDay документация

> **Канонический английский источник:** [README.md](../../README.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay изменяет правила песочницы, используемые миром абиотического фактора, без изменения уже запущенного сеанса. Начните с руководства, которое соответствует тому, что вы хотите сделать.
