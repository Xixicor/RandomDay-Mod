# Установка, обновление или удаление RandomDay

> **Канонический английский источник:** [INSTALL.md](../../../INSTALL.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay имеет две полные загрузки. Выберите один для мира, который вы настраиваете:

- используйте **выделенный сервер ZIP** для любого выделенного сервера, включая сервер, который открывается только для периодических сеансов;
- используйте **singleplayer/LAN ZIP** для локального мира, настройки которого вы будете копировать вручную.

Не объединяйте пакеты. Постоянный или временный выделенный сервер — это выбор в настройках RandomDay's настройки, а не другую загрузку.

<a id="before-you-begin"></a>
## Прежде чем начать

Создайте восстанавливаемую копию:

- мира, который вы меняете;
- его текущего `SandboxSettings.ini`;
- существующего `RandomDay` папка, если она установлена.

Установите UE4SS перед RandomDay. В приведенных ниже инструкциях **папка Mods** означает `ue4ss/Mods/` каталог внутри игры или установки выделенного сервера.

<a id="dedicated-server"></a>
## Выделенный сервер

<a id="new-installation"></a>
### Новая установка

1. Остановите сервер.
2. Откройте UE4SS `Mods`.
3. Извлеките выделенный сервер ZIP. Результат должен быть один: `ue4ss/Mods/RandomDay/`, а не папка внутри другой `RandomDay`.
4. Откройте эту папку и убедитесь, что `RandomDay/Scripts/main.lua` присутствует. Если он отсутствует, значит, ZIP был извлечен на неправильный уровень.
5. Откройте UE4SS `mods.txt` и включите эту строку:

   ```text
   RandomDay : 1
   ```

6. Запустите сервер в обычном режиме.
7. Откройте RandomDay's читаемую страницу состояния и подтвердите, что она называет как активный профиль, так и профиль, подготовленный для следующего запуска.

Первый запуск не заменяет правила, уже загруженные этим сеансом. Он готовит следующий профиль. Запускайте сервер снова только тогда, когда вы действительно хотите, чтобы подготовленный профиль стал активным.

[Проверьте первый цикл](%D0%9D%D0%90%D0%A7%D0%9D%D0%98%D0%A2%D0%95_%D0%97%D0%94%D0%95%D0%A1%D0%AC.md)

<a id="choose-always-on-or-temporary-behavior"></a>
### Выберите постоянное или временное поведение

Пакет выделенного сервера поддерживает оба стиля:

- **постоянный выделенный** возобновляет сохраненную ротацию при обычных перезапусках;
- **временный выделенный** может начаться с настроенной или случайной начальной точки, когда начинается новый временный запуск.

Выберите поведение в [Конфигурация](%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%AF.md). Не устанавливайте второй пакет, чтобы изменить этот параметр.

<a id="update-an-existing-installation"></a>
### Обновите существующую установку

1. Остановите сервер и запустите его. резервные копии, перечисленные выше.
2. Переместите старую папку `RandomDay` из папки UE4SS `Mods`. Сохраняйте ее до тех пор, пока обновление не завершит один успешный цикл.
3. Извлеките новый выделенный сервер ZIP в `Mods`.
4. Применяйте повторно только те настройки, которые вы намеренно изменили и которые все еще существуют в новом [руководстве по настройке](%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%AF.md).
5. Сохраняйте документированные файлы состояния ротации только в том случае, если в примечаниях к выпуску указано, что их формат совместим. Не копируйте старые временные выходные файлы или файлы с ошибками записи в новую установку.
6. Подтвердить `RandomDay : 1` все еще включен, затем запустите сервер один раз и проверьте активные и подготовленные имена профилей.

<a id="updating-from-v0315-alpha"></a>
### Обновление с v0.3.15-alpha

`RandomDay_v0.3.15-alpha.zip` был старым базовым пакетом. `RandomDay_v0.3.15-alpha_singleplayer_patch.zip` был наложением, а не отдельной загрузкой.

Текущий `v0.3.16-alpha` заменяет историческую схему базового и наложения двумя полными пакетами. Не помещайте старый патч ни на одну упаковку. Текущие маркеры `.randomday_mode=dedicated_server` и `.randomday_mode=singleplayer_manual`.

<a id="singleplayer-or-lan"></a>
## одиночной игре или LAN

singleplayer/LAN создает файл настроек; он не ищет и не изменяет личное сохранение самостоятельно.

1. Закройте игру.
2. Резервное копирование мира и его текущего состояния `SandboxSettings.ini`.
3. Извлеките singleplayer/LAN ZIP в игре UE4SS `Mods` папка одна `Mods/RandomDay/` существует.
4. Включить `RandomDay : 1` в UE4SS `mods.txt`.
5. Запустите игру один раз, дождитесь завершения RandomDay и полностью закройте игру.
6. Найдите сгенерированный `SandboxSettings.ini` в RandomDay's `runtime/singleplayer_manual/`.
7. Прочитайте сгенерированную сводку, затем скопируйте файл в выбранный вами мир.
8. Запустите этот мир и убедитесь, что ожидаемое поведение песочницы активно.

LAN использует тот же ручной процесс, поскольку локальный мир принадлежит хосту. Мод не выбирает мир и не перезаписывает его автоматически.

[Одиночная игра и LAN руководстве](%D0%9B%D0%90%D0%9D_%D0%94%D0%9B%D0%AF_%D0%9E%D0%94%D0%98%D0%9D%D0%9E%D0%A7%D0%9D%D0%9E%D0%99_%D0%98%D0%93%D0%A0%D0%AB.md)

<a id="remove-or-disable-randomday"></a>
## Удалите или отключите RandomDay

1. Остановить игру или сервер.
2. Резервное копирование мира, его текущих настроек песочницы и состояния RandomDay's.
3. Установить `RandomDay : 0` в UE4SS `mods.txt`, чтобы отключить мод, или переместите всю папку `RandomDay` из папки `Mods`, чтобы удалить его.
4. Решите, какой `SandboxSettings.ini` должен быть загружен при следующем запуске. Восстановите предустановленную копию, если вам не нужен текущий подготовленный профиль RandomDay.
5. Запустите мир и подтвердите его правила перед удалением резервной копии.

Отключение RandomDay останавливает будущую подготовку профиля.

<a id="recover-from-an-unsuccessful-update"></a>
## Восстановление после неудачного обновления

Остановка после первого явного сбоя может затруднить просмотр того, какой профиль был активен. и какой из них ждал.

1. Остановить игру или сервер.
2. Переместите неудачную установку в сторону, не удаляя ее.
3. Восстановите полную версию. RandomDay резервная копия папки и песочницы, сделанная перед обновлением.
4. Запустите один раз и подтвердите восстановленные активные и подготовленные имена профилей.
5. Временно используйте [Устранение неполадок](%D0%A3%D0%A1%D0%A2%D0%A0%D0%90%D0%9D%D0%95%D0%9D%D0%98%D0%95_%D0%9D%D0%95%D0%9F%D0%9E%D0%9B%D0%90%D0%94%D0%9E%D0%9A.md) для первого отсутствующего или неудачного шага перед попыткой следующего обновления.
