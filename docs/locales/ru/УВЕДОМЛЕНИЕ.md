RandomDay — это независимый мод сообщества для выделенных серверов Abiotic Factor.

RandomDay не включает, не копирует, не повторно размещает и не распространяет код из поддерживаемых сторонних модов. Дополнительная интеграция осуществляется с помощью скриптов адаптера, принадлежащих RandomDay-owned сценарии адаптера, которые исправляют открытые настройки только в том случае, если владелец сервера установил эти поддерживаемые моды отдельно.
