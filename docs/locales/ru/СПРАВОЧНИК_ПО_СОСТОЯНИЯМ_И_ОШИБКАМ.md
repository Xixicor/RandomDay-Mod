# Справочник по состоянию и ошибкам

> **Канонический английский источник:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Используйте точные `status`, `transaction_status`, `rollback_status` и `error` значения из экспорта во время выполнения. Аналогичные формулировки на панели или консоли не заменяют эти поля.

Этот раздел представляет собой полный справочник по поиску. Дерево решений выше выбирает в соответствующей категории в этих таблицах сохраняются точные значения параметров машины и безопасные реакции оператора.

<a id="normal-or-informational-states"></a>
## Нормальное или информационное состояние

| Состояние | Значение | Реакция оператора |
|---|---|---|
| `prepared_for_next_reboot` | Проверенный профиль записан для следующей загрузки. | Нет действий; текущий сеанс не изменился. |
| `next_reboot_already_prepared` | Предполагаемый следующий профиль уже соответствует целевому. | Нет действий; не выполняйте принудительное повторное вращение. |
| `already_current` / `unchanged` | Цель уже содержит нужные байты. | Нет действий. |
| `applied` | Запись и обратное чтение пройдены. | Проверьте различие active/prepared после следующей загрузки. |
| `bootstrap_prepare_first_family_start_day` | Нет предшествующего состояния ротации существовал, поэтому настроенный первый день был подготовлен. | Ожидается при первом использовании. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | Сохраненное состояние было восстановлено, и тот же подготовленный профиль был перезаписан. | Проверьте восстановленный день; нового случайного выбора не произошло. |
| `supervision_reconfirm_prepared_profile_no_advance` | Пропуск на надзор подтвердил существующую подготовку. | Ожидается; очередь не перемещалась дважды. |
| `external_mods_disabled` | Необязательная обработка адаптера отключена. | Никаких действий, если адаптеры не были предназначены. |
| `external_mods_processed` | Все включенные планы адаптеров достигли конечного результата. | Просмотрите каждую строку адаптера. |

<a id="startup-configuration-errors"></a>
## Ошибки конфигурации запуска

Эти сообщения прекращают запуск до того, как RandomDay запишет профиль. Исправьте указанную настройку или маркер пакета; не обходите ветку проверки.

| Текст ошибки | Значение | Безопасный ответ |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` отсутствует, имеет неверный формат или принадлежит не тому пакету. | Переустановите один полный пакет в чистую промежуточную папку и сохраните маркер предполагаемого режима. |
| `invalid experience.mode` | `experience.mode` не является одним из документированных значений. | Временно используйте `auto`, `persistent_dedicated`, `temporary_dedicated` или `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | A пакет ручного копирования был настроен как выделенный сервер. | Восстановить `auto` или `singleplayer_lan`; не направляйте его во внешний мир автоматически. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | Для рабочего процесса копирования вручную был настроен специальный пакет. | Временно используйте `auto`, `persistent_dedicated` или `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | Селектор начального дня недействителен. | Используйте точно `configured` или `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | Селектор порядка дней недействителен. | Используйте точно `sequential` или `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | Настроенный день начала является дробным или вне цикла. | Используйте целое число от 1 до `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | Резервное копирование или последнее хорошее восстановление отключено. | Восстановить оба предохранителя; RandomDay намеренно отказывается от небезопасной записи. |
| `external adapter transaction safety locks must remain true` | Исправление адаптера или защита резервного копирования были отключены. | Восстановите обе блокировки адаптера или отключите адаптеры как группу. |
| `paths.world_name must be one folder name` | Настроенное мировое имя содержит разделитель или небезопасный символ. | Вводите только точное имя папки, используя буквы, цифры, пробелы, подчеркивания или дефисы. |
| `required runtime directory unavailable` | Не удалось создать или подтвердить требуемый локальный выходной каталог мода. | Проверяйте только указанный RandomDay каталог и его разрешение на запись. |

<a id="profile-wide-configuration-errors"></a>
## Ошибки конфигурации на уровне профиля

Эти ошибки останавливают построение профиля перед записью в песочницу.

| Текст ошибки | Значение | Безопасный ответ |
|---|---|---|
| `sandbox.profile_overrides must be a table` | Четыре варианта выбора для всего профиля были заменены другим типом Lua. | Восстановите документированную таблицу в `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | Таблица содержит параметр, который не является одним из четырех поддерживаемых ключей. | Удалите указанный ключ и используйте family/profile источники для других настроек песочницы. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` или `AllowIronMode` не `true` или `false`. | Используйте логическое значение Lua без кавычек. |
| `sandbox.profile_overrides.<key> must be integer` | Поддерживаемое значение не является целым числом. | Используйте целое число. |
| `sandbox.profile_overrides.<key> outside supported range` | Поддерживаемое значение находится вне `0..1000`. | Выберите целое число из `0` до `1000`. |

<a id="rollback-and-intermediate-states"></a>
## Откат и промежуточные состояния

| Значение | Значение | Безопасный ответ |
|---|---|---|
| `not_started` / `pending` | Транзакция или план адаптера не достигли конечного результата. | Дождитесь только текущего ограниченного прохода запуска; постоянное состояние требует исследования. |
| `not_needed` | Откат не требовался. | Нет действий. |
| `original_held` | Исходная цель была перемещена в положение восстановления перед повышением уровня. | Не удаляйте файл восстановления, пока транзакция не завершена. |
| `retained_after_success` | Новая цель проверена, но данные для восстановления остаются, поскольку очистка была недоступна или намеренно сохранена. | Проверьте рабочие байты перед удалением любого именованного файла восстановления. |
| `discarded_after_success` | Подтвержденная замена и временные данные отката были удалены. | Нет действий. |
| `rollback_failed` | Попытка восстановления не может быть проверена. | Оставьте сервер остановленным и используйте последнюю проверенную резервную копию операции. |
| `skipped_state_persistence_failed` | Байты песочницы были подготовлены, но ротация состояние не сохранялось, поэтому адаптеры и сообщения подготовленного игрока были пропущены. | Восстановить хранилище состояния времени выполнения; не перезагружайте и не продвигайте очередь вручную. |
| `failed` | Сводная строка представляет собой сбой терминала, конкретная причина которого находится в его `error` или полях транзакции. | Следуйте первому конкретному коду; не устраняйте неполадки только с помощью `failed`. |

<a id="transaction-failures"></a>
## Ошибки транзакций

| Состояние | Значение | Безопасный ответ |
|---|---|---|
| `invalid_input` | Запрос на замену содержал недопустимый текст или не имел допустимой цели. | Правильная конфигурация; не повторяйте попытку без изменений. |
| `stale_pending_cleanup_failed` | Не удалось удалить старый ожидающий файл. | Остановите и сохраните ожидающий файл перед очисткой вручную. |
| `stale_rollback_requires_review` | Данные для восстановления существуют рядом с текущей целью и не могут быть безопасно удалены. | Сравните целевые байты и байты отката, прежде чем выбрать любой из них. |
| `interrupted_transaction_restore_failed` | Восстановление после прерванной замены не смогло восстановить целевой объект. | Оставьте сервер остановленным и восстановите проверенную резервную копию. |
| `interrupted_transaction_cleanup_failed` | Цель была восстановлена, но устаревшие данные транзакции не удалось очистить. | Проверьте целевые байты, затем удалите только указанный устаревший дополнительный компонент. |
| `pending_write_failed` | Кандидат не может быть записан. | Проверьте узкий целевой каталог и свободное место. |
| `pending_readback_failed` / `pending_readback_mismatch` | Байты кандидата не могут быть прочитаны или различаются после записи. | Не продвигайте ожидающий файл. |
| `pending_validation_failed` | Кандидат не выполнен schema/profile проверка перед продвижением. | Исправьте указанный ключ или правило; не обходите проверку. |
| `operation_backup_failed` / `backup_failed` | Проверенная резервная копия перед записью не была создана. | Стоп; нельзя доверять никакой целевой замене. |
| `original_preserved_move_failed` | Исходная цель не может быть перемещена в положение восстановления. | Сохраните все файлы транзакций и восстановите вручную. |
| `promotion_failed` | Ожидающий кандидат не может стать рабочей целью. | Перед повторной попыткой проверьте, был ли оригинал восстановлен. |
| `production_validation_failed` | Повышенные байты неудачное производство readback/validation. | Восстановите проверенную резервную копию и проверьте целевой модуль записи. |
| `replacement_committed_recovery_cleanup_failed` | Замена действительна, но данные отката не могут быть удалены. | Считайте целевой объект как зафиксированный; удалить только проверенные устаревшие данные восстановления. |
| `rollback_failed` | Автоматическое восстановление не проверено. | Оставить сервер остановленным и использовать восстановление вручную. |

<a id="target-profile-adapter-and-export-failures"></a>
## Ошибки цели, профиля, адаптера и экспорта

| Состояние | Значение | Безопасный ответ |
|---|---|---|
| `target_refused` | Настроенный путь находится за пределами границы разрешенного режима. | Исправьте путь; никогда не ослабляйте границу. |
| `target_directory_failed` | Целевой каталог не может быть создан или подтвержден. | Проверьте только существование и разрешения этого каталога. |
| `profile_validation_failed` | В профиле отсутствует ключ, указан неверный type/range или нарушает правило оставшегося инварианта. | Используйте именованный ключ, `sandbox.profile_overrides` и ссылка на профиль для восстановления источника. |
| `skipped_incompatible` | Необязательный мод существует, но не соответствует поддерживаемой подписи адаптера. | Оставьте его без изменений или отключите этот адаптер. |
| `external_mods_partial` | Некоторые дополнительные адаптеры завершены, а другие благополучно skipped/failed. | Просмотрите строки адаптера независимо; результат песочницы отдельный. |
| `external_adapter_failed` | Необходимый адаптер не завершился безопасно. | Восстановите проверенную резервную копию перед повторной попыткой. |
| `degraded_state_persistence` | Подготовка песочницы завершена, но сохранение состояния вращения не выполнено. | Не предполагайте, что следующая загрузка пройдет корректно; восстановить хранилище состояния. |
| `export_directory_failed` | `web_export/` не удалось создать или записать. | Подготовка к игровому процессу все еще может быть действительна; восстанавливайте отчеты отдельно. |

<a id="translation-and-message-validation-errors"></a>
## Ошибки перевода и проверки сообщений

Это сбои словаря или контракта представления. Они проверяются перед выпуском и могут также отображаться в виде ограниченного предупреждения о статусе выполнения.

| Текст ошибки | Значение | Безопасный ответ |
|---|---|---|
| `dictionary coverage mismatch` | Словарь профиля не объясняет все документированные настройки. | Добавьте отсутствующую запись словаря и повторно запустите профиль generation/validation. |
| `missing profile setting` | В выбранном профиле отсутствуют настройки, необходимые для dictionary/schema. | Восстановите источник семейства профилей; не придумывайте значение по умолчанию во время выполнения. |
| `empty explanation` | Настройка существует, но не имеет operator/player объяснения. | Добавьте объяснение открытым языком перед выпуском. |
| `join line too wide` | Сгенерированная строка соединения превышает ограничение источника в 42 символа. | Сократите словарь фраза; не полагайтесь на перенос клиента. |
| `join message too tall` | Сгенерированная сводка о присоединении превышает четыре строки. | Уменьшите или измените приоритет содержимого сообщения. |
