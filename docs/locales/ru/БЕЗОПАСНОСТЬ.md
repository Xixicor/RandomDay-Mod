# Политика безопасности

> **Канонический английский источник:** [SECURITY.md](../../../SECURITY.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay записывает файлы конфигурации сервера и может исправлять дополнительные файлы конфигурации модов. Считайте изменения конфиденциальными.

<a id="do-not-report-as-security-issues"></a>
## Не сообщать о проблемах безопасности

- Обычные изменения игрового баланса.
- Ожидаемая ротация профиля при следующей перезагрузке.

<a id="report-privately"></a>
## Сообщить конфиденциально

- Риски обхода пути.
- Небезопасное поведение при записи файлов.
- Возможность перезаписывать файлы не по назначению server/mod пути.
- Выполнение вредоносной команды.

Пока не существует общедоступного канала безопасности, сообщите об этом лично владельцу хранилища.
