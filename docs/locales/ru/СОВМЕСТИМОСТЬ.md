<a id="compatibility"></a>
# Совместимость

> **Канонический английский источник:** [COMPATIBILITY.md](../../COMPATIBILITY.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


<a id="supported-installations"></a>
## Поддерживаемые установки

RandomDay создан для установок Abiotic Factor, которые могут загружать UE4SS моды Lua.

| Среда | Поддержка | Пакет |
| --- | --- | --- |
| Выделенный сервер Windows | Поддерживается | Выделенный сервер ZIP |
| Однопользовательская игра Windows или LAN хост | Поддерживается рабочий процесс копирования вручную | Singleplayer/LAN ZIP |
| Сервер Linux с использованием Wine или Proton | Не тестировался | Специальный пакет Windows может быть оценен опытными операторами, но совместимость не гарантируется. |
| Xbox и PlayStation | Не поддерживается | Эти платформы не обеспечивают доступ к файлам и UE4SS путь загрузки Lua, необходимые для этой версии. |

RandomDay не объединяет эти два пакета. Выделенный сервер, который запускается только для эпизодической игры, по-прежнему использует выделенный сервер ZIP и выбирает временное поведение в состоянии конфигурации.

<a id="abiotic-factor-updates"></a>
## Обновления абиотического фактора

После обновления игры начните с остановленного сервера и сохраните восстанавливаемую копию мира, `SandboxSettings.ini` и RandomDay. Подтвердите UE4SS загрузку, затем завершите один RandomDay цикл и проверьте как активный, так и подготовленный профиль, прежде чем возобновить нормальное вращение.

<a id="companion-mods"></a>
## Сопутствующие моды

RandomDay изменяет отдельно установленный мод только тогда, когда его полный макет настроек соответствует поддерживаемому адаптеру. Одного номера версии недостаточно.

| Интеграция | Текущая версия проверена | RandomDay граница поддержки |
| --- | --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | `0.8.5`; основной файл `0.8.5-Hotfix1` | Поддерживаемый `SharedData.lua` макет охватывает параметры появления, восстановления, населения, портала, нарушения, босса и RandomDay встреч, перечисленных в справочнике по адаптеру. |
| Смертельные лазеры | `1.0-UE4SS` | Поддерживаемый `Scripts/main.lua` макет охватывает распознанный излучатель, излучатель окружающей среды, отражатель и призму settings. |
| ANTE Вверх | `1`, обновлено 19 июля 2026 г. | Текущий общедоступный макет не завершил настройку адаптера. RandomDay пропускает несоответствующий файл без изменений до тех пор, пока этот макет не будет проверен. |

Отсутствующий, отключенный или нераспознанный сопутствующий мод остается без изменений. См. [Поддерживаемые дополнительные моды](%D0%9F%D0%9E%D0%94%D0%94%D0%95%D0%A0%D0%96%D0%98%D0%92%D0%90%D0%95%D0%9C%D0%AB%D0%95_%D0%90%D0%94%D0%90%D0%9F%D0%A2%D0%95%D0%A0%D0%AB.md) для точных настроек, элементов управления конфигурацией, поведения резервного копирования и действий по восстановлению.

<a id="what-compatibility-validation-proves"></a>
## Что доказывает проверка совместимости

Проверка репозитория может подтвердить макет отправленного пакета, покрытие конфигурации, распознанные поля адаптера, поведение резервного копирования и восстановления и безопасное отклонение неизвестного макета. Он не может доказать каждую будущую версию Абиотического Фактора, UE4SS или сопутствующего мода. В примечаниях к выпуску называются проверенные версии, а не предполагается совместимость при успешной загрузке.
