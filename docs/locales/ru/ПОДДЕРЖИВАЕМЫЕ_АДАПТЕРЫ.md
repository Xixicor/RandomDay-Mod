# Поддерживаемые дополнительные моды

> **Канонический английский источник:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay может заставить отдельно установленный мод следовать активному RandomDay профилю. Эта функция доступна только в пакете выделенного сервера. singleplayer/LAN никогда не редактирует другой мод.

RandomDay не включает и не распространяет какие-либо из перечисленных здесь модов. Установите и включите каждый дополнительный мод со своей страницы Nexus и сначала следуйте инструкциям его автора. RandomDay изменяет только распознанные настройки, которые уже существуют в установленном файле. Он не добавляет функций в другой мод, и адаптер можно отключить, не удаляя этот мод. Пакет выделенного сервера начинается с `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## Что RandomDay меняется

| Дополнительная интеграция | Настройки, выбранные из активного профиля. |
| --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | Жесткий режим, player/area поведение перезарядки, активность шторма и горячей зоны, появление боссов и взрывов, время цикла появления, малые и большие диапазоны восстановления, расстояние появления, global/local/mod ограничения, портал-шторм, вероятность нарушения порядка и босса, а также минимальное появление на область. |
| Дополнительные поля расширения Chaotic Spawn Engine | Если установленный `SharedData.lua` уже содержит RandomDay поля расширения, адаптер может предоставить профиль встречи, уровень, тему, групповые ограничения, значения для особых событий и смешанных встреч, бюджет, время восстановления и элементы управления масштабом мира. Это не очередной мод для скачивания. |
| Смертельные лазеры | Активация мода плюс повреждение и включение элементов управления для развертываемых излучателей, излучателей окружающей среды, отражателей и призм. |
| ANTE Вверх | Множитель частоты возрождения, частота антеварианта и существующие development/debug переключается. RandomDay сохраняет все распознаваемые переключатели разработки и отладки. |

Библиотека профилей предоставляет подготовленный набор значений для каждого поддерживаемого дня. Тихий день может снизить давление, опасный день – повысить его, а день восстановления – резко снизить. RandomDay не вычисляет произвольные значения при загрузке; он применяет проверенный набор значений, указанный в активном профиле.

<a id="how-recognition-protects-another-mod"></a>
## Как распознавание защищает другой мод

Недостаточно найти знакомое имя файла. RandomDay проверяет наличие всех необходимых настроек для этого адаптера в целевом файле. Он исправляет только существующие назначения; он никогда не изобретает недостающие настройки.

Для распознанного макета RandomDay выполняет одну ограниченную транзакцию:

1. вычисляет каждое предполагаемое значение для активного профиля;
2. создает и проверяет побайтовую резервную копию каждого целевого файла;
3. запись через отложенный одноуровневый файл file;
4. продвиньте ожидающий файл и прочитайте сохраненные байты обратно;
5. подтвердите каждое заданное значение;
6. используйте автоматическое восстановление из проверенных резервных копий, если какой-либо шаг не удался.

DynamicSpawns может включать свои настройки и распознанные файлы сообщений игрока в одну транзакцию. RandomDay не сообщает об успешном обновлении нескольких файлов, пока не завершится полная транзакция.

<a id="read-an-adapter-result"></a>
## Прочитайте результат адаптера

| Результат | Значение |
| --- | --- |
| `applied` | Распознанные настройки изменились и прошли обратное чтение. |
| `already_current` | Опознанные настройки уже соответствуют активному профилю. |
| `not_installed` | Необязательный мод не найден. RandomDay продолжил без него. |
| `skipped_incompatible` | Файл был найден, но его полный макет настроек не был распознан. Ничего не было изменено. |
| `partial` | Основные настройки DynamicSpawns были применены, но дополнительный переведенный файл сообщения не был завершен. Просмотрите записанный результат адаптера. |
| `failed_rolled_back` | Транзакция не удалась, а предыдущие байты остались нетронутыми или были восстановлены и проверены. |
| `rollback_failed` | RandomDay не удалось проверить изменение или восстановление. Остановите затронутый мод и восстановите его записанную резервную копию вручную. |

Отсутствующие и несовместимые дополнительные моды не останавливают вращение песочницы RandomDay's вращение песочницы в соответствии с поставляемой конфигурацией.

<a id="enable-or-disable-integrations"></a>
## Включение или отключение интеграции

Элементы управления находятся в:

```text
RandomDay/Scripts/ax_config/server.lua
```

Пакет выделенного сервера поставляется с:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- Установить `enabled = false` чтобы запретить RandomDay проверять или изменять каждый дополнительный мод.
- Удалите один идентификатор адаптера, чтобы оставить этот мод в покое, сохраняя при этом другие интеграции активными.
- Оставьте для `patch_only_existing_keys` и `backup_before_write` значение `true`. Это граница безопасности записи.
- Оставьте для `optional_by_default = true` за исключением случаев, когда каждый указанный дополнительный мод является обязательной частью сервера. Установка значения `false` приводит к тому, что отсутствующий, несовместимый или безопасно откатный адаптер влияет на совокупный результат.

Удалять не обязательно или отключите дополнительный мод при отключении его RandomDay адаптера.

<a id="backups-and-manual-recovery"></a>
## Резервные копии и восстановление вручную

Проверенные копии предварительной записи сохраняются в:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

Если `rollback_failed` появляется:

1. остановить игру или сервер;
2. установить `external_mods.enabled = false` или удалите идентификатор затронутого адаптера;
3. сохранить текущий целевой файл и его родственный файл pending/rollback файлы;
4. сопоставить пронумерованные файлы резервных копий с целевыми путями, записанными в результате адаптера;
5. восстановить проверенные байты, пока служба остановлена;
6. запустите дополнительный мод самостоятельно, прежде чем повторно включать его. RandomDay адаптера.

Не форсируйте совместимость, переименовывая настройки или добавляя недостающие ключи. Используйте признанный макет, оставьте адаптер отключенным или добавьте новую версию и тест транзакции, прежде чем расширять заявку на поддержку.
