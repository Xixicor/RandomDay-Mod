# Выберите желаемый тип игры

> **Канонический английский источник:** [CHOOSE_A_PROFILE.md](../../CHOOSE_A_PROFILE.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay включает 289 готовых наборов мировых правил. Они организованы в 17 **семейств** по 17 **профилей** в каждом семействе:

- семья – это один широкий игровой стиль, например выживание, строительство, скрытность или исследование;
- профиль – это один полный набор правил внутри этого игрового стиля; и
- номер профиля называется днем, потому что RandomDay перемещается по этим 17 позициям при перезапуске сервера. Это не реальный календарный день.

Начнем с таблицы ниже. Выберите строку, которая ближе всего соответствует нужному сеансу, затем откройте одну или две семейные страницы, чтобы сравнить их точные эффекты.

## Подтвердите точную семью и день

1. Откройте семейную страницу и сравните все позиции за 17 дней.
2. Используйте [справку по полному профилю](%D0%9F%D0%A0%D0%9E%D0%A4%D0%98%D0%9B%D0%98/%D0%9F%D0%9E%D0%9B%D0%9D%D0%AB%D0%99_%D0%A1%D0%9F%D0%A0%D0%90%D0%92%D0%9E%D0%A7%D0%9D%D0%98%D0%9A_%D0%9F%D0%9E_%D0%9F%D0%A0%D0%9E%D0%A4%D0%98%D0%9B%D0%AE.md) для сравнения имен профилей и правил интерпретации во всех 289 комбинациях.
3. Временно используйте [ключи настройки песочницы](%D0%9F%D0%A0%D0%9E%D0%A4%D0%98%D0%9B%D0%98/%D0%9A%D0%9B%D0%AE%D0%A7%D0%98_%D0%9D%D0%90%D0%A1%D0%A2%D0%A0%D0%9E%D0%95%D0%9A_%D0%9F%D0%95%D0%A1%D0%9E%D0%A7%D0%9D%D0%98%D0%A6%D0%AB.md) для интерпретации каждого необработанного значения, поддерживаемого диапазона, диапазона оценок и поставляемого профиля по умолчанию.
4. Временно используйте [`profiles.generated.json`](../../profiles/profiles.generated.json) когда инструменту необходим точный машиночитаемый профиль, словарь и источник перевода.

<a id="configure-the-chosen-experience"></a>
## Настройте выбранный опыт

Следуйте [Выберите вариант](%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%AF.md#choose-an-experience) для установите семейный режим, список подходящих семей, поведение в первый день и последовательный или неповторяющийся случайный порядок дней. RandomDay сохраняет выбранный порядок; восстановление не перезапускает текущий семейный запуск автоматически.
