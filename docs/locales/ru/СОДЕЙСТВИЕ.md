<a id="contributing"></a>
# Содействие

> **Канонический английский источник:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


RandomDay поддерживается как контролируемый проект.

Публичные запросы на включение, нежелательная отправка кода, автоматические переписывания, отправка очистки сгенерированного кода и спекулятивные исправления функций не принимаются, если это явно не запрошено владельцем репозитория.

<a id="accepted-contact"></a>
## Принятый контакт

Для отчетов об ошибках, замечаний по совместимости или замечаний по администрированию сервера используйте каналы связи, указанные в документации проекта.

<a id="not-accepted"></a>
## Не принимается

По умолчанию не принимаются следующие данные:

- нежелательные запросы на включение;
- перезапись сгенерированного кода;
- широкие рефакторинги;
- изменения форматирования только в стиле;
- непроверенные изменения логики игрового процесса;
- пакетные файлы сторонних модов;
- распространяемый сторонний исходный код;
- изменения, предполагающие официальную принадлежность к Abiotic Factor, UE4SS, Nexus Mods или сторонним авторам модов.

<a id="controlled-development"></a>
## Контролируемая разработка

Владелец репозитория может при необходимости запросить специальную помощь по проверке, тестированию или документации. Незапрошенные материалы могут быть закрыты без проверки.
