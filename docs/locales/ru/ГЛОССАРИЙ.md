# Глоссарий

> **Канонический английский источник:** [GLOSSARY.md](../../GLOSSARY.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Это канонический словарь RandomDay документация. Процедуры ссылаются на эти определения вместо переопределения одного и того же состояния в нескольких руководствах. Правила полей, специфичные для схемы, остаются в [Выходные данные во время выполнения](%D0%92%D0%AB%D0%A5%D0%9E%D0%94%D0%9D%D0%AB%D0%95_%D0%94%D0%90%D0%9D%D0%9D%D0%AB%D0%95_%D0%92%D0%A0%D0%95%D0%9C%D0%95%D0%9D%D0%98_%D0%92%D0%AB%D0%9F%D0%9E%D0%9B%D0%9D%D0%95%D0%9D%D0%98%D0%AF.md).

| Термин | Простой смысл | Точное техническое значение |
|---|---|---|
| Активный профиль | Правила, используемые в текущем сеансе. | family/day, определенный RandomDay считывается из песочницы при запуске процесса. |
| Подготовленный профиль | Правила готовы для последующего сеанса. | Полный family/day профиль, целевые байты которого прошли проверку и обратное чтение и состояние ротации которого было зафиксировано. Он не активен до перезапуска обратного чтения. |
| Восстановлено | Подготовка не удалась, и ранее проверенные байты были возвращены. | Ошибочная транзакция сообщает об успешном откате и чтении сохраненной исходной или проверенной копии для восстановления. |
| Очередь следующей перезагрузки | Один подготовленный выбор сохраняется для следующей загрузки. | `next_reboot_queue` выбирает один раз для каждого процесса и повторно использует этот выбор, принадлежащий загрузке, во время контроля. |
| Bootstrap | Первая подготовка, когда активный маркер не существует. | Выбор настроенного или случайного первого дня из подходящего семейства `cycle.bootstrap_day` является лишь запасным вариантом совместимости. |
| Семья | 17-дневный стиль игры. | Одна запись в реестре и семейный модуль, который создает ровно 17 полных профилей. |
| Поворот | Проход через подходящие семьи. | Состояние, определенное `rotation_id`, с доступными, оставшимися, и полные списки семейств. |
| Выполнить | Одно семейство по всем идентификаторам за 17 дней. | Последовательность, связанная с семейством, идентифицированная `run_id`; семейство остается заблокированным до тех пор, пока не будет завершена каждая постоянная позиция дневного заказа. |
| Режим сеанса | Как оператор использует этот пакет. | `persistent_dedicated`, `temporary_dedicated` или `singleplayer_lan`; пакетный режим по-прежнему контролирует границу файловой системы. |
| Дневной порядок | Точный порядок, используемый одним семейством. | Постоянная 17-значная перестановка. Последовательный режим завершается со дня его начала; случайный режим перемешивается один раз без повторения. |
| Маркер | Идентификация хранится в файле песочницы. | `RANDOMDAY_*` поля отображаются с полным профилем и считываются при следующем запуске процесса. |
| Подготовлено | Запись и фиксация состояния выполнены успешно. | `prepared_ready=true` требует успешного результата в песочнице и отсутствия сбоев при фиксации состояния. Это не доказывает активацию. |
| Уже актуально | Цель уже содержит нужные байты. | Отображаемый хеш профиля соответствует целевому, поэтому RandomDay проверяет last-good/mirror работают без перезаписи основного. |
| Сохранение ухудшенного состояния | Байты песочницы прошли успешно, но учет ротации - нет. | `profile_status=degraded_state_persistence`; адаптеры и сообщения подготовленного профиля пропускаются. |
| Файл в ожидании | Байты-кандидаты еще не повышены. | `<target>.randomday.pending` записаны, прочитаны и проверены перед заменой. |
| Файл отката | Исходный файл сохраняется во время замены. | `<target>.randomday.rollback`, используется для восстановления работоспособности при повышении уровня или сбое проверки. |
| Операция резервного копирования | Надежная копия, сделанная до мутации. | Проверенный файл в `runtime/backups/` для основной, зеркальной транзакции или транзакции адаптера. |
| Последний известный удачный | Последняя песочница, принятая для восстановление. | `runtime/last_good/SandboxSettings.ini` плюс `manifest.lua`; пара записывает идентификатор и хеш профиля. |
| Зеркало | Необязательная вторая цель песочницы. | Явно настроенная цель или цель, полученная из мирового имени, записываемая после основной посредством собственной транзакции. |
| Режим пакета | Граница установки, выбранная освободить актив. | `dedicated_server` или `singleplayer_manual` из `.randomday_mode`. |
| Режим ручного копирования | Singleplayer/LAN создание без сохранения сохранения. | `singleplayer_manual` записывает только внутри `runtime/singleplayer_manual/` и отключает адаптеры и зеркала. |
| Адаптер | RandomDay-owned сопоставление для другого установленного мода. | План транзакций с подписью, который обновляет существующие назначения только после проверки резервного копирования и совместимости. |
| Распознанный макет | Точная форма файла адаптера, принятая для записи. | Присутствуют все необходимые ключи подписи и целевые файлы; одного имени файла недостаточно. |
| `not_installed` | Необязательная цель не найдена. | Безопасный результат адаптера без мутаций. |
| `skipped_incompatible` | Цель существует, но ее форма не поддерживается. | Безопасный результат адаптера без мутаций, поскольку полная подпись не совпала. |
| `failed_rolled_back` | Изменение не удалось, предыдущие байты не повреждены. | Транзакция адаптера не удалась до того, как мутация или все затронутые файлы были восстановлены и проверены. |
| `rollback_failed` | Не удалось проверить автоматическое восстановление. | Состояние адаптера жесткой остановки, требующее ручного восстановления из записанной резервной копии. |
| Словарь | Сопоставление необработанных значений с общедоступными объяснениями. | `randomday_dictionary_v2`, созданный из `dictionary.lua` и включается в вывод статуса выполнения. |
| Перевод | Человеческое представление, полученное на основе необработанных значений профиля. | Оценки, факты, сводки и сообщения ограниченной области, созданные `translation.lua`; необработанные значения остаются авторитетными. |
| Публичный статус | Обеззараженная машиночитаемая сводка оператора. | `web_export/today.json` с использованием `randomday_public_status_v2`. |
| статуса выполнения | подробного локального машиночитаемого снимка. | `runtime/current/randomday_status.json` с использованием `randomday_runtime_status_v2`. |
