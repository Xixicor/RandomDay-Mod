RandomDay ist ein unabhängiger Community-Mod für dedizierte Server von Abiotic Factor.

RandomDay beinhaltet, kopiert, rehostet oder verteilt keinen Code von unterstützten Drittanbieter-Mods. Die optionale Integration erfolgt über RandomDay-ownedAdapterskripte, die offengelegte Einstellungen nur dann patchen, wenn der Serverbesitzer diese unterstützten Mods separat installiert hat.
