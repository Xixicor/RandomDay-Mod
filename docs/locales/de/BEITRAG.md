# Beitrag

> **Kanonisch-englische Quelle:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Diese lokalisierte Dokumentation bewahrt genaue Befehle, Pfade, Schlüssel, Statuswerte, Hashes und Dateinamen. Wenn der technische Wortlaut abweicht, verwenden Sie die englische Quelle.


RandomDay wird als kontrolliertes Projekt verwaltet.

Öffentliche Pull-Anfragen, unaufgeforderte Code-Übermittlungen, automatisierte Umschreibungen, Übermittlungen zur Bereinigung generierten Codes und spekulative Feature-Patches werden nicht akzeptiert, es sei denn, dies wird ausdrücklich vom Repository-Eigentümer angefordert.

<a id="accepted-contact"></a>
## Akzeptiert Kontakt

Für Fehlerberichte, Kompatibilitätshinweise oder Beobachtungen zur Serververwaltung verwenden Sie die in der Projektdokumentation aufgeführten Kontaktkanäle.

<a id="not-accepted"></a>
## Nicht akzeptiert

Folgendes wird standardmäßig nicht akzeptiert:

- unaufgeforderte Pull-Anfragen;
- generierter Code schreibt um;
- umfassende Umgestaltungen;
- nur stilistische Formatierungsänderungen;
- ungetestete Gameplay-Logikänderungen;
- gebündelte Mod-Dateien von Drittanbietern;
- weiterverbreiteter Quellcode von Drittanbietern;
- Änderungen, die eine offizielle Zugehörigkeit zu Abiotic Factor implizieren, UE4SS, Nexus Mods oder Drittanbieter-Mod-Autoren.

<a id="controlled-development"></a>
## Kontrollierte Entwicklung

Der Repository-Eigentümer kann bei Bedarf spezifische Überprüfungs-, Test- oder Dokumentationshilfe anfordern. Nicht angeforderte Einsendungen können ohne Überprüfung geschlossen werden.
