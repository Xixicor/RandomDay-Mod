# Sicherheitsrichtlinie

> **Kanonisch-englische Quelle:** [SECURITY.md](../../../SECURITY.md). Diese lokalisierte Dokumentation bewahrt genaue Befehle, Pfade, Schlüssel, Statuswerte, Hashes und Dateinamen. Wenn der technische Wortlaut abweicht, verwenden Sie die englische Quelle.


RandomDay schreibt Serverkonfigurationsdateien und kann optionale Mod-Konfigurationsdateien patchen. Behandeln Sie Änderungen als betriebsrelevant.

<a id="do-not-report-as-security-issues"></a>
## Nicht als Sicherheitsproblem melden

- Normale Änderungen der Spielbalance.
- Profilrotation beim nächsten Neustart erwartet.

<a id="report-privately"></a>
## Privat melden

- Pfaddurchquerungsrisiken.
- Unsicheres Dateischreibverhalten.
- Möglichkeit zum Überschreiben von Dateien außerhalb der vorgesehenen server/modPfade.
- Böswillige Befehlsausführung.

Bis ein öffentlicher Sicherheitskanal existiert, melden Sie sich privat beim Repository-Eigentümer.
