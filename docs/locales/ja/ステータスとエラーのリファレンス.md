# ステータスとエラーのリファレンス

> **正規の英語ソース:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


ランタイム エクスポートからの正確な`status`, `transaction_status`, `rollback_status` と `error`値を使用します。パネルまたはコンソール内の同様の文言は、これらのフィールドの代わりにはなりません。

このセクションは完全な参照リファレンスです。上のデシジョン ツリーは関連するカテゴリを選択します。これらのテーブルは正確なマシン値と安全なオペレータを保持します。

<a id="normal-or-informational-states"></a>
## 通常状態または情報状態

| ステータス | 意味 | オペレーターの応答 |
|---|---|---|
| `prepared_for_next_reboot` | 次回の起動用に検証されたプロファイルが書き込まれました。 | アクションはありません。現在のセッションは変更されません。 |
| `next_reboot_already_prepared` | 意図された次のプロファイルはすでにターゲットと一致しています。 | アクションはありません。別のローテーションを強制しないでください。 |
| `already_current` / `unchanged` | ターゲットには、意図したバイトがすでに含まれています。 | アクションはありません。 |
| `applied` | 書き込みと本番リードバックは成功しました。 | 次回の起動後に、active/prepared区別を確認してください。 |
| `bootstrap_prepare_first_family_start_day` | 以前のローテーション状態は存在しません。  | 最初の使用時に期待されます。 |
| `state_recovery_rewrite_prepared_profile_no_reroll` | 保存された状態が復元され、同じ準備されたプロファイルが書き換えられました。 | 復元された日を確認します。新しいランダムな選択は発生しませんでした。 |
| `supervision_reconfirm_prepared_profile_no_advance` | 監視パスにより、既存の準備が確認されました。 | 予想通り。キューは 2 回進みませんでした。 |
| `external_mods_disabled` | オプションのアダプター処理は無効になっています。 | アダプターが意図したものでない限り、アクションはありません。 |
| `external_mods_processed` | 有効なアダプター プランはすべて最終結果に達しました。 | 各アダプター行を確認してください。 |

<a id="startup-configuration-errors"></a>
## 起動構成エラー

これらのメッセージは、RandomDay がプロファイルを書き込む前に起動を停止するを参照してください。名前付き設定またはパッケージ マーカーを修正します。検証ブランチをバイパスしないでください。

| エラー テキスト | 意味 | 安全な応答 |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode`が見つからないか、不正な形式であるか、間違ったパッケージからのものです。 | 1 つの完全なパッケージをクリーンなステージング フォルダーに再インストールし、目的のモード マーカーを保存してください。 |
| `invalid experience.mode` | `experience.mode`は文書化された値の 1 つではありません。 | 使用する `auto`, `persistent_dedicated`, `temporary_dedicated`、または `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | A手動コピー パッケージは専用サーバーとして構成されました。 | 復元`auto` または `singleplayer_lan`;自動的に外部を指さないでください。 |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | 手動コピー ワークフロー用に専用のパッケージが設定されました。 | 使用する `auto`, `persistent_dedicated`、または `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | 最初の日セレクタが無効です。 | 正確に使用してください。`configured` または `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | 日順セレクタが無効です。 | 正確に使用してください。`sequential` または `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | 設定された開始日が小数であるか、範囲外です。サイクル。 | 1 から 1 までの整数を使用してください。`cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | バックアップまたは前回の正常な復元が無効になりました。 | 両方の安全ロックを元に戻します。 RandomDay 安全でない書き込みを意図的に拒否します。 |
| `external adapter transaction safety locks must remain true` | アダプターのパッチ適用またはバックアップ保護が無効になりました。 | 両方のアダプターの安全ロックを復元するか、グループとしてアダプターを無効にします。 |
| `paths.world_name must be one folder name` | 設定されたワールド名には区切り文字または安全でない文字が含まれています。 | 文字、数字、文字を使用して正確なフォルダー名のみを入力してください。スペース、アンダースコア、またはハイフン。 |
| `required runtime directory unavailable` | 必要な mod-local 出力ディレクトリを作成または確認できませんでした。 | 指定されたもののみをチェックしますRandomDay ディレクトリとその書き込み権限。 |

<a id="profile-wide-configuration-errors"></a>
## プロファイル全体の構成エラー

これらのエラーは、サンドボックスの書き込み前にプロファイルの構築を停止します。

| エラー テキスト | 意味 | 安全な応答 |
|---|---|---|
| `sandbox.profile_overrides must be a table` | プロファイル全体の 4 つの選択肢は、別の Lua タイプに置き換えられました。 | 文書化された表を`Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | この表には、サポートされている 4 つのキーのいずれでもない設定が含まれています。 | 名前付きキーを削除して使用しますfamily/profile 他のサンドボックス設定のソース。 |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` または `AllowIronMode` は `true` または `false`. | 引用符で囲まれていない Lua ブール値を使用します。 |
| `sandbox.profile_overrides.<key> must be integer` | サポート値は整数ではありません。 | 整数を使用します。 |
| `sandbox.profile_overrides.<key> outside supported range` | サポート値が範囲外です `0..1000`. | 整数を次から選択してください`0`から`1000`. |

<a id="rollback-and-intermediate-states"></a>
## ロールバックと中間状態

| 値 | 意味 | 安全な応答 |
|---|---|---|
| `not_started` / `pending` | トランザクションまたはアダプター プランは最終結果に達していません。 | 現在の制限されたスタートアップ パスのみを待ちます。永続的な状態は調査が必要です。 |
| `not_needed` | ロールバックは必要ありませんでした。 | アクションはありません。 |
| `original_held` | 元のターゲットは昇格前に回復位置に移動されました。 | トランザクションが完了していない間はリカバリ ファイルを削除しないでください。 |
| `retained_after_success` | 新しいターゲットは検証されましたが、クリーンアップが利用できなかったか、意図的に保持されていたため、リカバリ データが残ります。 | 名前付きリカバリ ファイルを削除する前に、実稼働バイトを確認してください。 |
| `discarded_after_success` | 置換が検証され、一時的なロールバック データが消去されました。 | アクションはありません。 |
| `rollback_failed` | 試行された復元を検証できませんでした。 | サーバーを停止したままにして、最後に検証された操作のバックアップを使用します。 |
| `skipped_state_persistence_failed` | サンドボックス バイトは準備されましたが、ローテーション状態が保持されなかったため、アダプターと準備されたプレーヤーのメッセージングは​​スキップされました。 | ランタイム状態ストレージを修復します。キューを手動で再ロールしたり進めたりしないでください。 |
| `failed` | 概要行は、`error` フィールドまたはトランザクション フィールドに特定の原因がある端末障害を表します。 | 最初の特定のコードに従います。 `failed` 単独でトラブルシューティングを行わないでください。 |

<a id="transaction-failures"></a>
## トランザクションの失敗

| ステータス | 意味 | 安全な応答 |
|---|---|---|
| `invalid_input` | 置換リクエストが有効なテキストでないか、有効なターゲットがありませんでした。 | 正しい設定。変更せずに再試行しないでください。 |
| `stale_pending_cleanup_failed` | 古い保留中のファイルを削除できませんでした。 | 手動クリーンアップの前に保留中のファイルを停止して保存してください。 |
| `stale_rollback_requires_review` | リカバリ データは現在のターゲットの横に存在するため、安全に破棄できません。 | どちらかを選択する前に、ターゲット バイトとロールバック バイトを比較してください。 |
| `interrupted_transaction_restore_failed` | 置換が中断された後のリカバリではターゲットを復元できませんでした。 | サーバーを停止したままにして、検証済みのバックアップを復元してください。 |
| `interrupted_transaction_cleanup_failed` | ターゲットはリカバリされましたが、古いトランザクション データはクリアできませんでした。 | ターゲットのバイトを確認し、指定された古いサイドカーのみを削除します。 |
| `pending_write_failed` | 候補を書き込むことができませんでした。 | 狭いターゲット ディレクトリと空き領域を確認してください。 |
| `pending_readback_failed` / `pending_readback_mismatch` | 候補バイトを読み取れなかったか、書き込み後に異なっていました。 | 保留中のファイルをプロモートしないでください。 |
| `pending_validation_failed` | 候補は検証に失敗しました。schema/profile  | 報告されたキーまたはルールを修正します。検証をバイパスしないでください。 |
| `operation_backup_failed` / `backup_failed` | 検証済みの書き込み前のバックアップが作成されませんでした。 | 停止;ターゲット置換は信頼できません。 |
| `original_preserved_move_failed` | 元のターゲットをリカバリ位置に移動できませんでした。 | すべてのトランザクション ファイルを保存し、手動でリカバリしてください。 |
| `promotion_failed` | 保留中の候補を本番ターゲットにできませんでした。 | 再試行する前に、元のターゲットが復元されたかどうかを確認してください。 |
| `production_validation_failed` | プロモートされたバイトが本番に失敗しましたreadback/validation. | 検証済みのバックアップを復元し、ターゲット ライターを検査します。 |
| `replacement_committed_recovery_cleanup_failed` | 置換は有効ですが、ロールバック データをクリアできませんでした。 | ターゲットをコミット済みとして扱います。検証された古いリカバリ データのみを削除します。 |
| `rollback_failed` | 自動復元は検証されませんでした。 | サーバーを停止したままにし、手動リカバリを使用します。 |

<a id="target-profile-adapter-and-export-failures"></a>
## ターゲット、プロファイル、アダプタ、およびエクスポートの失敗

| ステータス | 意味 | 安全な応答 |
|---|---|---|
| `target_refused` | 設定されたパスが許可されたモードの境界外にあります。 | パスを修正してください。境界を弱めないでください。 |
| `target_directory_failed` | ターゲット ディレクトリを作成または確認できませんでした。 | そのディレクトリの存在と権限のみを確認してください。 |
| `profile_validation_failed` | プロファイルにキーがないか、間違っているtype/rangeか、残りの不変ルールに違反しています。 | 名前付きのディレクトリを使用してください。キー、`sandbox.profile_overrides`、およびプロファイル参照を使用してソースを修復します。 |
| `skipped_incompatible` | オプションの MOD が存在しますが、サポートされているアダプタの署名と一致しません。 | 変更しないままにするか、そのアダプタを無効にします。 |
| `external_mods_partial` | 一部のオプション アダプタは完了し、その他は安全でした。skipped/failed. | アダプタ行を個別に確認します。サンドボックスの結果は別のものです。 |
| `external_adapter_failed` | 必要なアダプタが安全に完了しませんでした。 | 再試行する前に、検証済みのバックアップを復元してください。 |
| `degraded_state_persistence` | サンドボックスの準備は完了しましたが、回転状態の永続化は完了しませんでした。 | 次回の起動が正しく完了するとは考えないでください。状態ストレージを修復します。 |
| `export_directory_failed` | `web_export/`作成または書き込みできませんでした。 | ゲームプレイの準備がまだ有効である可能性があります。  |

<a id="translation-and-message-validation-errors"></a>
## 翻訳エラーとメッセージ検証エラー

これらは、辞書エラーまたはプレゼンテーション契約エラーです。これらはリリース前に検証され、制限された実行時ステータスの警告として表示される場合もあります。

| エラー テキスト | 意味 | 安全な応答 |
|---|---|---|
| `dictionary coverage mismatch` | プロファイル辞書は、文書化されたすべての設定を説明しているわけではありません。 | 欠落している辞書エントリを追加し、プロファイルを再実行します。generation/validation. |
| `missing profile setting` | 選択したプロファイルには、dictionary/schema. | プロファイル ファミリ ソースを修復するために必要な設定がありません。ランタイムのデフォルトを作成しないでください。 |
| `empty explanation` | 設定は存在しますが、operator/player説明がありません。 | リリース前にわかりやすい説明を追加してください。 |
| `join line too wide` | 生成された結合行が 42 文字のソース制限を超えています。 | 辞書の語句を短くしてください。クライアント ラッピングに依存しないでください。 |
| `join message too tall` | 生成された結合概要は 4 行を超えます。 | メッセージの内容を減らすか優先順位を変更します。 |
