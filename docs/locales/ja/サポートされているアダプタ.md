# サポートされるオプションの Mods

> **正規の英語ソース:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDay 個別にインストールされた MOD をアクティブな MOD に追従させることができます RandomDay プロフィール。この機能は、専用サーバー パッケージでのみ使用できます。 singleplayer/LAN パッケージが他の MOD を編集することはありません。

RandomDay には、ここにリストされている MOD は含まれておらず、再配布もされていません。各オプションの MOD をそれぞれの Nexus ページからインストールして有効にし、まずその作成者の指示に従ってください。 RandomDay は、インストールされたファイルに既に存在する認識された設定のみを変更します。別の MOD に機能を追加するものではなく、その MOD をアンインストールせずにアダプターを無効にすることができます。専用サーバー パッケージは `external_mods.enabled = true`.

## 内容 RandomDay 変更点

| オプションの統合 | アクティブなプロファイルから選択された設定 |
| --- | --- |
| カオス スポーン エンジン / DynamicSpawns | ハード モード、player/areaクールダウン動作、ストームとホットゾーンのアクティビティ、ボスとバーストのスポーン、スポーン サイクルのタイミング、大小のクールダウン範囲、スポーン距離、global/local/modキャップ、ポータル ストーム、命令違反とボスのチャンス、およびエリアごとの最小スポーン数。 |
| オプションのカオス スポーン エンジン拡張フィールド | インストールされた`SharedData.lua` にはすでに RandomDay 拡張フィールドを使用すると、アダプタはエンカウント プロファイル、階層、テーマ、グループ制限、特別イベントおよび混合エンカウントの値、予算、クールダウン、ワールド スコープの制御を提供できます。これはダウンロードする必要のある別の MOD ではありません。 |
| リーサル レーザー | MOD のアクティベーションに加え、ダメージと、展開可能なエミッタ、環境エミッタ、リフレクタ、およびプリズムのコントロールを有効にします。 |
| ANTE 上 | リスポーン周波数乗数、アンテバリアント周波数、および既存の development/debug スイッチ。 RandomDay 認識されるすべての開発スイッチとデバッグ スイッチがオフのままになります。 |

プロファイル ライブラリは、サポートされている日ごとに準備された値セットを提供します。静かな日は圧力を下げることができ、危険な日は圧力を上げ、回復日は急激に下げることができます。 RandomDay は起動時に任意の値を計算しません。アクティブなプロファイルによって指定されたレビュー済みの値セットが適用されます。

<a id="how-recognition-protects-another-mod"></a>
## 認識によって別の MOD が保護される仕組み

馴染みのあるファイル名を見つけるだけでは十分ではありません。書く前に、RandomDay は、そのアダプターに必要なすべての設定がターゲット ファイルに存在することを確認します。既存の割り当てのみにパッチを適用します。欠落した設定が生み出されることはありません。

認識されたレイアウトの場合、RandomDay は、1 つの制限付きトランザクションを実行します。

1. アクティブなプロファイルのすべての意図された値を計算します。
2. すべてのターゲット ファイルのバックアップを作成してバイトチェックします。
3. 兄弟の保留中のファイルを介して書き込みます。
4. 保留中のファイルをプロモートし、保存されたバイトを読み戻します。
5. 意図した値をすべて確認してください。
6. いずれかの手順が失敗した場合は、検証済みのバックアップからの自動復元を使用します。

DynamicSpawns は、その設定と認識されたプレーヤー メッセージ ファイルを 1 つのトランザクションに含めることができます。 RandomDay は、トランザクションが完了しない限り、複数ファイルの更新が成功したことを報告しません。

<a id="read-an-adapter-result"></a>
## アダプターの結果を読み取る

| 結果 | 意味 |
| --- | --- |
| `applied` | 認識された設定が変更され、リードバックが渡されました。 |
| `already_current` | 認識された設定はすでにアクティブなプロファイルと一致しています。 |
| `not_installed` | オプションの MOD が見つかりませんでした。 RandomDay はそのまま続行されました。 |
| `skipped_incompatible` | ファイルは見つかりましたが、その完全な設定レイアウトが認識されませんでした。何も変更されませんでした。 |
| `partial` | 主なDynamicSpawns設定は適用されましたが、オプションの翻訳されたメッセージ ファイルは完了しませんでした。記録されたアダプターの結果を確認します。 |
| `failed_rolled_back` | トランザクションが失敗し、以前のバイトはそのまま残っているか、復元されて検証されました。 |
| `rollback_failed` | RandomDay は変更または復元を検証できませんでした。影響を受ける MOD を停止したままにし、記録されたバックアップを手動で復元します。 |

欠落しているオプション MOD や互換性のないオプション MOD は、出荷時の設定では RandomDay's出荷時の設定でのサンドボックス ローテーション。

<a id="enable-or-disable-integrations"></a>
## 統合を有効または無効にする

コントロールは次の場所にあります。

```text
RandomDay/Scripts/ax_config/server.lua
```

専用サーバー パッケージには次のものが付属しています。

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- `enabled = false`これにより、RandomDay すべてのオプション MOD の検査または変更が停止されます。
- アダプター ID を 1 つ削除して、他の統合をアクティブなままにしてその MOD をそのままにしておきます。
- `patch_only_existing_keys` と `backup_before_write` を `true` に設定したままにします。これらは書き込み安全境界です。
- `optional_by_default = true` リストされているすべてのオプション MOD がサーバーの必須部分である場合を除きます。 `false` に設定すると、欠落しているアダプター、互換性のないアダプター、または安全にロールバックされたアダプターが集計結果に影響します。

アンインストールまたは変更する必要はありません。 RandomDay アダプターを無効にすると、オプションの MOD も無効になります。

<a id="backups-and-manual-recovery"></a>
## バックアップと手動リカバリ

検証済みの書き込み前のコピーは次の場所に保持されます:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

場合 `rollback_failed` が表示されます:

1. ゲームまたはサーバーを停止します。
2. 設定 `external_mods.enabled = false`または、影響を受けるアダプター ID を削除します。
3. 現在のターゲット ファイルとその兄弟ファイルを保存します pending/rollback ファイル;
4. 番号付きバックアップ ファイルをアダプターの結果に記録されたターゲット パスと照合します。
5. サービスの停止中に検証されたバイトを復元します。
6. オプションの MOD を再度有効にする前に単独で起動します。RandomDay アダプターを無効にすると、オプションの MOD も無効になります。

設定の名前を変更したり、不足しているキーを追加したりして互換性を強制しないでください。サポート要求を拡大する前に、認識されたレイアウトを使用するか、アダプターを無効のままにするか、新しいバージョンのフィクスチャとトランザクション テストを追加してください。
