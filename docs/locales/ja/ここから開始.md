# ここから開始: 最初の部分を完了します。 RandomDay サイクル

> **正規の英語ソース:** [START_HERE.md](../../START_HERE.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


このガイドは、RandomDay がインストールされた後に開始します。 MOD が何を変更し、何をそのままにし、成功したサイクルをどのように認識するかを示します。

<a id="know-the-two-states"></a>
## 2 つの状態を理解する

Abiotic Factor は、RandomDay が開始される前に世界のサンドボックス設定を読み取ります。したがって、RandomDay は、明確に名前が付けられた 2 つの状態を保持します。

- **アクティブなプロファイル:**現在のセッションがすでに使用しているルール。
- **準備済みプロファイル:**次回の起動のために保存されたルール。

準備されたプロファイルは、すでに進行中のセッションを変更しません。

<a id="dedicated-server-prepare-the-next-profile"></a>
## 専用サーバー: 次のセッションを準備します。プロファイル

1. サーバーを通常どおり起動します。
2. RandomDay が起動作業を完了するのを待ちます。
3. インストールされた MOD フォルダで `RandomDay/web_export/today.html` を開きます。
4. 検索**アクティブなプロファイル** と **準備されたプロファイル**.

最初の正常な起動では、ページにすでにアクティブなルールと別のプロファイルが次の開始を待っています。このページでは、選択したファミリー、位置、準備されたファイルが安全性チェックに合格したかどうかについても説明します。

ステータスを変更するためだけに再起動しないでください。次に計画されたサーバーが起動するまで、アクティブなルールを使用し続けます。

<a id="dedicated-server-activate-it-later"></a>
## 専用サーバー: 後でアクティブ化します

1. 次回計画された再起動時にサーバーを停止して起動します。
2. 読み取り可能なステータス ページを再度開きます。
3. 以前に準備したプロファイルがアクティブとしてリストされていることを確認します。
4. RandomDayが次のプロファイルを準備したことを確認します。

準備、その後、アクティブ化の遷移が完了しました。 RandomDay サイクル。

<a id="temporary-dedicated-servers"></a>
## 一時的な専用サーバー

一時的な動作では、同じ専用サーバー パッケージが使用されます。 [構成](%E6%A7%8B%E6%88%90.md) で、新しい実行を特定のプロファイルで開始するか、ランダムな開始点を選択するかを選択します。ステータス ページは、アクティブなプロファイルと次回の起動用に準備されたプロファイルを分離します。

<a id="singleplayer-or-lan"></a>
## シングルプレイヤーまたは LAN

1. singleplayer/LANパッケージがインストールされた状態でゲームを 1 回開始します。
2. RandomDay が終了したら、ゲームを完全に閉じます。
3. 生成された概要を読みます。
4. 生成されたプロファイルをコピーします。`SandboxSettings.ini`ゲームが閉じている間に、選択したワールドにコピーされます。
5. そのワールドを開始し、予想されるルールを確認します。

ローカル パッケージは、ワールドを選択したり、ファイルを単独で保存場所にコピーしたりすることはありません。完全な手順については、[シングルプレイヤーとLAN](%E3%82%B7%E3%83%B3%E3%82%B0%E3%83%AB%E3%83%97%E3%83%AC%E3%82%A4%E3%83%A4%E3%83%BC_LAN.md)を参照してください。

<a id="if-the-expected-result-is-missing"></a>
## 期待した結果が得られない場合

再起動を続けないでください。現在のファイルを保存し、[トラブルシューティング](%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB%E3%82%B7%E3%83%A5%E3%83%BC%E3%83%86%E3%82%A3%E3%83%B3%E3%82%B0.md) で一致する症状を選択します。通常の結果では、常にアクティブなプロファイルと、準備されたプロファイルまたは 1 つの明らかな準備失敗のいずれかが指定されます。
