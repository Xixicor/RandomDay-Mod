# シングルプレイヤーとLAN手動ワークフロー

> **正規の英語ソース:** [SINGLEPLAYER_LAN.md](../../SINGLEPLAYER_LAN.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDay's singleplayer/LAN パッケージは、mod フォルダー内に完全な `SandboxSettings.ini` を生成します。ワールドを選択し、ゲームを閉じている間にファイルを手動でコピーします。

パッケージは次の出力にロックされます:

```text
RandomDay/runtime/singleplayer_manual/SandboxSettings.ini
```

専用サーバーのサンドボックス書き込み、サンドボックス ミラー、およびすべてのオプションのアダプター書き込みが無効になります。検索はしませんAppData、Steam ユーザーデータ、ドキュメント、保存フォルダー、サーバー フォルダー、またはサードパーティの MOD フォルダー。

<a id="understand-the-manual-boundary"></a>
## 手動境界を理解してください。

開始する前に、`RandomDay/Scripts/ax_config/server.lua` でエクスペリエンスを設定してください。マニュアル パッケージは `experience.mode="auto"` または `"singleplayer_lan"` を受け入れます。固定またはランダムの初日と、連続または非反復のランダムな 17 日間の順序を選択できます。ファミリの選択では、専用サーバーと同じ選択、ローテーション、または非反復ランダム ファミリ設定が使用されます。

生成された出力にはマーカーが含まれますRandomDay は次のプロセスで読み取ります。状態を一致させておくには、別の生成プロセスを開始する前に、生成されたファイルを選択した停止ワールドにコピーします。コピーせずに繰り返し開始すると、たとえ以前の出力がロードされなかったとしても、mod-local キューが進む可能性があります。

正規版に従う [シングルプレイヤーまたは LANインストール手順](%E3%82%A4%E3%83%B3%E3%82%B9%E3%83%88%E3%83%BC%E3%83%AB.md#singleplayer-or-lan) バックアップ、パッケージの配置、有効化、生成、手動コピー、検証用。このページでは手動境界について説明します。別のインストール方法を定義するものではありません。

最初の世代ではプロファイルが準備されます。そのゲームプロセスによってすでにロードされているルールを変更することはできません。使用するには、閉じてコピーし、再度起動してください。次の日を意図的に永続化したい場合にのみ、このサイクルを繰り返します。

削除中 RandomDay は、手動でコピーしたワールド ファイルを復元しません。そのロールバックには独自のバックアップを使用してください。フォロー[インストールを削除またはロールバックする](%E3%82%A4%E3%83%B3%E3%82%B9%E3%83%88%E3%83%BC%E3%83%AB.md#remove-or-disable-randomday)をご覧ください。
