# 用語集

> **正規の英語ソース:** [GLOSSARY.md](../../GLOSSARY.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


これは RandomDayドキュメント。プロシージャは、複数のガイドで同じ状態を再定義するのではなく、これらの定義にリンクします。スキーマ固有のフィールド ルールは [実行時出力](%E3%83%A9%E3%83%B3%E3%82%BF%E3%82%A4%E3%83%A0%E5%87%BA%E5%8A%9B.md).

| 用語 | わかりやすい意味 | 正確な技術的意味 |
|---|---|---|
| アクティブなプロファイル | 現在のセッションが使用しているルール。 | family/day プロファイルは RandomDay プロセスの起動時にサンドボックスから読み取られるマーカー。 |
| 準備されたプロファイル | ルールは後のセッションで使用できるようになりました。 | 完全版 family/day ターゲット バイトが検証とリードバックに合格し、ローテーション状態がコミットされたプロファイル。リードバックを再開するまではアクティブではありません。 |
| 復元されました | 準備が失敗し、以前に検証されたバイトが戻されました。 | 失敗したトランザクションは、保持されているオリジナルまたは検証済みのリカバリ コピーの成功したロールバックとリードバックを報告します。 |
| 次回再起動キュー | 準備された 1 つの選択肢は、次回の起動まで保持されます。 | `next_reboot_queue` プロセスごとに 1 回選択し、監視中にそのブート所有の選択を再利用します。 |
| ブートストラップ | アクティブなマーカーが存在しない場合の最初の準備。 | 対象となるファミリーからの設定済みまたはランダムな初日の選択。 `cycle.bootstrap_day` は互換性のフォールバックにすぎません。 |
| ファミリー | 17 日間のプレイスタイルの進行。 | 正確に 17 個の完全なプロファイルを生成する 1 つのレジストリ エントリとファミリー モジュール。 |
| 回転 | 対象となるファミリーを通過します。 | 州は`rotation_id`によって識別され、利用可能なものは、  |
| 実行 | 17 日間の ID すべてにわたって 1 つのファミリーを実行します。 | ファミリー結合シーケンスは `run_id`によって識別されます。永続化された日次注文ポジションがすべて完了するまで、ファミリーはロックされたままになります。 |
| セッション モード | オペレーターによるこのパッケージの使用方法。 | `persistent_dedicated`, `temporary_dedicated`、または `singleplayer_lan`;パッケージ モードは引き続きファイル システムの境界を制御します。 |
| 日順 | 1 つのファミリー実行で使用される正確な順序。 | 永続的な 17 個の数値の順列。シーケンシャル モードは開始日からラップされます。ランダム モードは、繰り返しなしで 1 回シャッフルします。 |
| マーカー | サンドボックス ファイルに保存された ID。 | `RANDOMDAY_*`フィールドは完全なプロファイルでレンダリングされ、次のプロセス起動時に読み取られます。 |
| 準備完了 | 書き込みと状態のコミット | `prepared_ready=true` には、サンドボックスの結果が成功し、状態コミットが失敗していないことが必要です。これはアクティベーションを証明するものではありません。 |
| すでに最新です | ターゲットにはすでに意図したバイトがあります。 | レンダリングされたプロファイル ハッシュはターゲットと一致するため、RandomDay が検証します last-good/mirrorプライマリを書き換えずに動作します。 |
| 劣化状態の永続性 | サンドボックス バイトは成功しましたが、ローテーション ブックキーピングは失敗しました。 | `profile_status=degraded_state_persistence`;アダプタと準備されたプロファイルのメッセージングはスキップされます。 |
| 保留中のファイル | まだ昇格されていない候補バイト。 | `<target>.randomday.pending`、置換前に書き込まれ、読み戻され、検証されます。 |
| ロールバック ファイル | 置換中に保持されるオリジナル。 | `<target>.randomday.rollback`、プロモーションまたは検証の失敗時に本番環境を復元するために使用されます。 |
| 操作のバックアップ | 変更前に作成された耐久性のあるコピー。 | プライマリ、ミラー、またはアダプター トランザクションの`runtime/backups/`にある検証済みのファイル。 |
| 最後に確認された正常な状態 | 受け入れられた最新のサンドボックス回復。 | `runtime/last_good/SandboxSettings.ini` プラス `manifest.lua`;このペアはプロファイル ID とハッシュを記録します。 |
| ミラー | オプションの 2 番目のサンドボックス ターゲット。 | 明示的に設定されたターゲット、または独自のトランザクションを通じてプライマリの後に書き込まれるワールド名由来のターゲット。 |
| パッケージ モード | リリースによって選択されたインストール境界アセット。 | `dedicated_server` または `singleplayer_manual` を検証します。プロファイル全体の 4 つの選択肢は、`.randomday_mode`. |
| 手動コピー モード | Singleplayer/LAN保存検出なしの生成。 | `singleplayer_manual` `runtime/singleplayer_manual/`アダプタとミラーを無効にします。 |
| アダプター | RandomDay-ownedインストールされている別の MOD のマッピング。 | バックアップと互換性チェック後にのみ既存の割り当てを更新する、署名ゲート型トランザクション プラン。 |
| 認識されたレイアウト | 書き込みに受け入れられる正確なアダプター ファイルの形式。 | 必要な署名キーとターゲット ファイルがすべて存在します。ファイル名だけでは不十分です。 |
| `not_installed` | オプションのターゲットが見つかりませんでした。 | 突然変異のない安全なアダプターの結果。 |
| `skipped_incompatible` | ターゲットは存在しますが、その形状はサポートされていません。 | 完全な署名が一致しなかったため、突然変異のない安全なアダプターの結果。 |
| `failed_rolled_back` | 変更は失敗しましたが、以前のバイトはそのままです。 | 変更または影響を受けるすべてのファイルが復元および検証される前に、アダプターのトランザクションが失敗しました。 |
| `rollback_failed` | 自動リカバリを確認できませんでした。 | 記録されたバックアップから手動で回復する必要があるハードストップ アダプターの状態。 |
| 辞書 | 生の値から公開された説明へのマッピング。 | `randomday_dictionary_v2`、`dictionary.lua` 実行時のステータス出力に含まれます。 |
| 翻訳 | 生のプロファイル値から派生した人間の視点。 | 境界付きドメインのスコア、ファクト、概要、および生成されたメッセージ`translation.lua`;生の値は引き続き信頼されます。 |
| 公開ステータス | サニタイズされた機械可読オペレータの概要。 | `web_export/today.json`使用`randomday_public_status_v2`. |
| 実行時ステータス | 詳細なローカル機械可読スナップショット。 | `runtime/current/randomday_status.json`使用`randomday_runtime_status_v2`. |
