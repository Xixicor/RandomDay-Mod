# リリースの検証

> **正規の英語ソース:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


このページは、寄稿者およびリリース管理者向けです。 MOD をインストールするプレイヤーは、これらのコマンドを実行する必要はありません。

<a id="ordinary-user-proof"></a>
## 一般ユーザーの証明

新しい読者が 2 つのパッケージのいずれかを選択し、インストールし、アクティブなプロファイルと準備されたプロファイルを識別し、リンクされたガイドに従って欠落した結果を回復できる場合、リリースは理解できます。これらのリーダー タスクには Git が必要であってはなりません。PowerShell、Python、またはチェックサムの知識。

<a id="contributor-checks"></a>
## 投稿者チェック

リポジトリ ルートから実行します:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

`luac`が利用可能な場合、出荷されたすべての Lua ファイルの構文チェックを行います。

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

 Lua ランタイム テストには `lupa` が必要です。 Lua インタープリタまたは`lupa`インストールが欠落している場合は、使用できないテスト機能であり、合格結果ではありません。

<a id="release-checks"></a>
## リリース チェック

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

リリース チェックでは、次の条件が検証されます:

- `VERSION` と `RandomDay/.randomday_version` が一致する。
- 現在のバージョンのみが`releases/`.
- 専用 ZIP と singleplayer/LAN ZIP は完全な代替手段です。
- どちらのアーカイブにも正規の `RandomDay/Scripts/main.lua` パスが含まれており、大文字と小文字が衝突するローダーはありません。
- パッケージ モード マーカーは `dedicated_server` と `singleplayer_manual`.
- ZIP バイトは決定的で一致します `CHECKSUMS.sha256`.
- ランタイム データ、プライベート構成、資格情報、キャッシュ、テスト出力はパッケージ化されません。
- すべてのローカル ドキュメント リンクと 27 のロケール エントリ ページが検証されます。

<a id="avoid-validation-environment-pitfalls"></a>
## 検証環境の落とし穴を回避します

- 2 つのプロセスが同じ一時ファイルを置き換えないように、リポジトリ書き込みチェックを連続して実行します。
- Windows では、チェックボックスをオンにしますZIP 小文字のローダーが存在するかどうかを判断するために、大文字と小文字を区別しないファイル検索を使用するのではなく、メンバー名を指定します。
- 確認 `mods.txt` と `enabled.txt`インストールされたサーバーのテストでのみ。これらはソース テストが実行されたことを証明するものではありません。
- コマンド タイムアウトを不完全として記録します。コマンドの制限された出力がなければ、合格または失敗に変換しないでください。
- リポジトリ内の一時ファイルは無視されます。`.tmp/` ディレクトリ。

<a id="known-limits"></a>
## 既知の制限

ローカル検証により、ソース、パッケージ、ドキュメント、およびフィクスチャのコントラクトが証明されます。特定のサーバー パネルの起動順序、ライブ クライアントのメッセージ レイアウト、またはホスト固有のファイル システム パスを証明するものではありません。テスト時にそれらを個別の統合結果として記録します。
