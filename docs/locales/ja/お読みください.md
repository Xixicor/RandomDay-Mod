# RandomDay 日本語ガイド

> [!IMPORTANT]
> ## プロジェクト状況 — RandomDay のテスト終了
>
> RandomDay のテスト運用は完了し、公開テストサーバーはまもなく終了します。
>
> この運用では、RandomDay と RandomDayGuard を組み合わせ、プロファイルの反復ローテーション、通常時および中断時のサーバー再起動、復旧とロールバックの確認、拡張 Mod との統合、サーバー証拠の収集、運用者レポートの確認を実施しました。
>
> これにより、目標としていた知見を得られました。実際の専用サーバーのライフサイクル全体でローテーションする sandbox プロファイルがどう動作するか、RandomDay が対応する拡張 Mod とどう連携するか、そして RandomDayGuard が欠落や推測を事実として示すことなく、サーバーが記録した証拠をどこまで有用かつ慎重な監視に変換できるか、という知見です。
>
> **テストサーバーで使用した構成:**
>
> - RandomDay 非公開の開発ビルド `v0.41.76`
> - RandomDayGuard 非公開の開発ビルド `v0.46.130`
> - Chaotic Spawn Engine / DynamicSpawns `0.8.5 Hotfix 1`
> - Lethal Lasers `1.0 UE4SS`
> - ANTE Up `0.26`
> - Encounter Director integration — RandomDay が所有する DynamicSpawns 拡張であり、単独配布の Mod ではありません
> - UE4SS `v3.0.1 Beta #0` (Git `01e0a584`; Nexus `v3.0.1-940-g01e0a584`)
> - Abiotic Factor 専用サーバー `1.4.0.27939`
>
> 現在の公開パッケージは、引き続き RandomDay `v0.3.16-alpha` と RandomDayGuard `v0.4.12-alpha` です。
>
> 両プロジェクトの開発は、現在一時停止しています。既存のリリースとドキュメントは引き続き利用でき、また作業を続けたいと感じたときに戻る可能性があります。
>
> この構成は運用中に使用したものを記録するもので、最低バージョン要件でも、今後のゲーム、loader、Mod バージョンとの互換性を保証するものでもありません。正式に記録された最後のサイクルでは Abiotic Factor `1.4.0.27939` を使用しました。

**v0.3.16-alpha**

RandomDay は次回の Abiotic Factor 起動用に完全な `SandboxSettings.ini` を
準備します。現在のセッションが読み込み済みのルールは変更せず、使用中の
プロファイルと準備済みプロファイルを分けて管理します。

## インストールと確認

[インストールガイド](%E3%82%A4%E3%83%B3%E3%82%B9%E3%83%88%E3%83%BC%E3%83%AB.md)に従ってください。正しい場所は
`ue4ss/Mods/RandomDay` で、`mods.txt` には `RandomDay : 1` が必要です。
通常、最初の起動で準備し、その後の起動で準備済みプロファイルを有効にします。

`runtime/current/randomday_status.json`、`runtime/rotation_state.txt`、
`web_export/today.json` を確認します。3 つのファイルで使用中と準備済みの
識別情報が一致している必要があります。

## 体験を選ぶ

モード、ファミリー、開始日、進行方式は
`RandomDay/Scripts/ax_config/server.lua` で設定します。[開始手順](%E3%81%93%E3%81%93%E3%81%8B%E3%82%89%E9%96%8B%E5%A7%8B.md)、
[プロファイル選択](%E3%83%97%E3%83%AD%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%AE%E9%81%B8%E6%8A%9E.md)、[設定](%E6%A7%8B%E6%88%90.md)、
[運用](%E6%93%8D%E4%BD%9C.md)を参照してください。

`HardcoreMode=False`、`AllowIronMode=False`、`StructuralSupportLimit=0`、
`BridgeSupports=0` はこのリリースの初期値であり、ゲームの固定ルールではありません。
[高度な設定](%E6%A7%8B%E6%88%90.md#customize-the-shipped-profile-defaults)に永続的な変更手順があります。

コマンド、パス、キー、状態値は実ファイルと一致させるため英語のままです。

## アルファ版と維持される設定

これはアルファ版です。文書化された導入、ローテーション、復旧手順はテスト済みですが、互換性と使いやすさは引き続き改善中です。

`RandomDay/Scripts/ax_config/server.lua` の `sandbox.profile_overrides` は、4つの値をすべてのファミリーと日で維持します。サーバーを停止し、一度編集してから再起動してください。その後のローテーションや起動でも同じ値が使われます。`SandboxSettings.ini` だけを変更しても一時的です。

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

以下の任意modは各作者が提供する別ダウンロードです。RandomDayは再配布も機能変更も行わず、有効なアダプターは既存の対応設定だけを調整します。作者とメンテナーの皆様に感謝します。
