# パッケージ化されたソース リファレンス

> **正規の英語ソース:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


リリース ZIP には、以下の 51 個のパスが正確に含まれています。ビルダーは、パスの欠落、追加のパッケージ形式のソース、ケースの衝突、シンボリックリンク、または文字通りの許可リスト外のメンバーを拒否します。ランタイム出力、テスト、リポジトリ ドキュメント、サードパーティ MOD はパッケージ メンバーではありません。

マシンチェック可能なコンパニオンは [`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json)。入力、出力、副作用、公開設定、表示状態、障害モード、編集可能性、正規ドキュメントを含む同じパスが記録されます。

出荷されたすべての Lua 行には、1 つの安定した`module-*`アンカーがあります。正規のソース ヘッダーとマシン レコード内の同一のリンクにより、所有権、契約、副作用、障害、回復が直接追跡可能になります。
