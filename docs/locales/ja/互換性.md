<a id="compatibility"></a>
# 互換性

> **正規の英語ソース:** [COMPATIBILITY.md](../../COMPATIBILITY.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


<a id="supported-installations"></a>
## サポートされているインストール

RandomDay は、UE4SS Lua MOD をロードできる Abiotic Factor インストール用に構築されています。

| 環境 | サポート | パッケージ |
| --- | --- | --- |
| Windows 専用サーバー | サポートされています | 専用サーバー ZIP |
| Windows シングルプレイヤーまたは LAN ホスト | サポートされている手動コピー ワークフロー | Singleplayer/LAN ZIP |
| Wine または Proton を使用した Linux サーバー | リリーステストされていません | Windows 専用パッケージは経験豊富なオペレーターによって評価される場合がありますが、互換性は保証されません。 |
| Xbox およびPlayStation | サポートされていません | これらのプラットフォームは、このリリースで必要なファイル アクセスと UE4SS Lua 読み込みパスを提供しません。 |

RandomDay は 2 つのパッケージを組み合わせません。時折プレイするためにのみ起動される専用サーバーは、依然として専用サーバーを使用し、 ZIP 設定で一時的な動作を選択します。

<a id="abiotic-factor-updates"></a>
## Abiotic Factor の更新

ゲームの更新後、サーバーを停止した状態から開始し、ワールド、`SandboxSettings.ini` と RandomDay 状態。 UE4SS ロードを確認し、RandomDay サイクルを 1 つ完了し、通常の回転を再開する前に、アクティブなプロファイルと準備されたプロファイルの両方を確認します。

<a id="companion-mods"></a>
## コンパニオン MOD

RandomDay 個別にインストールされた MOD は、その完全な設定レイアウトがサポートされているアダプターと一致する場合にのみ変更されます。バージョン番号だけでは十分ではありません。

| 統合 | 確認された現在のバージョン | RandomDayサポート境界 |
| --- | --- | --- |
| カオス スポーン エンジン / DynamicSpawns | `0.8.5`;メイン ファイル`0.8.5-Hotfix1` | サポートされている`SharedData.lua` レイアウトは、アダプター リファレンスに記載されているスポーン、クールダウン、人口、ポータル、違反、ボス、RandomDayエンカウント設定をカバーします。 |
| リーサル レーザー | `1.0-UE4SS` | サポートされている`Scripts/main.lua`レイアウトは、認識されたエミッター、環境エミッター、リフレクター、およびプリズムをカバーします。  |
| ANTE 上 | `1`、2026 年 7 月 19 日更新 | 現在のパブリック レイアウトはアダプター フィクスチャを完了していません。 RandomDay は、レイアウトが検証されるまで、一致しないファイルを変更せずにスキップします。 |

コンパニオン MOD が存在しない、無効になっている、または認識されていない場合は、変更されないままになります。 [サポートされているオプションの MOD](%E3%82%B5%E3%83%9D%E3%83%BC%E3%83%88%E3%81%95%E3%82%8C%E3%81%A6%E3%81%84%E3%82%8B%E3%82%A2%E3%83%80%E3%83%97%E3%82%BF.md) 正確な設定、構成制御、バックアップ動作、リカバリ手順については。

<a id="what-compatibility-validation-proves"></a>
## 互換性検証で証明されること

リポジトリの検証では、出荷されたパッケージのレイアウト、構成範囲、認識されたアダプタ フィールド、バックアップと復元の動作、未知のレイアウトの安全な拒否を証明できます。将来の非生物的要素をすべて証明できるわけではありません。UE4SS、またはコンパニオン MOD のバージョン。リリース ノートでは、正常なロードによる互換性を想定するのではなく、テストされたバージョンに名前を付けます。
