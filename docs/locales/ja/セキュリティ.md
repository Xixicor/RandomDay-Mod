<a id="security-policy"></a>
# セキュリティ ポリシー

> **正規の英語ソース:** [SECURITY.md](../../../SECURITY.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDay サーバー構成ファイルを書き込み、オプションの MOD 構成ファイルにパッチを適用できます。変更は運用上重要なものとして扱います。

<a id="do-not-report-as-security-issues"></a>
## セキュリティ問題として報告しないでください。

- 通常のゲームプレイ バランスの変更。
- 次回の再起動時にプロファイルのローテーションが予想されます。

<a id="report-privately"></a>
## 非公開で報告してください。

- パス トラバーサルのリスク。
- 安全でないファイル書き込み動作。
- 意図したserver/modパス以外のファイルを上書きする可能性。
- 悪意のあるコマンドの実行。

パブリック セキュリティ チャネルが存在するまで、リポジトリ所有者に非公開で報告してください。
