# 実行時の状態と出力スキーマの解釈

> **正規の英語ソース:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


これは、正規のフィールド完全スキーマ ガイドです。これは、各フィールド、状態、空の値、およびマシンの結果が何を意味するかを答えます。 [ランタイム ファイル マップ](%E3%83%A9%E3%83%B3%E3%82%BF%E3%82%A4%E3%83%A0_%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB.md)プロデューサー、パス、書き込みタイミング、保持、トランザクション サイドカー、リカバリ場所。

このガイドのすべてのパスは、特に明記されていない限り、インストールされている `RandomDay/` フォルダー。ただし、行で構成済みのサンドボックスまたはオプションのアダプター ターゲットを明示的に指定している場合を除きます。ランタイム出力はインストール後に生成され、どちらのリリースのメンバーでもありません。 ZIP.

<a id="choose-the-authoritative-view"></a>
## 信頼できるビューを選択してください

| 必要 | 信頼できるソース |
|---|---|
| 現在のプロセスによってロードされたルール | RandomDayのマーカー`SandboxSettings.ini`起動時に読み取られます |
| 準備されたキューのブックキーピング | `runtime/rotation_state.txt`、スキーマ `1` |
| 詳細なローカル ステータス | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| パブリックな機械可読ステータス | `web_export/today.json`、スキーマ `2` と `randomday_public_status_v2` |
| 人間が判読可能なステータス | `web_export/today.html`。同じパブリック ステータス遷移 |
| 翻訳語彙 | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| 正確な制限付きプレーヤー通知 | `runtime/current/player_message_preview.txt` |

HTML ビュー、プレビュー、翻訳された概要は派生ビューです。これらは、サンドボックス マーカー、トランザクション結果、または生のプロファイル値をオーバーライドしません。最後に正常に動作したファイル、操作バックアップ、サイドカー、ミラー、アダプター ターゲット、および `UE4SS.log` 内 [ランタイム ファイル](%E3%83%A9%E3%83%B3%E3%82%BF%E3%82%A4%E3%83%A0_%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB.md).

<a id="rotation-state-schema"></a>
## ローテーション状態スキーマ

`runtime/rotation_state.txt` はスキーマ `1` を使用し、`key=value` ペアが 1 つ含まれています) 1 行あたり:

| フィールド | 意味 |
|---|---|
| `schema_version` | 必ず`1`. |
| `mod_version` | パッケージ ID を読み取ります `.randomday_version`. |
| `rotation_id` | 適格なファミリ セットを介した現在のパスの識別子。 |
| `mode` | `selected_run`, `non_repeating_random_run`、または `rotation_run`. |
| `available_families` | 設定フィルタリング後のカンマ区切りの適格なファミリ ID。 |
| `remaining_families` | 現在の非繰り返しパスでまだ選択されていない適格なファミリ。 |
| `completed_families` | 現在のパスで完全に永続化された 17 位の順序が完了したファミリ。 |
| `active_family`, `active_day` | 選択が確定されたときに記録されたアクティブ マーカー情報。サンドボックス マーカーは次回の起動時に有効になります。 |
| `prepared_family`, `prepared_day` | 次回の再起動まで保持されるプロファイル。 |
| `active_run_id` | 準備された選択に関連付けられたファミリー実行の識別子。 |
| `last_status` | このファイルを生成したカレンダーの選択状態。 |
| `session_mode` | 解決された永続的な専用、一時的な専用、singleplayer/LANライフサイクル。 |
| `start_day_mode` | 新しい実行の設定済みまたは 1 回限りのランダムな開始の選択。 |
| `day_progression_mode` | ラップされたシーケンシャルまたは非反復ランダム進行。 |
| `day_order` | 準備される正確な順序でのカンマ区切りの永続的な日 ID。 |
| `day_position` | 準備された日の`day_order`. |
| `updated_at` | 演算子比較のローカル書き込み時間。 |

状態の書き込みは、スキーマ マーカー、準備されたファミリ、および準備された日が正しく読み戻された場合にのみ受け入れられます。現在のファイルが読み取れない場合は、`rotation_state.last_good.txt` にフォールバックする可能性があります。選択したサンドボックス マーカーによって、ゲームが現在のプロセスにロードした内容が決まります。

<a id="runtime-status-json"></a>
## 実行時のステータス JSON

`runtime/current/randomday_status.json` は `status_schema=randomday_runtime_status_v2` を使用します。その主なフィールド グループは次のとおりです。

| グループ | フィールドと解釈 |
|---|---|
| アイデンティティ | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| 選択 | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| アクティブ | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| 準備済み | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| 人間による要約 | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| 書き込み証明 | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| アダプタ証明 | `adapter_status`, `adapter_results`;各アダプター レコードには、互換性の証拠、transaction/rollback状態、変更されたファイル数、および編集されたターゲット参照が含まれています。 |
| 境界 | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| 診断 | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

不明なアクティブな値は、現在のサンドボックスに読み取り可能なデータが含まれていないことを意味しますRandomDay マーカー。これらを準備された値に置き換えてはなりません。外部のアダプター パス `runtime/`外部のアダプター パスはベース名参照に還元され、検出された絶対パスは診断文字列によって編集されます。

<a id="public-status-json"></a>
## 公開ステータス JSON

`web_export/today.json` は `schema_version=2` と `status_schema=randomday_public_status_v2`。オペレーターが必要とする ID、active/prepared、選択、トランザクション、アダプター、および再起動境界ファクトを繰り返します。また、

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` と `prepared_day_position`;
- `family_selection_mode`、レガシー`family_locked_until_day_17` と `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`、およびそれらの数、
- 準備されたエンカウント プロファイル、ティア、テーマ、および混合エンカウントのチャンス、
- ワールド スコープの有効化、オープンワールド設定、未知の世界のポリシー、および設定された除外ワールド パターンの数のみも含まれます。
- 準備されたメッセージと結合されたメッセージのプレビュー。
- `selected_at`, `sandbox_target`, `manual_copy_required`、準備されたハッシュ。

`profile_status` は、`prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence`、または `write_failed_or_rollback`. `prepared_ready=true` の 1 つですが、まだアクティブであることを意味しません。後の起動マーカーが必要です。

<a id="dictionary-and-translation-output"></a>
## 辞書と翻訳の出力

`runtime/current/randomday_dictionary.json` は `schema=randomday_runtime_dictionary_v2`および辞書のバージョンを識別します`randomday_dictionary_v2`。パッケージ モード、選択状態、圧力ドメイン、設定ラベル、生の値、および平易な言語の意味について説明します。不明な値は、信頼できる説明に変換されず、明示的なままになります。

`player_message_preview.txt`, `today.json`, `today.html`、ゲーム内通知は、同じ翻訳モジュールから派生したビューです。基礎となるプロファイルと生の`SandboxSettings.ini`値は、信頼できる情報源のままです。

<a id="failure-and-recovery-rules"></a>
## 失敗と回復のルール

1. 失敗した保留中の書き込みまたは検証が本番ターゲットになることはありません。
2. 失敗したプロモーションまたは本番のリードバックは、保持されていたオリジナルの復元をトリガーします。オペレーション バックアップは、リストアが失敗した場合のフォールバックです。
3. 保持されているロールバック ファイルまたは`rollback_failed`ステータスは、ゲームまたはサーバーが停止している間に手動で確認する必要があります。
4. 成功したサンドボックス書き込みと失敗した回転状態コミットはデグレードされており、準備ができていません。アダプタと準備されたプロファイルのメッセージングは​​スキップされます。
5. エクスポートが失敗してもサンドボックスの結果は変わりませんが、コンビニエンスプルーフソースが削除されます。トランザクション ログ、状態、ファイルのリードバックを使用します。
6. ランタイム出力はローカル操作データです。リリースには追加しないでください。 ZIPまたは、個別のプライバシー審査なしで例として公開することもできます。
