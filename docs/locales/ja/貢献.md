# 貢献

> **正規の英語ソース:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDay は、管理されたプロジェクトとして維持されます。

パブリック プル リクエスト、一方的なコードの送信、自動リライト、生成されたコードのクリーンアップの送信、投機的な機能パッチは、リポジトリ所有者によって明示的に要求されない限り受け入れられません。

<a id="accepted-contact"></a>
## 受け入れられます連絡先

バグ レポート、互換性に関するメモ、またはサーバー管理の観察については、プロジェクト ドキュメントに記載されている連絡先チャネルを使用してください。

<a id="not-accepted"></a>
## 受け付けられません

デフォルトでは、以下は受け付けられません:

- 一方的なプル リクエスト、
- 生成されたコード書き換え、
- 広範なリファクタリング、
- スタイルのみの書式変更、
- テストされていないゲームプレイ ロジックの変更、
- バンドルされたサードパーティ MOD ファイル。
- 再配布されたサードパーティのソース コード。
- Abiotic Factor との正式な提携を示唆する変更、UE4SS、Nexus Mods、またはサードパーティの MOD 作成者。

<a id="controlled-development"></a>
## 管理された開発

リポジトリの所有者は、必要に応じて、特定のレビュー、テスト、またはドキュメントのヘルプを要求できます。リクエストされていない送信は審査なしで閉じられる場合があります。
