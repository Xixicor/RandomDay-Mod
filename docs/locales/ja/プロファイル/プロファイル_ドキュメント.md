# RandomDay プロファイル ドキュメント

> **正規の英語ソース:** [README.md](../../../profiles/README.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


バージョン: `v0.3.16-alpha`

- 家族: **17**
- プロファイル: **289**
- SandboxSettings 辞書エントリ: **46**

[プロファイル選択ガイド](../%E3%83%97%E3%83%AD%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%E3%81%AE%E9%81%B8%E6%8A%9E.md)でゲームプレイの意図に応じてファミリーを選択し、この生成されたインデックスを使用して正確な値を求めます。

これらのファイルは、ランタイム Lua ソースとその dictionary/translation コントラクトから生成されます。これらは、出荷時の `sandbox.profile_overrides` デフォルトを示しています。 1 つのサーバーの設定値は異なる場合があります:

- `profiles.generated.json`: 機械可読プロファイル、生の値、辞書、翻訳。
- `FULL_PROFILE_REFERENCE.md`: 完全なインデックスと解釈ルール。
- `SANDBOX_SETTINGS_KEYS.md`: 完全な 46 キー辞書。
- `families/*.md`: 詳細な 17 日間のファミリー参照。

次の方法で再生成: `python -B tools/generate_profile_docs.py`次の方法でドリフトをチェックします。`python -B tools/generate_profile_docs.py --check`
