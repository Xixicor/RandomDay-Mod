# Төлөв байдал ба алдааны лавлагаа

> **Каноник англи эх сурвалж:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Яг `status`, `transaction_status`, `rollback_status` болон `error` утгууд. Самбар эсвэл консол дээрх ижил төстэй үг хэллэг нь эдгээр талбарыг орлохгүй.

Энэ хэсэг нь хайлтын бүрэн лавлагаа юм. Дээрх шийдвэрийн мод нь холбогдох ангиллыг сонгоно; Эдгээр хүснэгтүүд нь яг машины утгууд болон аюулгүй операторын хариуг хадгалдаг.

<a id="normal-or-informational-states"></a>
## Хэвийн буюу мэдээллийн төлөв

| Төлөв | Утга | Операторын хариулт |
|---|---|---|
| `prepared_for_next_reboot` | Дараагийн ачаалахад зориулж баталгаажуулсан профайл бичигдсэн. | Үйлдэл байхгүй; одоогийн сесс өөрчлөгдөөгүй. |
| `next_reboot_already_prepared` | Төлөвлөсөн дараагийн профайл зорилтот түвшинд аль хэдийн таарч байна. | Үйлдэл байхгүй; дахин эргүүлэхийг бүү албад. |
| `already_current` / `unchanged` | Зорилтод төлөвлөсөн байт аль хэдийн агуулж байна. | Үйлдэл алга. |
| `applied` | Бичих болон үйлдвэрлэлийг дахин давлаа. | Баталгаажуулах active/prepared ялгаа. |
| `bootstrap_prepare_first_family_start_day` | Өмнө нь эргүүлэх төлөв байхгүй байсан тул тохируулсан эхний өдрийг бэлтгэсэн. | Анхны хэрэглээнд хүлээгдэж буй. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | Хадгалагдсан төлөвийг сэргээж, ижил бэлтгэсэн профайлыг дахин бичсэн. | Сэргээгдсэн өдрийг баталгаажуулах; ямар ч шинэ санамсаргүй сонголт хийгдээгүй. |
| `supervision_reconfirm_prepared_profile_no_advance` | Хяналтын үнэмлэх нь одоо байгаа бэлтгэлийг баталгаажуулсан. | Хүлээгдэж буй; дараалал хоёр удаа урагшлаагүй. |
| `external_mods_disabled` | Заавал тохируулагчийн боловсруулалтыг идэвхгүй болгосон. | Адаптеруудыг зориулаагүй л бол ямар ч үйлдэл хийхгүй. |
| `external_mods_processed` | Бүх идэвхжүүлсэн адаптерийн төлөвлөгөөнүүд терминалын үр дүнд хүрсэн. | Адаптерийн мөр бүрийг шалгана уу. |

<a id="startup-configuration-errors"></a>
## Эхлүүлэх тохиргооны алдаа

Эдгээр мессежүүд RandomDay профайл бичдэг. Нэрлэсэн тохиргоо эсвэл багц тэмдэглэгээг засах; баталгаажуулалтын салбарыг тойрч болохгүй.

| Алдааны текст | Утга | Аюулгүй хариулт |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` байхгүй, алдаатай эсвэл буруу багцаас авсан байна. | Нэг бүрэн багцыг цэвэр үе шаттай хавтсанд дахин суулгаж, төлөвлөсөн горимын тэмдэглэгээг хадгална уу. |
| `invalid experience.mode` | `experience.mode` нь баримтжуулсан утгуудын нэг биш юм. | Ашиглах `auto`, `persistent_dedicated`, `temporary_dedicated`, эсвэл `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | Гараар хуулбарлах багцыг зориулалтын сервер болгон тохируулсан. | Сэргээх `auto` эсвэл `singleplayer_lan`; автоматаар гадаад ертөнц рүү бүү чиглүүл. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | Гараар хуулах ажлын урсгалд зориулж тусгай багцыг тохируулсан. | Ашиглах `auto`, `persistent_dedicated`, эсвэл `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | Эхний өдрийн сонгогч буруу байна. | Яг ашиглах `configured` эсвэл `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | Өдрийн захиалга сонгогч хүчингүй байна. | Яг ашиглах `sequential` эсвэл `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | Тохируулсан эхлэх өдөр нь бутархай буюу мөчлөгийн гадуур байна. | 1-ээс `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | Нөөцлөх эсвэл хамгийн сүүлд сэргээх ажиллагааг идэвхгүй болгосон. | Аюулгүйн түгжээг хоёуланг нь сэргээх; RandomDay аюултай бичихээс санаатайгаар татгалздаг. |
| `external adapter transaction safety locks must remain true` | Адаптерийн засвар эсвэл нөөц хамгаалалтыг идэвхгүй болгосон. | Адаптерийн аюулгүй байдлын түгжээг хоёуланг нь сэргээх эсвэл адаптеруудыг бүлэг болгон идэвхгүй болгох. |
| `paths.world_name must be one folder name` | Тохируулсан дэлхийн нэр нь тусгаарлагч эсвэл аюултай тэмдэгт агуулж байна. | Үсэг, тоо, зай, доогуур зураас, зураас ашиглан зөвхөн фолдерын нэрийг оруулна уу. |
| `required runtime directory unavailable` | Шаардлагатай мод-локал гаралтын лавлахыг үүсгэж, баталгаажуулж чадсангүй. | Зөвхөн нэрлэгдсэнийг шалгана уу RandomDay лавлах ба түүний бичих зөвшөөрөл. |

<a id="profile-wide-configuration-errors"></a>
## Профайлын тохиргооны алдаа

Эдгээр алдаа нь хамгаалагдсан хязгаарлагдмал орчинд бичихээс өмнө профайл үүсгэхийг зогсооно.

| Алдааны текст | Утга | Аюулгүй хариулт |
|---|---|---|
| `sandbox.profile_overrides must be a table` | Дөрвөн профайлын сонголтыг өөр Lua төрлөөр сольсон. | Баримтжуулсан хүснэгтийг `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | Хүснэгт нь дэмжигдсэн дөрвөн товчлуурын нэг биш тохиргоог агуулж байна. | Нэрлэсэн түлхүүрийг устгаад family/profile эх сурвалж. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` эсвэл `AllowIronMode` нь `true` эсвэл `false`. | Ишлэлгүй Луа логикийг ашиглана уу. |
| `sandbox.profile_overrides.<key> must be integer` | Дэмжих утга нь бүхэл тоо биш юм. | Бүтэн тоо ашиглана уу. |
| `sandbox.profile_overrides.<key> outside supported range` | Дэмжлэгийн утга нь `0..1000`. | `0` `1000`. |

<a id="rollback-and-intermediate-states"></a>
## Буцах болон завсрын төлөвүүд

| Утга | Утга | Аюулгүй хариулт |
|---|---|---|
| `not_started` / `pending` | Гүйлгээ эсвэл адаптерийн төлөвлөгөө терминалын үр дүнд хүрээгүй байна. | Зөвхөн одоогийн хязгаарлагдмал эхлүүлэх зөвшөөрлийг хүлээнэ үү; Тогтвортой байдал нь шалгалтыг шаарддаг. |
| `not_needed` | Буцах шаардлагагүй. | Үйлдэл алга. |
| `original_held` | Анхны зорилтыг дэвшүүлэхээс өмнө сэргээх байрлал руу шилжүүлсэн. | Гүйлгээ дуусаагүй байхад сэргээх файлыг устгаж болохгүй. |
| `retained_after_success` | Шинэ зорилтыг баталгаажуулсан боловч цэвэрлэх боломжгүй эсвэл зориудаар хадгалагдсан тул сэргээх өгөгдөл хэвээр байна. | Нэрлэсэн сэргээх файлыг устгахаасаа өмнө үйлдвэрлэлийн байтыг шалгана уу. |
| `discarded_after_success` | Солилтыг баталгаажуулж, түр зуур буцаах өгөгдлийг устгасан. | Үйлдэл алга. |
| `rollback_failed` | Сэргээх оролдлогыг баталгаажуулж чадсангүй. | Серверийг зогсоож, хамгийн сүүлд баталгаажуулсан үйлдлийн нөөцлөлтийг ашиглана уу. |
| `skipped_state_persistence_failed` | Sandbox байтуудыг бэлтгэсэн боловч эргүүлэх төлөв хэвээр үлдсэнгүй, тиймээс адаптерууд болон бэлтгэгдсэн тоглогчийн мессежийг алгассан. | Ажиллах үеийн төлөвийн санах ойг засах; дарааллыг гараар дахин эргүүлж эсвэл урагшлуулж болохгүй. |
| `failed` | Тогтоосон мөр нь тодорхой шалтгаан нь `error` эсвэл гүйлгээний талбарууд. | Эхний тусгай кодыг дагах; `failed` дангаараа. |

<a id="transaction-failures"></a>
## Гүйлгээний алдаа

| Төлөв | Утга | Аюулгүй хариулт |
|---|---|---|
| `invalid_input` | Орлуулах хүсэлт нь буруу текст эсвэл хүчинтэй зорилтгүй байна. | Зөв тохиргоо; өөрчлөхгүйгээр дахин оролдох хэрэггүй. |
| `stale_pending_cleanup_failed` | Хуучин хүлээгдэж буй файлыг устгаж чадсангүй. | Гараар цэвэрлэхийн өмнө хүлээгдэж буй файлыг зогсоож, хадгална уу. |
| `stale_rollback_requires_review` | Сэргээх өгөгдөл нь одоогийн зорилтот хажууд байгаа бөгөөд үүнийг аюулгүйгээр устгах боломжгүй. | Аль нэгийг нь сонгохын өмнө зорилтот болон буцаах байтыг харьцуулна уу. |
| `interrupted_transaction_restore_failed` | Тасалдсан орлуулсны дараа сэргээх нь зорилтыг сэргээж чадсангүй. | Серверийг зогсоож, баталгаажуулсан нөөцлөлтийг сэргээнэ үү. |
| `interrupted_transaction_cleanup_failed` | Зорилтотыг сэргээсэн боловч хуучирсан гүйлгээний өгөгдлийг арилгах боломжгүй. | Зорилтот байтыг баталгаажуулаад, зөвхөн нэрлэгдсэн хуучирсан хажуугийн тэрэгийг устгана уу. |
| `pending_write_failed` | Нэр дэвшигчийг бичиж чадсангүй. | Нарийхан зорилтот лавлах болон сул зайг шалгана уу. |
| `pending_readback_failed` / `pending_readback_mismatch` | Нэр дэвшигчийн байтыг унших боломжгүй эсвэл бичсэний дараа зөрүүтэй байна. | Хүлээгдэж буй файлыг сурталчилж болохгүй. |
| `pending_validation_failed` | Нэр дэвшигч амжилтгүй болсон schema/profile сурталчилгааны өмнөх баталгаажуулалт. | Мэдэгдэж буй түлхүүр эсвэл дүрмийг засах; Баталгаажуулалтыг бүү тойр. |
| `operation_backup_failed` / `backup_failed` | Баталгаажсан урьдчилан бичих нөөцийг үүсгээгүй. | Зогс; ямар ч зорилтот орлуулалтад итгэх ёсгүй. |
| `original_preserved_move_failed` | Анхны зорилтыг сэргээх байрлал руу зөөж чадсангүй. | Бүх гүйлгээний файлыг хадгалж, гараар сэргээнэ үү. |
| `promotion_failed` | Хүлээгдэж буй нэр дэвшигч үйлдвэрлэлийн зорилт болж чадсангүй. | Дахин оролдохын өмнө эх хувь нь сэргээгдсэн эсэхийг шалгана уу. |
| `production_validation_failed` | Дэмжүүлсэн байт үйлдвэрлэл амжилтгүй болсон readback/validation. | Баталгаажсан нөөцлөлтийг сэргээж, зорилтот бичигчийг шалгана уу. |
| `replacement_committed_recovery_cleanup_failed` | Солилт хүчинтэй боловч буцаах өгөгдлийг устгаж чадсангүй. | Зорилтод тохирсон байдлаар хандах; зөвхөн баталгаажуулсан хуучирсан сэргээх өгөгдлийг устгана уу. |
| `rollback_failed` | Автоматаар сэргээх ажиллагааг баталгаажуулаагүй. | Серверийг зогсоож, гараар сэргээх аргыг ашиглана уу. |

<a id="translation-and-message-validation-errors"></a>
## Орчуулга болон мессежийн баталгаажуулалтын алдаа

Эдгээр нь толь бичиг эсвэл үзүүлэнгийн гэрээний алдаа юм. Тэдгээрийг гаргахаас өмнө баталгаажуулсан бөгөөд мөн хязгаарлагдмал ажиллах хугацааны төлөвийн анхааруулга хэлбэрээр гарч ирж болно.

| Алдааны текст | Утга | Аюулгүй хариулт |
|---|---|---|
| `dictionary coverage mismatch` | Профайлын толь бичиг баримтжуулсан тохиргоо бүрийг тайлбарладаггүй. | Дутуу толь бичгийн оруулгыг нэмээд профайлыг дахин ажиллуулна уу generation/validation. |
| `missing profile setting` | Сонгосон профайлд dictionary/schema. | Профайл гэр бүлийн эх сурвалжийг засах; ажиллах цагийн өгөгдмөлийг бүү зохион бүтээ. |
| `empty explanation` | Тохиргоо байгаа боловч operator/player тайлбар. | Гарахаасаа өмнө энгийн хэлээр тайлбар нэмнэ үү. |
| `join line too wide` | Үйлдвэрлэсэн нэгдэх шугам нь 42 тэмдэгтийн эх үүсвэрийн хязгаараас хэтэрсэн байна. | Толь бичгийн хэллэгийг товчлох; үйлчлүүлэгчийн боодол дээр бүү найд. |
| `join message too tall` | Үйлдвэрлэсэн нэгтгэлийн хураангуй дөрвөн мөрөөс хэтэрсэн байна. | Мессежийн агуулгыг багасгах эсвэл дахин эрэмбэлэх. |
