# Ажиллах үеийн төлөв болон гаралтын схемүүдийг тайлбарлах

> **Каноник англи эх сурвалж:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ бол каноник талбарын бүрэн схемийн гарын авлага юм. Энэ нь талбар, төлөв, хоосон утга, машины үр дүн ямар утгатай болохыг хариулдаг. [ажиллах үеийн файлын зураг](%D0%90%D0%96%D0%98%D0%9B%D0%9B%D0%90%D0%A5_%D2%AE%D0%95%D0%98%D0%99%D0%9D_%D0%A4%D0%90%D0%99%D0%9B%D0%A3%D0%A3%D0%94.md) үйлдвэрлэгчид, замууд, бичих хугацаа, хадгалалт, гүйлгээний хажуугийн тэрэг болон сэргээх байршилд зориулагдсан.

Энэ гарын авлагад байгаа бүх зам нь суулгасантай холбоотой `RandomDay/` фолдер. Ажиллах үеийн гаралт нь суулгасны дараа үүсдэг ба аль ч хувилбарын гишүүн биш ZIP.

<a id="choose-the-authoritative-view"></a>
## Эрх бүхий харагдацыг сонгоно уу

| Хэрэгтэй | Эрх бүхий эх сурвалж |
|---|---|
| Одоогийн процессоор ачаалагдсан дүрмүүд | RandomDayдахь тэмдэглэгээ`SandboxSettings.ini` эхлүүлэх үед уншина уу |
| Бэлтгэсэн дарааллын бүртгэл | `runtime/rotation_state.txt`, схем `1` |
| Нутгийн дэлгэрэнгүй төлөв | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| Олон нийтийн машин унших боломжтой байдал | `web_export/today.json`, схем `2` болон `randomday_public_status_v2` |
| Хүн унших боломжтой байдал | `web_export/today.html`, ижил нийтийн статусын шилжилтээс үүсэлтэй |
| Орчуулгын толь бичиг | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| Тоглогчийн тодорхой хязгаарлалттай мэдэгдэл | `runtime/current/player_message_preview.txt` |

The HTML харах, урьдчилан харах, орчуулсан хураангуй нь үүсмэл харагдац юм. Тэд хамгаалагдсан хязгаарлагдмал орчны тэмдэглэгээ, гүйлгээний үр дүн эсвэл түүхий профайлын утгыг дардаггүй. Хамгийн сүүлд мэддэг сайн файлууд, үйлдлийн нөөцлөлтүүд, хажуугийн тэрэг, толь, адаптерийн зорилтууд болон `UE4SS.log` [Ажиллах үеийн файлууд](%D0%90%D0%96%D0%98%D0%9B%D0%9B%D0%90%D0%A5_%D2%AE%D0%95%D0%98%D0%99%D0%9D_%D0%A4%D0%90%D0%99%D0%9B%D0%A3%D0%A3%D0%94.md).

<a id="rotation-state-schema"></a>
## Эргүүлэх төлөвийн схем

`runtime/rotation_state.txt` схемийг ашигладаг `1` бөгөөд нэгийг агуулна `key=value` мөр бүрт хос:

| Талбар | Утга |
|---|---|
| `schema_version` | Заавал `1`. |
| `mod_version` | Багцын таниулбарыг `.randomday_version`. |
| `rotation_id` | Одоогийн эрх бүхий гэр бүлийн багцыг нэвтрүүлэх таниулбар. |
| `mode` | `selected_run`, `non_repeating_random_run`, эсвэл `rotation_run`. |
| `available_families` | Тохиргоог шүүсний дараа таслалаар тусгаарласан эрх бүхий гэр бүлийн ID. |
| `remaining_families` | Одоогийн давтагдахгүй тасалбараар сонгогдоогүй эрх бүхий гэр бүлүүд. |
| `completed_families` | Одоогийн тасалбараар 17-р албан тушаалын бүрэн захиалга дууссан гэр бүлүүд. |
| `active_family`, `active_day` | Сонголт хийх үед тэмдэглэсэн идэвхтэй тэмдэглэгээний мэдээлэл. Хамгаалагдсан хязгаарлагдмал орчны тэмдэглэгээ нь дараагийн ачаалах үед эрх мэдэлтэй байна. |
| `prepared_family`, `prepared_day` | Дараагийн дахин эхлүүлэхэд зориулагдсан профайл. |
| `active_run_id` | Бэлтгэсэн сонголттой холбоотой гэр бүлийн танигч. |
| `last_status` | Энэ файлыг үүсгэсэн хуанлийн сонголт. |
| `session_mode` | Тогтвортой зориулалтын, түр зуурын зориулалтын эсвэл singleplayer/LAN амьдралын мөчлөг. |
| `start_day_mode` | Шинэ ажиллуулахын тулд тохируулсан эсвэл нэг удаагийн санамсаргүй эхлүүлэх сонголт. |
| `day_progression_mode` | Дараалсан эсвэл давтагдахгүй санамсаргүй прогресс. |
| `day_order` | Таслалаар тусгаарлагдсан тогтмол өдрийн ID-г яг дарааллаар нь бэлтгэнэ. |
| `day_position` | Бэлдсэн өдрийн байрлал `day_order`. |
| `updated_at` | Операторын харьцуулалт хийх орон нутгийн бичих хугацаа. |

Төрийн бичвэрийг зөвхөн схемийн тэмдэглэгээ, бэлдсэн гэр бүл, бэлтгэсэн өдөр зөв уншсан тохиолдолд л хүлээн авна. Унших боломжгүй одоогийн файл `rotation_state.last_good.txt`; Сонгогдсон хамгаалагдсан хязгаарлагдмал орчны тэмдэглэгээ нь одоогийн процесст ямар тоглоом ачаалагдсаныг тодорхойлдог хэвээр байна.

<a id="runtime-status-json"></a>
## Ажиллах үеийн төлөв JSON

`runtime/current/randomday_status.json` нь `status_schema=randomday_runtime_status_v2`. Түүний үндсэн талбарын бүлгүүд нь:

| Бүлэг | Талбар ба тайлбар |
|---|---|
| Identity | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| Сонголт | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| Идэвхтэй | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| Бэлтгэсэн | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| Хүний дүгнэлт | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| Баталгаа бичих | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| Адаптерийн баталгаа | `adapter_status`, `adapter_results`; адаптерийн бичлэг бүр нь нийцтэй байдлын нотолгоог агуулдаг, transaction/rollback төлөв, өөрчлөгдсөн файлын тоо, засварласан зорилтот лавлагаа |
| Хил хязгаар | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| Оношлогоо | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

Үл мэдэгдэх идэвхтэй утгууд нь одоогийн хамгаалагдсан хязгаарлагдмал орчинд унших боломжтой зүйл агуулаагүй гэсэн үг юм RandomDay тэмдэглэгээ. Тэдгээрийг бэлтгэсэн утгуудаар сольж болохгүй. Гаднах адаптерийн замууд `runtime/` нь үндсэн нэрний лавлагаа болгон бууруулж, оношилгооны мөрүүд илрүүлсэн үнэмлэхүй замыг засдаг.

<a id="public-status-json"></a>
## Нийтийн байдал JSON

`web_export/today.json` нь `schema_version=2` болон `status_schema=randomday_public_status_v2`. Энэ нь таних тэмдэгийг давтдаг, active/prepared, сонголт, гүйлгээ, адаптер, операторт шаардлагатай дахин эхлүүлэх-хязгаарлалтын баримтууд. Үүнд:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` болон `prepared_day_position`;
- `family_selection_mode`, хуучин `family_locked_until_day_17` болон `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`болон тэдгээрийн тоо;
- боловсролын профайл, түвшин, сэдэв болон холимог учрал тохиолдлыг бэлтгэсэн;
- дэлхийн хамрах хүрээг идэвхжүүлэх, нээлттэй ертөнцийн тохиргоо, үл мэдэгдэх ертөнцийн бодлого, зөвхөн тохируулсан хасагдсан ертөнцийн хэв маягийн тоо;
- бэлтгэсэн мессеж болон мессежийг урьдчилан харах;
- `selected_at`, `sandbox_target`, `manual_copy_required`, бэлтгэсэн хэш.

`profile_status` нь `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence`, эсвэл `write_failed_or_rollback`. `prepared_ready=true` нь идэвхтэй гэсэн үг биш хэвээр байна; хожуу эхлүүлэх тэмдэглэгээ шаардлагатай.

<a id="dictionary-and-translation-output"></a>
## Толь бичиг болон орчуулгын гаралт

`runtime/current/randomday_dictionary.json` нь `schema=randomday_runtime_dictionary_v2` болон толь бичгийн хувилбарыг тодорхойлдог `randomday_dictionary_v2`. Энэ нь багцын горим, сонголтын төлөв, даралтын домэйн, тохиргооны шошго, түүхий утгууд, энгийн хэл дээрх утгыг тайлбарладаг. Үл мэдэгдэх утгууд нь итгэлтэй тайлбар болгон хувиргахын оронд тодорхой хэвээр байна.

`player_message_preview.txt`, `today.json`, `today.html` болон тоглоомын мэдэгдлүүд нь ижил орчуулгын модулиас авсан харагдац юм. Үндсэн профайл болон түүхий `SandboxSettings.ini` утгууд үнэний эх сурвалж хэвээр байна.

<a id="failure-and-recovery-rules"></a>
## Алдаа болон сэргээх дүрэм

1. Бүтэлгүй хүлээгдэж буй бичих эсвэл баталгаажуулалт хэзээ ч үйлдвэрлэлийн зорилт болохгүй.
2. Бүтэлгүй сурталчилгаа эсвэл үйлдвэрлэлийг дахин сэргээсэн нь хадгалагдсан эх хувийг сэргээхэд хүргэдэг; Үйл ажиллагааны нөөцлөлт нь тухайн сэргээлт амжилтгүй болсон үед нөөцлөх юм.
3. Хадгалагдсан буцаах файл эсвэл `rollback_failed` статус нь тоглоом эсвэл сервер зогссон үед гараар шалгах шаардлагатай.
4. Амжилттай хамгаалагдсан хязгаарлагдмал орчинд бичих, мөн амжилтгүй эргүүлэх төлөвийн даалгавар нь доройтсон, бэлэн биш байна; адаптерууд болон бэлтгэсэн профайл мессежийг алгассан.
5. Экспортын алдаа нь хамгаалагдсан хязгаарлагдмал орчны үр дүнг өөрчилдөггүй, гэхдээ энэ нь ая тухтай байдлыг баталгаажуулсан эх сурвалжийг устгадаг. Гүйлгээний бүртгэл, төлөв, файлыг дахин уншина уу.
6. Ажиллах үеийн гаралт нь дотоод үйлдлийн өгөгдөл юм. Тэдгээрийг хувилбарт нэмж болохгүй ZIP эсхүл нууцлалын талаар тусад нь шалгахгүйгээр жишээ болгон нийтлэх боломжтой.
