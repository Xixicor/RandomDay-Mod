# Өөрчлөлтийн бүртгэл

> **Каноник англи эх сурвалж:** [CHANGELOG.md](../../../CHANGELOG.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


<a id="v0316-alpha"></a>
## v0.3.16-alpha

- Хоёр бүрэн багц нэмсэн: нэг нь зориулалтын серверт, нөгөө нь ганц тоглогч эсвэл LAN ертөнц.
- Байнгын болон түр зуурын зориулалтын серверийн горимууд, тохируулах боломжтой эхлүүлэх профайлууд, дараалсан эсвэл давтагдахгүй санамсаргүй прогрессийг нэмсэн.
- Номын санг гэр бүл бүрт арван долоон профайлтай арван долоон профайл гэр бүл болгон өргөжүүлэв.
- Унших боломжтой нэмсэн active/prepared профайлын төлөв, авсаархан тоглогчийн мэдэгдэл, аюулгүй хамгаалагдсан хязгаарлагдмал орчинд бичих, баталгаажсан нөөцлөлт, дахин сэргээх болон буцаах.
- Дэмжигдсэн дагалдагч горимд зориулсан загвараар шалгагдсан нэмэлт тохируулагчийг нэмсэн.
- Нийтийн серверийн тохиргоонд Хардкор горим, Төмөр горим, бүтцийн дэмжлэг болон гүүрний дэмжлэгт зориулсан байнгын профайлын өргөн хяналтыг нэмсэн.
- Англи хэлний иж бүрэн номын сан болон локалжуулсан 27 нэвтрэх хуудас нэмсэн.
- Хувилбарын багцуудыг цэвэр, тодорхой, тохиолдлын аюулгүй байдлаар баталгаажуулсан UE4SS хувийн тохиргоо эсвэл ажиллах цагийн өгөгдөлгүй бүдүүвч.
