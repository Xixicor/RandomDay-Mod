# Тохирох байдал

> **Каноник англи эх сурвалж:** [COMPATIBILITY.md](../../COMPATIBILITY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


<a id="supported-installations"></a>
## Дэмждэг суулгацууд

RandomDay нь ачаалах боломжтой Abiotic Factor суулгацуудад зориулагдсан UE4SS Луа загварууд.

| Орчин орчин | Дэмжлэг | Багц |
| --- | --- | --- |
| Windows тусгай сервер | Дэмжигдсэн | Зориулагдсан сервер ZIP |
| Windows singleplayer эсвэл LAN хост | Гараар хуулбарлах ажлын урсгалыг дэмждэг | Singleplayer/LAN ZIP |
| Wine эсвэл Proton ашигладаг Linux сервер | Хувилбараар шалгагдаагүй | Windows-д зориулагдсан багцыг туршлагатай операторууд үнэлж болох ч нийцтэй байх амлалт өгөөгүй. |
| Xbox болон PlayStation | Дэмжихгүй | Эдгээр платформууд нь файлд хандах эрх өгдөггүй бөгөөд UE4SS Энэ хувилбарт шаардлагатай Lua ачаалах зам. |

RandomDay нь хоёр багцыг нэгтгэдэггүй. Зөвхөн хааяа тоглоход зориулагдсан тусгай сервер нь зориулалтын серверийг ZIP ба тохиргоонд түр зуурын үйлдлийг сонгоно.

<a id="abiotic-factor-updates"></a>
## Абиотик хүчин зүйлийн шинэчлэлтүүд

Тоглоомыг шинэчилсэний дараа сервер зогссоноор эхэлж, дэлхийн дахин сэргээх боломжтой хуулбарыг хадгална уу, `SandboxSettings.ini` болон RandomDay төлөв. UE4SS ачаалсны дараа нэгийг дуусгана уу RandomDay эргүүлж, хэвийн эргэлтийг үргэлжлүүлэхийн өмнө идэвхтэй болон бэлтгэсэн профайлыг хоёуланг нь шалгана уу.

<a id="companion-mods"></a>
## Хамтрагчийн горимууд

RandomDay нь тусад нь суулгасан горимыг зөвхөн түүний бүрэн тохиргоо нь дэмжигдсэн адаптертай таарч байвал өөрчилдөг. Зөвхөн хувилбарын дугаар хангалттай биш.

| Интеграци | Одоогийн хувилбарыг шалгасан | RandomDay дэмжлэгийн хил хязгаар |
| --- | --- | --- |
| Эмх замбараагүй үржлийн хөдөлгүүр / DynamicSpawns | `0.8.5`; үндсэн файл `0.8.5-Hotfix1` | Дэмжигдсэн `SharedData.lua` зохион байгуулалт нь түрс, зогсолт, популяци, портал, зөрчил, босс болон RandomDay адаптерийн лавлагаанд жагсаасан тохиргоотой тулгарна. |
| Үхлийн лазер | `1.0-UE4SS` | Дэмжигдсэн `Scripts/main.lua` зохион байгуулалт нь хүлээн зөвшөөрөгдсөн ялгаруулагч, хүрээлэн буй орчны ялгаруулагч, тусгал болон призмийн тохиргоог хамарна. |
| ANTE Дээш | `1`, 2026 оны 7-р сарын 19-нд шинэчлэгдсэн | Одоогийн нийтийн зохион байгуулалт нь адаптерийн бэхэлгээг дуусгаагүй байна. RandomDay тохиргоог баталгаажуулах хүртэл тохирохгүй файлыг алгасах болно. |

Байхгүй, идэвхгүй эсвэл танигдаагүй хамтрагч горим өөрчлөгдөөгүй хэвээр үлдэнэ. [Дэмждэг нэмэлт горимууд](%D0%94%D0%AD%D0%9C%D0%96%D0%94%D0%AD%D0%93_%D0%90%D0%94%D0%90%D0%9F%D0%A2%D0%95%D0%A0%D0%A3%D0%A3%D0%94.md) нарийн тохиргоо, тохиргооны хяналт, нөөцлөлт болон сэргээх алхмуудын хувьд.

<a id="what-compatibility-validation-proves"></a>
## Тохирох байдлын баталгаажуулалт юуг баталж байна

Репозиторын баталгаажуулалт нь илгээсэн багцын бүтэц, тохиргооны хамрах хүрээ, хүлээн зөвшөөрөгдсөн адаптерийн талбарууд, нөөцлөлт болон сэргээх үйл ажиллагаа, үл мэдэгдэх байршлаас найдвартай татгалзаж байгааг баталж чадна. Энэ нь ирээдүйн абиотик хүчин зүйл бүрийг баталж чадахгүй, UE4SS, эсвэл хамтрагч-mod хувилбар. Амжилттай ачаалсны дараа нийцтэй байна гэж таамаглахын оронд туршилтын хувилбаруудын нэрийг гарга.
