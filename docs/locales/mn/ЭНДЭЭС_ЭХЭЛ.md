# Эндээс эхэл: эхнийхийг дуусгана уу RandomDay мөчлөг

> **Каноник англи эх сурвалж:** [START_HERE.md](../../START_HERE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ гарын авлага RandomDay суулгасан. Энэ нь мод юу өөрчлөгддөг, юуг дангаар нь үлдээдэг, нэг амжилттай циклийг хэрхэн танихыг харуулдаг.

<a id="know-the-two-states"></a>
## Хоёр төлөвийг мэдэх

Абиотик хүчин зүйл нь дэлхийн хамгаалагдсан хязгаарлагдмал орчны тохиргоог уншихаас өмнө RandomDay эхэлнэ. RandomDay тиймээс тодорхой нэрлэгдсэн хоёр төлөвийг хадгалдаг:

- **Идэвхтэй профайл:** одоогийн сешн аль хэдийн ашиглаж байгаа дүрмүүд.
- **Бэлтгэсэн профайл:** дараагийн эхлүүлэхэд зориулан хадгалсан дүрмүүд.

Бэлтгэсэн профайл нь аль хэдийн явагдаж байгаа сешнийг өөрчлөхгүй.

<a id="dedicated-server-prepare-the-next-profile"></a>
## Зориулалтын сервер: дараагийн профайлыг бэлтгэ

1. Серверийг хэвийн эхлүүлнэ үү.
2. Хүлээгээрэй RandomDay эхлүүлэх ажлыг дуусгана уу.
3. Нээх `RandomDay/web_export/today.html` суулгасан mod хавтсанд.
4. Олох **Идэвхтэй профайл** болон **Бэлтгэсэн профайл**.

Анхны амжилттай эхлэх үед хуудсанд аль хэдийн идэвхтэй байгаа дүрмүүд болон дараагийн эхлэлийг хүлээж байгаа өөр профайлыг нэрлэх ёстой. Мөн энэ хуудсанд сонгосон гэр бүл, албан тушаал, бэлтгэсэн файл аюулгүй байдлын шалгалтандаа тэнцсэн эсэхийг тайлбарлана.

Зөвхөн статусыг өөрчлөхийн тулд дахин эхлүүлж болохгүй. Дараагийн төлөвлөсөн сервер эхлэх хүртэл идэвхтэй дүрмээр тоглоорой.

<a id="dedicated-server-activate-it-later"></a>
## Зориулалтын сервер: дараа идэвхжүүлнэ үү

1. Дараагийн төлөвлөсөн дахин эхлүүлэх үед серверийг зогсоож эхлүүлнэ үү.
2. Унших боломжтой статусын хуудсыг дахин нээнэ үү.
3. Өмнө нь бэлтгэсэн профайлыг идэвхтэй гэж жагсаасан болохыг баталгаажуулна уу.
4. Үүнийг баталгаажуулна уу RandomDay дараах профайлыг бэлтгэв.

Бэлтгэх-дараа нь-идэвхжүүлэх шилжилт нь бүрэн бүтэн нэг юм RandomDay мөчлөг.

<a id="temporary-dedicated-servers"></a>
## Түр зуурын зориулалтын серверүүд

Түр зуурын үйлдэл нь зориулагдсан серверийн багцыг ашигладаг. [Тохиргоо](%D0%A2%D0%9E%D0%A5%D0%98%D0%A0%D0%93%D0%9E%D0%9E.md), тодорхой профайл дээр шинэ гүйлт эхлэх үү эсвэл санамсаргүй эхлэх цэг сонгох уу. Статус хуудас нь идэвхтэй профайлыг дараагийн эхлүүлэхэд бэлтгэсэн профайлаас тусгаарласан хэвээр байна.

<a id="singleplayer-or-lan"></a>
## Ганц тоглогч эсвэл LAN

1. Тоглоомыг singleplayer/LAN багц суулгасан.
2. Тоглоомын дараа RandomDay дуусна.
3. Үйлдвэрлэсэн хураангуйг уншина уу.
4. Үйлдвэрлэсэн файлыг хуулах `SandboxSettings.ini` тоглоомыг хааж байх үед сонгосон ертөнц рүү оруулна уу.
5. Тэр ертөнцийг эхлүүлж, хүлээгдэж буй дүрмийг баталгаажуулна уу.

Дотоодын багц хэзээ ч ертөнцийг сонгохгүй эсвэл файлыг өөрөө хадгалахад хуулдаггүй. [Ганц тоглогч болон LAN](%D0%93%D0%90%D0%9D%D0%A6_%D0%A2%D0%9E%D0%93%D0%9B%D0%9E%D0%93%D0%A7%D0%98%D0%99%D0%9D_LAN.md).

<a id="if-the-expected-result-is-missing"></a>
## Хэрэв хүлээгдэж буй үр дүн байхгүй бол

Дахин асааж болохгүй. Одоогийн файлуудыг хадгалж, тохирох шинж тэмдгийг [Алдааг олж засварлах](%D0%90%D0%9B%D0%94%D0%90%D0%90%D0%93_%D0%9E%D0%9B%D0%96_%D0%97%D0%90%D0%A1%D0%92%D0%90%D0%A0%D0%9B%D0%90%D0%A5.md). Ердийн үр дүн нь идэвхтэй профайлыг үргэлж нэрлэж, бэлтгэсэн профайлыг эсвэл нэг тодорхой бэлтгэлийн алдааг илэрхийлдэг.
