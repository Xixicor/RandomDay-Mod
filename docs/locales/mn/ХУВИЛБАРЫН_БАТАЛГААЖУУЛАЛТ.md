# Хувилбарын баталгаажуулалт

> **Каноник англи эх сурвалж:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ хуудас нь хувь нэмэр оруулагчид болон хувилбарын засварлагчдад зориулагдсан. Мод суулгаж буй тоглогчид эдгээр командыг ажиллуулах шаардлагагүй.

<a id="ordinary-user-proof"></a>
## Энгийн хэрэглэгчийн баталгаа

Шинэ уншигч хоёр багцын аль нэгийг сонгож, суулгаж, идэвхтэй профайлыг тодорхойлж, дараах холбоосоор сэргээсэн удирдамжийг сэргээж чадвал хувилбар нь ойлгомжтой. Уншигчийн эдгээр даалгавар нь Git, PowerShell, Python эсвэл шалгах нийлбэрийн мэдлэг.

<a id="contributor-checks"></a>
## Хувь нэмэр оруулагчийн шалгалт

Repository root-ээс ажиллуулах:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

Хэзээ `luac` боломжтой, илгээсэн Луа файл бүрийг синтакс-шалгана уу:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

Lua-н ажиллах үеийн тестүүд `lupa`. Луа хэлмэрч алга эсвэл `lupa` суулгац нь туршилтын үр дүн биш харин боломжгүй туршилт юм.

<a id="release-checks"></a>
## Хувилбарыг шалгах

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

Хувилбарын шалгалт нь дараах нөхцлийг баталгаажуулдаг:

- `VERSION` болон `RandomDay/.randomday_version` таарч байна.
- Зөвхөн одоогийн хувилбар нь `releases/`.
- Зориулалтын болон singleplayer/LAN ZIP бол бүрэн хувилбар юм.
- Хоёр архив нь каноникийг агуулж байна `RandomDay/Scripts/main.lua` зам ба тохиолдлоор мөргөлдөх ачигч байхгүй.
- Багцын горимын тэмдэглэгээ нь `dedicated_server` болон `singleplayer_manual`.
- ZIP байт нь тодорхойлогч бөгөөд таарч `CHECKSUMS.sha256`.
- Ажиллах үеийн өгөгдөл, хувийн тохиргоо, итгэмжлэл, кэш эсвэл туршилтын гаралтыг багцалсангүй.
- Бүх локал баримт бичгийн холбоосууд болон 27 хэлний оруулгын хуудсыг баталгаажуулна.

<a id="avoid-validation-environment-pitfalls"></a>
## Баталгаажуулах орчны алдаанаас зайлсхий

- Repository-writing checks-ийг дараалан ажиллуулснаар хоёр процесс нэг түр зуурын файлыг нэг дор орлуулахгүй.
- Windows дээр ZIP гишүүний нэрсийг жижиг үсгээр дуудагч байгаа эсэхийг шийдэхийн тулд жижиг үсгээр файл хайхын оронд ашиглах.
- Баталгаажуулах `mods.txt` болон `enabled.txt` зөвхөн суулгасан серверийн туршилтанд; Эдгээр нь эх сурвалжийн туршилтыг явуулсны баталгаа биш юм.
- Тушаалын завсарлагыг бүрэн бус гэж тэмдэглэ. Үүнийг командын хязгаарлагдмал гаралтгүйгээр дамжуулж, бүтэлгүйтэхээр бүү хөрвүүл.
- Түр зуурын файлуудыг хадгалах газарт хадгалах `.tmp/` лавлах.

<a id="known-limits"></a>
## Мэдэгдэж буй хязгаарууд

Орон нутгийн баталгаажуулалт нь эх сурвалж, багц, баримт бичиг, бэхэлгээний гэрээг нотолдог. Энэ нь тодорхой серверийн самбарын эхлүүлэх дараалал, шууд үйлчлүүлэгчийн мессежийн байршил эсвэл хостын тусгай файлын системийн замыг нотолж чадахгүй. Туршилт хийхдээ тэдгээрийг тусад нь нэгтгэх үр дүн болгон тэмдэглэнэ үү.
