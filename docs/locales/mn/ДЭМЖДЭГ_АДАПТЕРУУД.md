# Дэмждэг нэмэлт загварууд

> **Каноник англи эх сурвалж:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


RandomDay нь RandomDay профайл. Энэ функцийг зөвхөн тусгай серверийн багцад ашиглах боломжтой. singleplayer/LAN багц нь өөр модыг хэзээ ч засдаггүй.

RandomDay нь энд жагсаасан ямар ч горимыг оруулаагүй эсвэл дахин түгээдэггүй. Нэмэлт горим бүрийг өөрийн Nexus хуудаснаас суулгаж идэвхжүүлээд эхлээд зохиогчийн зааврыг дагана уу. RandomDay нь зөвхөн суулгасан файлд байгаа танигдсан тохиргоог өөрчилдөг. Энэ нь өөр горимд функц нэмэхгүй бөгөөд адаптерийг устгахгүйгээр идэвхгүй болгож болно. Зориулалтын серверийн багц нь `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## Юу RandomDay өөрчлөлтүүд

| Нэмэлт интеграци | Идэвхтэй профайлаас сонгосон тохиргоо |
| --- | --- |
| Эмх замбараагүй үржлийн хөдөлгүүр / DynamicSpawns | Хатуу горим, player/area хөргөлтийн горим, шуурга ба халуун бүсийн үйл ажиллагаа, босс болон тэсрэлт, түрс үүсгэх мөчлөгийн хугацаа, жижиг болон том хөргөлтийн хүрээ, үржлийн зай, global/local/mod дээд хязгаар, портал шуурга, Захиалга зөрчих болон боссуудын боломж, мөн нэг газар ногдох хамгийн бага өндгөвч. |
| Заавал эмх замбараагүй түрс хөдөлгүүрийн өргөтгөлийн талбарууд | Суулгах үед `SharedData.lua` аль хэдийн RandomDay өргөтгөлийн талбарт адаптер нь учралын профайл, түвшин, сэдэв, бүлгийн хязгаар, тусгай үйл явдал болон холимог учралуудын утгууд, төсөв, хөргөлтийн хугацаа, дэлхийн хамрах хүрээний хяналтыг хангаж чадна. Энэ нь татаж авах өөр загвар биш. |
| Үхлийн лазер | Модыг идэвхжүүлэх, гэмтээж, байрлуулж болох ялгаруулагч, хүрээлэн буй орчны ялгаруулагч, цацруулагч, призмийн хяналтыг идэвхжүүлнэ. |
| ANTE Дээш | Дахин сэргэх давтамжийн үржүүлэгч, Антевариант давтамж болон одоо байгаа development/debug шилжүүлэгч. RandomDay нь хүлээн зөвшөөрөгдсөн бүх хөгжүүлэлт болон дибагуудыг унтраадаг. |

Профайл номын сан нь дэмжигдсэн өдөр болгонд бэлтгэсэн утгыг нийлүүлдэг. Чимээгүй өдөр даралтыг бууруулж, аюултай өдөр түүнийг өсгөж, сэргэх өдөр нь түүнийг эрс багасгадаг. RandomDay нь ачаалах үед дурын утгыг тооцдоггүй; энэ нь идэвхтэй профайлаар нэрлэсэн хянан үзсэн утгыг хэрэглэнэ.

<a id="how-recognition-protects-another-mod"></a>
## Таних нь өөр горимыг хэрхэн хамгаалдаг вэ

Танил файлын нэрийг олох нь хангалтгүй. Бичихийн өмнө RandomDay нь тухайн адаптерт шаардлагатай бүх тохиргоо зорилтот файлд байгаа эсэхийг шалгадаг. Энэ нь зөвхөн одоо байгаа даалгавруудыг нөхдөг; энэ нь хэзээ ч дутуу тохиргоо хийдэггүй.

Мэдэгдэж байгаа бүдүүвчийн хувьд RandomDay нь нэг хязгаарлагдмал гүйлгээг гүйцэтгэдэг:

1. идэвхтэй профайлд зориулагдсан утга бүрийг тооцоолох;
2. зорилтот файл бүрийн нөөцлөлтийг үүсгэж, байт-шалгах;
3. хүлээгдэж буй ах дүү файлаар дамжуулан бичих;
4. хүлээгдэж буй файлыг сурталчилж, хадгалсан байтуудыг буцааж унших;
5. зориулсан утга бүрийг баталгаажуулах;
6. хэрэв ямар нэг алхам амжилтгүй болбол баталгаажуулсан нөөцлөлтөөс автоматаар сэргээх аргыг ашиглана уу.

DynamicSpawns нь өөрийн тохиргоо болон хүлээн зөвшөөрөгдсөн тоглогч-мессеж файлуудыг нэг гүйлгээнд оруулах боломжтой. RandomDay нь гүйлгээг бүрэн дуусгаагүй тохиолдолд олон файлын шинэчлэлтийг амжилттай гэж мэдээлдэггүй.

<a id="read-an-adapter-result"></a>
## Адаптерийн үр дүнг унших

| Үр дүн | Утга |
| --- | --- |
| `applied` | Хүлээн зөвшөөрөгдсөн тохиргоонууд өөрчлөгдөж, дахин дахин давтагдсан. |
| `already_current` | Хүлээн зөвшөөрөгдсөн тохиргоо нь идэвхтэй профайлтай аль хэдийн таарсан байна. |
| `not_installed` | Нэмэлт горим олдсонгүй. RandomDay үүнгүйгээр үргэлжлүүлэв. |
| `skipped_incompatible` | Файл олдсон боловч түүний тохиргооны бүдүүвч бүрэн танигдаагүй. Юу ч өөрчлөгдөөгүй. |
| `partial` | Анхдагч DynamicSpawns тохиргоог ашигласан боловч нэмэлт орчуулсан мессежийн файл дуусаагүй байна. Бүртгэгдсэн адаптерийн үр дүнг шалгана уу. |
| `failed_rolled_back` | Гүйлгээ амжилтгүй болсон бөгөөд өмнөх байтууд хэвээр үлдсэн эсвэл сэргээж, баталгаажуулсан. |
| `rollback_failed` | RandomDay өөрчлөлт эсвэл сэргээлтийг баталгаажуулж чадсангүй. Нөлөөлөлд өртсөн горимыг зогсоож, хадгалсан нөөцлөлтийг гараар сэргээнэ үү. |

Алга болсон болон тохирохгүй нэмэлт горимууд зогсохгүй RandomDay's хамгаалагдсан хязгаарлагдмал орчны эргэлт.

<a id="enable-or-disable-integrations"></a>
## Интеграцийг идэвхжүүлэх эсвэл идэвхгүй болгох

Удирдлагууд нь:

```text
RandomDay/Scripts/ax_config/server.lua
```

Зориулалтын серверийн багц нь:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- Тохируулах `enabled = false` зогсоох RandomDay нэмэлт горим бүрийг шалгах эсвэл өөрчлөх боломжтой.
- Нэг адаптерийн ID-г устгаж, бусад интеграцийг идэвхтэй байлгахын зэрэгцээ энэ горимыг ганцаараа үлдээнэ үү.
- Хадгалах `patch_only_existing_keys` болон `backup_before_write`-г `true`. Эдгээр нь бичих аюулгүй байдлын хил хязгаар юм.
- Хадгалах `optional_by_default = true`. Үүнийг `false` нь дутуу, тохирохгүй эсвэл аюулгүй буцаагдсан адаптерийг нэгтгэсэн үр дүнд нөлөөлдөг.

Та нэмэлт горимыг идэвхгүй болгох үед устгах эсвэл идэвхгүй болгох шаардлагагүй RandomDay адаптер.

<a id="backups-and-manual-recovery"></a>
## Нөөцлөлт болон гараар сэргээх

Урьдчилан бичсэн баталгаажуулсан хуулбарыг дараах дор хадгална:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

Хэрэв `rollback_failed` гарч ирнэ:

1. тоглоом эсвэл серверийг зогсоох;
2. тогтоосон `external_mods.enabled = false`эсвэл нөлөөлөлд өртсөн адаптерийн ID-г устгана уу;
3. одоогийн зорилтот файл болон түүний дүүг хадгалах pending/rollback файлууд;
4. дугаарласан нөөц файлуудыг адаптерийн үр дүнд бичигдсэн зорилтот замуудтай тааруулах;
5. үйлчилгээ зогссон үед баталгаажуулсан байтыг сэргээх;
6. өөрийн нэмэлт горимыг дахин идэвхжүүлэхийн өмнө өөрөө эхлүүлнэ үү RandomDay адаптер.

Тохиргооны нэрийг өөрчлөх эсвэл дутуу түлхүүр нэмэх замаар нийцтэй байдлыг хүчлэх хэрэггүй. Дэмжлэгийн нэхэмжлэлийг өргөжүүлэхийн өмнө хүлээн зөвшөөрөгдсөн бүдүүвчийг ашиглах, адаптерийг идэвхгүй орхих эсвэл шинэ хувилбарын бэхэлгээ болон гүйлгээний тестийг нэмнэ үү.
