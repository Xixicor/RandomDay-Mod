# Аюулгүй байдлын бодлого

> **Каноник англи эх сурвалж:** [SECURITY.md](../../../SECURITY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


RandomDay нь серверийн тохиргооны файлуудыг бичих ба нэмэлт горимын тохиргооны файлуудыг нөхөж чаддаг. Өөрчлөлтүүдийг үйл ажиллагааны хувьд эмзэг гэж үзнэ.

<a id="do-not-report-as-security-issues"></a>
## Аюулгүй байдлын асуудал гэж бүү мэдээл

- Тоглоомын хэвийн тэнцвэрт өөрчлөлтүүд.
- Дараагийн дахин ачаалах профайлын эргэлт.

<a id="report-privately"></a>
## Хувийн байдлаар мэдээлэх

- Зам дамжих эрсдэл.
- Файл бичих аюултай.
- Зориулалтаас гадуур файлуудыг дарж бичих чадвар server/mod зам.
- Хортой тушаалын гүйцэтгэл.

Нийтийн аюулгүй байдлын суваг бий болтол нөөцийн эзэмшигчид хувийн байдлаар мэдээлнэ үү.
