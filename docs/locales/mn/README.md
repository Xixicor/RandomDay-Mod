# RandomDay монгол хэлээр

**v0.3.16-alpha**

RandomDay нь Abiotic Factor-ийн дараагийн эхлэлд зориулсан бүрэн
`SandboxSettings.ini` файлыг бэлтгэнэ. Одоо ажиллаж буй сессийн дүрмийг өөрчлөхгүй;
идэвхтэй болон дараагийн эхлэлд бэлтгэсэн профайлыг тусад нь мэдээлнэ.

## Суулгах ба шалгах

[Суулгах зааврыг](../../../INSTALL.md) дагана уу. Зөв хавтас нь
`ue4ss/Mods/RandomDay`, `mods.txt` дотор `RandomDay : 1` байх ёстой. Ихэнхдээ
эхний эхлэл профайлыг бэлтгэж, дараагийн эхлэл идэвхжүүлнэ.

`runtime/current/randomday_status.json`, `runtime/rotation_state.txt` болон
`web_export/today.json` файлыг шалгана. Идэвхтэй ба бэлтгэсэн профайлын таних
мэдээлэл гурвууланд нь таарах ёстой.

## Туршлагаа сонгох

Горим, бүлэг, эхлэх өдөр болон ахицыг
`RandomDay/Scripts/ax_config/server.lua` файлд тохируулна. [Эхлэх](../../START_HERE.md),
[Профайл сонгох](../../CHOOSE_A_PROFILE.md), [Тохиргоо](../../CONFIGURATION.md)
болон [Алдаа засах](../../TROUBLESHOOTING.md) хэсгийг уншина уу.

`HardcoreMode=False`, `AllowIronMode=False`, `StructuralSupportLimit=0` болон
`BridgeSupports=0` нь дагалдах профайл бүтээгчийн эхний утга бөгөөд Abiotic
Factor-ийн заавал мөрдөх дүрэм биш. Өөрчлөх болон дахин үүсгэх аргыг тохиргооны
баримтад тайлбарласан.

Бодит файлтай яг тааруулахын тулд команд, зам, INI түлхүүр болон төлөв англи
хэлээр хэвээр үлдэнэ.

## Альфа хувилбар ба хадгалагдах сонголт

Энэ нь альфа хувилбар. Баримтжуулсан суулгалт, эргэлт, сэргээх замуудыг туршсан бөгөөд нийцтэй байдал, ашиглахад хялбар байдлыг үргэлжлүүлэн сайжруулж байна.

`RandomDay/Scripts/ax_config/server.lua` доторх `sandbox.profile_overrides` нь дөрвөн утгыг бүх бүлэг, өдөрт хадгална. Серверийг зогсоож, нэг удаа өөрчлөөд дахин эхлүүл. Дараагийн эргэлт, эхлэлт ижил утгыг ашиглана; зөвхөн `SandboxSettings.ini`-г өөрчлөх нь түр зуурынх.

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

Доорх нэмэлт модууд нь зохиогчдын тусдаа таталт юм. RandomDay тэдгээрийг дахин түгээхгүй, боломжийг нь өөрчлөхгүй; идэвхтэй адаптер зөвхөн байгаа, дэмжигдсэн тохиргоог өөрчилнө. Зохиогч, арчлагчдад баярлалаа.
