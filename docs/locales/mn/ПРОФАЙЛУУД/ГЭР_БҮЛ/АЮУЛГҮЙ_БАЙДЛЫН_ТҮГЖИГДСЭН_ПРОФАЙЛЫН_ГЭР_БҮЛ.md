# RandomDay - Хамгаалалтын түгжрэлийн гэр бүл

> **Каноник англи эх сурвалж:** [security_lockdown.md](../../../../profiles/families/security_lockdown.md). <a id="day-1---badge-check-orientation"></a>
## 1 дэх өдөр - Тэмдэг шалгах чиглэл

**Профайл ID:** `security_lockdown_badge_check_orientation` **Нийт нөхцөл:** Стандарт даралт (2.02/5) **Энгийн утга:** Стандарт даралт. Байлдааны даралт: Стандарт даралт нь гол даралт юм. Хүрээлэн буй орчны даралт: Стандарт даралт нь дараагийн хамгийн хүчтэй хүчин зүйл юм. **Тоглогчийн зөвлөгөө:** Зэвсэг зөөж, ухрах замаа баримталж, дэмжлэггүй тулалдахаас зайлсхий.

<a id="main-effects"></a>
### Үндсэн эффект

- Дайсны нарийвчлал: өндөр нарийвчлалтай.
- Нөхөрсөг галын гэмтэл хэвийн хэмжээнээс хамаагүй доогуур байна (0.25x).
- Нас барсны дараа эдэлгээний алдагдал хэвийн хэмжээнээс хамаагүй доогуур байна (0.25x).
- Стекийн багтаамж хэвийн хэмжээнээс хамаагүй өндөр байна (2x).
- Цахилгааны залгуурууд шөнө унтардаг.
