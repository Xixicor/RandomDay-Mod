# Толь бичиг

> **Каноник англи эх сурвалж:** [GLOSSARY.md](../../GLOSSARY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ бол RandomDay баримт бичиг. Процедурууд нь олон гарын авлагад ижил төлөвийг дахин тодорхойлохын оронд эдгээр тодорхойлолтуудтай холбогддог. Схемийн тусгай талбарын дүрмүүд [Ажиллах үеийн гаралт](%D0%90%D0%96%D0%98%D0%9B%D0%9B%D0%90%D0%A5_%D0%A5%D0%A3%D0%93%D0%90%D0%A6%D0%90%D0%90%D0%9D%D0%AB_%D0%93%D0%90%D0%A0%D0%90%D0%9B%D0%A2.md).

| Хугацаа | Энгийн утга | Яг техникийн утга |
|---|---|---|
| Идэвхтэй профайл | Одоогийн сешн ашиглаж байгаа дүрмүүд. | The family/day профайл RandomDay тэмдэглэгээг процессыг эхлүүлэх үед хамгаалагдсан хязгаарлагдмал орчинд уншина. |
| Бэлтгэсэн профайл | Дүрэмүүд дараа нь ажиллахад бэлэн байна. | Бүрэн family/day профайл, зорилтот байт нь баталгаажуулалт болон дахин дахин давтагдаж, эргэлтийн төлөв нь хийгдсэн байна. Энэ нь дахин уншихаас өмнө идэвхгүй байна. |
| Сэргээгдсэн | Бэлтгэл амжилтгүй болж, өмнө нь баталгаажуулсан байтуудыг буцааж өгсөн. | Бүтэлгүйтсэн гүйлгээ нь хадгалагдсан эх эсвэл баталгаажсан сэргээх хуулбарыг амжилттай буцаах болон дахин сэргээсэн тухай мэдээлдэг. |
| Дараагийн дахин ачаалах дараалал | Дараагийн ачаалахад бэлэн болсон нэг сонголт байна. | `next_reboot_queue` нь процесс бүрт нэг удаа сонгож, хяналтын үед ачаалах өмчлөлийн сонголтыг дахин ашигладаг. |
| Ачаалах систем | Идэвхтэй тэмдэглэгээ байхгүй үед эхний бэлтгэл. | Эрх бүхий гэр бүлээс тохируулсан эсвэл санамсаргүй эхний өдрийг сонгох; `cycle.bootstrap_day` нь зөвхөн нийцтэй байдлын нөөц юм. |
| Гэр бүл | 17 хоногийн тоглоомын хэв маяг. | Яг 17 бүрэн профайл үүсгэдэг нэг бүртгэлийн оруулга ба гэр бүлийн модуль. |
| Эргүүлэх | Эрх бүхий гэр бүлээр дамжих дамжуулалт. | Төлөвийг тодорхойлсон `rotation_id`, боломжтой, үлдсэн болон дууссан гэр бүлийн жагсаалттай. |
| Ажиллуулах | 17 хоногийн бүх ID дээр нэг гэр бүл. | Гэр бүлд хамаарах дараалал `run_id`; Тогтвортой өдрийн захиалгын байрлал бүр дуусах хүртэл гэр бүл түгжигдсэн хэвээр байна. |
| Үйл ажиллагааны горим | Оператор энэ багцыг хэрхэн ашигладаг вэ. | `persistent_dedicated`, `temporary_dedicated`, эсвэл `singleplayer_lan`; багц горим нь файлын системийн хил хязгаарыг хянадаг хэвээр байна. |
| Өдрийн захиалга | Нэг гэр бүлийн ашигладаг яг дараалал. | Тогтвортой 17-тоо солих. Дараалсан горим нь эхэлсэн өдрөөсөө эхлэнэ; санамсаргүй горим давталгүйгээр нэг удаа холилдоно. |
| Маркер | Хамгаалалттай орчинд хадгалагдсан таниулбар. | `RANDOMDAY_*` талбаруудыг бүрэн профайлтай хамт гаргаж, дараагийн процессыг эхлүүлэх үед уншина. |
| Бэлдсэн бэлэн | Бичих болон төлөвийн үүрэг амжилттай боллоо. | `prepared_ready=true` нь хамгаалагдсан хязгаарлагдмал орчинд амжилттай үр дүнд хүрэхийг шаарддаг бөгөөд төлөвийн алдаа байхгүй. Энэ нь идэвхжүүлэлтийг нотлохгүй. |
| Одоо байгаа | Зорилтод төлөвлөсөн байт аль хэдийн байна. | Үзүүлсэн профайлын хэш нь зорилтот хэмжээтэй таарч байгаа тул RandomDay баталгаажуулдаг last-good/mirrorанхныг дахин бичихгүйгээр ажиллана. |
| Муу төлөв байдлын тогтвортой байдал | Sandbox байт амжилттай болсон ч эргэлтийн бүртгэл амжилтгүй болсон. | `profile_status=degraded_state_persistence`; адаптерууд болон бэлтгэсэн профайл мессежийг алгассан. |
| Хүлээгдэж буй файл | Нэр дэвшигчийн байт хараахан дэвшээгүй байна. | `<target>.randomday.pending`, солихын өмнө бичиж, дахин уншиж, баталгаажуулсан. |
| Буцах файл | Эх хувь нь солих үед хадгалагддаг. | `<target>.randomday.rollback`, урамшуулал эсвэл баталгаажуулалт амжилтгүй болсон үед үйлдвэрлэлийг сэргээхэд ашигладаг. |
| Үйл ажиллагааны нөөцлөлт | Мутацийн өмнө хийгдсэн бат бөх хуулбар. |  `runtime/backups/` үндсэн, толин тусгал эсвэл адаптер гүйлгээнд. |
| Хамгийн сүүлд мэдэгдэж байсан сайн зүйл | Сэргээхээр зөвшөөрөгдсөн хамгийн сүүлийн үеийн хамгаалагдсан хязгаарлагдмал орчин. | `runtime/last_good/SandboxSettings.ini` нэмэх `manifest.lua`; хос профайлын таниулбар болон хэшийг бичдэг. |
| Толь | Нэмэлттэй хоёр дахь хамгаалагдсан хязгаарлагдмал орчны зорилт. | Анхан шатны дараа өөрийн гүйлгээгээр бичигдсэн, тодорхой тохируулсан эсвэл дэлхийн нэрнээс гаралтай зорилт. |
| Багцын горим | Хувилбарын өмчөөр сонгосон суулгацын хил хязгаар. | `dedicated_server` эсвэл `singleplayer_manual`-аас `.randomday_mode`. |
| Гараар хуулах горим | Singleplayer/LAN хадгалалтгүйгээр үүсгэнэ. | `singleplayer_manual` нь зөвхөн `runtime/singleplayer_manual/` ба адаптер болон толин тусгалыг идэвхгүй болгодог. |
| Адаптер | RandomDay-owned өөр суулгасан горимын зураглал. | Зөвхөн нөөцлөлт болон нийцтэй байдлыг шалгасны дараа одоо байгаа даалгавруудыг шинэчилдэг гарын үсэг бүхий гүйлгээний төлөвлөгөө. |
| Танигдсан байршил | Бичихэд хүлээн зөвшөөрөгдсөн адаптер файлын яг хэлбэр. | Бүх шаардлагатай гарын үсгийн түлхүүрүүд болон зорилтот файлууд байгаа; зөвхөн файлын нэр хангалтгүй байна. |
| `not_installed` | Нэмэлт зорилт олдсонгүй. | Мутаци байхгүй аюулгүй адаптерийн үр дүн. |
| `skipped_incompatible` | Зорилтот байгаа боловч хэлбэр нь дэмжигдээгүй байна. | Бүрэн гарын үсэг таараагүй тул мутацигүй аюулгүй адаптерийн үр дүн. |
| `failed_rolled_back` | Өөрчлөлт амжилтгүй болсон бөгөөд өмнөх байтууд хэвээр байна. | Мутаци хийхээс өмнө адаптерийн гүйлгээ амжилтгүй болсон эсвэл нөлөөлөлд өртсөн бүх файлыг сэргээж, баталгаажуулсан. |
| `rollback_failed` | Автомат сэргээх ажиллагааг баталгаажуулж чадсангүй. | Бичигдсэн нөөцлөлтөөс гараар сэргээх шаардлагатай хатуу зогсолтын адаптерийн төлөв. |
| Толь бичиг | Түүхий үнэ цэнээс олон нийтийн тайлбар руу зураглал хийх. | `randomday_dictionary_v2`, үүсгэсэн `dictionary.lua` ба ажиллах үеийн төлөвийн гаралтад багтсан. |
| Орчуулга | Түүхий профайлын утгуудаас авсан хүний ​​харагдац. | Хязгаарлагдмал домэйны оноо, баримт, хураангуй болон үүсгэсэн мессежүүд `translation.lua`; түүхий утгууд нь эрх мэдэлтэй хэвээр байна. |
| Нийтийн байдал | Ариутгасан машинд уншигдахуйц операторын хураангуй. | `web_export/today.json` `randomday_public_status_v2`. |
| Ажиллах үеийн төлөв | Орон нутгийн машинд унших боломжтой нарийвчилсан агшин зураг. | `runtime/current/randomday_status.json` `randomday_runtime_status_v2`. |
