<a id="compatibility"></a>
# 호환성

> **표준 영어 소스:** [COMPATIBILITY.md](../../COMPATIBILITY.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


<a id="supported-installations"></a>
## 지원되는 설치

RandomDay는 UE4SS Lua 모드를 로드할 수 있는 Abiotic Factor 설치용으로 제작되었습니다.

| 환경 | 지원 | 패키지 |
| --- | --- | --- |
| Windows 전용 서버 | 지원됨 | 전용 서버 ZIP |
| Windows 싱글 플레이어 또는 LAN 호스트 | 지원되는 수동 복사 워크플로 | Singleplayer/LAN ZIP |
| Wine 또는 Proton을 사용하는 Linux 서버 | 릴리스 테스트되지 않음 | Windows 전용 패키지는 숙련된 운영자에 의해 평가될 수 있지만 호환성은 보장되지 않습니다. |
| Xbox 및 PlayStation | 지원되지 않음 | 이러한 플랫폼은 파일 액세스를 제공하지 않으며 UE4SS 이 릴리스에 필요한 Lua 로딩 경로를 제공하지 않습니다. |

RandomDay 두 패키지를 결합하지 않습니다. 가끔 플레이를 위해서만 시작되는 전용 서버는 여전히 전용 서버 ZIP를 사용하고 구성에서 임시 동작을 선택합니다.

<a id="abiotic-factor-updates"></a>
## 비생물적 요소 업데이트

게임 업데이트 후 서버가 중지된 상태에서 시작하고 세계, `SandboxSettings.ini` 및 RandomDay 상태. UE4SS 로드를 확인한 다음 하나의 RandomDay 주기를 완료하고 일반 회전을 재개하기 전에 활성 프로필과 준비된 프로필을 모두 확인하세요.

<a id="companion-mods"></a>
## 컴패니언 모드

RandomDay 전체 설정 레이아웃이 지원되는 어댑터와 일치하는 경우에만 별도로 설치된 모드를 변경합니다. 버전 번호만으로는 충분하지 않습니다.

| 통합 | 현재 버전 검토됨 | RandomDay 지원 경계 |
| --- | --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | `0.8.5`; 기본 파일 `0.8.5-Hotfix1` | 지원되는 `SharedData.lua` 레이아웃은 스폰, 쿨다운, 인구, 포털, 위반, 보스 및 RandomDay 어댑터 참조에 나열된 만남 설정을 다룹니다. |
| 치명적인 레이저 | `1.0-UE4SS` | 지원되는 `Scripts/main.lua` 레이아웃은 인식된 방출기, 환경 방출기, 반사기 및 프리즘 설정을 다룹니다. |
| ANTE Up | `1`, 2026년 7월 19일 업데이트 | 현재 공개 레이아웃은 어댑터 고정 장치를 완성하지 않았습니다. RandomDay 해당 레이아웃이 확인될 때까지 일치하지 않는 파일을 변경되지 않고 건너뜁니다. |

부재, 비활성화 또는 인식할 수 없는 컴패니언 모드는 변경되지 않고 그대로 유지됩니다. 참조 [지원되는 선택적 모드](%EC%A7%80%EC%9B%90%EB%90%98%EB%8A%94_%EC%96%B4%EB%8C%91%ED%84%B0.md) 정확한 설정, 구성 제어, 백업 동작 및 복구 단계를 확인하세요.

<a id="what-compatibility-validation-proves"></a>
## 호환성 검증이 증명하는 것

저장소 유효성 검사를 통해 배송된 패키지 레이아웃, 구성 적용 범위, 인식된 어댑터 필드, 백업 및 복원 동작, 알 수 없는 레이아웃의 안전한 거부를 입증할 수 있습니다. 미래의 모든 Abiotic Factor, UE4SS 또는 동반 모드 버전을 증명할 수는 없습니다. 릴리스 노트에는 성공적인 로드에서 호환성을 가정하는 대신 테스트된 버전의 이름이 지정됩니다.
