# 기여

> **표준 영어 소스:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay는 제어된 프로젝트로 유지됩니다.

공개 풀 요청, 원치 않는 코드 제출, 자동 재작성, 생성된 코드 정리 제출 및 추측 기능 패치는 저장소 소유자가 명시적으로 요청하지 않는 한 허용되지 않습니다.

<a id="accepted-contact"></a>
## 수락됨 문의

버그 보고서, 호환성 참고 사항 또는 서버 관리 관찰에 대해서는 프로젝트 문서에 나열된 문의 채널을 사용하세요.

<a id="not-accepted"></a>
## 허용되지 않음

다음은 기본적으로 허용되지 않습니다:

- 원치 않는 풀 요청;
- generated-code 재작성;
- 광범위한 리팩터링;
- 스타일 전용 형식 변경;
- 테스트되지 않은 게임플레이 로직 변경;
- 번들링된 타사 모드 파일;
- 재배포된 타사 소스 코드;
- Abiotic Factor, UE4SS, Nexus Mods 또는 타사 모드 작성자와의 공식 제휴를 암시하는 변경 사항.

<a id="controlled-development"></a>
## 통제된 개발

저장소 소유자는 필요할 때 특정 검토, 테스트 또는 문서화 지원을 요청할 수 있습니다. 요청되지 않은 제출은 검토 없이 종료될 수 있습니다.
