# 런타임 상태 및 출력 스키마 해석

> **표준 영어 소스:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이것은 표준 필드 완성 스키마 가이드입니다. 각 필드, 상태, 빈 값 및 기계 결과가 무엇을 의미하는지 답변합니다. [런타임 파일 맵](%EB%9F%B0%ED%83%80%EC%9E%84_%ED%8C%8C%EC%9D%BC.md) 생산자, 경로, 쓰기 타이밍, 보존, 트랜잭션 사이드카 및 복구 위치에 대한 정보입니다.

이 가이드의 모든 경로는 달리 명시되지 않는 한 설치된 `RandomDay/` 폴더는 설치 후에 구성된 샌드박스 또는 선택적 어댑터 대상의 이름을 명시적으로 지정하고 두 릴리스 ZIP.

<a id="choose-the-authoritative-view"></a>
## 신뢰할 수 있는 보기 선택

| 필요 | 신뢰할 수 있는 출처 |
|---|---|
| 현재 프로세스에 의해 로드된 규칙 | RandomDay 마커의 구성원이 아닙니다. `SandboxSettings.ini` 시작 시 읽기 |
| 준비된 대기열 기록 | `runtime/rotation_state.txt`, 스키마 `1` |
| 상세한 현지 현황 | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| 공용 기계 판독 가능 상태 | `web_export/today.json`, 스키마 `2` 및 `randomday_public_status_v2` |
| 사람이 읽을 수 있는 상태 | `web_export/today.html`, 동일한 공개 상태 전환에서 파생됨 |
| 번역 어휘 | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| 정확한 제한 플레이어 알림 | `runtime/current/player_message_preview.txt` |

HTML 보기에서 미리보기 및 번역된 요약은 샌드박스 마커, 트랜잭션 결과 또는 원시 프로필 값을 재정의하지 않으며, 작업 백업, 사이드카, 미러, 어댑터 대상 및 `UE4SS.log` [런타임 파일](%EB%9F%B0%ED%83%80%EC%9E%84_%ED%8C%8C%EC%9D%BC.md).

<a id="rotation-state-schema"></a>
## 회전 상태 스키마

`runtime/rotation_state.txt` 스키마 사용 `1` 하나를 포함 `key=value` 한 줄에 쌍:

| 필드 | 의미 |
|---|---|
| `schema_version` | 반드시 `1`. |
| `mod_version` | 다음에서 읽은 패키지 ID`.randomday_version`. |
| `rotation_id` | 적격 패밀리 세트를 통한 현재 패스의 식별자. |
| `mode` | `selected_run`, `non_repeating_random_run` 또는 `rotation_run`. |
| `available_families` | 구성 필터링 후 쉼표로 구분된 적격 가족 ID. |
| `remaining_families` | 현재 비반복 패스에서 아직 선택되지 않은 적격 가족. |
| `completed_families` | 현재 패스에서 완전한 지속 17 위치 순서가 완료된 패밀리 |
| `active_family`, `active_day` | 선택이 커밋되었을 때 기록된 활성 마커 정보입니다. 샌드박스 마커는 다음 부팅 시 권한을 갖습니다. |
| `prepared_family`, `prepared_day` | 다음 재시작을 위해 프로필이 유지됩니다. |
| `active_run_id` | 준비된 선택과 연관된 가족 실행 식별자. |
| `last_status` | 이 파일을 생성한 캘린더 선택 상태. |
| `session_mode` | 영구 전용, 임시 전용 또는 singleplayer/LAN 해결 lifecycle. |
| `start_day_mode` | 새 실행을 위한 구성된 또는 일회성 무작위 시작 선택. |
| `day_progression_mode` | 래핑된 순차 또는 비반복 무작위 진행. |
| `day_order` | 준비될 정확한 순서대로 쉼표로 구분된 지속형 날짜 ID. |
| `day_position` | 준비된 날짜의 위치 `day_order`. |
| `updated_at` | 연산자 비교를 위한 로컬 쓰기 시간. |

상태 쓰기는 스키마 마커, 준비된 패밀리 및 준비된 날짜가 올바르게 다시 읽혀진 경우에만 허용됩니다. 읽을 수 없는 현재 파일은 `rotation_state.last_good.txt`로 대체될 수 있습니다. 선택한 샌드박스 마커는 현재 프로세스에 대해 게임이 로드한 내용을 결정합니다.

<a id="runtime-status-json"></a>
## 런타임 상태 JSON

`runtime/current/randomday_status.json`은 `status_schema=randomday_runtime_status_v2`을 사용합니다. 주요 필드 그룹은 다음과 같습니다:

| 그룹 | 필드 및 해석 |
|---|---|
| ID | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| 선택 | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| 활성 | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| 준비됨 | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| 인간 요약 | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| 쓰기 증명 | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| 어댑터 증명 | `adapter_status`, `adapter_results`; 각 어댑터 레코드에는 호환성 증거, transaction/rollback 상태, 변경된 파일 수 및 수정된 대상 참조 |
| 경계 | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| 진단 | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

알 수 없는 활성 값은 현재 샌드박스에 읽을 수 있는 값이 포함되어 있지 않음을 의미합니다. RandomDay 마커. 준비된 값으로 대체하면 안 됩니다. 외부 어댑터 경로 `runtime/` 외부의 어댑터 경로는 기본 이름 참조로 축소되고 진단 문자열은 감지된 절대 경로를 수정합니다.

<a id="public-status-json"></a>
## 공개 상태 JSON

`web_export/today.json`은 `schema_version=2` 및 `status_schema=randomday_public_status_v2`. 운영자에게 필요한 ID, active/prepared, 선택, 트랜잭션, 어댑터 및 재시작 경계 사실을 반복합니다. 여기에는 다음 항목도 포함됩니다:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` 및 `prepared_day_position`;
- `family_selection_mode`레거시 `family_locked_until_day_17` 및 `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families` 및 개수;
- 준비된 조우 프로필, 계층, 테마 및 혼합 조우 기회;
- 세계 범위 활성화, 개방형 세계 설정, 알 수 없는 세계 정책 및 구성된 제외 세계 패턴 수
- 준비된 메시지 및 결합된 메시지 미리보기,
- `selected_at`, `sandbox_target`, `manual_copy_required` 및 준비된 해시.

`profile_status`는 `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` 또는 `write_failed_or_rollback`. `prepared_ready=true` 중 하나이지만 여전히 활성을 의미하지는 않습니다. 이후 시작 표시가 필요합니다.

<a id="dictionary-and-translation-output"></a>
## 사전 및 번역 출력

`runtime/current/randomday_dictionary.json`은 `schema=randomday_runtime_dictionary_v2` 사전 버전을 식별합니다 `randomday_dictionary_v2`. 패키지 모드, 선택 상태, 압력 영역, 설정 라벨, 원시 값 및 일반 언어 의미를 설명합니다. 알 수 없는 값은 확실한 설명으로 변환되지 않고 명시적으로 유지됩니다.

`player_message_preview.txt`, `today.json`, `today.html`, 게임 내 알림은 동일한 번역 모듈에서 파생된 보기입니다. 기본 프로필과 원시 `SandboxSettings.ini` 값은 진실의 소스로 유지됩니다.

<a id="failure-and-recovery-rules"></a>
## 실패 및 복구 규칙

1. 실패한 보류 중인 쓰기 또는 검증은 프로덕션 대상이 될 수 없습니다.
2. 실패한 승격 또는 프로덕션 다시 읽기는 보관된 원본의 복원을 트리거합니다. 작업 백업은 복원이 실패할 때의 대체입니다.
3. 보존된 롤백 파일 또는 `rollback_failed` 상태는 게임이나 서버가 중지된 동안 수동 검토가 필요합니다.
4. 성공적인 샌드박스 쓰기와 실패한 회전 상태 커밋은 성능이 저하되어 준비되지 않았습니다. 어댑터 및 준비된 프로필 메시징은 건너뜁니다.
5. 내보내기 실패는 샌드박스 결과를 변경하지 않지만 편의 증명 소스를 제거합니다. 트랜잭션 로그, 상태, 파일 다시 읽기를 사용하세요.
6. 런타임 출력은 로컬 작동 데이터입니다. 릴리스에 추가하지 마세요. ZIP또는 별도의 개인정보 보호 검토 없이 예시로 게시하세요.
