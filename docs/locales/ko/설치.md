# 설치, 업데이트 또는 제거 RandomDay

> **표준 영어 소스:** [INSTALL.md](../../../INSTALL.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay 2개의 전체 다운로드가 있습니다. 설정하려는 세계에 대해 하나를 선택하세요.

- 비정기적인 세션을 위해서만 열리는 서버를 포함하여 전용 서버에 **전용 서버 ZIP**를 사용하세요.
- 비정기적인 세션을 위해서만 열리는 서버를 포함하여 전용 서버에 **singleplayer/LAN ZIP**설정을 수동으로 복사할 로컬 세계에 사용하세요.

패키지를 결합하지 마세요. 영구 또는 임시 전용 서버는 다른 다운로드가 아닌 RandomDay's설정, 다른 다운로드가 아닙니다.

<a id="before-you-begin"></a>
## 시작하기 전에

다음의 복원 가능한 복사본을 만드세요:

- 변경하려는 세계,
- 현재 `SandboxSettings.ini`;
- 기존 `RandomDay` 폴더(설치되어 있는 경우).

설치하기 전에 UE4SSRandomDay. 아래 지침에서 **Mods 폴더**는 `ue4ss/Mods/` 디렉터리를 의미합니다.

<a id="dedicated-server"></a>
## 전용 서버

<a id="new-installation"></a>
### 새 설치

1. 서버를 중지하세요.
2. 해당 폴더 열기 UE4SS `Mods` 폴더.
3. 전용 서버 추출 ZIP를 의미합니다. 결과는 하나여야 하며 `ue4ss/Mods/RandomDay/` 폴더, 다른 폴더 안의 폴더 아님 `RandomDay` 폴더.
4. 해당 폴더를 열고 `RandomDay/Scripts/main.lua`가 있어야 합니다. 누락된 경우 ZIP가 잘못된 레벨로 추출된 것입니다.
5. 설치된 mod 폴더에서 UE4SS `mods.txt` 다음 줄을 활성화하세요:

   ```text
   RandomDay : 1
   ```

6. 서버를 정상적으로 시작하세요.
7. 설치된 mod 폴더에서 RandomDay's 읽을 수 있는 상태 페이지를 의미하며 활성 프로필과 다음 시작을 위해 준비된 프로필의 이름을 모두 지정하는지 확인하세요.

첫 번째 시작은 해당 세션에서 이미 로드한 규칙을 대체하지 않습니다. 다음 프로필을 준비합니다. 준비된 프로필을 실제로 활성화하려는 경우에만 서버를 다시 시작하세요.

[첫 번째 주기를 확인하세요](%EC%97%AC%EA%B8%B0%EC%84%9C_%EC%8B%9C%EC%9E%91.md)

<a id="choose-always-on-or-temporary-behavior"></a>
### 상시 작동 또는 임시 동작 선택

전용 서버 패키지는 두 가지 스타일을 모두 지원합니다.

- **영구 전용** 정상적인 재시작 시 저장된 회전을 재개합니다.
- **임시 전용**은 새로운 임시 실행이 시작될 때 구성된 또는 임의의 시작 지점에서 시작할 수 있습니다.

[구성](%EA%B5%AC%EC%84%B1.md)에서 동작을 선택하세요. 이 설정을 변경하려면 두 번째 패키지를 설치하지 마세요.

<a id="update-an-existing-installation"></a>
### 기존 설치를 업데이트하세요

1. 서버를 중지하고 위에 나열된 백업.
2. 이전 `RandomDay` 폴더를 UE4SS `Mods` 폴더 밖으로 이동하세요. 업데이트가 한 번의 성공적인 주기를 완료할 때까지 보관하세요.
3. 새 전용 서버 추출 ZIP `Mods` 폴더.
4. 의도적으로 변경했으며 새 [구성 가이드](%EA%B5%AC%EC%84%B1.md).
5. 릴리스 노트에 해당 형식이 호환된다고 나와 있는 경우에만 문서화된 회전 상태 파일을 유지하십시오. 이전 임시 출력 또는 쓰기 실패 파일을 새 설치에 복사하지 마세요.
6. 확인 `RandomDay : 1`이 여전히 활성화되어 있으면 서버를 한 번 시작하고 활성 및 준비된 프로필 이름을 확인하세요.

<a id="updating-from-v0315-alpha"></a>
### 에서 업데이트 v0.3.15-alpha

`RandomDay_v0.3.15-alpha.zip`는 이전 기본 패키지였습니다. `RandomDay_v0.3.15-alpha_singleplayer_patch.zip`는 오버레이였으며 독립 실행형 다운로드가 아닙니다.

현재 `v0.3.16-alpha`는 역사적인 기본 및 오버레이 배열을 두 개의 완전한 패키지로 대체합니다. 어느 패키지에도 이전 패치를 부착하지 마십시오. 현재 마커는 `.randomday_mode=dedicated_server` 및 `.randomday_mode=singleplayer_manual`.

<a id="singleplayer-or-lan"></a>
## 싱글 플레이어 또는 LAN

singleplayer/LAN 패키지가 설정 파일을 생성합니다. 자체적으로 개인 저장을 검색하거나 변경하지 않습니다.

1. 게임을 닫습니다.
2. 세계와 현재 `SandboxSettings.ini`.
3. 게임의 UE4SS singleplayer/LAN ZIP 게임 UE4SS `Mods` 폴더에 `Mods/RandomDay/` 폴더가 존재합니다.
4. UE4SS에서 `RandomDay : 1` UE4SS `mods.txt`.
5. 게임을 한 번 시작하고 RandomDay 끝날 때까지 기다린 후 게임을 완전히 닫습니다.
6. RandomDay에서 생성된 `SandboxSettings.ini` RandomDay's `runtime/singleplayer_manual/` 폴더.
7. 생성된 요약을 읽은 다음 선택한 월드에 파일을 복사하세요.
8. 해당 월드를 시작하고 예상되는 샌드박스 동작이 활성화되어 있는지 확인하세요.

LAN 사용 호스트가 로컬 세계를 소유하기 때문에 동일한 수동 프로세스입니다. 모드는 세계를 선택하거나 자동으로 덮어쓰지 않습니다.

[싱글플레이어 및 LAN 가이드](%EC%8B%B1%EA%B8%80_%ED%94%8C%EB%A0%88%EC%9D%B4%EC%96%B4_LAN.md)

<a id="remove-or-disable-randomday"></a>
## 제거 또는 비활성화 RandomDay

1. 게임이나 서버를 중지하세요.
2. 세계, 현재 샌드박스 설정 및 RandomDay's 상태에 여전히 존재하는 설정만 다시 적용하세요.
3. `RandomDay : 0` UE4SS `mods.txt`를 비활성화하도록 설정하세요 모드를 선택하거나 전체 `RandomDay` 폴더를 `Mods` 폴더 밖으로 이동하여 제거하세요.
4. 다음 시작 시 로드해야 할 `SandboxSettings.ini`는 다음 시작 시 로드되어야 합니다. 현재 준비된 RandomDay 프로필을 원하지 않으면 사전 설치 복사본을 복원하세요.
5. 세계를 시작하고 규칙을 확인하세요. 백업을 삭제하기 전에.

비활성화하면 RandomDay 이미 디스크에 대기 중인 샌드박스 파일이 다시 작성되지 않습니다.

<a id="recover-from-an-unsuccessful-update"></a>
## 실패한 업데이트에서 복구

첫 번째 지우기 실패 후 중지를 반복하면 어떤 프로필이 활성 상태인지, 어떤 프로필이 대기 중인지 확인하기가 더 어려워질 수 있습니다.

1. 게임이나 서버를 중지하세요.
2. 이동 실패한 설치는 삭제하지 말고 따로 보관하세요.
3. 전체를 복원하세요. RandomDay 업데이트 이전에 생성된 폴더 및 샌드박스 백업.
4. 한 번 시작하여 복원된 활성 및 준비된 프로필 이름을 확인하세요.
5. [문제 해결](%EB%AC%B8%EC%A0%9C_%ED%95%B4%EA%B2%B0.md) 첫 번째 누락되거나 실패한 단계에 대해 다른 단계를 시도하기 전에 업데이트하세요.
