# 보안 정책

> **표준 영어 소스:** [SECURITY.md](../../../SECURITY.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay 서버 구성 파일을 작성하고 선택적 모드 구성 파일을 패치할 수 있습니다. 변경 사항을 운영상 민감한 것으로 처리합니다.

<a id="do-not-report-as-security-issues"></a>
## 보안 문제로 보고하지 마세요

- 일반적인 게임플레이 밸런스 변경
- 다음 재부팅 프로필 교체가 예상됩니다.

<a id="report-privately"></a>
## 비공개로 보고하세요

- 경로 통과 위험.
- 안전하지 않습니다 파일 쓰기 동작.
- 의도한 server/mod 경로 외부의 파일을 덮어쓰는 기능.
- 악성 명령 실행.

공용 보안 채널이 존재할 때까지 저장소 소유자에게 비공개로 보고하십시오.
