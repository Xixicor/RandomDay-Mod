<a id="status-and-error-reference"></a>
# 상태 및 오류 참조

> **표준 영어 소스:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


런타임 내보내기의 정확한 `status`, `transaction_status`, `rollback_status` 및 `error` 값을 사용하십시오. 패널이나 콘솔의 비슷한 표현은 해당 필드를 대체하지 않습니다.

이 섹션은 전체 조회 참조입니다. 위의 결정 트리는 관련 카테고리를 선택합니다. 이 테이블은 정확한 기계 값과 안전한 작업자 응답을 보존합니다.

<a id="normal-or-informational-states"></a>
## 정상 또는 정보 상태

| 상태 | 의미 | 작업자 응답 |
|---|---|---|
| `prepared_for_next_reboot` | 다음 부팅을 위해 검증된 프로필이 작성되었습니다. | 조치 없음; 현재 세션은 변경되지 않습니다. |
| `next_reboot_already_prepared` | 의도한 다음 프로필이 이미 대상과 일치합니다. | 아무 작업도 없습니다. 다른 회전을 강요하지 마세요. |
| `already_current` / `unchanged` | 대상에 의도한 바이트가 이미 포함되어 있습니다. | 작업이 없습니다. |
| `applied` | 쓰기 및 프로덕션 다시 읽기가 통과되었습니다. | 다음 부팅 후 active/prepared 구별을 확인하세요. |
| `bootstrap_prepare_first_family_start_day` | 이전 회전 상태가 존재하지 않습니다. 그래서 구성된 첫날이 준비되었습니다. | 처음 사용 시 예상됩니다. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | 저장된 상태가 복구되었으며 동일한 준비된 프로필이 다시 작성되었습니다. | 복구된 날짜를 확인하세요. 새로운 무작위 선택이 발생하지 않았습니다. |
| `supervision_reconfirm_prepared_profile_no_advance` | 감독 통과를 통해 기존 준비가 확인되었습니다. | 예상; 대기열이 두 번 진행되지 않았습니다. |
| `external_mods_disabled` | 선택적 어댑터 처리가 비활성화되었습니다. | 어댑터가 의도된 것이 아니면 아무 작업도 수행되지 않습니다. |
| `external_mods_processed` | 활성화된 모든 어댑터 계획이 최종 결과에 도달했습니다. | 각 어댑터 행을 검토합니다. |

<a id="startup-configuration-errors"></a>
## 시작 구성 오류

이 메시지는 RandomDay 프로필을 작성하기 전에 시작을 중지합니다. 명명된 설정이나 패키지 마커를 수정하세요. 유효성 검사 분기를 우회하지 마세요.

| 오류 텍스트 | 의미 | 안전한 응답 |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode`이 누락되었거나 형식이 잘못되었거나 잘못된 패키지에서 왔습니다. | 완전한 패키지 하나를 깨끗한 준비 폴더에 다시 설치하고 의도한 모드 마커를 보존하세요. |
| `invalid experience.mode` | `experience.mode`는 문서화된 값 중 하나가 아닙니다. | `auto`, `persistent_dedicated`, `temporary_dedicated` 또는 `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | A 수동 복사 패키지가 전용 서버로 구성되었습니다. | 복원 `auto` 또는 `singleplayer_lan`; 자동으로 외부 세계를 가리키지 마세요. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | 수동 복사 작업 흐름을 위해 전용 패키지가 구성되었습니다. | `auto`, `persistent_dedicated` 또는 `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | 초기 날짜 선택기가 유효하지 않습니다. | 정확히 사용하세요. `configured` 또는 `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | 날짜 순서 선택기가 유효하지 않습니다. | 정확히 사용하세요. `sequential` 또는 `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | 구성된 시작일이 소수이거나 날짜 범위를 벗어났습니다. 주기. | 1부터 `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | 백업 또는 마지막 복원이 비활성화되었습니다. | 두 안전 잠금 장치를 모두 복원하세요. RandomDay 안전하지 않은 쓰기를 의도적으로 거부합니다. |
| `external adapter transaction safety locks must remain true` | 어댑터 패치 또는 백업 보호가 비활성화되었습니다. | 두 어댑터 안전 잠금 장치를 모두 복원하거나 어댑터를 그룹으로 비활성화합니다. |
| `paths.world_name must be one folder name` | 구성된 전체 이름에 구분 기호나 안전하지 않은 문자가 포함되어 있습니다. | 문자, 숫자, 공백을 사용하여 정확한 폴더 이름만 입력하세요. 밑줄 또는 하이픈. |
| `required runtime directory unavailable` | 필요한 mod-local 출력 디렉터리를 생성하거나 확인할 수 없습니다. | 이름이 지정된 항목만 확인하세요RandomDay 디렉토리 및 쓰기 권한. |

<a id="profile-wide-configuration-errors"></a>
## 프로필 전체 구성 오류

이러한 오류는 샌드박스 쓰기 전에 프로필 구성을 중지합니다.

| 오류 텍스트 | 의미 | 안전한 응답 |
|---|---|---|
| `sandbox.profile_overrides must be a table` | 네 가지 프로필 전체 선택 항목이 다른 Lua 유형으로 대체되었습니다. | 문서화된 테이블을 `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | 테이블에 포함된 설정이 지원되는 네 가지 키 중 하나가 아닌 설정으로 포함되어 있습니다. | 이름이 지정된 키를 제거하고 family/profile다른 샌드박스 설정 소스를 사용하세요. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` 또는 `AllowIronMode`는 `true` 또는 `false`. | 따옴표가 없는 Lua 부울을 사용하세요. |
| `sandbox.profile_overrides.<key> must be integer` | 지원 값이 정수가 아닙니다. | 정수를 사용하세요. |
| `sandbox.profile_overrides.<key> outside supported range` | 지원 값이 `0..1000`. | 다음에서 정수를 선택하세요.`0`부터 `1000`. |

<a id="rollback-and-intermediate-states"></a>
## 롤백 및 중간 상태

| 값 | 의미 | 안전한 응답 |
|---|---|---|
| `not_started` / `pending` | 트랜잭션 또는 어댑터 계획이 최종 결과에 도달하지 않았습니다. | 현재 제한된 시작 패스만 기다리세요. 지속적인 상태에서는 조사가 필요합니다. |
| `not_needed` | 롤백이 필요하지 않았습니다. | 작업이 없습니다. |
| `original_held` | 원래 대상이 승격되기 전에 복구 위치로 이동되었습니다. | 트랜잭션이 완료되지 않은 동안 복구 파일을 삭제하지 마세요. |
| `retained_after_success` | 새 대상이 확인되었지만 정리가 불가능하거나 의도적으로 보관되었기 때문에 복구 데이터가 남아 있습니다. | 이름이 지정된 복구 파일을 제거하기 전에 프로덕션 바이트를 확인하세요. |
| `discarded_after_success` | 확인된 대체 데이터와 임시 롤백 데이터가 삭제되었습니다. | 작업이 없습니다. |
| `rollback_failed` | 복원 시도를 확인할 수 없습니다. | 서버를 중지한 상태로 유지하고 마지막으로 확인된 작업 백업을 사용하세요. |
| `skipped_state_persistence_failed` | 샌드박스 바이트가 준비되었지만 회전 상태가 그렇지 않았습니다. 지속되므로 어댑터와 준비된 플레이어 메시지를 건너뛰었습니다. | 런타임 상태 저장소를 복구합니다. 대기열을 수동으로 다시 시작하거나 진행하지 마세요. |
| `failed` | 요약 행은 `error` 또는 거래 필드에 구체적인 원인이 있는 최종 오류를 나타냅니다. | 첫 번째 특정 코드를 따르세요. `failed` 단독으로 문제를 해결하지 마세요. |

<a id="transaction-failures"></a>
## 트랜잭션 실패

| 상태 | 의미 | 안전한 응답 |
|---|---|---|
| `invalid_input` | 교체 요청에 유효한 텍스트가 없거나 유효한 대상이 없습니다. | 올바른 구성입니다. 변경하지 않고 재시도하지 마세요. |
| `stale_pending_cleanup_failed` | 오래된 보류 파일을 제거할 수 없습니다. | 수동 정리 전에 보류 중인 파일을 중지하고 보존하세요. |
| `stale_rollback_requires_review` | 복구 데이터는 현재 대상 옆에 존재하며 안전하게 삭제할 수 없습니다. | 둘 중 하나를 선택하기 전에 대상 바이트와 롤백 바이트를 비교하세요. |
| `interrupted_transaction_restore_failed` | 중단된 교체 후 복구에서는 대상을 복원할 수 없습니다. | 서버를 중지한 상태로 유지하고 확인된 백업을 복원하십시오. |
| `interrupted_transaction_cleanup_failed` | 대상은 복구되었지만 오래된 트랜잭션 데이터를 지울 수 없습니다. | 대상 바이트를 확인한 다음 명명된 오래된 사이드카만 제거하세요. |
| `pending_write_failed` | 후보를 쓸 수 없습니다. | 좁은 대상 디렉터리와 여유 공간을 확인하세요. |
| `pending_readback_failed` / `pending_readback_mismatch` | 쓰기 후 후보 바이트를 읽거나 다를 수 없습니다. | 보류 중인 파일을 승격하지 마세요. |
| `pending_validation_failed` | 후보가 이전에 검증에 실패했습니다. schema/profile 프로모션. | 보고된 키 또는 규칙을 수정하세요. 검증을 우회하지 마십시오. |
| `operation_backup_failed` / `backup_failed` | 검증된 사전 쓰기 백업이 생성되지 않았습니다. | 그만하세요. 대체 대상은 신뢰할 수 없습니다. |
| `original_preserved_move_failed` | 원래 대상을 복구 위치로 이동할 수 없습니다. | 모든 트랜잭션 파일을 보존하고 수동으로 복구하십시오. |
| `promotion_failed` | 보류 중인 후보가 프로덕션 대상이 될 수 없습니다. | 재시도하기 전에 원본이 복원되었는지 확인하세요. |
| `production_validation_failed` | 승격된 바이트가 프로덕션에 실패했습니다. readback/validation. | 확인된 백업을 복원하고 대상 작성자를 검사합니다. |
| `replacement_committed_recovery_cleanup_failed` | 교체가 유효하지만 롤백 데이터를 지울 수 없습니다. | 대상을 커밋된 것으로 처리합니다. 확인된 오래된 복구 데이터만 제거하세요. |
| `rollback_failed` | 자동 복원이 확인되지 않았습니다. | 서버를 중지한 상태로 두고 수동 복구를 사용하세요. |

<a id="target-profile-adapter-and-export-failures"></a>
## 대상, 프로필, 어댑터 및 내보내기 실패

| 상태 | 의미 | 안전한 응답 |
|---|---|---|
| `target_refused` | 구성된 경로가 허용 모드 경계를 벗어났습니다. | 수정하세요. 경로; 경계를 약화시키지 마세요. |
| `target_directory_failed` | 대상 디렉터리를 생성하거나 확인할 수 없습니다. | 해당 디렉터리의 존재와 권한만 확인하세요. |
| `profile_validation_failed` | 프로필에 키가 없거나, 잘못된 type/range가 있거나, 나머지 불변 규칙을 위반합니다. | 이름이 지정된 키를 사용하세요. `sandbox.profile_overrides`및 소스 복구를 위한 프로필 참조. |
| `skipped_incompatible` | 선택적 모드가 존재하지만 지원되는 어댑터 서명과 일치하지 않습니다. | 변경하지 않고 그대로 두거나 해당 어댑터를 비활성화하세요. |
| `external_mods_partial` | 일부 선택 어댑터는 완료되었고 나머지는 안전하게 완료되었습니다. skipped/failed. | 어댑터 행을 독립적으로 검토하세요. 샌드박스 결과는 별개입니다. |
| `external_adapter_failed` | 필요한 어댑터가 안전하게 완료되지 않았습니다. | 다시 시도하기 전에 확인된 백업을 복원하세요. |
| `degraded_state_persistence` | 샌드박스 준비가 완료되었지만 회전 상태 지속성이 완료되지 않았습니다. | 다음 부팅이 올바르게 진행될 수 있다고 가정하지 마세요. 상태 저장소를 복구하세요. |
| `export_directory_failed` | `web_export/` 생성하거나 쓸 수 없습니다. | 게임플레이 준비가 여전히 유효할 수 있습니다. 보고는 별도로 수리하세요. |

<a id="translation-and-message-validation-errors"></a>
## 번역 및 메시지 유효성 검사 오류

이러한 오류는 사전 또는 프리젠테이션 계약 오류입니다. 릴리스 전에 검증되며 제한된 런타임 상태 경고로 나타날 수도 있습니다.

| 오류 텍스트 | 의미 | 안전한 응답 |
|---|---|---|
| `dictionary coverage mismatch` | 프로필 사전이 문서화된 모든 설정을 설명하지는 않습니다. | 누락된 사전 항목을 추가하고 프로필을 다시 실행하세요. generation/validation. |
| `missing profile setting` | 선택한 프로필에 dictionary/schema. | 프로필 계열 소스를 복구하는 데 필요한 설정이 없습니다. 런타임 기본값을 만들지 마세요. |
| `empty explanation` | 설정이 존재하지만 operator/player 설명이 없습니다. | 릴리스 전에 일반 언어 설명을 추가하세요. |
| `join line too wide` | 생성된 조인 라인이 42자 소스 제한을 초과합니다. | 사전 문구를 줄이세요. 클라이언트 래핑에 의존하지 마세요. |
| `join message too tall` | 생성된 조인 요약이 4줄을 초과합니다. | 메시지 내용을 줄이거나 우선순위를 다시 지정하세요. |
