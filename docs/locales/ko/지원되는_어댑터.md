# 지원되는 선택적 모드

> **표준 영어 소스:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay 별도로 설치된 모드를 활성 모드를 따르도록 할 수 있습니다 RandomDay 프로필. 이 기능은 전용 서버 패키지에서만 사용할 수 있습니다. singleplayer/LAN 패키지는 다른 모드를 절대 편집하지 않습니다.

RandomDay는 여기에 나열된 모드를 포함하거나 재배포하지 않습니다. 자체 Nexus 페이지에서 각 선택적 모드를 설치 및 활성화하고 먼저 작성자의 지침을 따르세요. RandomDay은 설치된 파일에 이미 존재하는 인식된 설정만 변경합니다. 다른 모드에 기능을 추가하지 않으며 해당 모드를 제거하지 않고도 어댑터를 비활성화할 수 있습니다. 전용 서버 패키지는 `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## 뭐야 RandomDay 변경 사항

| 선택적 통합 | 활성 프로필에서 선택한 설정 |
| --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | 하드 모드, player/area 쿨다운 동작, 폭풍 및 핫존 활동, 보스 및 버스트 생성, 생성 주기 타이밍, 소형 및 대형 쿨다운 범위, 생성 거리, global/local/mod 캡, 포털 폭풍, 명령 위반 및 보스 확률, 지역당 최소 스폰 수. |
| 선택적 Chaotic Spawn Engine 확장 필드 | 설치된 `SharedData.lua`이미 RandomDay 확장 필드에서 어댑터는 만남 프로필, 계층, 테마, 그룹 제한, 특별 이벤트 및 혼합 만남 값, 예산, 재사용 대기시간 및 세계 범위 제어를 제공할 수 있습니다. 이것은 다운로드할 또 다른 모드가 아닙니다. |
| 치명적인 레이저 | 모드 활성화와 손상 및 배포 가능한 이미터, 환경 이미터, 반사경 및 프리즘에 대한 제어를 활성화합니다. |
| ANTE Up | Respawn-주파수 승수, Antevariant 주파수 및 기존 development/debug 스위치. RandomDay 인식된 모든 개발 및 디버그 스위치를 꺼진 상태로 유지합니다. |

프로필 라이브러리는 지원되는 모든 날짜에 대해 준비된 값 세트를 제공합니다. 조용한 날은 압력을 줄일 수 있고, 위험한 날은 압력을 높일 수 있으며, 회복의 날은 압력을 급격히 줄일 수 있습니다. RandomDay은 부팅 시 임의의 값을 계산하지 않습니다. 활성 프로필에 의해 명명된 검토된 값 집합을 적용합니다.

<a id="how-recognition-protects-another-mod"></a>
## 인식이 다른 모드를 보호하는 방법

익숙한 파일 이름을 찾는 것만으로는 충분하지 않습니다. 글을 쓰기 전에 RandomDay은 해당 어댑터에 필요한 모든 설정이 대상 파일에 있는지 확인합니다. 기존 할당만 패치합니다. 누락된 설정을 만들어내는 일은 결코 없습니다.

인식된 레이아웃의 경우 RandomDay 하나의 제한된 트랜잭션을 수행합니다:

1. 활성 프로필에 대해 의도한 모든 값을 계산합니다.
2. 모든 대상 파일의 백업을 생성하고 바이트 확인합니다.
3. 형제 보류 파일을 통해 쓰기;
4. 보류 중인 파일을 승격하고 저장된 바이트를 다시 읽습니다.
5. 모든 의도된 값을 확인하세요.
6. 단계 하나라도 실패하면 확인된 백업에서 자동 복원을 사용합니다.

DynamicSpawns는 하나의 트랜잭션에 해당 설정과 인식된 플레이어 메시지 파일을 포함할 수 있습니다. RandomDay는 전체 트랜잭션이 완료되지 않는 한 다중 파일 업데이트가 성공한 것으로 보고하지 않습니다.

<a id="read-an-adapter-result"></a>
## 어댑터 결과 읽기

| 결과 | 의미 |
| --- | --- |
| `applied` | 인식된 설정이 변경되어 다시 읽기를 통과했습니다. |
| `already_current` | 인식된 설정이 이미 활성 프로필과 일치합니다. |
| `not_installed` | 선택적 모드를 찾을 수 없습니다. RandomDay 없이 계속 진행됩니다. |
| `skipped_incompatible` | 파일을 찾았지만 전체 설정 레이아웃이 인식되지 않았습니다. 아무것도 변경되지 않았습니다. |
| `partial` | 기본 DynamicSpawns 설정이 적용되었지만 선택적 번역 메시지 파일이 완료되지 않았습니다. 기록된 어댑터 결과를 검토하세요. |
| `failed_rolled_back` | 트랜잭션이 실패했으며 이전 바이트는 그대로 유지되거나 복원 및 확인되었습니다. |
| `rollback_failed` | RandomDay 변경 또는 복원을 확인할 수 없습니다. 영향을 받은 모드를 중지된 상태로 유지하고 기록된 백업을 수동으로 복원하세요. |

누락 및 호환되지 않는 선택적 모드가 중지되지 않음 RandomDay's 제공된 구성에 따른 샌드박스 회전.

<a id="enable-or-disable-integrations"></a>
## 통합 활성화 또는 비활성화

컨트롤은 다음과 같습니다.

```text
RandomDay/Scripts/ax_config/server.lua
```

전용 서버 패키지는 다음과 함께 제공됩니다:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- `enabled = false` 중지하려면 RandomDay모든 선택적 모드를 검사하거나 변경할 수 없습니다.
- 다른 통합을 활성 상태로 유지하면서 해당 모드를 그대로 두려면 어댑터 ID 하나를 제거하세요.
- `patch_only_existing_keys` 및 `backup_before_write`를 `true`로 설정하세요. 이는 쓰기 안전 경계입니다.
- `optional_by_default = true` 나열된 모든 선택적 모드가 서버의 필수 부분이 아닌 한. `false`로 설정하면 누락되거나 호환되지 않거나 안전하게 롤백된 어댑터가 집계 결과에 영향을 미칩니다.

선택적 모드를 비활성화할 때 해당 옵션 모드를 제거하거나 비활성화할 필요는 없습니다. RandomDay 어댑터.

<a id="backups-and-manual-recovery"></a>
## 백업 및 수동 복구

검증된 사전 쓰기 복사본은 다음 위치에 보관됩니다.

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

만약 `rollback_failed` 표시:

1. 게임 또는 서버 중지;
2. 설정 `external_mods.enabled = false` 또는 영향을 받은 어댑터 ID를 제거하세요.
3. 현재 대상 파일과 그 형제 파일을 보존합니다 pending/rollback 파일;
4. 번호가 지정된 백업 파일을 어댑터 결과에 기록된 대상 경로와 일치시킵니다.
5. 서비스가 중지된 동안 확인된 바이트를 복원합니다.
6. 선택적 모드를 다시 활성화하기 전에 자동으로 시작하세요RandomDay 어댑터.

설정 이름을 바꾸거나 누락된 키를 추가하여 호환성을 강요하지 마세요. 인식된 레이아웃을 사용하거나, 어댑터를 비활성화한 상태로 두거나, 지원 요청을 확장하기 전에 새 버전 픽스처 및 트랜잭션 테스트를 추가하세요.
