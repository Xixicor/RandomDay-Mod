# RandomDay 한국어 안내

> [!IMPORTANT]
> ## 프로젝트 상태 — RandomDay 테스트 종료
>
> RandomDay 테스트 운영이 완료되었으며 공개 테스트 서버는 곧 종료됩니다.
>
> 이번 운영에서 RandomDay와 RandomDayGuard는 반복적인 프로필 순환, 정상 및 중단된 서버 재시작, 복구와 롤백 점검, 확장 모드 통합, 서버 증거 수집, 운영자 보고서 검토를 함께 거쳤습니다.
>
> 이를 통해 목표했던 지식을 얻었습니다. 실제 전용 서버 수명 주기 전체에서 순환 sandbox 프로필이 어떻게 작동하는지, RandomDay가 지원되는 확장 모드와 어떻게 상호작용하는지, 그리고 RandomDayGuard가 누락이나 추측을 사실로 제시하지 않으면서 서버가 기록한 증거를 어느 정도까지 유용하고 신중한 모니터링으로 바꿀 수 있는지 확인했습니다.
>
> **테스트 서버에서 사용한 구성:**
>
> - RandomDay 비공개 개발 빌드 `v0.41.76`
> - RandomDayGuard 비공개 개발 빌드 `v0.46.130`
> - Chaotic Spawn Engine / DynamicSpawns `0.8.5 Hotfix 1`
> - Lethal Lasers `1.0 UE4SS`
> - ANTE Up `0.26`
> - Encounter Director integration — RandomDay가 소유한 DynamicSpawns 확장이며 별도로 배포되는 모드가 아님
> - UE4SS `v3.0.1 Beta #0` (Git `01e0a584`; Nexus `v3.0.1-940-g01e0a584`)
> - Abiotic Factor 전용 서버 `1.4.0.27939`
>
> 현재 공개된 패키지는 계속해서 RandomDay `v0.3.16-alpha`와 RandomDayGuard `v0.4.12-alpha`입니다.
>
> 두 프로젝트의 개발은 현재 일시 중지되었습니다. 기존 릴리스와 문서는 계속 제공되며, 다시 이 작업을 이어가고 싶을 때 돌아올 수 있습니다.
>
> 이 구성은 운영 중 사용된 항목을 기록한 것입니다. 최소 버전 요구 사항이나 이후 게임, loader 또는 모드 버전과의 호환성 보장이 아닙니다. 마지막으로 공식 기록된 주기에서는 Abiotic Factor `1.4.0.27939`를 사용했습니다.

**v0.3.16-alpha**

RandomDay는 다음 Abiotic Factor 시작에 사용할 완전한 `SandboxSettings.ini`를
준비합니다. 현재 세션이 이미 불러온 규칙은 바꾸지 않으며, 활성 프로필과 준비된
프로필을 분리하여 관리합니다.

## 설치와 확인

[설치 안내](%EC%84%A4%EC%B9%98.md)를 따르십시오. 올바른 위치는
`ue4ss/Mods/RandomDay`이고 `mods.txt`에는 `RandomDay : 1`이 있어야 합니다.
일반적으로 첫 시작은 준비하고, 이후 시작이 준비된 프로필을 활성화합니다.

`runtime/current/randomday_status.json`, `runtime/rotation_state.txt`,
`web_export/today.json`을 확인하십시오. 세 파일의 활성 및 준비된 식별자가 서로
일치해야 합니다.

## 플레이 방식 선택

모드, 패밀리, 시작일, 진행 방식은 `RandomDay/Scripts/ax_config/server.lua`에서
설정합니다. [시작](%EC%97%AC%EA%B8%B0%EC%84%9C_%EC%8B%9C%EC%9E%91.md), [프로필 선택](%ED%94%84%EB%A1%9C%ED%95%84_%EC%84%A0%ED%83%9D.md),
[설정](%EA%B5%AC%EC%84%B1.md), [운영](%EC%9E%91%EC%97%85.md)을 참고하십시오.

`HardcoreMode=False`, `AllowIronMode=False`, `StructuralSupportLimit=0`,
`BridgeSupports=0`은 이 릴리스의 기본값이며 고정된 게임 규칙이 아닙니다.
[고급 설정](%EA%B5%AC%EC%84%B1.md#customize-the-shipped-profile-defaults)은 지속적인 변경 방법을 설명합니다.

명령, 경로, 키, 상태 값은 실제 파일과 맞도록 영어를 유지합니다.

## 알파 릴리스와 유지되는 선택값

이 버전은 알파입니다. 문서화된 설치, 순환, 복구 경로는 테스트했으며 호환성과 사용 편의성은 계속 개선 중입니다.

`RandomDay/Scripts/ax_config/server.lua`의 `sandbox.profile_overrides`는 네 값을 모든 패밀리와 날짜에 유지합니다. 서버를 멈추고 한 번 수정한 뒤 다시 시작하세요. 이후 순환과 시작에도 같은 값이 사용됩니다. `SandboxSettings.ini`만 바꾸면 일시적입니다.

- [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156)
- [Lethal Lasers](https://www.nexusmods.com/abioticfactor/mods/141)
- [ANTE Up](https://www.nexusmods.com/abioticfactor/mods/201)

아래 선택 모드는 각 제작자가 따로 배포합니다. RandomDay는 이를 재배포하거나 기능을 바꾸지 않으며, 활성화된 어댑터는 이미 존재하는 지원 설정만 조정합니다. 제작자와 유지관리자께 감사드립니다.
