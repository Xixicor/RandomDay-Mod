# 용어집

> **표준 영어 소스:** [GLOSSARY.md](../../GLOSSARY.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이것은 RandomDay 문서입니다. 절차는 여러 가이드에서 동일한 상태를 재정의하는 대신 이러한 정의에 연결됩니다. 스키마별 필드 규칙은 [런타임 출력](%EB%9F%B0%ED%83%80%EC%9E%84_%EC%B6%9C%EB%A0%A5.md).

| 용어 | 일반적인 의미 | 정확한 기술적 의미 |
|---|---|---|
| 활성 프로필 | 현재 세션이 사용하는 규칙입니다. | family/day RandomDay 프로세스 시작 시 샌드박스에서 마커를 읽습니다. |
| 준비된 프로필 | 나중 세션을 위해 준비된 규칙. | 대상 바이트가 검증 및 다시 읽기를 통과했고 회전 상태가 다시 읽기 전에 커밋된 전체 family/day 프로필입니다. |
| 복원됨 | 준비가 실패했으며 이전에 확인된 바이트가 다시 보관되었습니다. | 실패한 트랜잭션은 보관된 원본 또는 확인된 복구 복사본의 성공적인 롤백 및 읽기를 보고합니다. |
| 다음 재부팅 대기열 | 다음 부팅을 위해 준비된 선택 하나가 유지됩니다. | `next_reboot_queue` 프로세스당 한 번 선택하고 감독 중에 해당 부팅 소유 선택을 재사용합니다. |
| 부트스트랩 | 활성 마커가 없을 때 첫 번째 준비. | 적격 제품군에서 구성된 또는 무작위 첫날 선택 `cycle.bootstrap_day`은 호환성 대체일 뿐입니다. |
| 가족 | 17일간의 플레이스타일 진행. | 정확히 17개의 완전한 프로필을 생성하는 하나의 레지스트리 항목 및 가족 모듈. |
| 회전 | 적격 가족을 통과합니다. | 사용 가능한 가족, 남은 가족, 완료된 가족과 함께 `rotation_id`로 식별된 상태 목록. |
| 실행 | 17일 ID 전체에 걸쳐 하나의 패밀리. | `run_id`로 식별되는 패밀리 바인딩 시퀀스; 모든 지속되는 일일 주문 위치가 완료될 때까지 가족은 잠긴 상태로 유지됩니다. |
| 세션 모드 | 운영자가 이 패키지를 사용하는 방법. | `persistent_dedicated`, `temporary_dedicated` 또는 `singleplayer_lan`; 패키지 모드는 여전히 파일 시스템 경계를 제어합니다. |
| 일 순서 | 한 계열 실행에서 사용되는 정확한 순서. | 지속되는 17자리 숫자 순열. 순차 모드는 시작일부터 종료됩니다. 무작위 모드는 반복 없이 한 번 섞입니다. |
| 마커 | 샌드박스 파일에 저장된 ID. | `RANDOMDAY_*` 필드는 전체 프로필로 렌더링되고 다음 프로세스 시작 시 읽혀집니다. |
| 준비 완료 | 쓰기 및 상태 커밋이 성공했습니다. | `prepared_ready=true`에는 성공적인 샌드박스 결과가 필요하고 상태 커밋 실패가 없어야 합니다. 활성화를 증명하지 않습니다. |
| 이미 현재 | 대상에 이미 의도한 바이트가 있습니다. | 렌더링된 프로필 해시가 대상과 일치하므로 RandomDay 확인 last-good/mirror 기본을 다시 작성하지 않고도 작동합니다. |
| 상태 지속성 저하 | 샌드박스 바이트는 성공했지만 회전 기록은 실패했습니다. | `profile_status=degraded_state_persistence`; 어댑터 및 준비된 프로필 메시지는 건너뜁니다. |
| 보류 중인 파일 | 후보 바이트는 아직 승격되지 않았습니다. | `<target>.randomday.pending`, 교체 전에 작성, 다시 읽기 및 검증되었습니다. |
| 롤백 파일 | 교체 중에 원본이 유지됩니다. | `<target>.randomday.rollback`, 승격 또는 검증 실패 시 생산을 복원하는 데 사용됩니다. |
| 작업 백업 | 변이 전에 만들어진 내구성 있는 복사본. | 기본, 미러 또는 어댑터 트랜잭션에 대해 `runtime/backups/`에서 확인된 파일. |
| 마지막으로 알려진 양호한 | 복구에 허용된 최신 샌드박스. | `runtime/last_good/SandboxSettings.ini` 플러스 `manifest.lua`; 쌍은 프로필 ID와 해시를 기록합니다. |
| 미러 | 선택적인 두 번째 샌드박스 대상. | 자체 트랜잭션을 통해 기본 대상 다음에 작성된 명시적으로 구성되거나 세계 이름에서 파생된 대상. |
| 패키지 모드 | 릴리스에서 선택한 설치 경계 자산. | `dedicated_server` 또는 `singleplayer_manual` `.randomday_mode`. |
| 수동 복사 모드 | Singleplayer/LAN 저장 검색 없이 생성. | `singleplayer_manual` 내부에만 씁니다 `runtime/singleplayer_manual/`어댑터와 미러를 비활성화합니다. |
| 어댑터 | RandomDay-owned 설치된 다른 모드에 대한 매핑 | 백업 및 호환성 확인 후에만 기존 할당을 업데이트하는 서명 기반 트랜잭션 계획입니다. |
| 인식된 레이아웃 | 쓰기에 허용되는 정확한 어댑터 파일 형태입니다. | 필요한 서명 키와 대상 파일이 모두 존재합니다. 파일 이름만으로는 부족합니다. |
| `not_installed` | 선택적 대상을 찾을 수 없습니다. | 변이가 없는 안전한 어댑터 결과. |
| `skipped_incompatible` | 대상이 존재하지만 해당 모양이 지원되지 않습니다. | 완전한 서명이 일치하지 않았기 때문에 변형이 없는 안전한 어댑터 결과입니다. |
| `failed_rolled_back` | 변경이 실패했으며 이전 바이트는 그대로 유지됩니다. | 변이가 발생하거나 영향을 받은 모든 파일이 복원 및 확인되기 전에 어댑터 트랜잭션이 실패했습니다. |
| `rollback_failed` | 자동 복구를 확인할 수 없습니다. | 기록된 백업에서 수동 복구가 필요한 하드 스톱 어댑터 상태입니다. |
| 사전 | 원시 값에서 공개 설명으로 매핑 | `randomday_dictionary_v2`, `dictionary.lua`런타임 상태 출력에 포함됩니다. |
| 번역 | 원본 프로필 값에서 파생된 사람의 관점 | 에서 생성된 제한된 도메인 점수, 사실, 요약 및 메시지`translation.lua`; 원시 값은 신뢰할 수 있는 상태로 유지됩니다. |
| 공개 상태 | 삭제된 기계 판독 가능 연산자 요약. | `web_export/today.json` `randomday_public_status_v2`. |
| 런타임 상태 | 상세한 로컬 기계 판독 가능 스냅샷 사용. | `runtime/current/randomday_status.json` `randomday_runtime_status_v2`. |
