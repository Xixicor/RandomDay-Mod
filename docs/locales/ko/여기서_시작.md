# 여기에서 시작: 첫 번째 완료 RandomDay 주기

> **표준 영어 소스:** [START_HERE.md](../../START_HERE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이 가이드는 RandomDay 설치 후 시작됩니다. 모드가 변경하는 내용, 그대로 두는 내용, 성공적인 주기를 인식하는 방법을 보여줍니다.

<a id="know-the-two-states"></a>
## 두 가지 상태를 파악하세요

Abiotic Factor는 RandomDay가 시작되기 전에 세계의 샌드박스 설정을 읽습니다. RandomDay 따라서 두 가지 명확한 이름의 상태를 유지합니다.

- **활성 프로필:** 현재 세션이 이미 사용하고 있는 규칙.
- **준비된 프로필:** 다음 시작을 위해 저장된 규칙.

준비된 프로필은 이미 진행 중인 세션을 변경하지 않습니다.

<a id="dedicated-server-prepare-the-next-profile"></a>
## 전용 서버: 다음 프로필 준비

1. 서버를 정상적으로 시작하세요.
2. RandomDay가 시작 작업을 완료할 때까지 기다립니다.
3. 설치된 mod 폴더에서 `RandomDay/web_export/today.html`를 엽니다.
4. 찾기 **활성 프로필** 및 **준비된 프로필**.

처음 성공적으로 시작하면 페이지는 이미 활성화된 규칙과 다음 프로필을 기다리는 다른 프로필의 이름을 지정해야 합니다. 시작합니다. 이 페이지에는 선택한 제품군, 위치, 준비된 파일이 안전 검사를 통과했는지 여부도 설명되어 있습니다.

단순히 상태 변경을 위해 다시 시작하지 마세요. 다음 계획된 서버가 시작될 때까지 활성 규칙을 계속 사용하세요.

<a id="dedicated-server-activate-it-later"></a>
## 전용 서버: 나중에 활성화

1. 다음 계획된 재시작 시 서버를 중지했다가 시작하세요.
2. 읽기 가능한 상태 페이지를 다시 엽니다.
3. 이전에 준비한 프로필이 이제 활성 상태로 표시되는지 확인하세요.
4. RandomDay가 다음 프로필을 준비했는지 확인하세요.

준비-후 활성화 전환이 하나의 완료입니다. RandomDay 주기.

<a id="temporary-dedicated-servers"></a>
## 임시 전용 서버

임시 동작은 동일한 전용 서버 패키지를 사용합니다. [구성](%EA%B5%AC%EC%84%B1.md)에서 새 실행이 특정 프로필에서 시작되는지 아니면 임의의 시작점을 선택할지 선택합니다. 상태 페이지는 다음 시작을 위해 준비된 프로필과 활성 프로필을 계속 분리합니다.

<a id="singleplayer-or-lan"></a>
## 싱글 플레이어 또는 LAN

1. 패키지가 설치된 singleplayer/LAN게임을 한 번 시작하세요.
2. RandomDay 완료 후 게임을 완전히 닫습니다.
3. 생성된 요약을 읽어보세요.
4. 생성된 프로필을 복사하세요 `SandboxSettings.ini` 게임이 종료되는 동안 선택한 세계로 들어가세요.
5. 해당 세계를 시작하고 예상되는 규칙을 확인하세요.

로컬 패키지는 절대로 세계를 선택하거나 파일을 저장 공간에 자체적으로 복사하지 않습니다. 전체 절차는 [싱글플레이어 및 LAN](%EC%8B%B1%EA%B8%80_%ED%94%8C%EB%A0%88%EC%9D%B4%EC%96%B4_LAN.md)를 참조하세요.

<a id="if-the-expected-result-is-missing"></a>
## 예상한 결과가 누락된 경우

계속 다시 시작하지 마세요. 현재 파일을 보존하고 [문제 해결](%EB%AC%B8%EC%A0%9C_%ED%95%B4%EA%B2%B0.md)에서 일치하는 증상을 선택하세요. 일반적인 결과는 항상 활성 프로필과 준비된 프로필 또는 명확한 준비 실패 중 하나를 지정합니다.
