<a id="release-validation"></a>
# 출시 확인

> **표준 영어 소스:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이 페이지는 기여자와 릴리스 관리자를 위한 것입니다. 모드를 설치하는 플레이어는 이러한 명령을 실행할 필요가 없습니다.

<a id="ordinary-user-proof"></a>
## 일반 사용자 증명

새로운 독자가 두 패키지 중 하나를 선택하여 설치하고, 활성 프로필과 준비된 프로필을 식별하고, 링크된 가이드를 따라 누락된 결과를 복구할 수 있으면 릴리스가 이해될 수 있습니다. 이러한 독자 작업에는 Git이 필요하지 않아야 합니다. PowerShell, Python 또는 체크섬 지식.

<a id="contributor-checks"></a>
## 기여자 확인

저장소 루트에서 실행:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

언제 `luac`을 사용할 수 있습니다. 배송된 모든 Lua 파일의 구문을 확인하세요.

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

Lua 런타임 테스트에는 `lupa`. Lua 통역사가 없거나 `lupa` 설치는 통과 결과가 아니라 사용할 수 없는 테스트 기능입니다.

<a id="release-checks"></a>
## 출시 확인

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

릴리스 확인을 통해 다음 조건을 확인합니다:

- `VERSION` 및 `RandomDay/.randomday_version` 일치합니다.
- 아래에는 현재 버전만 존재합니다`releases/`.
- 전담 및 singleplayer/LAN ZIP은 완전한 대안입니다.
- 두 아카이브 모두 표준 `RandomDay/Scripts/main.lua` 경로가 있고 대소문자 충돌 로더가 없습니다.
- 패키지 모드 마커는 `dedicated_server` 및 `singleplayer_manual`.
- ZIP 바이트는 결정적이며 일치합니다. `CHECKSUMS.sha256`.
- 런타임 데이터, 개인 구성, 자격 증명, 캐시 또는 테스트 출력이 패키지되지 않습니다.
- 모든 로컬 문서 링크와 27개의 로케일 항목 페이지가 검증됩니다.

<a id="avoid-validation-environment-pitfalls"></a>
## 검증 환경의 함정을 피하세요

- 두 프로세스가 한 번에 동일한 임시 파일을 대체하지 않도록 저장소 쓰기 검사를 순차적으로 실행하세요.
- Windows에서는 ZIP 소문자 로더 존재 여부를 결정하기 위해 대소문자를 구분하지 않는 파일 조회를 사용하는 대신 멤버 이름을 확인하세요.
- 확인 `mods.txt` 및 `enabled.txt` 설치된 서버 테스트에서만 가능합니다. 이는 소스 테스트가 실행되었다는 증거가 아닙니다.
- 명령 시간 초과를 불완전한 것으로 기록하세요. 명령의 제한된 출력 없이 통과 또는 실패로 변환하지 마세요.
- 임시 파일을 저장소의 무시된 내부에 보관하세요. `.tmp/` 디렉토리.

<a id="known-limits"></a>
## 알려진 제한

로컬 검증은 소스, 패키지, 문서 및 고정 장치 계약을 증명합니다. 특정 서버 패널의 시작 순서, 라이브 클라이언트의 메시지 레이아웃 또는 호스트별 파일 시스템 경로를 증명하지 않습니다. 이를 테스트할 때 별도의 통합 결과로 기록합니다.
