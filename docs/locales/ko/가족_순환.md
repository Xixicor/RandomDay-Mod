# 열일곱 가족, 열일곱일

> **표준 영어 소스:** [FAMILY_ROTATION.md](../../FAMILY_ROTATION.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay 17개의 플레이스타일 패밀리가 포함되어 있으며 각 패밀리에는 17개의 완전한 일일 프로필이 있습니다. 289개의 문서가 생성됩니다. family/day 조합.

가족이 다양한 달리기 스타일을 결정합니다. 1일부터 17일까지는 가족의 압박감, 회복, 속도 및 자원의 발전을 제공합니다. 실행은 매일 ID를 포함하는 하나의 주문을 정확히 한 번만 저장합니다. 재시작은 다음 저장된 위치로 진행됩니다. RandomDay 주문 중간에 가족을 변경하지 않습니다.

<a id="selection-modes"></a>
## 선택 모드

| 모드 | 새 실행 동작 | 실행 중 |
|---|---|---|
| `selected_run` | `profile_family.selected_family`. | 17개의 저장된 위치 전체에서 해당 가족을 유지합니다. |
| `non_repeating_random_run` | 적격한 미사용 가족을 선택합니다. | 17개 직위를 모두 유지하고 적격 목록이 소진될 때까지 가족 반복을 방지합니다. |
| `rotation_run` | 구성된 순서대로 다음 계열을 가져옵니다. | 17개의 저장된 위치를 모두 유지합니다. |

제공된 구성은 `non_repeating_random_run`. 최종 저장 위치 이후에 준비된 패밀리는 여전히 준비만 되어 있습니다. 다시 시작하면 활성화됩니다. `cycle.start_day_mode` 및 `cycle.day_progression_mode` 가족 선택을 변경하지 않고 첫 번째 요일과 요일 순서를 선택하세요.

<a id="custom-families-and-days"></a>
## 사용자 정의 가족 및 요일

가족 소스는 다음 위치에 있습니다.

```text
RandomDay/Scripts/ax_profiles/families/
```

마크다운과 JSON 아래 `docs/profiles/` 아래의 Markdown 및 JSON은 생성된 참조입니다. 생성된 출력이 아닌 소스를 변경한 다음 전체 profile/schema 유효성 검사를 실행하세요. 단 하루만 구문 분석하면 사용자 정의 세트가 준비되지 않습니다. 17일 동안 구성된 프로필 기본값, 유형, 범위 및 생성된 참조가 일치해야 합니다.
