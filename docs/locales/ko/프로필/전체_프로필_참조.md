# RandomDay - 전체 프로필 참조

> **표준 영어 소스:** [FULL_PROFILE_REFERENCE.md](../../../profiles/FULL_PROFILE_REFERENCE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


버전: `v0.3.16-alpha`

이 생성된 참조에는 17개 제품군의 289개 프로필이 모두 포함됩니다. 이는 런타임에 사용되는 동일한 Lua 프로필 테이블과 번역 사전에서 생성됩니다. 원시 값은 신뢰할 수 있는 상태로 유지됩니다.

<a id="read-the-reference"></a>
## 참조 읽기

- 전체 및 도메인 등급은 46개의 모든 SandboxSettings 키와 압력 발생으로 계산됩니다.
- 일반 언어 텍스트는 권고사항입니다. 모든 설명 옆에 정확한 값이 유지됩니다.
- 활성 설정이 현재 부팅에 적용됩니다. 준비된 설정은 다음에 다시 시작한 후에만 적용됩니다.
- 선택적 어댑터 선택은 요청입니다. 런타임 상태는 설치된 어댑터가 실제로 일치하고 확인되었는지 기록합니다.
