# RandomDay 프로필 문서

> **표준 영어 소스:** [README.md](../../../profiles/README.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


버전: `v0.3.16-alpha`

- 가족: **17**
- 프로필: **289**
- SandboxSettings 사전 항목: **46**

[프로필 선택 가이드](../%ED%94%84%EB%A1%9C%ED%95%84_%EC%84%A0%ED%83%9D.md)그런 다음 생성된 이 인덱스를 사용하여 정확한 값을 확인하세요.

이러한 파일은 런타임 Lua 소스와 해당 dictionary/translation 계약에서 생성됩니다. 배송된 `sandbox.profile_overrides` 기본값을 보여줍니다. 한 서버의 구성 값은 다를 수 있습니다:

- `profiles.generated.json`: 기계 판독 가능 프로필, 원시 값, 사전 및 번역.
- `FULL_PROFILE_REFERENCE.md`: 완전한 색인 및 해석 규칙.
- `SANDBOX_SETTINGS_KEYS.md`: 완전한 46키 사전.
- `families/*.md`: 상세한 17일 가족 참조.

다음으로 재생성: `python -B tools/generate_profile_docs.py` 확인 드리프트의 경우: `python -B tools/generate_profile_docs.py --check`
