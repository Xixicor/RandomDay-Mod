# 원하는 게임 종류를 선택하세요

> **표준 영어 소스:** [CHOOSE_A_PROFILE.md](../../CHOOSE_A_PROFILE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


RandomDay에는 미리 만들어진 289개의 세계 규칙 세트가 포함되어 있습니다. 17개로 정리되어 있습니다**가족**, 17개 **프로필** 각 가족의 경우:

- 패밀리는 생존, 건설, 스텔스 또는 탐험과 같은 하나의 광범위한 플레이 스타일입니다.
- 프로필은 해당 플레이 스타일 내의 하나의 완전한 규칙 세트입니다. 그리고
- 프로필 번호는 서버가 다시 시작될 때 RandomDay 17개 위치를 통과하기 때문에 하루에 호출됩니다. 실제 날짜가 아닙니다.

아래 표부터 시작하세요. 원하는 세션에 가장 가까운 행을 선택한 다음 하나 또는 두 개의 패밀리 페이지를 열어 정확한 효과를 비교하세요.

## 정확한 가족 및 날짜를 확인하세요

1. 가족 페이지를 열고 모든 17일 위치를 비교하세요.
2. 사용[전체 프로필 참조](%ED%94%84%EB%A1%9C%ED%95%84/%EC%A0%84%EC%B2%B4_%ED%94%84%EB%A1%9C%ED%95%84_%EC%B0%B8%EC%A1%B0.md) 전체 289개 조합에 걸쳐 프로필 이름과 해석 규칙을 비교합니다.
3. [샌드박스 설정 키](%ED%94%84%EB%A1%9C%ED%95%84/%EC%83%8C%EB%93%9C%EB%B0%95%EC%8A%A4_%EC%84%A4%EC%A0%95_%ED%82%A4.md) 각 원시 값, 지원 범위, 점수 대역 및 배송된 프로필 기본값을 해석합니다.
4. [`profiles.generated.json`](../../profiles/profiles.generated.json)도구에 기계가 읽을 수 있는 정확한 프로필, 사전 및 번역 소스가 필요한 경우

## 선택한 환경을 구성하세요
