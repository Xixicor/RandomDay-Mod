# নিরাপত্তা নীতি

> **ক্যাননিকাল ইংরেজি উৎস:** [SECURITY.md](../../../SECURITY.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


RandomDay সার্ভার কনফিগারেশন ফাইল লেখে এবং ঐচ্ছিক মোড কনফিগারেশন ফাইল প্যাচ করতে পারে। পরিবর্তনগুলিকে কার্যত সংবেদনশীল হিসাবে বিবেচনা করুন৷

<a id="do-not-report-as-security-issues"></a>
## নিরাপত্তা সমস্যা হিসেবে রিপোর্ট করবেন না

- সাধারণ গেমপ্লে ব্যালেন্স পরিবর্তন।
- প্রত্যাশিত পরবর্তী-রিবুট প্রোফাইল রোটেশন।

<a id="report-privately"></a>
## ব্যক্তিগতভাবে রিপোর্ট করুন

- পাথ ট্রাভার্সাল ঝুঁকি।
- অনিরাপদ ফাইল লেখার আচরণ।
- অভিপ্রেত server/mod পাথের বাইরে ফাইলগুলিকে ওভাররাইট করার ক্ষমতা৷
- দূষিত কমান্ড এক্সিকিউশন।

একটি সর্বজনীন নিরাপত্তা চ্যানেল বিদ্যমান না হওয়া পর্যন্ত, সংগ্রহস্থলের মালিককে ব্যক্তিগতভাবে রিপোর্ট করুন৷
