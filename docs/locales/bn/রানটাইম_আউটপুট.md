# রানটাইম অবস্থা এবং আউটপুট স্কিমা ব্যাখ্যা করুন

> **ক্যাননিকাল ইংরেজি উৎস:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এটি ক্যানোনিকাল ফিল্ড-সম্পূর্ণ স্কিমা গাইড। এটি প্রতিটি ক্ষেত্র, অবস্থা, খালি মান এবং মেশিনের ফলাফলের অর্থ কী তা উত্তর দেয়। [রানটাইম ফাইল ম্যাপ](%E0%A6%B0%E0%A6%BE%E0%A6%A8%E0%A6%9F%E0%A6%BE%E0%A6%87%E0%A6%AE_%E0%A6%AB%E0%A6%BE%E0%A6%87%E0%A6%B2.md) প্রযোজক, পথ, লেখার সময়, ধারণ, লেনদেন সাইডকার এবং পুনরুদ্ধারের অবস্থানগুলির জন্য৷

এই গাইডের সমস্ত পাথ ইনস্টল করা `RandomDay/` ফোল্ডার যদি না একটি সারি স্পষ্টভাবে কনফিগার করা স্যান্ডবক্স বা একটি ঐচ্ছিক অ্যাডাপ্টার লক্ষ্যের নাম না দেয়৷ রানটাইম আউটপুট ইনস্টলেশনের পরে উত্পন্ন হয় এবং উভয়ই প্রকাশের সদস্য নয় ZIP.

<a id="choose-the-authoritative-view"></a>
## অনুমোদিত দৃশ্য চয়ন করুন

| প্রয়োজন | অনুমোদিত উৎস |
|---|---|
| বর্তমান প্রক্রিয়া দ্বারা লোড করা নিয়ম | RandomDay `SandboxSettings.ini` স্টার্টআপে পড়ুন |
| প্রস্তুত সারি বুককিপিং | `runtime/rotation_state.txt`, স্কিমা `1` |
| বিশদ স্থানীয় অবস্থা | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| পাবলিক মেশিন-পাঠযোগ্য অবস্থা | `web_export/today.json`, স্কিমা `2` এবং `randomday_public_status_v2` |
| মানুষ-পাঠযোগ্য অবস্থা | `web_export/today.html`, একই পাবলিক স্ট্যাটাস ট্রানজিশন থেকে প্রাপ্ত |
| অনুবাদ শব্দভান্ডার | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| সঠিক আবদ্ধ প্লেয়ার বিজ্ঞপ্তি | `runtime/current/player_message_preview.txt` |

দি HTML ভিউ, প্রিভিউ এবং অনূদিত সারাংশ প্রাপ্ত ভিউ। তারা স্যান্ডবক্স মার্কার, লেনদেনের ফলাফল, বা কাঁচা প্রোফাইল মানগুলিকে ওভাররাইড করে না। সর্বশেষ-পরিচিত-ভাল ফাইল, অপারেশন ব্যাকআপ, সাইডকার, মিরর, অ্যাডাপ্টার লক্ষ্য এবং `UE4SS.log` মধ্যে [রানটাইম ফাইল](%E0%A6%B0%E0%A6%BE%E0%A6%A8%E0%A6%9F%E0%A6%BE%E0%A6%87%E0%A6%AE_%E0%A6%AB%E0%A6%BE%E0%A6%87%E0%A6%B2.md).

<a id="rotation-state-schema"></a>
## রোটেশন স্টেট স্কিমা

`runtime/rotation_state.txt` স্কিমা ব্যবহার করে `1` এবং একটি রয়েছে `key=value` প্রতি লাইনে জোড়া:

| ক্ষেত্র | অর্থ |
|---|---|
| `schema_version` | অবশ্যই `1`. |
| `mod_version` | প্যাকেজ পরিচয় `.randomday_version`. |
| `rotation_id` | যোগ্য পরিবার সেটের মাধ্যমে বর্তমান পাসের জন্য শনাক্তকারী৷ |
| `mode` | `selected_run`, `non_repeating_random_run` বা `rotation_run`. |
| `available_families` | কনফিগারেশন ফিল্টারিংয়ের পরে কমা দিয়ে আলাদা করা যোগ্য পারিবারিক আইডি। |
| `remaining_families` | বর্তমান অ-পুনরাবৃত্ত পাসে যোগ্য পরিবারগুলি এখনও নির্বাচিত হয়নি৷ |
| `completed_families` | যেসব পরিবারে 17-পজিশনের সম্পূর্ণ টিকে থাকা অর্ডার বর্তমান পাসে সম্পূর্ণ হয়েছে। |
| `active_family`, `active_day` | সক্রিয় মার্কার তথ্য রেকর্ড করা হয়েছে যখন নির্বাচন করা হয়েছিল। স্যান্ডবক্স মার্কার পরবর্তী বুটে প্রামাণিক৷ |
| `prepared_family`, `prepared_day` | প্রোফাইল পরবর্তী রিস্টার্টের জন্য রাখা হয়েছে। |
| `active_run_id` | পরিবার-চালিত শনাক্তকারী প্রস্তুত নির্বাচনের সাথে যুক্ত৷ |
| `last_status` | ক্যালেন্ডার নির্বাচনের অবস্থা যা এই ফাইলটি তৈরি করেছে৷ |
| `session_mode` | সমাধান করা অবিরাম ডেডিকেটেড, অস্থায়ী ডেডিকেটেড, বা singleplayer/LAN জীবনচক্র। |
| `start_day_mode` | নতুন রানের জন্য কনফিগার করা বা এককালীন র্যান্ডম স্টার্ট পছন্দ৷ |
| `day_progression_mode` | মোড়ানো অনুক্রমিক বা নন-রিপিটিং-এলোমেলো অগ্রগতি। |
| `day_order` | কমা দ্বারা বিভক্ত স্থায়ী দিনের আইডিগুলি সঠিক ক্রমে প্রস্তুত করা হবে৷ |
| `day_position` | এতে প্রস্তুত দিনের অবস্থান `day_order`. |
| `updated_at` | অপারেটর তুলনার জন্য স্থানীয় লেখার সময়। |

রাষ্ট্রীয় লেখাটি তখনই গৃহীত হয় যখন স্কিমা মার্কার, প্রস্তুত পরিবার এবং প্রস্তুত দিন সঠিকভাবে পড়া হয়। একটি অপঠিত বর্তমান ফাইল `rotation_state.last_good.txt`; নির্বাচিত স্যান্ডবক্স মার্কার এখনও নির্ধারণ করে যে বর্তমান প্রক্রিয়াটির জন্য গেমটি কী লোড হয়েছে৷

<a id="runtime-status-json"></a>
## রানটাইম স্ট্যাটাস JSON

`runtime/current/randomday_status.json` ব্যবহার করে `status_schema=randomday_runtime_status_v2`। এর প্রধান ক্ষেত্র গ্রুপগুলি হল:

| গ্রুপ | ক্ষেত্র এবং ব্যাখ্যা |
|---|---|
| পরিচয় | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| নির্বাচন | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| সক্রিয় | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| প্রস্তুত | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| মানুষের সারাংশ | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| প্রমাণ লিখুন | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| অ্যাডাপ্টার প্রমাণ | `adapter_status`, `adapter_results`; প্রতিটি অ্যাডাপ্টার রেকর্ডে সামঞ্জস্যের প্রমাণ রয়েছে, transaction/rollback অবস্থা, পরিবর্তিত ফাইলের সংখ্যা, এবং সংশোধিত টার্গেট রেফারেন্স |
| সীমানা | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| ডায়াগনস্টিকস | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

অজানা সক্রিয় মান মানে বর্তমান স্যান্ডবক্সে পঠনযোগ্য RandomDay মার্কার। তারা প্রস্তুত মান সঙ্গে প্রতিস্থাপিত করা উচিত নয়. বাইরে অ্যাডাপ্টার পাথ `runtime/` একটি বেসনাম রেফারেন্সে হ্রাস করা হয় এবং ডায়াগনস্টিক স্ট্রিংগুলি সনাক্ত করা পরম পাথগুলিকে সংশোধন করে৷

<a id="public-status-json"></a>
## পাবলিক স্ট্যাটাস JSON

`web_export/today.json` ব্যবহার করে `schema_version=2` এবং `status_schema=randomday_public_status_v2`। এটি পরিচয়ের পুনরাবৃত্তি করে, active/prepared, নির্বাচন, লেনদেন, অ্যাডাপ্টার, এবং রিস্টার্ট-সীমার তথ্য একটি অপারেটরের প্রয়োজন। এতে আরও রয়েছে:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` এবং `prepared_day_position`;
- `family_selection_mode`, উত্তরাধিকার `family_locked_until_day_17` এবং `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`, এবং তাদের সংখ্যা;
- প্রস্তুত এনকাউন্টার প্রোফাইল, টিয়ার, থিম এবং মিশ্র-এনকাউন্টারের সুযোগ;
- ওয়ার্ল্ড-স্কোপ সক্ষমতা, ওপেন-ওয়ার্ল্ড সেটিং, অজানা-ওয়ার্ল্ড পলিসি, এবং শুধুমাত্র কনফিগার করা বাদ দেওয়া-ওয়ার্ল্ড প্যাটার্নগুলির একটি গণনা;
- প্রস্তুত বার্তা এবং সম্মিলিত বার্তা পূর্বরূপ;
- `selected_at`, `sandbox_target`, `manual_copy_required`, এবং প্রস্তুত হ্যাশ।

`profile_status` এর মধ্যে একটি `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` বা `write_failed_or_rollback`. `prepared_ready=true` এখনও সক্রিয় মানে না; পরবর্তী স্টার্টআপ মার্কার প্রয়োজন৷

<a id="dictionary-and-translation-output"></a>
## অভিধান এবং অনুবাদ আউটপুট

`runtime/current/randomday_dictionary.json` ব্যবহার করে `schema=randomday_runtime_dictionary_v2` এবং অভিধান সংস্করণ `randomday_dictionary_v2` সনাক্ত করে৷ এটি প্যাকেজ মোড, নির্বাচনের অবস্থা, চাপের ডোমেন, লেবেল সেটিং, কাঁচা মান এবং সরল-ভাষার অর্থ বর্ণনা করে। অজানা মানগুলি একটি আত্মবিশ্বাসী বিবরণে রূপান্তরিত হওয়ার পরিবর্তে সুস্পষ্ট থাকে৷

`player_message_preview.txt`, `today.json`, `today.html`, এবং ইন-গেম নোটিশগুলি একই অনুবাদ মডিউল থেকে প্রাপ্ত ভিউ৷ অন্তর্নিহিত প্রোফাইল এবং অপরিশোধিত `SandboxSettings.ini` মান সত্যের উৎস থেকে যায়।

<a id="failure-and-recovery-rules"></a>
## ব্যর্থতা এবং পুনরুদ্ধারের নিয়ম

1. একটি ব্যর্থ মুলতুবি লেখা বা যাচাইকরণ কখনই উৎপাদন লক্ষ্য হয়ে ওঠে না।
2. একটি ব্যর্থ প্রচার বা প্রোডাকশনের রিডব্যাক রিডব্যাক হোল্ডব্যাক যখন এটি পুনরুদ্ধার ব্যর্থ হয় তখন একটি অপারেশন ব্যাকআপ হল ফলব্যাক৷
3. একটি ধরে রাখা রোলব্যাক ফাইল বা `rollback_failed` স্থিতির ম্যানুয়াল পর্যালোচনার প্রয়োজন হয় যখন খেলা বা সার্ভার বন্ধ থাকে৷
4. একটি সফল স্যান্ডবক্স লিখন প্লাস ব্যর্থ ঘূর্ণন-রাষ্ট্র প্রতিশ্রুতি অবনমিত হয়, প্রস্তুত নয়; অ্যাডাপ্টার এবং প্রস্তুত-প্রোফাইল মেসেজিং এড়িয়ে গেছে৷
5. একটি রপ্তানি ব্যর্থতা স্যান্ডবক্সের ফলাফলকে পরিবর্তন করে না, তবে এটি একটি সুবিধার প্রমাণের উত্সকে সরিয়ে দেয়৷ লেনদেন লগ, অবস্থা, এবং ফাইল রিডব্যাক ব্যবহার করুন৷
6. রানটাইম আউটপুট হল স্থানীয় অপারেশনাল ডেটা। তাদের একটি রিলিজে যোগ করবেন না ZIP অথবা আলাদা গোপনীয়তা পর্যালোচনা ছাড়াই সেগুলিকে উদাহরণ হিসেবে প্রকাশ করুন৷
