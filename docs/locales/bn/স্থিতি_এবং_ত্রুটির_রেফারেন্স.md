# স্থিতি এবং ত্রুটির রেফারেন্স

> **ক্যাননিকাল ইংরেজি উৎস:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


ঠিক ব্যবহার করুন `status`, `transaction_status`, `rollback_status` এবং `error` রানটাইম এক্সপোর্ট থেকে মান। একটি প্যানেল বা কনসোলে অনুরূপ শব্দগুলি এই ক্ষেত্রগুলির জন্য একটি বিকল্প নয়৷

এই বিভাগটি সম্পূর্ণ লুকআপ রেফারেন্স। উপরের সিদ্ধান্ত গাছটি প্রাসঙ্গিক বিভাগ বেছে নেয়; এই টেবিলগুলি সঠিক মেশিনের মান এবং নিরাপদ অপারেটর প্রতিক্রিয়া সংরক্ষণ করে।

<a id="normal-or-informational-states"></a>
## স্বাভাবিক বা তথ্যগত অবস্থা

| স্থিতি | অর্থ | অপারেটরের প্রতিক্রিয়া |
|---|---|---|
| `prepared_for_next_reboot` | পরবর্তী বুটের জন্য একটি বৈধ প্রোফাইল লেখা হয়েছে৷ | কোন কাজ নেই; বর্তমান অধিবেশন অপরিবর্তিত। |
| `next_reboot_already_prepared` | অভিপ্রেত পরবর্তী প্রোফাইলটি ইতিমধ্যেই লক্ষ্যের সাথে মেলে৷ | কোন কাজ নেই; অন্য ঘূর্ণন জোর করবেন না. |
| `already_current` / `unchanged` | লক্ষ্যে ইতিমধ্যেই উদ্দিষ্ট বাইট রয়েছে৷ | কোন কাজ নেই। |
| `applied` | লেখা এবং উৎপাদন রিডব্যাক পাস হয়েছে৷ | যাচাই করুন active/prepared পরবর্তী বুটের পরে পার্থক্য। |
| `bootstrap_prepare_first_family_start_day` | কোন পূর্বের ঘূর্ণন অবস্থা বিদ্যমান ছিল না, তাই কনফিগার করা প্রথম দিন প্রস্তুত করা হয়েছিল৷ | প্রথম ব্যবহারে প্রত্যাশিত৷ |
| `state_recovery_rewrite_prepared_profile_no_reroll` | সঞ্চিত অবস্থা পুনরুদ্ধার করা হয়েছে এবং একই প্রস্তুত প্রোফাইল পুনরায় লেখা হয়েছে৷ | পুনরুদ্ধার দিন যাচাই করুন; কোনো নতুন এলোমেলো পছন্দ ঘটেনি। |
| `supervision_reconfirm_prepared_profile_no_advance` | একটি তত্ত্বাবধান পাস বিদ্যমান প্রস্তুতি নিশ্চিত করেছে৷ | প্রত্যাশিত; সারি দুবার এগোয়নি। |
| `external_mods_disabled` | ঐচ্ছিক অ্যাডাপ্টার প্রক্রিয়াকরণ নিষ্ক্রিয় করা আছে৷ | অ্যাডাপ্টার না থাকলে কোন কাজ নেই। |
| `external_mods_processed` | সমস্ত সক্ষম অ্যাডাপ্টার পরিকল্পনা একটি টার্মিনাল ফলাফলে পৌঁছেছে৷ | প্রতিটি অ্যাডাপ্টার সারি পর্যালোচনা করুন৷ |

<a id="startup-configuration-errors"></a>
## স্টার্টআপ কনফিগারেশন ত্রুটি

এই বার্তাগুলি শুরু হওয়ার আগে বন্ধ করে দেয় RandomDay একটি প্রোফাইল লেখে। নামযুক্ত সেটিং বা প্যাকেজ মার্কার সংশোধন করুন; বৈধতা শাখাকে বাইপাস করবেন না।

| ত্রুটি পাঠ্য | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` অনুপস্থিত, বিকৃত, বা ভুল প্যাকেজ থেকে। | একটি সম্পূর্ণ প্যাকেজ একটি পরিষ্কার স্টেজিং ফোল্ডারে পুনরায় ইনস্টল করুন এবং উদ্দেশ্যযুক্ত মোড মার্কার সংরক্ষণ করুন৷ |
| `invalid experience.mode` | `experience.mode` নথিভুক্ত মানগুলির মধ্যে একটি নয়৷ | ব্যবহার করুন `auto`, `persistent_dedicated`, `temporary_dedicated` বা `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | একটি ম্যানুয়াল-কপি প্যাকেজ একটি ডেডিকেটেড সার্ভার হিসাবে কনফিগার করা হয়েছিল৷ | পুনরুদ্ধার করুন `auto` বা `singleplayer_lan`; এটিকে স্বয়ংক্রিয়ভাবে একটি বাহ্যিক বিশ্বের দিকে নির্দেশ করবেন না। |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | ম্যানুয়াল-কপি ওয়ার্কফ্লো-এর জন্য একটি ডেডিকেটেড প্যাকেজ কনফিগার করা হয়েছে৷ | ব্যবহার করুন `auto`, `persistent_dedicated` বা `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | প্রাথমিক দিনের নির্বাচক অবৈধ৷ | ঠিক ব্যবহার করুন `configured` বা `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | দিন-অর্ডার নির্বাচক অবৈধ৷ | ঠিক ব্যবহার করুন `sequential` বা `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | কনফিগার করা শুরুর দিনটি ভগ্নাংশ বা চক্রের বাইরে৷ | 1 থেকে `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | ব্যাকআপ বা শেষ-ভালো পুনরুদ্ধার অক্ষম করা হয়েছে৷ | উভয় নিরাপত্তা লক পুনরুদ্ধার করুন; RandomDay ইচ্ছাকৃতভাবে অনিরাপদ লেখা প্রত্যাখ্যান করে। |
| `external adapter transaction safety locks must remain true` | অ্যাডাপ্টার প্যাচিং বা ব্যাকআপ সুরক্ষা অক্ষম করা হয়েছে৷ | উভয় অ্যাডাপ্টার নিরাপত্তা লক পুনরুদ্ধার করুন বা একটি গ্রুপ হিসাবে অ্যাডাপ্টার নিষ্ক্রিয় করুন৷ |
| `paths.world_name must be one folder name` | কনফিগার করা বিশ্বের নামটিতে একটি বিভাজক বা অনিরাপদ অক্ষর রয়েছে৷ | অক্ষর, সংখ্যা, স্পেস, আন্ডারস্কোর বা হাইফেন ব্যবহার করে শুধুমাত্র সঠিক ফোল্ডারের নাম লিখুন। |
| `required runtime directory unavailable` | একটি প্রয়োজনীয় মড-লোকাল আউটপুট ডিরেক্টরি তৈরি বা নিশ্চিত করা যায়নি৷ | শুধুমাত্র নামযুক্ত RandomDay ডিরেক্টরি এবং তার লেখার অনুমতি পরীক্ষা করুন৷ |

<a id="profile-wide-configuration-errors"></a>
## প্রোফাইল-ওয়াইড কনফিগারেশন ত্রুটি

এই ত্রুটিগুলি একটি স্যান্ডবক্স লেখার আগে প্রোফাইল নির্মাণ বন্ধ করে দেয়৷

| ত্রুটি পাঠ্য | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `sandbox.profile_overrides must be a table` | চারটি প্রোফাইল-ওয়াইড পছন্দ অন্য লুয়া টাইপ দিয়ে প্রতিস্থাপিত হয়েছে। | এ নথিভুক্ত টেবিলটি পুনরুদ্ধার করুন `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | টেবিলে একটি সেটিং রয়েছে যা চারটি সমর্থিত কীগুলির মধ্যে একটি নয়৷ | নামিত কীটি সরান এবং ব্যবহার করুন family/profile অন্যান্য স্যান্ডবক্স সেটিংসের জন্য উৎস। |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` বা `AllowIronMode` নয় `true` বা `false`. | একটি উদ্ধৃতিহীন লুয়া বুলিয়ান ব্যবহার করুন৷ |
| `sandbox.profile_overrides.<key> must be integer` | একটি সমর্থন মান একটি সম্পূর্ণ সংখ্যা নয়৷ | একটি পূর্ণ সংখ্যা ব্যবহার করুন৷ |
| `sandbox.profile_overrides.<key> outside supported range` | একটি সমর্থন মান বাইরে রয়েছে `0..1000`. | থেকে একটি পূর্ণ সংখ্যা চয়ন করুন `0` এর মাধ্যমে `1000`. |

<a id="rollback-and-intermediate-states"></a>
## রোলব্যাক এবং মধ্যবর্তী অবস্থা

| মান | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `not_started` / `pending` | লেনদেন বা অ্যাডাপ্টার প্ল্যান টার্মিনাল ফলাফলে পৌঁছায়নি৷ | শুধুমাত্র বর্তমান আবদ্ধ স্টার্টআপ পাসের জন্য অপেক্ষা করুন; অবিরাম রাষ্ট্রের তদন্ত প্রয়োজন৷ |
| `not_needed` | কোন রোলব্যাকের প্রয়োজন ছিল না৷ | কোন কাজ নেই। |
| `original_held` | প্রোমোশনের আগে মূল টার্গেটটি পুনরুদ্ধারের অবস্থানে সরানো হয়েছিল৷ | লেনদেন অসম্পূর্ণ থাকা অবস্থায় পুনরুদ্ধার ফাইলটি মুছবেন না৷ |
| `retained_after_success` | নতুন লক্ষ্য যাচাই করা হয়েছে, কিন্তু পুনরুদ্ধারের ডেটা রয়ে গেছে কারণ পরিষ্কার করা অনুপলব্ধ ছিল বা ইচ্ছাকৃতভাবে ধরে রাখা হয়েছিল৷ | কোনও নামযুক্ত পুনরুদ্ধার ফাইল সরানোর আগে উত্পাদন বাইট যাচাই করুন৷ |
| `discarded_after_success` | প্রতিস্থাপন যাচাই করা হয়েছে এবং অস্থায়ী রোলব্যাক ডেটা সাফ করা হয়েছে৷ | কোন কাজ নেই। |
| `rollback_failed` | পুনরুদ্ধারের প্রচেষ্টা যাচাই করা যায়নি৷ | সার্ভার বন্ধ রাখুন এবং সর্বশেষ যাচাইকৃত অপারেশন ব্যাকআপ ব্যবহার করুন। |
| `skipped_state_persistence_failed` | স্যান্ডবক্স বাইট প্রস্তুত করা হয়েছিল, কিন্তু ঘূর্ণন অবস্থা বজায় ছিল না, তাই অ্যাডাপ্টার এবং প্রস্তুত-প্লেয়ার মেসেজিং এড়িয়ে যাওয়া হয়েছিল৷ | রানটাইম স্টেট স্টোরেজ মেরামত করুন; ম্যানুয়ালি পুনরায় রোল বা সারি অগ্রসর করবেন না। |
| `failed` | একটি সারাংশ সারি একটি টার্মিনাল ব্যর্থতার প্রতিনিধিত্ব করে যার নির্দিষ্ট কারণ এর মধ্যে রয়েছে `error` বা লেনদেনের ক্ষেত্র। | প্রথম নির্দিষ্ট কোড অনুসরণ করুন; `failed` একা। |

<a id="transaction-failures"></a>
## লেনদেন ব্যর্থতা

| স্থিতি | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `invalid_input` | প্রতিস্থাপনের অনুরোধটি বৈধ পাঠ্য ছিল না বা একটি বৈধ লক্ষ্যের অভাব ছিল৷ | সঠিক কনফিগারেশন; অপরিবর্তিত পুনরায় চেষ্টা করবেন না। |
| `stale_pending_cleanup_failed` | একটি পুরানো মুলতুবি ফাইল সরানো যায়নি৷ | ম্যানুয়াল ক্লিনআপের আগে মুলতুবি থাকা ফাইলটি বন্ধ করুন এবং সংরক্ষণ করুন। |
| `stale_rollback_requires_review` | পুনরুদ্ধারের ডেটা একটি বর্তমান লক্ষ্যের পাশে বিদ্যমান এবং নিরাপদে বাতিল করা যাবে না৷ | কোনও একটি বেছে নেওয়ার আগে লক্ষ্য এবং রোলব্যাক বাইট তুলনা করুন৷ |
| `interrupted_transaction_restore_failed` | বিঘ্নিত প্রতিস্থাপনের পরে পুনরুদ্ধার লক্ষ্য পুনরুদ্ধার করতে পারেনি৷ | সার্ভার বন্ধ রাখুন এবং একটি যাচাইকৃত ব্যাকআপ পুনরুদ্ধার করুন। |
| `interrupted_transaction_cleanup_failed` | লক্ষ্য পুনরুদ্ধার করা হয়েছে কিন্তু পুরানো লেনদেনের ডেটা সাফ করা যায়নি৷ | টার্গেট বাইট যাচাই করুন, তারপর শুধুমাত্র নামযুক্ত বাসি সাইডকার সরান। |
| `pending_write_failed` | প্রার্থী লেখা যাবে না। | সংকীর্ণ লক্ষ্য ডিরেক্টরি এবং ফাঁকা স্থান পরীক্ষা করুন৷ |
| `pending_readback_failed` / `pending_readback_mismatch` | প্রার্থীর বাইট পড়া বা লেখার পরে আলাদা করা যায়নি। | পেন্ডিং ফাইলের প্রচার করবেন না। |
| `pending_validation_failed` | প্রার্থী ব্যর্থ হয়েছে schema/profile প্রচারের আগে বৈধতা। | রিপোর্ট করা কী বা নিয়ম ঠিক করুন; বৈধতা বাইপাস করবেন না। |
| `operation_backup_failed` / `backup_failed` | একটি যাচাইকৃত প্রাক-রাইট ব্যাকআপ তৈরি করা হয়নি৷ | স্টপ; কোন লক্ষ্য প্রতিস্থাপন বিশ্বাস করা উচিত নয়. |
| `original_preserved_move_failed` | মূল লক্ষ্য পুনরুদ্ধারের অবস্থানে সরানো যাবে না৷ | সমস্ত লেনদেন ফাইল সংরক্ষণ করুন এবং ম্যানুয়ালি পুনরুদ্ধার করুন। |
| `promotion_failed` | অমীমাংসিত প্রার্থী উৎপাদন লক্ষ্য হতে পারেনি৷ | পুনরায় চেষ্টা করার আগে আসলটি পুনরুদ্ধার করা হয়েছে কিনা তা পরীক্ষা করুন৷ |
| `production_validation_failed` | প্রচারিত বাইট উৎপাদন ব্যর্থ হয়েছে readback/validation. | যাচাইকৃত ব্যাকআপ পুনরুদ্ধার করুন এবং লক্ষ্য লেখক পরিদর্শন করুন৷ |
| `replacement_committed_recovery_cleanup_failed` | প্রতিস্থাপনটি বৈধ, কিন্তু রোলব্যাক ডেটা সাফ করা যায়নি৷ | লক্ষ্যটিকে প্রতিশ্রুতিবদ্ধ হিসাবে বিবেচনা করুন; শুধুমাত্র যাচাইকৃত পুরানো পুনরুদ্ধার ডেটা সরান৷ |
| `rollback_failed` | স্বয়ংক্রিয় পুনরুদ্ধার যাচাই করা হয়নি৷ | সার্ভার বন্ধ রাখুন এবং ম্যানুয়াল পুনরুদ্ধার ব্যবহার করুন৷ |

## লক্ষ্য, প্রোফাইল, অ্যাডাপ্টার, এবং এক্সপোর্ট ব্যর্থতা

| স্থিতি | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `target_refused` | কনফিগার করা পথটি অনুমোদিত মোড সীমানার বাইরে৷ | পাথ ঠিক করুন; কখনই সীমারেখা দুর্বল করবেন না। |
| `target_directory_failed` | টার্গেট ডিরেক্টরি তৈরি বা নিশ্চিত করা যায়নি৷ | শুধুমাত্র সেই ডিরেক্টরির অস্তিত্ব এবং অনুমতিগুলি পরীক্ষা করুন৷ |
| `profile_validation_failed` | একটি প্রোফাইলে একটি কী অনুপস্থিত, ভুল আছে type/range, অথবা একটি অবশিষ্ট অপরিবর্তনীয় নিয়ম লঙ্ঘন করে। | নামিত কী ব্যবহার করুন, `sandbox.profile_overrides`, এবং উৎস মেরামতের জন্য প্রোফাইল রেফারেন্স। |
| `skipped_incompatible` | একটি ঐচ্ছিক মোড বিদ্যমান কিন্তু সমর্থিত অ্যাডাপ্টারের স্বাক্ষরের সাথে মেলে না৷ | এটিকে অপরিবর্তিত রাখুন বা সেই অ্যাডাপ্টারটিকে নিষ্ক্রিয় করুন৷ |
| `external_mods_partial` | কিছু ​​ঐচ্ছিক অ্যাডাপ্টার সম্পূর্ণ হয়েছে এবং অন্যগুলো নিরাপদে ছিল skipped/failed. | স্বতন্ত্রভাবে অ্যাডাপ্টারের সারি পর্যালোচনা করুন; স্যান্ডবক্স ফলাফল আলাদা। |
| `external_adapter_failed` | একটি প্রয়োজনীয় অ্যাডাপ্টার নিরাপদে সম্পূর্ণ হয়নি৷ | পুনরায় চেষ্টা করার আগে এটির যাচাইকৃত ব্যাকআপ পুনরুদ্ধার করুন৷ |
| `degraded_state_persistence` | স্যান্ডবক্সের প্রস্তুতি সম্পন্ন হয়েছে, কিন্তু ঘূর্ণন-স্থিতি স্থায়ী হয়নি। | অনুমান করবেন না পরবর্তী বুট সঠিকভাবে অগ্রসর হতে পারে; স্টেট স্টোরেজ মেরামত করুন। |
| `export_directory_failed` | `web_export/` তৈরি বা লেখা যায়নি৷ | গেমপ্লে প্রস্তুতি এখনও বৈধ হতে পারে; আলাদাভাবে মেরামত রিপোর্টিং। |

## অনুবাদ এবং বার্তা যাচাইকরণ ত্রুটি

এগুলি অভিধান বা উপস্থাপনা-চুক্তি ব্যর্থতা৷ এগুলি প্রকাশের আগে যাচাই করা হয় এবং একটি আবদ্ধ রানটাইম-স্ট্যাটাস সতর্কতা হিসাবেও উপস্থিত হতে পারে৷

| ত্রুটি পাঠ্য | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `dictionary coverage mismatch` | প্রোফাইল অভিধান প্রতিটি নথিভুক্ত সেটিং ব্যাখ্যা করে না৷ | অনুপস্থিত অভিধান এন্ট্রি যোগ করুন এবং প্রোফাইল পুনরায় চালান generation/validation. |
| `missing profile setting` | একটি নির্বাচিত প্রোফাইলে dictionary/schema. | প্রোফাইল ফ্যামিলি সোর্স মেরামত করুন; রানটাইম ডিফল্ট আবিষ্কার করবেন না। |
| `empty explanation` | একটি সেটিং বিদ্যমান কিন্তু নেই operator/player ব্যাখ্যা। | রিলিজের আগে একটি সরল-ভাষা ব্যাখ্যা যোগ করুন। |
| `join line too wide` | একটি জেনারেট করা যোগ লাইন 42-অক্ষরের উত্স সীমা অতিক্রম করে৷ | অভিধান বাক্যাংশ সংক্ষিপ্ত করুন; ক্লায়েন্ট মোড়ানোর উপর নির্ভর করবেন না। |
| `join message too tall` | উৎপন্ন যোগদানের সারাংশ চার লাইন ছাড়িয়ে গেছে। | বার্তার বিষয়বস্তু হ্রাস করুন বা পুনরায় অগ্রাধিকার দিন৷ |
