# শব্দকোষ

> **ক্যাননিকাল ইংরেজি উৎস:** [GLOSSARY.md](../../GLOSSARY.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এটি হল RandomDay ডকুমেন্টেশন। পদ্ধতিগুলি একাধিক গাইডে একই অবস্থাকে পুনরায় সংজ্ঞায়িত করার পরিবর্তে এই সংজ্ঞাগুলির সাথে লিঙ্ক করে। স্কিমা-নির্দিষ্ট ক্ষেত্রের নিয়ম [রানটাইম আউটপুট](%E0%A6%B0%E0%A6%BE%E0%A6%A8%E0%A6%9F%E0%A6%BE%E0%A6%87%E0%A6%AE_%E0%A6%86%E0%A6%89%E0%A6%9F%E0%A6%AA%E0%A7%81%E0%A6%9F.md).
