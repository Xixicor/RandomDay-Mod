# রিলিজের বৈধতা

> **ক্যাননিকাল ইংরেজি উৎস:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এই পৃষ্ঠাটি অবদানকারী এবং রিলিজ রক্ষণাবেক্ষণকারীদের জন্য। মোড ইনস্টল করা প্লেয়ারদের এই কমান্ডগুলি চালানোর প্রয়োজন নেই৷

<a id="ordinary-user-proof"></a>
## সাধারণ ব্যবহারকারীর প্রমাণ

একটি রিলিজ বোধগম্য হয় যখন একজন নতুন পাঠক দুটি প্যাকেজের মধ্যে একটি বেছে নিতে পারেন, এটি ইনস্টল করতে পারেন, সক্রিয় প্রোফাইল সনাক্ত করতে পারেন এবং একটি প্রোফাইল অনুসরণ করে লিংক তৈরি করা ফলাফলটি মিস করতে পারেন। এই পাঠকের কাজগুলির জন্য অবশ্যই গিট, PowerShell, পাইথন, বা চেকসাম জ্ঞানের প্রয়োজন হবে না৷

<a id="contributor-checks"></a>
## কন্ট্রিবিউটর চেক

রিপোজিটরি রুট থেকে চালান:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

কখন `luac` উপলব্ধ, প্রতিটি শিপ করা লুয়া ফাইল সিনট্যাক্স-চেক করুন:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

লুয়া রানটাইম পরীক্ষার প্রয়োজন `lupa`। একজন অনুপস্থিত লুয়া দোভাষী বা `lupa` ইনস্টলেশন একটি অনুপলব্ধ পরীক্ষার ক্ষমতা, পাস করা ফলাফল নয়৷

<a id="release-checks"></a>
## রিলিজ চেক

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

রিলিজ চেক এই শর্তগুলি যাচাই করে:

- `VERSION` এবং `RandomDay/.randomday_version` মিল।
- শুধুমাত্র বর্তমান সংস্করণ `releases/`.
- ডেডিকেটেড এবং singleplayer/LAN জিপগুলি সম্পূর্ণ বিকল্প৷
- উভয় সংরক্ষণাগারেই ক্যানোনিকাল রয়েছে `RandomDay/Scripts/main.lua` পাথ এবং কোনো কেস-কলাইডিং লোডার নেই৷
- প্যাকেজ মোড মার্কার হল `dedicated_server` এবং `singleplayer_manual`.
- ZIP বাইটগুলি নির্ধারক এবং মেলে `CHECKSUMS.sha256`.
- কোন রানটাইম ডেটা, ব্যক্তিগত কনফিগারেশন, শংসাপত্র, ক্যাশে বা পরীক্ষার আউটপুট প্যাকেজ করা নেই৷
- সমস্ত স্থানীয় ডকুমেন্টেশন লিঙ্ক এবং 27টি লোকেল এন্ট্রি পৃষ্ঠা যাচাই করে৷

<a id="avoid-validation-environment-pitfalls"></a>
## বৈধকরণ পরিবেশের ত্রুটিগুলি এড়িয়ে চলুন

- রিপোজিটরি-রাইটিং চেকগুলি সিরিয়ালভাবে চালান যাতে দুটি প্রক্রিয়া একই অস্থায়ী ফাইলকে একবারে প্রতিস্থাপন না করে৷
- উইন্ডোজে, চেক করুন ZIP একটি ছোট হাতের লোডার বিদ্যমান কিনা তা সিদ্ধান্ত নিতে একটি কেস-সংবেদনশীল ফাইল লুকআপ ব্যবহার করার পরিবর্তে সদস্যদের নাম৷
- নিশ্চিত করুন `mods.txt` এবং `enabled.txt` শুধুমাত্র একটি ইনস্টল-সার্ভার পরীক্ষায়; তারা প্রমাণ নয় যে উৎস পরীক্ষা চালানো হয়েছে।
- অসম্পূর্ণ হিসাবে একটি কমান্ড টাইমআউট রেকর্ড করুন৷ কমান্ডের আবদ্ধ আউটপুট ছাড়া এটিকে পাস বা ফেলতে রূপান্তর করবেন না।
- অস্থায়ী ফাইলগুলিকে রিপোজিটরির উপেক্ষা করার ভিতরে রাখুন `.tmp/` ডিরেক্টরি।

<a id="known-limits"></a>
## জানা সীমা

স্থানীয় বৈধতা উৎস, প্যাকেজ, ডকুমেন্টেশন এবং ফিক্সচার চুক্তি প্রমাণ করে। এটি একটি নির্দিষ্ট সার্ভার প্যানেলের স্টার্টআপ অর্ডার, একটি লাইভ ক্লায়েন্টের বার্তা লেআউট, বা হোস্ট-নির্দিষ্ট ফাইল সিস্টেম পাথ প্রমাণ করে না। সেগুলি পরীক্ষা করার সময় আলাদা ইন্টিগ্রেশন ফলাফল হিসাবে রেকর্ড করুন৷
