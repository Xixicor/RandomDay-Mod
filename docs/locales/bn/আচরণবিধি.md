# আচরণবিধি

> **ক্যাননিকাল ইংরেজি উৎস:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন। এই অনুবাদটি তথ্যপূর্ণ; ইংরেজি আইনি পাঠ্য নিয়ন্ত্রণ।


রিপোর্টগুলিকে প্রযুক্তিগত, পুনরুত্পাদনযোগ্য এবং সম্মানজনক রাখুন৷

এই সংগ্রহস্থলটি একটি সার্ভার মোডের নিয়ন্ত্রিত বিকাশের জন্য৷ বাগ রিপোর্টে লগ, পাথ, প্রত্যাশিত আচরণ এবং প্রকৃত আচরণ অন্তর্ভুক্ত করা উচিত।
