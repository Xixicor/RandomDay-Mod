# Ερμηνεύστε σχήματα κατάστασης χρόνου εκτέλεσης και εξόδου

> **Κανονική αγγλική πηγή:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτός είναι ο κανονικός οδηγός σχήματος πλήρους πεδίου. Απαντά τι σημαίνει κάθε πεδίο, κατάσταση, κενή τιμή και αποτέλεσμα μηχανής. Χρησιμοποιήστε το [χάρτης αρχείου χρόνου εκτέλεσης](%CE%91%CE%A1%CE%A7%CE%95%CE%8A%CE%91_%CE%A7%CE%A1%CE%8C%CE%9D%CE%9F%CE%A5_%CE%95%CE%9A%CE%A4%CE%88%CE%9B%CE%95%CE%A3%CE%97%CE%A3.md) για παραγωγούς, διαδρομές, χρονισμό εγγραφής, διατήρηση, παράπλευρες θέσεις συναλλαγών και τοποθεσίες ανάκτησης.

Όλες οι διαδρομές σε αυτόν τον οδηγό σχετίζονται με την εγκατεστημένη `RandomDay/` εκτός εάν μια σειρά ονομάζει ρητά το διαμορφωμένο sandbox ή έναν προαιρετικό στόχο προσαρμογέα. Οι έξοδοι χρόνου εκτέλεσης δημιουργούνται μετά την εγκατάσταση και δεν είναι μέλη καμίας έκδοσης ZIP.

<a id="choose-the-authoritative-view"></a>
## Επιλέξτε την έγκυρη προβολή

| Απαιτείται | Επίσημη πηγή |
|---|---|
| Κανόνες που φορτώθηκαν από την τρέχουσα διαδικασία | RandomDay στο `SandboxSettings.ini` ανάγνωση κατά την εκκίνηση |
| Έτοιμη λογιστική ουρά | `runtime/rotation_state.txt`, σχήμα `1` |
| Αναλυτική τοπική κατάσταση | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| Κατάσταση αναγνώσιμη από το κοινό από μηχανή | `web_export/today.json`, σχήμα `2` και `randomday_public_status_v2` |
| Κατάσταση αναγνώσιμη από τον άνθρωπο | `web_export/today.html`, που προέρχεται από την ίδια δημόσια μετάβαση κατάστασης |
| Λεξιλόγιο μετάφρασης | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| Ειδοποίηση ακριβούς περιορισμένου προγράμματος αναπαραγωγής | `runtime/current/player_message_preview.txt` |

Το HTML η προβολή, η προεπισκόπηση και οι μεταφρασμένες περιλήψεις είναι προβολές που παράγονται. Δεν παρακάμπτουν τη σήμανση sandbox, το αποτέλεσμα συναλλαγής ή τις μη επεξεργασμένες τιμές προφίλ. Εντοπίστε τα τελευταία γνωστά καλά αρχεία, αντίγραφα ασφαλείας λειτουργιών, πλαϊνές θέσεις, καθρέφτες, στόχους προσαρμογέων και `UE4SS.log` σε [Αρχεία χρόνου εκτέλεσης](%CE%91%CE%A1%CE%A7%CE%95%CE%8A%CE%91_%CE%A7%CE%A1%CE%8C%CE%9D%CE%9F%CE%A5_%CE%95%CE%9A%CE%A4%CE%88%CE%9B%CE%95%CE%A3%CE%97%CE%A3.md).

<a id="rotation-state-schema"></a>
## Σχήμα κατάστασης περιστροφής

`runtime/rotation_state.txt` χρησιμοποιεί σχήμα `1` και περιέχει ένα `key=value` ζεύγος ανά γραμμή:

| Πεδίο | Σημασία |
|---|---|
| `schema_version` | Πρέπει να είναι `1`. |
| `mod_version` | Ανάγνωση ταυτότητας πακέτου από `.randomday_version`. |
| `rotation_id` | Αναγνωριστικό για το τρέχον πάσο μέσω του κατάλληλου οικογενειακού συνόλου. |
| `mode` | `selected_run`, `non_repeating_random_run` ή `rotation_run`. |
| `available_families` | Κατάλληλα οικογενειακά αναγνωριστικά διαχωρισμένα με κόμματα μετά το φιλτράρισμα της διαμόρφωσης. |
| `remaining_families` | Κατάλληλες οικογένειες που δεν έχουν επιλεγεί ακόμη στο τρέχον μη επαναλαμβανόμενο πάσο. |
| `completed_families` | Οικογένειες των οποίων η πλήρης διαρκής παραγγελία 17 θέσεων έχει ολοκληρωθεί στο τρέχον πάσο. |
| `active_family`, `active_day` | Πληροφορίες ενεργού δείκτη που καταγράφηκαν όταν δεσμεύτηκε η επιλογή. Ο δείκτης sandbox είναι έγκυρος στην επόμενη εκκίνηση. |
| `prepared_family`, `prepared_day` | Το προφίλ κρατήθηκε για την επόμενη επανεκκίνηση. |
| `active_run_id` | Αναγνωριστικό οικογενειακής εκτέλεσης που σχετίζεται με την προετοιμασμένη επιλογή. |
| `last_status` | Κατάσταση επιλογής ημερολογίου που παρήγαγε αυτό το αρχείο. |
| `session_mode` | Επιλύθηκε μόνιμο αποκλειστικό, προσωρινό αποκλειστικό ή singleplayer/LAN κύκλος ζωής. |
| `start_day_mode` | Διαμορφωμένη ή εφάπαξ τυχαία επιλογή εκκίνησης για μια νέα εκτέλεση. |
| `day_progression_mode` | Τυλιγμένη διαδοχική ή μη επαναλαμβανόμενη τυχαία εξέλιξη. |
| `day_order` | Τα διατηρημένα αναγνωριστικά ημέρας διαχωρισμένα με κόμματα με την ακριβή σειρά που θα προετοιμαστούν. |
| `day_position` | Θέση της προετοιμασμένης ημέρας στο `day_order`. |
| `updated_at` | Τοπικός χρόνος εγγραφής για σύγκριση χειριστή. |

Η εγγραφή κατάστασης γίνεται αποδεκτή μόνο όταν ο δείκτης σχήματος, η προετοιμασμένη οικογένεια και η προετοιμασμένη ημέρα διαβάζονται σωστά. Ένα μη αναγνώσιμο τρέχον αρχείο μπορεί να επιστρέψει στο `rotation_state.last_good.txt`; ο επιλεγμένος δείκτης sandbox εξακολουθεί να καθορίζει τι φόρτωσε το παιχνίδι για την τρέχουσα διαδικασία.

<a id="runtime-status-json"></a>
## Κατάσταση χρόνου εκτέλεσης JSON

`runtime/current/randomday_status.json` χρησιμοποιεί `status_schema=randomday_runtime_status_v2`. Οι κύριες ομάδες πεδίων του είναι:

| Ομάδα | Πεδία και ερμηνεία |
|---|---|
| Ταυτότητα | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| Επιλογή | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| Ενεργό | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| Έτοιμο | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| Ανθρώπινες περιλήψεις | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| Εγγραφή απόδειξης | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| Απόδειξη προσαρμογέα | `adapter_status`, `adapter_results`; κάθε εγγραφή προσαρμογέα περιέχει στοιχεία συμβατότητας, transaction/rollback κατάσταση, πλήθος αλλαγμένων αρχείων και αναθεωρημένες αναφορές στόχων |
| Όρια | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| Διαγνωστικά | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

Οι άγνωστες ενεργές τιμές σημαίνουν ότι το τρέχον sandbox δεν περιείχε αναγνώσιμο στοιχείο RandomDay. Δεν πρέπει να αντικαθίστανται με έτοιμες τιμές. Διαδρομές προσαρμογέα εκτός `runtime/` μειώνονται σε μια αναφορά ονόματος βάσης και οι διαγνωστικές συμβολοσειρές αφαιρούν τις ανιχνευμένες απόλυτες διαδρομές.

<a id="public-status-json"></a>
## Δημόσια κατάσταση JSON

`web_export/today.json` χρησιμοποιεί `schema_version=2` και `status_schema=randomday_public_status_v2`. Επαναλαμβάνει την ταυτότητα, active/prepared, στοιχεία επιλογής, συναλλαγής, προσαρμογέα και ορίου επανεκκίνησης που απαιτούνται από έναν χειριστή. Περιλαμβάνει επίσης:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` και `prepared_day_position`;
- `family_selection_mode`, παλαιού τύπου `family_locked_until_day_17` και `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families` και ο αριθμός τους;
- προετοιμασμένο προφίλ συνάντησης, επίπεδο, θέμα και πιθανότητα μικτής συνάντησης;
- ενεργοποίηση παγκόσμιου εύρους, ρύθμιση ανοιχτού κόσμου, πολιτική άγνωστου κόσμου και μόνο πλήθος διαμορφωμένων μοτίβων αποκλεισμένου κόσμου.
- έτοιμες προεπισκοπήσεις μηνυμάτων και συνδυασμένων μηνυμάτων;
- `selected_at`, `sandbox_target`, `manual_copy_required` και προετοιμασμένος κατακερματισμός.

`profile_status` είναι ένα από τα `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` ή `write_failed_or_rollback`. `prepared_ready=true` εξακολουθεί να μην σημαίνει ενεργό. απαιτείται ο μεταγενέστερος δείκτης εκκίνησης.

<a id="dictionary-and-translation-output"></a>
## Έξοδος λεξικού και μετάφρασης

`runtime/current/randomday_dictionary.json` χρησιμοποιεί `schema=randomday_runtime_dictionary_v2` και προσδιορίζει την έκδοση λεξικού `randomday_dictionary_v2`. Περιγράφει λειτουργίες συσκευασίας, καταστάσεις επιλογής, τομείς πίεσης, ετικέτες ρύθμισης, μη επεξεργασμένες τιμές και έννοιες σε απλή γλώσσα. Οι άγνωστες τιμές παραμένουν σαφείς αντί να μετατρέπονται σε μια σίγουρη περιγραφή.

`player_message_preview.txt`, `today.json`, `today.html` και οι ειδοποιήσεις εντός του παιχνιδιού είναι προβολές που προέρχονται από την ίδια μονάδα μετάφρασης. Το υποκείμενο προφίλ και ακατέργαστο `SandboxSettings.ini` παραμένουν η πηγή της αλήθειας.

<a id="failure-and-recovery-rules"></a>
## Κανόνες αποτυχίας και ανάκτησης

1. Μια αποτυχημένη εκκρεμής εγγραφή ή επικύρωση δεν γίνεται ποτέ στόχος παραγωγής.
2. Μια αποτυχημένη προώθηση ή επανάληψη παραγωγής ενεργοποιεί την επαναφορά του αρχικού που κρατήθηκε. ένα αντίγραφο ασφαλείας λειτουργίας είναι το εναλλακτικό όταν αποτύχει αυτή η επαναφορά.
3. Ένα αρχείο επαναφοράς που διατηρείται ή `rollback_failed` απαιτεί μη αυτόματο έλεγχο ενώ το παιχνίδι ή ο διακομιστής είναι σταματημένο.
4. Μια επιτυχημένη εγγραφή στο sandbox συν αποτυχημένη δέσμευση κατάστασης περιστροφής έχει υποβαθμιστεί, δεν είναι έτοιμη. Οι προσαρμογείς και τα μηνύματα έτοιμου προφίλ παραλείπονται.
5. Μια αποτυχία εξαγωγής δεν αλλάζει το αποτέλεσμα του sandbox, αλλά καταργεί μια πηγή απόδειξης ευκολίας. Χρησιμοποιήστε αρχεία καταγραφής συναλλαγών, κατάσταση και ανάγνωση αρχείων.
6. Οι έξοδοι χρόνου εκτέλεσης είναι τοπικά επιχειρησιακά δεδομένα. Μην τα προσθέτετε σε μια έκδοση ZIP ή δημοσιεύστε τα ως παραδείγματα χωρίς ξεχωριστό έλεγχο απορρήτου.
