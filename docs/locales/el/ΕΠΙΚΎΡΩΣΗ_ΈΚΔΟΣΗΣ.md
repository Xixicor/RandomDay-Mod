# Επικύρωση κυκλοφορίας

> **Κανονική αγγλική πηγή:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτή η σελίδα προορίζεται για συνεισφέροντες και συντηρητές εκδόσεων. Οι παίκτες που εγκαθιστούν το mod δεν χρειάζεται να εκτελέσουν αυτές τις εντολές.

<a id="ordinary-user-proof"></a>
## Συνήθης απόδειξη χρήστη

Μια έκδοση είναι κατανοητή όταν ένας νέος αναγνώστης μπορεί να επιλέξει ένα από τα δύο πακέτα, να το εγκαταστήσει, να αναγνωρίσει το αποτέλεσμα που έχει ετοιμάσει και να ανακτήσει το προφίλ που ακολουθεί και να ανακτήσει το ενεργό προφίλ από το προφίλ. Αυτές οι εργασίες αναγνώστη δεν πρέπει να απαιτούν Git, PowerShell, Python ή γνώση αθροίσματος ελέγχου.

<a id="contributor-checks"></a>
## Έλεγχοι συνεργατών

Εκτέλεση από τη ρίζα του αποθετηρίου:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

Όταν `luac` είναι διαθέσιμο, έλεγχος σύνταξης κάθε αρχείου Lua που αποστέλλεται:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

Οι δοκιμές χρόνου εκτέλεσης Lua απαιτούν `lupa`. Λείπει διερμηνέας Lua ή `lupa` είναι μια μη διαθέσιμη δυνατότητα δοκιμής και όχι ένα θετικό αποτέλεσμα.

<a id="release-checks"></a>
## Απελευθέρωση επιταγών

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

Ο έλεγχος έκδοσης επαληθεύει αυτές τις συνθήκες:

- `VERSION` και `RandomDay/.randomday_version` αντιστοιχία.
- Μόνο η τρέχουσα έκδοση υπάρχει στο `releases/`.
- Το αποκλειστικό και singleplayer/LAN Τα ταχυδρομεία είναι πλήρεις εναλλακτικές.
- Και τα δύο αρχεία περιέχουν το κανονικό `RandomDay/Scripts/main.lua` διαδρομή και χωρίς φόρτωση περίπτωσης σύγκρουσης.
- Οι δείκτες λειτουργίας πακέτου είναι `dedicated_server` και `singleplayer_manual`.
- ZIP byte είναι ντετερμινιστικά και ταιριάζουν με `CHECKSUMS.sha256`.
- Δεν συσκευάζονται δεδομένα χρόνου εκτέλεσης, ιδιωτικές ρυθμίσεις παραμέτρων, διαπιστευτήρια, κρυφές μνήμες ή δοκιμαστική έξοδος.
- Όλοι οι σύνδεσμοι τοπικής τεκμηρίωσης και οι 27 σελίδες καταχώρισης τοπικών ρυθμίσεων επικυρώνονται.

<a id="avoid-validation-environment-pitfalls"></a>
## Αποφύγετε τις παγίδες του περιβάλλοντος επικύρωσης

- Εκτελέστε σειριακά ελέγχους εγγραφής αποθετηρίου, ώστε δύο διεργασίες να μην αντικαταστήσουν το ίδιο προσωρινό αρχείο ταυτόχρονα.
- Στα Windows, επιλέξτε ZIP ονόματα μελών αντί να χρησιμοποιήσετε αναζήτηση αρχείων χωρίς διάκριση πεζών-κεφαλαίων για να αποφασίσετε εάν υπάρχει πρόγραμμα φόρτωσης πεζών.
- Επιβεβαίωση `mods.txt` και `enabled.txt` μόνο σε δοκιμή εγκατεστημένου διακομιστή. δεν αποτελούν απόδειξη ότι έγιναν οι δοκιμές πηγής.
- Καταγράψτε ένα χρονικό όριο λήξης εντολής ως μη ολοκληρωμένο. Μην το μετατρέψετε σε επιτυχία ή αποτυχία χωρίς την οριοθετημένη έξοδο της εντολής.
- Διατηρήστε τα προσωρινά αρχεία μέσα στο χώρο αποθήκευσης αγνοημένα `.tmp/` κατάλογος.

<a id="known-limits"></a>
## Γνωστά όρια

Η τοπική επικύρωση αποδεικνύει συμβάσεις πηγής, πακέτου, τεκμηρίωσης και εξοπλισμού. Δεν αποδεικνύει τη σειρά εκκίνησης ενός συγκεκριμένου πίνακα διακομιστή, τη διάταξη μηνυμάτων ενός ζωντανού πελάτη ή μια διαδρομή συστήματος αρχείων για συγκεκριμένο υπολογιστή. Καταγράψτε τα ως ξεχωριστά αποτελέσματα ενσωμάτωσης κατά τη δοκιμή.
