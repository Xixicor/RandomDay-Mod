# Αναφορά συσκευασμένης πηγής

> **Κανονική αγγλική πηγή:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Η έκδοση ZIP περιέχει ακριβώς τις 51 διαδρομές παρακάτω. Το πρόγραμμα δημιουργίας απορρίπτει μια διαδρομή που λείπει, μια πρόσθετη πηγή σε σχήμα πακέτου, μια σύγκρουση περίπτωσης, έναν συμβολικό σύνδεσμο ή ένα μέλος εκτός της κυριολεκτικής λίστας επιτρεπόμενων. Η έξοδος χρόνου εκτέλεσης, οι δοκιμές, τα έγγραφα αποθετηρίου και οι τροποποιήσεις τρίτων δεν είναι μέλη πακέτου.

Το συνοδευτικό που μπορεί να ελεγχθεί από μηχανή είναι [`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json). Καταγράφει τις ίδιες διαδρομές με εισόδους, εξόδους, παρενέργειες, δημόσιες ρυθμίσεις, ορατές καταστάσεις, καταστάσεις αποτυχίας, δυνατότητα επεξεργασίας και κανονική τεκμηρίωση.

Κάθε σειρά Lua που αποστέλλεται έχει έναν στάβλο `module-*` άγκυρα. Ο πανομοιότυπος σύνδεσμος στην κανονική κεφαλίδα πηγής και το αρχείο μηχανής καθιστά άμεσα ανιχνεύσιμα την ιδιοκτησία, τη σύμβαση, τις παρενέργειες, τις αποτυχίες και την ανάκτηση.

## Δημιουργημένες αναφορές

`docs/profiles/profiles.generated.json`, τα οικογενειακά αρχεία Markdown και `FULL_PROFILE_REFERENCE.md` είναι contributor/operator αναφορές που δημιουργούνται από το ίδιο σύνολο προφίλ. Δεν είναι μέλη πακέτου και δεν πρέπει να υποβάλλονται σε επεξεργασία ως υποκατάστατο για την αλλαγή της πηγής προφίλ. Η επικύρωση απαιτεί 17 οικογένειες, 17 προφίλ ανά οικογένεια, μοναδικά αναγνωριστικά, όλα τα κλειδιά σχήματος, σταθερούς κανόνες, κάλυψη μετάφρασης και περιορισμένα μηνύματα.
