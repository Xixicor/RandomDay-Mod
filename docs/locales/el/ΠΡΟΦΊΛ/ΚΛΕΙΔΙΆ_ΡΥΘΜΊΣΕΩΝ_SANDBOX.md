# RandomDay - SandboxSettings λεξικό

> **Κανονική αγγλική πηγή:** [SANDBOX_SETTINGS_KEYS.md](../../../profiles/SANDBOX_SETTINGS_KEYS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Έκδοση: `v0.3.16-alpha`
