# RandomDay - Οικογένεια Horde

> **Κανονική αγγλική πηγή:** [horde.md](../../../../profiles/families/horde.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Έκδοση: `v0.3.16-alpha`

Πρόβλημα ποσότητας. Η εγκατάσταση έχει παραγγείλει πάρα πολλούς εχθρούς.

**Στυλ αναπαραγωγής:** πίεση πλήθους και έλεγχος σμήνους **Ήχος μηνύματος:** κατακλυσμένο γραφείο logistics
