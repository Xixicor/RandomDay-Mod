# RandomDay τεκμηρίωση προφίλ

> **Κανονική αγγλική πηγή:** [README.md](../../../profiles/README.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Έκδοση: `v0.3.16-alpha`

- Οικογένειες: **17**
- Προφίλ: **289**
- SandboxSettings καταχωρήσεις λεξικού: **46**

Επιλέξτε μια οικογένεια με βάση την πρόθεση παιχνιδιού στο [οδηγός επιλογής προφίλ](../%CE%95%CE%A0%CE%99%CE%9B%CE%88%CE%9E%CE%A4%CE%95_%CE%88%CE%9D%CE%91_%CE%A0%CE%A1%CE%9F%CE%A6%CE%8A%CE%9B.md) και, στη συνέχεια, χρησιμοποιήστε αυτό το ευρετήριο που δημιουργείται για ακριβείς τιμές.

Αυτά τα αρχεία δημιουργούνται από την πηγή Lua χρόνου εκτέλεσης και dictionary/translation συμβόλαιο. Δείχνουν τα αποσταλμένα `sandbox.profile_overrides` προεπιλογές. οι διαμορφωμένες τιμές ενός διακομιστή ενδέχεται να διαφέρουν:

- `profiles.generated.json`: μηχανικά αναγνώσιμα προφίλ, πρωτογενείς τιμές, λεξικό και μεταφράσεις.
- `FULL_PROFILE_REFERENCE.md`: πλήρεις κανόνες ευρετηρίου και ερμηνείας.
- `SANDBOX_SETTINGS_KEYS.md`: πλήρες λεξικό 46 κλειδιών.
- `families/*.md`: λεπτομερείς οικογενειακές αναφορές 17 ημερών.

Αναγέννηση με: `python -B tools/generate_profile_docs.py` Ελέγξτε για drift με: `python -B tools/generate_profile_docs.py --check`
