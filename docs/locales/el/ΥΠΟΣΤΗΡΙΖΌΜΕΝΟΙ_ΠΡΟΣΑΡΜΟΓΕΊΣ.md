# Υποστηριζόμενες προαιρετικές λειτουργίες

> **Κανονική αγγλική πηγή:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


RandomDay μπορεί να κάνει ένα ξεχωριστά εγκατεστημένο mod να ακολουθεί το ενεργό RandomDay προφίλ. Αυτή η δυνατότητα είναι διαθέσιμη μόνο στο πακέτο αποκλειστικού διακομιστή. Το singleplayer/LAN δεν επεξεργάζεται ποτέ άλλο mod.

RandomDay δεν περιλαμβάνει ούτε αναδιανέμει κανένα από τα mods που αναφέρονται εδώ. Εγκαταστήστε και ενεργοποιήστε κάθε προαιρετικό mod από τη δική του σελίδα Nexus και ακολουθήστε πρώτα τις οδηγίες του συγγραφέα του. RandomDay αλλάζει μόνο αναγνωρισμένες ρυθμίσεις που υπάρχουν ήδη στο εγκατεστημένο αρχείο. Δεν προσθέτει δυνατότητες σε άλλο mod και ένας προσαρμογέας μπορεί να απενεργοποιηθεί χωρίς να απεγκαταστήσετε αυτό το mod. Το πακέτο αποκλειστικού διακομιστή ξεκινά με `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## Τι RandomDay αλλαγές

| Προαιρετική ενοποίηση | Επιλεγμένες ρυθμίσεις από το ενεργό προφίλ |
| --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | Σκληρή λειτουργία, player/area συμπεριφορά ψύξης, δραστηριότητα καταιγίδας και θερμής ζώνης, αφεντικό και ριπή αναπαραγωγής, χρονισμός του κύκλου αναπαραγωγής, μικρές και μεγάλες περιοχές ψύξης, απόσταση αναπαραγωγής, global/local/mod ανώτατα όρια, πύλη-θύελλα, παραβίαση παραγγελιών και πιθανότητες αφεντικού και ελάχιστες αναπαραγωγές ανά περιοχή. |
| Προαιρετικά πεδία επέκτασης Chaotic Spawn Engine | Όταν εγκατασταθεί το `SharedData.lua` περιέχει ήδη RandomDay πεδία επέκτασης, ο προσαρμογέας μπορεί να παρέχει προφίλ συνάντησης, βαθμίδα, θέμα, όρια ομάδας, τιμές ειδικών συμβάντων και μικτών συναντήσεων, προϋπολογισμό, cooldown και στοιχεία ελέγχου παγκόσμιας εμβέλειας. Αυτό δεν είναι άλλο mod για λήψη. |
| Λέιζερ θανατηφόρων | Ενεργοποίηση mod συν ζημιές και ενεργοποίηση στοιχείων ελέγχου για αναπτυσσόμενους εκπομπούς, περιβαλλοντικούς εκπομπούς, ανακλαστήρες και πρίσματα. |
| ANTE Πάνω | Πολλαπλασιαστής επαναληπτικής συχνότητας, συχνότητα προμεταβλητής και η υπάρχουσα development/debug διακόπτες. RandomDay διατηρεί απενεργοποιημένες όλες τις αναγνωρισμένες λειτουργίες ανάπτυξης και εντοπισμού σφαλμάτων. |

Η βιβλιοθήκη προφίλ παρέχει ένα έτοιμο σύνολο τιμών για κάθε υποστηριζόμενη ημέρα. Μια ήρεμη μέρα μπορεί να μειώσει την πίεση, μια ημέρα κινδύνου μπορεί να την αυξήσει και μια ημέρα ανάκαμψης μπορεί να τη μειώσει απότομα. RandomDay δεν υπολογίζει αυθαίρετες τιμές κατά την εκκίνηση. εφαρμόζει την ελεγμένη τιμή που έχει οριστεί από το ενεργό προφίλ.

<a id="how-recognition-protects-another-mod"></a>
## Πώς η αναγνώριση προστατεύει ένα άλλο mod

Η εύρεση ενός οικείου ονόματος αρχείου δεν αρκεί. Πριν γράψετε, RandomDay ελέγχει ότι κάθε απαιτούμενη ρύθμιση για αυτόν τον προσαρμογέα υπάρχει στο αρχείο προορισμού. Επιδιορθώνει μόνο τις υπάρχουσες αναθέσεις. δεν εφευρίσκει ποτέ μια ρύθμιση που λείπει.

Για αναγνωρισμένη διάταξη, RandomDay εκτελεί μία δεσμευμένη συναλλαγή:

1. υπολογίστε κάθε προβλεπόμενη τιμή για το ενεργό προφίλ.
2. δημιουργήστε και ελέγξτε byte ένα αντίγραφο ασφαλείας για κάθε αρχείο προορισμού,
3. εγγραφή μέσω ενός εκκρεμούς αρχείου αδερφού,
4. προωθήστε το αρχείο σε εκκρεμότητα και διαβάστε ξανά τα αποθηκευμένα byte.
5. επιβεβαιώστε κάθε προβλεπόμενη τιμή.
6. χρησιμοποιήστε αυτόματη επαναφορά από τα επαληθευμένα αντίγραφα ασφαλείας εάν κάποιο βήμα αποτύχει.

DynamicSpawns μπορεί να περιλαμβάνει τις ρυθμίσεις του και τα αναγνωρισμένα αρχεία μηνυμάτων του προγράμματος αναπαραγωγής σε μία συναλλαγή. RandomDay δεν αναφέρει αυτήν την ενημέρωση πολλών αρχείων ως επιτυχημένη, εκτός εάν ολοκληρωθεί η πλήρης συναλλαγή.

<a id="read-an-adapter-result"></a>
## Διαβάστε ένα αποτέλεσμα προσαρμογέα

| Αποτέλεσμα | Σημασία |
| --- | --- |
| `applied` | Οι αναγνωρισμένες ρυθμίσεις άλλαξαν και πέρασαν από την ανάγνωση. |
| `already_current` | Οι αναγνωρισμένες ρυθμίσεις αντιστοιχούσαν ήδη στο ενεργό προφίλ. |
| `not_installed` | Το προαιρετικό mod δεν βρέθηκε. RandomDay συνεχίστηκε χωρίς αυτό. |
| `skipped_incompatible` | Βρέθηκε ένα αρχείο, αλλά η πλήρης διάταξη ρύθμισής του δεν αναγνωρίστηκε. Δεν άλλαξε τίποτα. |
| `partial` | Το κύριο DynamicSpawns, αλλά δεν ολοκληρώθηκε ένα προαιρετικό μεταφρασμένο αρχείο μηνύματος. Ελέγξτε το αποτέλεσμα της εγγραφής του προσαρμογέα. |
| `failed_rolled_back` | Μια συναλλαγή απέτυχε και τα προηγούμενα byte παρέμειναν ανέπαφα ή αποκαταστάθηκαν και επαληθεύτηκαν. |
| `rollback_failed` | RandomDay δεν μπόρεσε να επαληθεύσει την αλλαγή ή την επαναφορά. Διατηρήστε το επηρεαζόμενο mod σταματημένο και επαναφέρετε το εγγεγραμμένο αντίγραφο ασφαλείας του με μη αυτόματο τρόπο. |

Οι προαιρετικές λειτουργίες που λείπουν και δεν είναι συμβατοί δεν σταματούν RandomDay's περιστροφή sandbox κάτω από τη διαμόρφωση αποστολής.

<a id="enable-or-disable-integrations"></a>
## Ενεργοποίηση ή απενεργοποίηση ενσωματώσεων

Τα στοιχεία ελέγχου βρίσκονται σε:

```text
RandomDay/Scripts/ax_config/server.lua
```

Το πακέτο αποκλειστικού διακομιστή αποστέλλεται με:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- Ορισμός `enabled = false` για να σταματήσετε RandomDay από τον έλεγχο ή την αλλαγή κάθε προαιρετικού mod.
- Καταργήστε ένα αναγνωριστικό προσαρμογέα για να αφήσετε αυτό το mod μόνο του, ενώ παράλληλα θα διατηρήσετε τις άλλες ενσωματώσεις ενεργές.
- Διατήρηση `patch_only_existing_keys` και `backup_before_write` ορίστηκε σε `true`. Αποτελούν το όριο ασφάλειας εγγραφής.
- Διατήρηση `optional_by_default = true` εκτός εάν κάθε προαιρετικό mod που αναφέρεται είναι απαραίτητο μέρος του διακομιστή. Ρυθμίστε το σε `false` κάνει έναν προσαρμογέα που λείπει, δεν είναι συμβατός ή έχει επαναφερθεί με ασφάλεια, επηρεάζει το συγκεντρωτικό αποτέλεσμα.

Δεν χρειάζεται να απεγκαταστήσετε ή να απενεργοποιήσετε ένα προαιρετικό mod όταν το απενεργοποιήσετε RandomDay προσαρμογέας.

RandomDay's χρησιμοποιούν μόνο πεδία διαμόρφωσης που υπάρχουν σε μια εγκατεστημένη, αναγνωρισμένη διάταξη. δεν αναδιανέμουν ούτε αντικαθιστούν αυτά τα mod.

<a id="backups-and-manual-recovery"></a>
## Δημιουργία αντιγράφων ασφαλείας και μη αυτόματη ανάκτηση

Τα επαληθευμένα αντίγραφα προεγγραφής διατηρούνται κάτω από:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

Αν `rollback_failed`:

1. διακοπή του παιχνιδιού ή του διακομιστή;
2. σύνολο `external_mods.enabled = false` ή αφαιρέστε το αναγνωριστικό προσαρμογέα που επηρεάζεται;
3. διατηρήστε το τρέχον αρχείο προορισμού και το αδερφό του pending/rollback αρχεία;
4. αντιστοιχίστε τα αριθμημένα αρχεία αντιγράφων ασφαλείας με τις διαδρομές προορισμού που έχουν καταγραφεί στο αποτέλεσμα του προσαρμογέα.
5. επαναφέρετε τα επαληθευμένα byte ενώ η υπηρεσία έχει διακοπεί.
6. ξεκινήστε το προαιρετικό mod από μόνο του πριν ενεργοποιήσετε ξανά το RandomDay προσαρμογέας.

Μην επιβάλλετε τη συμβατότητα μετονομάζοντας τις ρυθμίσεις ή προσθέτοντας κλειδιά που λείπουν. Χρησιμοποιήστε μια αναγνωρισμένη διάταξη, αφήστε τον προσαρμογέα απενεργοποιημένο ή προσθέστε μια νέα έκδοση προσαρμογής και δοκιμή συναλλαγής προτού επεκτείνετε την αξίωση υποστήριξης.
