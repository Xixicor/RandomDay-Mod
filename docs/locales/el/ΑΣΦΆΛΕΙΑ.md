# Πολιτική ασφαλείας

> **Κανονική αγγλική πηγή:** [SECURITY.md](../../../SECURITY.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


RandomDay εγγράφει αρχεία διαμόρφωσης διακομιστή και μπορεί να επιδιορθώσει τα προαιρετικά αρχεία διαμόρφωσης mod. Αντιμετωπίστε τις αλλαγές ως λειτουργικά ευαίσθητες.

<a id="do-not-report-as-security-issues"></a>
## Μην αναφέρετε ως ζητήματα ασφαλείας

- Κανονικές αλλαγές ισορροπίας παιχνιδιού.
- Αναμενόμενη εναλλαγή προφίλ επόμενης επανεκκίνησης.

<a id="report-privately"></a>
## Αναφορά ιδιωτικά

- Κίνδυνοι διέλευσης διαδρομής.
- Μη ασφαλής συμπεριφορά εγγραφής αρχείου.
- Δυνατότητα αντικατάστασης αρχείων εκτός του προβλεπόμενου server/mod μονοπάτια.
- Εκτέλεση κακόβουλης εντολής.

Μέχρι να υπάρχει ένα κανάλι δημόσιας ασφάλειας, αναφέρετε ιδιωτικά στον κάτοχο του χώρου αποθήκευσης.
