# RandomDay个人资料文档

> **规范的英文来源:** [README.md](../../../profiles/README.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


版本：`v0.3.16-alpha`

- 家庭：**17**
- 个人资料： **289**
- SandboxSettings字典条目：**46**

在个人资料选择指南中根据游戏意图选择一个系列[个人资料选择指南](../%E9%80%89%E6%8B%A9%E9%85%8D%E7%BD%AE%E6%96%87%E4%BB%B6.md)，然后使用此生成的索引获取精确值。

这些文件是从运行时 Lua 源及其 dictionary/translation 合约生成的。它们显示已发货的 `sandbox.profile_overrides` 默认值；一台服务器的配置值可能不同：

- `profiles.generated.json`：机器可读的配置文件、原始值、字典和翻译。
- `FULL_PROFILE_REFERENCE.md`：完整的索引和解释规则。
- `SANDBOX_SETTINGS_KEYS.md`：完整的 46 键字典。
- `families/*.md`：详细的 17 天家庭参考资料。

重新生成：`python -B tools/generate_profile_docs.py`检查对于漂移： `python -B tools/generate_profile_docs.py --check`
