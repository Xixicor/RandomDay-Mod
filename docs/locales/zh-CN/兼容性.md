<a id="compatibility"></a>
# 兼容性

> **规范的英文来源:** [COMPATIBILITY.md](../../COMPATIBILITY.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


<a id="supported-installations"></a>
## 支持的安装

RandomDay专为可以加载UE4SSLua mods的非生物因素安装而构建。

| 环境 | 支持 | 套餐 |
| --- | --- | --- |
| Windows 专用服务器 | 支持 | 专用服务器ZIP |
| Windows单人游戏或LAN主机 | 支持手动复制工作流程 | Singleplayer/LAN ZIP |
| 使用 Wine 或 Proton 的 Linux 服务器 | 未经版本测试 | Windows 专用包可能会由经验丰富的操作员进行评估，但不做出兼容性承诺。 |
| Xbox 和PlayStation | 不支持 | 这些平台不提供此版本所需的文件访问和 UE4SSLua 加载路径。 |

RandomDay不会合并这两个包。仅偶尔启动的专用服务器仍使用专用服务器ZIP并在配置中选择临时行为。

<a id="abiotic-factor-updates"></a>
## 非生物因子更新

游戏更新后，从服务器停止开始并保留世界、`SandboxSettings.ini` 和 RandomDay状态。确认UE4SS加载，然后完成一个RandomDay循环，并在恢复正常旋转之前检查活动的和准备好的配置文件。

<a id="companion-mods"></a>
## 配套模组

RandomDay仅当其完整设置布局与支持的适配器匹配时才更改单独安装的模组。仅有版本号是不够的。

| 集成 | 当前版本已审核 | RandomDay支持边界 |
| --- | --- | --- |
| 混沌生成引擎/DynamicSpawns | `0.8.5`；主文件`0.8.5-Hotfix1` | 支持的`SharedData.lua`布局涵盖了生成、冷却时间、人口、传送门、突破口、boss和RandomDay适配器参考中列出的遭遇设置。 |
| 致命激光 | `1.0-UE4SS` | 支持的`Scripts/main.lua`布局涵盖了可识别的发射器、环境发射器、反射器和棱镜设置。 |
| ANTE向上 | `1`，于 2026 年 7 月 19 日更新 | 当前公共布局尚未完成适配器固定装置。 RandomDay 会原封不动地跳过不匹配的文件，直到验证该布局。 |

缺失、禁用或无法识别的配套模组保持不变。请参阅[支持的可选模组](%E6%94%AF%E6%8C%81%E7%9A%84%E9%80%82%E9%85%8D%E5%99%A8.md)了解确切的设置、配置控制、备份行为和恢复步骤。

<a id="what-compatibility-validation-proves"></a>
## 兼容性验证证明了什么

存储库验证可以证明已发货的包布局、配置覆盖范围、已识别的适配器字段、备份和恢复行为以及对未知布局的安全拒绝。它无法证明未来的每一个非生物因子、UE4SS或companion-mod版本。发行说明命名了经过测试的版本，而不是假设成功加载后的兼容性。
