# 单人游戏和 LAN手动工作流程

> **规范的英文来源:** [SINGLEPLAYER_LAN.md](../../SINGLEPLAYER_LAN.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDay's singleplayer/LAN打包生成完整的`SandboxSettings.ini` 在 mod 文件夹内。您选择世界并在游戏关闭时手动复制文件。

包被锁定到此输出：

```text
RandomDay/runtime/singleplayer_manual/SandboxSettings.ini
```

它禁用专用服务器沙箱写入、沙箱镜像和所有可选适配器写入。它不搜索AppData，Steam 用户数据、文档、保存文件夹、服务器文件夹或第三方 mod 文件夹。

<a id="understand-the-manual-boundary"></a>
## 了解手动边界

开始之前，请在 `RandomDay/Scripts/ax_config/server.lua`。手动包接受`experience.mode="auto"` 或 `"singleplayer_lan"`。您可以选择固定或随机的第一天以及连续或非重复随机的 17 天订单。系列选择使用与专用服务器相同的选定、轮换或非重复随机系列设置。

生成的输出包含标记RandomDay 读取下一个进程。为了保持状态对齐，请在开始另一个生成过程之前将生成的文件复制到所选的停止世界中。即使世界从未加载先前的输出，重复启动而不复制也可以推进 mod-local 队列。

遵循规范[单人游戏或LAN安装过程](%E5%AE%89%E8%A3%85.md#singleplayer-or-lan)进行备份、包放置、启用、生成、手动复制、验证。本页解释了手动边界；它没有定义其他安装方法。

第一代准备一个配置文件；它没有定义其他安装方法。它不能更改该游戏进程已加载的规则。关闭、复制并重新开始即可使用。仅当您故意想要下一个持久日时才重复该循环。

删除RandomDay不会恢复您手动复制的世界文件；使用您自己的备份进行回滚。请按照[删除或回滚任何安装](%E5%AE%89%E8%A3%85.md#remove-or-disable-randomday)了解确切的删除过程。
