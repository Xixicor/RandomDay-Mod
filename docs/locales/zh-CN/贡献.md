<a id="contributing"></a>
# 贡献

> **规范的英文来源:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDay 作为受控项目进行维护。

除非存储库所有者明确请求，否则不接受公开拉取请求、未经请求的代码提交、自动重写、生成的代码清理提交和推测性功能补丁。

<a id="accepted-contact"></a>
## 接受联系方式

有关错误报告、兼容性说明或服务器管理意见，请使用项目文档中列出的联系渠道。

<a id="not-accepted"></a>
## 不接受

默认情况下不接受以下内容：

- 未经请求的拉取请求；
- 生成的代码重写；
- 广泛重构；
- 仅样式格式更改；
- 未经测试的游戏逻辑更改；
- 捆绑的第三方模组文件；
- 重新分发的第三方源代码；
- 暗示与 Abiotic Factor 的官方关系的更改，UE4SS、Nexus Mods 或第三方 Mod 作者。

<a id="controlled-development"></a>
## 受控开发

存储库所有者可以在需要时请求特定的审查、测试或文档帮助。未经请求的提交可能会在未经审核的情况下关闭。
