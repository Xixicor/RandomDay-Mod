# 安全策略

> **规范的英文来源:** [SECURITY.md](../../../SECURITY.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDay 写入服务器配置文件并可以修补可选的 mod 配置文件。将更改视为操作敏感的更改。

<a id="do-not-report-as-security-issues"></a>
## 请勿报告为安全问题

- 正常游戏平衡变化。
- 预计下次重新启动配置文件轮换。

<a id="report-privately"></a>
## 私下报告

- 路径遍历风险。
- 不安全的文件写入行为。
- 能够覆盖预期路径之外的文件server/mod。
- 恶意命令执行。

在公共安全渠道存在之前，私下向存储库所有者报告。
