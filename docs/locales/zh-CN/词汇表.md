# 词汇表

> **规范的英文来源:** [GLOSSARY.md](../../GLOSSARY.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


下的 Markdown 和 RandomDay文档。程序链接到这些定义，而不是在多个指南中重新定义相同的状态。特定于架构的字段规则保留在 [运行时输出](%E8%BF%90%E8%A1%8C%E6%97%B6%E8%BE%93%E5%87%BA.md).

| 术语 | 简单含义 | 确切的技术含义 |
|---|---|---|
| 活动配置文件 | 当前会话正在使用的规则。 | family/day配置文件由进程启动时从沙箱读取的RandomDay标记标识。 |
| 准备好的配置文件 | 规则已为以后的会话做好准备。 | 完整的family/day配置文件，其目标字节通过了验证和回读，并且其旋转状态已提交。在重新启动回读之前它不是活动的。 |
| 已恢复 | 准备失败，先前验证的字节已放回。 | 失败的事务报告成功回滚和读回所保留的原始或已验证的恢复副本。 |
| 下次重新启动队列 | 为下次启动保留一个准备好的选择。 | `next_reboot_queue`每个进程选择一次并重用该启动拥有的选项监督期间的选择。 |
| 引导 | 不存在活动标记时的第一个准备。 | 从符合条件的系列中选择配置的或随机的第一天；`cycle.bootstrap_day`只是兼容性回退。 |
| 家庭 | 17 天的游戏风格进展。 | 一个注册表项和家庭模块，可生成 17 个完整的个人资料。 |
| 旋转 | 合格家庭的通行证。 | 由 `rotation_id` 确定的州，包括可用、剩余和已完成的家庭 |
| 运行 | 在所有 17 天 ID 中运行一个家族。 | 由 `run_id` 识别的家族结合序列；该系列将保持锁定状态，直到每个持久日订单头寸完成为止。 |
| 会话模式 | 操作员如何使用此包。 | `persistent_dedicated`, `temporary_dedicated`，或 `singleplayer_lan`；包模式仍然控制文件系统边界。 |
| 日顺序 | 一个系列运行所使用的确切顺序。 | 持久的 17 个数字排列。顺序模式从开始之日起循环；随机模式随机洗牌一次，不重复。 |
| 标记 | 存储在沙箱文件中的身份。 | `RANDOMDAY_*`使用完整配置文件呈现的字段，并在下一个进程启动时读取。 |
| 准备就绪 | 写入和状态提交成功。 | `prepared_ready=true` 需要成功的沙箱结果并且没有状态提交失败。它并不证明激活。 |
| 已经是最新的 | 目标已经具有预期的字节。 | 呈现的配置文件哈希与目标匹配，因此RandomDay验证另一个已安装的last-good/mirror无需重写主数据即可工作。 |
| 降级状态持久性 | 沙箱字节成功，但轮换簿记未成功。 | `profile_status=degraded_state_persistence`；跳过适配器和准备好的配置文件消息传递。 |
| 待处理文件 | 尚未提升的候选字节。 | `<target>.randomday.pending`，在替换之前写入、读回和验证。 |
| 回滚文件 | 替换期间保留的原始文件。 | `<target>.randomday.rollback`，使用在升级或验证失败时恢复生产。 |
| 操作备份 | 在突变之前制作的持久副本。 | 在 `runtime/backups/` 下针对主、镜像或适配器事务进行验证的文件。 |
| 最后一次已知的正确 | 接受恢复的最新沙箱。 | `runtime/last_good/SandboxSettings.ini` 加 `manifest.lua`；该对记录配置文件身份和哈希。 |
| 镜像 | 可选的第二个沙箱目标。 | 通过自己的事务在主目标之后写入的显式配置或世界名称派生目标。 |
| 打包模式 | 安装由发布资产选择的边界。 | `dedicated_server` 或 `singleplayer_manual`从`.randomday_mode`. |
| 手动复制模式 | Singleplayer/LAN无需保存发现即可生成。 | `singleplayer_manual` 仅在内部写入 `runtime/singleplayer_manual/` 并禁用适配器和镜像。 |
| 适配器 | RandomDay-owned映射另一个已安装的模组。 | 签名门控交易计划，仅在备份和兼容性检查后更新现有分配。 |
| 识别的布局 | 接受写入的确切适配器文件形状。 | 所有必需的签名密钥和目标文件均已存在；仅有文件名是不够的。 |
| `not_installed` | 未找到可选目标。 | 安全的适配器结果，没有突变。 |
| `skipped_incompatible` | 目标存在，但其形状不受支持。 | 安全的适配器结果，没有突变，因为完整的签名不匹配。 |
| `failed_rolled_back` | 更改失败，之前的字节完好无损。 | 适配器事务在突变之前失败或恢复并验证所有受影响的文件。 |
| `rollback_failed` | 无法验证自动恢复。 | 硬停止适配器状态需要从记录的备份中手动恢复。 |
| 字典 | 从原始值到公共解释的映射。 | `randomday_dictionary_v2`，从 `dictionary.lua` 并包含在运行时状态输出中。 |
| 翻译 | 从原始配置文件值派生的人类视图。 | 由 `translation.lua`;原始值仍然具有权威性。 |
| 公共状态 | 清理后的机器可读操作员摘要。 | `web_export/today.json`使用`randomday_public_status_v2`. |
| 运行时状态 | 详细的本地机器可读快照。 | `runtime/current/randomday_status.json`使用`randomday_runtime_status_v2`. |
