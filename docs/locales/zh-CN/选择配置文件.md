# 选择您想要的游戏类型

> **规范的英文来源:** [CHOOSE_A_PROFILE.md](../../CHOOSE_A_PROFILE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDay包括 289 组现成的世界规则。他们分为 17 个**系列**，每个系列中有 17 个**个人资料**：

- 家族是一种广泛的游戏风格，例如生存、建筑、潜行或探索；
- 配置文件是该游戏风格内的一套完整规则；
- 配置文件编号称为一天，因为RandomDay随着服务器重新启动，会在这 17 个位置之间移动。这不是现实世界的日历日。

从下表开始。选择听起来最接近您想要的会话的行，然后打开一两个家庭页面来比较它们的确切效果。

<a id="confirm-the-exact-family-and-day"></a>
## 确认确切的系列和日期

1. 打开系列页面并比较所有 17 天的位置。
2. 使用[完整个人资料参考](%E5%89%96%E9%9D%A2/%E5%AE%8C%E6%95%B4%E9%85%8D%E7%BD%AE%E6%96%87%E4%BB%B6%E5%8F%82%E8%80%83.md) 比较所有 289 种组合的配置文件名称和解释规则。
3. 暂时使用[沙箱设置键](%E5%89%96%E9%9D%A2/%E6%B2%99%E7%AE%B1%E8%AE%BE%E7%BD%AE%E9%94%AE.md)解释每个原始值、支持的范围、分数范围和出厂的配置文件默认值。
4. 暂时使用[`profiles.generated.json`](../../profiles/profiles.generated.json)当工具需要精确的机器可读配置文件、字典和翻译源时。

<a id="configure-the-chosen-experience"></a>
## 配置所选体验

按照[选择体验](%E9%85%8D%E7%BD%AE.md#choose-an-experience)设置系列模式、符合条件的家庭列表、起始日行为以及顺序或非重复随机日顺序。 RandomDay 保留所选顺序；恢复不会默默地重新滚动正在进行的家庭运行。
