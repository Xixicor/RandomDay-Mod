# 十七个家庭，十七天

> **规范的英文来源:** [FAMILY_ROTATION.md](../../FAMILY_ROTATION.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDay包含 17 种游戏风格每个家庭有17个完整的日常档案。这产生了 289 个记录family/day 组合。

该家族设定了跑步的大致风格。第 1 天到第 17 天提供了该家庭在压力、恢复、节奏和资源方面的进展。一次运行仅存储一次包含每日 ID 的订单。重新启动前进到下一个存储位置； RandomDay 不会在订单中间更改系列。

<a id="selection-modes"></a>
## 选择模式

| 模式 | 新运行行为 | 运行期间 |
|---|---|---|
| `selected_run` | 使用`profile_family.selected_family`. | 在所有 17 个存储位置中保留该族。 |
| `non_repeating_random_run` | 选择符合条件的未使用系列。 | 保留所有 17 个位置并避免家庭重复，直到符合条件的列表用完为止。 |
| `rotation_run` | 按照配置的顺序获取下一个系列。 | 保留所有 17 个存储位置。 |

附带的配置使用`non_repeating_random_run`。最终储存位置后准备的家庭仍然只是准备；重新启动后它将变为活动状态。 `cycle.start_day_mode` 和 `cycle.day_progression_mode`在不更改家庭选择的情况下选择第一天和当天的顺序。

<a id="custom-families-and-days"></a>
## 自定义家庭和日期

家庭来源位于：

```text
RandomDay/Scripts/ax_profiles/families/
```

JSON 这是 `docs/profiles/`下的Markdown和JSON是生成的引用。更改源，而不是生成的输出，然后运行完整的 profile/schema 验证。自定义设置仅一天解析时尚未准备好；所有 17 天，配置的配置文件默认值、类型、范围和生成的参考必须一致。
