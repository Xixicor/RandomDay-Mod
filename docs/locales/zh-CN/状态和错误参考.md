# 状态和错误参考

> **规范的英文来源:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


使用确切的`status`, `transaction_status`, `rollback_status` 和 `error` 来自运行时导出的值。面板或控制台中的类似措辞不能替代这些字段。

此部分是完整的查找参考。上面的决策树选择相关类别；这些表保留了准确的机器值和安全的操作员响应。

<a id="normal-or-informational-states"></a>
## 正常或信息状态

| 状态 | 含义 | 操作员响应 |
|---|---|---|
| `prepared_for_next_reboot` | 已为下次启动写入经过验证的配置文件。 | 无操作；当前会话未更改。 |
| `next_reboot_already_prepared` | 预期的下一个配置文件已与目标匹配。 | 无操作；请勿强制再次轮换。 |
| `already_current` / `unchanged` | 目标已包含预期字节。 | 无操作。 |
| `applied` | 写入和生产读回已通过。 | 下次启动后验证active/prepared区别。 |
| `bootstrap_prepare_first_family_start_day` | 不存在先前的轮换状态，因此已准备好配置的第一天。 | 预计首次使用。 |
| `state_recovery_rewrite_prepared_profile_no_reroll` | 存储的状态已恢复，并重写了相同的准备配置文件。 | 验证恢复的日期；没有发生新的随机选择。 |
| `supervision_reconfirm_prepared_profile_no_advance` | 监督通过确认了现有的准备工作。 | 预期；队列未前进两次。 |
| `external_mods_disabled` | 可选适配器处理已禁用。 | 除非打算使用适配器，否则不会采取任何操作。 |
| `external_mods_processed` | 所有启用的适配器计划都达到了最终结果。 | 检查每个适配器行。 |

<a id="startup-configuration-errors"></a>
## 启动配置错误

这些消息在RandomDay写入配置文件之前停止启动。更正命名设置或包标记；不要绕过验证分支。

| 错误文本 | 含义 | 安全响应 |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode`丢失、格式错误或来自错误的软件包。 | 将一个完整的软件包重新安装到干净的暂存文件夹中并保留预期的模式标记。 |
| `invalid experience.mode` | `experience.mode`不是记录的值之一。 | 暂时使用`auto`, `persistent_dedicated`, `temporary_dedicated`，或 `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | 手动复制软件包已配置为专用服务器。 | 恢复`auto` 或 `singleplayer_lan`；不要自动将其指向外部世界。 |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | 为手动复制工作流程配置了专用包。 | 暂时使用`auto`, `persistent_dedicated`，或 `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | 初始日期选择器无效。 | 准确使用`configured` 或 `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | 日期顺序选择器无效。 | 准确使用`sequential` 或 `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | 配置的开始日期为小数或超出范围 | 使用从 1 到 `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | 备份或上次良好恢复已禁用。 | 恢复两个安全锁； RandomDay故意拒绝不安全的写入。 |
| `external adapter transaction safety locks must remain true` | 适配器修补或备份保护已禁用。 | 恢复两个适配器安全锁或将适配器作为一个组禁用。 |
| `paths.world_name must be one folder name` | 配置的世界名称包含分隔符或不安全字符。 | 仅输入确切的文件夹名称，使用字母、数字、空格、下划线或连字符。 |
| `required runtime directory unavailable` | 无法创建或确认所需的 mod-local 输出目录。 | 仅检查指定的RandomDay目录及其写入权限。 |

<a id="profile-wide-configuration-errors"></a>
## 配置文件范围的配置错误

这些错误会在沙箱写入之前停止配置文件构建。

| 错误文本 | 含义 | 安全响应 |
|---|---|---|
| `sandbox.profile_overrides must be a table` | 四个配置文件范围的选择已替换为另一种 Lua 类型。 | 恢复 `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | 该表包含的设置不属于四个受支持的键之一。 | 删除指定的密钥并使用family/profile 其他沙箱设置的来源。 |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` 或 `AllowIronMode` 不是 `true` 或 `false`. | 使用不带引号的 Lua 布尔值。 |
| `sandbox.profile_overrides.<key> must be integer` | 支持值不是整数。 | 使用整数。 |
| `sandbox.profile_overrides.<key> outside supported range` | 支撑值超出`0..1000`. | 从 `0`到`1000`. |

<a id="rollback-and-intermediate-states"></a>
## 回滚和中间状态

| 值 | 含义 | 安全响应 |
|---|---|---|
| `not_started` / `pending` | 事务或适配器计划尚未达到最终结果。 | 仅等待当前有界启动阶段；持久状态需要调查。 |
| `not_needed` | 无需回滚。 | 无操作。 |
| `original_held` | 原始目标在提升前已移至恢复位置。 | 交易未完成时请勿删除恢复文件。 |
| `retained_after_success` | 新目标已验证，但恢复数据仍然存在，因为清理不可用或有意保留。 | 在删除任何指定的恢复文件之前验证生产字节。 |
| `discarded_after_success` | 替换验证和临时回滚数据已清除。 | 无操作。 |
| `rollback_failed` | 无法验证尝试的恢复。 | 保持服务器停止并使用上次验证的操作备份。 |
| `skipped_state_persistence_failed` | 沙箱字节已准备好，但旋转状态未持续，因此适配器和准备好的播放器消息传递被跳过。 | 修复运行时状态存储；不要手动重新滚动或推进队列。 |
| `failed` | 摘要行表示终端故障，其具体原因在其`error` 或交易字段。 | 遵循第一个具体代码；不要从 `failed` 单独。 |

<a id="transaction-failures"></a>
## 交易失败

| 状态 | 含义 | 安全响应 |
|---|---|---|
| `invalid_input` | 替换请求不是有效文本或缺少有效目标。 | 正确配置；请勿按原样重试。 |
| `stale_pending_cleanup_failed` | 无法删除旧的挂起文件。 | 在手动清理之前停止并保留挂起的文件。 |
| `stale_rollback_requires_review` | 恢复数据存在于当前目标旁边，无法安全丢弃。 | 在选择之前比较目标字节和回滚字节。 |
| `interrupted_transaction_restore_failed` | 中断替换后的恢复无法恢复目标。 | 保持服务器停止并恢复经过验证的备份。 |
| `interrupted_transaction_cleanup_failed` | 目标已恢复，但无法清除过时的交易数据。 | 验证目标字节，然后仅删除指定的过时 sidecar。 |
| `pending_write_failed` | 无法写入候选人。 | 检查狭窄的目标目录和可用空间。 |
| `pending_readback_failed` / `pending_readback_mismatch` | 候选字节无法读取或写入后不同。 | 不要升级待处理的文件。 |
| `pending_validation_failed` | 候选人失败schema/profile 升级前验证。 | 修复报告的键或规则；不要绕过验证。 |
| `operation_backup_failed` / `backup_failed` | 未创建经过验证的预写备份。 | 停止；不应信任目标替换。 |
| `original_preserved_move_failed` | 原始目标无法移至恢复位置。 | 保留所有事务文件并手动恢复。 |
| `promotion_failed` | 待处理的候选目标无法成为生产目标。 | 在重试之前检查原始目标是否已恢复。 |
| `production_validation_failed` | 提升的字节失败了生产readback/validation. | 恢复已验证的备份并检查目标写入器。 |
| `replacement_committed_recovery_cleanup_failed` | 替换有效，但无法清除回滚数据。 | 将目标视为已提交；仅删除已验证的过时恢复数据。 |
| `rollback_failed` | 自动恢复未验证。 | 让服务器停止并使用手动恢复。 |

<a id="target-profile-adapter-and-export-failures"></a>
## 目标、配置文件、适配器和导出失败

| 状态 | 含义 | 安全响应 |
|---|---|---|
| `target_refused` | 配置的路径超出允许的模式边界。 | 更正路径；切勿削弱边界。 |
| `target_directory_failed` | 无法创建或确认目标目录。 | 仅检查该目录的存在和权限。 |
| `profile_validation_failed` | 配置文件缺少密钥、有错误type/range或违反剩余的不变规则。 | 使用命名密钥， `sandbox.profile_overrides`，以及用于修复源的配置文件参考。 |
| `skipped_incompatible` | 存在可选 mod，但与支持的适配器签名不匹配。 | 保留其不变或禁用该适配器。 |
| `external_mods_partial` | 一些可选适配器已完成，其他适配器已安全skipped/failed. | 独立审核适配器行；沙箱结果是单独的。 |
| `external_adapter_failed` | 所需的适配器未安全完成。 | 在重试之前恢复其经过验证的备份。 |
| `degraded_state_persistence` | 沙盒准备已完成，但旋转状态持久性未完成。 | 不要假设下次启动可以正确进行；修复状态存储。 |
| `export_directory_failed` | `web_export/` 无法创建或写入。 | 游戏准备可能仍然有效；单独修复报告。 |

<a id="translation-and-message-validation-errors"></a>
## 翻译和消息验证错误

这些是字典或表示契约失败。它们在发布前经过验证，也可能显示为有限的运行时状态警告。

| 错误文本 | 含义 | 安全响应 |
|---|---|---|
| `dictionary coverage mismatch` | 配置文件字典不会解释每个记录的设置。 | 添加缺少的字典条目并重新运行配置文件generation/validation. |
| `missing profile setting` | 所选配置文件缺少 dictionary/schema. | 修复配置文件系列源；不要发明运行时默认值。 |
| `empty explanation` | 设置存在但没有operator/player 解释。 | 发布前添加通俗易懂的解释。 |
| `join line too wide` | 生成的连接行超出了 42 个字符的源限制。 | 缩短字典短语；不要依赖客户端包装。 |
| `join message too tall` | 生成的连接摘要超过四行。 | 减少消息内容或重新调整消息内容的优先级。 |
