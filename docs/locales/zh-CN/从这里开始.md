# 从这里开始：完成第一个RandomDay周期

> **规范的英文来源:** [START_HERE.md](../../START_HERE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


本指南在安装RandomDay后开始。它显示了 mod 更改的内容、保留的内容以及如何识别一个成功的周期。

<a id="know-the-two-states"></a>
## 了解两种状态

Abiotic Factor 在RandomDay 开始之前读取世界的沙盒设置。 RandomDay因此保留两个明确命名的状态：

- **活动配置文件：**当前会话已使用的规则。
- **准备的配置文件：**为下次启动保存的规则。

准备的配置文件不会更改已在进行中的会话。

<a id="dedicated-server-prepare-the-next-profile"></a>
## 专用服务器：准备下一个配置文件

1. 正常启动服务器。
2. 等待RandomDay完成其启动工作。
3. 在已安装的 mod 文件夹中打开 `RandomDay/web_export/today.html`。
4. 查找**活动配置文件** 和 **准备好的配置文件**.

在第一次成功启动时，页面应命名已激活的规则和等待下一次启动的不同配置文件。该页面还解释了所选的系列、位置以及准备的文件是否通过了安全检查。

不要仅仅为了更改状态而重新启动。继续使用活动规则，直到下一次计划的服务器启动。

<a id="dedicated-server-activate-it-later"></a>
## 专用服务器：稍后激活

1. 在下一次计划的重新启动时停止并启动服务器。
2. 再次打开可读状态页面。
3. 确认之前准备的配置文件现已列为活动状态。
4. 确认RandomDay准备了以下配置文件。

准备-然后-激活转换是其中之一完成RandomDay循环。

<a id="temporary-dedicated-servers"></a>
## 临时专用服务器

临时行为使用相同的专用服务器包。在 [配置](%E9%85%8D%E7%BD%AE.md) 中，选择新的运行是在特定配置文件上开始还是选择随机起点。状态页面仍然将活动配置文件与为下一次启动准备的配置文件分开。

<a id="singleplayer-or-lan"></a>
## 单人游戏或 LAN

1. 使用 singleplayer/LAN 软件包已安装。
2. 完成后完全关闭游戏RandomDay。
3. 阅读生成的摘要。
4. 复制生成的`SandboxSettings.ini`进入游戏关闭时您选择的世界。
5. 启动那个世界并确认预期的规则。

本地包永远不会选择世界或将文件复制到自己的保存中。请参阅 [单人游戏和 LAN](%E5%8D%95%E4%BA%BA%E5%B1%80%E5%9F%9F%E7%BD%91.md) 了解完整过程。

<a id="if-the-expected-result-is-missing"></a>
## 如果缺少预期结果

不要继续重新启动。保留当前文件并在[疑难解答](%E7%96%91%E9%9A%BE%E8%A7%A3%E7%AD%94.md)中选择匹配的症状。正常结果总是命名一个活动配置文件以及一个准备好的配置文件或一个明显的准备失败。
