# 打包源代码参考

> **规范的英文来源:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


发布ZIP 恰好包含下面的 51 条路径。构建器会拒绝丢失的路径、附加的包形源、大小写冲突、符号链接或其文字允许列表之外的成员。运行时输出、测试、存储库文档和第三方 mod 不是包成员。

机器可检查的伴侣是[`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json)。它记录具有输入、输出、副作用、公共设置、可见状态、故障模式、可编辑性和规范文档的相同路径。

每个发布的 Lua 行都有一个稳定的`module-*`锚点。其规范源标头和机器记录中的相同链接使得所有权、合同、副作用、故障和恢复可直接追踪。
