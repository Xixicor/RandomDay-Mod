# ریلیز کی توثیق

> **کیننیکل انگریزی ماخذ:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


یہ صفحہ شراکت داروں اور ریلیز مینٹینرز کے لیے ہے۔ موڈ انسٹال کرنے والے پلیئرز کو ان کمانڈز کو چلانے کی ضرورت نہیں ہے۔

<a id="ordinary-user-proof"></a>
## عام صارف کا ثبوت

ایک ریلیز سمجھ میں آتی ہے جب کوئی نیا قاری دو پیکجوں میں سے کسی ایک کا انتخاب کر سکتا ہے، اسے انسٹال کر سکتا ہے، فعال پروفائل اور تیار شدہ پروفائل کی شناخت کر سکتا ہے، اور لنک شدہ گائیڈ کی پیروی کر کے گمشدہ نتائج سے بازیافت کر سکتا ہے۔ قارئین کے ان کاموں کو Git کی ضرورت نہیں ہونی چاہیے، PowerShell، ازگر، یا چیکسم علم۔

<a id="contributor-checks"></a>
## Contributor کے چیک

ریپوزٹری روٹ سے چلائیں:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

کب `luac` دستیاب ہے، ہر بھیجی گئی Lua فائل کو نحو کی جانچ پڑتال کریں:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

Lua رن ٹائم ٹیسٹ کی ضرورت ہے `lupa`۔ لاپتہ Lua ترجمان یا `lupa` انسٹالیشن ایک غیر دستیاب ٹیسٹ کی اہلیت ہے، نہ کہ پاس ہونے والا نتیجہ۔

<a id="release-checks"></a>
## ریلیز چیک

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

ریلیز چیک ان شرائط کی تصدیق کرتا ہے:

- `VERSION` اور `RandomDay/.randomday_version` میچ۔
- صرف موجودہ ورژن `releases/`.
- سرشار اور singleplayer/LAN زپ مکمل متبادل ہیں۔
- دونوں آرکائیوز میں کینونیکل `RandomDay/Scripts/main.lua` راستہ اور کوئی کیس ٹکرانے والا لوڈر نہیں۔
- پیکیج موڈ مارکر ہیں `dedicated_server` اور `singleplayer_manual`.
- ZIP بائٹس تعییناتی ہیں اور مماثل ہیں `CHECKSUMS.sha256`.
- کوئی رن ٹائم ڈیٹا، نجی کنفیگریشن، اسناد، کیچز، یا ٹیسٹ آؤٹ پٹ پیک نہیں کیا گیا ہے۔
- تمام مقامی دستاویزات کے لنکس اور 27 مقامی اندراج کے صفحات کی توثیق ہوتی ہے۔

<a id="avoid-validation-environment-pitfalls"></a>
## توثیق کے ماحول کے نقصانات سے بچیں

- ریپوزٹری رائٹنگ چیکس کو سلسلہ وار چلائیں تاکہ دو پروسیس ایک ہی عارضی فائل کو ایک ساتھ تبدیل نہ کریں۔
- ونڈوز پر، چیک کریں ZIP یہ فیصلہ کرنے کے لیے کہ آیا لوئر کیس لوڈر موجود ہے یا نہیں، کیس غیر حساس فائل تلاش کرنے کے بجائے اراکین کے نام۔
- تصدیق کریں `mods.txt` اور `enabled.txt` صرف انسٹال سرور ٹیسٹ میں؛ وہ اس بات کا ثبوت نہیں ہیں کہ سورس ٹیسٹ چلائے گئے۔
- کمانڈ ٹائم آؤٹ کو نامکمل کے طور پر ریکارڈ کریں۔ کمانڈ کے پابند آؤٹ پٹ کے بغیر اسے پاس یا فیل میں تبدیل نہ کریں۔
- عارضی فائلوں کو ذخیرہ کے اندر رکھیں جسے نظر انداز کیا گیا ہے `.tmp/` ڈائریکٹری۔

<a id="known-limits"></a>
## معلوم حدود

مقامی توثیق ماخذ، پیکیج، دستاویزات، اور فکسچر کے معاہدوں کو ثابت کرتی ہے۔ یہ کسی خاص سرور پینل کے سٹارٹ اپ آرڈر، لائیو کلائنٹ کے میسج لے آؤٹ، یا میزبان کے لیے مخصوص فائل سسٹم کا راستہ ثابت نہیں کرتا ہے۔ جب ان کا تجربہ کیا جائے تو ان کو الگ الگ انضمام کے نتائج کے طور پر ریکارڈ کریں۔
