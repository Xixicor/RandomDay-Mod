# انسٹال کریں، اپ ڈیٹ کریں یا ہٹائیں RandomDay

> **کیننیکل انگریزی ماخذ:** [INSTALL.md](../../../INSTALL.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


RandomDay میں دو مکمل ڈاؤن لوڈ ہیں۔ آپ جس دنیا کو ترتیب دے رہے ہیں اس کے لیے ایک کا انتخاب کریں:

- استعمال کریں **سرشار سرور ZIP** کسی بھی سرشار سرور کے لیے، بشمول ایک سرور جو صرف کبھی کبھار سیشنز کے لیے کھولا جاتا ہے؛
- استعمال کریں **singleplayer/LAN ZIP** ایک مقامی دنیا کے لیے جس کی ترتیبات آپ دستی طور پر کاپی کریں گے۔

پیکیجز کو یکجا نہ کریں۔ ایک مستقل یا عارضی سرور RandomDay's ترتیبات، کوئی مختلف ڈاؤن لوڈ نہیں۔

<a id="before-you-begin"></a>
## اس سے پہلے کہ آپ شروع کریں

اس کی ایک قابل بحالی کاپی بنائیں:

- جس دنیا کو آپ تبدیل کر رہے ہیں؛
- اس کا موجودہ `SandboxSettings.ini`;
- موجودہ `RandomDay` فولڈر، اگر کوئی انسٹال ہو۔

انسٹال کریں UE4SS پہلے RandomDay۔ نیچے دی گئی ہدایات میں، **Mods فولڈر** کا مطلب ہے `ue4ss/Mods/` گیم کے اندر ڈائرکٹری یا سرشار سرور انسٹالیشن۔

<a id="dedicated-server"></a>
## سرشار سرور

<a id="new-installation"></a>
### نئی تنصیب

1. سرور کو روکیں۔
2. اسے کھولیں UE4SS `Mods` فولڈر۔
3. سرشار سرور کو نکالیں ZIP۔ نتیجہ ایک ہونا چاہیے `ue4ss/Mods/RandomDay/` فولڈر، دوسرے کے اندر کا فولڈر نہیں `RandomDay` فولڈر۔
4. اس فولڈر کو کھولیں اور تصدیق کریں `RandomDay/Scripts/main.lua` موجود ہے۔ اگر یہ غائب ہے تو ZIP غلط سطح پر نکالا گیا تھا۔
5. کھولیں UE4SS `mods.txt` اور اس لائن کو فعال کریں:

   ```text
   RandomDay : 1
   ```

6. سرور کو عام طور پر شروع کریں۔
7. کھولیں RandomDay's پڑھنے کے قابل اسٹیٹس کا صفحہ اور تصدیق کریں کہ یہ فعال پروفائل اور اگلی شروعات کے لیے تیار کردہ پروفائل دونوں کا نام ہے۔

پہلا آغاز اس سیشن کے ذریعہ پہلے سے لوڈ کردہ قواعد کو تبدیل نہیں کرتا ہے۔ یہ اگلا پروفائل تیار کرتا ہے۔ سرور کو دوبارہ شروع کریں تبھی جب آپ چاہتے ہیں کہ وہ تیار شدہ پروفائل فعال ہو۔

[پہلا چکر چیک کریں](%DB%8C%DB%81%D8%A7%DA%BA_%D8%B4%D8%B1%D9%88%D8%B9_%DA%A9%D8%B1%DB%8C%DA%BA.md)

<a id="choose-always-on-or-temporary-behavior"></a>
### ہمیشہ آن یا عارضی رویہ کا انتخاب کریں

ڈیڈیکیٹڈ-سرور پیکیج دونوں طرزوں کو سپورٹ کرتا ہے:

- **مسلسل وقف** عام دوبارہ شروع ہونے پر محفوظ شدہ گردش کو دوبارہ شروع کرتا ہے؛
- **عارضی وقف** جب کوئی نیا عارضی رن شروع ہوتا ہے تو ترتیب شدہ یا بے ترتیب نقطہ آغاز سے شروع ہوسکتا ہے۔

میں طرز عمل کا انتخاب کریں [کنفیگریشن](%DA%A9%D9%86%D9%81%DB%8C%DA%AF%D8%B1%DB%8C%D8%B4%D9%86.md)۔ اس ترتیب کو تبدیل کرنے کے لیے دوسرا پیکج انسٹال نہ کریں۔

<a id="update-an-existing-installation"></a>
### موجودہ انسٹالیشن کو اپ ڈیٹ کریں

1. سرور کو روکیں اور اوپر درج بیک اپ بنائیں۔
2. پرانے کو منتقل کریں `RandomDay` فولڈر سے باہر UE4SS `Mods` فولڈر۔ اسے اس وقت تک رکھیں جب تک کہ اپ ڈیٹ ایک کامیاب سائیکل مکمل نہ کر لے۔
3. نیا سرشار سرور نکالیں ZIP میں `Mods` فولڈر۔
4. صرف ان ترتیبات کو دوبارہ لاگو کریں جو آپ نے جان بوجھ کر تبدیل کی ہیں اور جو اب بھی نئی میں موجود ہیں [کنفیگریشن گائیڈ](%DA%A9%D9%86%D9%81%DB%8C%DA%AF%D8%B1%DB%8C%D8%B4%D9%86.md).
5. دستاویز شدہ روٹیشن اسٹیٹ فائلوں کو صرف اس صورت میں رکھیں جب ریلیز نوٹس یہ کہے کہ ان کا فارمیٹ مطابقت رکھتا ہے۔ نئی تنصیب میں پرانی عارضی آؤٹ پٹ یا ناکام تحریر فائلوں کو کاپی نہ کریں۔
6. تصدیق کریں `RandomDay : 1` اب بھی فعال ہے، پھر ایک بار سرور شروع کریں اور فعال اور تیار شدہ پروفائل ناموں کو چیک کریں۔

<a id="updating-from-v0315-alpha"></a>
### سے اپ ڈیٹ ہو رہا ہے v0.3.15-alpha

`RandomDay_v0.3.15-alpha.zip` پرانا بیس پیکج تھا۔ `RandomDay_v0.3.15-alpha_singleplayer_patch.zip` ایک اوورلے تھا اور اسٹینڈ اسٹون ڈاؤن لوڈ نہیں تھا۔

موجودہ `v0.3.16-alpha` تاریخی بیس اور اوورلے انتظام کو دو مکمل پیکجوں سے بدل دیتا ہے۔ کسی بھی پیکیج پر پرانا پیچ نہ رکھیں۔ موجودہ مارکر `.randomday_mode=dedicated_server` اور `.randomday_mode=singleplayer_manual`.

<a id="singleplayer-or-lan"></a>
## سنگل پلیئر یا LAN

The singleplayer/LAN پیکج ایک سیٹنگ فائل بناتا ہے۔ یہ خود سے کسی ذاتی محفوظ کو تلاش یا تبدیل نہیں کرتا ہے۔

1. گیم بند کریں۔
2. دنیا اور اس کے موجودہ کا بیک اپ لیں `SandboxSettings.ini`.
3.  کو نکالیں singleplayer/LAN ZIP گیم کے UE4SS `Mods` فولڈر تو ایک `Mods/RandomDay/` فولڈر موجود ہے۔
4. فعال کریں `RandomDay : 1` میں UE4SS `mods.txt`.
5. ایک بار گیم شروع کریں، انتظار کریں RandomDay ختم کرنے کے لیے، اور گیم کو مکمل طور پر بند کریں۔
6. جنریٹڈ تلاش کریں `SandboxSettings.ini` میں RandomDay's `runtime/singleplayer_manual/` فولڈر۔
7. تخلیق کردہ خلاصہ پڑھیں، پھر فائل کو اپنی منتخب کردہ دنیا میں کاپی کریں۔
8. اس دنیا کو شروع کریں اور چیک کریں کہ متوقع سینڈ باکس سلوک فعال ہے۔

LAN وہی دستی عمل استعمال کرتا ہے کیونکہ میزبان مقامی دنیا کا مالک ہے۔ موڈ کسی دنیا کا انتخاب نہیں کرتا ہے یا خود بخود اسے اوور رائٹ نہیں کرتا ہے۔

[سنگل پلیئر اور LAN گائیڈ](%D8%B3%D9%86%DA%AF%D9%84_%D9%BE%D9%84%DB%8C%D8%A6%D8%B1_%D9%84%DB%8C%D9%86.md)

<a id="remove-or-disable-randomday"></a>
## ہٹائیں یا غیر فعال کریں RandomDay

1. گیم یا سرور کو روکیں۔
2. دنیا، اس کی موجودہ سینڈ باکس کی ترتیبات، اور RandomDay's حالت۔
3. سیٹ کریں `RandomDay : 0` میں UE4SS `mods.txt` موڈ کو غیر فعال کرنے کے لیے، یا مکمل منتقل کرنے کے لیے `RandomDay` فولڈر سے باہر `Mods` اسے ہٹانے کے لیے فولڈر۔
4. فیصلہ کریں کہ کون سا `SandboxSettings.ini` اگلے آغاز پر لوڈ ہونا چاہیے۔ اگر آپ فی الحال تیار شدہ RandomDay پروفائل۔
5. دنیا شروع کریں اور کسی بھی بیک اپ کو حذف کرنے سے پہلے اس کے قواعد کی تصدیق کریں۔

غیر فعال کرنا RandomDay مستقبل کی پروفائل کی تیاری کو روکتا ہے۔ یہ ڈسک پر پہلے سے منتظر سینڈ باکس فائل کو دوبارہ نہیں لکھتا۔

<a id="recover-from-an-unsuccessful-update"></a>
## ایک ناکام اپ ڈیٹ سے بازیافت

پہلی واضح ناکامی کے بعد رک جائیں۔ بار بار دوبارہ شروع کرنے سے یہ دیکھنا مشکل ہو جاتا ہے کہ کون سا پروفائل فعال تھا اور کون سا انتظار کر رہا تھا۔

1. گیم یا سرور کو روکیں۔
2. ناکام انسٹالیشن کو حذف کیے بغیر ایک طرف منتقل کریں۔
3. مکمل بحال کریں RandomDay فولڈر اور سینڈ باکس کا بیک اپ اپ ڈیٹ سے پہلے بنایا گیا ہے۔
4. ایک بار شروع کریں اور بحال شدہ فعال اور تیار شدہ پروفائل ناموں کی تصدیق کریں۔
5. استعمال کریں [ٹربل شوٹنگ](%D9%B9%D8%B1%D8%A8%D9%84_%D8%B4%D9%88%D9%B9%D9%86%DA%AF.md) ایک اور اپ ڈیٹ کرنے سے پہلے پہلے غائب یا ناکام قدم کے لیے۔
