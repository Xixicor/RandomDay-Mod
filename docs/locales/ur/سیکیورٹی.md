# سیکیورٹی پالیسی

> **کیننیکل انگریزی ماخذ:** [SECURITY.md](../../../SECURITY.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


RandomDay سرور کنفیگریشن فائلیں لکھتا ہے اور اختیاری موڈ کنفیگریشن فائلوں کو پیچ کرسکتا ہے۔ تبدیلیوں کو عملی طور پر حساس سمجھیں۔

<a id="do-not-report-as-security-issues"></a>
## سیکیورٹی مسائل کے طور پر رپورٹ نہ کریں

- عام گیم پلے بیلنس میں تبدیلیاں۔
- متوقع اگلی ریبوٹ پروفائل گردش۔

<a id="report-privately"></a>
## نجی طور پر رپورٹ کریں

- پاتھ ٹراورسل خطرات۔
- غیر محفوظ فائل لکھنے کا برتاؤ۔
- مقصد سے باہر فائلوں کو اوور رائٹ کرنے کی اہلیت server/mod راستے۔
- نقصانیت پر مبنی کمانڈ پر عمل درآمد۔

جب تک کوئی عوامی سیکورٹی چینل موجود نہ ہو، مخزن کے مالک کو نجی طور پر رپورٹ کریں۔
