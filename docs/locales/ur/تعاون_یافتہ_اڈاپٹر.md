# تعاون یافتہ اختیاری موڈز

> **کیننیکل انگریزی ماخذ:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


RandomDay الگ سے انسٹال کردہ موڈ کو فعال کی پیروی کر سکتا ہے RandomDay پروفائل۔ یہ خصوصیت صرف سرشار سرور پیکج میں دستیاب ہے۔ singleplayer/LAN پیکیج کبھی بھی دوسرے موڈ میں ترمیم نہیں کرتا ہے۔

RandomDay یہاں درج کردہ کسی بھی موڈ کو شامل یا دوبارہ تقسیم نہیں کرتا ہے۔ ہر اختیاری موڈ کو اس کے اپنے Nexus صفحہ سے انسٹال اور فعال کریں اور پہلے اس کے مصنف کی ہدایات پر عمل کریں۔ RandomDay صرف ان تسلیم شدہ ترتیبات کو تبدیل کرتا ہے جو انسٹال شدہ فائل میں پہلے سے موجود ہیں۔ یہ کسی دوسرے موڈ میں فیچرز شامل نہیں کرتا ہے، اور اس موڈ کو ان انسٹال کیے بغیر اڈاپٹر کو غیر فعال کیا جا سکتا ہے۔ وقف سرور پیکج `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## کیا RandomDay تبدیلیاں

| اختیاری انضمام | ایکٹو پروفائل سے منتخب کردہ ترتیبات |
| --- | --- |
| Chaotic Spawn Engine / DynamicSpawns | ہارڈ موڈ، player/area کول ڈاؤن رویہ، طوفان اور گرم زون کی سرگرمی، باس اور برسٹ اسپانس، اسپون سائیکل ٹائمنگ، چھوٹی اور بڑی کولڈاؤن رینجز، سپون فاصلہ، global/local/mod کیپس، پورٹل-طوفان، آرڈر کی خلاف ورزی اور باس کے امکانات، اور فی رقبہ کم از کم اسپون۔ |
| اختیاری Chaotic Spawn Engine ایکسٹینشن فیلڈز | جب انسٹال ہوتا ہے `SharedData.lua` پہلے سے موجود ہے RandomDay ایکسٹینشن فیلڈز، اڈاپٹر انکاؤنٹر پروفائل، ٹائر، تھیم، گروپ کی حدود، اسپیشل ایونٹ اور مکسڈ انکاؤنٹر ویلیوز، بجٹ، کولڈاؤن، اور ورلڈ اسکوپ کنٹرول فراہم کر سکتا ہے۔ یہ ڈاؤن لوڈ کرنے کے لیے کوئی دوسرا موڈ نہیں ہے۔ |
| مہلک لیزر | موڈ ایکٹیویشن پلس ڈیمیج اور قابل استعمال ایمیٹرز، ماحولیاتی ایمیٹرز، ریفلیکٹرز اور پرزم کے لیے کنٹرولز کو فعال کرتا ہے۔ |
| ANTE اوپر | Respawn-frequency multiplier، Antivariant تعدد، اور موجودہ development/debug سوئچز۔ RandomDay تمام تسلیم شدہ ڈیولپمنٹ اور ڈیبگ سوئچز کو آف رکھتا ہے۔ |

پروفائل لائبریری ہر معاون دن کے لیے ایک تیار شدہ ویلیو سیٹ فراہم کرتی ہے۔ ایک پرسکون دن دباؤ کو کم کر سکتا ہے، خطرے کا دن اسے بڑھا سکتا ہے، اور بحالی کا دن اسے تیزی سے کم کر سکتا ہے۔ RandomDay بوٹ پر صوابدیدی قدروں کا حساب نہیں لگاتا ہے۔ یہ فعال پروفائل کے نام سے طے شدہ جائزہ شدہ قدر کا اطلاق کرتا ہے۔

<a id="how-recognition-protects-another-mod"></a>
## تسلیم کسی دوسرے موڈ کی حفاظت کیسے کرتا ہے

ایک مانوس فائل کا نام تلاش کرنا کافی نہیں ہے۔ لکھنے سے پہلے، RandomDay چیک کرتا ہے کہ اس اڈاپٹر کے لیے ہر مطلوبہ ترتیب ہدف فائل میں موجود ہے۔ یہ صرف موجودہ اسائنمنٹس کو پیچ کرتا ہے۔ یہ کبھی بھی گمشدہ ترتیب ایجاد نہیں کرتا۔

ایک تسلیم شدہ لے آؤٹ کے لیے، RandomDay ایک باؤنڈڈ ٹرانزیکشن کرتا ہے:

1. ایکٹو پروفائل کے لیے ہر مطلوبہ قدر کا حساب لگائیں؛
2. ہر ٹارگٹ فائل کا بیک اپ بنائیں اور بائٹ چیک کریں؛
3. ایک بہن بھائی زیر التواء فائل کے ذریعے لکھیں؛
4.  زیر التواء فائل کو فروغ دیں اور محفوظ کردہ بائٹس کو واپس پڑھیں؛
5. ہر مطلوبہ قدر کی تصدیق کریں؛
6. اگر کوئی مرحلہ ناکام ہوجاتا ہے تو تصدیق شدہ بیک اپس سے خودکار بحالی کا استعمال کریں۔

DynamicSpawns ایک لین دین میں اس کی ترتیبات اور تسلیم شدہ پلیئر میسج فائلیں شامل کر سکتا ہے۔ RandomDay اس ملٹی فائل اپ ڈیٹ کو کامیاب قرار نہیں دیتا جب تک کہ مکمل لین دین ختم نہ ہوجائے۔

<a id="read-an-adapter-result"></a>
## ایڈاپٹر کا نتیجہ پڑھیں

| نتیجہ | مطلب |
| --- | --- |
| `applied` | تسلیم شدہ ترتیبات تبدیل ہوگئیں اور ریڈ بیک پاس کر دیا گیا۔ |
| `already_current` | تسلیم شدہ ترتیبات پہلے ہی فعال پروفائل سے مماثل ہیں۔ |
| `not_installed` | اختیاری موڈ نہیں ملا۔ RandomDay اس کے بغیر جاری رہا۔ |
| `skipped_incompatible` | ایک فائل ملی، لیکن اس کی مکمل ترتیب کی ترتیب کو تسلیم نہیں کیا گیا۔ کچھ بھی تبدیل نہیں ہوا۔ |
| `partial` | بنیادی DynamicSpawns ترتیبات لاگو کی گئیں، لیکن ایک اختیاری ترجمہ شدہ پیغام فائل مکمل نہیں ہوئی۔ ریکارڈ شدہ اڈاپٹر کے نتائج کا جائزہ لیں۔ |
| `failed_rolled_back` | ایک ٹرانزیکشن ناکام ہوگئی اور پچھلے بائٹس برقرار رہے یا بحال اور تصدیق کی گئیں۔ |
| `rollback_failed` | RandomDay تبدیلی یا بحالی کی تصدیق نہیں کر سکا۔ متاثرہ موڈ کو روک کر رکھیں اور اس کا ریکارڈ شدہ بیک اپ دستی طور پر بحال کریں۔ |

گمشدہ اور غیر موافق اختیاری موڈز بند نہیں ہوتے ہیں RandomDay's بھیجے گئے کنفیگریشن کے تحت سینڈ باکس کی گردش۔

<a id="enable-or-disable-integrations"></a>
## انٹیگریشنز کو فعال یا غیر فعال کریں

کنٹرول اس میں ہیں:

```text
RandomDay/Scripts/ax_config/server.lua
```

سرشار سرور پیکج اس کے ساتھ بھیجتا ہے:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- سیٹ کریں `enabled = false` روکنے کے لیے RandomDay ہر اختیاری موڈ کا معائنہ کرنے یا تبدیل کرنے سے۔
- دوسرے انضمام کو فعال رکھتے ہوئے اس موڈ کو تنہا چھوڑنے کے لیے ایک اڈاپٹر ID کو ہٹا دیں۔
- رکھیں `patch_only_existing_keys` اور `backup_before_write` پر سیٹ ہے `true`۔ وہ تحریری حفاظت کی حد ہیں۔
- رکھیں `optional_by_default = true` جب تک کہ ہر درج اختیاری موڈ سرور کا مطلوبہ حصہ نہ ہو۔ اسے `false` ایک غائب، غیر مطابقت پذیر، یا محفوظ طریقے سے رولڈ بیک اڈاپٹر مجموعی نتیجہ کو متاثر کرتا ہے۔

جب آپ کسی اختیاری موڈ کو غیر فعال کرتے ہیں تو آپ کو اسے ان انسٹال یا غیر فعال کرنے کی ضرورت نہیں ہے RandomDay اڈاپٹر۔

## شکریہ اور ملکیت

کے مصنفین اور دیکھ بھال کرنے والوں کا شکریہ [Chaotic Spawn Engine](https://www.nexusmods.com/abioticfactor/mods/156), [مہلک لیزر](https://www.nexusmods.com/abioticfactor/mods/141)، اور [ANTE اوپر](https://www.nexusmods.com/abioticfactor/mods/201)۔ ان کے موڈز ان کے اپنے صفحات، اجازتوں اور معاون ہدایات کے تحت الگ الگ ڈاؤن لوڈز رہتے ہیں۔ RandomDay's اڈاپٹر صرف نصب شدہ، تسلیم شدہ لے آؤٹ میں موجود کنفیگریشن فیلڈز کا استعمال کرتے ہیں۔ وہ ان طریقوں کو دوبارہ تقسیم یا تبدیل نہیں کرتے ہیں۔

<a id="backups-and-manual-recovery"></a>
## بیک اپس اور مینوئل ریکوری

تصدیق شدہ پہلے سے لکھی ہوئی کاپیاں اس کے تحت برقرار ہیں:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

اگر `rollback_failed` ظاہر ہوتا ہے:

1. گیم یا سرور کو روکیں؛
2. سیٹ کریں `external_mods.enabled = false`، یا متاثرہ اڈاپٹر ID کو ہٹا دیں؛
3. موجودہ ٹارگٹ فائل اور اس کے بھائی کو محفوظ رکھیں pending/rollback فائلیں؛
4. اڈاپٹر کے نتیجے میں ریکارڈ کردہ ہدف کے راستوں سے نمبر والی بیک اپ فائلوں کو میچ کریں؛
5. سروس بند ہونے پر تصدیق شدہ بائٹس کو بحال کریں؛
6. اس کو دوبارہ فعال کرنے سے پہلے اختیاری موڈ کو خود سے شروع کریں RandomDay اڈاپٹر۔

ترتیبات کا نام تبدیل کرکے یا گمشدہ کلیدوں کو شامل کرکے مطابقت کو مجبور نہ کریں۔ ایک تسلیم شدہ لے آؤٹ استعمال کریں، اڈاپٹر کو غیر فعال چھوڑ دیں، یا سپورٹ کلیم کو بڑھانے سے پہلے ایک نیا ورژن فکسچر اور ٹرانزیکشن ٹیسٹ شامل کریں۔
