# رن ٹائم حالت اور آؤٹ پٹ اسکیموں کی تشریح کریں

> **کیننیکل انگریزی ماخذ:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


یہ کینونیکل فیلڈ مکمل اسکیما گائیڈ ہے۔ یہ جواب دیتا ہے کہ ہر فیلڈ، حالت، خالی قیمت، اور مشین کے نتیجے کا کیا مطلب ہے۔ استعمال کریں [رن ٹائم فائل کا نقشہ](%D8%B1%D9%86_%D9%B9%D8%A7%D8%A6%D9%85_%D9%81%D8%A7%D8%A6%D9%84%D8%B2.md) پروڈیوسر، پاتھ، رائٹ ٹائمنگ، ریٹینشن، ٹرانزیکشن سائڈ کارز، اور ریکوری لوکیشنز کے لیے۔

اس گائیڈ میں موجود تمام راستے انسٹال کردہ `RandomDay/` فولڈر جب تک کہ ایک قطار واضح طور پر ترتیب شدہ سینڈ باکس یا اختیاری اڈاپٹر ہدف کا نام نہ لے۔ رن ٹائم آؤٹ پٹ انسٹالیشن کے بعد تیار ہوتے ہیں اور کسی بھی ریلیز کے ممبر نہیں ہوتے ہیں ZIP.

<a id="choose-the-authoritative-view"></a>
## مستند منظر کا انتخاب کریں

| ضرورت ہے | مستند ذریعہ |
|---|---|
| موجودہ عمل کے ذریعہ لوڈ کردہ قواعد | RandomDay مارکر `SandboxSettings.ini` آغاز پر پڑھیں |
| تیار قطار بک کیپنگ | `runtime/rotation_state.txt`، اسکیما `1` |
| تفصیلی مقامی حیثیت | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| عوامی مشین پڑھنے کے قابل حیثیت | `web_export/today.json`، اسکیما `2` اور `randomday_public_status_v2` |
| انسانی پڑھنے کے قابل حیثیت | `web_export/today.html`، اسی عوامی حیثیت کی منتقلی سے ماخوذ ہے |
| ترجمے کی ذخیرہ الفاظ | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| بالکل باؤنڈڈ پلیئر نوٹس | `runtime/current/player_message_preview.txt` |

The HTML منظر، پیش نظارہ، اور ترجمہ شدہ خلاصے اخذ کردہ ملاحظات ہیں۔ وہ سینڈ باکس مارکر، لین دین کے نتیجے، یا خام پروفائل اقدار کو اوور رائڈ نہیں کرتے ہیں۔ آخری معروف اچھی فائلیں، آپریشن بیک اپ، سائڈ کار، آئینہ، اڈاپٹر اہداف، اور `UE4SS.log` میں [رن ٹائم فائلیں](%D8%B1%D9%86_%D9%B9%D8%A7%D8%A6%D9%85_%D9%81%D8%A7%D8%A6%D9%84%D8%B2.md).

<a id="rotation-state-schema"></a>
## روٹیشن اسٹیٹ اسکیما

`runtime/rotation_state.txt` اسکیما استعمال کرتا ہے `1` اور ایک پر مشتمل ہے `key=value` فی لائن جوڑا:

| فیلڈ | مطلب |
|---|---|
| `schema_version` | ہونا چاہیے `1`. |
| `mod_version` | پیکیج کی شناخت `.randomday_version`. |
| `rotation_id` | اہل فیملی سیٹ سے موجودہ پاس کے لیے شناخت کنندہ۔ |
| `mode` | `selected_run`, `non_repeating_random_run`، یا `rotation_run`. |
| `available_families` | کنفیگریشن فلٹرنگ کے بعد کوما سے الگ کردہ اہل فیملی IDs۔ |
| `remaining_families` | موجودہ غیر دہرائے جانے والے پاس میں اہل خاندان ابھی تک منتخب نہیں ہوئے ہیں۔ |
| `completed_families` | وہ خاندان جن کا 17-پوزیشن آرڈر موجودہ پاس میں مکمل ہو چکا ہے۔ |
| `active_family`, `active_day` | ایکٹو مارکر کی معلومات ریکارڈ کی گئی جب انتخاب کیا گیا تھا۔ سینڈ باکس مارکر اگلے بوٹ پر مستند ہے۔ |
| `prepared_family`, `prepared_day` | پروفائل کو اگلے دوبارہ شروع کرنے کے لیے رکھا گیا ہے۔ |
| `active_run_id` | تیار کردہ انتخاب سے وابستہ فیملی کے ذریعے چلائے جانے والا شناخت کنندہ۔ |
| `last_status` | کیلنڈر کے انتخاب کی حالت جس نے یہ فائل تیار کی ہے۔ |
| `session_mode` | حل شدہ مستقل وقف، عارضی وقف، یا singleplayer/LAN لائف سائیکل۔ |
| `start_day_mode` | نئے رن کے لیے کنفیگر یا ایک بار کا بے ترتیب آغاز انتخاب۔ |
| `day_progression_mode` | لپٹا ہوا ترتیب وار یا غیر دہرایا جانے والا بے ترتیب ترقی۔ |
| `day_order` | کوما سے الگ شدہ مستقل دن کی IDs بالکل اسی ترتیب میں تیار کی جائیں گی۔ |
| `day_position` | میں تیار دن کی پوزیشن `day_order`. |
| `updated_at` | آپریٹر کے مقابلے کے لیے مقامی تحریری وقت۔ |

ریاست کی تحریر صرف اس وقت قبول کی جاتی ہے جب اسکیما مارکر، تیار شدہ خاندان، اور تیار دن صحیح طریقے سے پڑھتا ہے۔ ایک ناقابل پڑھنے والی موجودہ فائل واپس `rotation_state.last_good.txt`؛ منتخب شدہ سینڈ باکس مارکر اب بھی اس بات کا تعین کرتا ہے کہ گیم نے موجودہ عمل کے لیے کیا لوڈ کیا ہے۔

<a id="runtime-status-json"></a>
## رن ٹائم اسٹیٹس JSON

`runtime/current/randomday_status.json` استعمال کرتا ہے `status_schema=randomday_runtime_status_v2`۔ اس کے اہم فیلڈ گروپس ہیں:

| گروپ | فیلڈز اور تشریح |
|---|---|
| شناخت | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| انتخاب | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| فعال | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| تیار | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| انسانی خلاصے | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| ثبوت لکھیں | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| ایڈاپٹر ثبوت | `adapter_status`, `adapter_results`; ہر اڈاپٹر ریکارڈ میں مطابقت کا ثبوت، transaction/rollback حالت، تبدیل شدہ فائل کی گنتی، اور ترمیم شدہ ہدف کے حوالہ جات |
| حدود | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| تشخیص | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

نامعلوم فعال قدروں کا مطلب ہے کہ موجودہ سینڈ باکس میں پڑھنے کے قابل نہیں ہے RandomDay مارکر۔ انہیں تیار شدہ اقدار سے تبدیل نہیں کیا جانا چاہئے۔ باہر اڈاپٹر کے راستے `runtime/` سے باہر اڈاپٹر کے راستوں کو ایک بنیادی نام کے حوالے سے کم کر دیا جاتا ہے، اور تشخیصی سٹرنگز پتہ لگائے گئے مطلق راستوں کو رد کر دیتی ہیں۔

<a id="public-status-json"></a>
## عوامی حیثیت JSON

`web_export/today.json` استعمال کرتا ہے `schema_version=2` اور `status_schema=randomday_public_status_v2`۔ یہ شناخت، active/prepared، انتخاب، لین دین، اڈاپٹر، اور آپریٹر کو درکار ری اسٹارٹ باؤنڈری حقائق کو دہراتا ہے۔ اس میں یہ بھی شامل ہیں:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order`، اور `prepared_day_position`;
- `family_selection_mode`، میراث `family_locked_until_day_17`، اور `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`، اور ان کی گنتی؛
- تیار شدہ انکاؤنٹر پروفائل، ٹائر، تھیم، اور مکسڈ انکاؤنٹر کا موقع؛
- عالمی دائرہ کار کی ترتیب، اوپن ورلڈ کاؤنٹ ایک غیر معروف پالیسی، اوپن ورلڈ کاؤنٹ کی ترتیب، excluded-world پیٹرن؛
- تیار کردہ پیغام اور مشترکہ پیغام کے پیش نظارہ؛
- `selected_at`, `sandbox_target`, `manual_copy_required`، اور تیار شدہ ہیش۔

`profile_status` میں سے ایک ہے `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence`، یا `write_failed_or_rollback`. `prepared_ready=true` کا مطلب اب بھی فعال نہیں ہے۔ بعد میں اسٹارٹ اپ مارکر درکار ہے۔

<a id="dictionary-and-translation-output"></a>
##  ڈکشنری اور ترجمہ آؤٹ پٹ

`runtime/current/randomday_dictionary.json` استعمال کرتا ہے `schema=randomday_runtime_dictionary_v2` اور لغت کے ورژن کی شناخت کرتا ہے `randomday_dictionary_v2`۔ یہ پیکیج کے طریقوں، انتخاب کی حالتوں، دباؤ کے ڈومینز، لیبل کی ترتیب، خام اقدار، اور سادہ زبان کے معنی بیان کرتا ہے۔ نامعلوم اقدار ایک پراعتماد تفصیل میں تبدیل ہونے کے بجائے واضح رہتی ہیں۔

`player_message_preview.txt`, `today.json`, `today.html`، اور درون گیم نوٹس اسی ترجمہ ماڈیول سے اخذ کردہ ملاحظات ہیں۔ بنیادی پروفائل اور خام `SandboxSettings.ini` قدریں سچائی کا ماخذ رہتی ہیں۔

<a id="failure-and-recovery-rules"></a>
## ناکامی اور بازیابی کے اصول

1. ایک ناکام زیر التواء تحریر یا توثیق کبھی بھی پیداواری ہدف نہیں بنتی ہے۔
2. ایک ناکام پروموشن یا پروڈکشن ریڈ بیک روکے ہوئے اصل کی بحالی کو متحرک کرتا ہے۔ آپریشن بیک اپ فال بیک ہوتا ہے جب وہ بحالی ناکام ہو جاتی ہے۔
3. رول بیک فائل یا `rollback_failed` گیم یا سرور کے بند ہونے کے دوران اسٹیٹس کو دستی جائزہ لینے کی ضرورت ہوتی ہے۔
4. ایک کامیاب سینڈ باکس رائٹ پلس ناکام روٹیشن سٹیٹ کمٹ ڈیگریڈ ہے، تیار نہیں ہے۔ اڈاپٹر اور تیار شدہ پروفائل پیغام رسانی کو چھوڑ دیا گیا ہے۔
5. ایک برآمدی ناکامی سینڈ باکس کے نتیجے کو تبدیل نہیں کرتی ہے، لیکن یہ سہولت کے ثبوت کے ذریعہ کو ہٹا دیتی ہے۔ ٹرانزیکشن لاگز، اسٹیٹ، اور فائل ریڈ بیک استعمال کریں۔
6. رن ٹائم آؤٹ پٹ مقامی آپریشنل ڈیٹا ہیں۔ انہیں ریلیز میں شامل نہ کریں ZIP یا علیحدہ رازداری کے جائزے کے بغیر انہیں بطور مثال شائع کریں۔
