# RandomDay दस्तावेज़

> **कैनोनिकल अंग्रेजी स्रोत:** [README.md](../../README.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


RandomDay पहले से चल रहे सत्र को बदले बिना अजैविक कारक दुनिया द्वारा उपयोग किए जाने वाले सैंडबॉक्स नियमों को बदलता है। उस गाइड से शुरुआत करें जो आप जो करना चाहते हैं उससे मेल खाता हो।
