# RandomDay प्रोफ़ाइल दस्तावेज़

> **कैनोनिकल अंग्रेजी स्रोत:** [README.md](../../../profiles/README.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


संस्करण: `v0.3.16-alpha`

- परिवार: **17**
- प्रोफ़ाइल: **289**
- SandboxSettings शब्दकोश प्रविष्टियाँ: **46**

[प्रोफ़ाइल चयन मार्गदर्शिका](../%E0%A4%8F%E0%A4%95_%E0%A4%AA%E0%A5%8D%E0%A4%B0%E0%A5%8B%E0%A4%AB%E0%A4%BC%E0%A4%BE%E0%A4%87%E0%A4%B2_%E0%A4%9A%E0%A5%81%E0%A4%A8%E0%A5%87%E0%A4%82.md), फिर सटीक मानों के लिए इस जेनरेट किए गए इंडेक्स का उपयोग करें।

ये फ़ाइलें रनटाइम Lua स्रोत और उसके dictionary/translation अनुबंध। वे भेजे गए `sandbox.profile_overrides` डिफ़ॉल्ट; एक सर्वर के कॉन्फ़िगर किए गए मान भिन्न हो सकते हैं:

- `profiles.generated.json`: मशीन-पठनीय प्रोफ़ाइल, मूल मान, शब्दकोश और अनुवाद।
- `FULL_PROFILE_REFERENCE.md`: संपूर्ण अनुक्रमणिका और व्याख्या नियम।
- `SANDBOX_SETTINGS_KEYS.md`: संपूर्ण 46-कुंजी शब्दकोश।
- `families/*.md`: विस्तृत 17-दिवसीय पारिवारिक संदर्भ।

इसके साथ पुन: उत्पन्न करें: `python -B tools/generate_profile_docs.py` इसके साथ बहाव की जांच करें: `python -B tools/generate_profile_docs.py --check`
