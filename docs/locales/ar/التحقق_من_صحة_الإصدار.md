# التحقق من صحة الإصدار

> **المصدر الإنجليزي الأساسي:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


هذه الصفحة مخصصة للمساهمين ومشرفي الإصدار. لا يحتاج اللاعبون الذين يقومون بتثبيت التعديل إلى تشغيل هذه الأوامر.

<a id="ordinary-user-proof"></a>
## إثبات المستخدم العادي

يكون الإصدار مفهومًا عندما يتمكن القارئ الجديد من اختيار إحدى الحزمتين، وتثبيته، وتحديد الملف الشخصي النشط والملف الشخصي المُجهز، والتعافي من نتيجة مفقودة باتباع الدليل المرتبط. يجب ألا تتطلب مهام القارئ هذه معرفة Git أو PowerShell أو Python أو المجموع الاختباري.

<a id="contributor-checks"></a>
## عمليات التحقق من المساهمين

التشغيل من جذر المستودع:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

عندما يكون `luac` متاحًا، تحقق من صياغة كل ملف Lua تم شحنه:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

تتطلب اختبارات وقت تشغيل Lua `lupa`. مترجم Lua المفقود أو تثبيت `lupa` هو إمكانية اختبار غير متاحة، وليست نتيجة ناجحة.

<a id="release-checks"></a>
## فحوصات الإصدار

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

يتحقق فحص الإصدار من هذه الشروط:

- `VERSION` و `RandomDay/.randomday_version` مطابقة.
- الإصدار الحالي فقط موجود ضمن `releases/`.
- الملفات المضغوطة المخصصة وsingleplayer/LAN هي بدائل كاملة.
- كلاهما تحتوي الأرشيفات على المسار `RandomDay/Scripts/main.lua` الأساسي ولا يوجد أداة تحميل تصادم الحالة.
- علامات وضع الحزمة هي `dedicated_server` و `singleplayer_manual`.
- ZIP البايتات حتمية ومتطابقة `CHECKSUMS.sha256`.
- لا يتم تجميع بيانات وقت التشغيل أو التكوين الخاص أو بيانات الاعتماد أو ذاكرات التخزين المؤقت أو مخرجات الاختبار.
- يتم التحقق من صحة جميع روابط الوثائق المحلية و27 صفحة إدخال محلية.

<a id="avoid-validation-environment-pitfalls"></a>
## تجنب مخاطر بيئة التحقق

- قم بتشغيل فحوصات كتابة المستودع بشكل تسلسلي بحيث لا تحل عمليتان محل نفس الملف المؤقت في مرة واحدة.
- في نظام التشغيل Windows، تحقق من ZIP أسماء الأعضاء بدلاً من استخدام بحث ملف غير حساس لحالة الأحرف لتحديد ما إذا كان مُحمل الأحرف الصغيرة موجودًا أم لا.
- تأكيد `mods.txt` و `enabled.txt` فقط في اختبار الخادم المثبت؛ فهي ليست دليلاً على تشغيل اختبارات المصدر.
- تسجيل مهلة الأمر على أنها غير مكتملة. لا تقم بتحويله إلى تمرير أو فشل بدون إخراج الأمر المحدود.
- احتفظ بالملفات المؤقتة داخل المستودع متجاهلة `.tmp/`.

<a id="known-limits"></a>
## الحدود المعروفة

يثبت التحقق المحلي من صحة عقود المصدر والحزمة والوثائق والتركيبات. ولا يثبت أمر بدء تشغيل لوحة خادم معينة، أو تخطيط رسالة العميل المباشر، أو مسار نظام الملفات الخاص بالمضيف. قم بتسجيلها كنتائج تكامل منفصلة عند اختبارها.
