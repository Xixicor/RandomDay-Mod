# المساهمة

> **المصدر الإنجليزي الأساسي:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


RandomDay يتم الاحتفاظ بها كتخطيطات خاضعة للرقابة. المشروع.

لا يتم قبول طلبات السحب العامة، وعمليات إرسال التعليمات البرمجية غير المرغوب فيها، وعمليات إعادة الكتابة التلقائية، وعمليات إرسال تنظيف التعليمات البرمجية التي تم إنشاؤها، وتصحيحات الميزات التخمينية ما لم يطلبها مالك المستودع صراحةً.

<a id="accepted-contact"></a>
## جهة اتصال مقبولة

بالنسبة لتقارير الأخطاء، التوافق ملاحظات، أو ملاحظات إدارة الخادم، استخدم قنوات الاتصال المدرجة في وثائق المشروع.

<a id="not-accepted"></a>
## غير مقبول

لا يتم قبول ما يلي افتراضيًا:

- طلبات السحب غير المرغوب فيها؛
- إعادة كتابة التعليمات البرمجية المُنشأة؛
- واسعة النطاق refactors؛
- تغييرات تنسيق النمط فقط؛
- تغييرات منطق اللعب غير المختبرة؛
- ملفات تعديل الطرف الثالث المجمعة؛
- رمز مصدر الطرف الثالث المعاد توزيعه؛
- التغييرات التي تشير ضمنًا إلى الارتباط الرسمي بـ Abiotic Factor، UE4SS، أو Nexus Mods، أو مؤلفي التعديل التابعين لجهات خارجية.

<a id="controlled-development"></a>
## التطوير المتحكم فيه

يجوز لمالك المستودع طلب مساعدة محددة في المراجعة أو الاختبار أو التوثيق عند الحاجة. قد يتم إغلاق عمليات الإرسال غير المطلوبة دون مراجعتها.
