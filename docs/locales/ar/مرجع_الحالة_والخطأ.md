# مرجع الحالة والخطأ

> **المصدر الإنجليزي الأساسي:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


استخدم بالضبط `status`, `transaction_status`, `rollback_status` الحالي و`error` القيم من تصدير وقت التشغيل. إن الصياغة المشابهة في اللوحة أو وحدة التحكم ليست بديلاً عن تلك الحقول.

هذا القسم هو مرجع البحث الكامل. تختار شجرة القرار أعلاه الفئة ذات الصلة؛ تحافظ هذه الجداول على قيم الجهاز الدقيقة واستجابات المشغل الآمنة.

<a id="normal-or-informational-states"></a>
## الحالات العادية أو المعلوماتية

| الحالة | المعنى | استجابة المشغل |
|---|---|---|
| `prepared_for_next_reboot` | تمت كتابة ملف تعريف تم التحقق من صحته للتمهيد التالي. | لا يوجد إجراء؛ لم تتغير الجلسة الحالية. |
| `next_reboot_already_prepared` | الملف الشخصي التالي المقصود يطابق الهدف بالفعل. | لا يوجد إجراء؛ لا تفرض تدويرًا آخر. |
| `already_current` / `unchanged` | يحتوي الهدف بالفعل على البايتات المقصودة. | لا يوجد إجراء. |
| `applied` | تم تمرير إعادة قراءة الكتابة والإنتاج. | تحقق من active/prepared التمييز بعد التمهيد التالي. |
| `bootstrap_prepare_first_family_start_day` | لم تكن هناك حالة دوران مسبقة، لذلك تم إعداد اليوم الأول الذي تم تكوينه. | متوقع عند الاستخدام الأول. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | تم استرداد الحالة المخزنة وتمت إعادة كتابة نفس ملف التعريف المجهز. | التحقق من يوم الاسترداد؛ لم يحدث أي اختيار عشوائي جديد. |
| `supervision_reconfirm_prepared_profile_no_advance` | أكد تصريح الإشراف الإعداد الحالي. | متوقع؛ لم تتقدم قائمة الانتظار مرتين. |
| `external_mods_disabled` | تم تعطيل معالجة المحول الاختياري. | لا يوجد إجراء ما لم تكن المحولات مقصودة. |
| `external_mods_processed` | وصلت جميع خطط المحولات الممكّنة إلى نتيجة نهائية. | راجع كل صف محول. |

<a id="startup-configuration-errors"></a>
## أخطاء تكوين بدء التشغيل

تتوقف هذه الرسائل عن بدء التشغيل قبل RandomDay يكتب ملفًا شخصيًا. قم بتصحيح الإعداد المسمى أو علامة الحزمة؛ لا تتجاوز فرع التحقق من الصحة.

| نص الخطأ | المعنى | الاستجابة الآمنة |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` مفقود أو مشوه أو من حزمة خاطئة. | أعد تثبيت حزمة واحدة كاملة في مجلد مرحلي نظيف واحتفظ بعلامة الوضع المقصود. |
| `invalid experience.mode` | `experience.mode` ليست إحدى القيم الموثقة. | استخدم `auto`, `persistent_dedicated`, `temporary_dedicated`، أو `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | تم تكوين حزمة النسخ اليدوية كخادم مخصص. | استعادة `auto` أو `singleplayer_lan`; ولا توجهه إلى عالم خارجي تلقائيًا. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | تم تكوين حزمة مخصصة لسير عمل النسخ اليدوي. | استخدم `auto`, `persistent_dedicated`، أو `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | محدد اليوم الأولي غير صالح. | استخدم بالضبط `configured` أو `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | محدد ترتيب اليوم غير صالح. | استخدم بالضبط `sequential` أو `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | يوم البدء الذي تم تكوينه كسري أو خارج دورة. | استخدم رقمًا صحيحًا من 1 إلى `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | تم تعطيل النسخ الاحتياطي أو الاستعادة الأخيرة. | قم باستعادة قفلي الأمان؛RandomDay يرفض عمدًا عمليات الكتابة غير الآمنة. |
| `external adapter transaction safety locks must remain true` | تم تعطيل تصحيح المحول أو الحماية الاحتياطية. | قم باستعادة أقفال أمان المحول أو تعطيل المحولات كمجموعة. |
| `paths.world_name must be one folder name` | يحتوي الاسم العالمي الذي تم تكوينه على فاصل أو حرف غير آمن. | أدخل اسم المجلد الدقيق فقط، باستخدام الحروف، أرقام أو مسافات أو شرطات سفلية أو واصلات. |
| `required runtime directory unavailable` | تعذر إنشاء أو تأكيد دليل الإخراج المحلي المطلوب. | حدد فقط الاسم RandomDay الدليل وإذن الكتابة الخاص به. |

<a id="profile-wide-configuration-errors"></a>
## أخطاء التكوين على مستوى الملف الشخصي

توقف هذه الأخطاء عن إنشاء الملف الشخصي قبل كتابة وضع الحماية.

| نص الخطأ | المعنى | الاستجابة الآمنة |
|---|---|---|
| `sandbox.profile_overrides must be a table` | تم استبدال الاختيارات الأربعة على مستوى الملف الشخصي بأخرى نوع Lua. | قم باستعادة الجدول الموثق في `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | يحتوي الجدول على إعداد ليس أحد المفاتيح الأربعة المدعومة. | قم بإزالة المفتاح المسمى واستخدم family/profile مصادر لإعدادات وضع الحماية الأخرى. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` أو `AllowIronMode` ليس `true` أو `false`. | استخدم قيمة منطقية Lua غير المقتبسة. |
| `sandbox.profile_overrides.<key> must be integer` | قيمة الدعم هي ليس رقمًا صحيحًا. | استخدم رقمًا صحيحًا. |
| `sandbox.profile_overrides.<key> outside supported range` | قيمة الدعم موجودة بالخارج `0..1000`. | اختر رقمًا صحيحًا من `0` حتى `1000`. |

<a id="rollback-and-intermediate-states"></a>
## التراجع والحالات الوسيطة

| القيمة | المعنى | الاستجابة الآمنة |
|---|---|---|
| `not_started` / `pending` | لم تصل خطة المعاملة أو المحول إلى نتيجة نهائية. | انتظر فقط تصريح بدء التشغيل المحدد الحالي؛ تتطلب الحالة المستمرة التحقيق. |
| `not_needed` | لم تكن هناك حاجة للتراجع. | لا يوجد إجراء. |
| `original_held` | تم نقل الهدف الأصلي إلى وضع الاسترداد قبل الترقية. | لا تحذف ملف الاسترداد عندما تكون المعاملة غير مكتملة. |
| `retained_after_success` | تم التحقق من الهدف الجديد، ولكن تظل بيانات الاسترداد قائمة لأن التنظيف لم يكن متاحًا أو تم الاحتفاظ به عمدًا. | تحقق من بايتات الإنتاج قبل إزالة أي ملف استرداد مسمى. |
| `discarded_after_success` | تم مسح البيانات البديلة التي تم التحقق منها والتراجع المؤقت. | لا يوجد إجراء. |
| `rollback_failed` | تعذر التحقق من محاولة الاستعادة. | أبق الخادم متوقفًا واستخدم آخر نسخة احتياطية للعملية التي تم التحقق منها. |
| `skipped_state_persistence_failed` | تم إعداد وحدات البايت المعزولة، ولكن حالة التدوير لم تستمر، لذلك تم تخطي المحولات ورسائل المشغل المعدة. | إصلاح تخزين حالة وقت التشغيل؛ لا تقم بإعادة ترتيب قائمة الانتظار أو تقديمها يدويًا. |
| `failed` | يمثل صف الملخص فشلًا طرفيًا يوجد سببه المحدد في `error` أو حقول المعاملات. | اتبع الكود المحدد الأول؛ لا تقم باستكشاف الأخطاء وإصلاحها من `failed` وحده. |

<a id="transaction-failures"></a>
## فشل المعاملات

| الحالة | المعنى | الاستجابة الآمنة |
|---|---|---|
| `invalid_input` | لم يكن طلب الاستبدال نصًا صالحًا أو يفتقر إلى هدف صالح. | التكوين الصحيح؛ لا تقم بإعادة المحاولة دون تغيير. |
| `stale_pending_cleanup_failed` | تعذرت إزالة الملف المعلق القديم. | أوقف الملف المعلق واحتفظ به قبل التنظيف اليدوي. |
| `stale_rollback_requires_review` | توجد بيانات الاسترداد بجوار هدف موجود ولا يمكن التخلص منها بأمان. | قارن بايت الهدف والتراجع قبل اختيار أي منهما. |
| `interrupted_transaction_restore_failed` | تعذر على الاسترداد بعد الاستبدال المتقطع استعادة الهدف. | حافظ على توقف الخادم واستعادة نسخة احتياطية تم التحقق منها. |
| `interrupted_transaction_cleanup_failed` | تم استرداد الهدف ولكن تعذر مسح بيانات المعاملات القديمة. | تحقق من وحدات البايت المستهدفة، ثم قم بإزالة الملف الجانبي القديم المحدد فقط. |
| `pending_write_failed` | تعذرت كتابة المرشح. | تحقق من ضيق الدليل الهدف والمساحة الحرة. |
| `pending_readback_failed` / `pending_readback_mismatch` | تعذرت قراءة بايتات المرشح أو اختلافها بعد الكتابة. | لا تقم بترقية الملف المعلق. |
| `pending_validation_failed` | فشل المرشح schema/profile التحقق قبل الترقية. | أصلح المفتاح أو القاعدة المبلغ عنها؛ لا تتجاوز التحقق من الصحة. |
| `operation_backup_failed` / `backup_failed` | لم يتم إنشاء نسخة احتياطية تم التحقق منها للكتابة المسبقة. | توقف؛ لا ينبغي الوثوق باستبدال الهدف. |
| `original_preserved_move_failed` | تعذر نقل الهدف الأصلي إلى وضع الاسترداد. | احتفظ بجميع ملفات المعاملات واستردها يدويًا. |
| `promotion_failed` | لا يمكن أن يصبح المرشح المعلق هدف الإنتاج. | تحقق مما إذا كان قد تمت استعادة الأصل قبل إعادة المحاولة. |
| `production_validation_failed` | فشل إنتاج وحدات البايت التي تمت ترقيتها readback/validation. | قم باستعادة النسخة الاحتياطية التي تم التحقق منها وافحص الكاتب الهدف. |
| `replacement_committed_recovery_cleanup_failed` | الاستبدال صالح، ولكن تعذر مسح بيانات التراجع. | تعامل مع الهدف على أنه ملتزم؛ قم بإزالة بيانات الاسترداد القديمة التي تم التحقق منها فقط. |
| `rollback_failed` | لم يتم التحقق من الاستعادة التلقائية. | أبق الخادم متوقفًا واستخدم الاسترداد اليدوي. |

<a id="target-profile-adapter-and-export-failures"></a>
## فشل الهدف والملف الشخصي والمحول والتصدير

| الحالة | المعنى | الاستجابة الآمنة |
|---|---|---|
| `target_refused` | المسار الذي تم تكوينه يقع خارج حدود الوضع المسموح به. | تصحيح المسار؛ لا تضعف الحدود أبدًا. |
| `target_directory_failed` | تعذر إنشاء الدليل الهدف أو تأكيده. | تحقق فقط من وجود هذا الدليل وأذوناته. |
| `profile_validation_failed` | يفتقد الملف الشخصي مفتاحًا، ويحتوي على خطأ type/range، أو ينتهك قاعدة ثابتة متبقية. | استخدم المفتاح المسمى، `sandbox.profile_overrides`، ومرجع الملف الشخصي لإصلاح المصدر. |
| `skipped_incompatible` | يوجد تعديل اختياري ولكنه لا يتطابق مع توقيع محول مدعوم. | اتركه بدون تغيير أو قم بتعطيل هذا المحول. |
| `external_mods_partial` | اكتملت بعض المحولات الاختيارية والبعض الآخر كان آمنًا. skipped/failed. | راجع صفوف المحول بشكل مستقل؛ نتيجة وضع الحماية منفصلة. |
| `external_adapter_failed` | لم يكتمل المحول المطلوب بشكل آمن. | قم باستعادة النسخة الاحتياطية التي تم التحقق منها قبل إعادة المحاولة. |
| `degraded_state_persistence` | اكتمل إعداد وضع الحماية، ولكن لم يتم استمرار حالة التدوير. | لا تفترض أن التمهيد التالي يمكن أن يتقدم بشكل صحيح؛ إصلاح تخزين الحالة. |
| `export_directory_failed` | `web_export/` لا يمكن إنشاؤها أو كتابتها. | قد لا يزال الإعداد للعبة صالحًا؛ الإبلاغ عن الإصلاح بشكل منفصل. |

<a id="translation-and-message-validation-errors"></a>
## أخطاء الترجمة والتحقق من صحة الرسائل

هذه هي حالات فشل القاموس أو عقد العرض التقديمي. يتم التحقق من صحتها قبل الإصدار وقد تظهر أيضًا كتحذير لحالة وقت التشغيل المحدود.

| نص الخطأ | المعنى | الاستجابة الآمنة |
|---|---|---|
| `dictionary coverage mismatch` | لا يشرح قاموس ملف التعريف كل إعداد موثق. | إضافة إدخال القاموس المفقود وإعادة تشغيل الملف الشخصي generation/validation. |
| `missing profile setting` | الملف الشخصي المحدد يفتقر إلى الإعداد المطلوب بواسطة dictionary/schema. | إصلاح مصدر عائلة الملف الشخصي؛ لا تخترع افتراضيًا لوقت التشغيل. |
| `empty explanation` | يوجد إعداد ولكن لا يحتوي على operator/player شرح. | أضف شرحًا بلغة عادية قبل الإصدار. |
| `join line too wide` | يتجاوز سطر الربط الذي تم إنشاؤه حد المصدر المكون من 42 حرفًا. | تقصير عبارة القاموس؛ لا تعتمد على التفاف العميل. |
| `join message too tall` | يتجاوز ملخص الانضمام الذي تم إنشاؤه أربعة أسطر. | قم بتقليل محتوى الرسالة أو إعادة ترتيب أولوياتها. |
