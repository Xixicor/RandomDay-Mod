# المسرد

> **المصدر الإنجليزي الأساسي:** [GLOSSARY.md](../../GLOSSARY.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


هذه هي المفردات الأساسية لـ RandomDay الوثائق. ترتبط الإجراءات بهذه التعريفات بدلاً من إعادة تعريف نفس الحالة في أدلة متعددة. تظل قواعد الحقول الخاصة بالمخطط موجودة في [مخرجات وقت التشغيل](%D9%85%D8%AE%D8%B1%D8%AC%D8%A7%D8%AA_%D9%88%D9%82%D8%AA_%D8%A7%D9%84%D8%AA%D8%B4%D8%BA%D9%8A%D9%84.md).

| المصطلح | معنى عادي | المعنى الفني الدقيق |
|---|---|---|
| الملف الشخصي النشط | القواعد التي تستخدمها الجلسة الحالية. | تقوم الحزمة family/day الملف الشخصي الذي تم تحديده بواسطة RandomDay من وضع الحماية عند بدء العملية. |
| ملف تعريف مُجهز | قواعد جاهزة لجلسة لاحقة. | ملف التعريف الكامل family/day الذي اجتازت وحدات البايت المستهدفة الخاصة به التحقق من الصحة والقراءة وتم الالتزام بحالة التدوير. وهو غير نشط قبل إعادة تشغيل القراءة. |
| تمت الاستعادة | فشل الإعداد وتمت إعادة وحدات البايت التي تم التحقق منها مسبقًا. | تشير المعاملة الفاشلة إلى نجاح التراجع والقراءة لنسخة الاسترداد الأصلية أو التي تم التحقق منها. |
| قائمة انتظار إعادة التشغيل التالية | يتم الاحتفاظ باختيار واحد مُجهز للإقلاع التالي. | `next_reboot_queue` يتم تحديده مرة واحدة لكل عملية ويعيد استخدام هذا الاختيار المملوك للتمهيد أثناء الإشراف. |
| Bootstrap | التحضير الأول عند عدم وجود علامة نشطة موجود. | اختيار اليوم الأول الذي تم تكوينه أو عشوائيًا من عائلة مؤهلة؛ `cycle.bootstrap_day` هو مجرد بديل للتوافق. |
| العائلة | تقدم في أسلوب اللعب لمدة 17 يومًا. | إدخال تسجيل واحد ووحدة عائلية تنتج بالضبط 17 ملفًا شخصيًا كاملاً. |
| التدوير | بطاقة مرور عبر العائلات المؤهلة. | الحالة المحددة بواسطة `rotation_id`، مع قوائم العائلة المتاحة والمتبقية والمكتملة. |
| تشغيل | عائلة واحدة عبر جميع معرفات الـ 17 يومًا. | تسلسل مرتبط بالعائلة تم تحديده بواسطة `run_id`؛ وتظل العائلة مقفلة حتى اكتمال كل موضع طلب يومي مستمر. |
| وضع الجلسة | كيف يستخدم المشغل هذه الحزمة. | `persistent_dedicated`, `temporary_dedicated`، أو `singleplayer_lan`؛ ولا يزال وضع الحزمة يتحكم في حدود نظام الملفات. |
| ترتيب اليوم | الترتيب الدقيق المستخدم بواسطة عائلة واحدة. | تبديل مستمر مكون من 17 رقمًا. يلتف الوضع التسلسلي من يوم بدايته؛ يتم التبديل في الوضع العشوائي مرة واحدة دون تكرار. |
| العلامة | الهوية المخزنة في ملف وضع الحماية. | `RANDOMDAY_*` يتم عرض الحقول مع الملف الشخصي الكامل وقراءتها عند بدء العملية التالية. |
| مُعدة جاهز | نجح تنفيذ الكتابة والحالة. | `prepared_ready=true` تتطلب نتيجة وضع حماية ناجحة ولا يتم إثبات ذلك التنشيط. |
| حالي بالفعل | يحتوي الهدف بالفعل على البايتات المقصودة. | تتطابق تجزئة الملف الشخصي المعروض مع الهدف، لذا RandomDay يتحقق من last-good/mirror دون إعادة كتابة الملف الأساسي. |
| استمرارية الحالة المتدهورة | نجحت بايتات وضع الحماية ولكن لم ينجح مسك الدفاتر بالتناوب. | `profile_status=degraded_state_persistence`؛ ويتم تخطي المحولات ورسائل الملف الشخصي المعدة. |
| الملف المعلق | لم تتم ترقية وحدات البايت المرشحة بعد. | `<target>.randomday.pending`، ويتم كتابتها وإعادة قراءتها والتحقق من صحتها قبل الاستبدال. |
| ملف التراجع | النسخة الأصلية التي تم الاحتفاظ بها أثناء الاستبدال. | `<target>.randomday.rollback`، مستخدمة لاستعادة الإنتاج عند فشل الترقية أو التحقق من الصحة. |
| النسخ الاحتياطي للعملية | نسخة دائمة تم إنشاؤها قبل التغيير. | ملف تم التحقق منه ضمن `runtime/backups/` للمعاملة الأساسية أو المرآة أو المحول. |
| آخر سلعة معروفة | تم قبول أحدث وضع حماية للاسترداد. | `runtime/last_good/SandboxSettings.ini` بالإضافة إلى `manifest.lua`؛ يسجل الزوج هوية الملف الشخصي والتجزئة. |
| مرآة | هدف Sandbox ثانٍ اختياري. | هدف تم تكوينه بشكل صريح أو مشتق من اسم عالمي مكتوب بعد الهدف الأساسي من خلال معاملته الخاصة. |
| وضع الحزمة | تثبيت الحدود المحددة بواسطة الإصدار الأصل. | `dedicated_server` أو `singleplayer_manual` من `.randomday_mode`. |
| النسخ اليدوي الوضع | Singleplayer/LAN يتم إنشاؤه بدون اكتشاف الحفظ. | `singleplayer_manual` يكتب فقط داخل `runtime/singleplayer_manual/` ويعطل المحولات والمرايا. |
| المحول | RandomDay-owned لنموذج آخر مثبت. | خطة معاملات خاضعة للتوقيع تقوم بتحديث المهام الحالية فقط بعد النسخ الاحتياطي والتوافق الشيكات. |
| التخطيط الذي تم التعرف عليه | الشكل الدقيق لملف المحول المقبول للكتابة. | جميع مفاتيح التوقيع المطلوبة والملفات المستهدفة موجودة؛ اسم الملف وحده غير كافٍ. |
| `not_installed` | لم يتم العثور على الهدف الاختياري. | نتيجة المحول الآمن بدون أي تغيير. |
| `skipped_incompatible` | الهدف موجود ولكن شكله غير مدعوم. | نتيجة المحول الآمن بدون أي تغيير لأن التوقيع الكامل غير متطابق. |
| `failed_rolled_back` | فشل التغيير وبقيت وحدات البايت السابقة سليمة. | فشلت معاملة المحول قبل إجراء التغيير أو تمت استعادة جميع الملفات المتأثرة والتحقق منها. |
| `rollback_failed` | تعذر التحقق من الاسترداد التلقائي. | تتطلب حالة المحول الثابت الاسترداد اليدوي من النسخة الاحتياطية المسجلة. |
| القاموس | التعيين من القيم الأولية إلى القيم العامة التوضيحات. | `randomday_dictionary_v2`، تم إنشاؤه من `dictionary.lua` ويتم تضمينه في مخرجات حالة وقت التشغيل. |
| الترجمة | عرض بشري مشتق من ملف التعريف الأولي القيم. | نتائج النطاق المحدود، والحقائق، والملخصات، والرسائل التي تم إنشاؤها بواسطة `translation.lua`؛ تظل القيم الأولية موثوقة. |
| الحالة العامة | ملخص عامل التشغيل المصحح والقابل للقراءة آليًا. | `web_export/today.json` باستخدام `randomday_public_status_v2`. |
| حالة وقت التشغيل | لقطة محلية تفصيلية يمكن قراءتها آليًا. | `runtime/current/randomday_status.json` باستخدام `randomday_runtime_status_v2`. |
