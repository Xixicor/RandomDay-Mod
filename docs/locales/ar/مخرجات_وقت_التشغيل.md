# تفسير حالة وقت التشغيل ومخططات الإخراج

> **المصدر الإنجليزي الأساسي:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


هذا هو دليل مخطط إكمال الحقل الأساسي. إنه يجيب على ما يعنيه كل حقل وحالة وقيمة فارغة ونتيجة الآلة. استخدم [خريطة ملف وقت التشغيل](%D9%85%D9%84%D9%81%D8%A7%D8%AA_%D9%88%D9%82%D8%AA_%D8%A7%D9%84%D8%AA%D8%B4%D8%BA%D9%8A%D9%84.md) للمنتجين والمسارات وتوقيت الكتابة والاحتفاظ والمعاملات الجانبية ومواقع الاسترداد.

جميع المسارات في هذا الدليل مرتبطة بالمجلد المثبت `RandomDay/` ما لم يتم إنشاء صف واضح لصندوق الحماية الذي تم تكوينه أو هدف محول اختياري بعد التثبيت وليسوا أعضاء في أي من الإصدارين تعد علامة ZIP.

<a id="choose-the-authoritative-view"></a>
## اختر العرض الموثوق

| تحتاج | مصدر موثوق |
|---|---|
| القواعد التي تم تحميلها بواسطة العملية الحالية | RandomDay الموجودة في طريقة العرض والمعاينة والملخصات المترجمة `SandboxSettings.ini` القراءة عند بدء التشغيل |
| مسك الدفاتر في قائمة الانتظار المعدة | `runtime/rotation_state.txt`، المخطط `1` |
| الحالة المحلية التفصيلية | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| الحالة العامة القابلة للقراءة آليًا | `web_export/today.json`، المخطط `2` و `randomday_public_status_v2` |
| الحالة القابلة للقراءة البشرية | `web_export/today.html`، المستمدة من نفس انتقال الحالة العامة |
| مفردات الترجمة | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| تمام إشعار اللاعب المحدود | `runtime/current/player_message_preview.txt` |

تقوم الحزمة HTML طرق عرض مشتقة. وهي لا تتجاوز علامة الحماية أو نتيجة المعاملة أو قيم ملف التعريف الأولية. حدد موقع آخر الملفات الجيدة المعروفة، والنسخ الاحتياطية للعمليات، والمرايا الجانبية، وأهداف المحول، و`UE4SS.log` في [ملفات وقت التشغيل](%D9%85%D9%84%D9%81%D8%A7%D8%AA_%D9%88%D9%82%D8%AA_%D8%A7%D9%84%D8%AA%D8%B4%D8%BA%D9%8A%D9%84.md).

<a id="rotation-state-schema"></a>
## مخطط حالة الدوران

`runtime/rotation_state.txt` يستخدم المخطط `1` ويحتوي على `key=value` زوج واحد في كل سطر:

| الحقل | المعنى |
|---|---|
| `schema_version` | يجب أن يكون `1`. |
| `mod_version` | قراءة هوية الحزمة من `.randomday_version`. |
| `rotation_id` | معرف المرور الحالي عبر مجموعة العائلة المؤهلة. |
| `mode` | `selected_run`, `non_repeating_random_run`، أو `rotation_run`. |
| `available_families` | معرفات العائلة المؤهلة مفصولة بفواصل بعد تصفية التكوين. |
| `remaining_families` | لم يتم تحديد العائلات المؤهلة بعد في تصريح المرور الحالي غير المتكرر. |
| `completed_families` | العائلات التي اكتمل ترتيبها المستمر المكون من 17 موضعًا في التمرير الحالي. |
| `active_family`, `active_day` | تم تسجيل معلومات العلامة النشطة عند تنفيذ التحديد. تعتبر علامة وضع الحماية موثوقة عند التشغيل التالي. |
| `prepared_family`, `prepared_day` | تم الاحتفاظ بالملف الشخصي لإعادة التشغيل التالية. |
| `active_run_id` | معرف تديره عائلة مرتبط بالاختيار المجهز. |
| `last_status` | حالة تحديد التقويم التي أنتجت هذا الملف. |
| `session_mode` | تم حل دورة الحياة المخصصة أو المؤقتة أو singleplayer/LAN. |
| `start_day_mode` | اختيار بدء عشوائي مكون أو لمرة واحدة لتشغيل جديد. |
| `day_progression_mode` | متسلسل ملفوف أو تقدم عشوائي غير متكرر. |
| `day_order` | معرفات اليوم المستمرة مفصولة بفواصل بالترتيب الدقيق الذي سيتم إعدادها به. |
| `day_position` | موضع اليوم المعد في `day_order`. |
| `updated_at` | وقت الكتابة المحلي لمقارنة عامل التشغيل. |

لا يتم قبول كتابة الحالة إلا عندما تتم إعادة قراءة علامة المخطط والعائلة المجهزة واليوم المعد بشكل صحيح قد يعود الملف إلى `rotation_state.last_good.txt`؛ ولا تزال علامة الحماية المحددة تحدد ما تم تحميله في اللعبة للعملية الحالية.

<a id="runtime-status-json"></a>
## حالة وقت التشغيل JSON

`runtime/current/randomday_status.json` تستخدم `status_schema=randomday_runtime_status_v2` ومجموعات الحقول الرئيسية هي:

| المجموعة | الحقول والتفسير |
|---|---|
| الهوية | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| التحديد | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| نشط | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| مُعد | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| الملخصات البشرية | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| اكتب إثباتًا | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| إثبات المحول | `adapter_status`, `adapter_results`؛ يحتوي كل سجل محول على دليل التوافق، transaction/rollback، وعدد الملفات التي تم تغييرها، و مراجع الهدف المنقحة |
| الحدود | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| التشخيصات | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

القيم النشطة غير المعروفة تعني أن صندوق الحماية الحالي لا يحتوي على علامة RandomDay قابلة للقراءة. ويجب عدم استبدالها بقيم معدة خارج `runtime/` إلى مرجع الاسم الأساسي، وتنقيح السلاسل التشخيصية للمسارات المطلقة المكتشفة.

<a id="public-status-json"></a>
## الحالة العامة JSON

`web_export/today.json` تستخدم `schema_version=2` و `status_schema=randomday_public_status_v2`. فهو يكرر الهوية، active/prepared، والتحديد، والمعاملة، والمحول، وحقائق حدود إعادة التشغيل التي يحتاجها المشغل. ويتضمن أيضًا:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` الحالي و`prepared_day_position`;
- `family_selection_mode`، والإرث `family_locked_until_day_17` الحالي و`family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`، وعددهم؛
- ملف تعريف المواجهة المُجهز، والطبقة، والموضوع، وفرصة اللقاء المختلط؛
- تمكين النطاق العالمي، إعداد العالم المفتوح، وسياسة العالم غير المعروف، وعدد فقط من أنماط العالم المستبعد التي تم تكوينها؛
- الرسالة المُجهزة ومعاينات الرسائل المجمعة؛
- `selected_at`, `sandbox_target`, `manual_copy_required`، والتجزئة المجهزة.

`profile_status` هي واحدة من `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence`، أو `write_failed_or_rollback`. `prepared_ready=true` لا تزال لا تعني نشطًا؛ مطلوب علامة بدء التشغيل الأحدث.

<a id="dictionary-and-translation-output"></a>
## مخرجات القاموس والترجمة

`runtime/current/randomday_dictionary.json` تستخدم `schema=randomday_runtime_dictionary_v2` ويحدد إصدار القاموس `randomday_dictionary_v2`. وهو يصف أوضاع الحزمة وحالات الاختيار ومجالات الضغط وتسميات الإعداد والقيم الأولية والمعاني باللغة البسيطة. تظل القيم غير المعروفة واضحة بدلاً من تحويلها إلى وصف موثوق.

`player_message_preview.txt`, `today.json`, `today.html`، والإشعارات داخل اللعبة هي طرق عرض مشتقة من نفس وحدة الترجمة. يظل الملف الشخصي الأساسي وقيم `SandboxSettings.ini` الأولية هي مصدر الحقيقة.

<a id="failure-and-recovery-rules"></a>
## قواعد الفشل والاسترداد

1. لا تصبح عملية الكتابة أو التحقق من الصحة المعلقة الفاشلة أبدًا هدفًا للإنتاج.
2. يؤدي فشل الترقية أو إعادة قراءة الإنتاج إلى استعادة النسخة الأصلية المحفوظة؛ النسخ الاحتياطي للعملية هو البديل عند فشل تلك الاستعادة.
3. يتطلب ملف التراجع المحتفظ به أو حالة `rollback_failed` مراجعة يدوية أثناء توقف اللعبة أو الخادم.
4. يتم تدهور كتابة وضع الحماية الناجح بالإضافة إلى الالتزام الفاشل بحالة التدوير، وليس جاهزًا؛ يتم تخطي المحولات ورسائل الملف الشخصي المعدة.
5. لا يؤدي فشل التصدير إلى تغيير نتيجة وضع الحماية، ولكنه يزيل مصدر إثبات الراحة. استخدم سجلات المعاملات والحالة وقراءة الملفات.
6. مخرجات وقت التشغيل هي بيانات تشغيلية محلية. لا تقم بإضافتها إلى إصدار ZIP أو نشرها كأمثلة دون مراجعة منفصلة للخصوصية.
