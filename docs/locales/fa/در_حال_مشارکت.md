# در حال مشارکت

> **منبع انگلیسی متعارف:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


RandomDay به عنوان یک پروژه کنترل شده نگهداری می شود.

درخواست‌های کشش عمومی، ارسال کد ناخواسته، بازنویسی خودکار، ارسال‌های پاک‌سازی کد تولید شده، و وصله‌های ویژگی‌های احتمالی پذیرفته نمی‌شوند مگر اینکه صراحتاً توسط مالک مخزن درخواست شود.

<a id="accepted-contact"></a>
## مخاطب پذیرفته شده

برای گزارش‌های اشکال، یادداشت‌های سازگاری، یا مشاهدات مدیریت سرور، از کانال‌های تماس فهرست‌شده در مستندات پروژه استفاده کنید.

<a id="not-accepted"></a>
## پذیرفته نشد

موارد زیر به طور پیش فرض پذیرفته نمی شوند:

- درخواست‌های کشش ناخواسته؛
- بازنویسی کدهای تولید شده؛
- بازسازهای گسترده؛
- تغییر قالب‌بندی فقط سبک؛
- تغییر منطق بازی آزمایش نشده؛
- فایل‌های مود شخص ثالث همراه؛
- کد منبع شخص ثالث دوباره توزیع شده؛
- تغییراتی که دلالت بر وابستگی رسمی به Abiotic Factor دارد، UE4SS، Nexus Mods یا نویسندگان مود شخص ثالث.

<a id="controlled-development"></a>
## توسعه کنترل شده

مالک مخزن ممکن است در صورت نیاز درخواست کمک برای بررسی، آزمایش یا مستندات خاص کند. موارد ارسالی درخواست نشده ممکن است بدون بازبینی بسته شوند.
