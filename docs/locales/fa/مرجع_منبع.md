# مرجع منبع بسته بندی شده

> **منبع انگلیسی متعارف:** [SOURCE_REFERENCE.md](../../SOURCE_REFERENCE.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


نسخه ZIP دقیقاً شامل 51 مسیر زیر است. سازنده مسیر گم شده، منبع بسته شکل اضافی، برخورد موردی، پیوند نمادی یا عضوی خارج از لیست مجاز تحت اللفظی خود را رد می کند. خروجی زمان اجرا، آزمایش‌ها، اسناد مخزن، و حالت‌های شخص ثالث عضو بسته نیستند.

همراه قابل بررسی ماشینی [`SOURCE_TRACEABILITY.json`](../../SOURCE_TRACEABILITY.json). این مسیرها را با ورودی‌ها، خروجی‌ها، عوارض جانبی، تنظیمات عمومی، حالت‌های قابل مشاهده، حالت‌های خرابی، قابلیت ویرایش و مستندات متعارف ثبت می‌کند.

هر ردیف Lua ارسال شده دارای یک `module-*` لنگر. پیوند یکسان در هدر منبع متعارف و سابقه ماشین آن، مالکیت، قرارداد، عوارض جانبی، خرابی‌ها و بازیابی را مستقیماً قابل ردیابی می‌کند.
