# مدهای اختیاری پشتیبانی شده

> **منبع انگلیسی متعارف:** [SUPPORTED_ADAPTERS.md](../../SUPPORTED_ADAPTERS.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


RandomDay می‌تواند یک مود نصب شده جداگانه از RandomDay. این ویژگی فقط در بسته سرور اختصاصی موجود است. singleplayer/LAN هرگز مود دیگری را ویرایش نمی کند.

RandomDay هیچ یک از مدهای فهرست شده در اینجا را شامل نمی شود یا توزیع مجدد نمی کند. هر مد اختیاری را از صفحه Nexus خودش نصب و فعال کنید و ابتدا دستورالعمل‌های نویسنده آن را دنبال کنید. RandomDay فقط تنظیمات شناسایی شده را تغییر می دهد که از قبل در فایل نصب شده وجود دارد. ویژگی‌هایی را به حالت دیگری اضافه نمی‌کند، و یک آداپتور را می‌توان بدون حذف نصب آن مود غیرفعال کرد. بسته سرور اختصاصی با `external_mods.enabled = true`.

<a id="what-randomday-changes"></a>
## چه RandomDay تغییرات

| ادغام اختیاری | تنظیمات انتخاب شده از نمایه فعال |
| --- | --- |
| موتور تخم ریزی آشفته / DynamicSpawns | حالت سخت، player/area رفتار خنک‌کردن، فعالیت طوفان و منطقه داغ، تخم‌گذاری رئیس و انفجار، زمان‌بندی چرخه تخم‌ریزی، محدوده کوچک و بزرگ خنک‌کردن، فاصله تخم‌ریزی، global/local/mod سرپوش، طوفان پورتال، نقض سفارش و شانس رئیس، و حداقل تخم ریزی در هر منطقه. |
| فیلدهای برنامه افزودنی Chaotic Spawn Engine اختیاری | هنگامی که `SharedData.lua` قبلاً حاوی RandomDay فیلدهای برنامه افزودنی، آداپتور می‌تواند نمایه برخورد، ردیف، موضوع، محدودیت‌های گروه، مقادیر رویداد ویژه و برخورد مختلط، بودجه، خنک‌سازی و کنترل‌های دامنه جهانی را ارائه دهد. این حالت دیگری برای دانلود نیست. |
| لیزرهای کشنده | فعال‌سازی حالت به‌علاوه آسیب و فعال کردن کنترل‌ها برای ساطع‌کننده‌های قابل استقرار، ساطع‌کننده‌های محیطی، بازتابنده‌ها و منشورها. |
| ANTE بالا | ضریب فرکانس Respawn، فرکانس Antevariant و development/debug سوئیچ می کند. RandomDay تمام کلیدهای توسعه و اشکال زدایی شناخته شده را خاموش نگه می دارد. |

کتابخانه نمایه مجموعه ای از مقادیر آماده شده را برای هر روز پشتیبانی می کند. یک روز آرام می تواند فشار را کاهش دهد، یک روز خطر می تواند آن را افزایش دهد و یک روز بهبودی می تواند آن را به شدت کاهش دهد. RandomDay مقادیر دلخواه را هنگام بوت محاسبه نمی کند. مقدار بازبینی شده را که توسط نمایه فعال نامگذاری شده است اعمال می کند.

<a id="how-recognition-protects-another-mod"></a>
## چگونه تشخیص از یک مد دیگر محافظت می کند

پیدا کردن یک نام فایل آشنا کافی نیست. قبل از نوشتن، RandomDay بررسی می کند که همه تنظیمات مورد نیاز برای آن آداپتور در فایل مورد نظر وجود داشته باشد. فقط تکالیف موجود را اصلاح می کند. هرگز یک تنظیم از دست رفته را اختراع نمی کند.

برای یک طرح‌بندی شناخته شده، RandomDay یک تراکنش محدود را انجام می دهد:

1. هر مقدار در نظر گرفته شده را برای نمایه فعال محاسبه کنید؛
2. یک نسخه پشتیبان از هر فایل مورد نظر ایجاد و بایت چک کنید؛
3. از طریق یک فایل در انتظار خواهر و برادر بنویسید؛
4. فایل معلق را تبلیغ کنید و بایت های ذخیره شده را دوباره بخوانید؛
5. هر مقدار مورد نظر را تأیید کنید؛
6. در صورت عدم موفقیت در هر مرحله، از بازیابی خودکار از نسخه‌های پشتیبان تأیید شده استفاده کنید.

DynamicSpawns می‌تواند تنظیمات و فایل‌های پیام پخش‌کننده شناسایی‌شده خود را در یک تراکنش شامل شود. RandomDay آن به‌روزرسانی چند فایل را به‌عنوان موفقیت‌آمیز گزارش نمی‌کند مگر اینکه تراکنش کامل به پایان برسد.

<a id="read-an-adapter-result"></a>
## نتیجه آداپتور را بخوانید

| نتیجه | معنا |
| --- | --- |
| `applied` | تنظیمات شناسایی شده تغییر کرد و بازخوانی شد. |
| `already_current` | تنظیمات شناسایی شده قبلاً با نمایه فعال مطابقت دارد. |
| `not_installed` | موارد اختیاری پیدا نشد. RandomDay بدون آن ادامه یافت. |
| `skipped_incompatible` | یک فایل پیدا شد، اما طرح تنظیمات کامل آن شناسایی نشد. چیزی تغییر نکرد. |
| `partial` | اصلی DynamicSpawns اعمال شد، اما یک فایل پیام ترجمه اختیاری تکمیل نشد. نتیجه آداپتور ضبط شده را مرور کنید. |
| `failed_rolled_back` | یک تراکنش ناموفق بود و بایت های قبلی دست نخورده باقی ماندند یا بازیابی و تأیید شدند. |
| `rollback_failed` | RandomDay نتوانست تغییر یا بازیابی را تأیید کند. حالت آسیب دیده را متوقف نگه دارید و نسخه پشتیبان ضبط شده آن را به صورت دستی بازیابی کنید. |

مدهای اختیاری موجود و ناسازگار متوقف نمی شوند RandomDay's چرخش جعبه ایمنی تحت پیکربندی ارسال شده.

<a id="enable-or-disable-integrations"></a>
## یکپارچه‌سازی‌ها را فعال یا غیرفعال کنید

کنترل ها در:

```text
RandomDay/Scripts/ax_config/server.lua
```

بسته سرور اختصاصی با:

```lua
external_mods = {
    enabled = true,
    optional_by_default = true,
    patch_only_existing_keys = true,
    backup_before_write = true,
    adapters = {
        "lethal_lasers",
        "dynamic_spawns",
        "encounter_director",
        "ante_up"
    }
}
```

- تنظیم `enabled = false` برای توقف RandomDay از بازرسی یا تغییر هر مد اختیاری.
- یک شناسه آداپتور را بردارید تا آن مد را به حال خود رها کنید و در عین حال ادغام های دیگر را فعال نگه دارید.
- نگه دارید `patch_only_existing_keys` و `backup_before_write` روی `true`. آنها مرز ایمنی نوشتن هستند.
- نگه دارید `optional_by_default = true` مگر اینکه هر مد اختیاری فهرست شده بخشی ضروری از سرور باشد. تنظیم آن بر روی `false` باعث می‌شود آداپتور مفقود، ناسازگار، یا به‌طور ایمن برگشت‌خورده روی نتیجه کل تأثیر بگذارد.

وقتی یک مد اختیاری را غیرفعال می‌کنید لازم نیست آن را حذف یا غیرفعال کنید RandomDay.

RandomDay's فقط از فیلدهای پیکربندی موجود در یک چیدمان نصب شده و شناخته شده استفاده می کنند. آنها آن مدها را دوباره توزیع یا جایگزین نمی کنند.

<a id="backups-and-manual-recovery"></a>
## پشتیبان گیری و بازیابی دستی

کپی‌های پیش‌نوشته تأیید شده در زیر نگهداری می‌شوند:

```text
RandomDay/runtime/backups/external_<transaction>_<adapter>/
```

اگر `rollback_failed` ظاهر می شود:

1. بازی یا سرور را متوقف کنید؛
2. تنظیم `external_mods.enabled = false`، یا شناسه آداپتور آسیب دیده را حذف کنید؛
3. فایل هدف فعلی و خواهر و برادر آن را حفظ کنید pending/rollback فایل‌ها؛
4. فایل های پشتیبان شماره گذاری شده را با مسیرهای هدف ثبت شده در نتیجه آداپتور مطابقت دهید؛
5. بایت های تایید شده را در زمانی که سرویس متوقف شده است بازیابی کنید؛
6. مد اختیاری را به تنهایی قبل از فعال کردن مجدد آن شروع کنید RandomDay.

با تغییر نام تنظیمات یا افزودن کلیدهای از دست رفته، سازگاری را مجبور نکنید. از طرح‌بندی شناخته‌شده استفاده کنید، آداپتور را غیرفعال بگذارید، یا قبل از گسترش ادعای پشتیبانی، یک نسخه جدید ثابت و آزمایش تراکنش اضافه کنید.
