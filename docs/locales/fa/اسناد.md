# RandomDay مستندات

> **منبع انگلیسی متعارف:** [README.md](../../README.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


RandomDay قوانین جعبه ایمنی مورد استفاده توسط دنیای عامل Abiotic را بدون تغییر جلسه‌ای که قبلاً در حال اجرا است تغییر می‌دهد. با راهنمای منطبق با کاری که می‌خواهید انجام دهید شروع کنید.
