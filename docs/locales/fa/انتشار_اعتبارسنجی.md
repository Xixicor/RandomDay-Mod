# تأیید اعتبار

> **منبع انگلیسی متعارف:** [RELEASE_VALIDATION.md](../../RELEASE_VALIDATION.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


این صفحه برای مشارکت کنندگان و نگهبانان انتشار است. بازیکنانی که مود را نصب می کنند نیازی به اجرای این دستورات ندارند.

<a id="ordinary-user-proof"></a>
## گواهی کاربر معمولی

نسخه زمانی قابل درک است که یک خواننده جدید بتواند یکی از دو بسته را انتخاب کند، آن را نصب کند، نمایه آماده‌شده را از طریق نمایه‌ای فعال شناسایی کند و نتیجه را بازیابی کند. این وظایف خواننده نباید به Git نیاز داشته باشند، PowerShell، پایتون، یا چک‌سوم.

<a id="contributor-checks"></a>
## بررسی های مشارکت کننده

از ریشه مخزن اجرا شود:

```powershell
python -B tools/validate_repo.py
python -B -m unittest discover tests
```

وقتی `luac` موجود است، هر فایل Lua ارسال شده را بررسی کنید:

```powershell
Get-ChildItem RandomDay -Recurse -Filter *.lua | ForEach-Object { luac -p $_.FullName }
```

آزمایش‌های زمان اجرا Lua به `lupa`. یک مترجم Lua یا `lupa` یک قابلیت آزمایشی در دسترس نیست، نه یک نتیجه مثبت.

<a id="release-checks"></a>
## چک‌ها را آزاد کنید

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

بررسی انتشار این شرایط را تأیید می‌کند:

- `VERSION` و `RandomDay/.randomday_version` مطابقت دارد.
- فقط نسخه فعلی در `releases/`.
- اختصاصی و singleplayer/LAN ZIP ها جایگزین کامل هستند.
- هر دو بایگانی حاوی `RandomDay/Scripts/main.lua` و بدون بارگیری مورد برخورد.
- نشانگرهای حالت بسته `dedicated_server` و `singleplayer_manual`.
- ZIP بایت‌ها قطعی هستند و با `CHECKSUMS.sha256`.
- هیچ داده زمان اجرا، پیکربندی خصوصی، اعتبارنامه، حافظه پنهان، یا خروجی آزمایشی بسته بندی نشده است.
- همه پیوندهای اسناد محلی و 27 صفحه ورودی محلی تأیید می شوند.

<a id="avoid-validation-environment-pitfalls"></a>
## از دام های محیط اعتبارسنجی پرهیز کنید

- بررسی‌های مخزن‌نویسی را به‌صورت سریال اجرا کنید تا دو فرآیند به طور همزمان جایگزین یک فایل موقت نشوند.
- در Windows، ZIP نام اعضا را به جای استفاده از جستجوی فایل حساس به حروف کوچک برای تصمیم گیری در مورد وجود بارگیری با حروف کوچک می نامد.
- تأیید `mods.txt` و `enabled.txt` فقط در تست سرور نصب شده. آنها دلیلی بر انجام آزمایشات منبع نیستند.
- یک مهلت زمانی فرمان را به عنوان ناقص ضبط کنید. بدون خروجی محدود فرمان، آن را به پاس یا شکست تبدیل نکنید.
- فایل‌های موقت داخل مخزن را نادیده بگیرید `.tmp/`.

<a id="known-limits"></a>
## محدودیت های شناخته شده

 اعتبار سنجی محلی قراردادهای منبع، بسته، اسناد و تجهیزات را ثابت می کند. ترتیب راه‌اندازی پانل سرور خاص، طرح‌بندی پیام مشتری زنده، یا مسیر سیستم فایل خاص میزبان را ثابت نمی‌کند. آنها را هنگام آزمایش به عنوان نتایج یکپارچه سازی جداگانه ثبت کنید.
