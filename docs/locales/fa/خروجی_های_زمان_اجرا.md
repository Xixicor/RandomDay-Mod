# شماهای وضعیت زمان اجرا و خروجی را تفسیر کنید

> **منبع انگلیسی متعارف:** [RUNTIME_OUTPUTS.md](../../RUNTIME_OUTPUTS.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


این راهنمای طرحواره کامل فیلد متعارف است. به معنای هر فیلد، حالت، مقدار خالی و نتیجه ماشین است. از [نقشه فایل زمان اجرا](%D9%81%D8%A7%DB%8C%D9%84%E2%80%8C%D9%87%D8%A7%DB%8C_%D8%B2%D9%85%D8%A7%D9%86_%D8%A7%D8%AC%D8%B1%D8%A7.md) برای تولیدکنندگان، مسیرها، زمان‌بندی نوشتن، حفظ، حاشیه‌های تراکنش، و مکان‌های بازیابی.

همه مسیرهای موجود در این راهنما نسبت به `RandomDay/` مگر اینکه یک ردیف به صراحت جعبه ایمنی پیکربندی شده یا یک هدف آداپتور اختیاری را نامگذاری کند. خروجی‌های زمان اجرا پس از نصب تولید می‌شوند و عضو هیچکدام از نسخه‌های ZIP.

<a id="choose-the-authoritative-view"></a>
## نمای معتبر را انتخاب کنید

| نیاز | منبع معتبر |
|---|---|
| قوانین بارگیری شده توسط فرآیند فعلی | RandomDay در `SandboxSettings.ini` خواندن در هنگام راه اندازی |
| صف حسابداری آماده شده | `runtime/rotation_state.txt`، طرحواره `1` |
| وضعیت محلی مفصل | `runtime/current/randomday_status.json`, `randomday_runtime_status_v2` |
| وضعیت عمومی قابل خواندن توسط ماشین | `web_export/today.json`، طرحواره `2` و `randomday_public_status_v2` |
| وضعیت قابل خواندن توسط انسان | `web_export/today.html`، برگرفته از همان انتقال وضعیت عمومی |
| واژگان ترجمه | `runtime/current/randomday_dictionary.json`, `randomday_runtime_dictionary_v2` |
| اطلاعیه پخش دقیق محدود شده | `runtime/current/player_message_preview.txt` |

HTML مشاهده، پیش‌نمایش، و خلاصه‌های ترجمه شده، نماهای مشتق شده‌اند. آنها نشانگر جعبه ایمنی، نتیجه تراکنش یا مقادیر نمایه خام را لغو نمی کنند. مکان یابی آخرین فایل های شناخته شده، نسخه های پشتیبان عملیات، آینه ها، اهداف آداپتور، و `UE4SS.log` در [فایل های زمان اجرا](%D9%81%D8%A7%DB%8C%D9%84%E2%80%8C%D9%87%D8%A7%DB%8C_%D8%B2%D9%85%D8%A7%D9%86_%D8%A7%D8%AC%D8%B1%D8%A7.md).

<a id="rotation-state-schema"></a>
## شما وضعیت چرخش

`runtime/rotation_state.txt` از طرحواره `1` و حاوی یک `key=value` جفت در هر خط:

| فیلد | معنا |
|---|---|
| `schema_version` | باید `1`. |
| `mod_version` | هویت بسته خوانده شده از `.randomday_version`. |
| `rotation_id` | شناسه برای پاس فعلی از مجموعه خانواده واجد شرایط. |
| `mode` | `selected_run`, `non_repeating_random_run` یا `rotation_run`. |
| `available_families` | شناسه‌های خانواده واجد شرایط جدا شده با کاما پس از فیلتر کردن پیکربندی. |
| `remaining_families` | خانواده‌های واجد شرایط هنوز در مجوز غیر تکراری فعلی انتخاب نشده‌اند. |
| `completed_families` | خانواده هایی که سفارش 17 موقعیتی کامل آنها در مجوز فعلی تکمیل شده است. |
| `active_family`, `active_day` | اطلاعات نشانگر فعال که هنگام انجام انتخاب ثبت می‌شوند. نشانگر جعبه ایمنی در راه‌اندازی بعدی معتبر است. |
| `prepared_family`, `prepared_day` | نمایه برای راه اندازی مجدد بعدی نگه داشته شد. |
| `active_run_id` | شناسه اجرای خانوادگی مرتبط با انتخاب آماده شده. |
| `last_status` | ایالت انتخابی تقویم که این فایل را تولید کرده است. |
| `session_mode` | تخصیص دائمی، اختصاصی موقت، یا singleplayer/LAN چرخه حیات. |
| `start_day_mode` | انتخاب شروع تصادفی پیکربندی شده یا یکبار مصرف برای اجرای جدید. |
| `day_progression_mode` | پیشرفت متوالی یا تصادفی بدون تکرار. |
| `day_order` | شناسه‌های روز باقی‌مانده جدا شده با کاما به ترتیب دقیقی که آماده می‌شوند. |
| `day_position` | موقعیت روز آماده شده در `day_order`. |
| `updated_at` | زمان نوشتن محلی برای مقایسه اپراتور. |

نوشتن حالت فقط زمانی پذیرفته می شود که نشانگر طرحواره، خانواده آماده شده و روز آماده شده به درستی خوانده شوند. یک فایل فعلی ناخوانا ممکن است به `rotation_state.last_good.txt`; نشانگر جعبه ایمنی انتخاب شده همچنان تعیین می کند که بازی برای فرآیند فعلی چه چیزی بارگیری شده است.

<a id="runtime-status-json"></a>
## وضعیت زمان اجرا JSON

`runtime/current/randomday_status.json` از `status_schema=randomday_runtime_status_v2`. گروه های اصلی آن عبارتند از:

| گروه | فیلدها و تفسیر |
|---|---|
| هویت | `mod`, `version`, `package_mode`, `mode`, `session_mode`, `profile_system`, `status_schema`, `dictionary_version` |
| انتخاب | `reason`, `selection_status`, `active_profile_detection`, `rotation_id`, `run_id`, `cycle_length_days` |
| فعال | `active_cycle_day`, `active_profile_id`, `active_display_name`, `active_family`, `active_family_label`, `active_profile_translation` |
| آماده شده | `prepared_next_cycle_day`, `prepared_next_profile_id`, `prepared_next_display_name`, `prepared_next_family`, `prepared_next_family_label`, `prepared_profile_translation` |
| خلاصه های انسانی | `profile_intensity`, `player_summary`, `prepared_profile_intensity`, `prepared_player_summary`, `admin_summary`, `message_preview` |
| اثبات بنویسید | `write_status`, `backup_status`, `last_known_good_status`, `sandbox_transaction_status`, `sandbox_rollback_status`, `prepared_ready`, `state_commit_ok`, `state_commit_error_code` |
| ضد آداپتور | `adapter_status`, `adapter_results`; هر رکورد آداپتور حاوی شواهد سازگاری است، transaction/rollback وضعیت، تعداد فایل های تغییر یافته، و منابع هدف ویرایش شده |
| مرزها | `restart_required_for_prepared_profile`, `sandbox_target`, `manual_copy_required`, `mirrors_written`, `world_scope`, `dictionary_path` |
| تشخیص | `hash`, `replacement_method`, `pending_readback_verified`, `target_readback_verified`, `updated_at` |

مقادیر فعال ناشناخته به این معنی است که جعبه ایمنی فعلی حاوی یک RandomDay. آنها نباید با مقادیر آماده شده جایگزین شوند. مسیرهای آداپتور خارج از `runtime/` به یک مرجع نام پایه کاهش می یابد، و رشته های تشخیصی مسیرهای مطلق شناسایی شده را ویرایش می کنند.

<a id="public-status-json"></a>
## وضعیت عمومی JSON

`web_export/today.json` از `schema_version=2` و `status_schema=randomday_public_status_v2`. این هویت، active/prepared، حقایق انتخاب، تراکنش، آداپتور و راه‌اندازی مجدد که توسط اپراتور مورد نیاز است. همچنین شامل موارد زیر است:

- `session_mode`, `start_day_mode`, `configured_start_day`, `day_progression_mode`, `day_order` و `prepared_day_position`;
- `family_selection_mode`، میراث `family_locked_until_day_17` و `family_locked_until_cycle_complete`;
- `remaining_families`, `completed_families`، و تعداد آنها؛
- نمایه رویارویی آماده شده، ردیف، موضوع، و شانس برخورد مختلط؛
- فعال‌سازی حوزه جهانی، تنظیم جهان باز، خط‌مشی جهان ناشناخته، و تنها تعدادی از الگوهای جهان حذف‌شده پیکربندی شده؛
- پیام آماده شده و پیش نمایش پیام ترکیبی؛
- `selected_at`, `sandbox_target`, `manual_copy_required` و هش آماده شد.

`profile_status` یکی از `prepared_for_next_reboot`, `next_reboot_already_prepared`, `degraded_state_persistence` یا `write_failed_or_rollback`. `prepared_ready=true` هنوز به معنای فعال نیست. نشانگر راه اندازی بعدی مورد نیاز است.

<a id="dictionary-and-translation-output"></a>
## فرآوری فرهنگ لغت و ترجمه

`runtime/current/randomday_dictionary.json` از `schema=randomday_runtime_dictionary_v2` و نسخه فرهنگ لغت `randomday_dictionary_v2`. حالت‌های بسته، حالت‌های انتخاب، حوزه‌های فشار، برچسب‌های تنظیم، مقادیر خام و معانی به زبان ساده را توصیف می‌کند. مقادیر ناشناخته به جای تبدیل شدن به توضیحات مطمئن، صریح باقی می مانند.

`player_message_preview.txt`, `today.json`, `today.html` و اعلان‌های درون بازی نماهایی هستند که از همان ماژول ترجمه مشتق شده‌اند. نمایه زیرین و خام `SandboxSettings.ini` منبع حقیقت باقی می مانند.

<a id="failure-and-recovery-rules"></a>
## قوانین خرابی و بازیابی

1. نوشتن یا تأیید اعتبار معلق ناموفق هرگز به هدف تولید تبدیل نمی شود.
2. یک تبلیغ ناموفق یا بازخوانی تولید باعث بازیابی نسخه اصلی می شود. یک پشتیبان عملیاتی زمانی که بازیابی با شکست مواجه می شود، بازگشتی است.
3. یک فایل بازگشتی حفظ شده یا `rollback_failed` نیاز به بازبینی دستی دارد در حالی که بازی یا سرور متوقف شده است.
4. نوشتن موفق در جعبه ماسه‌بازی به‌علاوه تعهد وضعیت چرخش ناموفق، تنزل یافته، آماده نیست. آداپتورها و پیام‌های نمایه آماده نادیده گرفته می‌شوند.
5. یک شکست صادراتی نتیجه جعبه ایمنی را تغییر نمی‌دهد، اما منبع اثبات راحتی را حذف می‌کند. از گزارش‌های تراکنش، وضعیت و بازخوانی فایل استفاده کنید.
6. خروجی های زمان اجرا داده های عملیاتی محلی هستند. آنها را به نسخه ZIP یا آنها را به عنوان نمونه بدون بررسی حریم خصوصی جداگانه منتشر کنید.
