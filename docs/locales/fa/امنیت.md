# خط مشی امنیتی

> **منبع انگلیسی متعارف:** [SECURITY.md](../../../SECURITY.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


RandomDay فایل های پیکربندی سرور را می نویسد و می تواند فایل های پیکربندی مود اختیاری را وصله کند. تغییرات را از نظر عملیاتی حساس تلقی کنید.

<a id="do-not-report-as-security-issues"></a>
## مشکلات امنیتی را گزارش نکنید

- تغییر تعادل عادی بازی.
- چرخش نمایه راه اندازی مجدد بعدی مورد انتظار است.

<a id="report-privately"></a>
## گزارش خصوصی

- خطرات پیمایش مسیر.
- رفتار نوشتن فایل ناامن.
- قابلیت بازنویسی فایل های خارج از server/mod مسیرها.
- اجرای دستور مخرب.

تا زمانی که یک کانال امنیتی عمومی وجود داشته باشد، به صورت خصوصی به صاحب مخزن گزارش دهید.
