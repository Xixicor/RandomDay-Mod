# واژه نامه

> **منبع انگلیسی متعارف:** [GLOSSARY.md](../../GLOSSARY.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


این واژگان متعارف برای RandomDay مستندات. رویه‌ها به جای بازتعریف یک حالت در چندین راهنما به این تعاریف پیوند می‌خورند. قوانین فیلد ویژه طرحواره در [خروجی های زمان اجرا](%D8%AE%D8%B1%D9%88%D8%AC%DB%8C_%D9%87%D8%A7%DB%8C_%D8%B2%D9%85%D8%A7%D9%86_%D8%A7%D8%AC%D8%B1%D8%A7.md).

| مدت | معنی ساده | معنای فنی دقیق |
|---|---|---|
| نمایه فعال | قوانینی که جلسه فعلی استفاده می کند. | family/day شناسایی شده توسط RandomDay هنگام راه‌اندازی فرآیند از جعبه ایمنی خوانده می‌شود. |
| نمایه آماده | قوانین آماده برای جلسه بعدی. | کامل family/day که بایت های هدف آن اعتبارسنجی و بازخوانی را پشت سر گذاشتند و وضعیت چرخش آن متعهد شد. قبل از شروع مجدد بازخوانی فعال نیست. |
| بازیابی شد | آماده سازی ناموفق بود و بایت های تایید شده قبلی برگردانده شدند. | تراکنش ناموفق گزارش بازگشت موفقیت آمیز و بازخوانی نسخه اصلی یا تأیید شده بازیابی شده است. |
| صف راه اندازی مجدد بعدی | یک انتخاب آماده برای بوت بعدی نگه داشته شد. | `next_reboot_queue` در هر فرآیند یک بار انتخاب می‌کند و در حین نظارت از آن گزینه متعلق به بوت استفاده مجدد می‌کند. |
| بوت استرپ | اولین آماده سازی زمانی که هیچ نشانگر فعالی وجود ندارد. | انتخاب اولین روز پیکربندی شده یا تصادفی از یک خانواده واجد شرایط. `cycle.bootstrap_day` فقط یک نسخه بازگشتی سازگاری است. |
| خانواده | پیشرفت سبک پخش 17 روزه. | یک ورودی رجیستری و ماژول خانواده که دقیقاً 17 نمایه کامل تولید می کند. |
| چرخش | یک مجوز از طریق خانواده های واجد شرایط. | ایالت شناسایی شده توسط `rotation_id`، با فهرست‌های خانواده موجود، باقی‌مانده و تکمیل‌شده. |
| اجرا | یک خانواده در تمام شناسه‌های 17 روزه. | یک توالی وابسته به خانواده که با `run_id`; خانواده تا زمانی که همه موقعیت‌های سفارش روزانه تکمیل شوند، قفل می‌مانند. |
| حالت جلسه | نحوه استفاده اپراتور از این بسته. | `persistent_dedicated`, `temporary_dedicated` یا `singleplayer_lan`; حالت بسته همچنان مرز سیستم فایل را کنترل می کند. |
| سفارش روزانه | ترتیب دقیق استفاده شده توسط یک خانواده اجرا شده. | جایگشت 17 عددی ادامه دار. حالت متوالی از روز شروع آن بسته می شود. حالت تصادفی یک بار بدون تکرار به هم می‌ریزد. |
| نشانگر | هویت ذخیره شده در فایل sandbox. | `RANDOMDAY_*` با نمایه کامل ارائه شده و در راه اندازی فرآیند بعدی خوانده می شوند. |
| آماده آماده | تعهد نوشتن و وضعیت با موفقیت انجام شد. | `prepared_ready=true` به نتیجه موفقیت آمیز جعبه ایمنی و عدم موفقیت در ارتکاب حالت نیاز دارد. فعال سازی را ثابت نمی کند. |
| از قبل فعلی | هدف از قبل دارای بایت های مورد نظر است. | هش نمایه ارائه شده با هدف مطابقت دارد، بنابراین RandomDay last-good/mirror بدون بازنویسی اولیه کار می کند. |
| تداوم وضعیت تنزل یافته | بایت‌های جعبه ایمنی با موفقیت انجام شد، اما حسابداری چرخشی انجام نشد. | `profile_status=degraded_state_persistence`; آداپتورها و پیام‌های نمایه آماده نادیده گرفته می‌شوند. |
| فایل معلق | بایت های نامزد هنوز ارتقاء نیافته اند. | `<target>.randomday.pending`، نوشته شده، بازخوانی شده و قبل از جایگزینی تأیید شده است. |
| پرونده برگشتی | نسخه اصلی در حین تعویض نگه داشته شد. | `<target>.randomday.rollback`، برای بازیابی تولید در صورت عدم موفقیت در تبلیغات یا اعتبارسنجی استفاده می‌شود. |
| پشتیبان گیری عملیات | یک کپی بادوام که قبل از جهش ایجاد شده است. | یک فایل تایید شده در زیر `runtime/backups/` برای تراکنش اصلی، آینه ای یا آداپتور. |
| آخرین خوب شناخته شده | آخرین جعبه ایمنی پذیرفته شده برای بازیابی. | `runtime/last_good/SandboxSettings.ini` به علاوه `manifest.lua`; جفت هویت و هش نمایه را ثبت می کند. |
| آینه | هدف دوم جعبه ایمنی اختیاری. | هدفی که صریحاً پیکربندی شده یا مشتق از نام جهانی است که پس از اصلی از طریق تراکنش خود نوشته شده است. |
| حالت بسته | مرز انتخاب شده توسط دارایی انتشار را نصب کنید. | `dedicated_server` یا `singleplayer_manual` از `.randomday_mode`. |
| حالت کپی دستی | Singleplayer/LAN بدون کشف ذخیره. | `singleplayer_manual` فقط در داخل `runtime/singleplayer_manual/` و آداپتورها و آینه ها را غیرفعال می کند. |
| آداپتور | RandomDay-owned نگاشت برای مود نصب شده دیگری. | یک طرح تراکنش دارای دروازه امضا که تکالیف موجود را فقط پس از پشتیبان گیری و بررسی سازگاری به روز می کند. |
| طرح بندی شناخته شده | شکل فایل آداپتور دقیق برای نوشتن پذیرفته شد. | همه کلیدهای امضای مورد نیاز و فایل های هدف موجود هستند. نام فایل به تنهایی کافی نیست. |
| `not_installed` | هدف اختیاری پیدا نشد. | نتیجه آداپتور ایمن بدون جهش. |
| `skipped_incompatible` | یک هدف وجود دارد اما شکل آن پشتیبانی نمی‌شود. | نتیجه آداپتور ایمن بدون جهش، زیرا امضای کامل مطابقت نداشت. |
| `failed_rolled_back` | تغییر انجام نشد و بایت های قبلی دست نخورده هستند. | تراکنش آداپتور قبل از جهش انجام نشد یا همه فایل‌های آسیب‌دیده بازیابی و تأیید شدند. |
| `rollback_failed` | بازیابی خودکار تأیید نشد. | وضعیت آداپتور سخت که نیاز به بازیابی دستی از نسخه پشتیبان ضبط شده دارد. |
| فرهنگ لغت | نگاشت از مقادیر خام به توضیحات عمومی. | `randomday_dictionary_v2`، تولید شده از `dictionary.lua` و در خروجی وضعیت زمان اجرا گنجانده شده است. |
| ترجمه | نمایش انسانی برگرفته از مقادیر نمایه خام. | نمرات دامنه محدود، حقایق، خلاصه‌ها و پیام‌های تولید شده توسط `translation.lua`; مقادیر خام معتبر باقی می مانند. |
| وضعیت عمومی | خلاصه اپراتور قابل خواندن توسط ماشین پاکسازی شده. | `web_export/today.json` با استفاده از `randomday_public_status_v2`. |
| وضعیت زمان اجرا | عکس فوری محلی دقیق و قابل خواندن توسط ماشین. | `runtime/current/randomday_status.json` با استفاده از `randomday_runtime_status_v2`. |
