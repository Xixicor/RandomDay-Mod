# مرجع وضعیت و خطا

> **منبع انگلیسی متعارف:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


از `status`, `transaction_status`, `rollback_status` و `error` از صادرات زمان اجرا. عبارت مشابه در یک پنل یا کنسول جایگزین آن فیلدها نیست.

این بخش مرجع جستجوی کامل است. درخت تصمیم بالا دسته مربوطه را انتخاب می کند. این جداول مقادیر دقیق ماشین و پاسخ های امن اپراتور را حفظ می کنند.

<a id="normal-or-informational-states"></a>
## حالت های عادی یا اطلاعاتی

| وضعیت | معنا | پاسخ اپراتور |
|---|---|---|
| `prepared_for_next_reboot` | یک نمایه معتبر برای بوت بعدی نوشته شد. | بدون اقدام. جلسه فعلی بدون تغییر است. |
| `next_reboot_already_prepared` | نمایه بعدی مورد نظر از قبل با هدف مطابقت دارد. | بدون اقدام. چرخش دیگری را مجبور نکنید. |
| `already_current` / `unchanged` | هدف از قبل حاوی بایت های مورد نظر است. | بدون اقدام. |
| `applied` | بازخوانی نوشتن و تولید انجام شد. | active/prepared تمایز پس از بوت بعدی. |
| `bootstrap_prepare_first_family_start_day` | هیچ حالت چرخشی قبلی وجود نداشت، بنابراین اولین روز پیکربندی شده آماده شد. | در اولین استفاده مورد انتظار است. |
| `state_recovery_rewrite_prepared_profile_no_reroll` | وضعیت ذخیره شده بازیابی شد و همان نمایه آماده شده بازنویسی شد. | روز بازیابی را تأیید کنید. هیچ انتخاب تصادفی جدیدی رخ نداده است. |
| `supervision_reconfirm_prepared_profile_no_advance` | یک مجوز نظارت، آماده سازی موجود را تأیید کرد. | مورد انتظار. صف دو بار جلو نرفت. |
| `external_mods_disabled` | پردازش آداپتور اختیاری غیرفعال است. | هیچ اقدامی مگر اینکه آداپتورها در نظر گرفته شده باشند. |
| `external_mods_processed` | همه طرح‌های آداپتور فعال به یک نتیجه پایانی رسیدند. | هر ردیف آداپتور را مرور کنید. |

<a id="startup-configuration-errors"></a>
## خطاهای پیکربندی راه اندازی

این پیام‌ها قبل از RandomDay یک نمایه می نویسد. تنظیم نامگذاری شده یا نشانگر بسته را تصحیح کنید. شاخه اعتبار سنجی را دور نزنید.

| متن خطا | معنا | پاسخ ایمن |
|---|---|---|
| `invalid package mode marker; expected dedicated_server or singleplayer_manual` | `.randomday_mode` وجود ندارد، نادرست است، یا از بسته اشتباهی موجود است. | یک بسته کامل را دوباره در یک پوشه مرحله بندی تمیز نصب کنید و نشانگر حالت مورد نظر را حفظ کنید. |
| `invalid experience.mode` | `experience.mode` یکی از مقادیر مستند نیست. | از `auto`, `persistent_dedicated`, `temporary_dedicated` یا `singleplayer_lan`. |
| `singleplayer_manual package requires experience.mode=auto or singleplayer_lan` | یک بسته کپی دستی به عنوان یک سرور اختصاصی پیکربندی شده است. | بازیابی `auto` یا `singleplayer_lan`; آن را به طور خودکار به سمت یک دنیای بیرونی هدایت نکنید. |
| `dedicated_server package cannot use experience.mode=singleplayer_lan` | یک بسته اختصاصی برای گردش کار کپی دستی پیکربندی شده است. | از `auto`, `persistent_dedicated` یا `temporary_dedicated`. |
| `cycle.start_day_mode must be configured or random` | انتخابگر روز اولیه نامعتبر است. | دقیقاً از `configured` یا `random`. |
| `cycle.day_progression_mode must be sequential or non_repeating_random` | انتخابگر ترتیب روز نامعتبر است. | دقیقاً از `sequential` یا `non_repeating_random`. |
| `cycle.start_day must be a whole day inside the configured cycle` | روز شروع پیکربندی شده کسری یا خارج از چرخه است. | از یک عدد کامل از 1 تا `cycle_length_days`. |
| `sandbox recovery safety locks must remain true` | پشتیبان گیری یا آخرین بازیابی غیرفعال شد. | هر دو قفل ایمنی را بازیابی کنید. RandomDay عمداً از نوشتن ناامن امتناع می کند. |
| `external adapter transaction safety locks must remain true` | پچ کردن آداپتور یا محافظت پشتیبان غیرفعال شد. | هر دو قفل ایمنی آداپتور را بازیابی کنید یا آداپتورها را به صورت گروهی غیرفعال کنید. |
| `paths.world_name must be one folder name` | نام جهانی پیکربندی شده حاوی یک جداکننده یا نویسه ناامن است. | فقط نام دقیق پوشه را با استفاده از حروف، اعداد، فاصله، زیرخط یا خط فاصله وارد کنید. |
| `required runtime directory unavailable` | یک فهرست خروجی mod-local مورد نیاز ایجاد یا تأیید نشد. | فقط نام RandomDay و اجازه نوشتن آن. |

<a id="profile-wide-configuration-errors"></a>
## خطاهای پیکربندی در سطح نمایه

این خطاها ساخت نمایه را قبل از نوشتن جعبه شنی متوقف می‌کنند.

| متن خطا | معنا | پاسخ ایمن |
|---|---|---|
| `sandbox.profile_overrides must be a table` | چهار گزینه در سطح نمایه با نوع دیگری از Lua جایگزین شدند. | جدول مستند شده را در `Scripts/ax_config/server.lua`. |
| `unsupported sandbox.profile_overrides key` | جدول حاوی تنظیماتی است که یکی از چهار کلید پشتیبانی شده نیست. | کلید نامگذاری شده را بردارید و از family/profile برای سایر تنظیمات جعبه ایمنی. |
| `sandbox.profile_overrides.<key> must be boolean` | `HardcoreMode` یا `AllowIronMode` `true` یا `false`. | از یک لوا بولی نقل قول نشده استفاده کنید. |
| `sandbox.profile_overrides.<key> must be integer` | مقدار پشتیبانی یک عدد کامل نیست. | از یک عدد کامل استفاده کنید. |
| `sandbox.profile_overrides.<key> outside supported range` | مقدار پشتیبانی خارج از `0..1000`. | یک عدد کامل را از `0` تا `1000`. |

<a id="rollback-and-intermediate-states"></a>
## حالت بازگشتی و میانی

| مقدار | معنا | پاسخ ایمن |
|---|---|---|
| `not_started` / `pending` | تراکنش یا طرح آداپتور به نتیجه پایانی نرسیده است. | فقط برای مجوز راه اندازی محدود فعلی منتظر بمانید. وضعیت پایدار نیاز به بررسی دارد. |
| `not_needed` | برگشت لازم نیست. | بدون اقدام. |
| `original_held` | هدف اصلی قبل از ارتقاء به موقعیت بازیابی منتقل شد. | در زمانی که تراکنش ناقص است، فایل بازیابی را حذف نکنید. |
| `retained_after_success` | هدف جدید تأیید شد، اما داده های بازیابی باقی می مانند زیرا پاکسازی در دسترس نبود یا عمداً حفظ شد. | بایت های تولید را قبل از حذف هر فایل بازیابی نامگذاری شده تأیید کنید. |
| `discarded_after_success` | جایگزین تأیید شد و داده‌های بازگشت موقت پاک شد. | بدون اقدام. |
| `rollback_failed` | تلاش برای بازیابی تأیید نشد. | سرور را متوقف نگه دارید و از آخرین نسخه پشتیبان عملیات تأیید شده استفاده کنید. |
| `skipped_state_persistence_failed` | بایت‌های جعبه ایمنی آماده شدند، اما وضعیت چرخش ادامه نداشت، بنابراین آداپتورها و پیام‌های پخش‌کننده آماده حذف شدند. | تعمیر ذخیره سازی حالت زمان اجرا. صف را به صورت دستی دوباره رول نکنید یا جلو نبرید. |
| `failed` | یک ردیف خلاصه نشان دهنده یک خرابی ترمینال است که علت خاص آن در `error` یا فیلدهای تراکنش. | اولین کد خاص را دنبال کنید. از `failed` به تنهایی. |

<a id="transaction-failures"></a>
## معامله شکست

| وضعیت | معنا | پاسخ ایمن |
|---|---|---|
| `invalid_input` | درخواست جایگزینی متن معتبری نبود یا هدف معتبری نداشت. | پیکربندی صحیح. بدون تغییر دوباره سعی نکنید. |
| `stale_pending_cleanup_failed` | یک فایل معلق قدیمی حذف نشد. | فایل معلق را قبل از پاکسازی دستی متوقف و حفظ کنید. |
| `stale_rollback_requires_review` | داده‌های بازیابی در کنار هدف فعلی وجود دارد و نمی‌توان آنها را به‌طور ایمن دور انداخت. | قبل از انتخاب هر کدام، بایت های هدف و بازگشت را مقایسه کنید. |
| `interrupted_transaction_restore_failed` | بازیابی پس از جایگزینی قطع شده نتوانست هدف را بازیابی کند. | سرور را متوقف نگه دارید و یک نسخه پشتیبان تأیید شده را بازیابی کنید. |
| `interrupted_transaction_cleanup_failed` | هدف بازیابی شد اما داده‌های تراکنش قدیمی پاک نشدند. | بایت‌های هدف را تأیید کنید، سپس فقط چرخ کناری قدیمی نام‌گذاری شده را حذف کنید. |
| `pending_write_failed` | نامزد نمی تواند نوشته شود. | دایرکتوری هدف باریک و فضای خالی را بررسی کنید. |
| `pending_readback_failed` / `pending_readback_mismatch` | بایت های کاندید پس از نوشتن قابل خواندن یا تغییر نیستند. | فایل معلق را تبلیغ نکنید. |
| `pending_validation_failed` | نامزد شکست خورد schema/profile اعتبارسنجی قبل از ارتقاء. | کلید یا قانون گزارش شده را اصلاح کنید. اعتبار سنجی را دور نزنید. |
| `operation_backup_failed` / `backup_failed` | یک نسخه پشتیبان تأیید شده از قبل از نوشتن ایجاد نشد. | توقف؛ هیچ جایگزین هدفی نباید قابل اعتماد باشد. |
| `original_preserved_move_failed` | هدف اصلی را نمی توان به موقعیت بازیابی منتقل کرد. | همه فایل های تراکنش را حفظ کنید و به صورت دستی بازیابی کنید. |
| `promotion_failed` | نامزد معلق نمی تواند به هدف تولید تبدیل شود. | قبل از تلاش مجدد بررسی کنید که آیا نسخه اصلی بازیابی شده است یا خیر. |
| `production_validation_failed` | بایت های تبلیغی تولید نشد readback/validation. | پشتیبان تأیید شده را بازیابی کنید و نویسنده هدف را بررسی کنید. |
| `replacement_committed_recovery_cleanup_failed` | جایگزینی معتبر است، اما داده های برگشتی پاک نشد. | با هدف به عنوان متعهد رفتار کنید. فقط داده های بازیابی قدیمی تایید شده را حذف کنید. |
| `rollback_failed` | بازیابی خودکار تأیید نشد. | سرور را متوقف نگه دارید و از بازیابی دستی استفاده کنید. |

<a id="target-profile-adapter-and-export-failures"></a>
## مشکلات هدف، نمایه، آداپتور و صادرات

| وضعیت | معنا | پاسخ ایمن |
|---|---|---|
| `target_refused` | مسیر پیکربندی شده خارج از مرز حالت مجاز است. | مسیر را تصحیح کنید. هرگز مرز را تضعیف نکنید. |
| `target_directory_failed` | دایرکتوری هدف ایجاد یا تأیید نشد. | فقط وجود و مجوزهای آن دایرکتوری را بررسی کنید. |
| `profile_validation_failed` | کلیدی در نمایه وجود ندارد، type/range، یا یک قانون ثابت باقی مانده را نقض می کند. | از کلید نامگذاری شده، `sandbox.profile_overrides` و مرجع نمایه برای تعمیر منبع. |
| `skipped_incompatible` | یک مد اختیاری وجود دارد اما با امضای آداپتور پشتیبانی شده مطابقت ندارد. | آن را بدون تغییر بگذارید یا آداپتور را غیرفعال کنید. |
| `external_mods_partial` | برخی آداپتورهای اختیاری تکمیل شدند و برخی دیگر با خیال راحت skipped/failed. | ردیف های آداپتور را به طور مستقل بررسی کنید. نتیجه جعبه شنی جدا است. |
| `external_adapter_failed` | آداپتور مورد نیاز با خیال راحت تکمیل نشد. | قبل از تلاش مجدد، نسخه پشتیبان تأیید شده آن را بازیابی کنید. |
| `degraded_state_persistence` | آماده سازی جعبه ایمنی کامل شد، اما تداوم وضعیت چرخش انجام نشد. | فرض نکنید که راه‌اندازی بعدی به درستی پیش می‌رود. ذخیره سازی وضعیت را تعمیر کنید. |
| `export_directory_failed` | `web_export/` ایجاد یا نوشته نشد. | آماده سازی بازی ممکن است همچنان معتبر باشد. گزارش تعمیر به طور جداگانه. |

<a id="translation-and-message-validation-errors"></a>
## خطاهای ترجمه و اعتبارسنجی پیام

اینها خرابی در فرهنگ لغت یا قرارداد ارائه است. آنها قبل از انتشار تأیید می شوند و همچنین ممکن است به عنوان یک هشدار وضعیت زمان اجرا محدود ظاهر شوند.

| متن خطا | معنا | پاسخ ایمن |
|---|---|---|
| `dictionary coverage mismatch` |  فرهنگ لغت نمایه همه تنظیمات مستند را توضیح نمی دهد. | مدخل فرهنگ لغت گمشده را اضافه کنید و نمایه را دوباره اجرا کنید generation/validation. |
| `missing profile setting` | یک نمایه انتخابی فاقد تنظیمات مورد نیاز dictionary/schema. | تعمیر منبع خانواده نمایه. یک پیش فرض زمان اجرا اختراع نکنید. |
| `empty explanation` | تنظیمی وجود دارد اما operator/player توضیح. | قبل از انتشار، توضیحی به زبان ساده اضافه کنید. |
| `join line too wide` | خط الحاق ایجاد شده از محدودیت منبع 42 نویسه بیشتر است. |  عبارت فرهنگ لغت را کوتاه کنید. به بسته بندی مشتری تکیه نکنید. |
| `join message too tall` | خلاصه پیوستن ایجاد شده بیش از چهار خط است. | محتوای پیام را کاهش یا اولویت بندی مجدد کنید. |
