# RandomDay اسناد نمایه

> **منبع انگلیسی متعارف:** [README.md](../../../profiles/README.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


نسخه: `v0.3.16-alpha`

- خانواده ها: **17**
- نمایه ها: **289**
- SandboxSettings مدخل های فرهنگ لغت: **46**

یک خانواده را بر اساس هدف بازی در [راهنمای انتخاب نمایه](../%DB%8C%DA%A9_%D9%86%D9%85%D8%A7%DB%8C%D9%87_%D8%B1%D8%A7_%D8%A7%D9%86%D8%AA%D8%AE%D8%A7%D8%A8_%DA%A9%D9%86%DB%8C%D8%AF.md)، سپس از این شاخص تولید شده برای مقادیر دقیق استفاده کنید.

این فایل‌ها از منبع Lua زمان اجرا و dictionary/translation. آنها `sandbox.profile_overrides` پیش فرض; مقادیر پیکربندی شده یک سرور ممکن است متفاوت باشد:

- `profiles.generated.json`: نمایه‌های قابل خواندن ماشین، مقادیر خام، فرهنگ لغت و ترجمه‌ها.
- `FULL_PROFILE_REFERENCE.md`: قوانین فهرست و تفسیر کامل.
- `SANDBOX_SETTINGS_KEYS.md`: فرهنگ لغت 46 کلیدی کامل.
- `families/*.md`: ارجاعات مفصل 17 روزه خانواده.

بازسازی با: `python -B tools/generate_profile_docs.py` دریفت را با: `python -B tools/generate_profile_docs.py --check`
