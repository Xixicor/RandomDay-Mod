# Changelog

## v0.3.16-alpha

- Added two complete packages: one for dedicated servers and one for
  singleplayer or LAN worlds.
- Added persistent and temporary dedicated-server modes, configurable starting
  profiles, and sequential or non-repeating random progression.
- Expanded the library to seventeen profile families with seventeen profiles
  in each family.
- Added readable active/prepared profile status, compact player notices, safe
  sandbox writes, verified backups, readback, and rollback.
- Added optional, layout-checked adapters for supported companion mods.
- Added persistent profile-wide controls for Hardcore Mode, Iron Mode,
  structural support, and bridge support in the public server configuration.
- Added a complete English guide library and 27 localized entry pages.
- Validated the release packages as clean, deterministic, case-safe UE4SS
  layouts with no private configuration or runtime data.
